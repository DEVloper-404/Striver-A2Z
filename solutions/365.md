# Check for Prime Number

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Know Basic Maths

## Problem
Given a positive integer `n`, return `true` if it is prime — that is, `n > 1` and its only divisors are 1 and itself — otherwise `false`.

Input: `n = 29`
Output: `true`

Input: `n = 1`
Output: `false`

Input: `n = 91`
Output: `false` (7 × 13)

## Approach 1: Test every possible divisor
Loop `d` from 2 to `n - 1`; if any divides `n`, it is composite. Equivalently, count the divisors from 1 to `n` and check whether the count is exactly 2.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Test divisors up to √n
If `n = a × b` with `a ≤ b`, then `a ≤ √n`. So if no `d ≤ √n` divides `n`, nothing larger can either (its partner would be smaller than `√n`). Loop while `d * d ≤ n`.

Small refinements: reject `n < 2` first, handle 2 and 3 directly, and then test only odd `d` (or numbers of the form `6k ± 1`) to skip obvious composites.

- **Time:** O(√n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    bool isPrime(int n) {
        if (n < 2) return false;
        if (n < 4) return true;          // 2 and 3
        if (n % 2 == 0 || n % 3 == 0) return false;
        for (long long d = 5; d * d <= n; d += 6) {
            if (n % d == 0 || n % (d + 2) == 0) return false;
        }
        return true;
    }
};
```

### Python
```python
class Solution:
    def isPrime(self, n: int) -> bool:
        if n < 2:
            return False
        if n < 4:
            return True  # 2 and 3
        if n % 2 == 0 or n % 3 == 0:
            return False
        d = 5
        while d * d <= n:
            if n % d == 0 or n % (d + 2) == 0:
                return False
            d += 6
        return True
```

## Key Takeaways
- A divisor pair `(a, b)` always has one member `≤ √n`, so testing up to `√n` is sufficient.
- `1` is not prime and `2` is the only even prime — handle both before the loop.
- Compare `d * d <= n` in 64-bit arithmetic to avoid overflow near the `int` limit.
- For many queries on a range, use the Sieve of Eratosthenes instead of repeating this test.
