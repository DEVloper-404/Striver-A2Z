# Power Set

**Difficulty:** Medium  ·  **Topic:** Recursion [PatternWise] › Subsequences Pattern

## Problem
Given a string (or array) of `n` distinct elements, print every possible subsequence, i.e. the power set. A subsequence keeps the original relative order but may skip any elements; the empty subsequence counts. There are exactly `2^n` of them.

Input: `s = "abc"`
Output: `["", "a", "b", "c", "ab", "ac", "bc", "abc"]` (any order)

## Approach 1: Recursion — take or skip each element
Walk the input from left to right. At every index there are two choices: include the current character in the subsequence being built or leave it out. Recurse on both choices; when the index reaches `n`, the buffer holds one complete subsequence.

1. `solve(i, cur)`: if `i == n`, record `cur` and return.
2. Append `s[i]`, recurse with `i + 1`, then remove `s[i]` (backtrack).
3. Recurse with `i + 1` without appending.

This is the template for the whole "subsequences pattern"; almost every later problem in this section is this recursion with an extra condition.
- **Time:** O(2^n · n) — 2^n leaves, each copying up to n characters.
- **Space:** O(n) recursion depth (excluding output)

## Approach 2: Bitmask enumeration
Every subsequence corresponds to an `n`-bit number: bit `j` set means "include `s[j]`". Loop `mask` from `0` to `2^n - 1`, and for each mask collect the characters whose bit is set. This is iterative and equally fast; it is the version to reach for when recursion depth is a concern or when you want the output in a deterministic index order.
- **Time:** O(2^n · n)
- **Space:** O(n) for the current subsequence (excluding output)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
public:
    vector<string> powerSet(const string& s) {
        int n = s.size();
        vector<string> out;
        out.reserve(1 << n);
        for (int mask = 0; mask < (1 << n); mask++) {
            string cur;
            for (int j = 0; j < n; j++) {
                if (mask & (1 << j)) cur.push_back(s[j]);
            }
            out.push_back(cur);
        }
        return out;
    }
};
```

### Java
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> powerSet(String s) {
        int n = s.length();
        List<String> out = new ArrayList<>();
        for (int mask = 0; mask < (1 << n); mask++) {
            StringBuilder cur = new StringBuilder();
            for (int j = 0; j < n; j++) {
                if ((mask & (1 << j)) != 0) cur.append(s.charAt(j));
            }
            out.add(cur.toString());
        }
        return out;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def powerSet(self, s: str) -> List[str]:
        n = len(s)
        out: List[str] = []
        for mask in range(1 << n):
            cur = [s[j] for j in range(n) if mask & (1 << j)]
            out.append("".join(cur))
        return out
```

## Key Takeaways
- "Take it or leave it" at each index is the fundamental subsequence recursion; memorise its shape.
- Bitmask enumeration is the iterative twin: `n` bits ↔ `n` include/exclude decisions.
- Output size is `2^n`, so `n` beyond roughly 20–25 is impractical regardless of method.
- Include the empty subsequence unless the problem explicitly excludes it.
