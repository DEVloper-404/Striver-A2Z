# Add one to a number represented by LL

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
A non-negative integer is stored in a singly linked list one digit per node, most significant digit first. Add 1 to the number and return the head of the resulting list. The carry may propagate all the way to the front, in which case a new leading node is needed.

```
Input:  1 -> 9 -> 9
Output: 2 -> 0 -> 0

Input:  9 -> 9
Output: 1 -> 0 -> 0
```

## Approach 1: Reverse, add, reverse back
Because the least significant digit is at the tail, reverse the list so it comes first. Walk with `carry = 1`: set `node.val = (val + carry) % 10`, `carry = (val + carry) / 10`, and stop early once the carry is 0. Reverse the list again. If a carry remains, prepend a node with value 1.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Recursion carrying from the back (optimal for space-free traversal)
Recurse to the end of the list first, then on the way back apply the carry to each node. Define `addCarry(node)` that returns the carry left after adding 1 to the sub-number starting at `node`:

1. If `node` is null, return 1 (this is the "+1" entering from the right).
2. `carry = addCarry(node.next)`; `sum = node.val + carry`; write `sum % 10` and return `sum / 10`.

After the top call, if the returned carry is 1, create a new head with value 1. No list reversal, but the recursion uses stack space proportional to the length.

- **Time:** O(n)
- **Space:** O(n) recursion stack

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
    int addCarry(ListNode* node) {
        if (!node) return 1;
        int carry = addCarry(node->next);
        int sum = node->val + carry;
        node->val = sum % 10;
        return sum / 10;
    }
public:
    ListNode* addOne(ListNode* head) {
        int carry = addCarry(head);
        if (carry) {
            ListNode* newHead = new ListNode(1);
            newHead->next = head;
            return newHead;
        }
        return head;
    }
};
```

```java
class Solution {
    private int addCarry(ListNode node) {
        if (node == null) return 1;

        }

    }
```

```python
class Solution:
    def _add_carry(self, node) -> int:
        if node is None:
            return 1
        carry = self._add_carry(node.next)
        total = node.val + carry
        node.val = total % 10
        return total // 10

    def addOne(self, head):
        carry = self._add_carry(head)
        if carry:
            return ListNode(1, head)
        return head
```

## Key Takeaways
- Digit addition must start at the least significant end; either reverse the list or recurse to the tail.
- Treat the initial "+1" as a carry of 1 entering from the right, which unifies the logic.
- A leftover carry after the most significant digit means a new leading node.
- The reverse-twice method is preferable for very long lists since it avoids deep recursion.
