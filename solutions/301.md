# Best time to buy and sell stock

**Difficulty:** Medium  ·  **Topic:** Dynamic Programming [Patterns and Problems] › DP on Stocks

## Problem
You are given an array `prices` where `prices[i]` is the price of a stock on day `i`. You may complete **at most one transaction**: buy on one day and sell on a strictly later day. Return the maximum profit achievable, or `0` if no profitable trade exists (you are allowed to do nothing).

```
Input:  prices = [7, 1, 5, 3, 6, 4]
Output: 5      (buy on day 1 at price 1, sell on day 4 at price 6)
```

## Approach 1: Check every pair (Brute Force)
Try every buy day `i` and every sell day `j > i`, and keep the largest `prices[j] - prices[i]`. This is obviously correct because it literally enumerates the whole solution space, but it is quadratic and will time out for `n` up to 10^5.

- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Track the minimum price so far (Optimal)
The key observation: for a fixed **sell day** `j`, the best possible profit is `prices[j] - min(prices[0..j-1])`. Which earlier day gave that minimum does not matter, and nothing about days after `j` affects it. So instead of re-scanning the prefix for every `j`, carry the running minimum along.

Sweep left to right maintaining two values:
1. `minPrice` — the cheapest price seen strictly before the current day.
2. `best` — the best profit found so far.

For each day: first update `best = max(best, price - minPrice)`, then update `minPrice = min(minPrice, price)`. Doing the profit update *before* the minimum update guarantees the buy day is strictly earlier than the sell day (though with this order even a same-day pairing would only contribute `0`, so it is harmless either way).

**Dry run** on `[7, 1, 5, 3, 6, 4]`:

| day | price | best (before update of min) | minPrice after |
|-----|-------|-----------------------------|----------------|
| 0   | 7     | 0 (nothing earlier)         | 7              |
| 1   | 1     | max(0, 1−7) = 0             | 1              |
| 2   | 5     | max(0, 5−1) = 4             | 1              |
| 3   | 3     | max(4, 3−1) = 4             | 1              |
| 4   | 6     | max(4, 6−1) = **5**         | 1              |
| 5   | 4     | max(5, 4−1) = 5             | 1              |

Answer: `5`.

Because losses are never taken (`best` starts at 0 and only ever grows), a strictly decreasing array correctly returns `0`.

- **Time:** O(n)
- **Space:** O(1)

## Approach 3: The DP-on-stocks framing
It is worth seeing this problem in the same language as the harder variants in this section, because that framework generalises. Define a state machine with two states per day:

- `hold` = best cash balance while currently owning the stock.
- `free` = best cash balance while owning nothing.

Transitions for day `i`:
```
hold = max(hold, -prices[i])           // keep holding, or buy today (only one buy allowed,
                                       // so we buy from a zero balance, i.e. -price)
free = max(free, hold + prices[i])     // stay out, or sell today
```
The answer is `free` after the last day. Notice that `hold = max(hold, -price)` is just `-minPrice` in disguise — the greedy single-pass solution *is* this DP, written compactly. Once you add "unlimited transactions" or "at most k transactions", the state machine is the version that keeps working.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int minPrice = INT_MAX;
        int best = 0;
        for (int price : prices) {
            if (minPrice != INT_MAX) best = max(best, price - minPrice);
            minPrice = min(minPrice, price);
        }
        return best;
    }
};
```

### Java
```java
class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE;
        int best = 0;
        for (int price : prices) {
            if (minPrice != Integer.MAX_VALUE) {
                best = Math.max(best, price - minPrice);
            }
            minPrice = Math.min(minPrice, price);
        }
        return best;
    }
}
```

### Python
```python
from typing import List


class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price = float('inf')
        best = 0
        for price in prices:
            if price - min_price > best:
                best = price - min_price
            if price < min_price:
                min_price = price
        return best
```

## Key Takeaways
- Fixing the sell day and asking "what was the cheapest buy before it?" turns an O(n²) pair search into one linear sweep.
- Initialise the answer to `0`, not to a negative sentinel — doing nothing is a legal choice.
- The greedy min-tracking solution is exactly the two-state (`hold` / `free`) stock DP with a single transaction; recognising that makes the II/III/IV variants feel like the same problem.
- An empty or single-element array must return `0`; guard the very first day so you never sell before buying.
