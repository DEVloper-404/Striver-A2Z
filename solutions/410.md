# Pattern 18

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a right-angled triangle of `n` rows using letters, where every row ends at the `n`-th letter. Row 1 has only that last letter, row 2 has the two letters before it up to the last, and so on until the final row prints `A` through the `n`-th letter.

Input: `n = 5`
Output:
```
E
D E
C D E
B C D E
A B C D E
```

## Approach
Each row is a suffix of the alphabet's first `n` letters, so the inner loop starts at a row-dependent letter and always finishes at the same one.

1. Compute the last letter once: `last = 'A' + n - 1`.
2. Outer loop `i` from `0` to `n-1`.
3. Inner loop starts at `last - i` and runs up to `last`, printing each character.
4. Newline.

Row 0 starts at `last`, row 1 at `last - 1`, and the final row starts at `'A'`.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern18(int n) {
    char last = 'A' + n - 1;
    for (int i = 0; i < n; i++) {
        for (char ch = last - i; ch <= last; ch++) {
            cout << ch << " ";
        }
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern18 {
    public static void pattern18(int n) {
        char last = (char) ('A' + n - 1);
        for (int i = 0; i < n; i++) {
            StringBuilder row = new StringBuilder();
            for (char ch = (char) (last - i); ch <= last; ch++) {
                row.append(ch).append(' ');
            }
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern18(n: int) -> None:
    last = ord("A") + n - 1
    for i in range(n):
        print(" ".join(chr(c) for c in range(last - i, last + 1)))
```

## Key Takeaways
- A fixed end point with a moving start point produces a right-aligned sequence in a left-aligned shape.
- Compute the last letter once instead of recalculating it in the inner loop.
- Java needs explicit `char` casts when doing arithmetic; C++ can loop on a `char` directly.
