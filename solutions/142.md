# Power Set Bit Manipulation

**Difficulty:** Medium  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Interview Problems

## Problem
Given an array `nums` of distinct integers, return every possible subset (the power set), including the empty set and the full array. Subsets may be returned in any order, but each subset must appear exactly once.

Input: `nums = [1, 2, 3]`
Output: `[[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]`

## Approach 1: Recursive pick / skip
For each index decide whether to include the element, recursing on the next index. When the index reaches `n`, record the current subset. This produces `2^n` leaves and is the standard backtracking solution.
- **Time:** O(2^n · n)
- **Space:** O(n) recursion depth (plus the output)

## Approach 2: Enumerate bitmasks (Optimal)
There are `2^n` subsets and `2^n` integers in `[0, 2^n)`. Treat each integer `mask` as a membership vector: bit `i` of `mask` is 1 exactly when `nums[i]` is in the subset. Loop `mask` from `0` to `2^n - 1`, and for each mask collect the `nums[i]` whose bit is set.

The mapping is a bijection, so every subset appears once, with no recursion and no duplicate bookkeeping. Iteration order is by mask value, which is a natural way to generate subsets in a fixed order.
- **Time:** O(2^n · n) — every mask is examined and each takes O(n) to expand
- **Space:** O(1) extra beyond the output

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        int n = nums.size();
        vector<vector<int>> out;
        out.reserve(1 << n);
        for (int mask = 0; mask < (1 << n); ++mask) {
            vector<int> cur;
            for (int i = 0; i < n; ++i)
                if (mask & (1 << i)) cur.push_back(nums[i]);
            out.push_back(cur);
        }
        return out;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        int n = nums.length;
        List<List<Integer>> out = new ArrayList<>();
        for (int mask = 0; mask < (1 << n); mask++) {
            List<Integer> cur = new ArrayList<>();
            for (int i = 0; i < n; i++)
                if ((mask & (1 << i)) != 0) cur.add(nums[i]);
            out.add(cur);
        }
        return out;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        n = len(nums)
        out = []
        for mask in range(1 << n):
            out.append([nums[i] for i in range(n) if mask & (1 << i)])
        return out
```

## Key Takeaways
- `n` elements give `2^n` subsets, and the integers `0 .. 2^n - 1` index them one-to-one via their bits.
- `mask & (1 << i)` tests membership of element `i`; `mask = 0` is the empty set, `mask = 2^n - 1` is the full set.
- The same idea yields "iterate over all submasks of a mask": `for (s = m; s; s = (s - 1) & m)`.
- Keep `n` below about 20; beyond that `2^n` subsets are too many to materialise.
