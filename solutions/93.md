# Find the smallest divisor

**Difficulty:** Medium  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on Answers

## Problem
Given an array of positive integers `nums` and an integer `threshold`, choose a positive integer divisor `d`, divide every element by `d`, round each result *up*, and sum them. Return the smallest `d` whose sum is `<= threshold`. A valid answer always exists.

Input: nums = [1, 2, 5, 9], threshold = 6
Output: 5  (ceil(1/5)+ceil(2/5)+ceil(5/5)+ceil(9/5) = 1+1+1+2 = 5 <= 6; with d=4 the sum is 7)

## Approach 1: Try Every Divisor
Any `d >= max(nums)` gives the minimum possible sum `n` (every term becomes 1), so the answer is in `[1, max(nums)]`. Loop `d` from 1 upward, compute the ceiling sum, and return the first `d` that fits under `threshold`.
- **Time:** O(max(nums) * n)
- **Space:** O(1)

## Approach 2: Binary Search on the Divisor
Increasing `d` can only shrink each `ceil(nums[i] / d)`, so the sum is non-increasing in `d`. That monotonicity lets us binary search `d` in `[1, max(nums)]`: if the sum at `mid` is `<= threshold`, remember `mid` and go left; otherwise go right.
- **Time:** O(n * log(max(nums)))
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    long long ceilSum(const vector<int>& nums, int d) {
        long long s = 0;
        for (int x : nums) s += (x + d - 1LL) / d;
        return s;
    }

    int smallestDivisor(vector<int>& nums, int threshold) {
        int lo = 1, hi = *max_element(nums.begin(), nums.end());
        int ans = hi;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (ceilSum(nums, mid) <= threshold) {
                ans = mid;
                hi = mid - 1;
            } else {
                lo = mid + 1;
            }
        }
        return ans;
    }
};
```

### Java
```java
class Solution {
    private long ceilSum(int[] nums, int d) {
        long s = 0;
        for (int x : nums) s += (x + d - 1L) / d;
        return s;
    }

    public int smallestDivisor(int[] nums, int threshold) {
        int hi = 0;
        for (int x : nums) hi = Math.max(hi, x);
        int lo = 1, ans = hi;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (ceilSum(nums, mid) <= threshold) {
                ans = mid;
                hi = mid - 1;
            } else {
                lo = mid + 1;
            }
        }
        return ans;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def smallestDivisor(self, nums: List[int], threshold: int) -> int:
        def ceil_sum(d: int) -> int:
            return sum((x + d - 1) // d for x in nums)

        lo, hi = 1, max(nums)
        ans = hi
        while lo <= hi:
            mid = (lo + hi) // 2
            if ceil_sum(mid) <= threshold:
                ans = mid
                hi = mid - 1
            else:
                lo = mid + 1
        return ans
```

## Key Takeaways
- Structurally identical to Koko Eating Bananas: a non-increasing cost function and a "find the smallest feasible value" query.
- Upper bound is `max(nums)` because beyond it every term is already 1.
- Use integer ceiling division; keep the running sum in 64-bit to be safe.
