# Largest Odd Number in a String

**Difficulty:** Easy  ·  **Topic:** Strings [Basic and Medium] › Basic and Easy String Problems

## Problem
You get a string `num` made of decimal digits. Return the largest odd integer (as a string, no leading-zero stripping needed since the input has none) that appears as a **substring** of `num`. If no odd number exists, return the empty string.

Input: `num = "52"`
Output: `"5"`

Input: `num = "4206"`
Output: `""`

Input: `num = "35427"`
Output: `"35427"`

## Approach 1: Enumerate all substrings
Generate every substring, keep those whose last digit is odd, and track the numerically largest (compare by length first, then lexicographically). Correct but far too slow for long inputs.
- **Time:** O(n^2) substrings, O(n) each to compare → O(n^3)
- **Space:** O(n)

## Approach 2: Longest prefix ending in an odd digit (Optimal)
Two observations:
1. A number is odd iff its last digit is odd.
2. Among substrings, the longest ones are prefixes (they start at index 0). A longer number with no leading zero is always larger than a shorter one.

So the answer is the prefix `num[0..i]` where `i` is the **rightmost** odd digit. Scan from the end, stop at the first odd digit, and return everything up to and including it. If no odd digit exists, return `""`.
- **Time:** O(n)
- **Space:** O(1) extra (the returned substring is O(n))

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Solution {
public:
    string largestOddNumber(string num) {
        for (int i = (int)num.size() - 1; i >= 0; --i) {
            if ((num[i] - '0') % 2 == 1) {
                return num.substr(0, i + 1);
            }
        }
        return "";
    }
};
```

### Java
```java
class Solution {
    public String largestOddNumber(String num) {
        for (int i = num.length() - 1; i >= 0; i--) {
            if ((num.charAt(i) - '0') % 2 == 1) {
                return num.substring(0, i + 1);
            }
        }
        return "";
    }
}
```

### Python
```python
class Solution:
    def largestOddNumber(self, num: str) -> str:
        for i in range(len(num) - 1, -1, -1):
            if int(num[i]) % 2 == 1:
                return num[:i + 1]
        return ""
```

## Key Takeaways
- Parity of a decimal number depends only on its last digit.
- "Largest substring number" reduces to "longest useful prefix" because the input has no leading zeros.
- Scan from the right so the first hit is the answer; no comparisons needed.
- Edge cases: all even digits (return `""`), a single odd digit, and the whole string being odd.
