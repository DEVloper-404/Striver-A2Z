# Pattern 6

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print an inverted number triangle with `n` rows. Row `i` (0-indexed) contains the numbers `1` through `n - i` separated by spaces.

Input: `n = 5`
Output:
```
1 2 3 4 5
1 2 3 4
1 2 3
1 2
1
```

## Approach
Combine the shrinking bound of Pattern 5 with the column-counter printing of Pattern 3.

1. Outer loop `i` from `0` to `n-1`.
2. Inner loop `j` from `1` to `n - i` prints `j` and a space.
3. Newline after the row.

Each row restarts counting from 1, and the row length decreases by one each time.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern6(int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 1; j <= n - i; j++) {
            cout << j << " ";
        }
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern6 {
    public static void pattern6(int n) {
        for (int i = 0; i < n; i++) {
            StringBuilder row = new StringBuilder();
            for (int j = 1; j <= n - i; j++) {
                row.append(j).append(' ');
            }
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern6(n: int) -> None:
    for length in range(n, 0, -1):
        print(" ".join(str(j) for j in range(1, length + 1)))
```

## Key Takeaways
- Shape (how many items per row) and content (what each item is) are independent decisions; mix and match them.
- The inner loop starts at 1 every row, so the printed sequence always begins with 1.
- Verify the first row prints `1 … n` and the last row prints just `1`.
