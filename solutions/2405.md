# Print name N times using recursion

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Learn Basic Recursion

## Problem
Given a string `name` and an integer `N`, print `name` exactly `N` times, one per line, using recursion rather than a loop. This is the same exercise as printing a message `N` times, but the string is a parameter.

Input: `name = "Alice", N = 3`
Output:
```
Alice
Alice
Alice
```

## Approach 1: Parameterised recursion
Add the string as an extra argument that is passed unchanged through every call, while the counter shrinks.

1. Base case: `n == 0` → return.
2. Print `name`.
3. Recurse with `n - 1`.

The string is never copied by value in the recursion if you pass it by reference (C++) or as an object reference (Java/Python), so the extra parameter costs nothing.

- **Time:** O(n) calls (plus O(L) per print for a name of length L)
- **Space:** O(n) recursion depth

## Approach 2: Index-based recursion
Keep a counter `i` starting at 1 and stop when `i > n`. Functionally identical; it is the form you will reuse when the *value* of the counter matters (for example printing 1 to N).

- **Time:** O(n)
- **Space:** O(n) stack

## Code (Optimal)

### C++
```cpp
#include <iostream>
#include <string>
using namespace std;

void printName(const string& name, int n) {
    if (n == 0) return;
    cout << name << '\n';
    printName(name, n - 1);
}

int main() {
    printName("Alice", 3);
    return 0;
}
```

### Java
```java
public class Main {
    static void printName(String name, int n) {
        if (n == 0) return;
        System.out.println(name);
        printName(name, n - 1);
    }

    public static void main(String[] args) {
        printName("Alice", 3);
    }
}
```

### Python
```python
def print_name(name: str, n: int) -> None:
    if n == 0:
        return
    print(name)
    print_name(name, n - 1)

if __name__ == "__main__":
    print_name("Alice", 3)
```

## Key Takeaways
- Values that never change across calls (the name) are just carried along as parameters; the value that changes (`n`) drives the base case.
- Passing large objects by reference keeps recursion cheap.
- Depth is O(n): for very large `n` a loop is safer because most languages cap the stack at a few thousand to a few hundred thousand frames (Python defaults to 1000).
