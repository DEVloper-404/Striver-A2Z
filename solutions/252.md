# Counting Frequencies of Array Elements

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Learn Basic Hashing

## Problem
Given an array `arr` of `n` integers, report how many times each distinct value appears. Output each distinct value together with its frequency (any consistent order is fine; ascending by value is typical).

Input: `arr = [10, 5, 10, 15, 10, 5]`
Output:
```
5 -> 2
10 -> 3
15 -> 1
```

## Approach 1: Brute force with a visited array
For each index `i` that has not been counted yet, scan the rest of the array, count matches, and mark every match as visited so it is not reported again.

- **Time:** O(n²)
- **Space:** O(n) for the visited flags

## Approach 2: Sort, then count runs
Sort the array; equal elements become adjacent. Walk once and count the length of each run of equal values.

- **Time:** O(n log n)
- **Space:** O(1) extra (ignoring the sort's internal space)

## Approach 3: Hash map counting (optimal)
Make one pass over the array, incrementing `freq[x]` for each element. Use a counting array if values are small non-negative integers, otherwise a hash map. Then iterate the map to print each value with its count. This is the "pre-store, then fetch" idea from basic hashing applied to every element at once.

- **Time:** O(n) average (O(n log n) if you use an ordered map for sorted output)
- **Space:** O(k) where k is the number of distinct values

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    // Returns (value, frequency) pairs in ascending order of value.
    vector<pair<int, int>> countFrequencies(const vector<int>& arr) {
        unordered_map<int, int> freq;
        for (int x : arr) freq[x]++;

        vector<pair<int, int>> result(freq.begin(), freq.end());
        sort(result.begin(), result.end());
        return result;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    // Returns (value, frequency) pairs in ascending order of value.
    public List<int[]> countFrequencies(int[] arr) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : arr) freq.merge(x, 1, Integer::sum);

        List<int[]> result = new ArrayList<>();
        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            result.add(new int[]{e.getKey(), e.getValue()});
        }
        result.sort((a, b) -> Integer.compare(a[0], b[0]));
        return result;
    }
}
```

### Python
```python
from collections import Counter

class Solution:
    # Returns (value, frequency) pairs in ascending order of value.
    def countFrequencies(self, arr: list[int]) -> list[tuple[int, int]]:
        freq = Counter(arr)
        return sorted(freq.items())
```

## Key Takeaways
- One pass with a hash map turns an O(n²) counting problem into O(n).
- Pick the container by key range: counting array for small non-negative integers, hash map otherwise, ordered map when sorted output is required.
- The same frequency table answers follow-up questions (most/least frequent element, duplicates, elements appearing exactly k times) without touching the array again.
