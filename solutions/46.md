# Move Zeros to End

**Difficulty:** Easy  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Easy

## Problem
Given an integer array `nums`, move every `0` to the end while keeping the relative order of the non-zero elements. The operation must be done in place, without making a copy of the array.

Input: `nums = [0, 1, 0, 3, 12]`
Output: `[1, 3, 12, 0, 0]`

## Approach 1: Collect Non-Zeros, Then Pad
Copy all non-zero values into a temporary list in order, write them back to the front of `nums`, and fill the rest with zeros.

- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Two Pointers (Optimal)
Keep a pointer `j` that marks where the next non-zero value should go (i.e. the index of the first zero in the processed prefix). Scan with `i`:

- If `nums[i] != 0`, swap `nums[i]` with `nums[j]` and advance `j`.
- If `nums[i] == 0`, do nothing; `j` stays on the zero.

Invariant: every index below `j` is non-zero, every index in `[j, i)` is zero. Because we only ever swap a non-zero forward past zeros, the relative order of the non-zero elements is preserved. Swapping when `i == j` is harmless.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <utility>
using namespace std;

class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int j = 0;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] != 0) {
                swap(nums[i], nums[j]);
                j++;
            }
        }
    }
};
```

### Java
```java
class Solution {
    public void moveZeroes(int[] nums) {
        int j = 0;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) {
                int tmp = nums[i];
                nums[i] = nums[j];
                nums[j] = tmp;
                j++;
            }
        }
    }
}
```

### Python
```python
class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        j = 0
        for i in range(len(nums)):
            if nums[i] != 0:
                nums[i], nums[j] = nums[j], nums[i]
                j += 1
```

## Key Takeaways
- Classic partition-by-predicate with two pointers: `j` tracks the boundary of the "good" prefix, `i` scans.
- Swapping (rather than overwriting and then padding) keeps it to a single pass and preserves order.
- Edge cases: no zeros (every step swaps an element with itself), all zeros (`j` never moves).
