# Find square root of a number

**Difficulty:** Medium  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on Answers

## Problem
Given a non-negative integer `n`, return the floor of its square root, i.e. the largest integer `x` such that `x * x <= n`. Do not use built-in `sqrt`.

Input: n = 28
Output: 5  (5*5 = 25 <= 28, but 6*6 = 36 > 28)

Input: n = 36
Output: 6

## Approach 1: Linear Scan
Try `x = 1, 2, 3, ...` and stop at the first `x` whose square exceeds `n`; the answer is `x - 1`. Straightforward but wasteful for large `n`.
- **Time:** O(sqrt(n))
- **Space:** O(1)

## Approach 2: Binary Search on the Answer
The predicate "`x * x <= n`" is true for every `x` up to the answer and false beyond it, so the search space `[1, n]` is monotone. Keep `lo = 1`, `hi = n`. At each step compute `mid`; if `mid * mid <= n`, `mid` is a candidate, record it and move `lo = mid + 1`; otherwise move `hi = mid - 1`. The last recorded candidate is the floor square root. Use 64-bit arithmetic so `mid * mid` does not overflow.
- **Time:** O(log n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    long long floorSqrt(long long n) {
        long long lo = 1, hi = n, ans = 0;
        while (lo <= hi) {
            long long mid = lo + (hi - lo) / 2;
            if (mid * mid <= n) {
                ans = mid;
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return ans;
    }
};
```

### Python
```python
class Solution:
    def floorSqrt(self, n: int) -> int:
        lo, hi, ans = 1, n, 0
        while lo <= hi:
            mid = (lo + hi) // 2
            if mid * mid <= n:
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1
        return ans
```

## Key Takeaways
- Classic "binary search on answer": the condition `mid*mid <= n` is monotone, so we can find the boundary.
- Always use 64-bit types for `mid * mid`; `int` overflows once `n` is around 2^31.
- `n = 0` and `n = 1` are handled naturally (`ans` starts at 0; for `n = 1` the loop records 1).
- When the loop ends, `hi` also holds the answer, so `return hi` works too.
