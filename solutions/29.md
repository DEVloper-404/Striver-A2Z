# Kadane's Algorithm

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Medium

## Problem
Given an integer array `nums` (which may contain negatives), find the contiguous subarray with the largest sum and return that sum. The subarray must contain at least one element, so if every number is negative the answer is the largest single element.

```
Input:  nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
Output: 6        (subarray [4, -1, 2, 1])
```

## Approach 1: Brute Force
Enumerate every `(start, end)` pair, add up the elements between them, and keep the best. Computing each sum from scratch gives O(n³); accumulating the sum while extending `end` brings it down to O(n²).
- **Time:** O(n²) (O(n³) if each sum is recomputed)
- **Space:** O(1)

## Approach 2: Kadane's Algorithm (Optimal)
Scan left to right maintaining `cur`, the best sum of a subarray that *ends at the current index*. When we reach `nums[i]` we have two choices: extend the previous best subarray (`cur + nums[i]`) or start fresh at `nums[i]`. Taking the maximum of these two is the same as saying "if `cur` went negative, throw it away". Track the global maximum across all `cur` values.

Why it works: a negative prefix can never help a subarray that continues past it, so dropping it is always safe. Because we initialise `best` with `nums[0]` (not 0), the all-negative case is handled correctly.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        long long cur = nums[0], best = nums[0];
        for (size_t i = 1; i < nums.size(); ++i) {
            cur = max<long long>(nums[i], cur + nums[i]);
            best = max(best, cur);
        }
        return (int)best;
    }
};
```

### Java
```java
class Solution {
    public int maxSubArray(int[] nums) {
        long cur = nums[0], best = nums[0];
        for (int i = 1; i < nums.length; i++) {
            cur = Math.max(nums[i], cur + nums[i]);
            best = Math.max(best, cur);
        }
        return (int) best;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        cur = best = nums[0]
        for x in nums[1:]:
            cur = max(x, cur + x)
            best = max(best, cur)
        return best
```

## Key Takeaways
- Kadane is dynamic programming in disguise: `cur[i] = max(nums[i], cur[i-1] + nums[i])`.
- Initialise `best` with the first element, not 0, or an all-negative array returns the wrong answer.
- Use a wider type for running sums if the values are large enough to overflow.
- The same scan can record `start`/`end` indices to print the subarray itself (see the extended version).
