# Next Permutation

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Medium

## Problem
Given an array of integers representing a permutation, rearrange it in place into the next permutation in lexicographic (dictionary) order. If the array is already the largest possible arrangement (fully descending), wrap around to the smallest one (fully ascending). Only constant extra memory is allowed.

```
Input:  nums = [1, 3, 2]
Output: [2, 1, 3]

Input:  nums = [3, 2, 1]
Output: [1, 2, 3]
```

## Approach 1: Brute Force
Generate every permutation of the array in sorted order, locate the current one, and return the one that follows it (or the first one if the current is last). Correct but hopeless for anything beyond tiny inputs since there are `n!` permutations.
- **Time:** O(n! · n)
- **Space:** O(n! · n) to hold the list (or O(n) with a generator, still O(n!) time)

## Approach 2: Pivot, Swap, Reverse (Optimal)
Think about how dictionary order works: to get the *next* word you change the rightmost position you possibly can.
1. **Find the pivot.** Scan from the right for the first index `i` where `nums[i] < nums[i+1]`. Everything after `i` is non-increasing, i.e. already the largest arrangement of that suffix. If no such `i` exists the whole array is descending; just reverse it and stop.
2. **Find the successor.** Scan from the right again for the first index `j` with `nums[j] > nums[i]`. Because the suffix is sorted descending, this is the smallest value larger than `nums[i]`. Swap `nums[i]` and `nums[j]`.
3. **Minimise the suffix.** The suffix after `i` is still descending; reverse it so it becomes ascending, i.e. the smallest arrangement.

Step 2 makes the prefix as small as possible while still being larger; step 3 makes the tail as small as possible. Together that is exactly the next permutation.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    void nextPermutation(vector<int>& nums) {
        int n = (int)nums.size();
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) --i;   // 1. pivot
        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) --j;             // 2. successor
            swap(nums[i], nums[j]);
        }
        reverse(nums.begin() + i + 1, nums.end());      // 3. minimise suffix
    }
};
```

### Java
```java
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) i--;
        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) j--;
            swap(nums, i, j);
        }
        reverse(nums, i + 1, n - 1);
    }

    private void swap(int[] a, int x, int y) {
        int t = a[x]; a[x] = a[y]; a[y] = t;
    }

    private void reverse(int[] a, int lo, int hi) {
        while (lo < hi) swap(a, lo++, hi--);
    }
}
```

### Python
```python
from typing import List

class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        n = len(nums)
        i = n - 2
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1
        if i >= 0:
            j = n - 1
            while nums[j] <= nums[i]:
                j -= 1
            nums[i], nums[j] = nums[j], nums[i]
        nums[i + 1:] = nums[i + 1:][::-1]
```

## Key Takeaways
- The rightmost "ascent" (`nums[i] < nums[i+1]`) is the only place you can increase the permutation by a minimal amount.
- Use `>=` / `<=` comparisons so duplicates are skipped correctly and the swap picks the rightmost strictly-greater element.
- If no pivot is found, `i` is -1 and the reverse covers the whole array, giving the wrap-around case for free.
- C++ has `std::next_permutation`, but interviewers expect you to implement it.
