# Count Good Numbers

**Difficulty:** Medium  ·  **Topic:** Recursion [PatternWise] › Get a Strong Hold

## Problem
A digit string of length `n` is "good" if every digit at an even index (0-based) is even (`0, 2, 4, 6, 8`) and every digit at an odd index is a prime (`2, 3, 5, 7`). Given `n` (up to `10^15`), return how many good digit strings of length `n` exist, modulo `10^9 + 7`. Leading zeros are allowed.

Input: `n = 1`
Output: `5` (the strings `"0"`, `"2"`, `"4"`, `"6"`, `"8"`)

Input: `n = 4`
Output: `400` (`5 · 4 · 5 · 4`)

## Approach 1: Multiply position by position
Each position is independent: even indices have 5 choices, odd indices have 4. Loop over all `n` positions multiplying the running answer by 5 or 4 (mod `10^9 + 7`). Correct, but `n` can be `10^15`, so the loop is far too long.
- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Closed form with fast modular exponentiation
Count the positions: there are `ceil(n / 2)` even indices and `floor(n / 2)` odd indices. The answer is therefore

```
5^ceil(n/2) · 4^floor(n/2)   (mod 1e9+7)
```

Both powers are computed with binary exponentiation (recursively: `a^e = (a^(e/2))^2`, times `a` if `e` is odd), taking the modulus after every multiplication. Use 64-bit integers so the intermediate product of two values below `10^9 + 7` does not overflow.
- **Time:** O(log n)
- **Space:** O(log n) recursion depth

## Code (Optimal)

### C++
```cpp
class Solution {
    static const long long MOD = 1'000'000'007LL;
    long long modPow(long long base, long long e) {
        if (e == 0) return 1;
        long long half = modPow(base, e / 2);
        long long res = half * half % MOD;
        if (e & 1) res = res * (base % MOD) % MOD;
        return res;
    }
public:
    int countGoodNumbers(long long n) {
        long long evens = (n + 1) / 2, odds = n / 2;
        return (int)(modPow(5, evens) * modPow(4, odds) % MOD);
    }
};
```

### Python
```python
class Solution:
    def countGoodNumbers(self, n: int) -> int:
        MOD = 10**9 + 7

        def mod_pow(base: int, e: int) -> int:
            if e == 0:
                return 1
            half = mod_pow(base, e // 2)
            res = half * half % MOD
            if e & 1:
                res = res * base % MOD
            return res

        evens, odds = (n + 1) // 2, n // 2
        return mod_pow(5, evens) * mod_pow(4, odds) % MOD
```

## Key Takeaways
- Independent positions multiply: the whole problem is `5^a · 4^b` once you count `a` and `b` correctly.
- `ceil(n/2)` even indices vs `floor(n/2)` odd indices; check with `n = 1` (5) and `n = 2` (20).
- Fast exponentiation is mandatory because `n` is up to `10^15`; reduce mod after every multiply.
- The recursion depth is only about 50, so recursion is safe here.
