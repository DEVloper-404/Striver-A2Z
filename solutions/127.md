# Check for balanced binary tree

**Difficulty:** Medium  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Medium Problems

## Problem
A binary tree is height-balanced if, for every node, the heights of its left and right subtrees differ by at most 1. Given the root, return `true` if the tree is balanced and `false` otherwise. An empty tree counts as balanced.

Input: root = [3,9,20,null,null,15,7]
Output: true

Input: root = [1,2,2,3,3,null,null,4,4]
Output: false  (node 2 on the left has height 3 on its left side and 1 on its right)

## Approach 1: Height at Every Node (Brute Force)
For each node, compute the height of its left subtree and right subtree with a separate recursive `height()` call, check `|lh - rh| <= 1`, then recurse into both children and require them to be balanced too.

This works but recomputes heights repeatedly: a node deep in the tree has its height calculated once for each ancestor.
- **Time:** O(n²) in the worst case (skewed tree), O(n log n) if balanced
- **Space:** O(h) recursion stack

## Approach 2: Height with Early Failure (Optimal)
Merge the height computation and the balance check into one post-order pass. The helper returns the subtree height when the subtree is balanced, and a sentinel `-1` when it is not:

1. If the node is null, return 0.
2. Compute `lh` from the left child; if it is -1, return -1 immediately.
3. Compute `rh` from the right child; if it is -1, return -1.
4. If `|lh - rh| > 1`, return -1; otherwise return `1 + max(lh, rh)`.

The tree is balanced iff the root's helper result is not -1. Each node is visited exactly once.
- **Time:** O(n)
- **Space:** O(h)

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; ... } — standard definition
class Solution {
    int check(TreeNode* node) {
        if (!node) return 0;
        int lh = check(node->left);
        if (lh == -1) return -1;
        int rh = check(node->right);
        if (rh == -1) return -1;
        if (abs(lh - rh) > 1) return -1;
        return 1 + max(lh, rh);
    }
public:
    bool isBalanced(TreeNode* root) {
        return check(root) != -1;
    }
};
```

class Solution:
    def isBalanced(self, root) -> bool:
        def check(node):
            if node is None:
                return 0
            lh = check(node.left)
            if lh == -1:
                return -1
            rh = check(node.right)
            if rh == -1:
                return -1
            if abs(lh - rh) > 1:

            return 1 + max(lh, rh)

        return check(root) != -1

## Key Takeaways
- Returning a sentinel (-1) from the height function lets one traversal both measure and validate — a common trick for "property holds at every node" problems.
- Short-circuit as soon as any subtree reports -1; there is no need to finish the traversal.
- Balance must hold at every node, not just at the root — checking only the root's two subtrees is a classic wrong answer.
