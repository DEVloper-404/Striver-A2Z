# Detect a cycle in an undirected graph

**Difficulty:** Hard  ·  **Topic:** Graphs [Concepts & Problems] › Problems on BFS/DFS

## Problem
Given an undirected graph with `V` vertices numbered `0..V-1`, described by an adjacency list, report whether the graph contains at least one cycle. The graph need not be connected, so every component has to be examined. Here we solve it with DFS.

```
Input:  V = 6, adj = [[1], [0,2,3], [1,4], [1], [2,5], [4,1]]
Output: true          (1 → 2 → 4 → 5 → 1)

Input:  V = 3, adj = [[1], [0,2], [1]]
Output: false
```

## Approach 1: Counting edges (works only for connected graphs)
A connected undirected graph is a tree — and therefore acyclic — exactly when it has `V − 1` edges. So for a *connected* input you could just count edges and compare. But this collapses for disconnected inputs: a graph with a 3-cycle plus two isolated vertices has `V = 5`, `E = 3`, and `E < V − 1` even though a cycle exists. You would have to count vertices and edges per component, which is itself a traversal — so you may as well detect the cycle directly during that traversal.
- **Time:** O(V + E)
- **Space:** O(V), but the reasoning is fragile and easy to get wrong

## Approach 2: DFS carrying the parent (Optimal)
The whole difficulty of undirected cycle detection is that each edge `u — v` is stored twice. Standing on `v` after arriving from `u`, you will always see `u` in `adj[v]` and it will always be visited — that is not a cycle, just the edge you walked in on.

**Key observation:** during a DFS, meeting an already-visited vertex that is *not* your immediate parent means you have found a second, independent route to that vertex. Combine the tree path from that vertex down to you with the edge you just examined, and you have a closed walk of length ≥ 3 — a cycle.

Algorithm:
1. `visited[0..V-1] = false`.
2. For every `s` with `visited[s] == false`, call `dfs(s, -1)`. If any call returns `true`, the answer is `true`.
3. `dfs(node, parent)`:
   - `visited[node] = true`.
   - For each `nb` in `adj[node]`:
     - if `!visited[nb]`: if `dfs(nb, node)` returns `true`, propagate `true`;
     - else if `nb != parent`: return `true`.
   - Return `false`.

Why there are no false negatives: suppose the graph has a cycle `c1 — c2 — … — ck — c1`. DFS eventually enters this component; let `c_i` be the first cycle vertex it visits. From `c_i` the DFS can reach every other cycle vertex, so all of them get visited during this DFS. A DFS tree on the component has one fewer tree edge than it has vertices, so at least one cycle edge is a non-tree edge; when its lower endpoint scans that edge, the other endpoint is already visited and is not its parent, and the check fires.

Why there are no false positives: the only way an undirected edge points at an already-visited vertex without creating a second route is the back-edge to the parent, and we exclude exactly that.

Dry run on `V = 6, adj = [[1], [0,2,3], [1,4], [1], [2,5], [4,1]]`:
- `dfs(0, -1)` marks 0; neighbour 1 unvisited → `dfs(1, 0)`.
- `dfs(1, 0)` marks 1; neighbour 0 is visited but equals the parent → skip. Neighbour 2 unvisited → `dfs(2, 1)`.
- `dfs(2, 1)` marks 2; neighbour 1 == parent → skip. Neighbour 4 unvisited → `dfs(4, 2)`.
- `dfs(4, 2)` marks 4; neighbour 2 == parent → skip. Neighbour 5 unvisited → `dfs(5, 4)`.
- `dfs(5, 4)` marks 5; neighbour 4 == parent → skip. Neighbour **1 is visited and 1 ≠ parent 4** → return `true`.
- The `true` propagates up the chain. The cycle is 1-2-4-5-1.

On the acyclic example every visited neighbour turns out to be the parent, so all calls return `false`.

Note the parent must be tracked *per recursive call*, not stored in a shared variable — each frame arrived from a different vertex. And when `V` can be 10^5, prefer an explicit stack (or the BFS variant) so a long path does not overflow the call stack.
- **Time:** O(V + E) — each vertex is entered once, each adjacency entry read once.
- **Space:** O(V) for `visited` plus O(V) recursion depth.

## Approach 3: Disjoint Set Union
Iterate over the edge list. For edge `(u, v)`, if `find(u) == find(v)` the two endpoints are already connected, so this edge closes a cycle → return `true`; otherwise `union(u, v)`. With union by size and path compression this is effectively O(E·α(V)) and needs no adjacency list at all — handy when edges arrive as a stream and you must answer after each one.
- **Time:** O(E · α(V))
- **Space:** O(V)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    bool isCycle(int V, vector<vector<int>>& adj) {
        vector<int> visited(V, 0);
        for (int s = 0; s < V; s++) {
            if (!visited[s] && dfs(s, -1, adj, visited)) return true;
        }
        return false;
    }

private:
    bool dfs(int node, int parent, vector<vector<int>>& adj, vector<int>& visited) {
        visited[node] = 1;
        for (int nb : adj[node]) {
            if (!visited[nb]) {
                if (dfs(nb, node, adj, visited)) return true;
            } else if (nb != parent) {
                return true;          // second route to an already-visited vertex
            }
        }
        return false;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public boolean isCycle(int V, List<List<Integer>> adj) {
        boolean[] visited = new boolean[V];
        for (int s = 0; s < V; s++) {
            if (!visited[s] && dfs(s, -1, adj, visited)) return true;
        }
        return false;
    }

    private boolean dfs(int node, int parent, List<List<Integer>> adj, boolean[] visited) {
        visited[node] = true;
        for (int nb : adj.get(node)) {
            if (!visited[nb]) {
                if (dfs(nb, node, adj, visited)) return true;
            } else if (nb != parent) {
                return true;
            }
        }
        return false;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def isCycle(self, V: int, adj: List[List[int]]) -> bool:
        visited = [False] * V

        for s in range(V):
            if visited[s]:
                continue
            # iterative DFS: stack holds (node, parent)
            stack = [(s, -1)]
            visited[s] = True
            while stack:
                node, parent = stack.pop()
                for nb in adj[node]:
                    if not visited[nb]:
                        visited[nb] = True
                        stack.append((nb, node))
                    elif nb != parent:
                        return True
        return False
```

## Key Takeaways
- The parent argument is the entire trick: without it, every single edge looks like a cycle.
- Cycle found ⇔ DFS meets a visited vertex reached by an edge other than the one it came in on.
- Always loop over all vertices — the cycle may sit in a component the first DFS never touches.
- This parent rule is specific to **undirected** graphs; directed graphs need a recursion-stack (grey/black) flag instead.
