# Count Square Submatrices with All Ones|(DP-56)

**Difficulty:** Easy  ·  **Topic:** Dynamic Programming [Patterns and Problems] › DP on Squares

## Problem
Given an `n x m` matrix of `0`s and `1`s, count how many **square** submatrices consist entirely of `1`s. Squares of every size count, and overlapping squares are counted separately.

```
Input:
0 1 1 1
1 1 1 1
0 1 1 1

Output: 15
```
There are 10 squares of side 1, 4 of side 2, and 1 of side 3 — total 15.

## Approach 1: Expand from every top-left corner (Brute Force)

For every cell, try every side length and verify all cells inside the square are `1`. With `n·m` starting cells, up to `min(n,m)` sizes, and O(size^2) cells to verify, this is far too slow on large grids.

- **Time:** O(n · m · min(n,m)^3)
- **Space:** O(1)

## Approach 2: DP on the bottom-right corner (Optimal)

**Observation 1 — index squares by their bottom-right corner.** Every all-ones square has exactly one bottom-right cell, so if we can count, for each cell `(i, j)`, how many all-ones squares end there, summing over all cells counts every square exactly once with no double counting.

**Observation 2 — the count equals the largest side.** Here is the neat part. If the largest all-ones square with bottom-right corner `(i, j)` has side `s`, then squares of side `1, 2, ..., s` all also fit with that same bottom-right corner (each is nested inside the next). And side `s+1` does not fit. So the number of squares ending at `(i, j)` is exactly `s`. We only need one number per cell.

**Observation 3 — the recurrence for the largest side.** Let `dp[i][j]` be that largest side. If `matrix[i][j] == 0`, no square ends here, so `dp[i][j] = 0`. Otherwise a square of side `s` ending at `(i, j)` requires three overlapping squares of side `s-1` to exist: one ending at `(i-1, j)` (covers the rows above), one at `(i, j-1)` (covers the columns to the left), and one at `(i-1, j-1)` (covers the upper-left block). The tightest of these three limits us, so:

```
dp[i][j] = 1 + min( dp[i-1][j], dp[i][j-1], dp[i-1][j-1] )
```

Any one of the three being small immediately caps the square — for instance a `0` diagonally up-left punches a hole that no amount of ones above or to the left can repair, which is why all three neighbours appear and not just two.

**Base cases.** For row 0 and column 0, a square can have side at most 1, so `dp[i][j] = matrix[i][j]` there. (Handling them by treating out-of-range neighbours as 0 gives the same result.)

**The answer** is the sum of every `dp[i][j]`.

**Dry run on the example.**

Row 0 copies the matrix: `dp[0] = [0, 1, 1, 1]`.

Row 1: `dp[1][0] = 1` (first column). For `(1,1)`: neighbours `dp[0][1]=1, dp[1][0]=1, dp[0][0]=0`, min is 0 → `dp = 1`. For `(1,2)`: `dp[0][2]=1, dp[1][1]=1, dp[0][1]=1`, min 1 → `dp = 2`. For `(1,3)`: `dp[0][3]=1, dp[1][2]=2, dp[0][2]=1`, min 1 → `dp = 2`.
`dp[1] = [1, 1, 2, 2]`.

Row 2: `dp[2][0] = 0`. For `(2,1)`: `dp[1][1]=1, dp[2][0]=0, dp[1][0]=1`, min 0 → `dp = 1`. For `(2,2)`: `dp[1][2]=2, dp[2][1]=1, dp[1][1]=1`, min 1 → `dp = 2`. For `(2,3)`: `dp[1][3]=2, dp[2][2]=2, dp[1][2]=2`, min 2 → `dp = 3`.
`dp[2] = [0, 1, 2, 3]`.

Sum = `(0+1+1+1) + (1+1+2+2) + (0+1+2+3) = 3 + 6 + 6 = 15`. The single `3` at the bottom-right correctly announces that a 3×3, a 2×2 and a 1×1 square all end at that cell.

- **Time:** O(n · m)
- **Space:** O(n · m); can be reduced to O(m) by keeping only the previous row

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int countSquares(vector<vector<int>>& matrix) {
        int n = matrix.size(), m = matrix[0].size();
        // dp[i][j] = side of the largest all-ones square ending at (i, j),
        //            which equals the count of squares ending at (i, j).
        vector<vector<int>> dp(n, vector<int>(m, 0));
        int total = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (matrix[i][j] == 0) { dp[i][j] = 0; continue; }
                if (i == 0 || j == 0) dp[i][j] = 1;
                else dp[i][j] = 1 + min({ dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1] });
                total += dp[i][j];
            }
        }
        return total;
    }
};
```

### Java
```java
class Solution {
    public int countSquares(int[][] matrix) {
        int n = matrix.length, m = matrix[0].length;
        int[][] dp = new int[n][m];
        int total = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (matrix[i][j] == 0) { dp[i][j] = 0; continue; }
                if (i == 0 || j == 0) {
                    dp[i][j] = 1;
                } else {
                    int best = Math.min(dp[i - 1][j],
                               Math.min(dp[i][j - 1], dp[i - 1][j - 1]));
                    dp[i][j] = 1 + best;
                }
                total += dp[i][j];
            }
        }
        return total;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def countSquares(self, matrix: List[List[int]]) -> int:
        n, m = len(matrix), len(matrix[0])
        dp = [[0] * m for _ in range(n)]
        total = 0

        for i in range(n):
            for j in range(m):
                if matrix[i][j] == 0:
                    continue
                if i == 0 or j == 0:
                    dp[i][j] = 1
                else:
                    dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
                total += dp[i][j]

        return total
```

## Key Takeaways
- Counting squares by their bottom-right corner avoids double counting; the sum of `dp` is the answer directly.
- The largest side ending at a cell *is* the number of squares ending there, because smaller squares nest inside the largest one.
- All three neighbours (up, left, diagonal) are needed — the diagonal one catches holes the other two cannot see.
- Edge cases: row 0 and column 0 cap at side 1; an all-zero matrix returns 0. Space can drop to O(m) with a single rolling row.
