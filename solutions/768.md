# Next Smaller Element

**Difficulty:** Medium  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Monotonic Stack/Queue Problems [VVV. Imp]

## Problem
Given an array `arr`, produce an array where position `i` contains the nearest element to the *left* of `i` that is strictly smaller than `arr[i]`. If there is no smaller element on the left, output `-1`. (This is the "previous smaller element" variant; the mirror-image "next smaller to the right" uses exactly the same technique scanning from the other end.)

```
Input:  arr = [4, 5, 2, 10, 8]
Output: [-1, 4, -1, 2, 2]
```
5 has 4 before it; 2 has nothing smaller on its left; 10 and 8 both see 2 as the nearest smaller value.

## Approach 1: Brute Force
For each index `i`, walk leftwards from `i-1` until you meet a value less than `arr[i]`.
- **Time:** O(n²)
- **Space:** O(1) extra

## Approach 2: Monotonic Increasing Stack (Optimal)
Scan left to right and maintain a stack whose values increase from bottom to top. Before handling `arr[i]`:
1. Pop while the top is ≥ `arr[i]`. Any popped value is useless for future indices because `arr[i]` is both closer and smaller-or-equal.
2. The top (if any) is the nearest smaller element on the left; otherwise the answer is `-1`.
3. Push `arr[i]`.

Because each element is pushed once and popped at most once, the loop is linear overall despite the inner `while`.
- **Time:** O(n)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stack>
using namespace std;

class Solution {
public:
    vector<int> prevSmaller(vector<int>& arr) {
        int n = arr.size();
        vector<int> ans(n, -1);
        stack<int> st;
        for (int i = 0; i < n; ++i) {
            while (!st.empty() && st.top() >= arr[i]) st.pop();
            ans[i] = st.empty() ? -1 : st.top();
            st.push(arr[i]);
        }
        return ans;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int[] prevSmaller(int[] arr) {
        int n = arr.length;
        int[] ans = new int[n];
        Deque<Integer> st = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            while (!st.isEmpty() && st.peek() >= arr[i]) st.pop();
            ans[i] = st.isEmpty() ? -1 : st.peek();
            st.push(arr[i]);
        }
        return ans;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def prevSmaller(self, arr: List[int]) -> List[int]:
        ans = []
        st = []
        for x in arr:
            while st and st[-1] >= x:
                st.pop()
            ans.append(st[-1] if st else -1)
            st.append(x)
        return ans
```

## Key Takeaways
- Previous smaller = left-to-right scan with an increasing stack; next smaller = right-to-left scan with the same rule.
- Popping on `>=` ensures duplicates are not treated as "smaller".
- This building block is reused in histogram, subarray-minimum and stock-span problems, so the indices version (push `i` instead of `arr[i]`) is worth memorising too.
