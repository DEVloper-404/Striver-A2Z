# Replace Elements by Their Rank

**Difficulty:** Easy  ·  **Topic:** Heaps [Learning, Medium, Hard Problems] › Medium Problems

## Problem
Given an array of integers, replace every element with its rank. The smallest distinct value gets rank 1, the next distinct value gets rank 2, and so on. Equal values share the same rank, and ranks are dense (no gaps).

```
Input:  arr = [20, 15, 26, 2, 15]
Output: [3, 2, 4, 1, 2]
```
Distinct values in order are `2 < 15 < 20 < 26`, so 2 -> 1, 15 -> 2, 20 -> 3, 26 -> 4. Both copies of 15 receive rank 2.

## Approach 1: Brute force counting
For every element, scan the whole array and count how many *distinct* values are strictly smaller than it (use a set to avoid double-counting duplicates). The rank is that count plus one.
- **Time:** O(n^2)
- **Space:** O(n) for the temporary set

## Approach 2: Sort distinct values and map (optimal)
1. Copy the array and sort it.
2. Walk the sorted copy, assigning an increasing rank to each value the first time it appears; store `value -> rank` in a hash map.
3. Rewrite the original array using the map.

Sorting gives the order of distinct values directly, and the map lets each lookup be O(1).
- **Time:** O(n log n)
- **Space:** O(n)

## Approach 3: Min-heap variant
Since this lives in the heap section: push all values into a min-heap, then pop repeatedly. Track the last popped value; whenever a new (larger) value comes out, increment the rank counter and record it in the map. This is the same idea as sorting, expressed with a heap.
- **Time:** O(n log n)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<int> replaceWithRank(vector<int>& arr) {
        vector<int> sorted = arr;
        sort(sorted.begin(), sorted.end());

        unordered_map<int, int> rankOf;
        int rank = 0;
        for (int i = 0; i < (int)sorted.size(); i++) {
            if (i == 0 || sorted[i] != sorted[i - 1]) {
                rankOf[sorted[i]] = ++rank;
            }
        }

        vector<int> result(arr.size());
        for (int i = 0; i < (int)arr.size(); i++) {
            result[i] = rankOf[arr[i]];
        }
        return result;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int[] replaceWithRank(int[] arr) {
        int[] sorted = arr.clone();
        Arrays.sort(sorted);

        Map<Integer, Integer> rankOf = new HashMap<>();
        int rank = 0;
        for (int i = 0; i < sorted.length; i++) {
            if (i == 0 || sorted[i] != sorted[i - 1]) {
                rankOf.put(sorted[i], ++rank);
            }
        }

        int[] result = new int[arr.length];
        for (int i = 0; i < arr.length; i++) {
            result[i] = rankOf.get(arr[i]);
        }
        return result;
    }
}
```

### Python
```python
from typing import List


class Solution:
    def replaceWithRank(self, arr: List[int]) -> List[int]:
        distinct_sorted = sorted(set(arr))
        rank_of = {value: i + 1 for i, value in enumerate(distinct_sorted)}
        return [rank_of[x] for x in arr]
```

## Key Takeaways
- Ranks are over **distinct** values, so skip consecutive duplicates in the sorted copy instead of incrementing on every index.
- A hash map from value to rank turns the final rewrite into a single linear pass.
- The heap-based version is just sorting spelled differently; use whichever your interviewer is steering toward.
- Edge cases: all elements equal (every rank is 1) and a single-element array (rank 1).
