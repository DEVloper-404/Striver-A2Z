# Rotate a LL

**Difficulty:** Hard  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Hard Problems of LL

## Problem
Given the head of a singly linked list and a non-negative integer `k`, rotate the list to the right by `k` places: the last node moves to the front, and this is repeated `k` times. Return the head of the rotated list. `k` may be larger than the length of the list.

Input: `head = 1 → 2 → 3 → 4 → 5`, `k = 2`
Output: `4 → 5 → 1 → 2 → 3`

Input: `head = 0 → 1 → 2`, `k = 4`
Output: `2 → 0 → 1`

## Approach 1: Rotate one step at a time
Repeat `k` times: walk to the second-last node, detach the last node, and put it in front of the head. Each pass is a full traversal, so this is quadratic in the worst case and painfully slow when `k` is huge.
- **Time:** O(n · k)
- **Space:** O(1)

## Approach 2: Close the ring and cut it open
Two observations make this linear:

1. Rotating by `k` is the same as rotating by `k mod n`, where `n` is the length. If `k mod n == 0` nothing changes.
2. A right rotation by `r` places means the new head is the node at position `n - r` (1-indexed: the `(n-r+1)`-th node) and the node before it becomes the new tail.

So: traverse once to find the length `n` and the tail. Connect `tail->next = head` to form a ring. Walk `n - r` steps from the head to reach the new tail, set `newHead = newTail->next`, and break the ring with `newTail->next = null`.
- **Time:** O(n) — one pass for the length, at most one more pass to find the cut point.
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode *next; ListNode(int x) : val(x), next(nullptr) {} }; // standard definition
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if (!head || !head->next || k == 0) return head;
        int n = 1;
        ListNode* tail = head;
        while (tail->next) { tail = tail->next; n++; }
        k %= n;
        if (k == 0) return head;
        tail->next = head;                 // make it circular
        ListNode* newTail = head;
        for (int i = 1; i < n - k; i++) newTail = newTail->next;
        ListNode* newHead = newTail->next;
        newTail->next = nullptr;           // cut the ring
        return newHead;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } } // standard definition
class Solution {
    public ListNode rotateRight(ListNode head, int k) {
        if (head == null || head.next == null || k == 0) return head;
        int n = 1;
        ListNode tail = head;
        while (tail.next != null) { tail = tail.next; n++; }
        k %= n;
        if (k == 0) return head;
        tail.next = head;
        ListNode newTail = head;
        for (int i = 1; i < n - k; i++) newTail = newTail.next;
        ListNode newHead = newTail.next;
        newTail.next = null;
        return newHead;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
# (standard definition)
class Solution:
    def rotateRight(self, head, k):
        if not head or not head.next or k == 0:
            return head
        n, tail = 1, head
        while tail.next:
            tail = tail.next
            n += 1
        k %= n
        if k == 0:
            return head
        tail.next = head
        new_tail = head
        for _ in range(n - k - 1):
            new_tail = new_tail.next
        new_head = new_tail.next
        new_tail.next = None
        return new_head
```

## Key Takeaways
- Always reduce `k` with `k % n` first; the rotation is periodic with period `n`.
- Turning the list into a ring and cutting it at the right spot avoids repeated traversals.
- The new tail is the `(n - k)`-th node; off-by-one errors here are the most common bug, so test with `k = 1` and `k = n - 1`.
- Handle empty and single-node lists before doing any arithmetic.
