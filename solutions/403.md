# Pattern 11

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a right-angled triangle of `n` rows filled with alternating 1s and 0s. Odd-numbered rows start with `1`, even-numbered rows start with `0`, and the value flips at every position within a row.

Input: `n = 5`
Output:
```
1
0 1
1 0 1
0 1 0 1
1 0 1 0 1
```

## Approach
The value at row `i`, column `j` (both 1-indexed) depends only on the parity of `i + j`.

1. Outer loop `i` from `1` to `n`.
2. Set the starting bit for the row: `1` if `i` is odd, `0` if even.
3. Inner loop `j` from `1` to `i`: print the current bit, then flip it (`bit = 1 - bit`).
4. Newline.

Equivalently, print `1` when `(i + j)` is even and `0` when it is odd; both views give the same checkerboard-style output.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern11(int n) {
    for (int i = 1; i <= n; i++) {
        int bit = (i % 2 == 1) ? 1 : 0;
        for (int j = 1; j <= i; j++) {
            cout << bit << " ";
            bit = 1 - bit;
        }
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern11 {
    public static void pattern11(int n) {
        for (int i = 1; i <= n; i++) {
            int bit = (i % 2 == 1) ? 1 : 0;
            StringBuilder row = new StringBuilder();
            for (int j = 1; j <= i; j++) {
                row.append(bit).append(' ');
                bit = 1 - bit;
            }
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern11(n: int) -> None:
    for i in range(1, n + 1):
        print(" ".join(str((i + j) % 2) for j in range(1, i + 1)))
```

## Key Takeaways
- Alternating values are a parity problem: `(i + j) % 2` or a flipping bit both work.
- The starting value of each row is what makes the diagonals line up; do not always start at 1.
- `1 - bit` is a clean way to toggle between 0 and 1 without an if statement.
