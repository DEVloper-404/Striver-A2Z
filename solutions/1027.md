# Trie Implementation and Advanced Operations

**Difficulty:** Hard  ·  **Topic:** Tries › Problems

## Problem
Implement a trie that supports a **multiset** of words (duplicates allowed) with four operations:

- `insert(word)` — add one occurrence of `word`.
- `countWordsEqualTo(word)` — how many times `word` was inserted.
- `countWordsStartingWith(prefix)` — how many inserted words have `prefix` as a prefix.
- `erase(word)` — remove one occurrence of `word` (the word is guaranteed to exist).

```
Input:
insert("apple"); insert("apple"); insert("app");
countWordsEqualTo("apple"); countWordsStartingWith("app");
erase("apple"); countWordsEqualTo("apple");
Output:
2, 3, 1
```

## Approach 1: Store a list of words per node (Naive)

Give every node a list of the words passing through it. Counting is then a scan of that list. Correct, but memory blows up to O(total characters × words) and every count is O(size of list).

- **Time:** O(L + k) per count, where `k` is the number of words through that node
- **Space:** O(sum of word lengths × duplicates)

## Approach 2: Replace the boolean flag with two counters (Optimal)

**The key idea.** Trie-1 stored a single boolean `isEnd` per node, which answers "does a word end here — yes or no?". That is not enough here for two reasons: duplicates need a *count*, and prefix queries need to know how many words pass through a node. Both are fixed by replacing the flag with two integers on every node:

- `cntEnd` — how many inserted words end exactly at this node.
- `cntPrefix` — how many inserted words pass through this node (i.e. have this node's prefix as a prefix).

`cntPrefix` is the crucial addition: it lets `countWordsStartingWith` answer in O(L) by reading a single number, instead of exploring the whole subtree below the prefix.

**insert(word).** Walk the word, creating missing child nodes as usual. At *every* node you step into, increment `cntPrefix` by 1 (that word now passes through it). At the final node, also increment `cntEnd`. The root is not incremented — or if you prefer, incrementing it would make `countWordsStartingWith("")` return the total word count, which is harmless.

**countWordsEqualTo(word).** Walk the word; if any child is missing return 0. Otherwise return the final node's `cntEnd`.

**countWordsStartingWith(prefix).** Same walk; if any child is missing return 0. Otherwise return the final node's `cntPrefix`.

**erase(word).** This is the exact inverse of insert, and the invariants make it easy: walk the word, decrementing `cntPrefix` at each node you step into, and decrement `cntEnd` at the final node. Because the problem guarantees the word exists, the walk cannot fail and no counter can go negative. Optionally, when a child's `cntPrefix` drops to 0 you may unlink and free it to reclaim memory — the counters stay correct either way.

**Dry run on the example.** Write each node as `prefix(cntPrefix, cntEnd)`.

1. `insert("apple")` → `a(1,0) ap(1,0) app(1,0) appl(1,0) apple(1,1)`
2. `insert("apple")` again → every counter on that chain bumps: `a(2,0) ap(2,0) app(2,0) appl(2,0) apple(2,2)`
3. `insert("app")` → the walk reuses `a, ap, app`, so no new nodes: `a(3,0) ap(3,0) app(3,1)`, while `appl` and `apple` stay at `(2,0)` and `(2,2)` since this word never reached them.
4. `countWordsEqualTo("apple")` → walk to node `apple`, read `cntEnd = 2` → **2**
5. `countWordsStartingWith("app")` → walk to node `app`, read `cntPrefix = 3` → **3** (the two `"apple"`s plus the one `"app"`), answered without touching the subtree below.
6. `erase("apple")` → decrement along the chain: `a(2,0) ap(2,0) app(2,1) appl(1,0) apple(1,1)`
7. `countWordsEqualTo("apple")` → `cntEnd = 1` → **1**

Note how in step 6 the node `app` kept `cntEnd = 1`: erasing `"apple"` must not disturb the separately inserted `"app"`, and separating the two counters is exactly what guarantees that.

- **Time:** O(L) for every operation
- **Space:** O(total distinct characters stored) — duplicates cost no extra nodes

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Trie {
    struct Node {
        Node* links[26] = {nullptr};
        int cntEnd = 0;      // words ending exactly here
        int cntPrefix = 0;   // words passing through here
    };
    Node* root;

public:
    Trie() { root = new Node(); }

    void insert(string word) {
        Node* cur = root;
        for (char ch : word) {
            int idx = ch - 'a';
            if (cur->links[idx] == nullptr) cur->links[idx] = new Node();
            cur = cur->links[idx];
            cur->cntPrefix++;
        }
        cur->cntEnd++;
    }

    int countWordsEqualTo(string word) {
        Node* cur = root;
        for (char ch : word) {
            int idx = ch - 'a';
            if (cur->links[idx] == nullptr) return 0;
            cur = cur->links[idx];
        }
        return cur->cntEnd;
    }

    int countWordsStartingWith(string prefix) {
        Node* cur = root;
        for (char ch : prefix) {
            int idx = ch - 'a';
            if (cur->links[idx] == nullptr) return 0;
            cur = cur->links[idx];
        }
        return cur->cntPrefix;
    }

    void erase(string word) {
        Node* cur = root;
        for (char ch : word) {
            int idx = ch - 'a';
            if (cur->links[idx] == nullptr) return;   // defensive
            cur = cur->links[idx];
            cur->cntPrefix--;
        }
        cur->cntEnd--;
    }
};
```

### Java
```java
class Trie {
    private static class Node {
        Node[] links = new Node[26];
        int cntEnd = 0;      // words ending exactly here
        int cntPrefix = 0;   // words passing through here
    }

    private final Node root;

    public Trie() { root = new Node(); }

    public void insert(String word) {
        Node cur = root;
        for (int i = 0; i < word.length(); i++) {
            int idx = word.charAt(i) - 'a';
            if (cur.links[idx] == null) cur.links[idx] = new Node();
            cur = cur.links[idx];
            cur.cntPrefix++;
        }
        cur.cntEnd++;
    }

    private Node walk(String s) {
        Node cur = root;
        for (int i = 0; i < s.length(); i++) {
            int idx = s.charAt(i) - 'a';
            if (cur.links[idx] == null) return null;
            cur = cur.links[idx];
        }
        return cur;
    }

    public int countWordsEqualTo(String word) {
        Node node = walk(word);
        return node == null ? 0 : node.cntEnd;
    }

    public int countWordsStartingWith(String prefix) {
        Node node = walk(prefix);
        return node == null ? 0 : node.cntPrefix;
    }

    public void erase(String word) {
        Node cur = root;
        for (int i = 0; i < word.length(); i++) {
            int idx = word.charAt(i) - 'a';
            if (cur.links[idx] == null) return;       // defensive
            cur = cur.links[idx];
            cur.cntPrefix--;
        }
        cur.cntEnd--;
    }
}
```

### Python
```python
class TrieNode:
    __slots__ = ("links", "cnt_end", "cnt_prefix")

    def __init__(self):
        self.links = {}          # char -> TrieNode
        self.cnt_end = 0         # words ending exactly here
        self.cnt_prefix = 0      # words passing through here


class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        cur = self.root
        for ch in word:
            if ch not in cur.links:
                cur.links[ch] = TrieNode()
            cur = cur.links[ch]
            cur.cnt_prefix += 1
        cur.cnt_end += 1

    def _walk(self, s: str):
        cur = self.root
        for ch in s:
            if ch not in cur.links:
                return None
            cur = cur.links[ch]
        return cur

    def countWordsEqualTo(self, word: str) -> int:
        node = self._walk(word)
        return node.cnt_end if node else 0

    def countWordsStartingWith(self, prefix: str) -> int:
        node = self._walk(prefix)
        return node.cnt_prefix if node else 0

    def erase(self, word: str) -> None:
        cur = self.root
        for ch in word:
            if ch not in cur.links:
                return
            cur = cur.links[ch]
            cur.cnt_prefix -= 1
        cur.cnt_end -= 1
```

## Key Takeaways
- Swapping the boolean `isEnd` for two counters (`cntEnd`, `cntPrefix`) upgrades a set-trie into a multiset-trie with O(L) prefix counting.
- `cntPrefix` is maintained on the way *down* during insert/erase; that is what avoids ever traversing the subtree during a prefix query.
- `erase` is literally insert with `--` instead of `++` — keeping the two symmetric is what preserves the invariants.
- Duplicates add no nodes, only counter increments; optionally free nodes whose `cntPrefix` hits 0 to reclaim memory.
