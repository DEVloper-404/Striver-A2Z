# Iterative Preorder Traversal of Binary Tree

**Difficulty:** Easy  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Traversals

## Problem
Return the preorder traversal (Root, Left, Right) of a binary tree without using recursion. The point of this exercise is to see how the implicit call stack can be replaced by an explicit one, which matters when the tree is deep enough to overflow recursion.

Input: `root = [1, 2, 3, 4, 5, null, 6]`
```
      1
     / \
    2   3
   / \   \
  4   5   6
```
Output: `[1, 2, 4, 5, 3, 6]`

## Approach 1: Recursive (for reference)
Record the node, recurse left, recurse right. Correct but uses O(h) stack frames that you do not control. On a skewed tree of 10^5 nodes this can crash in most languages.
- **Time:** O(n)
- **Space:** O(h) recursion stack

## Approach 2: Explicit stack, push right then left (optimal)
The recursive version processes the node immediately, then the whole left subtree, then the whole right subtree. To reproduce that with a stack:

1. Push the root.
2. Pop the top node and record its value (this is the "Root" step).
3. Push its right child, then its left child, skipping nulls.
4. Repeat until the stack is empty.

Pushing right first means left is on top and is popped next, so the entire left subtree is exhausted before any right child is touched. Each node is pushed and popped exactly once. The stack holds at most one pending sibling per level, so its size is O(h).
- **Time:** O(n)
- **Space:** O(h) for the stack

## Approach 3: Morris preorder (O(1) space)
Thread the tree temporarily: for a node with a left child, find its inorder predecessor. If the predecessor's right is null, record the node, link predecessor's right to the node, and go left. If the thread already exists, unlink it and go right. Nodes with no left child are recorded and we go right. No stack needed, tree restored at the end. Useful to know, rarely required.
- **Time:** O(n)
- **Space:** O(1) extra

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stack>
using namespace std;

// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition

class Solution {
public:
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> res;
        if (!root) return res;
        stack<TreeNode*> st;
        st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            st.pop();
            res.push_back(node->val);
            if (node->right) st.push(node->right);
            if (node->left)  st.push(node->left);    // left on top, popped next
        }
        return res;
    }
};
```

### Java
```java
import java.util.*;

// class TreeNode { int val; TreeNode left, right; ... } — standard definition

class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        Deque<TreeNode> st = new ArrayDeque<>();
        st.push(root);
        while (!st.isEmpty()) {
            TreeNode node = st.pop();
            res.add(node.val);
            if (node.right != null) st.push(node.right);
            if (node.left != null)  st.push(node.left);    // left on top, popped next
        }
        return res;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def preorderTraversal(self, root):
        res = []
        if root is None:
            return res
        stack = [root]
        while stack:
            node = stack.pop()
            res.append(node.val)
            if node.right:
                stack.append(node.right)
            if node.left:
                stack.append(node.left)      # left on top, popped next
        return res
```

## Key Takeaways
- Replace the call stack with your own: pop, visit, push right, push left. The reversed push order is the only subtle part.
- Skip null children when pushing so the loop never has to check for null on pop.
- Stack size is bounded by the tree height, so space is O(h) just like recursion, but without the risk of a stack overflow.
- Preorder is the only DFS order where the node can be emitted at the moment it is popped; inorder and postorder need extra bookkeeping.
