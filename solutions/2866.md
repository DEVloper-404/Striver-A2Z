# Functions (Pass by Reference and Value)

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Things to Know in C++/Java/Python or any language

## Problem
A function is a named, reusable block of code that takes parameters and optionally returns a value. The key question this topic answers is: when you pass a variable into a function and the function changes it, does the caller see the change? That depends on whether the argument is passed **by value** (the function gets a copy) or **by reference** (the function gets an alias to the caller's variable).

Example task: write `increment(x)` that adds 1, and `fillZeros(arr)` that zeroes an array, and observe what the caller sees afterwards.

```
Input:  x = 5, arr = [1, 2, 3]
Output: x after increment-by-value: 5
        x after increment-by-reference: 6
        arr after fillZeros: [0, 0, 0]
```

## Approach: The two passing models

**1. Pass by value.** The parameter is a fresh copy. Changes inside the function are local and vanish when it returns. In C++ this is the default for every type: `void f(int x)`, `void f(vector<int> v)` (copies the whole vector — expensive!).

**2. Pass by reference.** The parameter is another name for the caller's variable. C++ uses `&`: `void f(int &x)` mutates the caller's `x`. To avoid copying a large container without allowing modification, use `const vector<int> &v`. Arrays declared with `[]` decay to pointers, so `void f(int arr[])` also sees the original memory.

**3. Java: always pass by value — of the reference.** Primitives (`int`, `double`) are copied, so `increment(int x)` cannot change the caller's variable. Object variables hold a reference; that reference is copied, but both copies point to the same object. So `fill(int[] arr)` can zero the caller's array, yet `arr = new int[3]` inside the function only rebinds the local copy.

**4. Python: the same "pass by object reference" model.** Immutable objects (`int`, `str`, `tuple`) cannot be changed in place, so reassigning `x += 1` creates a new local object. Mutable objects (`list`, `dict`, `set`) can be mutated in place (`arr[i] = 0`), and the caller sees it. Reassigning `arr = []` only rebinds the local name.

**5. Returning values.** When a language cannot mutate the caller's variable, return the new value and reassign: `x = increment(x)`. Multiple values can be returned via `pair`/`tuple`, a small struct, or output-reference parameters in C++.

**6. Why it matters for DSA.** Recursive helpers usually pass containers by reference (`vector<int>& path`) to avoid O(n) copies per call, and use a reference `int& count` to accumulate answers across calls. Forgetting the `&` produces correct-looking code that is either wrong (mutation lost) or too slow (copies).

- **Time:** O(1) for pass by reference; O(n) to pass an n-element container by value (copy)
- **Space:** O(1) extra for reference; O(n) extra for a by-value copy

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

void incrementByValue(int x) { x++; }           // caller unaffected
void incrementByRef(int &x) { x++; }            // caller's x changes

void fillZeros(vector<int> &arr) {              // reference: no copy, mutates original
    for (int &v : arr) v = 0;
}

long long sumOf(const vector<int> &arr) {       // const ref: no copy, read-only
    long long s = 0;
    for (int v : arr) s += v;
    return s;
}

pair<int, int> minMax(const vector<int> &arr) { // returning two values
    int mn = arr[0], mx = arr[0];
    for (int v : arr) { mn = min(mn, v); mx = max(mx, v); }
    return {mn, mx};
}

int main() {
    int x = 5;
    incrementByValue(x);
    cout << "after by value: " << x << '\n';    // 5
    incrementByRef(x);
    cout << "after by ref: " << x << '\n';      // 6

    vector<int> arr = {1, 2, 3};
    cout << "sum: " << sumOf(arr) << '\n';      // 6
    auto [mn, mx] = minMax(arr);
    cout << mn << ' ' << mx << '\n';            // 1 3
    fillZeros(arr);
    for (int v : arr) cout << v << ' ';         // 0 0 0
    cout << '\n';
    return 0;
}
```

### Java
```java
import java.util.Arrays;

public class Main {
    static void incrementByValue(int x) { x++; }        // primitive copied, no effect

    static int increment(int x) { return x + 1; }        // return the new value instead

    static void fillZeros(int[] arr) {                   // reference copied, same array
        for (int i = 0; i < arr.length; i++) arr[i] = 0;
    }

    static void rebind(int[] arr) {                      // rebinding local ref: no effect
        arr = new int[]{9, 9, 9};
    }

    static int[] minMax(int[] arr) {
        int mn = arr[0], mx = arr[0];
        for (int v : arr) { mn = Math.min(mn, v); mx = Math.max(mx, v); }
        return new int[]{mn, mx};
    }

    public static void main(String[] args) {
        int x = 5;
        incrementByValue(x);
        System.out.println("after by value: " + x);     // 5
        x = increment(x);
        System.out.println("after return: " + x);       // 6

        int[] arr = {1, 2, 3};
        int[] mm = minMax(arr);
        System.out.println(mm[0] + " " + mm[1]);        // 1 3
        rebind(arr);
        System.out.println(Arrays.toString(arr));       // [1, 2, 3]
        fillZeros(arr);
        System.out.println(Arrays.toString(arr));       // [0, 0, 0]
    }
}
```

### Python
```python
from typing import List, Tuple


def increment_local(x: int) -> None:
    x += 1                      # rebinds local name; caller unaffected


def increment(x: int) -> int:
    return x + 1                # return the new value instead


def fill_zeros(arr: List[int]) -> None:
    for i in range(len(arr)):   # in-place mutation: caller sees it
        arr[i] = 0


def rebind(arr: List[int]) -> None:
    arr = [9, 9, 9]             # rebinds local name only


def min_max(arr: List[int]) -> Tuple[int, int]:
    mn = mx = arr[0]
    for v in arr:
        mn = min(mn, v)
        mx = max(mx, v)
    return mn, mx


def main():
    x = 5
    increment_local(x)
    print("after local:", x)    # 5
    x = increment(x)
    print("after return:", x)   # 6

    arr = [1, 2, 3]
    print(*min_max(arr))        # 1 3
    rebind(arr)
    print(arr)                  # [1, 2, 3]
    fill_zeros(arr)
    print(arr)                  # [0, 0, 0]


if __name__ == "__main__":
    main()
```

## Key Takeaways
- C++ copies by default; add `&` to mutate the caller's variable and `const &` to avoid copying large containers you only read.
- Java and Python pass a copy of the reference: in-place mutation of an object is visible to the caller, reassignment of the parameter is not.
- Primitives and immutable objects can never be changed through a parameter — return the new value and reassign.
- In recursion, pass working containers by reference to avoid an O(n) copy per call.
