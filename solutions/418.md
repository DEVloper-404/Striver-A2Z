# Pattern 5

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print an inverted right-angled triangle of stars with `n` rows. The first row has `n` stars, the second has `n-1`, and so on down to a single star.

Input: `n = 5`
Output:
```
* * * * *
* * * *
* * *
* *
*
```

## Approach
Reverse the growing triangle: the number of stars in row `i` (0-indexed) is `n - i`.

1. Outer loop `i` from `0` to `n-1`.
2. Inner loop `j` from `0` to `n-i-1` prints `"* "`.
3. Newline after the row.

An equivalent formulation is to run the outer loop downward (`i` from `n` to `1`) and print `i` stars; both express the same idea of a shrinking bound.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern5(int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n - i; j++) {
            cout << "* ";
        }
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern5 {
    public static void pattern5(int n) {
        for (int i = 0; i < n; i++) {
            StringBuilder row = new StringBuilder();
            for (int j = 0; j < n - i; j++) {
                row.append("* ");
            }
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern5(n: int) -> None:
    for i in range(n, 0, -1):
        print("* " * i)
```

## Key Takeaways
- A shrinking inner bound (`n - i`) flips a triangle upside down.
- Counting the outer loop downward is often cleaner than subtracting inside the inner loop.
- Off-by-one check: the last row must have exactly one star, so the bound at `i = n-1` must be 1.
