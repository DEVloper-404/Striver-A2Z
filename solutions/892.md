# Remove Outermost Parentheses

**Difficulty:** Medium  ·  **Topic:** Strings [Basic and Medium] › Basic and Easy String Problems

## Problem
A valid parentheses string can be split into "primitive" pieces: the smallest non-empty balanced chunks that cannot be split further (e.g. `(()())(())` is `(()())` + `(())`). For each primitive piece, strip its first `(` and last `)` and glue the results together. Return the resulting string.

Input: `s = "(()())(())"`
Output: `"()()()"`

Input: `s = "()()"`
Output: `""`

## Approach 1: Split into primitives explicitly
Walk the string maintaining a running balance (`+1` for `(`, `-1` for `)`). Whenever the balance returns to zero, you have just closed one primitive chunk. Record the start/end indices of each chunk, then for each chunk copy `s[start+1 .. end-1]` into the answer.

This works because a primitive is exactly a substring whose balance is zero at the end and strictly positive everywhere inside it.
- **Time:** O(n)
- **Space:** O(n) for the answer (plus the index list)

## Approach 2: Depth counter, one pass (Optimal)
You never need the chunk boundaries. Keep a depth counter:

1. On `(`: if depth is already `> 0`, this bracket is *inside* a primitive, so keep it. Then increment depth.
2. On `)`: decrement depth first. If depth is still `> 0`, the bracket is inside, so keep it.

A bracket that opens from depth 0 or closes back to depth 0 is an outermost one and is skipped. Single pass, no extra bookkeeping.
- **Time:** O(n)
- **Space:** O(n) for the output only (O(1) extra)

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Solution {
public:
    string removeOuterParentheses(string s) {
        string out;
        out.reserve(s.size());
        int depth = 0;
        for (char c : s) {
            if (c == '(') {
                if (depth > 0) out.push_back(c);
                depth++;
            } else {
                depth--;
                if (depth > 0) out.push_back(c);
            }
        }
        return out;
    }
};
```

### Java
```java
class Solution {
    public String removeOuterParentheses(String s) {
        StringBuilder out = new StringBuilder(s.length());
        int depth = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                if (depth > 0) out.append(c);
                depth++;
            } else {
                depth--;
                if (depth > 0) out.append(c);
            }
        }
        return out.toString();
    }
}
```

### Python
```python
class Solution:
    def removeOuterParentheses(self, s: str) -> str:
        out = []
        depth = 0
        for c in s:
            if c == '(':
                if depth > 0:
                    out.append(c)
                depth += 1
            else:
                depth -= 1
                if depth > 0:
                    out.append(c)
        return "".join(out)
```

## Key Takeaways
- A running depth counter is the standard tool for bracket problems; depth 0 marks primitive boundaries.
- The order of "check then increment" for `(` versus "decrement then check" for `)` is what makes both outermost brackets get dropped.
- The input is guaranteed valid, so depth never goes negative; no validation is needed.
- Build the answer in a string builder / list to avoid quadratic concatenation.
