# Check if there exists a subsequence with sum K

**Difficulty:** Easy  ·  **Topic:** Recursion [PatternWise] › Subsequences Pattern

## Problem
Given an integer array `arr` and a target `k`, decide whether at least one subsequence of `arr` sums to exactly `k`. Return `true` or `false`; you do not need to produce the subsequence itself.

Input: `arr = [1, 2, 3]`, `k = 5`
Output: `true` (`[2, 3]`)

Input: `arr = [1, 4]`, `k = 3`
Output: `false`

## Approach 1: Count and compare with zero
Reuse the "count subsequences with sum k" recursion and return `count > 0`. This explores the entire recursion tree even when an answer is found in the first leaf, which is wasted effort.
- **Time:** O(2^n)
- **Space:** O(n)

## Approach 2: Boolean recursion with short-circuit
Make the function return a boolean and combine the two branches with OR: `take || notTake`. Because OR short-circuits, the "not take" branch is skipped as soon as the "take" branch reports success, so the search stops at the first valid subsequence.

1. Base case `i == n`: return `sum == k`.
2. Return `exists(i + 1, sum + arr[i]) || exists(i + 1, sum)`.

With non-negative inputs, add `if (sum > k) return false;` to prune. For larger `n` the same recursion is memoised on `(i, sum)` and becomes the subset-sum DP.
- **Time:** O(2^n) worst case, often far less due to early exit
- **Space:** O(n) recursion depth

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    bool exists(int i, long long sum, const vector<int>& arr, int k) {
        if (i == (int)arr.size()) return sum == k;
        return exists(i + 1, sum + arr[i], arr, k) || exists(i + 1, sum, arr, k);
    }
public:
    bool hasSubsequenceWithSumK(vector<int>& arr, int k) {
        return exists(0, 0, arr, k);
    }
};
```

### Java
```java
class Solution {
    private boolean exists(int i, long sum, int[] arr, int k) {
        if (i == arr.length) return sum == k;
        return exists(i + 1, sum + arr[i], arr, k) || exists(i + 1, sum, arr, k);
    }

    public boolean hasSubsequenceWithSumK(int[] arr, int k) {
        return exists(0, 0L, arr, k);
    }
}
```

### Python
```python
from typing import List

class Solution:
    def hasSubsequenceWithSumK(self, arr: List[int], k: int) -> bool:
        def exists(i: int, s: int) -> bool:
            if i == len(arr):
                return s == k
            return exists(i + 1, s + arr[i]) or exists(i + 1, s)

        return exists(0, 0)
```

## Key Takeaways
- For "does any exist" questions, return a boolean and OR the branches; the short-circuit is the optimisation.
- Never explore the second branch when the first already succeeded.
- `k == 0` is always `true` via the empty subsequence unless the problem forbids it.
- This recursion is the seed of the subset-sum DP: memoise on `(index, sum)` once `n` grows beyond ~20.
