# M Coloring Problem

**Difficulty:** Hard  ·  **Topic:** Recursion [PatternWise] › Trying out all Combos / Hard

## Problem
You are given an undirected graph with `n` vertices (as an adjacency matrix or edge list) and an integer `m`. Decide whether the vertices can be coloured using at most `m` colours so that no two adjacent vertices share a colour. Return `true` if such a colouring exists, otherwise `false`.

Input: `n = 4`, `m = 3`, edges `= [(0,1),(1,2),(2,3),(3,0),(0,2)]`
Output: `true` (e.g. colours 0,1,2,1 for vertices 0..3)

## Approach 1: Try every assignment
Assign each of the `n` vertices one of `m` colours in every possible way, then check every edge. There are `m^n` complete assignments and most of them are invalid long before the last vertex is coloured.
- **Time:** O(m^n · E)
- **Space:** O(n) for the colour array

## Approach 2: Backtracking vertex by vertex (Optimal)
Colour vertices in index order. For vertex `v`, try each colour `c` from `0` to `m-1`; `c` is allowed if no already-coloured neighbour of `v` has colour `c`. If it is allowed, assign it and recurse to `v + 1`; if the recursion fails, clear the colour and try the next one. Reaching `v == n` means every vertex has a valid colour.

The safety check only looks at neighbours that were coloured earlier, since later vertices are still uncoloured (colour `-1`). This prunes the search tree the moment a conflict appears rather than at the end.
- **Time:** O(m^n) worst case, but drastically fewer nodes visited in practice
- **Space:** O(n) colour array + O(n) recursion depth

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    bool safe(int v, int c, const vector<vector<int>>& adj, const vector<int>& color) {
        for (int u : adj[v]) if (color[u] == c) return false;
        return true;
    }
    bool go(int v, int n, int m, const vector<vector<int>>& adj, vector<int>& color) {
        if (v == n) return true;
        for (int c = 0; c < m; ++c) {
            if (!safe(v, c, adj, color)) continue;
            color[v] = c;
            if (go(v + 1, n, m, adj, color)) return true;
            color[v] = -1;
        }
        return false;
    }
public:
    // edges given as pairs; n vertices numbered 0..n-1
    bool graphColoring(int n, int m, vector<pair<int,int>>& edges) {
        vector<vector<int>> adj(n);
        for (auto& e : edges) { adj[e.first].push_back(e.second); adj[e.second].push_back(e.first); }
        vector<int> color(n, -1);
        return go(0, n, m, adj, color);
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    // edges[i] = {u, v}; vertices numbered 0..n-1
    public boolean graphColoring(int n, int m, int[][] edges) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) { adj.get(e[0]).add(e[1]); adj.get(e[1]).add(e[0]); }
        int[] color = new int[n];
        Arrays.fill(color, -1);
        return go(0, n, m, adj, color);
    }

    private boolean go(int v, int n, int m, List<List<Integer>> adj, int[] color) {
        if (v == n) return true;
        for (int c = 0; c < m; c++) {
            if (!safe(v, c, adj, color)) continue;
            color[v] = c;
            if (go(v + 1, n, m, adj, color)) return true;
            color[v] = -1;
        }
        return false;
    }

    private boolean safe(int v, int c, List<List<Integer>> adj, int[] color) {
        for (int u : adj.get(v)) if (color[u] == c) return false;
        return true;
    }
}
```

### Python
```python
from typing import List, Tuple

class Solution:
    def graphColoring(self, n: int, m: int, edges: List[Tuple[int, int]]) -> bool:
        adj = [[] for _ in range(n)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)
        color = [-1] * n

        def safe(v: int, c: int) -> bool:
            return all(color[u] != c for u in adj[v])

        def go(v: int) -> bool:
            if v == n:
                return True
            for c in range(m):
                if safe(v, c):
                    color[v] = c
                    if go(v + 1):
                        return True
                    color[v] = -1
            return False

        return go(0)
```

## Key Takeaways
- Assign one vertex per recursion level and validate against already-coloured neighbours only.
- Return `true` as soon as one full colouring is found; this is a decision problem, not an enumeration.
- The chromatic number of a graph with a `k`-clique is at least `k`, so `m < k` fails quickly.
- A graph with no edges is colourable with `m >= 1`; a graph with an edge needs `m >= 2`.
