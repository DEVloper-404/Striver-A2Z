# Print root to leaf path in BT

**Difficulty:** Medium  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Hard Problems

## Problem
Given the root of a binary tree and a target value that exists in the tree, return the list of node values on the path from the root down to that node (inclusive). A closely related variant asks for every root-to-leaf path; both are solved with the same idea.

Input: root = [1, 2, 3, 4, 5, null, 6], target = 5
Output: [1, 2, 5]

Input (all root-to-leaf paths): root = [1, 2, 3, 4, 5, null, 6]
Output: [[1, 2, 4], [1, 2, 5], [1, 3, 6]]

## Approach 1: Brute Force (store every path)
Do a DFS that carries the current path as a list. At every leaf, copy the path into an answer list. When finished, scan the stored paths for the one that ends at (or contains) the target. This works but stores far more than necessary.
- **Time:** O(N · H) to copy paths at each leaf
- **Space:** O(N · H) for all stored paths

## Approach 2: Optimal (DFS with backtracking, stop early)
Walk the tree with a recursive helper that pushes the current node onto a path list. If the node is the target, return `true` immediately so that no further popping happens. Otherwise recurse left, then right; if either subtree reports success, propagate `true`. If neither does, pop the node (backtrack) and return `false`. When the recursion unwinds with `true`, the path list holds exactly the root-to-target path.

Key observation: the path list is a shared stack, so each node is pushed and popped at most once, and the search halts as soon as the target is found.
- **Time:** O(N) in the worst case (the target may be the last node visited)
- **Space:** O(H) for recursion and the path (H = height)

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition
#include <vector>
using namespace std;

class Solution {
    bool dfs(TreeNode* node, int target, vector<int>& path) {
        if (!node) return false;
        path.push_back(node->val);
        if (node->val == target) return true;
        if (dfs(node->left, target, path) || dfs(node->right, target, path)) return true;
        path.pop_back();
        return false;
    }
public:
    vector<int> rootToNodePath(TreeNode* root, int target) {
        vector<int> path;
        dfs(root, target, path);
        return path;   // empty if target is absent
    }

    // Variant: every root-to-leaf path
    void allPaths(TreeNode* node, vector<int>& cur, vector<vector<int>>& out) {
        if (!node) return;
        cur.push_back(node->val);
        if (!node->left && !node->right) out.push_back(cur);
        allPaths(node->left, cur, out);
        allPaths(node->right, cur, out);
        cur.pop_back();
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
import java.util.*;

class Solution {
    private boolean dfs(TreeNode node, int target, List<Integer> path) {
        if (node == null) return false;
        path.add(node.val);
        if (node.val == target) return true;
        if (dfs(node.left, target, path) || dfs(node.right, target, path)) return true;
        path.remove(path.size() - 1);
        return false;
    }

    public List<Integer> rootToNodePath(TreeNode root, int target) {
        List<Integer> path = new ArrayList<>();
        dfs(root, target, path);
        return path;
    }

    // Variant: every root-to-leaf path
    public void allPaths(TreeNode node, List<Integer> cur, List<List<Integer>> out) {
        if (node == null) return;
        cur.add(node.val);
        if (node.left == null && node.right == null) out.add(new ArrayList<>(cur));
        allPaths(node.left, cur, out);
        allPaths(node.right, cur, out);
        cur.remove(cur.size() - 1);
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def rootToNodePath(self, root, target):
        path = []

        def dfs(node):
            if not node:
                return False
            path.append(node.val)
            if node.val == target:
                return True
            if dfs(node.left) or dfs(node.right):
                return True
            path.pop()
            return False

        dfs(root)
        return path

    # Variant: every root-to-leaf path
    def allPaths(self, root):
        out, cur = [], []

        def dfs(node):
            if not node:
                return
            cur.append(node.val)
            if not node.left and not node.right:
                out.append(cur[:])
            dfs(node.left)
            dfs(node.right)
            cur.pop()

        dfs(root)
        return out
```

## Key Takeaways
- Push on entry, pop on failure: this backtracking template is reused by LCA, distance-K, and burn-tree problems.
- Return a boolean up the recursion so you stop searching (and stop popping) the moment the target is found.
- If the target is not present, the returned path is empty; handle that explicitly if the caller expects otherwise.
- The "all root-to-leaf paths" variant must copy the current path at each leaf, since the shared list keeps changing.
