# Hand of Straights

**Difficulty:** Medium  ·  **Topic:** Heaps [Learning, Medium, Hard Problems] › Medium Problems

## Problem
Alice holds an array `hand` of card values and wants to split every card into groups of exactly `groupSize` consecutive values (for example `3,4,5`). Return `true` if such a partition exists using every card, otherwise `false`.

```
Input:  hand = [1, 2, 3, 6, 2, 3, 4, 7, 8], groupSize = 3
Output: true
```
Groups: `[1,2,3]`, `[2,3,4]`, `[6,7,8]`.

## Approach 1: Sort and remove greedily
Sort the hand. Repeatedly take the smallest remaining card `x`; it must start a group (nothing smaller is left to precede it), so look for `x+1, x+2, ..., x+groupSize-1` and delete one copy of each. If any is missing, return `false`. Deleting from a list costs linear time, so this version is slow.
- **Time:** O(n^2)
- **Space:** O(n)

## Approach 2: Ordered map (or min-heap) of counts — optimal
Use a sorted map from card value to count. While the map is non-empty:

1. Take the smallest key `x` (the group must start here).
2. For `v = x, x+1, ..., x+groupSize-1`: if `v` is absent, return `false`; otherwise decrement its count and erase it when it hits zero.

Each card is decremented exactly once, and each map operation costs `O(log n)`.

A min-heap of the distinct values plus a hash map of counts works the same way: pop the top, check that its count is still positive, then consume the run. The ordered map is cleaner because it gives both ordering and counts.

A quick early exit: if `n % groupSize != 0`, the answer is immediately `false`.
- **Time:** O(n log n)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    bool isNStraightHand(vector<int>& hand, int groupSize) {
        if (hand.size() % groupSize != 0) return false;

        map<int, int> count;
        for (int c : hand) count[c]++;

        while (!count.empty()) {
            int start = count.begin()->first;
            for (int v = start; v < start + groupSize; v++) {
                auto it = count.find(v);
                if (it == count.end()) return false;
                if (--it->second == 0) count.erase(it);
            }
        }
        return true;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public boolean isNStraightHand(int[] hand, int groupSize) {
        if (hand.length % groupSize != 0) return false;

        TreeMap<Integer, Integer> count = new TreeMap<>();
        for (int c : hand) count.merge(c, 1, Integer::sum);

        while (!count.isEmpty()) {
            int start = count.firstKey();
            for (int v = start; v < start + groupSize; v++) {
                Integer cnt = count.get(v);
                if (cnt == null) return false;
                if (cnt == 1) count.remove(v);
                else count.put(v, cnt - 1);
            }
        }
        return true;
    }
}
```

### Python
```python
import heapq
from collections import Counter
from typing import List


class Solution:
    def isNStraightHand(self, hand: List[int], groupSize: int) -> bool:
        if len(hand) % groupSize != 0:
            return False

        count = Counter(hand)
        min_heap = list(count.keys())
        heapq.heapify(min_heap)

        while min_heap:
            start = min_heap[0]
            for v in range(start, start + groupSize):
                if count.get(v, 0) == 0:
                    return False
                count[v] -= 1
                if count[v] == 0:
                    # The consumed value must be the current heap minimum;
                    # otherwise a smaller value was skipped, which is invalid.
                    if v != min_heap[0]:
                        return False
                    heapq.heappop(min_heap)
        return True
```

## Key Takeaways
- The smallest remaining card must be the first card of its group; that single observation makes the greedy choice safe.
- Erase a value from the ordered structure as soon as its count reaches zero so the "smallest key" lookup stays correct.
- The `n % groupSize` check is a cheap early rejection worth doing first.
- With a heap of distinct values, be careful to reject the case where a value reaches zero while it is not at the heap top; that means a smaller value was left orphaned.
