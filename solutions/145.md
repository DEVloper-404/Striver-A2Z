# Single Number - III

**Difficulty:** Medium  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Interview Problems

## Problem
In an array `nums`, exactly two distinct values appear an odd number of times (in the LeetCode version, exactly once) and every other value appears an even number of times (twice). Return those two values, in any order, using linear time and constant extra space.

Input: `nums = [1, 2, 1, 3, 2, 5]`
Output: `[3, 5]`

## Approach 1: Hash map frequency count
Count occurrences of every value and return the two keys with an odd count. Linear time but linear extra memory.
- **Time:** O(n)
- **Space:** O(n)

## Approach 2: XOR and split by a distinguishing bit (Optimal)
XOR the whole array. Every even-count value cancels, so the result is `x ^ y` where `x` and `y` are the two answers. Since `x != y`, the XOR is non-zero and has at least one set bit; pick the lowest one with `diff & -diff`. In that bit position `x` and `y` differ, so exactly one of them has the bit set.

Now split the array into two groups: numbers with that bit set and numbers without. Each group contains one of the answers plus only complete pairs, so XOR-ing each group separately yields `x` and `y`.

Overflow note: in C++/Java, if `diff` is `INT_MIN` the expression `-diff` overflows; use `diff & (-(long)diff)` or an unsigned negation. Python integers are unbounded, so no issue there.
- **Time:** O(n) — two passes
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> singleNumber(vector<int>& nums) {
        long long diff = 0;
        for (int v : nums) diff ^= v;
        long long lowBit = diff & (-diff);       // lowest differing bit, no overflow
        int a = 0, b = 0;
        for (int v : nums) {
            if (v & lowBit) a ^= v;
            else            b ^= v;
        }
        return {a, b};
    }
};
```

### Java
```java
class Solution {
    public int[] singleNumber(int[] nums) {
        long diff = 0;
        for (int v : nums) diff ^= v;
        long lowBit = diff & (-diff);
        int a = 0, b = 0;
        for (int v : nums) {
            if ((v & lowBit) != 0) a ^= v;
            else                   b ^= v;
        }
        return new int[]{a, b};
    }
}
```

### Python
```python
from typing import List

class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        diff = 0
        for v in nums:
            diff ^= v
        low_bit = diff & -diff
        a = b = 0
        for v in nums:
            if v & low_bit:
                a ^= v
            else:
                b ^= v
        return [a, b]
```

## Key Takeaways
- XOR of all elements gives `x ^ y`; a set bit in it is a position where `x` and `y` differ.
- Partition on that bit so each half contains exactly one odd-count value, then XOR each half.
- `diff & -diff` isolates the lowest set bit; guard against negating `INT_MIN` in fixed-width languages.
- Works for "odd number of times" as well as "exactly once" — only parity matters.
