# Floor and Ceil in Sorted Array

**Difficulty:** Easy  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on 1D Arrays

## Problem
Given a sorted array `arr` of size `n` and an integer `x`, find the floor and the ceil of `x`. The floor is the largest element that is `<= x`; the ceil is the smallest element that is `>= x`. Return both values, using `-1` for whichever does not exist.

Input: `arr = [3, 4, 4, 7, 8, 10], x = 5`
Output: `[4, 7]` (floor is 4, ceil is 7)

Input: `arr = [3, 4, 4, 7, 8, 10], x = 8`
Output: `[8, 8]` (x is present, so it is its own floor and ceil)

## Approach 1: Linear Scan
Track the largest value seen that is `<= x` and the smallest value seen that is `>= x` while walking the whole array. Works on unsorted input too, but wastes the sort order.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Two Binary Searches (Optimal)
Both answers are boundary positions of monotone predicates on a sorted array, so each is found by an independent binary search.

**Ceil** is the value at the lower bound of `x`: search for the first index with `arr[i] >= x`; if that index is `n`, no ceil exists.

**Floor** is the mirror image: search for the last index with `arr[i] <= x`. When `arr[mid] <= x`, record `mid` and move right (`low = mid + 1`) to find a larger qualifying index; otherwise move left. If no index is recorded, no floor exists.

- **Time:** O(log n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> getFloorAndCeil(vector<int>& arr, int x) {
        int n = arr.size();
        int floorVal = -1, ceilVal = -1;

        // floor: last index with arr[i] <= x
        int low = 0, high = n - 1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (arr[mid] <= x) {
                floorVal = arr[mid];
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }

        // ceil: first index with arr[i] >= x
        low = 0; high = n - 1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (arr[mid] >= x) {
                ceilVal = arr[mid];
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        return {floorVal, ceilVal};
    }
};
```

### Python
```python
from typing import List

class Solution:
    def getFloorAndCeil(self, arr: List[int], x: int) -> List[int]:
        n = len(arr)
        floor_val, ceil_val = -1, -1

        low, high = 0, n - 1
        while low <= high:
            mid = (low + high) // 2
            if arr[mid] <= x:
                floor_val = arr[mid]
                low = mid + 1
            else:
                high = mid - 1

        low, high = 0, n - 1
        while low <= high:
            mid = (low + high) // 2
            if arr[mid] >= x:
                ceil_val = arr[mid]
                high = mid - 1
            else:
                low = mid + 1

        return [floor_val, ceil_val]
```

## Key Takeaways
- Ceil is lower bound; floor is its mirror ("last index satisfying `<= x`"), found by moving right after recording a candidate.
- When `x` is present both answers equal `x` itself.
- Edge cases: `x` smaller than every element has no floor; `x` larger than every element has no ceil; return `-1` in those cases rather than an index.
- Once you know lower/upper bound, most "nearest value" questions on sorted data reduce to one or two such searches.
