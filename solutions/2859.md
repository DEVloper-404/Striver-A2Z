# Program for Least Recently Used (LRU) Page Replacement Algorithm

**Difficulty:** Medium  ·  **Topic:** Greedy Algorithms [Easy, Medium/Hard] › Medium/Hard

## Problem
A system has `capacity` page frames in memory. A sequence of page requests `pages[]` arrives one by one. When a requested page is already in memory it is a *hit*; otherwise it is a *page fault* and the page must be loaded. If memory is full, evict the page that was used **least recently**. Return the total number of page faults.

Input: `pages = [1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5]`, `capacity = 4`
Output: `8`

## Approach 1: Simulate with a list and linear search
Keep a list of pages currently in memory. For each request, search the list: on a hit move the page to the most-recent position; on a miss, if the list is full remove the least-recent page, then append the new page and count a fault.
- **Time:** O(n · capacity)
- **Space:** O(capacity)

## Approach 2: Hash map + doubly linked list (Optimal)
This is the same structure as an LRU cache. Keep pages in a doubly linked list ordered by recency (front = most recent, back = least recent) and a hash map from page number to its list node. Every operation then takes constant time:
- Hit: unlink the node and move it to the front.
- Miss: count a fault; if the list has `capacity` nodes, delete the back node and erase it from the map; insert the new page at the front.

- **Time:** O(n)
- **Space:** O(capacity)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <list>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int pageFaults(vector<int>& pages, int capacity) {
        list<int> order;                              // front = most recently used
        unordered_map<int, list<int>::iterator> pos;
        int faults = 0;
        for (int p : pages) {
            auto it = pos.find(p);
            if (it != pos.end()) {
                order.erase(it->second);              // hit: refresh recency
            } else {
                faults++;
                if ((int)order.size() == capacity) {
                    int victim = order.back();
                    order.pop_back();
                    pos.erase(victim);
                }
            }
            order.push_front(p);
            pos[p] = order.begin();
        }
        return faults;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int pageFaults(int[] pages, int capacity) {
        // LinkedHashMap in access order keeps least-recently-used entry first
        LinkedHashMap<Integer, Boolean> lru = new LinkedHashMap<>(16, 0.75f, true);
        int faults = 0;
        for (int p : pages) {
            if (lru.containsKey(p)) {
                lru.get(p);                       // access refreshes order
            } else {
                faults++;
                if (lru.size() == capacity) {
                    Integer victim = lru.keySet().iterator().next();
                    lru.remove(victim);
                }
                lru.put(p, Boolean.TRUE);
            }
        }
        return faults;
    }
}
```

### Python
```python
from collections import OrderedDict
from typing import List

class Solution:
    def pageFaults(self, pages: List[int], capacity: int) -> int:
        lru = OrderedDict()          # first item = least recently used
        faults = 0
        for p in pages:
            if p in lru:
                lru.move_to_end(p)   # hit: mark as most recent
            else:
                faults += 1
                if len(lru) == capacity:
                    lru.popitem(last=False)
                lru[p] = True
        return faults
```

## Key Takeaways
- LRU page replacement is exactly an LRU cache that counts misses; the hash map + ordered list gives O(1) per request.
- A hit must still update recency, otherwise the eviction order is wrong.
- Edge cases: `capacity == 0` (every request faults, and nothing is stored), and repeated requests for the same page (only the first is a fault).
