# Expression Add Operators

**Difficulty:** Hard  ·  **Topic:** Recursion [PatternWise] › Trying out all Combos / Hard

## Problem
Given a string `num` of digits and an integer `target`, insert the binary operators `+`, `-`, `*` between the digits (or nothing, which glues digits into a larger number) so that the resulting expression evaluates to `target`. Return all such expressions. Numbers in the expression may not have leading zeros (a lone `0` is fine).

Input: `num = "123"`, `target = 6`
Output: `["1+2+3", "1*2*3"]`

## Approach 1: Generate every expression, evaluate each
Between each pair of adjacent digits there are four choices (`+`, `-`, `*`, or join), so there are `4^(n-1)` candidate expressions. Build each one as a string and evaluate it with a small parser that respects `*` precedence. Then compare with `target`.

Correct but wasteful: the parsing repeats work that the recursion could carry along.
- **Time:** O(4^n · n)
- **Space:** O(n) recursion depth

## Approach 2: Backtracking carrying running value and last operand (Optimal)
Recurse on position `pos` with three pieces of state: the expression built so far, its `value` under normal precedence, and `last`, the most recent multiplicative term. At each step pick the next operand `num[pos..i]` (stop extending if it starts with `'0'`):
- First operand: just set `value = last = operand`.
- `+`: `value + operand`, `last = operand`.
- `-`: `value - operand`, `last = -operand`.
- `*`: precedence means we must undo the last additive step and multiply it: `value - last + last * operand`, `last = last * operand`.

When `pos == n` and `value == target`, record the expression. Use 64-bit integers because intermediate values can overflow 32 bits.
- **Time:** O(4^n · n) — the same enumeration, but evaluation is O(1) per step
- **Space:** O(n) recursion depth and expression buffer

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
    string num; long long target;
    vector<string> out;

    void go(int pos, string expr, long long value, long long last) {
        if (pos == (int)num.size()) {
            if (value == target) out.push_back(expr);
            return;
        }
        for (int i = pos; i < (int)num.size(); ++i) {
            if (i > pos && num[pos] == '0') break;           // no leading zeros
            string s = num.substr(pos, i - pos + 1);
            long long v = stoll(s);
            if (pos == 0) {
                go(i + 1, s, v, v);
            } else {
                go(i + 1, expr + "+" + s, value + v, v);
                go(i + 1, expr + "-" + s, value - v, -v);
                go(i + 1, expr + "*" + s, value - last + last * v, last * v);
            }
        }
    }
public:
    vector<string> addOperators(string n, int t) {
        num = n; target = t;
        go(0, "", 0, 0);
        return out;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private String num;
    private long target;
    private List<String> out = new ArrayList<>();

    public List<String> addOperators(String n, int t) {
        num = n; target = t;
        go(0, "", 0, 0);
        return out;
    }

    private void go(int pos, String expr, long value, long last) {
        if (pos == num.length()) {
            if (value == target) out.add(expr);
            return;
        }
        for (int i = pos; i < num.length(); i++) {
            if (i > pos && num.charAt(pos) == '0') break;
            String s = num.substring(pos, i + 1);
            long v = Long.parseLong(s);
            if (pos == 0) {
                go(i + 1, s, v, v);
            } else {
                go(i + 1, expr + "+" + s, value + v, v);
                go(i + 1, expr + "-" + s, value - v, -v);
                go(i + 1, expr + "*" + s, value - last + last * v, last * v);
            }
        }
    }
}
```

### Python
```python
from typing import List

class Solution:
    def addOperators(self, num: str, target: int) -> List[str]:
        out: List[str] = []
        n = len(num)

        def go(pos: int, expr: str, value: int, last: int) -> None:
            if pos == n:
                if value == target:
                    out.append(expr)
                return
            for i in range(pos, n):
                if i > pos and num[pos] == "0":
                    break
                s = num[pos:i + 1]
                v = int(s)
                if pos == 0:
                    go(i + 1, s, v, v)
                else:
                    go(i + 1, expr + "+" + s, value + v, v)
                    go(i + 1, expr + "-" + s, value - v, -v)
                    go(i + 1, expr + "*" + s, value - last + last * v, last * v)

        go(0, "", 0, 0)
        return out
```

## Key Takeaways
- Carry `value` and `last` through the recursion so `*` can be applied with correct precedence in O(1): `value - last + last * v`.
- Reject operands with a leading zero by breaking out of the loop once `num[pos] == '0'` and the length exceeds 1.
- The first operand gets no operator in front of it — handle `pos == 0` separately.
- Use 64-bit integers; a chain of multiplications easily overflows 32 bits even when the final answer fits.
