# Minimum Window Substring

**Difficulty:** Hard  ·  **Topic:** Sliding Window & Two Pointer Combined Problems › Hard Problems

## Problem
Given strings `s` and `t`, return the shortest substring of `s` that contains every character of `t` with at least the same multiplicity. If no such substring exists return the empty string. The answer is guaranteed unique.

Input: `s = "ADOBECODEBANC", t = "ABC"`
Output: `"BANC"`

Input: `s = "a", t = "aa"`
Output: `""`

## Approach 1: Brute Force
For every start index `i` in `s`, walk `j` to the right while maintaining a frequency array, and stop at the first `j` where all of `t`'s requirements are met. Compare that window length with the best. Checking "all requirements met" can be done incrementally with a counter.

- **Time:** O(n²)
- **Space:** O(256)

## Approach 2: Sliding Window with Need Counter (Optimal)
Build a frequency table `need` from `t`. Slide a window `[l, r]` over `s`, and keep `have` = number of characters in the window that still count toward satisfying `t`.

1. Add `s[r]`: decrement `need[s[r]]`; if it was positive before decrementing, this character was genuinely required, so `have++`.
2. While `have == |t|` the window is valid. Record it if it is the shortest so far, then remove `s[l]`: increment `need[s[l]]`; if it becomes positive, the window just lost a required character, so `have--`. Advance `l`.
3. Continue until `r` reaches the end.

Negative entries in `need` represent surplus copies inside the window; they never affect `have`. Each character is added and removed at most once.

- **Time:** O(|s| + |t|)
- **Space:** O(256) = O(1)

## Code (Optimal)

### C++
```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string minWindow(string s, string t) {
        vector<int> need(256, 0);
        for (char c : t) need[(unsigned char)c]++;
        int required = t.size(), have = 0;
        int bestLen = -1, bestStart = 0, l = 0;
        for (int r = 0; r < (int)s.size(); ++r) {
            if (need[(unsigned char)s[r]] > 0) have++;
            need[(unsigned char)s[r]]--;
            while (have == required) {
                if (bestLen == -1 || r - l + 1 < bestLen) {
                    bestLen = r - l + 1;
                    bestStart = l;
                }
                need[(unsigned char)s[l]]++;
                if (need[(unsigned char)s[l]] > 0) have--;
                l++;
            }
        }
        return bestLen == -1 ? "" : s.substr(bestStart, bestLen);
    }
};
```

### Java
```java
class Solution {
    public String minWindow(String s, String t) {
        int[] need = new int[256];
        for (char c : t.toCharArray()) need[c]++;
        int required = t.length(), have = 0;
        int bestLen = -1, bestStart = 0, l = 0;
        for (int r = 0; r < s.length(); r++) {
            char c = s.charAt(r);
            if (need[c] > 0) have++;
            need[c]--;
            while (have == required) {
                if (bestLen == -1 || r - l + 1 < bestLen) {
                    bestLen = r - l + 1;
                    bestStart = l;
                }
                char out = s.charAt(l);
                need[out]++;
                if (need[out] > 0) have--;
                l++;
            }
        }
        return bestLen == -1 ? "" : s.substring(bestStart, bestStart + bestLen);
    }
}
```

### Python
```python
from collections import defaultdict

class Solution:
    def minWindow(self, s: str, t: str) -> str:
        need = defaultdict(int)
        for ch in t:
            need[ch] += 1
        required = len(t)
        have = 0
        best_len = -1
        best_start = 0
        l = 0
        for r, ch in enumerate(s):
            if need[ch] > 0:
                have += 1
            need[ch] -= 1
            while have == required:
                if best_len == -1 or r - l + 1 < best_len:
                    best_len = r - l + 1
                    best_start = l
                out = s[l]
                need[out] += 1
                if need[out] > 0:
                    have -= 1
                l += 1
        return "" if best_len == -1 else s[best_start:best_start + best_len]
```

## Key Takeaways
- Track a single `have` counter that only changes when a *required* copy enters or leaves; surplus copies are represented by negative counts.
- Shrink greedily while valid to find the minimal window ending at each `r`.
- Edge cases: `t` longer than `s`, characters of `t` absent from `s`, duplicates in `t` (the multiplicity check is essential).
