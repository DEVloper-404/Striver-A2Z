# Symmetric Binary Tree

**Difficulty:** Medium  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Medium Problems

## Problem
A binary tree is symmetric if it is a mirror image of itself around its root: the left subtree is the mirror of the right subtree. Given the root, return `true` if the tree is symmetric, `false` otherwise. An empty tree is symmetric.

Input: root = [1,2,2,3,4,4,3]
Output: true

Input: root = [1,2,2,null,3,null,3]
Output: false  (both 3s are right children, so the sides do not mirror)

## Approach 1: Build the Mirror and Compare
Create a mirrored copy of the tree (swap left and right at every node), then check whether the original and the copy are identical using the same-tree recursion. Correct but allocates an entire second tree.

- **Time:** O(n)
- **Space:** O(n) for the copy

## Approach 2: Mirror-Aware Pairwise Recursion (Optimal)
Compare two subtrees `a` and `b` for being mirrors of each other. They are mirrors when:

1. Both are null → true.
2. Exactly one is null, or the values differ → false.
3. `a.left` mirrors `b.right` AND `a.right` mirrors `b.left`.

Call this on `root.left` and `root.right`. The crossed recursion (left with right, right with left) is the only difference from the "identical trees" check. An iterative version pushes pairs onto a queue in the same crossed order.
- **Time:** O(n)
- **Space:** O(h) recursion stack

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; ... } — standard definition
class Solution {
    bool mirror(TreeNode* a, TreeNode* b) {
        if (!a && !b) return true;
        if (!a || !b || a->val != b->val) return false;
        return mirror(a->left, b->right) && mirror(a->right, b->left);
    }
public:
    bool isSymmetric(TreeNode* root) {
        if (!root) return true;
        return mirror(root->left, root->right);
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
class Solution {
    private boolean mirror(TreeNode a, TreeNode b) {
        if (a == null && b == null) return true;
        if (a == null || b == null || a.val != b.val) return false;
        return mirror(a.left, b.right) && mirror(a.right, b.left);
    }

    public boolean isSymmetric(TreeNode root) {
        if (root == null) return true;
        return mirror(root.left, root.right);
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
class Solution:
    def isSymmetric(self, root) -> bool:
        def mirror(a, b):
            if a is None and b is None:
                return True
            if a is None or b is None or a.val != b.val:
                return False
            return mirror(a.left, b.right) and mirror(a.right, b.left)

        if root is None:
            return True
        return mirror(root.left, root.right)
```

## Key Takeaways
- Symmetry is "same tree" with the children crossed: compare `a.left` to `b.right` and `a.right` to `b.left`.
- Checking values level by level alone is insufficient; positions must mirror too (see the second example).
- Null handling first: both null is fine, one null is a mismatch.
