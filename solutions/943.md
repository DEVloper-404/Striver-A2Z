# Bubble Sort

**Difficulty:** Easy  ·  **Topic:** Learn Important Sorting Techniques › Sorting-I

## Problem
Given an array of `n` integers, sort it in non-decreasing order using bubble sort. Modify the array in place and return it.

Input: `arr = [13, 46, 24, 52, 20, 9]`
Output: `[9, 13, 20, 24, 46, 52]`

## Approach 1: Plain Bubble Sort
Compare every adjacent pair and swap when the left value is bigger. One full left-to-right sweep guarantees the largest remaining element "bubbles" to the end of the unsorted region. Repeating the sweep `n-1` times, and shrinking the range by one each time, sorts the whole array.

- **Time:** O(n²) in every case.
- **Space:** O(1).

## Approach 2: Bubble Sort with Early Exit (Optimal)
Track whether a sweep performed any swap. If a sweep finishes with zero swaps, every adjacent pair is already in order, which means the array is sorted and we can stop immediately. This turns the best case (already sorted input) into a single linear pass.

Bubble sort is stable because it only swaps strictly greater elements past smaller ones; equal elements never cross.

- **Time:** O(n) best case, O(n²) average and worst case.
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <utility>
using namespace std;

class Solution {
public:
    vector<int> bubbleSort(vector<int>& arr) {
        int n = arr.size();
        for (int i = n - 1; i > 0; i--) {
            bool swapped = false;
            for (int j = 0; j < i; j++) {
                if (arr[j] > arr[j + 1]) {
                    swap(arr[j], arr[j + 1]);
                    swapped = true;
                }
            }
            if (!swapped) break;
        }
        return arr;
    }
};
```

### Java
```java
class Solution {
    public int[] bubbleSort(int[] arr) {
        int n = arr.length;
        for (int i = n - 1; i > 0; i--) {
            boolean swapped = false;
            for (int j = 0; j < i; j++) {
                if (arr[j] > arr[j + 1]) {
                    int tmp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = tmp;
                    swapped = true;
                }
            }
            if (!swapped) break;
        }
        return arr;
    }
}
```

### Python
```python
class Solution:
    def bubbleSort(self, arr: list[int]) -> list[int]:
        n = len(arr)
        for i in range(n - 1, 0, -1):
            swapped = False
            for j in range(i):
                if arr[j] > arr[j + 1]:
                    arr[j], arr[j + 1] = arr[j + 1], arr[j]
                    swapped = True
            if not swapped:
                break
        return arr
```

## Key Takeaways
- Each sweep fixes the maximum of the unsorted region at its right end, so the inner loop bound shrinks by one per pass.
- The `swapped` flag is what makes bubble sort O(n) on already-sorted data; without it the algorithm is always quadratic.
- Stable sort, in place, but too slow for large inputs — mostly a teaching algorithm.
