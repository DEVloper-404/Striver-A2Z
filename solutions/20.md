# Count Inversions

**Difficulty:** Hard  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Hard

## Problem
Given an integer array `arr`, count the number of inversions: pairs of indices `(i, j)` with `i < j` and `arr[i] > arr[j]`. A sorted array has 0 inversions; a strictly decreasing array has the maximum, n(n-1)/2.

Input: `arr = [5, 3, 2, 4, 1]`
Output: `8` (pairs: (5,3) (5,2) (5,4) (5,1) (3,2) (3,1) (2,1) (4,1))

## Approach 1: Brute Force
Check every pair `i < j` and count those with `arr[i] > arr[j]`.
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Merge sort with counting (Optimal)
Merge sort splits the array, sorts both halves, and merges. During the merge, both halves are already sorted. When the element taken from the right half `right[j]` is smaller than the current left element `left[i]`, then it is also smaller than every remaining element in the left half (they are all `>= left[i]`). So that single step reveals `(len(left) - i)` inversions at once.

1. Recursively count inversions inside the left half and inside the right half.
2. While merging, whenever you pick from the right because `right[j] < left[i]`, add the number of elements still remaining in the left half.
3. The total is left-count + right-count + cross-count.

Use a 64-bit counter: the answer can reach ~n²/2.

- **Time:** O(n log n)
- **Space:** O(n) for the merge buffer

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    long long mergeCount(vector<int>& a, vector<int>& tmp, int lo, int mid, int hi) {
        int i = lo, j = mid + 1, k = lo;
        long long inv = 0;
        while (i <= mid && j <= hi) {
            if (a[i] <= a[j]) tmp[k++] = a[i++];
            else { inv += (mid - i + 1); tmp[k++] = a[j++]; }
        }
        while (i <= mid) tmp[k++] = a[i++];
        while (j <= hi) tmp[k++] = a[j++];
        for (int t = lo; t <= hi; ++t) a[t] = tmp[t];
        return inv;
    }

    long long sortCount(vector<int>& a, vector<int>& tmp, int lo, int hi) {
        if (lo >= hi) return 0;
        int mid = lo + (hi - lo) / 2;
        long long inv = sortCount(a, tmp, lo, mid);
        inv += sortCount(a, tmp, mid + 1, hi);
        inv += mergeCount(a, tmp, lo, mid, hi);
        return inv;
    }
public:
    long long numberOfInversions(vector<int>& arr) {
        vector<int> tmp(arr.size());
        return sortCount(arr, tmp, 0, (int)arr.size() - 1);
    }
};
```

### Python
```python
from typing import List

class Solution:
    def numberOfInversions(self, arr: List[int]) -> int:
        def sort_count(a: List[int]) -> (List[int], int):
            if len(a) <= 1:
                return a, 0
            mid = len(a) // 2
            left, li = sort_count(a[:mid])
            right, ri = sort_count(a[mid:])
            merged = []
            i = j = 0
            cross = 0
            while i < len(left) and j < len(right):
                if left[i] <= right[j]:
                    merged.append(left[i]); i += 1
                else:
                    cross += len(left) - i
                    merged.append(right[j]); j += 1
            merged.extend(left[i:])
            merged.extend(right[j:])
            return merged, li + ri + cross

        _, total = sort_count(list(arr))
        return total
```

## Key Takeaways
- Sorted halves let you count all cross-inversions of one right element in O(1): `mid - i + 1`.
- Use `<=` when taking from the left so equal values are not counted as inversions.
- The result can overflow 32-bit for n around 1e5; return a `long`/`long long`.
- Same skeleton solves Reverse Pairs, with a separate counting pass before the merge.
