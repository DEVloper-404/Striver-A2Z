# Pattern 14

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a right-angled triangle of `n` rows using uppercase letters. Row `i` contains the first `i` letters of the alphabet, `A` through the `i`-th letter, separated by spaces.

Input: `n = 5`
Output:
```
A
A B
A B C
A B C D
A B C D E
```

## Approach
Characters are integers underneath, so the number triangle from Pattern 3 becomes a letter triangle by adding the column offset to `'A'`.

1. Outer loop `i` from `0` to `n-1`.
2. Inner loop `j` from `0` to `i`: print the character `'A' + j`.
3. Newline.

In C++ and Java a cast to `char` is needed so the sum prints as a letter rather than a number; in Python use `chr(ord('A') + j)`.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern14(int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j <= i; j++) {
            cout << (char)('A' + j) << " ";
        }
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern14 {
    public static void pattern14(int n) {
        for (int i = 0; i < n; i++) {
            StringBuilder row = new StringBuilder();
            for (int j = 0; j <= i; j++) {
                row.append((char) ('A' + j)).append(' ');
            }
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern14(n: int) -> None:
    for i in range(n):
        print(" ".join(chr(ord("A") + j) for j in range(i + 1)))
```

## Key Takeaways
- Letter patterns are number patterns with an `'A'` offset; the loop structure is unchanged.
- Remember the `char` cast in C++/Java, otherwise you print ASCII codes like 65.
- Use 0-based column indices here so `'A' + 0` is the first letter.
