# Find the length of the Linked List

**Difficulty:** Easy  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Learn 1D LinkedList

## Problem
Given the head of a singly linked list, return the number of nodes in it. An empty list has length 0.

Input: `head = 1 -> 2 -> 3 -> 4`
Output: `4`

Input: `head = null`
Output: `0`

## Approach 1: Recursive count
The length of a list is `1 + length(rest)`, and the length of an empty list is 0. This is elegant but uses a stack frame per node, which can overflow on very long lists.
- **Time:** O(n)
- **Space:** O(n) call stack

## Approach 2: Iterative traversal (Optimal)
Start a pointer at the head and a counter at 0. While the pointer is not `null`, increment the counter and move the pointer to `next`. There is no way to know the length without touching each node, so this is optimal.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int v) : val(v), next(nullptr) {} };
// (standard definition)

class Solution {
public:
    int lengthOfList(ListNode* head) {
        int count = 0;
        for (ListNode* cur = head; cur != nullptr; cur = cur->next) {
            count++;
        }
        return count;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int val) { this.val = val; } }
// (standard definition)

class Solution {
    public int lengthOfList(ListNode head) {
        int count = 0;
        for (ListNode cur = head; cur != null; cur = cur.next) {
            count++;
        }
        return count;
    }
}
```

### Python
```python
from typing import Optional

# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
# (standard definition)

class Solution:
    def lengthOfList(self, head: Optional["ListNode"]) -> int:
        count = 0
        cur = head
        while cur:
            count += 1
            cur = cur.next
        return count
```

## Key Takeaways
- Linked lists do not store their size; counting requires a full walk.
- Use a temporary pointer for traversal so `head` remains intact.
- Prefer the iterative version; recursion risks stack overflow on long lists.
- Many later problems (middle node, k-th from end) start with this length computation.
