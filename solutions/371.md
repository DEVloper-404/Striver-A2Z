# Factorial of a given number

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Learn Basic Recursion

## Problem
Given a non-negative integer `N`, return `N!` — the product `1 × 2 × ... × N`. By definition `0! = 1`.

Input: `N = 5`
Output: `120`

Input: `N = 0`
Output: `1`

## Approach 1: Iterative loop
Start with `result = 1` and multiply by every integer from 2 to `N`.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Functional recursion
`fact(n) = n × fact(n - 1)` with base case `fact(0) = 1`. Each frame waits for the smaller factorial to come back and multiplies it by its own `n`.

Trace for `n = 4`: `fact(4)` = 4 × `fact(3)` = 4 × 3 × `fact(2)` = 4 × 3 × 2 × `fact(1)` = 4 × 3 × 2 × 1 × `fact(0)` = 24.

Practical note: `20!` is the largest factorial that fits in a signed 64-bit integer (`13!` already overflows 32 bits). For larger `N` you need big integers (Python does this automatically) or modular arithmetic.

- **Time:** O(n)
- **Space:** O(n) recursion depth

## Code (Optimal)

Both forms are O(n); the recursive one is the focus of this section. The iterative version is shown alongside because it avoids stack depth.

### C++
```cpp
class Solution {
public:
    long long factorial(int n) {
        if (n <= 1) return 1;            // 0! = 1! = 1
        return (long long)n * factorial(n - 1);
    }

    long long factorialIterative(int n) {
        long long result = 1;
        for (int i = 2; i <= n; i++) result *= i;
        return result;
    }
};
```

### Python
```python
class Solution:
    def factorial(self, n: int) -> int:
        if n <= 1:          # 0! = 1! = 1
            return 1
        return n * self.factorial(n - 1)

    def factorialIterative(self, n: int) -> int:
        result = 1
        for i in range(2, n + 1):
            result *= i
        return result
```

## Key Takeaways
- Classic functional recursion: base case `0! = 1`, step `n × (n-1)!`.
- Factorials grow extremely fast — use 64-bit for `n ≤ 20`, and big integers or a modulus beyond that.
- The recursive version uses O(n) stack; the loop gives the same answer in O(1) space.
