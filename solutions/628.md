# Segregate odd and even nodes in Linked List

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
Given the head of a singly linked list, regroup the nodes so that all nodes at odd positions (1st, 3rd, 5th, ...) come first, followed by all nodes at even positions (2nd, 4th, ...). Positions refer to the node index, not the stored value. The relative order inside each group must be preserved, and the solution should use O(1) extra space.

```
Input:  1 -> 2 -> 3 -> 4 -> 5
Output: 1 -> 3 -> 5 -> 2 -> 4
```

## Approach 1: Collect values, then overwrite
Walk the list twice, first gathering values at odd positions into an array, then values at even positions. Walk a third time writing the array back into the nodes. Correct and simple, but uses O(n) extra memory and only moves data, not nodes.

- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Two chains rewired in one pass (optimal)
Maintain two pointers: `odd` starting at the head and `even` at `head.next`. Remember `evenHead` because we will need to attach it at the end. Repeatedly:

1. `odd.next = even.next` (skip over the even node to the next odd one), then move `odd` forward.
2. `even.next = odd.next` (skip over the odd node to the next even one), then move `even` forward.

Stop when `even` or `even.next` is null. Finally connect `odd.next = evenHead`. Each node is relinked once.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
public:
    ListNode* oddEvenList(ListNode* head) {
        if (!head || !head->next) return head;
        ListNode* odd = head;
        ListNode* even = head->next;
        ListNode* evenHead = even;
        while (even && even->next) {
            odd->next = even->next;
            odd = odd->next;
            even->next = odd->next;
            even = even->next;
        }
        odd->next = evenHead;
        return head;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } }

class Solution {
    public ListNode oddEvenList(ListNode head) {
        if (head == null || head.next == null) return head;
        ListNode odd = head, even = head.next, evenHead = even;
        while (even != null && even.next != null) {
            odd.next = even.next;
            odd = odd.next;
            even.next = odd.next;
            even = even.next;
        }
        odd.next = evenHead;
        return head;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def oddEvenList(self, head):
        if head is None or head.next is None:
            return head
        odd, even = head, head.next
        even_head = even
        while even and even.next:
            odd.next = even.next
            odd = odd.next
            even.next = odd.next
            even = even.next
        odd.next = even_head
        return head
```

## Key Takeaways
- Build two interleaved chains simultaneously, then join the odd tail to the even head.
- Save `evenHead` before the loop; it is the only handle you will have on the even chain.
- The loop guard `even and even.next` covers both odd and even list lengths without special cases.
- "Odd/even" refers to positions; the same code works no matter what values the nodes hold.
