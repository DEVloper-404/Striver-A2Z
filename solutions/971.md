# Sum of Subarray Minimums

**Difficulty:** Medium  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Monotonic Stack/Queue Problems [VVV. Imp]

## Problem
Given an integer array `arr`, consider every contiguous subarray, take its minimum element, and add all those minimums together. Return the total modulo 1e9+7.

```
Input:  arr = [3, 1, 2, 4]
Output: 17
```
Subarray minimums: 3, 1, 2, 4, 1, 1, 2, 1, 1, 1 → sum 17.

## Approach 1: Brute Force
Enumerate all O(n²) subarrays; for each starting point, extend the end while tracking the running minimum and add it to the total.
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Contribution Counting with Monotonic Stacks (Optimal)
Flip the question: instead of asking "what is the min of each subarray", ask "in how many subarrays is `arr[i]` the minimum?" If `arr[i]` is the minimum of `k` subarrays, it contributes `arr[i] * k` to the answer.

`arr[i]` is the minimum of every subarray that stays strictly inside the window bounded by:
- `pse[i]` = index of the previous element that is **strictly smaller** than `arr[i]` (or -1),
- `nse[i]` = index of the next element that is **smaller or equal** to `arr[i]` (or n).

Then `k = (i - pse[i]) * (nse[i] - i)`. The asymmetric strict / non-strict rule guarantees that among equal minimums exactly one of them is credited for each subarray.

Both boundary arrays come from a single-direction monotonic stack scan each.
- **Time:** O(n)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stack>
using namespace std;

class Solution {
public:
    int sumSubarrayMins(vector<int>& arr) {
        const long long MOD = 1'000'000'007LL;
        int n = arr.size();
        vector<int> pse(n, -1), nse(n, n);
        stack<int> st;
        for (int i = 0; i < n; ++i) {               // previous strictly smaller
            while (!st.empty() && arr[st.top()] >= arr[i]) st.pop();
            pse[i] = st.empty() ? -1 : st.top();
            st.push(i);
        }
        while (!st.empty()) st.pop();
        for (int i = n - 1; i >= 0; --i) {          // next smaller-or-equal
            while (!st.empty() && arr[st.top()] > arr[i]) st.pop();
            nse[i] = st.empty() ? n : st.top();
            st.push(i);
        }
        long long total = 0;
        for (int i = 0; i < n; ++i) {
            long long left = i - pse[i], right = nse[i] - i;
            total = (total + (left * right % MOD) * arr[i]) % MOD;
        }
        return (int)total;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int sumSubarrayMins(int[] arr) {
        final long MOD = 1_000_000_007L;
        int n = arr.length;
        int[] pse = new int[n], nse = new int[n];
        Deque<Integer> st = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            while (!st.isEmpty() && arr[st.peek()] >= arr[i]) st.pop();
            pse[i] = st.isEmpty() ? -1 : st.peek();
            st.push(i);
        }
        st.clear();
        for (int i = n - 1; i >= 0; i--) {
            while (!st.isEmpty() && arr[st.peek()] > arr[i]) st.pop();
            nse[i] = st.isEmpty() ? n : st.peek();
            st.push(i);
        }
        long total = 0;
        for (int i = 0; i < n; i++) {
            long left = i - pse[i], right = nse[i] - i;
            total = (total + (left * right % MOD) * arr[i]) % MOD;
        }
        return (int) total;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def sumSubarrayMins(self, arr: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(arr)
        pse = [-1] * n
        nse = [n] * n
        st = []
        for i in range(n):
            while st and arr[st[-1]] >= arr[i]:
                st.pop()
            pse[i] = st[-1] if st else -1
            st.append(i)
        st = []
        for i in range(n - 1, -1, -1):
            while st and arr[st[-1]] > arr[i]:
                st.pop()
            nse[i] = st[-1] if st else n
            st.append(i)
        total = 0
        for i in range(n):
            total = (total + (i - pse[i]) * (nse[i] - i) * arr[i]) % MOD
        return total
```

## Key Takeaways
- "Sum over all subarrays of f(subarray)" problems often become "sum over elements of value × number of subarrays where it matters".
- Use strict on one side and non-strict on the other to avoid double-counting duplicates.
- Multiply in 64-bit and reduce modulo at every step; `left * right * arr[i]` can overflow 32-bit.
