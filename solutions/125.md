# Vertical Order Traversal

**Difficulty:** Medium  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Medium Problems

## Problem
Assign every node a column: the root is at column 0, a left child is at `col - 1`, a right child at `col + 1`. Return the nodes grouped by column from leftmost to rightmost. Within a column, order nodes by row (depth) top to bottom; if two nodes share the same row and column, order them by value ascending.

Input: root = [3,9,20,null,null,15,7]
Output: [[9],[3,15],[20],[7]]

Input: root = [1,2,3,4,6,5,7]
Output: [[4],[2],[1,5,6],[3],[7]]
(5 and 6 are both in column 0, row 2, so 5 comes before 6)

## Approach 1: Collect Triples and Sort
Traverse the tree (any order), recording `(col, row, val)` for each node. Sort the list of triples lexicographically, then sweep through it grouping consecutive entries with the same column.

- **Time:** O(n log n) for the sort
- **Space:** O(n)

## Approach 2: BFS with an Ordered Map of Columns (Optimal in practice)
Do a level-order traversal carrying `(node, col, row)`. Maintain `map<col, map<row, multiset<val>>>` (or a dictionary keyed by column, then row, with a list that is sorted at the end). Because BFS visits rows in increasing order, and the map keeps columns sorted, the only sorting needed is among values that tie on both row and column — usually a handful of nodes.

Finally iterate the columns in key order; for each column iterate its rows in order and append the (sorted) values.
- **Time:** O(n log n) worst case for the map inserts, near O(n) typically
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; ... } — standard definition
class Solution {
public:
    vector<vector<int>> verticalTraversal(TreeNode* root) {
        vector<vector<int>> res;
        if (!root) return res;
        map<int, map<int, multiset<int>>> cols; // col -> row -> values
        queue<tuple<TreeNode*, int, int>> q;
        q.push({root, 0, 0});
        while (!q.empty()) {
            auto [node, c, r] = q.front(); q.pop();
            cols[c][r].insert(node->val);
            if (node->left)  q.push({node->left,  c - 1, r + 1});
            if (node->right) q.push({node->right, c + 1, r + 1});
        }
        for (auto& [c, rows] : cols) {
            vector<int> column;
            for (auto& [r, vals] : rows)
                column.insert(column.end(), vals.begin(), vals.end());
            res.push_back(column);
        }
        return res;
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
import java.util.*;

class Solution {
    public List<List<Integer>> verticalTraversal(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;
        TreeMap<Integer, TreeMap<Integer, PriorityQueue<Integer>>> cols = new TreeMap<>();
        Queue<Object[]> q = new ArrayDeque<>();
        q.offer(new Object[]{root, 0, 0});
        while (!q.isEmpty()) {
            Object[] cur = q.poll();
            TreeNode node = (TreeNode) cur[0];
            int c = (Integer) cur[1], r = (Integer) cur[2];
            cols.computeIfAbsent(c, k -> new TreeMap<>())
                .computeIfAbsent(r, k -> new PriorityQueue<>())
                .offer(node.val);
            if (node.left != null)  q.offer(new Object[]{node.left,  c - 1, r + 1});
            if (node.right != null) q.offer(new Object[]{node.right, c + 1, r + 1});
        }
        for (TreeMap<Integer, PriorityQueue<Integer>> rows : cols.values()) {
            List<Integer> column = new ArrayList<>();
            for (PriorityQueue<Integer> pq : rows.values()) {
                while (!pq.isEmpty()) column.add(pq.poll());
            }
            res.add(column);
        }
        return res;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
from collections import deque, defaultdict

class Solution:
    def verticalTraversal(self, root):
        if root is None:
            return []
        cols = defaultdict(lambda: defaultdict(list))  # col -> row -> [vals]
        q = deque([(root, 0, 0)])
        while q:
            node, c, r = q.popleft()
            cols[c][r].append(node.val)
            if node.left:
                q.append((node.left, c - 1, r + 1))
            if node.right:
                q.append((node.right, c + 1, r + 1))
        res = []
        for c in sorted(cols):
            column = []
            for r in sorted(cols[c]):
                column.extend(sorted(cols[c][r]))
            res.append(column)
        return res
```

## Key Takeaways
- Track both column and row; row is needed only to break ties correctly when two nodes land in the same column at the same depth.
- The tie rule (same row and column → sort by value) is what distinguishes this from a simple "group by column" — forgetting it fails the second example.
- Top view and bottom view are this problem with only the first (or last) entry per column kept.
