# Find row with maximum 1's

**Difficulty:** Easy  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on 2D Arrays

## Problem
You are given an `n x m` binary matrix where every row is sorted in non-decreasing order (all 0s come before all 1s). Return the index of the row that contains the most 1s. If several rows tie, return the smallest index; if no row has a 1, return `-1`.

Input: matrix = [[1, 1, 1], [0, 0, 1], [0, 0, 0]]
Output: 0

Input: matrix = [[0, 0], [0, 0]]
Output: -1

## Approach 1: Count Every Cell
For each row, count its 1s by scanning all `m` cells. Track the row with the highest count, updating only on a strictly larger count so the first row wins ties.
- **Time:** O(n * m)
- **Space:** O(1)

## Approach 2: Binary Search Each Row
Because each row is sorted, the number of 1s equals `m - (index of the first 1)`. Find that first index with a lower-bound binary search for the value 1. Do this for every row and keep the best.
- **Time:** O(n * log m)
- **Space:** O(1)

## Approach 3: Staircase Walk (Bonus)
Start at the top-right corner. If the cell is 1, move left (this row has at least this many 1s); if it is 0, move down. The last row where you moved left is the answer. Each step moves either left or down, so the walk takes at most `n + m` steps. Both the binary-search and staircase versions are acceptable; the binary search one is the standard answer for this sheet.
- **Time:** O(n + m)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int firstOne(const vector<int>& row) {
        int lo = 0, hi = (int)row.size() - 1, idx = row.size();
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (row[mid] >= 1) { idx = mid; hi = mid - 1; }
            else lo = mid + 1;
        }
        return idx;
    }

    int rowWithMax1s(vector<vector<int>>& matrix) {
        int n = matrix.size(), m = matrix[0].size();
        int bestRow = -1, bestCount = 0;
        for (int i = 0; i < n; i++) {
            int count = m - firstOne(matrix[i]);
            if (count > bestCount) {
                bestCount = count;
                bestRow = i;
            }
        }
        return bestRow;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def rowWithMax1s(self, matrix: List[List[int]]) -> int:
        def first_one(row: List[int]) -> int:
            lo, hi, idx = 0, len(row) - 1, len(row)
            while lo <= hi:
                mid = (lo + hi) // 2
                if row[mid] >= 1:
                    idx = mid
                    hi = mid - 1
                else:
                    lo = mid + 1
            return idx

        m = len(matrix[0])
        best_row, best_count = -1, 0
        for i, row in enumerate(matrix):
            count = m - first_one(row)
            if count > best_count:
                best_count = count
                best_row = i
        return best_row
```

## Key Takeaways
- "Count of 1s in a sorted binary row" = `m - lowerBound(1)`; a one-line reuse of the lower-bound template.
- Update the best only on a strictly greater count so ties resolve to the smallest row index.
- Initialise `bestCount = 0` and `bestRow = -1` so an all-zero matrix returns `-1`.
