# Median of 2 sorted arrays

**Difficulty:** Hard  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on Answers

## Problem
Given two sorted arrays `nums1` (size `m`) and `nums2` (size `n`), return the median of the combined sorted sequence. The expected complexity is O(log(m + n)).

Input: nums1 = [1, 3], nums2 = [2]
Output: 2.0  (merged: [1, 2, 3])

Input: nums1 = [1, 2], nums2 = [3, 4]
Output: 2.5  (merged: [1, 2, 3, 4] → (2 + 3) / 2)

## Approach 1: Merge Fully
Merge the two arrays with two pointers into a third array of size `m + n`, then read the middle element(s). Simple and correct but uses linear extra space.
- **Time:** O(m + n)
- **Space:** O(m + n)

## Approach 2: Merge Without Storing
Run the same two-pointer merge but only keep a counter. Stop as soon as you have passed the middle index(es), remembering the last one or two values seen. This removes the extra array but is still linear time.
- **Time:** O(m + n)
- **Space:** O(1)

## Approach 3: Binary Search on the Partition
Let `total = m + n` and `left = (total + 1) / 2` = size of the left half of the merged array. Choose `i` elements from `nums1` for the left half; then the left half takes `j = left - i` from `nums2`. A partition is valid when everything in the left half is `<=` everything in the right half, which reduces to `l1 <= r2` and `l2 <= r1`, where `l1 = nums1[i-1]`, `r1 = nums1[i]`, `l2 = nums2[j-1]`, `r2 = nums2[j]` (use ±infinity at the boundaries).

Binary search `i` over `[0, m]` on the smaller array:
- If `l1 > r2`, we took too many from `nums1`: `hi = i - 1`.
- If `l2 > r1`, we took too few: `lo = i + 1`.
- Otherwise the median is `max(l1, l2)` when `total` is odd, or the average of `max(l1, l2)` and `min(r1, r2)` when even.
- **Time:** O(log(min(m, n)))
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
        if (nums1.size() > nums2.size()) return findMedianSortedArrays(nums2, nums1);
        int m = nums1.size(), n = nums2.size();
        int total = m + n, left = (total + 1) / 2;
        int lo = 0, hi = m;
        const int INF = INT_MAX;
        while (lo <= hi) {
            int i = lo + (hi - lo) / 2;
            int j = left - i;
            int l1 = (i > 0) ? nums1[i - 1] : -INF;
            int r1 = (i < m) ? nums1[i] : INF;
            int l2 = (j > 0) ? nums2[j - 1] : -INF;
            int r2 = (j < n) ? nums2[j] : INF;
            if (l1 <= r2 && l2 <= r1) {
                if (total % 2 == 1) return max(l1, l2);
                return (max(l1, l2) + (double)min(r1, r2)) / 2.0;
            }
            if (l1 > r2) hi = i - 1;
            else lo = i + 1;
        }
        return 0.0; // unreachable for valid sorted input
    }
};
```

class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        if (nums1.length > nums2.length) return findMedianSortedArrays(nums2, nums1);

            int j = left - i;
            int l1 = (i > 0) ? nums1[i - 1] : Integer.MIN_VALUE;
            int r1 = (i < m) ? nums1[i] : Integer.MAX_VALUE;
            int l2 = (j > 0) ? nums2[j - 1] : Integer.MIN_VALUE;

            if (l1 > r2) hi = i - 1;
            else lo = i + 1;
        }
        return 0.0;
    }
}

### Python
```python
from typing import List

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
        m, n = len(nums1), len(nums2)
        total = m + n
        left = (total + 1) // 2
        lo, hi = 0, m
        INF = float("inf")
        while lo <= hi:
            i = (lo + hi) // 2
            j = left - i
            l1 = nums1[i - 1] if i > 0 else -INF
            r1 = nums1[i] if i < m else INF
            l2 = nums2[j - 1] if j > 0 else -INF
            r2 = nums2[j] if j < n else INF
            if l1 <= r2 and l2 <= r1:
                if total % 2 == 1:
                    return float(max(l1, l2))
                return (max(l1, l2) + min(r1, r2)) / 2.0
            if l1 > r2:
                hi = i - 1
            else:
                lo = i + 1
        return 0.0
```

## Key Takeaways
- Binary search the *cut position*, not a value: pick `i` elements from the smaller array for the left half and derive `j`.
- A valid cut satisfies `l1 <= r2` and `l2 <= r1`; sentinels (±infinity) handle empty sides cleanly.
- Always search on the smaller array so `j = left - i` stays within `[0, n]`.
- Odd total → median is `max(l1, l2)`; even total → average of the two middle values.
