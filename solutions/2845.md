# Detect a loop in LL

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
Given the head of a singly linked list, decide whether the list contains a cycle, i.e. whether following `next` pointers ever revisits a node instead of reaching null. Return true if a cycle exists, false otherwise.

```
Input:  3 -> 2 -> 0 -> -4 -> (back to 2)
Output: true

Input:  1 -> 2 -> null
Output: false
```

## Approach 1: Hash set of visited nodes
Traverse the list, inserting each node's address into a set. If the current node is already present, a cycle exists. If we reach null, there is none. Simple and correct, but it stores every node.

- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Floyd's tortoise and hare (optimal)
Run two pointers: `slow` moves one step, `fast` moves two. If the list ends, `fast` hits null and we return false. If there is a cycle, both pointers eventually enter it, and because `fast` gains one node on `slow` every step, the gap between them inside the cycle shrinks by one each iteration until they land on the same node. That meeting is proof of a cycle.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
public:
    bool hasCycle(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) return true;
        }
        return false;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } }

public class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) return true;
        }
        return false;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def hasCycle(self, head) -> bool:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                return True
        return False
```

## Key Takeaways
- Compare node identities (pointers), never values; duplicates in value are not a cycle.
- Floyd's algorithm detects a cycle in O(1) space; the fast pointer closes the gap by exactly one per step.
- Move both pointers before comparing so the initial `slow == fast == head` does not trigger a false positive.
- The loop guard on `fast` and `fast.next` handles empty and short lists safely.
