# Maximum Nesting Depth of the Parentheses

**Difficulty:** Medium  ·  **Topic:** Strings [Basic and Medium] › Medium String Problems

## Problem
You are given a valid parentheses string that may also contain digits, letters, and operators. The nesting depth of a position is the number of unmatched `(` before it. Return the maximum nesting depth over the whole string.

Input: `s = "(1+(2*3)+((8)/4))+1"`
Output: `3`  (the digit `8` sits inside three open brackets)

Input: `s = "(1)+((2))+(((3)))"`
Output: `3`

## Approach 1: Stack
Push each `(` on a stack, pop on each `)`. After every push, record the stack size if it is larger than the best so far. The stack size at any moment is exactly the current depth.
- **Time:** O(n)
- **Space:** O(n) for the stack in the worst case

## Approach 2: Counter (Optimal)
You never inspect the stack contents, only its size, so replace it with an integer. Increment on `(`, decrement on `)`, and track the maximum value reached. Every other character is ignored. Because the string is valid, the counter never goes negative.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxDepth(string s) {
        int depth = 0, best = 0;
        for (char c : s) {
            if (c == '(') best = max(best, ++depth);
            else if (c == ')') --depth;
        }
        return best;
    }
};
```

### Java
```java
class Solution {
    public int maxDepth(String s) {
        int depth = 0, best = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                depth++;
                if (depth > best) best = depth;
            } else if (c == ')') {
                depth--;
            }
        }
        return best;
    }
}
```

### Python
```python
class Solution:
    def maxDepth(self, s: str) -> int:
        depth = best = 0
        for c in s:
            if c == '(':
                depth += 1
                best = max(best, depth)
            elif c == ')':
                depth -= 1
        return best
```

## Key Takeaways
- When a stack is only used for its size, replace it with a counter.
- Update the maximum right after incrementing, not after decrementing.
- Non-bracket characters do not affect depth and can be skipped.
- Edge cases: a string with no brackets (answer 0), and `"()"` (answer 1).
