# Check if String is Palindrome or Not

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Learn Basic Recursion

## Problem
Given a string `s`, decide whether it is a palindrome — it reads the same forwards and backwards. In the LeetCode variant ("Valid Palindrome"), only alphanumeric characters count and case is ignored; every other character is skipped.

Input: `s = "racecar"`
Output: `true`

Input: `s = "A man, a plan, a canal: Panama"`
Output: `true` (after filtering: `amanaplanacanalpanama`)

Input: `s = "race a car"`
Output: `false`

## Approach 1: Build the reverse and compare
Create the cleaned string (lower-cased alphanumerics only), reverse it, and compare with the cleaned original.

- **Time:** O(n)
- **Space:** O(n) for the cleaned copy and its reverse

## Approach 2: Two pointers (iterative)
Keep `l` at the start and `r` at the end. Skip non-alphanumeric characters on each side, compare the lower-cased characters, and move inward. Any mismatch means `false`; if the pointers cross, it is a palindrome. No extra memory.

- **Time:** O(n)
- **Space:** O(1)

## Approach 3: Two-pointer recursion
The same check as a recursive function `check(l, r)`: base case `l >= r` returns `true`; otherwise skip non-alphanumerics, compare `s[l]` and `s[r]`, and recurse on `(l + 1, r - 1)`. This is the recursive pattern the section is teaching; it costs stack depth proportional to half the string.

- **Time:** O(n)
- **Space:** O(n) recursion depth

## Code (Optimal)

The recursive two-pointer version is shown (the section's focus); an iterative loop is the same logic with `while (l < r)` instead of the recursive call.

### C++
```cpp
#include <string>
#include <cctype>
using namespace std;

class Solution {
public:
    bool isPalindrome(string s) {
        return check(s, 0, (int)s.size() - 1);
    }

private:
    bool check(const string& s, int l, int r) {
        if (l >= r) return true;
        if (!isalnum((unsigned char)s[l])) return check(s, l + 1, r);
        if (!isalnum((unsigned char)s[r])) return check(s, l, r - 1);
        if (tolower((unsigned char)s[l]) != tolower((unsigned char)s[r])) return false;
        return check(s, l + 1, r - 1);
    }
};
```

### Java
```java
class Solution {
    public boolean isPalindrome(String s) {
        return check(s, 0, s.length() - 1);
    }

    private boolean check(String s, int l, int r) {
        if (l >= r) return true;
        char a = s.charAt(l), b = s.charAt(r);
        if (!Character.isLetterOrDigit(a)) return check(s, l + 1, r);
        if (!Character.isLetterOrDigit(b)) return check(s, l, r - 1);
        if (Character.toLowerCase(a) != Character.toLowerCase(b)) return false;
        return check(s, l + 1, r - 1);
    }
}
```

### Python
```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        # Iterative two pointers: avoids Python's default recursion limit
        l, r = 0, len(s) - 1
        while l < r:
            if not s[l].isalnum():
                l += 1
            elif not s[r].isalnum():
                r -= 1
            else:
                if s[l].lower() != s[r].lower():
                    return False
                l += 1
                r -= 1
        return True

    def isPalindromeRecursive(self, s: str, l: int = 0, r: int | None = None) -> bool:
        if r is None:
            r = len(s) - 1
        if l >= r:
            return True
        if not s[l].isalnum():
            return self.isPalindromeRecursive(s, l + 1, r)
        if not s[r].isalnum():
            return self.isPalindromeRecursive(s, l, r - 1)
        if s[l].lower() != s[r].lower():
            return False
        return self.isPalindromeRecursive(s, l + 1, r - 1)
```

## Key Takeaways
- Two pointers moving inward is the palindrome pattern for strings, arrays, and (with a reversed second half) linked lists.
- Skip non-alphanumeric characters *before* comparing, and compare in a single case.
- The empty string and single characters are palindromes (base case `l >= r`).
- Recursive depth is O(n); in Python prefer the loop for long strings because of the 1000-frame default limit.
