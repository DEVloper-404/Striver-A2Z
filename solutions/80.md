# Lower Bound

**Difficulty:** Easy  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on 1D Arrays

## Problem
Given a sorted array `arr` of size `n` and an integer `x`, return the lower bound of `x`: the smallest index `i` such that `arr[i] >= x`. If no such element exists (every value is smaller than `x`), return `n`.

Input: `arr = [1, 2, 4, 4, 7, 9], x = 4`
Output: `2` (first index holding a value that is at least 4)

Input: `arr = [1, 2, 4, 4, 7, 9], x = 10`
Output: `6` (nothing is >= 10, so return n)

## Approach 1: Linear Scan
Scan from the left and return the first index where `arr[i] >= x`. If the loop finishes without finding one, return `n`. Simple, but it does not exploit the sort order.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Binary Search (Optimal)
The predicate `arr[i] >= x` is false for a prefix of the array and true for the rest, because the array is sorted. Binary search finds the boundary where it flips from false to true:

1. Start with `ans = n` (the answer if no element qualifies), `low = 0`, `high = n - 1`.
2. Look at `mid`. If `arr[mid] >= x`, then `mid` is a candidate; record `ans = mid` and search the left half (`high = mid - 1`) for an even smaller index.
3. Otherwise `arr[mid] < x`, so nothing at or before `mid` can qualify; move `low = mid + 1`.
4. When the range is empty, `ans` holds the smallest qualifying index.

- **Time:** O(log n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int lowerBound(vector<int>& arr, int x) {
        int n = arr.size();
        int low = 0, high = n - 1, ans = n;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (arr[mid] >= x) {
                ans = mid;
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        return ans;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def lowerBound(self, arr: List[int], x: int) -> int:
        n = len(arr)
        low, high, ans = 0, n - 1, n
        while low <= high:
            mid = (low + high) // 2
            if arr[mid] >= x:
                ans = mid
                high = mid - 1
            else:
                low = mid + 1
        return ans
```

## Key Takeaways
- Lower bound is the "first true" position for the monotone predicate `arr[i] >= x`; this "record and shrink" template reappears in many binary search problems.
- Initialise the answer to `n` so the case where every element is smaller than `x` needs no special handling.
- Equivalent library calls: `std::lower_bound` in C++ and `bisect.bisect_left` in Python; Java has no direct equivalent, so writing it by hand is worthwhile.
- Lower bound of `x` is also the index where `x` would be inserted to keep the array sorted (the basis of "Search Insert Position").
