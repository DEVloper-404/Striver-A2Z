# Implement stack using Linkedlist

**Difficulty:** Easy  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Learning

## Problem
Implement a stack backed by a singly linked list, so it never runs out of capacity. Support `push(x)`, `pop()`, `top()`, `isEmpty()` and `size()`. Return -1 for `pop`/`top` on an empty stack.

Input: `push(5), push(9), pop(), top(), size()`
Output: `9, 5, 1`

## Approach: Insert and remove at the head
Treat the head of the linked list as the top of the stack. Both insertion and deletion at the head of a singly linked list are constant time, which is exactly what a stack needs.

- `push(x)`: create a node, point it at the current head, make it the new head, `count++`.
- `pop()`: if head is null underflow; else save head's value, advance head to `head->next`, free the old node, `count--`.
- `top()`: head's value.
- `size()`: maintained `count`.

Unlike the array version there is no overflow condition; memory is allocated per node as needed.
- **Time:** O(1) per operation
- **Space:** O(n) for n stored elements

## Code (Optimal)

### C++
```cpp
class Stack {
    struct Node {
        int val;
        Node* next;
        Node(int v, Node* n) : val(v), next(n) {}
    };
    Node* head = nullptr;
    int count = 0;
public:
    ~Stack() { while (head) pop(); }

    void push(int x) {
        head = new Node(x, head);
        count++;
    }
    int pop() {
        if (!head) return -1;
        Node* old = head;
        int val = old->val;
        head = head->next;
        delete old;
        count--;
        return val;
    }
    int top() const { return head ? head->val : -1; }
    bool isEmpty() const { return head == nullptr; }
    int size() const { return count; }
};
```

### Java
```java
class Stack {
    private static class Node {
        int val; Node next;
        Node(int v, Node n) { val = v; next = n; }
    }
    private Node head = null;
    private int count = 0;

    void push(int x) {
        head = new Node(x, head);
        count++;
    }
    int pop() {
        if (head == null) return -1;
        int val = head.val;
        head = head.next;
        count--;
        return val;
    }
    int top() { return head == null ? -1 : head.val; }
    boolean isEmpty() { return head == null; }
    int size() { return count; }
}
```

### Python
```python
class Node:
    __slots__ = ("val", "next")
    def __init__(self, val, nxt=None):
        self.val = val
        self.next = nxt

class Stack:
    def __init__(self):
        self.head = None
        self.count = 0

    def push(self, x: int) -> None:
        self.head = Node(x, self.head)
        self.count += 1

    def pop(self) -> int:
        if self.head is None:
            return -1
        val = self.head.val
        self.head = self.head.next
        self.count -= 1
        return val

    def top(self) -> int:
        return -1 if self.head is None else self.head.val

    def is_empty(self) -> bool:
        return self.head is None

    def size(self) -> int:
        return self.count
```

## Key Takeaways
- Head of the list = top of the stack; both push and pop touch only the head pointer.
- No capacity limit, but each element costs a node allocation and a pointer.
- Keep a `count` so `size()` is O(1) instead of walking the list.
- Guard `pop`/`top` against an empty list (null head).
