# Deletion of the head of LL

**Difficulty:** Easy  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Learn 1D LinkedList

## Problem
Given the head of a singly linked list, remove its first node and return the new head. If the list is empty, return `null`. (The linked LeetCode variant, "Delete Node in a Linked List", gives you a pointer to a non-tail node instead of the head and asks you to remove it; both are covered below.)

Input: `head = 3 -> 4 -> 5`
Output: `4 -> 5`

Input: `head = 9`
Output: `null`

## Approach 1: Delete the head (Optimal)
1. If `head` is `null`, return `null`.
2. Save `head.next` as the new head.
3. Release the old head (in C++ with `delete`; in Java/Python just drop the reference).
4. Return the saved pointer.

No traversal is required; deleting at the front is O(1).
- **Time:** O(1)
- **Space:** O(1)

## Approach 2: Delete a node given only that node (LeetCode 237)
You cannot reach the previous node from a singly linked node, so you cannot unlink it directly. Instead, copy the *next* node's value into the given node and unlink the next node:

```
node.val  = node.next.val
node.next = node.next.next
```

The node "becomes" its successor and the successor is removed. This is guaranteed to work because the problem promises the node is not the tail.
- **Time:** O(1)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int v) : val(v), next(nullptr) {} };
// (standard definition)

class Solution {
public:
    // Remove the first node and return the new head.
    ListNode* deleteHead(ListNode* head) {
        if (head == nullptr) return nullptr;
        ListNode* newHead = head->next;
        delete head;
        return newHead;
    }

    // LeetCode 237: delete a non-tail node when only that node is given.
    void deleteNode(ListNode* node) {
        ListNode* nxt = node->next;
        node->val = nxt->val;
        node->next = nxt->next;
        delete nxt;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int val) { this.val = val; } }
// (standard definition)

class Solution {
    // Remove the first node and return the new head.
    public ListNode deleteHead(ListNode head) {
        if (head == null) return null;
        ListNode newHead = head.next;
        head.next = null; // help the GC, optional
        return newHead;
    }

    // LeetCode 237: delete a non-tail node when only that node is given.
    public void deleteNode(ListNode node) {
        node.val = node.next.val;
        node.next = node.next.next;
    }
}
```

### Python
```python
from typing import Optional

# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
# (standard definition)

class Solution:
    # Remove the first node and return the new head.
    def deleteHead(self, head: Optional["ListNode"]) -> Optional["ListNode"]:
        if head is None:
            return None
        new_head = head.next
        head.next = None
        return new_head

    # LeetCode 237: delete a non-tail node when only that node is given.
    def deleteNode(self, node: "ListNode") -> None:
        node.val = node.next.val
        node.next = node.next.next
```

## Key Takeaways
- Deleting the head is O(1): move the head pointer one step and free the old node.
- Always guard against an empty list before dereferencing `head.next`.
- When you only have the node (no previous pointer), copy the successor's value and skip it.
- In C++ free the removed node to avoid leaks; in managed languages just drop references.
