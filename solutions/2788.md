# Post-order Traversal of Binary Tree using 2 stack

**Difficulty:** Easy  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Traversals

## Problem
Return the postorder traversal (Left, Right, Root) of a binary tree iteratively, using two stacks. Postorder is the hardest DFS order to do without recursion because a node must wait for both children; the two-stack technique sidesteps that by producing the reversed order first.

Input: `root = [1, 2, 3, 4, 5, null, 6]`
```
      1
     / \
    2   3
   / \   \
  4   5   6
```
Output: `[4, 5, 2, 6, 3, 1]`

## Approach 1: Recursive (for reference)
Recurse left, recurse right, record the node. Trivial to write but bound to the call stack depth.
- **Time:** O(n)
- **Space:** O(h) recursion stack

## Approach 2: Two stacks (optimal for this problem)
Key observation: postorder is Left, Right, Root. Read it backwards and you get Root, Right, Left, which is a preorder traversal in which the children are visited right-before-left. Iterative preorder is easy, so:

1. Push the root onto stack 1.
2. Pop a node from stack 1, push it onto stack 2, then push its **left** child and then its **right** child onto stack 1 (nulls skipped). Because left is pushed first, right pops first, giving Root, Right, Left.
3. When stack 1 is empty, stack 2 holds the nodes in Root, Right, Left order from bottom to top. Popping stack 2 reverses it into Left, Right, Root.

Each node passes through both stacks exactly once. The cost is that stack 2 eventually holds every node, so the extra space is O(n) rather than O(h).
- **Time:** O(n)
- **Space:** O(n) for the two stacks combined

## Approach 3: One stack
It is possible to get O(h) space by using a single stack plus a "last visited" pointer to decide whether a node's right subtree has already been emitted. That is the subject of the next problem in the sheet; the two-stack version is the one to reach for when you want something quick and obviously correct.
- **Time:** O(n)
- **Space:** O(h)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stack>
using namespace std;

// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition

class Solution {
public:
    vector<int> postorderTraversal(TreeNode* root) {
        vector<int> res;
        if (!root) return res;
        stack<TreeNode*> s1, s2;
        s1.push(root);
        while (!s1.empty()) {
            TreeNode* node = s1.top();
            s1.pop();
            s2.push(node);
            if (node->left)  s1.push(node->left);
            if (node->right) s1.push(node->right);   // right pops first -> Root,Right,Left
        }
        while (!s2.empty()) {                          // reversed -> Left,Right,Root
            res.push_back(s2.top()->val);
            s2.pop();
        }
        return res;
    }
};
```

### Java
```java
import java.util.*;

// class TreeNode { int val; TreeNode left, right; ... } — standard definition

class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        Deque<TreeNode> s1 = new ArrayDeque<>();
        Deque<TreeNode> s2 = new ArrayDeque<>();
        s1.push(root);
        while (!s1.isEmpty()) {
            TreeNode node = s1.pop();
            s2.push(node);
            if (node.left != null)  s1.push(node.left);
            if (node.right != null) s1.push(node.right);   // right pops first -> Root,Right,Left
        }
        while (!s2.isEmpty()) {                             // reversed -> Left,Right,Root
            res.add(s2.pop().val);
        }
        return res;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def postorderTraversal(self, root):
        res = []
        if root is None:
            return res
        s1, s2 = [root], []
        while s1:
            node = s1.pop()
            s2.append(node)
            if node.left:
                s1.append(node.left)
            if node.right:
                s1.append(node.right)    # right pops first -> Root,Right,Left
        while s2:                        # reversed -> Left,Right,Root
            res.append(s2.pop().val)
        return res
```

## Key Takeaways
- Reversed postorder is a "mirrored" preorder (Root, Right, Left). Generate that with one stack, reverse it with a second.
- The push order on stack 1 is left then right, the opposite of iterative preorder, so that right comes out first.
- In practice you can replace stack 2 with an output list that you reverse at the end; it is the same idea.
- This costs O(n) extra space; use the single-stack method when the height bound matters.
