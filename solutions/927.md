# Longest Repeating Character Replacement

**Difficulty:** Hard  ·  **Topic:** Sliding Window & Two Pointer Combined Problems › Medium Problems

## Problem
Given an uppercase string `s` and an integer `k`, you may change at most `k` characters to any other uppercase letter. Return the length of the longest substring that can be made to consist of a single repeated letter.

Input: `s = "AABABBA", k = 1`
Output: `4` (change the middle `A` to `B`, giving `"ABBB"`, or the `B` at index 2 to get `"AAAA"`)

## Approach 1: Brute Force
For every start `i`, extend `j` while keeping letter counts. A window is fixable if `length - maxCount <= k` (change everything that is not the most frequent letter). Track the best fixable length.

- **Time:** O(n² · 26) or O(n²) with an incremental max
- **Space:** O(26)

## Approach 2: Sliding Window with Max Frequency (Optimal)
Window `[l, r]` is valid when `(r - l + 1) - maxFreq <= k`, where `maxFreq` is the count of the most common letter inside the window.

1. Add `s[r]` to a 26-slot frequency array and update `maxFreq`.
2. If the window is invalid, drop `s[l]` and advance `l` (one step is enough, see below).
3. Update the answer with the current window length.

Why we never decrease `maxFreq`: the answer only improves when `maxFreq` grows, because the window length is bounded by `maxFreq + k`. Keeping a stale, possibly too-large `maxFreq` can only leave the window a bit larger than strictly valid, and that window can never be reported as a new best unless a genuinely larger `maxFreq` appears. So a single `if` shrink (window never shrinks in size) is correct and avoids rescanning 26 counts.

- **Time:** O(n)
- **Space:** O(26) = O(1)

## Code (Optimal)

### C++
```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    int characterReplacement(string s, int k) {
        int freq[26] = {0};
        int l = 0, maxFreq = 0, best = 0;
        for (int r = 0; r < (int)s.size(); ++r) {
            maxFreq = max(maxFreq, ++freq[s[r] - 'A']);
            if ((r - l + 1) - maxFreq > k) {
                freq[s[l] - 'A']--;
                l++;
            }
            best = max(best, r - l + 1);
        }
        return best;
    }
};
```

class Solution {
    public int characterReplacement(String s, int k) {
        int[] freq = new int[26];
        int l = 0, maxFreq = 0, best = 0;
        for (int r = 0; r < s.length(); r++) {

        }
        return best;
    }
}

### Python
```python
class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        freq = [0] * 26
        l = 0
        max_freq = 0
        best = 0
        for r, ch in enumerate(s):
            idx = ord(ch) - ord('A')
            freq[idx] += 1
            max_freq = max(max_freq, freq[idx])
            if (r - l + 1) - max_freq > k:
                freq[ord(s[l]) - ord('A')] -= 1
                l += 1
            best = max(best, r - l + 1)
        return best
```

## Key Takeaways
- Validity condition: `windowLen - maxFreq <= k`; the letters to change are the ones that are not the majority.
- `maxFreq` never needs to decrease, which lets the window size be monotone non-decreasing and the loop stay O(n).
- Edge cases: `k >= n` (answer n), `k = 0` (longest run of one letter).
