# Cycle Detection in Undirected Graph (bfs)

**Difficulty:** Hard  ·  **Topic:** Graphs [Concepts & Problems] › Problems on BFS/DFS

## Problem
Given an undirected graph with `V` vertices (`0..V-1`) as an adjacency list, determine whether it contains a cycle. The graph may be disconnected, so a cycle can hide in any component. Return `true` if any cycle exists.

```
Input:  V = 5, adj = [[1], [0,2,4], [1,3], [2,4], [1,3]]
Output: true          (cycle 1 → 2 → 3 → 4 → 1)

Input:  V = 4, adj = [[1], [0,2], [1,3], [2]]
Output: false         (a simple path, no cycle)
```

## Approach 1: The naive "visited node seen again" test, and why it is wrong
The obvious rule — "if BFS reaches an already-visited node, there is a cycle" — is wrong for undirected graphs. Every edge `u — v` is stored twice, once in `adj[u]` and once in `adj[v]`. So when you are standing on `v` (which you reached from `u`), you will look back at `u` and find it visited. That is not a cycle; it is the same edge seen from the other end.

Key observation: a genuine cycle is detected when you reach an already-visited node **through a different edge than the one you came in on**. In BFS on an undirected graph this becomes: while processing node `cur` whose parent is `par`, if a neighbour `nb` is already visited and `nb != par`, then `nb` was discovered by some other branch of the search, and there are two distinct paths from the BFS root to `nb` — joining them gives a cycle.
- **Time:** O(V + E), but wrong answers on every graph with an edge.
- **Space:** O(V)

## Approach 2: BFS carrying the parent (Optimal)
Store `(node, parent)` pairs in the queue. The parent of the BFS root is a sentinel like `-1` that never matches a real vertex.

Algorithm:
1. `visited[0..V-1] = false`.
2. For every start vertex `s` with `visited[s] == false` (needed because the graph may be disconnected):
   - Push `(s, -1)`, mark `visited[s] = true`.
   - While the queue is non-empty, pop `(cur, par)` and for each neighbour `nb`:
     - If `nb` is **not** visited → mark it and push `(nb, cur)`.
     - Else if `nb != par` → a cycle exists, return `true`.
3. If all components drain without a hit, return `false`.

Why this is correct in both directions:
- *No false positives.* The only way an undirected edge leads to an already-visited neighbour without a cycle is the immediate back-edge to the parent, which we explicitly exclude.
- *No false negatives.* If a cycle exists, consider the BFS that covers it. Not all of its edges can be tree edges (a tree on `k` nodes has exactly `k−1` edges), so at least one cycle edge `u — v` is a non-tree edge. When `u` is processed, `v` is already visited (BFS discovers all of a component before draining it) and `v` is not `u`'s parent, so the check fires.

Dry run on `V = 5, adj = [[1], [0,2,4], [1,3], [2,4], [1,3]]`, starting at 0:
- Push `(0,-1)`. Pop it: neighbour 1 unvisited → push `(1,0)`.
- Pop `(1,0)`: neighbour 0 is visited but equals the parent → ignore. Neighbour 2 unvisited → push `(2,1)`. Neighbour 4 unvisited → push `(4,1)`.
- Pop `(2,1)`: neighbour 1 == parent → ignore. Neighbour 3 unvisited → push `(3,2)`.
- Pop `(4,1)`: neighbour 1 == parent → ignore. Neighbour 3 is **already visited** and 3 ≠ parent 1 → **cycle found**, return `true`. Indeed 1-2-3-4-1 is a cycle.

A subtlety: if the graph can contain a **self-loop** `u — u`, the parent test would wrongly skip it, so add an explicit `if (nb == cur) return true`. With **parallel edges** (`u — v` listed twice), the second copy correctly reports a cycle only if you also track edge identity; the standard formulation assumes a simple graph.
- **Time:** O(V + E) — each vertex is enqueued once, each adjacency entry read once.
- **Space:** O(V) for `visited` and the queue.

## Approach 3: DFS with parent, and DSU
The DFS version carries the same `parent` argument and returns `true` the moment it meets a visited non-parent neighbour; it is shorter but recurses up to `V` deep. Disjoint Set Union gives a third route: process every edge once, and if the two endpoints are already in the same set, adding the edge closes a cycle. DSU is the natural pick when edges stream in and you must answer after each insertion.
- **Time:** O(V + E) for DFS; O(E·α(V)) for DSU
- **Space:** O(V)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    bool isCycle(int V, vector<vector<int>>& adj) {
        vector<int> visited(V, 0);
        for (int s = 0; s < V; s++) {
            if (!visited[s] && bfsHasCycle(s, adj, visited)) return true;
        }
        return false;
    }

private:
    bool bfsHasCycle(int src, vector<vector<int>>& adj, vector<int>& visited) {
        queue<pair<int,int>> q;      // {node, parent}
        q.push({src, -1});
        visited[src] = 1;
        while (!q.empty()) {
            auto [cur, par] = q.front(); q.pop();
            for (int nb : adj[cur]) {
                if (!visited[nb]) {
                    visited[nb] = 1;
                    q.push({nb, cur});
                } else if (nb != par) {
                    return true;     // reached a visited node via a second edge
                }
            }
        }
        return false;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public boolean isCycle(int V, List<List<Integer>> adj) {
        boolean[] visited = new boolean[V];
        for (int s = 0; s < V; s++) {
            if (!visited[s] && bfsHasCycle(s, adj, visited)) return true;
        }
        return false;
    }

    private boolean bfsHasCycle(int src, List<List<Integer>> adj, boolean[] visited) {
        Queue<int[]> q = new LinkedList<>();   // {node, parent}
        q.add(new int[]{src, -1});
        visited[src] = true;
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int node = cur[0], par = cur[1];
            for (int nb : adj.get(node)) {
                if (!visited[nb]) {
                    visited[nb] = true;
                    q.add(new int[]{nb, node});
                } else if (nb != par) {
                    return true;
                }
            }
        }
        return false;
    }
}
```

### Python
```python
from collections import deque
from typing import List

class Solution:
    def isCycle(self, V: int, adj: List[List[int]]) -> bool:
        visited = [False] * V
        for s in range(V):
            if visited[s]:
                continue
            q = deque([(s, -1)])        # (node, parent)
            visited[s] = True
            while q:
                node, par = q.popleft()
                for nb in adj[node]:
                    if not visited[nb]:
                        visited[nb] = True
                        q.append((nb, node))
                    elif nb != par:
                        return True
        return False
```

## Key Takeaways
- In an undirected graph every edge appears twice, so "neighbour already visited" alone is never proof of a cycle — you must exclude the parent.
- A cycle exists iff BFS finds a visited neighbour that is not the node it arrived from.
- Loop over all vertices: the cycle may live in a component you would otherwise never start from.
- Self-loops need an extra `nb == cur` check; the parent rule silently swallows them.
