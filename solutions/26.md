# Reverse Pairs

**Difficulty:** Hard  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Hard

## Problem
Given an integer array `nums`, count the number of *reverse pairs*: index pairs `(i, j)` with `i < j` and `nums[i] > 2 * nums[j]`.

Input: `nums = [1, 3, 2, 3, 1]`
Output: `2` (pairs (1,4): 3 > 2·1 and (3,4): 3 > 2·1)

## Approach 1: Brute Force
Test every `i < j` for `nums[i] > 2 * nums[j]`. Use 64-bit for the doubled value.
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Merge sort with a separate counting pass (Optimal)
This looks like Count Inversions, but the condition `a > 2b` is not the same as the merge comparison `a > b`, so the count cannot piggyback on the merge itself. Instead, do it as an extra linear pass right before merging.

1. Recursively process both halves; afterwards each half is sorted.
2. Counting pass: pointer `r` starts at the beginning of the right half. For each `l` in the left half (ascending), advance `r` while `left[l] > 2 * right[r]`. Since both halves are sorted, `r` never moves backward across different `l`, so the pass is linear. Add `r - (mid+1)` for each `l`.
3. Then do the normal merge.

- **Time:** O(n log n)
- **Space:** O(n) merge buffer

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    vector<int> tmp;

    int countPairs(vector<int>& a, int lo, int mid, int hi) {
        int cnt = 0, r = mid + 1;
        for (int l = lo; l <= mid; ++l) {
            while (r <= hi && (long long)a[l] > 2LL * a[r]) ++r;
            cnt += r - (mid + 1);
        }
        return cnt;
    }

    void mergeHalves(vector<int>& a, int lo, int mid, int hi) {
        int i = lo, j = mid + 1, k = lo;
        while (i <= mid && j <= hi) tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
        while (i <= mid) tmp[k++] = a[i++];
        while (j <= hi) tmp[k++] = a[j++];
        for (int t = lo; t <= hi; ++t) a[t] = tmp[t];
    }

    int solve(vector<int>& a, int lo, int hi) {
        if (lo >= hi) return 0;
        int mid = lo + (hi - lo) / 2;
        int cnt = solve(a, lo, mid) + solve(a, mid + 1, hi);
        cnt += countPairs(a, lo, mid, hi);
        mergeHalves(a, lo, mid, hi);
        return cnt;
    }
public:
    int reversePairs(vector<int>& nums) {
        tmp.assign(nums.size(), 0);
        return solve(nums, 0, (int)nums.size() - 1);
    }
};
```

### Java

class Solution {
    private int[] tmp;

    private int countPairs(int[] a, int lo, int mid, int hi) {
        int cnt = 0, r = mid + 1;
        for (int l = lo; l <= mid; l++) {
            while (r <= hi && (long) a[l] > 2L * a[r]) r++;
            cnt += r - (mid + 1);
        }
        return cnt;
    }

    private void mergeHalves(int[] a, int lo, int mid, int hi) {
        int i = lo, j = mid + 1, k = lo;
        while (i <= mid && j <= hi) tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
        while (i <= mid) tmp[k++] = a[i++];
        while (j <= hi) tmp[k++] = a[j++];
        for (int t = lo; t <= hi; t++) a[t] = tmp[t];
    }

    private int solve(int[] a, int lo, int hi) {
        if (lo >= hi) return 0;
        int mid = lo + (hi - lo) / 2;
        int cnt = solve(a, lo, mid) + solve(a, mid + 1, hi);
        cnt += countPairs(a, lo, mid, hi);
        mergeHalves(a, lo, mid, hi);
        return cnt;
    }

    public int reversePairs(int[] nums) {
        tmp = new int[nums.length];
        return solve(nums, 0, nums.length - 1);
    }
}

### Python
```python
from typing import List

class Solution:
    def reversePairs(self, nums: List[int]) -> int:
        def solve(a: List[int]):
            if len(a) <= 1:
                return a, 0
            mid = len(a) // 2
            left, lc = solve(a[:mid])
            right, rc = solve(a[mid:])

            cnt = 0
            r = 0
            for x in left:
                while r < len(right) and x > 2 * right[r]:
                    r += 1
                cnt += r

            merged = []
            i = j = 0
            while i < len(left) and j < len(right):
                if left[i] <= right[j]:
                    merged.append(left[i]); i += 1
                else:
                    merged.append(right[j]); j += 1
            merged.extend(left[i:])
            merged.extend(right[j:])
            return merged, lc + rc + cnt

        _, total = solve(list(nums))
        return total
```

## Key Takeaways
- When the pair condition differs from the merge ordering, count in a separate two-pointer pass over the two sorted halves, then merge normally.
- The counting pointer `r` is monotone across the left half, so the pass costs O(n), keeping the total at O(n log n).
- `2 * nums[j]` can overflow 32-bit (values go to ±2³¹); compute it in 64-bit.
