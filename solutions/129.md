# Check if two trees are identical or not

**Difficulty:** Medium  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Medium Problems

## Problem
Given the roots of two binary trees `p` and `q`, decide whether they are identical: same shape and the same value at every corresponding position. Return `true` or `false`.

Input: p = [1,2,3], q = [1,2,3]
Output: true

Input: p = [1,2], q = [1,null,2]
Output: false  (same values, different shape)

## Approach 1: Compare Traversal Sequences
Serialize each tree with a traversal that records nulls (for example pre-order with a marker for missing children) and compare the two sequences. Without the null markers a single traversal is not enough to pin down the shape, which is why the second example above would wrongly look equal under a plain in-order.

- **Time:** O(n + m)
- **Space:** O(n + m) for the two sequences

## Approach 2: Simultaneous Recursion (Optimal)
Walk both trees in lockstep. At each pair of nodes:

1. If both are null, this part matches — return true.
2. If exactly one is null, shapes differ — return false.
3. If the values differ — return false.
4. Otherwise recurse on the two left children and the two right children and require both to match.

The recursion stops at the first mismatch, so it never does more work than needed.
- **Time:** O(min(n, m))
- **Space:** O(h) recursion stack

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; ... } — standard definition
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        if (!p && !q) return true;
        if (!p || !q) return false;
        if (p->val != q->val) return false;
        return isSameTree(p->left, q->left) && isSameTree(p->right, q->right);
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
class Solution {
    public boolean isSameTree(TreeNode p, TreeNode q) {
        if (p == null && q == null) return true;
        if (p == null || q == null) return false;
        if (p.val != q.val) return false;
        return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
class Solution:
    def isSameTree(self, p, q) -> bool:
        if p is None and q is None:
            return True
        if p is None or q is None:
            return False
        if p.val != q.val:
            return False
        return self.isSameTree(p.left, q.left) and self.isSameTree(p.right, q.right)
```

## Key Takeaways
- Handle the two null cases first: both null is a match, one null is a mismatch.
- Traversing two trees together is the building block for symmetric-tree and subtree-of-another-tree problems.
- If you ever compare by traversal output, include null markers or the shape information is lost.
