## Problem
This item introduces the binary heap: what it is, how it is stored in an array, the two core operations (sift up and sift down), how to build one in linear time, and how it backs the priority queue in each language's standard library. There is no single input/output; the goal is to be able to implement and reason about heaps before solving the problems that follow.

Example of the heap idea: inserting `5, 3, 8, 1` into a min heap and repeatedly popping yields `1, 3, 5, 8`.

## Approach: What a Heap Is
A **binary heap** is a complete binary tree (every level full except possibly the last, which is filled left to right) that satisfies the heap property:

- **Min heap:** every node is less than or equal to its children, so the root is the minimum.
- **Max heap:** every node is greater than or equal to its children, so the root is the maximum.

Because the tree is complete, it can be stored in a plain array without pointers. For 0-indexed storage:

- parent of `i` is `(i - 1) / 2`
- left child of `i` is `2i + 1`, right child is `2i + 2`

The height is `floor(log2 n)`, which is what makes the operations logarithmic.

### Core operations (min heap shown)

**Insert (sift up):** append the new value at the end, then swap it with its parent while it is smaller than the parent.

**Extract min (sift down):** move the last element to the root, shrink the size, then repeatedly swap the root with its smaller child while a child is smaller.

```cpp
void siftUp(vector<int>& h, int i) {
    while (i > 0 && h[(i - 1) / 2] > h[i]) {
        swap(h[(i - 1) / 2], h[i]);
        i = (i - 1) / 2;
    }
}

void siftDown(vector<int>& h, int i, int n) {
    while (true) {
        int l = 2 * i + 1, r = 2 * i + 2, smallest = i;
        if (l < n && h[l] < h[smallest]) smallest = l;
        if (r < n && h[r] < h[smallest]) smallest = r;
        if (smallest == i) return;
        swap(h[i], h[smallest]);
        i = smallest;
    }
}
```

**Peek:** return `h[0]` in O(1).

**Build heap (heapify):** call `siftDown` on every non-leaf index from `n/2 - 1` down to `0`. Although each call may cost O(log n), most nodes are near the bottom, and the sum telescopes to O(n). Inserting one by one instead costs O(n log n).

**Heap sort:** build a max heap, then repeatedly swap the root with the last element and sift down on the reduced size. O(n log n) time, O(1) extra space, not stable.

### Complexity summary
- **Time:** insert O(log n), extract O(log n), peek O(1), build O(n)
- **Space:** O(n) for the array, O(1) auxiliary

### Priority queues in the standard libraries
- **C++:** `priority_queue<int>` is a max heap; `priority_queue<int, vector<int>, greater<int>>` is a min heap. Custom comparators go in the third template argument.
- **Java:** `PriorityQueue<Integer>` is a min heap; pass `Collections.reverseOrder()` or a lambda comparator for other orders.
- **Python:** `heapq` provides min-heap functions on a list (`heappush`, `heappop`, `heapify`); negate values or push tuples for max-heap behaviour.

```python
import heapq
h = []
for x in [5, 3, 8, 1]:
    heapq.heappush(h, x)
print([heapq.heappop(h) for _ in range(len(h))])   # [1, 3, 5, 8]
```

### Where heaps show up
- Top-k / k-th largest: keep a min heap of size k.
- Merge k sorted lists: heap keyed by each list's head.
- Running median: a max heap for the lower half and a min heap for the upper half.
- Dijkstra and Prim: extract the cheapest frontier edge.
- Task scheduling and interval problems ordered by finishing time.

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stdexcept>
using namespace std;

class MinHeap {
    vector<int> h;
    void siftUp(int i) {
        while (i > 0 && h[(i - 1) / 2] > h[i]) {
            swap(h[(i - 1) / 2], h[i]);
            i = (i - 1) / 2;
        }
    }
    void siftDown(int i) {
        int n = h.size();
        while (true) {
            int l = 2 * i + 1, r = 2 * i + 2, s = i;
            if (l < n && h[l] < h[s]) s = l;
            if (r < n && h[r] < h[s]) s = r;
            if (s == i) return;
            swap(h[i], h[s]);
            i = s;
        }
    }
public:
    void push(int x) { h.push_back(x); siftUp(h.size() - 1); }
    int top() const { if (h.empty()) throw runtime_error("empty"); return h[0]; }
    int pop() {
        int v = top();
        h[0] = h.back(); h.pop_back();
        if (!h.empty()) siftDown(0);
        return v;
    }
    bool empty() const { return h.empty(); }
    int size() const { return h.size(); }
};
```

### Java
```java
import java.util.ArrayList;
import java.util.List;

class MinHeap {
    private final List<Integer> h = new ArrayList<>();

    private void swap(int i, int j) { int t = h.get(i); h.set(i, h.get(j)); h.set(j, t); }

    private void siftUp(int i) {
        while (i > 0 && h.get((i - 1) / 2) > h.get(i)) {
            swap((i - 1) / 2, i);
            i = (i - 1) / 2;
        }
    }

    private void siftDown(int i) {
        int n = h.size();
        while (true) {
            int l = 2 * i + 1, r = 2 * i + 2, s = i;
            if (l < n && h.get(l) < h.get(s)) s = l;
            if (r < n && h.get(r) < h.get(s)) s = r;
            if (s == i) return;
            swap(i, s);
            i = s;
        }
    }

    public void push(int x) { h.add(x); siftUp(h.size() - 1); }
    public int top() { if (h.isEmpty()) throw new RuntimeException("empty"); return h.get(0); }
    public int pop() {
        int v = top();
        int last = h.remove(h.size() - 1);
        if (!h.isEmpty()) { h.set(0, last); siftDown(0); }
        return v;
    }
    public boolean isEmpty() { return h.isEmpty(); }
    public int size() { return h.size(); }
}
```

### Python
```python
class MinHeap:
    def __init__(self):
        self.h = []

    def _sift_up(self, i):
        while i > 0 and self.h[(i - 1) // 2] > self.h[i]:
            p = (i - 1) // 2
            self.h[p], self.h[i] = self.h[i], self.h[p]
            i = p

    def _sift_down(self, i):
        n = len(self.h)
        while True:
            l, r, s = 2 * i + 1, 2 * i + 2, i
            if l < n and self.h[l] < self.h[s]:
                s = l
            if r < n and self.h[r] < self.h[s]:
                s = r
            if s == i:
                return
            self.h[i], self.h[s] = self.h[s], self.h[i]
            i = s

    def push(self, x):
        self.h.append(x)
        self._sift_up(len(self.h) - 1)

    def top(self):
        if not self.h:
            raise IndexError("empty heap")
        return self.h[0]

    def pop(self):
        v = self.top()
        last = self.h.pop()
        if self.h:
            self.h[0] = last
            self._sift_down(0)
        return v

    def __len__(self):
        return len(self.h)
```

## Key Takeaways
- A heap is a complete binary tree stored in an array; parent/child indices are computed arithmetically, no pointers needed.
- Insert = append + sift up; extract = swap root with last + sift down; both are O(log n).
- Building a heap from an array bottom-up is O(n), not O(n log n).
- A heap gives fast access to the extreme element only; it is not a sorted structure and does not support fast arbitrary search.
