# String to Integer (atoi)

**Difficulty:** Medium  ·  **Topic:** Strings [Basic and Medium] › Medium String Problems

## Problem
Implement `atoi`: parse a string into a 32-bit signed integer using these rules, in order:
1. Skip leading spaces.
2. An optional `+` or `-` sets the sign.
3. Read consecutive digits; stop at the first non-digit (or end of string). Leading zeros are fine.
4. If no digits were read, the result is `0`.
5. Clamp the result into `[-2^31, 2^31 - 1]`.

Input: `s = "   -042"`
Output: `-42`

Input: `s = "1337c0d3"`
Output: `1337`

Input: `s = "-91283472332"`
Output: `-2147483648`  (clamped)

## Approach 1: Parse into a wide integer, then clamp
Parse the digits into a 64-bit integer (or arbitrary precision in Python), applying the sign at the end, then clamp. Simple, but a 64-bit accumulator can still overflow if the digit run is very long, so you would need an extra early-exit check anyway.
- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Overflow check before each multiply (Optimal)
Accumulate the magnitude as a 32-bit int and, before doing `result = result * 10 + d`, check whether that would exceed `INT_MAX`:
- if `result > INT_MAX / 10`, it overflows for any digit;
- if `result == INT_MAX / 10` and `d > 7`, it overflows (`INT_MAX` ends in 7).

On overflow return `INT_MAX` for positive sign or `INT_MIN` for negative. Because `|INT_MIN| = INT_MAX + 1`, the check "would exceed INT_MAX" is slightly conservative for negatives, but since we return `INT_MIN` in that case the clamped answer is still correct.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <string>
#include <climits>
using namespace std;

class Solution {
public:
    int myAtoi(string s) {
        int i = 0, n = s.size();
        while (i < n && s[i] == ' ') i++;

        int sign = 1;
        if (i < n && (s[i] == '+' || s[i] == '-')) {
            if (s[i] == '-') sign = -1;
            i++;
        }

        int result = 0;
        while (i < n && s[i] >= '0' && s[i] <= '9') {
            int d = s[i] - '0';
            if (result > INT_MAX / 10 || (result == INT_MAX / 10 && d > 7)) {
                return sign == 1 ? INT_MAX : INT_MIN;
            }
            result = result * 10 + d;
            i++;
        }
        return sign * result;
    }
};
```

### Java
```java
class Solution {
    public int myAtoi(String s) {
        int i = 0, n = s.length();
        while (i < n && s.charAt(i) == ' ') i++;

        int sign = 1;
        if (i < n && (s.charAt(i) == '+' || s.charAt(i) == '-')) {
            if (s.charAt(i) == '-') sign = -1;
            i++;
        }

        int result = 0;
        while (i < n && Character.isDigit(s.charAt(i))) {
            int d = s.charAt(i) - '0';
            if (result > Integer.MAX_VALUE / 10
                    || (result == Integer.MAX_VALUE / 10 && d > 7)) {
                return sign == 1 ? Integer.MAX_VALUE : Integer.MIN_VALUE;
            }
            result = result * 10 + d;
            i++;
        }
        return sign * result;
    }
}
```

### Python
```python
class Solution:
    def myAtoi(self, s: str) -> int:
        INT_MAX, INT_MIN = 2**31 - 1, -2**31
        i, n = 0, len(s)
        while i < n and s[i] == ' ':
            i += 1

        sign = 1
        if i < n and s[i] in '+-':
            if s[i] == '-':
                sign = -1
            i += 1

        result = 0
        while i < n and s[i].isdigit():
            d = ord(s[i]) - ord('0')
            if result > INT_MAX // 10 or (result == INT_MAX // 10 and d > 7):
                return INT_MAX if sign == 1 else INT_MIN
            result = result * 10 + d
            i += 1
        return sign * result
```

## Key Takeaways
- Follow the spec order strictly: spaces, then one sign, then digits, then stop.
- Check for overflow *before* multiplying, using `INT_MAX / 10` and the last digit `7`.
- Only whitespace that is a literal space is skipped; tabs and newlines stop the parse.
- Edge cases: `"+-12"` gives 0, `"  "` gives 0, `"00000123"` gives 123, `"words 123"` gives 0.
