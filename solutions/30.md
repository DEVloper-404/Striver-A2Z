# Leaders in an Array

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Medium

## Problem
An element of an array is a *leader* if it is strictly greater than every element to its right. The last element is always a leader because nothing lies to its right. Return all leaders in the order they appear in the array.

```
Input:  nums = [10, 22, 12, 3, 0, 6]
Output: [22, 12, 6]
```

## Approach 1: Brute Force
For each index `i`, scan every index `j > i`. If some `nums[j] >= nums[i]`, then `nums[i]` is not a leader; otherwise add it to the answer.
- **Time:** O(n²)
- **Space:** O(1) extra (plus the output)

## Approach 2: Suffix Maximum Scan (Optimal)
An element is a leader exactly when it is larger than the maximum of everything after it. If we walk from right to left carrying `maxRight` (the largest value seen so far on the right), each element can be classified in O(1): it is a leader if `nums[i] > maxRight`, and then it becomes the new `maxRight`. The scan produces leaders in reverse order, so reverse the collected list at the end.
- **Time:** O(n)
- **Space:** O(1) extra (plus the output)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> leaders(const vector<int>& nums) {
        vector<int> res;
        int maxRight = INT_MIN;
        for (int i = (int)nums.size() - 1; i >= 0; --i) {
            if (nums[i] > maxRight) {
                res.push_back(nums[i]);
                maxRight = nums[i];
            }
        }
        reverse(res.begin(), res.end());
        return res;
    }
};
```

### Java
```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {
    public List<Integer> leaders(int[] nums) {
        List<Integer> res = new ArrayList<>();
        int maxRight = Integer.MIN_VALUE;
        for (int i = nums.length - 1; i >= 0; i--) {
            if (nums[i] > maxRight) {
                res.add(nums[i]);
                maxRight = nums[i];
            }
        }
        Collections.reverse(res);
        return res;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def leaders(self, nums: List[int]) -> List[int]:
        res = []
        max_right = float("-inf")
        for x in reversed(nums):
            if x > max_right:
                res.append(x)
                max_right = x
        res.reverse()
        return res
```

## Key Takeaways
- "Compare with everything to the right" is a suffix-maximum problem; sweep from the right and the comparison becomes O(1).
- Use strict `>` so duplicates of the current maximum are not counted as leaders (some problem statements use `>=`; read carefully).
- Initialise `maxRight` to negative infinity so the last element is always picked up.
- Reverse the result at the end to restore original order.
