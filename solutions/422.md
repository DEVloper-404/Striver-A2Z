# Pattern 9

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a diamond of stars: a centered pyramid of `n` rows followed immediately by an inverted pyramid of `n` rows, for `2n` rows in total.

Input: `n = 5`
Output:
```
    *
   ***
  *****
 *******
*********
*********
 *******
  *****
   ***
    *
```

## Approach
A diamond is Pattern 7 stacked on top of Pattern 8. Rather than inventing a new formula, reuse both halves.

1. Loop `i` from `0` to `n-1`: print `n-i-1` spaces then `2i+1` stars (upper half).
2. Loop `i` from `0` to `n-1`: print `i` spaces then `2(n-i)-1` stars (lower half).

The widest row appears twice (once as the end of the top half and once as the start of the bottom half), which is why the diamond has an even number of rows. If a problem wants a single middle row, run the second loop from `i = 1`.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern9(int n) {
    // upper half
    for (int i = 0; i < n; i++) {
        for (int s = 0; s < n - i - 1; s++) cout << " ";
        for (int j = 0; j < 2 * i + 1; j++) cout << "*";
        cout << "\n";
    }
    // lower half
    for (int i = 0; i < n; i++) {
        for (int s = 0; s < i; s++) cout << " ";
        for (int j = 0; j < 2 * (n - i) - 1; j++) cout << "*";
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern9 {
    public static void pattern9(int n) {
        for (int i = 0; i < n; i++) {
            StringBuilder row = new StringBuilder();
            for (int s = 0; s < n - i - 1; s++) row.append(' ');
            for (int j = 0; j < 2 * i + 1; j++) row.append('*');
            System.out.println(row);
        }
        for (int i = 0; i < n; i++) {
            StringBuilder row = new StringBuilder();
            for (int s = 0; s < i; s++) row.append(' ');
            for (int j = 0; j < 2 * (n - i) - 1; j++) row.append('*');
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern9(n: int) -> None:
    for i in range(n):
        print(" " * (n - i - 1) + "*" * (2 * i + 1))
    for i in range(n):
        print(" " * i + "*" * (2 * (n - i) - 1))
```

## Key Takeaways
- Composite shapes are built by sequencing simpler shapes, not by finding one clever formula.
- Watch whether the middle row should be duplicated; this sheet's version prints it twice.
- Sequential loops (not nested) keep the total work at O(n²).
