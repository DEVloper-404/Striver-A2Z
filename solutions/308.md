# Longest common subsequence

**Difficulty:** Hard  ·  **Topic:** Dynamic Programming [Patterns and Problems] › DP on Strings

## Problem
Given two strings `s1` and `s2`, return the length of their longest common subsequence. A subsequence keeps the relative order of characters but may drop any number of them; it does not have to be contiguous.

```
Input:  s1 = "abcde", s2 = "ace"
Output: 3
Explanation: "ace" is a subsequence of both.

Input:  s1 = "abc", s2 = "def"
Output: 0
```

## Approach 1: Brute Force (generate all subsequences)
Enumerate all 2^n subsequences of `s1`, check each against `s2`, and keep the longest that matches. Checking membership costs O(m), so this is hopeless for anything but toy inputs — but it does confirm the answer is well defined.

- **Time:** O(2^n · m)
- **Space:** O(n)

## Approach 2: Recursion on two indices

**The key observation.** Compare the *last* characters of the two prefixes we are considering. Let `f(i, j)` be the LCS length of `s1[0..i]` and `s2[0..j]`.

- **If `s1[i] == s2[j]`:** this character can be matched, and it is always safe to match it. Any LCS of the two prefixes can be rewritten to end with this pair without getting shorter, so we take it: `f(i, j) = 1 + f(i-1, j-1)`. There is no need to also try skipping it.
- **If `s1[i] != s2[j]`:** the two characters cannot both be the last matched character, so at least one of them is unused in the LCS. Try dropping each and take the better: `f(i, j) = max(f(i-1, j), f(i, j-1))`.

Base case: if either index goes negative, one string is empty and the LCS is 0.

- **Time:** O(2^(n+m)) without caching
- **Space:** O(n + m)

## Approach 3: Memoization / Tabulation with a shifted index

Negative indices are awkward, so shift by one: let `dp[i][j]` be the LCS of the first `i` characters of `s1` and the first `j` characters of `s2`, with `i, j` running from `0` to `n`, `m`. Then row/column 0 mean "empty string" and are all zeros — the base case becomes free.

```
dp[i][j] = dp[i-1][j-1] + 1                     if s1[i-1] == s2[j-1]
dp[i][j] = max(dp[i-1][j], dp[i][j-1])          otherwise
```

Fill the table row by row, `i` from 1 to n, `j` from 1 to m. The answer is `dp[n][m]`.

**Space optimisation.** Every cell reads only the previous row and the current row's left neighbour, so two rows of length `m+1` are enough. (A single row plus one saved diagonal value also works.)

**Dry run on s1 = "abcde", s2 = "ace".** Columns are `""`, `a`, `c`, `e`.

|     | "" | a | c | e |
|-----|----|---|---|---|
| ""  | 0 | 0 | 0 | 0 |
| a   | 0 | **1** | 1 | 1 |
| b   | 0 | 1 | 1 | 1 |
| c   | 0 | 1 | **2** | 2 |
| d   | 0 | 1 | 2 | 2 |
| e   | 0 | 1 | 2 | **3** |

The three bold diagonal bumps are the matches `a`, `c`, `e`. `dp[5][3] = 3`.

- **Time:** O(n · m)
- **Space:** O(m) with two rolling rows (O(n·m) if you keep the full table for reconstruction)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int longestCommonSubsequence(string s1, string s2) {
        int n = s1.size(), m = s2.size();
        vector<int> prev(m + 1, 0), cur(m + 1, 0);

        for (int i = 1; i <= n; i++) {
            cur[0] = 0;                                  // empty s2 prefix
            for (int j = 1; j <= m; j++) {
                if (s1[i - 1] == s2[j - 1])
                    cur[j] = 1 + prev[j - 1];            // match: consume both
                else
                    cur[j] = max(prev[j], cur[j - 1]);   // drop one side
            }
            prev = cur;
        }
        return prev[m];
    }
};
```

### Java
```java
class Solution {
    public int longestCommonSubsequence(String s1, String s2) {
        int n = s1.length(), m = s2.length();
        int[] prev = new int[m + 1];
        int[] cur = new int[m + 1];

        for (int i = 1; i <= n; i++) {
            cur[0] = 0;
            for (int j = 1; j <= m; j++) {
                if (s1.charAt(i - 1) == s2.charAt(j - 1))
                    cur[j] = 1 + prev[j - 1];
                else
                    cur[j] = Math.max(prev[j], cur[j - 1]);
            }
            int[] tmp = prev; prev = cur; cur = tmp;
        }
        return prev[m];
    }
}
```

### Python
```python
class Solution:
    def longestCommonSubsequence(self, s1, s2):
        n, m = len(s1), len(s2)
        prev = [0] * (m + 1)

        for i in range(1, n + 1):
            cur = [0] * (m + 1)
            for j in range(1, m + 1):
                if s1[i - 1] == s2[j - 1]:
                    cur[j] = 1 + prev[j - 1]
                else:
                    cur[j] = max(prev[j], cur[j - 1])
            prev = cur

        return prev[m]
```

## Key Takeaways
- Matching characters greedily on the diagonal is safe — an exchange argument shows you never lose by taking an equal pair.
- The 1-based shift turns the base case into a free zero row and column and removes all negative-index handling.
- Two rolling rows give O(m) space, but keep the full table if you need to *print* the LCS (see the "Print LCS" problem).
- This recurrence is the backbone of a whole family: longest palindromic subsequence, min insertions/deletions, and shortest common supersequence all reduce to it.
