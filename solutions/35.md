# Rotate matrix by 90 degrees

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Medium

## Problem
Given an `n x n` square matrix, rotate it 90 degrees clockwise in place. After rotation, the first row of the original becomes the last column, the second row becomes the second-last column, and so on. Allocating a second matrix is the easy way; the goal is to do it with O(1) extra space.

```
Input:  [[1, 2, 3],
         [4, 5, 6],
         [7, 8, 9]]
Output: [[7, 4, 1],
         [8, 5, 2],
         [9, 6, 3]]
```

## Approach 1: Extra Matrix
Notice where each element lands: the cell at `(i, j)` moves to `(j, n-1-i)`. Fill a fresh matrix using that formula and copy it back.
- **Time:** O(n²)
- **Space:** O(n²)

## Approach 2: Transpose + Reverse Rows (Optimal)
Break the rotation into two simple in-place steps:
1. **Transpose:** swap `matrix[i][j]` with `matrix[j][i]` for all `i < j`. Rows become columns.
2. **Reverse each row.** A transpose puts the first original row into the first column top-to-bottom, but a clockwise rotation needs it in the *last* column; reversing each row flips the columns left-to-right and fixes that.

(For an anticlockwise rotation, transpose and then reverse each *column* instead.)
- **Time:** O(n²)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = (int)matrix.size();
        // 1. transpose
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j)
                swap(matrix[i][j], matrix[j][i]);
        // 2. reverse each row
        for (auto& row : matrix)
            reverse(row.begin(), row.end());
    }
};
```

### Java
```java
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int t = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = t;
            }
        }
        for (int[] row : matrix) {
            int lo = 0, hi = n - 1;
            while (lo < hi) {
                int t = row[lo]; row[lo] = row[hi]; row[hi] = t;
                lo++; hi--;
            }
        }
    }
}
```

### Python
```python
from typing import List

class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        for row in matrix:
            row.reverse()
```

## Key Takeaways
- Clockwise 90° = transpose, then reverse each row. Anticlockwise = transpose, then reverse each column.
- In the transpose loop, iterate only `j > i`; touching every pair twice would undo the swap.
- The mapping `(i, j) -> (j, n-1-i)` is worth memorising for the extra-space version and for verifying the result.
- Only square matrices can be rotated in place this way; a rectangular one changes shape.
