# Palindrome partitioning

**Difficulty:** Hard  ·  **Topic:** Recursion [PatternWise] › Trying out all Combos / Hard

## Problem
Given a string `s`, split it into pieces so that every piece is a palindrome. Return every such partition (order of partitions does not matter, but the pieces inside a partition must appear in the original left-to-right order).

Input: `s = "aab"`
Output: `[["a","a","b"], ["aa","b"]]`

## Approach 1: Generate all cuts, then filter
There are `n-1` gaps between characters and each gap either gets a cut or not, so there are `2^(n-1)` ways to split the string. Generate every split, then check whether all of its pieces are palindromes and keep the ones that pass.

This works but does a lot of wasted work: a split whose very first piece is not a palindrome is still fully built before it is thrown away.
- **Time:** O(2^n · n) to enumerate and verify every split
- **Space:** O(n) recursion depth (plus output)

## Approach 2: Backtracking with early pruning (Optimal)
Walk the string from a start index. For every end index `i >= start`, look at the substring `s[start..i]`. If it is a palindrome, push it onto the current path and recurse from `i + 1`; if it is not, skip it. When `start` reaches `n`, the path is a complete valid partition, so record it.

Because we only ever extend the path with palindromic pieces, we never explore a branch that is already doomed. Adding an `isPal` helper that compares characters from both ends is enough; memoising palindromes in a 2-D table is an optional micro-optimisation.
- **Time:** O(2^n · n) in the worst case (e.g. `"aaaa"` where every split is valid), but much faster in practice due to pruning
- **Space:** O(n) recursion depth and current path

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
    bool isPal(const string& s, int l, int r) {
        while (l < r) if (s[l++] != s[r--]) return false;
        return true;
    }
    void go(int start, const string& s, vector<string>& path, vector<vector<string>>& out) {
        if (start == (int)s.size()) { out.push_back(path); return; }
        for (int i = start; i < (int)s.size(); ++i) {
            if (isPal(s, start, i)) {
                path.push_back(s.substr(start, i - start + 1));
                go(i + 1, s, path, out);
                path.pop_back();
            }
        }
    }
public:
    vector<vector<string>> partition(string s) {
        vector<vector<string>> out;
        vector<string> path;
        go(0, s, path, out);
        return out;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public List<List<String>> partition(String s) {
        List<List<String>> out = new ArrayList<>();
        go(0, s, new ArrayList<>(), out);
        return out;
    }

    private void go(int start, String s, List<String> path, List<List<String>> out) {
        if (start == s.length()) { out.add(new ArrayList<>(path)); return; }
        for (int i = start; i < s.length(); i++) {
            if (isPal(s, start, i)) {
                path.add(s.substring(start, i + 1));
                go(i + 1, s, path, out);
                path.remove(path.size() - 1);
            }
        }
    }

    private boolean isPal(String s, int l, int r) {
        while (l < r) if (s.charAt(l++) != s.charAt(r--)) return false;
        return true;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        out, path, n = [], [], len(s)

        def is_pal(l: int, r: int) -> bool:
            while l < r:
                if s[l] != s[r]:
                    return False
                l += 1
                r -= 1
            return True

        def go(start: int) -> None:
            if start == n:
                out.append(path[:])
                return
            for i in range(start, n):
                if is_pal(start, i):
                    path.append(s[start:i + 1])
                    go(i + 1)
                    path.pop()

        go(0)
        return out
```

## Key Takeaways
- Classic "choose where the next piece ends" backtracking: the loop variable is the end of the current piece, the recursion moves the start.
- Prune before recursing: only extend the path with a palindromic piece.
- A single character is always a palindrome, so every string has at least one partition and the recursion always terminates.
- The exponential worst case is unavoidable because the output itself can be exponential.
