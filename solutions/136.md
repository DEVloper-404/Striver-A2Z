# Pre, Post, Inorder in one traversal

**Difficulty:** Easy  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Traversals

## Problem
Given the root of a binary tree, produce all three depth-first orders, preorder, inorder and postorder, but walk the tree only once instead of running three separate traversals. Return the three lists.

Input: tree `1 -> (2 -> (4, 5), 3)`
```
      1
     / \
    2   3
   / \
  4   5
```
Output:
Preorder `[1, 2, 4, 5, 3]`, Inorder `[4, 2, 5, 1, 3]`, Postorder `[4, 5, 2, 3, 1]`

## Approach 1: Three separate traversals
Run a recursive preorder, then a recursive inorder, then a recursive postorder, each collecting into its own list. Correct and easy, but the tree is walked three times, which is exactly what the problem asks you to avoid.
- **Time:** O(3n) = O(n)
- **Space:** O(h) recursion stack per traversal

## Approach 2: Optimal (one stack, node paired with a visit counter)
Key observation: each node is "touched" exactly three times during a DFS: once when first reached (that is its preorder moment), once when coming back from its left subtree (inorder moment), and once when coming back from its right subtree (postorder moment). If we track which touch a node is on, a single pass can fill all three lists.

Keep a stack of `(node, state)` pairs where `state` is 1, 2 or 3. Push `(root, 1)`. Then loop while the stack is not empty, look at the top pair:

1. `state == 1`: record `node` in preorder, bump the state to 2, and if a left child exists push `(left, 1)`.
2. `state == 2`: record `node` in inorder, bump the state to 3, and if a right child exists push `(right, 1)`.
3. `state == 3`: record `node` in postorder and pop it; this node is finished.

Because the state is stored with the node, a node returns to the top of the stack after its subtree is fully processed and continues where it left off. Every node is pushed once and popped once, and each state transition is O(1).

- **Time:** O(n) — every node goes through exactly three constant-time steps
- **Space:** O(h) for the stack, plus O(n) for the three output lists

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stack>
#include <utility>
using namespace std;

// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition

vector<vector<int>> allTraversals(TreeNode* root) {
    vector<int> pre, in, post;
    if (!root) return {pre, in, post};

    stack<pair<TreeNode*, int>> st;
    st.push({root, 1});

    while (!st.empty()) {
        auto& top = st.top();
        TreeNode* node = top.first;

        if (top.second == 1) {
            pre.push_back(node->val);
            top.second = 2;
            if (node->left) st.push({node->left, 1});
        } else if (top.second == 2) {
            in.push_back(node->val);
            top.second = 3;
            if (node->right) st.push({node->right, 1});
        } else {
            post.push_back(node->val);
            st.pop();
        }
    }
    return {pre, in, post};
}
```

### Java
```java
import java.util.*;

// class TreeNode { int val; TreeNode left, right; ... } — standard definition

class Solution {
    public List<List<Integer>> allTraversals(TreeNode root) {
        List<Integer> pre = new ArrayList<>();
        List<Integer> in = new ArrayList<>();
        List<Integer> post = new ArrayList<>();
        if (root == null) return Arrays.asList(pre, in, post);

        // int[] holds the visit count for the node at the same stack depth
        Deque<TreeNode> nodes = new ArrayDeque<>();
        Deque<Integer> states = new ArrayDeque<>();
        nodes.push(root);
        states.push(1);

        while (!nodes.isEmpty()) {
            TreeNode node = nodes.peek();
            int state = states.pop();

            if (state == 1) {
                pre.add(node.val);
                states.push(2);
                if (node.left != null) { nodes.push(node.left); states.push(1); }
            } else if (state == 2) {
                in.add(node.val);
                states.push(3);
                if (node.right != null) { nodes.push(node.right); states.push(1); }
            } else {
                post.add(node.val);
                nodes.pop();
            }
        }
        return Arrays.asList(pre, in, post);
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

def all_traversals(root):
    pre, ino, post = [], [], []
    if root is None:
        return pre, ino, post

    stack = [[root, 1]]          # [node, state]
    while stack:
        node, state = stack[-1]
        if state == 1:
            pre.append(node.val)
            stack[-1][1] = 2
            if node.left:
                stack.append([node.left, 1])
        elif state == 2:
            ino.append(node.val)
            stack[-1][1] = 3
            if node.right:
                stack.append([node.right, 1])
        else:
            post.append(node.val)
            stack.pop()
    return pre, ino, post
```

## Key Takeaways
- A DFS visits each node three times: on arrival (preorder), between the children (inorder), and on leaving (postorder). Storing a counter with the node lets one pass emit all three orders.
- The state must live on the stack alongside the node, not in a separate map, so that a node resumes correctly after its subtree finishes.
- The node is only popped in state 3; in states 1 and 2 it stays on the stack and just has its counter incremented.
- An empty tree returns three empty lists; a single node yields `[v]` in all three.
