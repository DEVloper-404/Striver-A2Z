# K-th Largest element in an array

**Difficulty:** Medium  ·  **Topic:** Heaps [Learning, Medium, Hard Problems] › Medium Problems

## Problem
Given an integer array `nums` and an integer `k`, return the k-th largest element in the array when the array is viewed in sorted order (duplicates count separately, so it is the k-th position, not the k-th distinct value). You may assume `1 <= k <= n`.

```
Input:  nums = [3, 2, 1, 5, 6, 4], k = 2
Output: 5
```
Sorted descending the array is `6 5 4 3 2 1`, and the second entry is 5.

## Approach 1: Sort
Sort the whole array in ascending order and read off `nums[n - k]`. This is the simplest correct solution but it does more work than necessary because we only care about one position.
- **Time:** O(n log n)
- **Space:** O(1) extra (ignoring sort's internal stack)

## Approach 2: Min-heap of size k
Keep a min-heap that never holds more than `k` elements. Push every element; whenever the size exceeds `k`, pop the smallest. After the pass, the heap contains exactly the `k` largest values and its top (the smallest of those) is the answer.

Why it works: any element popped was smaller than at least `k` other elements seen so far, so it can never be the k-th largest.
- **Time:** O(n log k)
- **Space:** O(k)

## Approach 3: Quickselect (optimal on average)
Use the partition step from quicksort. Pick a pivot, move everything larger to its left and smaller to its right, and check the pivot's final index `p`. If `p == k - 1` the pivot is the answer; if `p < k - 1` recurse on the right part, else on the left part. Only one side is ever explored, which gives linear expected time. A random pivot avoids the O(n^2) worst case on adversarial inputs.
- **Time:** O(n) average, O(n^2) worst case
- **Space:** O(1) extra (iterative version)

The heap version is what interviewers usually expect when the topic is heaps, so the code below shows it; quickselect is included as a second function for reference.

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    // Heap version: O(n log k)
    int findKthLargest(vector<int>& nums, int k) {
        priority_queue<int, vector<int>, greater<int>> minHeap;
        for (int x : nums) {
            minHeap.push(x);
            if ((int)minHeap.size() > k) minHeap.pop();
        }
        return minHeap.top();
    }

    // Quickselect version: O(n) average
    int findKthLargestQuickselect(vector<int>& nums, int k) {
        int lo = 0, hi = nums.size() - 1, target = k - 1;
        srand(42);
        while (lo <= hi) {
            int pivotIdx = lo + rand() % (hi - lo + 1);
            swap(nums[pivotIdx], nums[hi]);
            int pivot = nums[hi], store = lo;
            for (int i = lo; i < hi; i++) {
                if (nums[i] > pivot) swap(nums[i], nums[store++]);
            }
            swap(nums[store], nums[hi]);
            if (store == target) return nums[store];
            if (store < target) lo = store + 1;
            else hi = store - 1;
        }
        return -1;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int findKthLargest(int[] nums, int k) {
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        for (int x : nums) {
            minHeap.offer(x);
            if (minHeap.size() > k) minHeap.poll();
        }
        return minHeap.peek();
    }

    public int findKthLargestQuickselect(int[] nums, int k) {
        int lo = 0, hi = nums.length - 1, target = k - 1;
        Random rng = new Random(42);
        while (lo <= hi) {
            int pivotIdx = lo + rng.nextInt(hi - lo + 1);
            swap(nums, pivotIdx, hi);
            int pivot = nums[hi], store = lo;
            for (int i = lo; i < hi; i++) {
                if (nums[i] > pivot) swap(nums, i, store++);
            }
            swap(nums, store, hi);
            if (store == target) return nums[store];
            if (store < target) lo = store + 1;
            else hi = store - 1;
        }
        return -1;
    }

    private void swap(int[] a, int i, int j) {
        int t = a[i]; a[i] = a[j]; a[j] = t;
    }
}
```

### Python
```python
import heapq
import random
from typing import List


class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        min_heap = []
        for x in nums:
            heapq.heappush(min_heap, x)
            if len(min_heap) > k:
                heapq.heappop(min_heap)
        return min_heap[0]

    def findKthLargestQuickselect(self, nums: List[int], k: int) -> int:
        lo, hi, target = 0, len(nums) - 1, k - 1
        while lo <= hi:
            pivot_idx = random.randint(lo, hi)
            nums[pivot_idx], nums[hi] = nums[hi], nums[pivot_idx]
            pivot, store = nums[hi], lo
            for i in range(lo, hi):
                if nums[i] > pivot:
                    nums[i], nums[store] = nums[store], nums[i]
                    store += 1
            nums[store], nums[hi] = nums[hi], nums[store]
            if store == target:
                return nums[store]
            if store < target:
                lo = store + 1
            else:
                hi = store - 1
        return -1
```

## Key Takeaways
- "K-th largest" pairs with a **min**-heap of size k: the top of the heap is the weakest survivor, which is exactly the answer.
- Bounding the heap to k elements is what turns O(n log n) into O(n log k); do not push everything and pop k times.
- Quickselect beats the heap asymptotically but needs a random pivot to avoid quadratic behaviour on sorted input.
- Duplicates are counted positionally: for `[3,3,3], k = 2` the answer is 3.
