# Traversal Techniques

**Difficulty:** Medium  ·  **Topic:** Graphs [Concepts & Problems] › Learning

## Problem
Traversing a graph means visiting every reachable node exactly once, in some systematic order. Unlike a tree, a graph can have cycles and multiple paths to the same node, so a traversal must remember what it has already seen. The two standard techniques are **BFS** (breadth-first search, level by level) and **DFS** (depth-first search, go deep then backtrack). This topic covers how both work, how they differ, and when to reach for each.

```
Input:  n = 5, adjacency list  1: [2,3]   2: [1,4]   3: [1]   4: [2,5]   5: [4]
BFS from 1: 1 2 3 4 5
DFS from 1: 1 2 4 5 3
```

## Approach 1: BFS — expand in rings
BFS treats the start node as the centre of a ripple. It first visits every node at distance 1, then every node at distance 2, and so on. The data structure that enforces this is a **queue** (FIFO): nodes are served in the order they were discovered, and since a node at distance `d` is always discovered before any node at distance `d+1`, the queue is always sorted by distance.

Algorithm:
1. Push the start node, mark it visited.
2. While the queue is not empty: pop the front node, record it in the answer, and for each unvisited neighbour, mark it visited and push it.

The crucial detail is *when* you mark visited. Mark on push, not on pop. If you mark only on pop, a node with three neighbours already in the queue gets enqueued three times, and the queue can blow up exponentially on dense graphs.

Dry run from node 1 on the example: queue `[1]` → pop 1, push 2 and 3 → queue `[2,3]` → pop 2, push 4 (1 is visited) → queue `[3,4]` → pop 3, nothing new → queue `[4]` → pop 4, push 5 → pop 5. Order: `1 2 3 4 5`.

Because BFS discovers nodes in non-decreasing distance order, it also computes the **shortest path in an unweighted graph** for free: the level at which a node is first popped is its minimum edge count from the source.
- **Time:** O(V + E)
- **Space:** O(V) for the queue and visited array

## Approach 2: DFS — go as deep as possible, then backtrack
DFS commits to one branch. From the current node it picks an unvisited neighbour and immediately recurses into it, only returning when that branch is exhausted. The structure is a **stack** — either the implicit call stack of recursion, or an explicit stack in the iterative form.

Algorithm (recursive):
1. Mark the current node visited and record it.
2. For each neighbour, if unvisited, recurse into it.
3. Return when all neighbours are handled (this is the "backtrack").

Dry run from node 1: visit 1 → neighbour 2 → visit 2 → neighbour 1 is visited, neighbour 4 → visit 4 → neighbour 5 → visit 5, dead end, backtrack to 4, to 2, to 1 → next neighbour 3 → visit 3. Order: `1 2 4 5 3`.

DFS does **not** give shortest paths — it may reach a nearby node through a long detour. What it does give is a natural place to run logic *after* a subtree finishes, which is why DFS underpins cycle detection, topological sort, bridges/articulation points, and strongly connected components.

Recursion depth equals the longest path, so on a 10^5-node chain a recursive DFS can overflow the stack in C++/Java and hit Python's default limit. Convert to the explicit-stack form (or raise the limit) when `n` is large.
- **Time:** O(V + E)
- **Space:** O(V) for visited plus O(V) worst-case stack depth

## Approach 3: Choosing between them
- Shortest path / minimum number of steps in an unweighted graph → **BFS**.
- Multi-source spreading (fire, rot, water flooding from many cells at once) → **BFS** with all sources pushed initially.
- "Does a path exist", flood fill, counting components, marking a region → either works; DFS is shorter to write.
- Cycle detection in a directed graph, topological order, post-order bookkeeping → **DFS**.
- Very deep graphs with recursion limits → **BFS** or iterative DFS.

Both are O(V + E) because each node is dequeued/entered once and each adjacency entry is examined once.
- **Time:** O(V + E)
- **Space:** O(V)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    // BFS traversal order starting at `src`
    vector<int> bfs(int n, vector<vector<int>>& adj, int src) {
        vector<int> order, visited(n, 0);
        queue<int> q;
        q.push(src);
        visited[src] = 1;
        while (!q.empty()) {
            int node = q.front(); q.pop();
            order.push_back(node);
            for (int nb : adj[node]) {
                if (!visited[nb]) {
                    visited[nb] = 1;      // mark on push
                    q.push(nb);
                }
            }
        }
        return order;
    }

    // DFS traversal order starting at `src`
    vector<int> dfs(int n, vector<vector<int>>& adj, int src) {
        vector<int> order, visited(n, 0);
        dfsHelper(src, adj, visited, order);
        return order;
    }

private:
    void dfsHelper(int node, vector<vector<int>>& adj, vector<int>& visited, vector<int>& order) {
        visited[node] = 1;
        order.push_back(node);
        for (int nb : adj[node]) {
            if (!visited[nb]) dfsHelper(nb, adj, visited, order);
        }
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public List<Integer> bfs(int n, List<List<Integer>> adj, int src) {
        List<Integer> order = new ArrayList<>();
        boolean[] visited = new boolean[n];
        Queue<Integer> q = new LinkedList<>();
        q.add(src);
        visited[src] = true;
        while (!q.isEmpty()) {
            int node = q.poll();
            order.add(node);
            for (int nb : adj.get(node)) {
                if (!visited[nb]) {
                    visited[nb] = true;
                    q.add(nb);
                }
            }
        }
        return order;
    }

    public List<Integer> dfs(int n, List<List<Integer>> adj, int src) {
        List<Integer> order = new ArrayList<>();
        boolean[] visited = new boolean[n];
        dfsHelper(src, adj, visited, order);
        return order;
    }

    private void dfsHelper(int node, List<List<Integer>> adj, boolean[] visited, List<Integer> order) {
        visited[node] = true;
        order.add(node);
        for (int nb : adj.get(node)) {
            if (!visited[nb]) dfsHelper(nb, adj, visited, order);
        }
    }
}
```

### Python
```python
from collections import deque
from typing import List

class Solution:
    def bfs(self, n: int, adj: List[List[int]], src: int) -> List[int]:
        order, visited = [], [False] * n
        q = deque([src])
        visited[src] = True
        while q:
            node = q.popleft()
            order.append(node)
            for nb in adj[node]:
                if not visited[nb]:
                    visited[nb] = True
                    q.append(nb)
        return order

    def dfs(self, n: int, adj: List[List[int]], src: int) -> List[int]:
        order, visited = [], [False] * n
        stack = [src]
        visited[src] = True
        while stack:                      # iterative DFS, no recursion limit
            node = stack.pop()
            order.append(node)
            for nb in reversed(adj[node]):
                if not visited[nb]:
                    visited[nb] = True
                    stack.append(nb)
        return order
```

## Key Takeaways
- Queue ⇒ BFS (level order, shortest unweighted path); stack/recursion ⇒ DFS (deep-first, backtracking).
- Always mark a node visited at the moment you push it, otherwise duplicates flood the queue.
- Both run in O(V + E); the difference is the *order* of visits and what invariants they give you.
- One traversal only covers one component — loop over all nodes to cover a disconnected graph.
