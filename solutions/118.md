# LCA in BT

**Difficulty:** Hard  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Hard Problems

## Problem
Given the root of a binary tree and two nodes `p` and `q` that both exist in it, return their lowest common ancestor: the deepest node that has both `p` and `q` in its subtree (a node counts as its own descendant).

Input: root = [3, 5, 1, 6, 2, 0, 8, null, null, 7, 4], p = 5, q = 1
Output: 3

Input: same tree, p = 5, q = 4
Output: 5 (a node can be an ancestor of itself)

## Approach 1: Brute Force (two root-to-node paths)
Find the root-to-`p` path and the root-to-`q` path with a backtracking DFS. Walk both lists in lockstep from the start; the last index where they agree is the LCA. Simple and easy to reason about, but it makes two full passes and stores two paths.
- **Time:** O(N)
- **Space:** O(H) for the two paths and recursion

## Approach 2: Optimal (single post-order pass)
Define `lca(node)`:
1. If `node` is null, or equals `p` or `q`, return `node`.
2. Recurse into left and right.
3. If both sides return non-null, the current node is where the two targets split, so it is the answer.
4. Otherwise return whichever side is non-null (that side already contains the LCA, or one of the targets).

Why this works: the first time a node sees non-null answers from both subtrees, it must be the lowest such node, because deeper nodes could only have found at most one of the targets. If `p` is an ancestor of `q`, the recursion returns `p` at step 1 without ever needing to look below it.
- **Time:** O(N)
- **Space:** O(H) recursion stack

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (root == nullptr || root == p || root == q) return root;
        TreeNode* l = lowestCommonAncestor(root->left, p, q);
        TreeNode* r = lowestCommonAncestor(root->right, p, q);
        if (l && r) return root;
        return l ? l : r;
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) return root;
        TreeNode l = lowestCommonAncestor(root.left, p, q);
        TreeNode r = lowestCommonAncestor(root.right, p, q);
        if (l != null && r != null) return root;
        return l != null ? l : r;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def lowestCommonAncestor(self, root, p, q):
        if root is None or root is p or root is q:
            return root
        l = self.lowestCommonAncestor(root.left, p, q)
        r = self.lowestCommonAncestor(root.right, p, q)
        if l and r:
            return root
        return l if l else r
```

## Key Takeaways
- "Both children returned something" is the signature of the split point; that is the LCA.
- Compare node references, not values, unless the problem guarantees unique values.
- The one-pass solution relies on both nodes being present; if that is not guaranteed, you must additionally verify that both were actually seen.
- The same skeleton (return non-null from whichever side has the target) generalizes to LCA of k nodes.
