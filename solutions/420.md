# Pattern 7

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a centered pyramid of stars with `n` rows. Row `i` (0-indexed) has `2i + 1` stars, padded on the left with `n - i - 1` spaces so the pyramid is symmetric.

Input: `n = 5`
Output:
```
    *
   ***
  *****
 *******
*********
```

## Approach
A centered shape needs three inner loops per row: leading spaces, the stars, and (optionally) trailing spaces. Only the leading spaces affect what is visible.

1. Outer loop `i` from `0` to `n-1`.
2. Print `n - i - 1` spaces (the padding shrinks as rows widen).
3. Print `2i + 1` stars (odd counts keep the peak centered).
4. Newline.

Row 0 has 1 star and `n-1` spaces; the last row has `2n-1` stars and no padding, which gives the triangular outline.

- **Time:** O(n²) — the last row alone has 2n-1 characters.
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern7(int n) {
    for (int i = 0; i < n; i++) {
        for (int s = 0; s < n - i - 1; s++) cout << " ";
        for (int j = 0; j < 2 * i + 1; j++) cout << "*";
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern7 {
    public static void pattern7(int n) {
        for (int i = 0; i < n; i++) {
            StringBuilder row = new StringBuilder();
            for (int s = 0; s < n - i - 1; s++) row.append(' ');
            for (int j = 0; j < 2 * i + 1; j++) row.append('*');
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern7(n: int) -> None:
    for i in range(n):
        print(" " * (n - i - 1) + "*" * (2 * i + 1))
```

## Key Takeaways
- Centered patterns = spaces loop + content loop; the space count shrinks as the content grows.
- `2i + 1` is the standard formula for a symmetric row that widens by one star on each side.
- Stars here are printed without separating spaces, otherwise the pyramid would not line up.
