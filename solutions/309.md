# Longest common substring

**Difficulty:** Hard  ·  **Topic:** Dynamic Programming [Patterns and Problems] › DP on Strings

## Problem
Given two strings `s1` and `s2`, return the length of the longest string that appears as a **contiguous** block in both. Unlike a subsequence, a substring cannot skip characters.

```
Input:  s1 = "abcjklp", s2 = "acjkp"
Output: 3
Explanation: "cjk" occurs contiguously in both. ("acjkp" is a common subsequence
             of length 5, but it is not contiguous in s1.)
```

## Approach 1: Brute Force (check every pair of starts)
For every start `i` in `s1` and every start `j` in `s2`, walk forward while the characters keep matching and record the longest run. This is three nested loops.

- **Time:** O(n · m · min(n, m))
- **Space:** O(1)

## Approach 2: Optimal (DP on "runs ending here")

**Why the LCS recurrence does not transfer.** In LCS, when characters differ we take `max(dp[i-1][j], dp[i][j-1])` — that step *skips* a character while keeping the accumulated length. Contiguity forbids exactly that. So we need a state whose meaning makes skipping impossible.

**The key observation.** Redefine the state to be anchored at the end:

`dp[i][j] = the length of the longest common suffix of s1[0..i-1] and s2[0..j-1]`

that is, the longest common substring that **ends exactly at** `s1[i-1]` and `s2[j-1]`.

With that meaning the recurrence is forced:
- If `s1[i-1] == s2[j-1]`, a run ending here exists and it is one longer than a run ending at the previous pair: `dp[i][j] = 1 + dp[i-1][j-1]`.
- If they differ, no common block can end at this pair at all: `dp[i][j] = 0`. The reset to zero is precisely what enforces contiguity.

No cell is ever the answer by itself, because the answer may end anywhere. So track a running maximum over every cell filled.

Row 0 and column 0 are zeros (an empty prefix has no common suffix), which handles the boundary without special cases.

**Space optimisation.** `dp[i][j]` depends only on `dp[i-1][j-1]`, so two rolling rows of size `m+1` suffice — but be careful to read `prev[j-1]` before overwriting anything in the current row (using separate `prev`/`cur` arrays makes this automatic).

**Dry run on s1 = "abcjklp", s2 = "acjkp".** Only the non-zero cells matter:

|     | a | c | j | k | p |
|-----|---|---|---|---|---|
| a   | **1** | 0 | 0 | 0 | 0 |
| b   | 0 | 0 | 0 | 0 | 0 |
| c   | 0 | **1** | 0 | 0 | 0 |
| j   | 0 | 0 | **2** | 0 | 0 |
| k   | 0 | 0 | 0 | **3** | 0 |
| l   | 0 | 0 | 0 | 0 | 0 |
| p   | 0 | 0 | 0 | 0 | **1** |

Follow the diagonal `c → j → k`: it climbs 1, 2, 3 because each match extends the previous diagonal cell. The `l` row wipes everything back to 0, and `p` restarts a fresh run of length 1. The maximum seen is 3, for `"cjk"`.

- **Time:** O(n · m)
- **Space:** O(m) with rolling rows

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int longestCommonSubstr(string s1, string s2) {
        int n = s1.size(), m = s2.size();
        vector<int> prev(m + 1, 0), cur(m + 1, 0);
        int best = 0;

        for (int i = 1; i <= n; i++) {
            cur[0] = 0;
            for (int j = 1; j <= m; j++) {
                if (s1[i - 1] == s2[j - 1]) {
                    cur[j] = 1 + prev[j - 1];      // extend the diagonal run
                    best = max(best, cur[j]);
                } else {
                    cur[j] = 0;                    // contiguity broken -> reset
                }
            }
            prev = cur;
        }
        return best;
    }
};
```

### Java
```java
class Solution {
    public int longestCommonSubstr(String s1, String s2) {
        int n = s1.length(), m = s2.length();
        int[] prev = new int[m + 1];
        int[] cur = new int[m + 1];
        int best = 0;

        for (int i = 1; i <= n; i++) {
            cur[0] = 0;
            for (int j = 1; j <= m; j++) {
                if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                    cur[j] = 1 + prev[j - 1];
                    best = Math.max(best, cur[j]);
                } else {
                    cur[j] = 0;
                }
            }
            int[] tmp = prev; prev = cur; cur = tmp;
        }
        return best;
    }
}
```

### Python
```python
class Solution:
    def longestCommonSubstr(self, s1, s2):
        n, m = len(s1), len(s2)
        prev = [0] * (m + 1)
        best = 0

        for i in range(1, n + 1):
            cur = [0] * (m + 1)
            for j in range(1, m + 1):
                if s1[i - 1] == s2[j - 1]:
                    cur[j] = 1 + prev[j - 1]
                    if cur[j] > best:
                        best = cur[j]
                # else cur[j] stays 0 -- run is broken
            prev = cur

        return best
```

## Key Takeaways
- Changing the state from "best so far" to "best **ending here**" is the standard trick for turning a subsequence DP into a substring DP.
- The mismatch branch resets to 0 instead of taking a max — that single line is what enforces contiguity.
- Because runs can end anywhere, the answer is a running maximum over all cells, not `dp[n][m]`.
- To also recover the substring itself, remember the `(i, j)` where the maximum occurred; the block is `s1[i - best .. i - 1]`.
