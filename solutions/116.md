# Boundary Traversal

**Difficulty:** Medium  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Medium Problems

## Problem
Return the boundary of a binary tree in anti-clockwise order starting from the root: the root, then the left boundary going down (excluding leaves), then all leaves from left to right, then the right boundary going up (excluding leaves). No node should be printed twice.

Input: root = [1,2,3,4,5,6,7,null,null,8,9]
Output: [1,2,4,8,9,6,7,3]
(left boundary 1 → 2, leaves 4, 8, 9, 6, 7, right boundary 3)

Input: root = [1,null,2,3,4]
Output: [1,3,4,2]

## Approach 1: Three Separate Walks
Split the boundary into three parts and collect each with its own traversal:

1. **Left boundary:** start from `root.left`; at each node, prefer the left child, else the right child; stop before a leaf. Add nodes on the way down.
2. **Leaves:** any DFS (pre-order) that records nodes with no children, in left-to-right order.
3. **Right boundary:** start from `root.right`; prefer the right child, else the left child; stop before a leaf. Collect on the way down, then add in reverse so it reads bottom-up.

Add the root first, but only treat it as a leaf if it has no children (then it is the entire answer). Because the left and right walks skip leaves, and the leaf walk skips internal nodes, nothing is duplicated.
- **Time:** O(n)
- **Space:** O(h) recursion for the leaf walk plus O(n) output

## Approach 2: Same Idea, Iterative Boundary Walks
The left and right boundary walks are naturally iterative (single pointer descending), which keeps the stack usage limited to the leaf DFS. This is what the code below does; there is no asymptotically better method since every boundary node must be output.
- **Time:** O(n)
- **Space:** O(h)

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; ... } — standard definition
class Solution {
    bool isLeaf(TreeNode* n) { return n && !n->left && !n->right; }

    void addLeft(TreeNode* root, vector<int>& res) {
        TreeNode* cur = root->left;
        while (cur) {
            if (!isLeaf(cur)) res.push_back(cur->val);
            cur = cur->left ? cur->left : cur->right;
        }
    }

    void addLeaves(TreeNode* node, vector<int>& res) {
        if (!node) return;
        if (isLeaf(node)) { res.push_back(node->val); return; }
        addLeaves(node->left, res);
        addLeaves(node->right, res);
    }

    void addRight(TreeNode* root, vector<int>& res) {
        vector<int> tmp;
        TreeNode* cur = root->right;
        while (cur) {
            if (!isLeaf(cur)) tmp.push_back(cur->val);
            cur = cur->right ? cur->right : cur->left;
        }
        for (int i = (int)tmp.size() - 1; i >= 0; --i) res.push_back(tmp[i]);
    }
public:
    vector<int> boundaryOfBinaryTree(TreeNode* root) {
        vector<int> res;
        if (!root) return res;
        res.push_back(root->val);
        if (isLeaf(root)) return res;
        addLeft(root, res);
        addLeaves(root, res);
        addRight(root, res);
        return res;
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
import java.util.*;

class Solution {
    private boolean isLeaf(TreeNode n) {
        return n != null && n.left == null && n.right == null;
    }

    private void addLeft(TreeNode root, List<Integer> res) {
        TreeNode cur = root.left;
        while (cur != null) {
            if (!isLeaf(cur)) res.add(cur.val);
            cur = (cur.left != null) ? cur.left : cur.right;
        }
    }

    private void addLeaves(TreeNode node, List<Integer> res) {
        if (node == null) return;
        if (isLeaf(node)) { res.add(node.val); return; }
        addLeaves(node.left, res);
        addLeaves(node.right, res);
    }

    private void addRight(TreeNode root, List<Integer> res) {
        List<Integer> tmp = new ArrayList<>();
        TreeNode cur = root.right;
        while (cur != null) {
            if (!isLeaf(cur)) tmp.add(cur.val);
            cur = (cur.right != null) ? cur.right : cur.left;
        }
        for (int i = tmp.size() - 1; i >= 0; i--) res.add(tmp.get(i));
    }

    public List<Integer> boundaryOfBinaryTree(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        res.add(root.val);
        if (isLeaf(root)) return res;
        addLeft(root, res);
        addLeaves(root, res);
        addRight(root, res);
        return res;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
class Solution:
    def boundaryOfBinaryTree(self, root):
        def is_leaf(n):
            return n is not None and n.left is None and n.right is None

        res = []
        if root is None:
            return res
        res.append(root.val)
        if is_leaf(root):
            return res

        # left boundary, top-down, excluding leaves
        cur = root.left
        while cur:
            if not is_leaf(cur):
                res.append(cur.val)
            cur = cur.left if cur.left else cur.right

        # leaves, left to right
        def leaves(node):
            if node is None:
                return
            if is_leaf(node):
                res.append(node.val)
                return
            leaves(node.left)
            leaves(node.right)
        leaves(root)

        # right boundary, bottom-up, excluding leaves
        tmp = []
        cur = root.right
        while cur:
            if not is_leaf(cur):
                tmp.append(cur.val)
            cur = cur.right if cur.right else cur.left
        res.extend(reversed(tmp))
        return res
```

## Key Takeaways
- Decompose into root + left edge + leaves + reversed right edge; excluding leaves from the two edge walks is what prevents duplicates.
- When descending the left edge, fall back to the right child if there is no left child (and symmetrically on the right).
- A root that is itself a leaf is a special case: output just the root.
