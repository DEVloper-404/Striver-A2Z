# Longest Substring Without Repeating Characters

**Difficulty:** Medium  ·  **Topic:** Sliding Window & Two Pointer Combined Problems › Medium Problems

## Problem
Given a string `s`, return the length of the longest contiguous substring in which no character appears more than once. The answer is a single integer (0 for the empty string).

Input: `s = "abcabcbb"`
Output: `3` (the substring `"abc"`)

Input: `s = "pwwkew"`
Output: `3` (`"wke"`; note `"pwke"` is a subsequence, not a substring)

## Approach 1: Brute Force
Fix every starting index `i`, extend `j` to the right while maintaining a seen-set of characters. The moment `s[j]` is already in the set, stop and record `j - i`. The set is reset for every new `i`.

- **Time:** O(n²)
- **Space:** O(k) where k is the alphabet size (at most 256)

## Approach 2: Sliding Window with Last-Seen Index (Optimal)
Keep a window `[l, r]` that always contains distinct characters. Store, for every character, the last index where it appeared.

1. Move `r` forward one character at a time.
2. If `s[r]` was seen before at index `p` and `p >= l`, the window would now contain a duplicate, so jump `l` to `p + 1`. Because the window before this step was duplicate-free, everything in `[p + 1, r]` is still distinct.
3. Update `last[s[r]] = r` and the answer with `r - l + 1`.

The `p >= l` check is what makes this correct: a stale index to the left of `l` must not shrink the window. Each pointer moves forward only, so the total work is linear.

- **Time:** O(n)
- **Space:** O(256) = O(1)

## Code (Optimal)

### C++
```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        vector<int> last(256, -1);
        int best = 0, l = 0;
        for (int r = 0; r < (int)s.size(); ++r) {
            unsigned char c = s[r];
            if (last[c] >= l) l = last[c] + 1;
            last[c] = r;
            best = max(best, r - l + 1);
        }
        return best;
    }
};
```

        java.util.Arrays.fill(last, -1);
        int best = 0, l = 0;
        for (int r = 0; r < s.length(); r++) {

### Python
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last = {}
        best = 0
        l = 0
        for r, ch in enumerate(s):
            if ch in last and last[ch] >= l:
                l = last[ch] + 1
            last[ch] = r
            best = max(best, r - l + 1)
        return best
```

## Key Takeaways
- Classic variable-size window: expand `r`, and only shrink `l` when a duplicate enters.
- Storing the last index lets `l` jump directly instead of stepping one by one; guard with `last[c] >= l` to ignore stale positions.
- Edge cases: empty string (returns 0), all identical characters (answer 1), all distinct (answer n).
