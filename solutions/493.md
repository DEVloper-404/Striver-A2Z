# Generate Binary Strings Without Consecutive 1s

**Difficulty:** Medium  ·  **Topic:** Recursion [PatternWise] › Subsequences Pattern

## Problem
Given an integer `n`, produce every binary string of length `n` in which no two `1`s are adjacent. Return them in lexicographic order (all strings starting with `0` before those starting with `1`).

Input: `n = 3`
Output: `["000", "001", "010", "100", "101"]`

Input: `n = 2`
Output: `["00", "01", "10"]`

## Approach 1: Generate everything, then filter
Enumerate all `2^n` binary strings (via recursion or by counting from `0` to `2^n - 1`), and keep only those that contain no `"11"` substring. Simple, but it builds many strings that are thrown away.
- **Time:** O(2^n · n)
- **Space:** O(n) recursion depth plus the output

## Approach 2: Recursion that never creates an invalid prefix
Build the string one character at a time and use the last placed character to decide what is allowed next. If the last character is `0`, both `0` and `1` may follow; if it is `1`, only `0` may follow. This prunes every invalid branch immediately, so the recursion tree contains only valid prefixes.

1. `build(pos, current)`: if `pos == n`, record `current` and return.
2. Append `'0'` and recurse (always allowed). Placing `'0'` first keeps the output lexicographically sorted.
3. If `current` is empty or ends with `'0'`, append `'1'` and recurse.

The number of results follows the Fibonacci sequence (`n=1: 2`, `n=2: 3`, `n=3: 5`, ...), and the work done is proportional to the output size, which is the best possible.
- **Time:** O(F(n) · n) where F(n) ≈ 1.618^n is the number of valid strings
- **Space:** O(n) recursion depth (excluding the output list)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
    void build(int n, string& cur, vector<string>& out) {
        if ((int)cur.size() == n) {
            out.push_back(cur);
            return;
        }
        cur.push_back('0');
        build(n, cur, out);
        cur.pop_back();
        if (cur.empty() || cur.back() == '0') {
            cur.push_back('1');
            build(n, cur, out);
            cur.pop_back();
        }
    }
public:
    vector<string> generateBinaryStrings(int n) {
        vector<string> out;
        string cur;
        build(n, cur, out);
        return out;
    }
};
```

### Java
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    private void build(int n, StringBuilder cur, List<String> out) {
        if (cur.length() == n) {
            out.add(cur.toString());
            return;
        }
        cur.append('0');
        build(n, cur, out);
        cur.deleteCharAt(cur.length() - 1);
        if (cur.length() == 0 || cur.charAt(cur.length() - 1) == '0') {
            cur.append('1');
            build(n, cur, out);
            cur.deleteCharAt(cur.length() - 1);
        }
    }

    public List<String> generateBinaryStrings(int n) {
        List<String> out = new ArrayList<>();
        build(n, new StringBuilder(), out);
        return out;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def generateBinaryStrings(self, n: int) -> List[str]:
        out: List[str] = []

        def build(cur: List[str]) -> None:
            if len(cur) == n:
                out.append("".join(cur))
                return
            cur.append('0')
            build(cur)
            cur.pop()
            if not cur or cur[-1] == '0':
                cur.append('1')
                build(cur)
                cur.pop()

        build([])
        return out
```

## Key Takeaways
- Look at the last placed character to decide the next choice; pruning at the prefix level avoids generating invalid strings at all.
- Trying `0` before `1` gives lexicographic order for free.
- The count of valid strings is Fibonacci-like, a useful sanity check for the output size.
- The same "constrain the next choice by the previous one" idea powers many string-generation problems.
