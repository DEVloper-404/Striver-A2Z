# Check if the Number is Armstrong

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Know Basic Maths

## Problem
A `k`-digit number is an Armstrong (narcissistic) number if the sum of each of its digits raised to the `k`-th power equals the number itself. Given a positive integer `n`, return `true` if it is an Armstrong number.

Input: `n = 153`
Output: `true` (1³ + 5³ + 3³ = 1 + 125 + 27 = 153)

Input: `n = 1634`
Output: `true` (1⁴ + 6⁴ + 3⁴ + 4⁴ = 1634)

Input: `n = 123`
Output: `false` (1 + 8 + 27 = 36)

## Approach 1: Count digits, then sum powers
Two passes over the digits:

1. Count the digits `k` with a `/ 10` loop (or via string length).
2. Walk the digits again; for each digit `d` add `d^k` to a running sum. Use an integer power helper or the library `pow` (cast carefully — `pow` returns a double).

Finally compare the sum with the original number. Keep a copy of `n` because the loop destroys it.

- **Time:** O(k) digit extraction plus O(k · log k) for the powers, effectively O(k) for the tiny `k` involved
- **Space:** O(1)

## Approach 2: String-based
Convert to a string, `k = len(s)`, and sum `int(c) ** k` for each character. Same idea, slightly less arithmetic, but allocates a string.

- **Time:** O(k)
- **Space:** O(k)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    bool isArmstrong(int n) {
        int k = 0;
        for (int t = n; t > 0; t /= 10) k++;

        long long sum = 0;
        for (int t = n; t > 0; t /= 10) {
            int d = t % 10;
            long long p = 1;
            for (int i = 0; i < k; i++) p *= d;
            sum += p;
        }
        return sum == n;
    }
};
```

### Python
```python
class Solution:
    def isArmstrong(self, n: int) -> bool:
        k = len(str(n))
        total = 0
        t = n
        while t > 0:
            total += (t % 10) ** k
            t //= 10
        return total == n
```

## Key Takeaways
- Two digit loops: one to count digits `k`, one to accumulate `digit^k`.
- Use an integer power loop (or a 64-bit accumulator) instead of `pow()`, which returns a floating-point value and can be off by one after truncation.
- Never modify the original `n` directly; you need it for the final comparison.
