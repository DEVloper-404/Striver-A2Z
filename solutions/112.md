# Serialize and De-serialize BT

**Difficulty:** Hard  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Hard Problems

## Problem
Design two functions: `serialize` turns a binary tree into a string, and `deserialize` turns that string back into an identical tree. The format is yours to choose, as long as the round trip reproduces the same structure and values (including negatives and multi-digit numbers).

Input: root = [1, 2, 3, null, null, 4, 5]
Output: serialize → e.g. "1,2,#,#,3,4,#,#,5,#,#" → deserialize → the same tree

Input: root = []
Output: serialize → "#" → deserialize → empty tree

## Approach 1: Level-order with null markers
BFS the tree, writing each node's value and a sentinel (`#`) for every null child encountered. To rebuild, read tokens in the same order with a queue: pop a parent, assign the next two tokens as its left and right children (skipping nulls), and push the non-null children.
- **Time:** O(N)
- **Space:** O(N)

## Approach 2: Preorder with null markers (optimal, simplest to code)
Write the tree in preorder, emitting `#` for nulls. Because nulls are explicit, the preorder sequence alone determines the tree: deserialization consumes tokens left to right, creating a node, then recursively building its left and right subtrees. A shared index (or iterator) tracks the current token. Both directions are a single pass and the code is very short.
- **Time:** O(N)
- **Space:** O(N) for the string, O(H) recursion

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left; TreeNode *right; TreeNode(int x) ... } — standard definition
#include <string>
#include <sstream>
using namespace std;

class Codec {
    void encode(TreeNode* node, ostringstream& out) {
        if (!node) { out << "#,"; return; }
        out << node->val << ',';
        encode(node->left, out);
        encode(node->right, out);
    }
    TreeNode* decode(istringstream& in) {
        string tok;
        if (!getline(in, tok, ',')) return nullptr;
        if (tok == "#") return nullptr;
        TreeNode* node = new TreeNode(stoi(tok));
        node->left  = decode(in);
        node->right = decode(in);
        return node;
    }
public:
    string serialize(TreeNode* root) {
        ostringstream out;
        encode(root, out);
        return out.str();
    }
    TreeNode* deserialize(string data) {
        istringstream in(data);
        return decode(in);
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; TreeNode(int x) ... } — standard definition
import java.util.*;

public class Codec {
    private void encode(TreeNode node, StringBuilder sb) {
        if (node == null) { sb.append("#,"); return; }
        sb.append(node.val).append(',');
        encode(node.left, sb);
        encode(node.right, sb);
    }

    private TreeNode decode(Deque<String> tokens) {
        String tok = tokens.poll();
        if (tok == null || tok.equals("#")) return null;
        TreeNode node = new TreeNode(Integer.parseInt(tok));
        node.left  = decode(tokens);
        node.right = decode(tokens);
        return node;
    }

    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        encode(root, sb);
        return sb.toString();
    }

    public TreeNode deserialize(String data) {
        Deque<String> tokens = new ArrayDeque<>(Arrays.asList(data.split(",")));
        return decode(tokens);
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Codec:
    def serialize(self, root):
        out = []

        def encode(node):
            if node is None:
                out.append("#")
                return
            out.append(str(node.val))
            encode(node.left)
            encode(node.right)

        encode(root)
        return ",".join(out)

    def deserialize(self, data):
        tokens = iter(data.split(","))

        def decode():
            tok = next(tokens)
            if tok == "#":
                return None
            node = TreeNode(int(tok))
            node.left = decode()
            node.right = decode()
            return node

        return decode()
```

## Key Takeaways
- A single traversal is enough for reconstruction *only because* nulls are written explicitly.
- Use a delimiter (comma) rather than fixed-width tokens so negatives and multi-digit values survive the round trip.
- Preorder + shared iterator is the shortest correct implementation; level-order is equally valid and avoids deep recursion on skewed trees.
- Do not use inorder for this: even with null markers, inorder cannot identify the root.
