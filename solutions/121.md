# Print all nodes at a distance of K in BT

**Difficulty:** Hard  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Hard Problems

## Problem
Given the root of a binary tree, a `target` node in it, and an integer `k`, return the values of all nodes whose distance (number of edges) from `target` is exactly `k`. The answer may include ancestors and nodes in other subtrees, not just descendants.

Input: root = [3, 5, 1, 6, 2, 0, 8, null, null, 7, 4], target = 5, k = 2
Output: [7, 4, 1] (any order)

## Approach 1: Brute Force (path plus downward searches)
Find the root-to-target path. For each ancestor at distance `d` from the target (d ≤ k), collect nodes at depth `k - d` in the ancestor's *other* subtree (not the one leading back toward the target). Also collect nodes at depth `k` below the target itself. Correct but bookkeeping-heavy.
- **Time:** O(N)
- **Space:** O(H)

## Approach 2: Optimal (parent pointers + BFS)
Treat the tree as an undirected graph. Each node has up to three neighbors: left child, right child, and parent. Record parents with one traversal, then run a BFS starting from `target`, expanding `k` rings outward while tracking visited nodes so we never walk back. After `k` expansions the queue holds exactly the answer.

Key observation: distance in an undirected tree is what BFS measures naturally; the parent map is what makes upward moves possible.
- **Time:** O(N)
- **Space:** O(N) for the parent map, visited set, and queue

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition
#include <vector>
#include <queue>
#include <unordered_map>
#include <unordered_set>
using namespace std;

class Solution {
public:
    vector<int> distanceK(TreeNode* root, TreeNode* target, int k) {
        unordered_map<TreeNode*, TreeNode*> parent;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            TreeNode* n = q.front(); q.pop();
            if (n->left)  { parent[n->left]  = n; q.push(n->left); }
            if (n->right) { parent[n->right] = n; q.push(n->right); }
        }

        unordered_set<TreeNode*> seen;
        q.push(target);
        seen.insert(target);
        int dist = 0;
        while (!q.empty() && dist < k) {
            int sz = q.size();
            for (int i = 0; i < sz; ++i) {
                TreeNode* n = q.front(); q.pop();
                TreeNode* nb[3] = { n->left, n->right, parent.count(n) ? parent[n] : nullptr };
                for (TreeNode* x : nb)
                    if (x && !seen.count(x)) { seen.insert(x); q.push(x); }
            }
            ++dist;
        }

        vector<int> ans;
        while (!q.empty()) { ans.push_back(q.front()->val); q.pop(); }
        return ans;
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
import java.util.*;

class Solution {
    public List<Integer> distanceK(TreeNode root, TreeNode target, int k) {
        Map<TreeNode, TreeNode> parent = new HashMap<>();
        Deque<TreeNode> q = new ArrayDeque<>();
        q.add(root);
        while (!q.isEmpty()) {
            TreeNode n = q.poll();
            if (n.left  != null) { parent.put(n.left,  n); q.add(n.left); }
            if (n.right != null) { parent.put(n.right, n); q.add(n.right); }
        }

        Set<TreeNode> seen = new HashSet<>();
        q.add(target);
        seen.add(target);
        int dist = 0;
        while (!q.isEmpty() && dist < k) {
            int sz = q.size();
            for (int i = 0; i < sz; i++) {
                TreeNode n = q.poll();
                TreeNode[] nb = { n.left, n.right, parent.get(n) };
                for (TreeNode x : nb)
                    if (x != null && seen.add(x)) q.add(x);
            }
            dist++;
        }

        List<Integer> ans = new ArrayList<>();
        for (TreeNode n : q) ans.add(n.val);
        return ans;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
from collections import deque

class Solution:
    def distanceK(self, root, target, k):
        parent = {}
        q = deque([root])
        while q:
            n = q.popleft()
            if n.left:
                parent[n.left] = n
                q.append(n.left)
            if n.right:
                parent[n.right] = n
                q.append(n.right)

        seen = {target}
        q.append(target)
        dist = 0
        while q and dist < k:
            for _ in range(len(q)):
                n = q.popleft()
                for x in (n.left, n.right, parent.get(n)):
                    if x and x not in seen:
                        seen.add(x)
                        q.append(x)
            dist += 1

        return [n.val for n in q]
```

## Key Takeaways
- Convert "tree + go upward" problems into a graph BFS by recording parent pointers.
- A visited set is mandatory: without it the BFS bounces between a node and its parent.
- Stop after exactly `k` layers; whatever is left in the queue is the answer (possibly empty if `k` exceeds the tree's reach).
- `k = 0` should return just the target; the loop handles this naturally.
