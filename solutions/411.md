# Pattern 19

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a `2n`-row star pattern with a symmetric hollow in the middle. The top row is `2n` solid stars; each following row removes one star from each end of the middle until only one star remains on each side, then the shape grows back to a full row.

Input: `n = 5`
Output:
```
**********
****  ****
***    ***
**      **
*        *
*        *
**      **
***    ***
****  ****
**********
```

## Approach
Each row is `left stars + middle spaces + right stars`, with the same star count on both sides. Split the figure into an upper half that shrinks and a lower half that grows.

1. Upper half, `i` from `0` to `n-1`: stars on each side = `n - i`, spaces in between = `2i`.
2. Lower half, `i` from `0` to `n-1`: stars on each side = `i + 1`, spaces in between = `2(n - i - 1)`.
3. For every row the total width is `2 * stars + spaces = 2n`, which keeps the right edge aligned.

The middle two rows are both `* … *` with `2n - 2` spaces, which is why the total row count is `2n` and not `2n - 1`.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void printRow(int stars, int spaces) {
    for (int j = 0; j < stars; j++) cout << "*";
    for (int j = 0; j < spaces; j++) cout << " ";
    for (int j = 0; j < stars; j++) cout << "*";
    cout << "\n";
}

void pattern19(int n) {
    for (int i = 0; i < n; i++) printRow(n - i, 2 * i);          // upper half
    for (int i = 0; i < n; i++) printRow(i + 1, 2 * (n - i - 1)); // lower half
}
```

### Java
```java
public class Pattern19 {
    private static String row(int stars, int spaces) {
        StringBuilder sb = new StringBuilder();
        for (int j = 0; j < stars; j++) sb.append('*');
        for (int j = 0; j < spaces; j++) sb.append(' ');
        for (int j = 0; j < stars; j++) sb.append('*');
        return sb.toString();
    }

    public static void pattern19(int n) {
        for (int i = 0; i < n; i++) System.out.println(row(n - i, 2 * i));
        for (int i = 0; i < n; i++) System.out.println(row(i + 1, 2 * (n - i - 1)));
    }
}
```

### Python
```python
def pattern19(n: int) -> None:
    def row(stars: int, spaces: int) -> str:
        return "*" * stars + " " * spaces + "*" * stars

    for i in range(n):
        print(row(n - i, 2 * i))
    for i in range(n):
        print(row(i + 1, 2 * (n - i - 1)))
```

## Key Takeaways
- Hollow symmetric shapes are `stars + spaces + stars` rows; keep the width invariant to stay aligned.
- Factor the row printer into a helper so the upper and lower halves only differ in their arguments.
- The middle row is duplicated here (2n rows); Pattern 20 is the same idea with a shared middle row.
