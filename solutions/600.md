# Kth Missing Positive Number

**Difficulty:** Medium  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on Answers

## Problem
Given a strictly increasing array `arr` of positive integers and an integer `k`, return the k-th positive integer that does not appear in the array.

Input: arr = [2, 3, 4, 7, 11], k = 5
Output: 9  (missing numbers are 1, 5, 6, 8, 9, 10, ... and the 5th is 9)

Input: arr = [1, 2, 3, 4], k = 2
Output: 6

## Approach 1: Walk and Shift
Start with `k` as the candidate answer. Scan the array: every element `<= k` occupies a slot that would otherwise be a missing number, so each such element pushes the answer one further: `k++`. Because the array is sorted, stop as soon as `arr[i] > k`. The final `k` is the answer.
- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Binary Search on Missing Count
For index `i`, the number of positives missing before `arr[i]` is `arr[i] - (i + 1)` (a perfect array would have `i + 1` at index `i`). This count is non-decreasing, so binary search for the first index whose missing count is `>= k`. Let `hi` be the last index where the missing count is `< k` (after the loop, `hi` ends there and `lo = hi + 1`). The answer is then `arr[hi] + (k - missing(hi))`, which simplifies to `hi + 1 + k`, i.e. `lo + k`.
- **Time:** O(log n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int findKthPositive(vector<int>& arr, int k) {
        int lo = 0, hi = (int)arr.size() - 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            int missing = arr[mid] - (mid + 1);
            if (missing < k) lo = mid + 1;
            else hi = mid - 1;
        }
        // lo is the count of elements with missing < k; answer = lo + k
        return lo + k;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def findKthPositive(self, arr: List[int], k: int) -> int:
        lo, hi = 0, len(arr) - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            missing = arr[mid] - (mid + 1)
            if missing < k:
                lo = mid + 1
            else:
                hi = mid - 1
        return lo + k
```

## Key Takeaways
- Key formula: `arr[i] - (i + 1)` = how many positives are missing before `arr[i]`.
- After the search, `lo` counts array elements that lie before the k-th missing number, so the answer is simply `lo + k`.
- If all missing counts are `>= k` (e.g. `arr = [5, 6]`, `k = 2`), `lo` stays 0 and the answer is `k` itself.
- The O(n) shifting approach is a great sanity check and is often accepted too.
