# Right/Left View of Binary Tree

**Difficulty:** Medium  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Medium Problems

## Problem
The right view of a binary tree is the list of nodes you would see standing to the right of it: the rightmost node on every level, top to bottom. The left view is the mirror: the leftmost node of every level. Given the root, return the right view (the left view uses the same idea).

Input: root = [1,2,3,null,5,null,4]
Output: [1,3,4]

Input: root = [1,2,3,4]  (4 is the left child of 2)
Output: [1,3,4]  (level 2 contains only 4, so it is visible from the right)

## Approach 1: Level Order, Take the Last Node per Level
Standard BFS that processes one level at a time. For each level, the last node popped is the rightmost one — record it. For the left view, record the first node of each level instead.

- **Time:** O(n)
- **Space:** O(w), the widest level

## Approach 2: DFS Visiting Right First (Optimal, minimal space)
Do a pre-order traversal that visits the right child before the left, carrying the current depth. The first time you reach a given depth, the node you are standing on is the rightmost node at that depth, so append it. Since `result.size()` equals the number of depths already seen, the check is simply `if depth == result.size()`.

For the left view, visit the left child first instead.
- **Time:** O(n)
- **Space:** O(h) recursion stack — better than BFS on wide, shallow trees

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; ... } — standard definition
class Solution {
    void dfs(TreeNode* node, int depth, vector<int>& res) {
        if (!node) return;
        if (depth == (int)res.size()) res.push_back(node->val);
        dfs(node->right, depth + 1, res);   // right first for the right view
        dfs(node->left,  depth + 1, res);
    }
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> res;
        dfs(root, 0, res);
        return res;
    }
    // Left view: identical, but call dfs on node->left before node->right.
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
import java.util.*;

class Solution {
    private void dfs(TreeNode node, int depth, List<Integer> res) {
        if (node == null) return;
        if (depth == res.size()) res.add(node.val);
        dfs(node.right, depth + 1, res);   // right first for the right view
        dfs(node.left,  depth + 1, res);
    }

    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        dfs(root, 0, res);
        return res;
    }
    // Left view: identical, but recurse into node.left before node.right.
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
class Solution:
    def rightSideView(self, root):
        res = []

        def dfs(node, depth):
            if node is None:
                return
            if depth == len(res):
                res.append(node.val)
            dfs(node.right, depth + 1)   # right first for the right view
            dfs(node.left, depth + 1)

        dfs(root, 0)
        return res

    # Left view: same function with dfs(node.left) called before dfs(node.right).
```

## Key Takeaways
- "First node reached at each depth" with a right-first pre-order gives the right view; swapping the child order gives the left view.
- The visible node on a level is not necessarily a right child — it is whatever node is rightmost on that level.
- Comparing `depth` to the result length avoids a separate visited-depth set.
