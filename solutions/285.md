# Number of Greater Elements to the Right

**Difficulty:** Easy  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Monotonic Stack/Queue Problems [VVV. Imp]

## Problem
You are given an array `arr` and a list of query indices. For each query index `q`, count how many elements to the right of position `q` are strictly greater than `arr[q]`. Return one count per query.

```
Input:  arr = [3, 4, 2, 7, 5, 8, 10, 6], queries = [0, 5]
Output: [6, 1]
```
Index 0 (value 3) has 4, 7, 5, 8, 10, 6 after it — six greater values. Index 5 (value 8) has only 10 after it.

## Approach 1: Brute Force
For each query index, walk to the end of the array and count values larger than `arr[q]`.
- **Time:** O(k · n) for k queries
- **Space:** O(1) extra

## Approach 2: Merge-Sort Counting (Better when many queries)
Count, for every index, the number of larger elements to its right in one shot using a merge-sort pass on (value, index) pairs. During the merge of two sorted halves, when an element from the left half is placed, every remaining element of the right half that is larger than it contributes to its count. Then answer queries by table lookup.
- **Time:** O(n log n + k)
- **Space:** O(n)

Note: the "count of greater elements to the right" is *not* a monotonic-stack problem in the usual sense — a stack only gives you the *nearest* greater element, not how many exist. This is a common misconception; the stack shortcut is wrong here.

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    vector<int> cnt;
    void mergeCount(vector<pair<int,int>>& a, int lo, int hi) {
        if (hi - lo <= 1) return;
        int mid = (lo + hi) / 2;
        mergeCount(a, lo, mid);
        mergeCount(a, mid, hi);
        vector<pair<int,int>> tmp;
        tmp.reserve(hi - lo);
        int i = lo, j = mid;
        // Sort ascending; when placing a left element, all right elements
        // still unplaced are >= it. Count only strictly greater ones.
        while (i < mid && j < hi) {
            if (a[j].first <= a[i].first) tmp.push_back(a[j++]);
            else {
                cnt[a[i].second] += (hi - j);
                tmp.push_back(a[i++]);
            }
        }
        while (i < mid) tmp.push_back(a[i++]);
        while (j < hi) tmp.push_back(a[j++]);
        for (int t = 0; t < (int)tmp.size(); ++t) a[lo + t] = tmp[t];
    }
public:
    vector<int> countGreaterRight(vector<int>& arr, vector<int>& queries) {
        int n = arr.size();
        cnt.assign(n, 0);
        vector<pair<int,int>> a(n);
        for (int i = 0; i < n; ++i) a[i] = {arr[i], i};
        mergeCount(a, 0, n);
        vector<int> ans;
        for (int q : queries) ans.push_back(cnt[q]);
        return ans;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private int[] cnt;

    private void mergeCount(int[][] a, int lo, int hi) {
        if (hi - lo <= 1) return;
        int mid = (lo + hi) / 2;
        mergeCount(a, lo, mid);
        mergeCount(a, mid, hi);
        int[][] tmp = new int[hi - lo][];
        int i = lo, j = mid, t = 0;
        while (i < mid && j < hi) {
            if (a[j][0] <= a[i][0]) tmp[t++] = a[j++];
            else {
                cnt[a[i][1]] += (hi - j);
                tmp[t++] = a[i++];
            }
        }
        while (i < mid) tmp[t++] = a[i++];
        while (j < hi) tmp[t++] = a[j++];
        System.arraycopy(tmp, 0, a, lo, tmp.length);
    }

    public int[] countGreaterRight(int[] arr, int[] queries) {
        int n = arr.length;
        cnt = new int[n];
        int[][] a = new int[n][2];
        for (int i = 0; i < n; i++) { a[i][0] = arr[i]; a[i][1] = i; }
        mergeCount(a, 0, n);
        int[] ans = new int[queries.length];
        for (int i = 0; i < queries.length; i++) ans[i] = cnt[queries[i]];
        return ans;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def countGreaterRight(self, arr: List[int], queries: List[int]) -> List[int]:
        n = len(arr)
        cnt = [0] * n
        a = [(v, i) for i, v in enumerate(arr)]

        def merge_count(lo: int, hi: int) -> None:
            if hi - lo <= 1:
                return
            mid = (lo + hi) // 2
            merge_count(lo, mid)
            merge_count(mid, hi)
            tmp = []
            i, j = lo, mid
            while i < mid and j < hi:
                if a[j][0] <= a[i][0]:
                    tmp.append(a[j]); j += 1
                else:
                    cnt[a[i][1]] += hi - j
                    tmp.append(a[i]); i += 1
            tmp.extend(a[i:mid])
            tmp.extend(a[j:hi])
            a[lo:hi] = tmp

        merge_count(0, n)
        return [cnt[q] for q in queries]
```

## Key Takeaways
- A monotonic stack finds the *nearest* greater element, not the *number* of greater elements; do not confuse the two.
- Per-query brute force is fine for a handful of queries; merge-sort counting precomputes all answers in O(n log n).
- Tie handling matters: place right-half elements first when values are equal so equal values are not counted as greater.
