# Reverse a LL

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
Given the head of a singly linked list, reverse it and return the head of the reversed list. This entry focuses on the recursive formulation, complementing the iterative version covered separately. Nodes must be reused, not copied.

```
Input:  head = 1 -> 2 -> 3
Output: 3 -> 2 -> 1
```

## Approach 1: Iterative three pointers
Walk the list with `prev`/`cur`, flipping each `cur.next` to point at `prev`. At the end `prev` is the new head. This is the most practical solution and uses constant memory.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Recursion (optimal for this entry)
Think of the list as `head -> rest`. If we recursively reverse `rest`, we get a list whose head is the old tail and whose tail is `head.next`. We then attach `head` after that tail:

1. Base case: an empty list or a single node is its own reverse.
2. `newHead = reverse(head.next)`.
3. `head.next.next = head` makes the old second node point back at `head`.
4. `head.next = null` so the original head becomes the tail.
5. Return `newHead`, which is unchanged through every level.

Each call reverses one link, so the recursion depth equals the list length.

- **Time:** O(n)
- **Space:** O(n) for the call stack

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if (!head || !head->next) return head;
        ListNode* newHead = reverseList(head->next);
        head->next->next = head;
        head->next = nullptr;
        return newHead;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } }

class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null || head.next == null) return head;
        ListNode newHead = reverseList(head.next);
        head.next.next = head;
        head.next = null;
        return newHead;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def reverseList(self, head):
        if head is None or head.next is None:
            return head
        new_head = self.reverseList(head.next)
        head.next.next = head
        head.next = None
        return new_head
```

## Key Takeaways
- Recursive reversal: reverse the tail, then hook the current node onto the end with `head.next.next = head`.
- Always clear `head.next` afterward or you create a two-node cycle.
- The recursive version costs O(n) stack; prefer the iterative loop for very long lists.
- Base case covers both empty and single-node lists.
