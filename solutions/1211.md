# Cpp Basics

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Things to Know in C++/Java/Python or any language

## Problem
This topic is a quick tour of the C++ features you will use in every DSA solution: program structure, primitive data types and their ranges, variables, operators, type conversion, and the `bits/stdc++.h` header that pulls in the whole standard library. The goal is to be fluent enough that syntax never slows you down.

Example: declare two integers, compute their sum, product and integer quotient, and print them.

```
Input:  a = 7, b = 2
Output: 9 14 3
```

## Approach: The essentials

**1. Program skeleton.** Every C++ program starts at `main`. Including `<bits/stdc++.h>` and writing `using namespace std;` is standard competitive-programming shorthand.

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << "Hello" << endl;
    return 0;
}
```

**2. Data types and ranges.** Knowing limits prevents overflow bugs.

| Type | Size | Range |
|------|------|-------|
| `int` | 4 bytes | about -2.1e9 to 2.1e9 |
| `long long` | 8 bytes | about -9.2e18 to 9.2e18 |
| `double` | 8 bytes | ~15 significant digits |
| `char` | 1 byte | -128 to 127 (ASCII) |
| `bool` | 1 byte | `true` / `false` |

Rule of thumb: if a value can exceed 10^9, use `long long`.

**3. Operators.** Arithmetic `+ - * / %`, where `/` on two integers truncates toward zero and `%` gives the remainder. Comparison `== != < > <= >=`. Logical `&& || !`. Bitwise `& | ^ ~ << >>`. Compound assignment `+=`, `-=`, and increment `++`/`--`.

**4. Type conversion.** Mixing `int` and `double` promotes to `double`. To force a conversion, cast explicitly: `(double)a / b` gives a fractional quotient. Characters are small integers: `'a' + 1` is `98`, and `c - '0'` turns a digit character into its numeric value.

**5. Constants and references.** `const int MOD = 1e9 + 7;` declares a value that cannot change. `int &r = x;` makes `r` an alias for `x` (used heavily when passing arrays to functions).

**6. Common containers (preview of STL).** `vector<int> v(n)`, `string s`, `pair<int,int> p`, `map<int,int> m`, `set<int> st`. Access with `v[i]`, size with `v.size()`.

- **Time:** O(1) for all basic operations shown
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a = 7, b = 2;
    int sum = a + b;
    int prod = a * b;
    int quot = a / b;          // integer division -> 3
    int rem = a % b;           // remainder -> 1
    double exact = (double)a / b;   // 3.5

    long long big = 1LL * a * 1000000000LL;  // 1LL avoids int overflow
    char c = 'a' + 1;          // 'b'
    int digit = '7' - '0';     // 7

    cout << sum << " " << prod << " " << quot << " " << rem << "\n";
    cout << fixed << setprecision(2) << exact << "\n";
    cout << big << " " << c << " " << digit << "\n";
    return 0;
}
```

### Java
```java
public class Main {
    public static void main(String[] args) {
        int a = 7, b = 2;
        int sum = a + b;
        int prod = a * b;
        int quot = a / b;          // 3
        int rem = a % b;           // 1
        double exact = (double) a / b;   // 3.5

        long big = (long) a * 1000000000L;
        char c = (char) ('a' + 1); // 'b'
        int digit = '7' - '0';     // 7

        System.out.println(sum + " " + prod + " " + quot + " " + rem);
        System.out.printf("%.2f%n", exact);
        System.out.println(big + " " + c + " " + digit);
    }
}
```

### Python
```python
def main():
    a, b = 7, 2
    total = a + b
    prod = a * b
    quot = a // b          # floor division -> 3
    rem = a % b            # 1
    exact = a / b          # 3.5 (true division)

    big = a * 10**9        # Python ints never overflow
    c = chr(ord('a') + 1)  # 'b'
    digit = ord('7') - ord('0')  # 7

    print(total, prod, quot, rem)
    print(f"{exact:.2f}")
    print(big, c, digit)

if __name__ == "__main__":
    main()
```

## Key Takeaways
- `int` holds up to about 2.1e9; switch to `long long` (Java `long`) beyond that, and multiply with `1LL *` to avoid overflow mid-expression.
- Integer division truncates in C++/Java (`7/2 == 3`); Python `/` is true division and `//` is floor division.
- Characters are integers underneath: `ch - '0'` converts a digit char, `ch - 'a'` gives a 0-based letter index.
- `#include <bits/stdc++.h>` and `using namespace std;` save typing in practice but are non-standard; prefer specific headers in production code.
