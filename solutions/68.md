# Search in 2D matrix - II

**Difficulty:** Hard  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on 2D Arrays

## Problem
You are given an `n x m` matrix in which every row is sorted left to right and every column is sorted top to bottom (rows may overlap in range). Return `true` if `target` exists in the matrix, otherwise `false`.

Input: matrix = [[1, 4, 7, 11], [2, 5, 8, 12], [3, 6, 9, 16], [10, 13, 14, 17]], target = 5
Output: true

Input: same matrix, target = 20
Output: false

## Approach 1: Scan Everything
Check each cell. Correct but ignores the ordering.
- **Time:** O(n * m)
- **Space:** O(1)

## Approach 2: Binary Search Every Row
Each row is sorted, so binary search `target` in every row independently. Better, but the column order is still unused.
- **Time:** O(n * log m)
- **Space:** O(1)

## Approach 3: Staircase Search from the Top-Right
Start at the top-right cell `(0, m - 1)`. Every element to its left is smaller and every element below it is larger, so:
- If the cell equals `target`, done.
- If the cell is larger than `target`, the whole column below it is too big: move left.
- If the cell is smaller, the whole row to its left is too small: move down.

Each step eliminates a full row or column, so the walk takes at most `n + m` steps. Starting from the bottom-left corner works symmetrically.
- **Time:** O(n + m)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int n = matrix.size();
        if (n == 0 || matrix[0].empty()) return false;
        int m = matrix[0].size();
        int r = 0, c = m - 1;
        while (r < n && c >= 0) {
            int val = matrix[r][c];
            if (val == target) return true;
            if (val > target) c--;
            else r++;
        }
        return false;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False
        n, m = len(matrix), len(matrix[0])
        r, c = 0, m - 1
        while r < n and c >= 0:
            val = matrix[r][c]
            if val == target:
                return True
            if val > target:
                c -= 1
            else:
                r += 1
        return False
```

## Key Takeaways
- The top-right (or bottom-left) corner is the only place where one comparison rules out an entire row *or* column.
- Never start at the top-left or bottom-right: both directions from those corners increase (or decrease), so nothing can be eliminated.
- This is not a binary search but the standard answer for row-and-column sorted matrices; the flattened trick from "Search in a 2D Matrix" does not apply here.
