# Merge Sorting

**Difficulty:** Medium  ·  **Topic:** Learn Important Sorting Techniques › Sorting-II

## Problem
Given an array of `n` integers, sort it in non-decreasing order using merge sort. Implement the standard divide-and-conquer version: split, sort the halves recursively, then merge.

Input: `arr = [4, 2, 1, 6, 7]`
Output: `[1, 2, 4, 6, 7]`

## Approach 1: Merge Sort (Divide and Conquer)
Merge sort relies on one observation: merging two already-sorted lists into one sorted list takes linear time using two pointers. So:

1. **Divide**: split the range `[low, high]` at `mid = low + (high - low) / 2`.
2. **Conquer**: recursively sort `[low, mid]` and `[mid+1, high]`. A range of length one is trivially sorted, which is the base case.
3. **Combine**: merge the two sorted halves. Keep pointers `i` and `j` at the start of each half, always copy the smaller of `arr[i]` and `arr[j]` into a temporary buffer, then append whatever is left, and finally copy the buffer back into `arr[low..high]`.

The recursion tree has `log n` levels and every level does O(n) work in merging, giving O(n log n) regardless of the input order. Using `<=` when comparing the two heads keeps equal elements from the left half first, so the sort is stable.

- **Time:** O(n log n) in every case.
- **Space:** O(n) for the temporary merge buffer plus O(log n) recursion stack.

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    void merge(vector<int>& arr, int low, int mid, int high) {
        vector<int> temp;
        temp.reserve(high - low + 1);
        int i = low, j = mid + 1;
        while (i <= mid && j <= high) {
            if (arr[i] <= arr[j]) temp.push_back(arr[i++]);
            else temp.push_back(arr[j++]);
        }
        while (i <= mid) temp.push_back(arr[i++]);
        while (j <= high) temp.push_back(arr[j++]);
        for (int k = 0; k < (int)temp.size(); k++) arr[low + k] = temp[k];
    }

    void mergeSortRec(vector<int>& arr, int low, int high) {
        if (low >= high) return;
        int mid = low + (high - low) / 2;
        mergeSortRec(arr, low, mid);
        mergeSortRec(arr, mid + 1, high);
        merge(arr, low, mid, high);
    }

public:
    vector<int> mergeSort(vector<int>& arr) {
        if (!arr.empty()) mergeSortRec(arr, 0, arr.size() - 1);
        return arr;
    }
};
```

### Java
```java
class Solution {
    private void merge(int[] arr, int low, int mid, int high) {
        int[] temp = new int[high - low + 1];
        int i = low, j = mid + 1, k = 0;
        while (i <= mid && j <= high) {
            if (arr[i] <= arr[j]) temp[k++] = arr[i++];
            else temp[k++] = arr[j++];
        }
        while (i <= mid) temp[k++] = arr[i++];
        while (j <= high) temp[k++] = arr[j++];
        for (int t = 0; t < temp.length; t++) arr[low + t] = temp[t];
    }

    private void mergeSortRec(int[] arr, int low, int high) {
        if (low >= high) return;
        int mid = low + (high - low) / 2;
        mergeSortRec(arr, low, mid);
        mergeSortRec(arr, mid + 1, high);
        merge(arr, low, mid, high);
    }

    public int[] mergeSort(int[] arr) {
        if (arr.length > 0) mergeSortRec(arr, 0, arr.length - 1);
        return arr;
    }
}
```

### Python
```python
class Solution:
    def mergeSort(self, arr: list[int]) -> list[int]:
        def merge(low: int, mid: int, high: int) -> None:
            temp = []
            i, j = low, mid + 1
            while i <= mid and j <= high:
                if arr[i] <= arr[j]:
                    temp.append(arr[i]); i += 1
                else:
                    temp.append(arr[j]); j += 1
            temp.extend(arr[i:mid + 1])
            temp.extend(arr[j:high + 1])
            arr[low:high + 1] = temp

        def rec(low: int, high: int) -> None:
            if low >= high:
                return
            mid = (low + high) // 2
            rec(low, mid)
            rec(mid + 1, high)
            merge(low, mid, high)

        if arr:
            rec(0, len(arr) - 1)
        return arr
```

## Key Takeaways
- The merge step is the heart of the algorithm: two sorted halves become one sorted range in linear time with two pointers.
- Guaranteed O(n log n) even on adversarial input, unlike quick sort; the price is O(n) extra memory.
- Use `<=` in the merge comparison to keep the sort stable.
- Edge cases: `low >= high` handles empty and single-element ranges; compute `mid` as `low + (high - low) / 2` to avoid overflow in C++/Java.
