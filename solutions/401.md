# Pattern 1

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a solid square made of stars: `n` rows, each containing `n` stars separated by a single space. This is the simplest nested-loop exercise and the foundation for every other pattern in this section.

Input: `n = 5`
Output:
```
* * * * *
* * * * *
* * * * *
* * * * *
* * * * *
```

## Approach
Every pattern problem is solved the same way: the outer loop counts rows, the inner loop decides what goes in each column of that row, and a newline is printed after the inner loop finishes.

1. Outer loop `i` runs from `0` to `n-1` (one iteration per row).
2. Inner loop `j` runs from `0` to `n-1` and prints `"* "` each time.
3. After the inner loop, print a newline to move to the next row.

Because the number of stars does not depend on the row index, the inner loop bound is a constant `n`.

- **Time:** O(n²) — we print n·n characters.
- **Space:** O(1) — nothing is stored besides loop counters.

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern1(int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            cout << "* ";
        }
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern1 {
    public static void pattern1(int n) {
        for (int i = 0; i < n; i++) {
            StringBuilder row = new StringBuilder();
            for (int j = 0; j < n; j++) {
                row.append("* ");
            }
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern1(n: int) -> None:
    for _ in range(n):
        print("* " * n)
```

## Key Takeaways
- Outer loop = rows, inner loop = columns; the newline always goes after the inner loop.
- When the inner bound is constant, the shape is a rectangle/square.
- Trailing spaces are usually accepted by judges for these problems, but check the expected format if a strict comparison is used.
