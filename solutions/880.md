# Count all subsequences with sum K

**Difficulty:** Easy  ·  **Topic:** Recursion [PatternWise] › Subsequences Pattern

## Problem
Given an array of integers `arr` and a target `k`, return how many subsequences of `arr` have elements that sum to exactly `k`. A subsequence is formed by deleting zero or more elements without reordering the rest. Different index choices count as different subsequences even if they contain the same values.

Input: `arr = [1, 2, 1]`, `k = 2`
Output: `2` (subsequences `[2]` and `[1, 1]`)

Input: `arr = [1, 1, 1]`, `k = 2`
Output: `3`

## Approach 1: Generate every subsequence and check
Enumerate all `2^n` subsequences (recursion or bitmask), compute each one's sum, and increment a counter when it equals `k`. Straightforward, but building each subsequence explicitly costs O(n) per leaf.
- **Time:** O(2^n · n)
- **Space:** O(n)

## Approach 2: Recursion that returns a count
Apply the take/not-take recursion but carry only the running sum, and make the function return the number of valid subsequences in its subtree:

1. Base case `i == n`: return `1` if `sum == k`, else `0`.
2. Return `count(i + 1, sum + arr[i]) + count(i + 1, sum)`.

Nothing is stored, and the addition of the two branch results is the whole logic. If all elements are non-negative, an extra pruning `if (sum > k) return 0;` cuts off hopeless branches early. (For large `n` this becomes the classic subset-sum DP with memoisation on `(i, sum)`.)
- **Time:** O(2^n)
- **Space:** O(n) recursion depth

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    int count(int i, long long sum, const vector<int>& arr, int k) {
        if (i == (int)arr.size()) return sum == k ? 1 : 0;
        return count(i + 1, sum + arr[i], arr, k) + count(i + 1, sum, arr, k);
    }
public:
    int countSubsequencesWithSumK(vector<int>& arr, int k) {
        return count(0, 0, arr, k);
    }
};
```

### Java
```java
class Solution {
    private int count(int i, long sum, int[] arr, int k) {
        if (i == arr.length) return sum == k ? 1 : 0;
        return count(i + 1, sum + arr[i], arr, k) + count(i + 1, sum, arr, k);
    }

    public int countSubsequencesWithSumK(int[] arr, int k) {
        return count(0, 0L, arr, k);
    }
}
```

### Python
```python
from typing import List

class Solution:
    def countSubsequencesWithSumK(self, arr: List[int], k: int) -> int:
        def count(i: int, s: int) -> int:
            if i == len(arr):
                return 1 if s == k else 0
            return count(i + 1, s + arr[i]) + count(i + 1, s)

        return count(0, 0)
```

## Key Takeaways
- Counting problems: return an int from the recursion and add the results of the branches.
- Carrying the running sum avoids re-summing the buffer at each leaf.
- Prune with `sum > k` only when every element is non-negative; with negatives the sum can come back down.
- The empty subsequence counts when `k == 0`; the base case handles it automatically.
