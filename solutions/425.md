# Input Output

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Things to Know in C++/Java/Python or any language

## Problem
This topic covers how a program reads data from standard input and writes results to standard output. Almost every DSA problem follows the same shape: read one or more values (numbers, strings, arrays), compute something, and print the answer. You need to know the idiomatic way to do this in C++, Java, and Python, and how to handle whitespace and multi-line input.

Example task: read an integer `n`, then read `n` integers, and print their sum.

```
Input:
3
4 5 6
Output:
15
```

## Approach: How standard I/O works in each language

**C++.** `cin` reads whitespace-separated tokens and `cout` writes them. `cin >> x` skips leading spaces and newlines, so reading numbers spread across several lines needs no special handling. To read a whole line including spaces use `getline(cin, s)`. Adding `ios::sync_with_stdio(false); cin.tie(nullptr);` at the top of `main` speeds up I/O noticeably when the input is large (10^5+ tokens).

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n; cin >> n;
    long long sum = 0;
    for (int i = 0; i < n; i++) { int x; cin >> x; sum += x; }
    cout << sum << '\n';
    string line; getline(cin >> ws, line);   // read a full line with spaces
}
```

**Java.** `Scanner` is the simplest reader: `nextInt()`, `nextLong()`, `next()` (one token), `nextLine()` (rest of line). Be careful mixing `nextInt()` and `nextLine()` — after `nextInt()` the newline is still buffered, so call `nextLine()` once to discard it. For heavy input use `BufferedReader` + `StringTokenizer`.

```java
import java.util.*;
import java.io.*;
public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        StringTokenizer st = new StringTokenizer(br.readLine());
        long sum = 0;
        for (int i = 0; i < n; i++) sum += Integer.parseInt(st.nextToken());
        System.out.println(sum);
    }
}
```

**Python.** `input()` returns one line as a string. Convert with `int(...)` or split into a list with `.split()`. For many lines, `sys.stdin.readline` is faster than `input()`. `print` adds a newline by default; use `end=""` to suppress it.

```python
import sys
n = int(input())
nums = list(map(int, sys.stdin.readline().split()))
print(sum(nums))
```

- **Time:** O(k) where k is the number of tokens read/written
- **Space:** O(k) if the input is stored, O(1) if processed on the fly

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        sum += x;
    }
    cout << sum << '\n';
    return 0;
}
```

### Java
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long sum = 0;
        for (int i = 0; i < n; i++) {
            sum += sc.nextInt();
        }
        System.out.println(sum);
        sc.close();
    }
}
```

### Python
```python
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    nums = list(map(int, data[1:1 + n]))
    print(sum(nums))

if __name__ == "__main__":
    main()
```

## Key Takeaways
- Token-based readers (`cin`, `Scanner.nextInt`, `split()`) ignore line breaks; line-based readers (`getline`, `nextLine`, `input`) do not.
- Use fast I/O (`sync_with_stdio(false)`, `BufferedReader`, `sys.stdin`) when input exceeds roughly 10^5 tokens.
- Use `long long` / `long` for sums that can overflow 32-bit integers.
- Always end output with a newline; judges compare output exactly.
