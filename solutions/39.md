# Left Rotate Array by K Places

**Difficulty:** Easy  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Easy

## Problem
Given an array of `n` integers and a non-negative integer `k`, rotate the array to the left by `k` positions in place. The first `k` elements wrap around to the end. `k` can be larger than `n`. (LeetCode's "Rotate Array" asks for a **right** rotation by `k`; the same technique applies with the reversal boundaries swapped, and both are shown below.)

Input: `arr = [1, 2, 3, 4, 5, 6, 7], k = 2`
Output: `[3, 4, 5, 6, 7, 1, 2]`

## Approach 1: Rotate by One, k Times
Apply the "rotate by one" routine `k` times. Works but wasteful.

- **Time:** O(n · k)
- **Space:** O(1)

## Approach 2: Temporary Buffer
Reduce `k` to `k mod n`. Copy the first `k` elements into a temp array, shift the remaining `n-k` elements to the front, then copy the temp elements into the last `k` slots.

- **Time:** O(n)
- **Space:** O(k)

## Approach 3: Three Reversals (Optimal)
Reversing a block of the array flips its order; reversing it again restores it. A left rotation by `k` is the same as:

1. Reverse the first `k` elements: `[1,2 | 3,4,5,6,7]` → `[2,1 | 3,4,5,6,7]`
2. Reverse the remaining `n-k` elements: `[2,1 | 7,6,5,4,3]`
3. Reverse the whole array: `[3,4,5,6,7,1,2]`

Step 3 undoes the internal reversal of each block while swapping the two blocks' positions, which is exactly a rotation. Always take `k mod n` first so large `k` values are handled and `k == n` becomes a no-op.

For a **right** rotation by `k`, reverse the whole array first, then reverse `[0, k-1]` and `[k, n-1]` — or equivalently do a left rotation by `n - k`.

- **Time:** O(n) — each element is touched at most twice.
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    // Left rotation by k (sheet version)
    vector<int> rotateLeft(vector<int>& arr, int k) {
        int n = arr.size();
        if (n == 0) return arr;
        k %= n;
        reverse(arr.begin(), arr.begin() + k);
        reverse(arr.begin() + k, arr.end());
        reverse(arr.begin(), arr.end());
        return arr;
    }

    // Right rotation by k (LeetCode 189 signature)
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        if (n == 0) return;
        k %= n;
        reverse(nums.begin(), nums.end());
        reverse(nums.begin(), nums.begin() + k);
        reverse(nums.begin() + k, nums.end());
    }
};
```

### Java
```java
class Solution {
    private void reverse(int[] a, int l, int r) {
        while (l < r) {
            int tmp = a[l]; a[l] = a[r]; a[r] = tmp;
            l++; r--;
        }
    }

    // Left rotation by k (sheet version)
    public int[] rotateLeft(int[] arr, int k) {
        int n = arr.length;
        if (n == 0) return arr;
        k %= n;
        reverse(arr, 0, k - 1);
        reverse(arr, k, n - 1);
        reverse(arr, 0, n - 1);
        return arr;
    }

    // Right rotation by k (LeetCode 189 signature)
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        if (n == 0) return;
        k %= n;
        reverse(nums, 0, n - 1);
        reverse(nums, 0, k - 1);
        reverse(nums, k, n - 1);
    }
}
```

### Python
```python
class Solution:
    @staticmethod
    def _reverse(a: list[int], l: int, r: int) -> None:
        while l < r:
            a[l], a[r] = a[r], a[l]
            l += 1
            r -= 1

    # Left rotation by k (sheet version)
    def rotateLeft(self, arr: list[int], k: int) -> list[int]:
        n = len(arr)
        if n == 0:
            return arr
        k %= n
        self._reverse(arr, 0, k - 1)
        self._reverse(arr, k, n - 1)
        self._reverse(arr, 0, n - 1)
        return arr

    # Right rotation by k (LeetCode 189 signature)
    def rotate(self, nums: list[int], k: int) -> None:
        n = len(nums)
        if n == 0:
            return
        k %= n
        self._reverse(nums, 0, n - 1)
        self._reverse(nums, 0, k - 1)
        self._reverse(nums, k, n - 1)
```

## Key Takeaways
- The reversal trick rotates in O(n) time and O(1) space: reverse the two blocks, then reverse everything.
- Always reduce `k` with `k % n` first; otherwise the reversal indices go out of range.
- Left rotation by `k` equals right rotation by `n - k`; the only difference is which reversal comes first.
