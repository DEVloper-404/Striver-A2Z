# Search in Linked List

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Learn 1D LinkedList

## Problem
Given the head of a singly linked list and a target value, determine whether some node holds that value. Return `true`/`false` (a common variant asks for the 0-based position, or `-1` if absent; both are shown).

Input: `head = 4 -> 1 -> 7 -> 3, key = 7`
Output: `true` (position 2)

Input: `head = 4 -> 1 -> 7 -> 3, key = 9`
Output: `false` (position -1)

## Approach 1: Recursive search
If the list is empty, the key is absent. Otherwise, either the head holds the key or the key is in the rest of the list. Concise, but each node adds a stack frame.
- **Time:** O(n)
- **Space:** O(n) call stack

## Approach 2: Linear traversal (Optimal)
Walk from the head, comparing each node's value to the key. Return as soon as a match is found; if the walk reaches `null`, the key is not present. Because a singly linked list offers no random access and no ordering guarantee, every node may need to be inspected, so linear time is the best possible.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int v) : val(v), next(nullptr) {} };
// (standard definition)

class Solution {
public:
    bool searchKey(ListNode* head, int key) {
        for (ListNode* cur = head; cur != nullptr; cur = cur->next) {
            if (cur->val == key) return true;
        }
        return false;
    }

    // Variant: return 0-based index of the first match, or -1.
    int indexOfKey(ListNode* head, int key) {
        int idx = 0;
        for (ListNode* cur = head; cur != nullptr; cur = cur->next, ++idx) {
            if (cur->val == key) return idx;
        }
        return -1;
    }
};
```

### Python
```python
from typing import Optional

# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
# (standard definition)

class Solution:
    def searchKey(self, head: Optional["ListNode"], key: int) -> bool:
        cur = head
        while cur:
            if cur.val == key:
                return True
            cur = cur.next
        return False

    # Variant: return 0-based index of the first match, or -1.
    def indexOfKey(self, head: Optional["ListNode"], key: int) -> int:
        idx = 0
        cur = head
        while cur:
            if cur.val == key:
                return idx
            cur = cur.next
            idx += 1
        return -1
```

## Key Takeaways
- Linked-list search is a linear walk; there is no binary search without random access.
- Return early on the first match to avoid unnecessary traversal.
- An empty list returns `false` / `-1` naturally because the loop body never runs.
- If you need the position, carry an index alongside the pointer.
