# Upper Bound

**Difficulty:** Easy  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on 1D Arrays

## Problem
Given a sorted array `arr` of size `n` and an integer `x`, return the upper bound of `x`: the smallest index `i` such that `arr[i] > x` (strictly greater). If no element is greater than `x`, return `n`.

Input: `arr = [1, 2, 4, 4, 7, 9], x = 4`
Output: `4` (index of 7, the first value strictly greater than 4)

Input: `arr = [1, 2, 4, 4, 7, 9], x = 0`
Output: `0`

## Approach 1: Linear Scan
Iterate from index 0 and return the first index where `arr[i] > x`; return `n` if none is found.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Binary Search (Optimal)
Exactly the same shape as lower bound, but the predicate is `arr[mid] > x` instead of `>=`. In a sorted array this predicate is false for a prefix and true for a suffix, so binary search can locate the first true index:

1. Set `ans = n`, `low = 0`, `high = n - 1`.
2. If `arr[mid] > x`, `mid` could be the answer: store it and try the left half (`high = mid - 1`).
3. Otherwise `arr[mid] <= x`; the answer must be to the right (`low = mid + 1`).
4. Return `ans` once the range closes.

- **Time:** O(log n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int upperBound(vector<int>& arr, int x) {
        int n = arr.size();
        int low = 0, high = n - 1, ans = n;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (arr[mid] > x) {
                ans = mid;
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        return ans;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def upperBound(self, arr: List[int], x: int) -> int:
        n = len(arr)
        low, high, ans = 0, n - 1, n
        while low <= high:
            mid = (low + high) // 2
            if arr[mid] > x:
                ans = mid
                high = mid - 1
            else:
                low = mid + 1
        return ans
```

## Key Takeaways
- Upper bound differs from lower bound by a single character in the comparison (`>` versus `>=`); keep the two straight.
- `upperBound(x) - lowerBound(x)` is the number of times `x` occurs in the array, and `upperBound(x) - 1` is the last index of `x` when it exists.
- The answer defaults to `n`, which correctly covers the case where `x` is greater than or equal to every element.
- Library equivalents: `std::upper_bound` in C++ and `bisect.bisect_right` in Python.
