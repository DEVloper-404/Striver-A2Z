# Count number of Nice subarrays

**Difficulty:** Hard  ·  **Topic:** Sliding Window & Two Pointer Combined Problems › Medium Problems

## Problem
A subarray is *nice* if it contains exactly `k` odd numbers. Given an integer array `nums` and `k`, return the number of nice contiguous subarrays.

Input: `nums = [1,1,2,1,1], k = 3`
Output: `2` (`[1,1,2,1]` and `[1,2,1,1]`)

## Approach 1: Brute Force
For every start index count odd numbers going right; whenever the count equals `k` increment the answer, and stop once it exceeds `k`.

- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Prefix Count + Hash Map
Convert each element to `1` if odd, `0` if even. The task becomes "count subarrays with sum k", solvable with a prefix-sum frequency map: at each index with prefix `p`, add `freq[p - k]` to the answer.

- **Time:** O(n)
- **Space:** O(n)

## Approach 3: Sliding Window "At Most" Trick (Optimal)
After the odd/even transformation this is identical to Binary Subarrays With Sum. Counting windows with **at most** `k` odds is a standard window: for each `r`, shrink `l` while the odd count exceeds `k`, then add `r - l + 1`. Then subtract: `exactly(k) = atMost(k) - atMost(k - 1)`.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    int atMost(const vector<int>& nums, int k) {
        if (k < 0) return 0;
        int l = 0, odds = 0, count = 0;
        for (int r = 0; r < (int)nums.size(); ++r) {
            odds += nums[r] & 1;
            while (odds > k) odds -= nums[l++] & 1;
            count += r - l + 1;
        }
        return count;
    }
public:
    int numberOfSubarrays(vector<int>& nums, int k) {
        return atMost(nums, k) - atMost(nums, k - 1);
    }
};
```

### Python
```python
from typing import List

class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        def at_most(m: int) -> int:
            if m < 0:
                return 0
            l = 0
            odds = 0
            count = 0
            for r, v in enumerate(nums):
                odds += v & 1
                while odds > m:
                    odds -= nums[l] & 1
                    l += 1
                count += r - l + 1
            return count

        return at_most(k) - at_most(k - 1)
```

## Key Takeaways
- Map "odd" to 1 and "even" to 0; the problem is then a binary-sum count.
- The at-most subtraction trick turns an awkward "exactly" count into two easy monotone windows.
- `k >= 1` per constraints, but guarding `k - 1 < 0` keeps the helper safe.
