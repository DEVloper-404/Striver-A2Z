# Job sequencing Problem

**Difficulty:** Medium  ·  **Topic:** Greedy Algorithms [Easy, Medium/Hard] › Medium/Hard

## Problem
You have `n` jobs, each with a deadline `deadline[i]` (a day number, 1-based) and a profit `profit[i]`. Every job takes exactly one day and only one job can be done per day. A job earns its profit only if it is finished on or before its deadline. Return the maximum number of jobs you can complete and the maximum total profit.

Input: `deadline = [4, 1, 1, 1]`, `profit = [20, 10, 40, 30]`
Output: `[2, 60]` (do job 3 on day 1 and job 1 on any day up to 4)

## Approach 1: Brute Force
Try every ordering / subset of jobs, assign each job to the earliest free day not after its deadline, and keep the best profit. Exponential.
- **Time:** O(n! ) or O(2^n · n)
- **Space:** O(n)

## Approach 2: Greedy by profit with latest free slot (Optimal)
Key observation: high-profit jobs should be considered first, and each should be scheduled as **late as possible** (on the last free day ≤ its deadline) so that earlier days stay open for jobs with tighter deadlines.

1. Sort jobs by profit descending.
2. Let `maxDeadline` be the largest deadline; create a `slot[1..maxDeadline]` array initialised to "free".
3. For each job in sorted order, scan from `deadline` down to `1`; the first free slot gets this job. If none is free, skip the job.
4. Count the scheduled jobs and sum their profit.

- **Time:** O(n log n + n · maxDeadline)
- **Space:** O(maxDeadline)

(A DSU over days can reduce the slot search to near O(1), giving O(n log n) overall, but the simple scan is what interviews usually expect.)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    // returns {number of jobs done, total profit}
    vector<int> jobSequencing(vector<int>& deadline, vector<int>& profit) {
        int n = deadline.size();
        vector<pair<int,int>> jobs(n);            // {profit, deadline}
        int maxD = 0;
        for (int i = 0; i < n; i++) {
            jobs[i] = {profit[i], deadline[i]};
            maxD = max(maxD, deadline[i]);
        }
        sort(jobs.rbegin(), jobs.rend());         // profit descending

        vector<bool> used(maxD + 1, false);
        int count = 0, total = 0;
        for (auto& j : jobs) {
            for (int d = j.second; d >= 1; d--) {
                if (!used[d]) {
                    used[d] = true;
                    count++;
                    total += j.first;
                    break;
                }
            }
        }
        return {count, total};
    }
};
```

### Java

```java
import java.util.*;

class Solution {
    // returns {number of jobs done, total profit}
    public int[] jobSequencing(int[] deadline, int[] profit) {
        int n = deadline.length;
        int[][] jobs = new int[n][2];             // {profit, deadline}
        int maxD = 0;
        for (int i = 0; i < n; i++) {
            jobs[i][0] = profit[i];
            jobs[i][1] = deadline[i];
            maxD = Math.max(maxD, deadline[i]);
        }
        Arrays.sort(jobs, (a, b) -> Integer.compare(b[0], a[0]));

        boolean[] used = new boolean[maxD + 1];
        int count = 0, total = 0;
        for (int[] j : jobs) {
            for (int d = j[1]; d >= 1; d--) {
                if (!used[d]) {
                    used[d] = true;
                    count++;
                    total += j[0];
                    break;
                }
            }
        }
        return new int[]{count, total};
    }
}
```

### Python
```python
from typing import List

class Solution:
    def jobSequencing(self, deadline: List[int], profit: List[int]) -> List[int]:
        jobs = sorted(zip(profit, deadline), reverse=True)
        max_d = max(deadline) if deadline else 0
        used = [False] * (max_d + 1)
        count = total = 0
        for p, d in jobs:
            for day in range(d, 0, -1):
                if not used[day]:
                    used[day] = True
                    count += 1
                    total += p
                    break
        return [count, total]
```

## Key Takeaways
- Two greedy ideas combine: pick jobs by profit descending, and place each in the **latest** free slot before its deadline.
- Placing a job earlier than necessary can block a job with a smaller deadline; that is why we scan downward.
- Deadlines are 1-based days; size the slot array as `maxDeadline + 1` and ignore index 0.
