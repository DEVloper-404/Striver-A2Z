# Implement Stack using Queue

**Difficulty:** Easy  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Learning

## Problem
Implement a LIFO stack using only standard queue operations (`push` to back, `pop`/`peek` from front, `size`, `empty`). Support `push(x)`, `pop()`, `top()` and `empty()`.

Input: `push(1), push(2), top(), pop(), empty()`
Output: `2, 2, false`

## Approach 1: Two queues (costly pop)
Push always goes into `q1`. To pop, move all but the last element of `q1` into `q2`, take the remaining element, then swap the queue names. Push is O(1), pop/top are O(n).
- **Time:** O(1) push, O(n) pop/top
- **Space:** O(n)

## Approach 2: Optimal (single queue, rotate on push)
Keep one queue whose front is always the most recently pushed element. After enqueuing a new value `x`, rotate the queue: pop the front and push it to the back `size - 1` times. This moves `x` from the back to the front while preserving the relative order of everything else.

Then `pop()` and `top()` are just the queue's front operations, and `empty()` is the queue's empty check.
- **Time:** O(n) push, O(1) pop/top/empty
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <queue>
using namespace std;

class MyStack {
    queue<int> q;
public:
    void push(int x) {
        q.push(x);
        int rotations = (int)q.size() - 1;
        while (rotations-- > 0) {
            q.push(q.front());
            q.pop();
        }
    }
    int pop() {
        int val = q.front();
        q.pop();
        return val;
    }
    int top() { return q.front(); }
    bool empty() { return q.empty(); }
};
```

### Java
```java
import java.util.*;

class MyStack {
    private final Queue<Integer> q = new ArrayDeque<>();

    public void push(int x) {
        q.offer(x);
        int rotations = q.size() - 1;
        while (rotations-- > 0) q.offer(q.poll());
    }
    public int pop() { return q.poll(); }
    public int top() { return q.peek(); }
    public boolean empty() { return q.isEmpty(); }
}
```

### Python
```python
from collections import deque

class MyStack:
    def __init__(self):
        self.q = deque()

    def push(self, x: int) -> None:
        self.q.append(x)
        for _ in range(len(self.q) - 1):
            self.q.append(self.q.popleft())

    def pop(self) -> int:
        return self.q.popleft()

    def top(self) -> int:
        return self.q[0]

    def empty(self) -> bool:
        return not self.q
```

## Key Takeaways
- Rotating the queue after each push keeps the newest element at the front, so pop and top become trivial.
- You choose which side pays: O(n) push with O(1) pop (this solution), or O(1) push with O(n) pop (two-queue version).
- Only queue primitives are used; never index into the middle.
- Standard callers guarantee `pop`/`top` are not called on an empty stack.
