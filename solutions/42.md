# Maximum Consecutive Ones

**Difficulty:** Easy  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Easy

## Problem
Given a binary array `nums` containing only `0`s and `1`s, return the length of the longest run of consecutive `1`s.

Input: `nums = [1, 1, 0, 1, 1, 1]`
Output: `3`

Input: `nums = [0, 0]`
Output: `0`

## Approach 1: Single Pass with a Running Counter
A run of ones is broken only by a zero, so a single scan is enough:

1. Keep `cur`, the length of the run of ones ending at the current index, and `best`, the longest run seen so far.
2. On a `1`, increment `cur` and update `best = max(best, cur)`.
3. On a `0`, reset `cur` to `0`.

Updating `best` inside the `1` branch (rather than only on zeros) means a run that reaches the end of the array is counted without a post-loop fix-up. Checking every element once is unavoidable, so this is optimal.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findMaxConsecutiveOnes(vector<int>& nums) {
        int cur = 0, best = 0;
        for (int x : nums) {
            if (x == 1) {
                cur++;
                best = max(best, cur);
            } else {
                cur = 0;
            }
        }
        return best;
    }
};
```

### Python
```python
class Solution:
    def findMaxConsecutiveOnes(self, nums: list[int]) -> int:
        cur = best = 0
        for x in nums:
            if x == 1:
                cur += 1
                best = max(best, cur)
            else:
                cur = 0
        return best
```

## Key Takeaways
- "Longest run of X" is a running-counter pattern: extend on match, reset on mismatch, track the max.
- Update the maximum as you extend, so a run ending at the last index is not missed.
- Edge cases: no ones at all returns `0`; an all-ones array returns `n`.
