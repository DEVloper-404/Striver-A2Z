# Articulation point in graph

**Difficulty:** Hard  ·  **Topic:** Graphs [Concepts & Problems] › Other Algorithms

## Problem
Given an undirected connected graph with `V` vertices and a list of edges, find all **articulation points** (also called cut vertices). A vertex is an articulation point if deleting it — together with every edge touching it — increases the number of connected components, i.e. it splits the graph. Return the vertices in sorted order (or `{-1}` if there are none).

```
Input:  V = 5, edges = [[0,1],[1,2],[2,0],[1,3],[3,4]]
Output: [1, 3]
```
Removing vertex `1` isolates the pair `{3,4}` from `{0,2}`; removing vertex `3` isolates vertex `4`.

## Approach 1: Brute force — remove each vertex and re-check connectivity
The definition can be tested directly. For every vertex `u` from `0` to `V-1`, pretend `u` is deleted, then run a BFS/DFS from any surviving vertex and count how many vertices it reaches. If some surviving vertex is unreachable, the graph broke apart, so `u` is an articulation point.

This is easy to get right and is a good mental model, but each of the `V` trials costs a full traversal.
- **Time:** O(V · (V + E))
- **Space:** O(V + E)

## Approach 2: Tarjan's low-link DFS (Optimal)

**The key observation.** Run one DFS and look at the resulting DFS tree. Every non-tree edge of an undirected graph is a *back edge* — it always points from a descendant up to an ancestor (cross edges cannot exist in undirected DFS). So the only way a subtree can stay connected to the rest of the graph without going through its parent `u` is via a back edge that jumps from inside the subtree to `u`'s ancestor or above.

That gives an exact test. Give each vertex two numbers during the DFS:

- `tin[u]` — the *discovery time*: a counter incremented each time we first visit a vertex.
- `low[u]` — the smallest `tin` reachable from the subtree of `u` using tree edges downward plus **at most one** back edge, **without** using the tree edge `parent(u) — u`.

`low[u]` is built from three sources: its own `tin[u]`; `low[v]` for every tree child `v`; and `tin[v]` for every back edge `u → v` to an already-visited non-parent vertex. Note the asymmetry: for a back edge we take `tin[v]`, not `low[v]`, because a single back edge lets us climb to `v` but not to whatever `v` itself could reach.

**The rule.** For a non-root vertex `u` with a DFS-tree child `v`:

> `u` is an articulation point ⟺ `low[v] >= tin[u]` for some child `v`.

Why: `low[v] >= tin[u]` says the entire subtree of `v` cannot reach any vertex discovered strictly before `u`. Its only lifeline to the upper part of the graph is `u` itself, so deleting `u` cuts that subtree off. Conversely if `low[v] < tin[u]`, some back edge from the subtree lands above `u`, and the subtree stays attached even without `u`.

Note the comparison is `>=` (for bridges it is the strict `>`): the subtree may reach *back to `u`* and `u` is still a cut vertex, because reaching `u` is useless once `u` is deleted.

**The root is special.** The root has no parent, so the rule above never applies. The root is an articulation point exactly when it has **two or more DFS-tree children** — two children mean two subtrees that never found a back edge to each other (otherwise one would have been explored from inside the other), so the root is the only bridge between them.

**Algorithm.**
1. Build an adjacency list. Keep `tin[]`, `low[]`, `visited[]`, and a boolean `isAP[]`.
2. DFS from every unvisited vertex (handles disconnected input) with a timer.
3. On entering `u`: `tin[u] = low[u] = timer++`.
4. For each neighbour `v`: skip the parent; if `v` is unvisited, recurse, then `low[u] = min(low[u], low[v])`, and if `low[v] >= tin[u]` and `u` is not the root mark `isAP[u]`, and count one child; if `v` is already visited, `low[u] = min(low[u], tin[v])`.
5. After the loop, if `u` is the root and `children > 1`, mark `isAP[u]`.
6. Collect all marked vertices.

**Dry run on the example** (DFS from `0`):

| step | vertex | tin | low after processing | check |
|---|---|---|---|---|
| 1 | 0 | 0 | 0 | root, children counted below |
| 2 | 1 | 1 | 0 (via child 2) | — |
| 3 | 2 | 2 | 0 (back edge 2→0 gives `tin[0]=0`) | `low[2]=0 >= tin[1]=1`? no |
| 4 | 3 | 3 | 3 | `low[3]=3 >= tin[1]=1`? **yes → 1 is an AP** |
| 5 | 4 | 4 | 4 | `low[4]=4 >= tin[3]=3`? **yes → 3 is an AP** |

Root `0` has exactly one DFS child (`1`), so it is not an articulation point. Answer `[1, 3]`. ✔

**Careful with parallel edges.** Skipping "the parent" by vertex id is wrong if the same pair is joined by two edges — then the second copy is a genuine back edge. If duplicates are possible, skip by *edge id* instead of by vertex id.
- **Time:** O(V + E) — one DFS.
- **Space:** O(V + E) for the adjacency list plus O(V) recursion depth.

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    int timer = 0;
    vector<int> tin, low;
    vector<char> vis, isAP;

    void dfs(int u, int parent, vector<vector<int>>& adj) {
        vis[u] = 1;
        tin[u] = low[u] = timer++;
        int children = 0;
        for (int v : adj[u]) {
            if (v == parent) continue;
            if (!vis[v]) {
                dfs(v, u, adj);
                low[u] = min(low[u], low[v]);
                if (low[v] >= tin[u] && parent != -1) isAP[u] = 1;
                children++;
            } else {
                low[u] = min(low[u], tin[v]);   // back edge: use tin, not low
            }
        }
        if (parent == -1 && children > 1) isAP[u] = 1;
    }

public:
    vector<int> articulationPoints(int V, vector<vector<int>>& edges) {
        vector<vector<int>> adj(V);
        for (auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }
        tin.assign(V, -1);
        low.assign(V, -1);
        vis.assign(V, 0);
        isAP.assign(V, 0);
        timer = 0;
        for (int i = 0; i < V; i++)
            if (!vis[i]) dfs(i, -1, adj);

        vector<int> res;
        for (int i = 0; i < V; i++)
            if (isAP[i]) res.push_back(i);
        if (res.empty()) res.push_back(-1);
        return res;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private int timer;
    private int[] tin, low;
    private boolean[] vis, isAP;
    private List<List<Integer>> adj;

    private void dfs(int u, int parent) {
        vis[u] = true;
        tin[u] = low[u] = timer++;
        int children = 0;
        for (int v : adj.get(u)) {
            if (v == parent) continue;
            if (!vis[v]) {
                dfs(v, u);
                low[u] = Math.min(low[u], low[v]);
                if (low[v] >= tin[u] && parent != -1) isAP[u] = true;
                children++;
            } else {
                low[u] = Math.min(low[u], tin[v]);
            }
        }
        if (parent == -1 && children > 1) isAP[u] = true;
    }

    public List<Integer> articulationPoints(int V, int[][] edges) {
        adj = new ArrayList<>();
        for (int i = 0; i < V; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }
        tin = new int[V];
        low = new int[V];
        vis = new boolean[V];
        isAP = new boolean[V];
        timer = 0;
        for (int i = 0; i < V; i++)
            if (!vis[i]) dfs(i, -1);

        List<Integer> res = new ArrayList<>();
        for (int i = 0; i < V; i++)
            if (isAP[i]) res.add(i);
        if (res.isEmpty()) res.add(-1);
        return res;
    }
}
```

### Python
```python
import sys
from typing import List


class Solution:
    def articulationPoints(self, V: int, edges: List[List[int]]) -> List[int]:
        sys.setrecursionlimit(10 ** 6)
        adj = [[] for _ in range(V)]
        for a, b in edges:
            adj[a].append(b)
            adj[b].append(a)

        tin = [-1] * V
        low = [-1] * V
        vis = [False] * V
        is_ap = [False] * V
        self.timer = 0

        def dfs(u: int, parent: int) -> None:
            vis[u] = True
            tin[u] = low[u] = self.timer
            self.timer += 1
            children = 0
            for v in adj[u]:
                if v == parent:
                    continue
                if not vis[v]:
                    dfs(v, u)
                    low[u] = min(low[u], low[v])
                    if low[v] >= tin[u] and parent != -1:
                        is_ap[u] = True
                    children += 1
                else:
                    low[u] = min(low[u], tin[v])   # back edge
            if parent == -1 and children > 1:
                is_ap[u] = True

        for i in range(V):
            if not vis[i]:
                dfs(i, -1)

        res = [i for i in range(V) if is_ap[i]]
        return res if res else [-1]
```

## Key Takeaways
- `low[u]` = earliest discovery time reachable from `u`'s subtree using at most one back edge, never crossing the edge to the parent.
- Cut vertex test: `low[child] >= tin[u]` (non-strict), versus the strict `low[child] > tin[u]` used for bridges — a vertex can be cut even when the subtree loops back to it.
- The root needs its own rule: it is a cut vertex only with ≥ 2 DFS-tree children.
- Update `low[u]` with `tin[v]` (not `low[v]`) on a back edge; and skip the parent by edge id, not vertex id, when parallel edges are allowed.
