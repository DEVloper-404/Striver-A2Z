# Sum of First N Numbers

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Learn Basic Recursion

## Problem
Given a positive integer `N`, return `1 + 2 + ... + N`.

Input: `N = 5`
Output: `15`

Input: `N = 10`
Output: `55`

## Approach 1: Iterative loop
Accumulate the numbers from 1 to `N` in a running total.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Parameterised recursion
Carry the running sum as a parameter: `solve(i, sum)` adds `i` to `sum` and recurses with `i - 1`; when `i == 0`, print or return `sum`. The answer is built on the way *down*.

- **Time:** O(n)
- **Space:** O(n) stack

## Approach 3: Functional recursion
Define the result in terms of a smaller instance: `sum(n) = n + sum(n - 1)` with `sum(0) = 0`. Each frame returns a value that the caller combines with its own `n`. This "return a value and combine" style is the one used for factorial, Fibonacci, and most divide-and-conquer problems.

- **Time:** O(n)
- **Space:** O(n) stack

## Approach 4: Closed-form formula (optimal)
The sum of the first `n` natural numbers is `n × (n + 1) / 2`. Constant time; use a 64-bit type because `n × (n + 1)` overflows 32 bits once `n` exceeds about 65,000.

- **Time:** O(1)
- **Space:** O(1)

## Code (Optimal)

The formula is the optimal answer; the functional recursion is included because it is the point of this section.

### C++
```cpp
class Solution {
public:
    // O(1) formula
    long long sumOfFirstN(int n) {
        return (long long)n * (n + 1) / 2;
    }

    // Functional recursion, for practice
    long long sumRecursive(int n) {
        if (n == 0) return 0;
        return n + sumRecursive(n - 1);
    }
};
```

```python
class Solution:
    # O(1) formula
    def sumOfFirstN(self, n: int) -> int:

    def sumRecursive(self, n: int) -> int:

            return 0
        return n + self.sumRecursive(n - 1)
```

## Key Takeaways
- Two recursion styles: *parameterised* (carry the answer down as an argument) and *functional* (return the answer up and combine). Learn to write both.
- The functional form `f(n) = n + f(n - 1)` is the template for factorial, power, and array-sum recursions.
- When a closed-form formula exists, use it — and watch for overflow in `n × (n + 1)`.
