# If ElseIf

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Things to Know in C++/Java/Python or any language

## Problem
Conditional statements let a program choose between different actions based on a boolean test. The `if / else if / else` ladder evaluates conditions from top to bottom and runs the first block whose condition is true; at most one block executes. A classic exercise: read a score and print a grade.

```
Input:  75
Output: B
```
Rules: 90 or more is A, 80 to 89 is B... no wait, use these bands: >= 90 → A, >= 75 → B, >= 60 → C, otherwise → F.

## Approach: Building the ladder

1. Write the most restrictive condition first. Because the ladder stops at the first match, ordering matters: checking `score >= 60` before `score >= 90` would wrongly give every high score a C.
2. Each `else if` is implicitly "and the previous ones were false", so you do not need to repeat the negation (`score >= 75 && score < 90` becomes just `score >= 75`).
3. The final `else` is a catch-all. Including it guarantees every input produces an answer.

Other useful forms:
- **Nested if:** an `if` inside another block, used when a second decision depends on the first.
- **Ternary operator:** `x = cond ? a : b;` for a one-line choice between two values.
- **Logical operators:** combine tests with `&&` (and), `||` (or), `!` (not). Both C++ and Java short-circuit, so `p != nullptr && p->val > 0` is safe.

Pitfalls: `=` (assignment) versus `==` (comparison) in C++/Java; forgetting braces so only the first statement is guarded; comparing floating-point values with `==`.

- **Time:** O(k) for a ladder with k conditions (each test is O(1))
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

char grade(int score) {
    if (score >= 90) return 'A';
    else if (score >= 75) return 'B';
    else if (score >= 60) return 'C';
    else return 'F';
}

int main() {
    int score;
    cin >> score;
    cout << grade(score) << '\n';

    // ternary and nested example
    string parity = (score % 2 == 0) ? "even" : "odd";
    if (score >= 0) {
        if (score <= 100) cout << "valid " << parity << '\n';
        else cout << "too large\n";
    } else {
        cout << "negative\n";
    }
    return 0;
}
```

### Java
```java
import java.util.Scanner;

public class Main {
    static char grade(int score) {
        if (score >= 90) return 'A';
        else if (score >= 75) return 'B';
        else if (score >= 60) return 'C';
        else return 'F';
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int score = sc.nextInt();
        System.out.println(grade(score));

        String parity = (score % 2 == 0) ? "even" : "odd";
        if (score >= 0) {
            if (score <= 100) System.out.println("valid " + parity);
            else System.out.println("too large");
        } else {
            System.out.println("negative");
        }
        sc.close();
    }
}
```

### Python
```python
def grade(score: int) -> str:
    if score >= 90:
        return "A"
    elif score >= 75:
        return "B"
    elif score >= 60:
        return "C"
    else:
        return "F"


def main():
    score = int(input())
    print(grade(score))

    parity = "even" if score % 2 == 0 else "odd"
    if score >= 0:
        if score <= 100:
            print("valid", parity)
        else:
            print("too large")
    else:
        print("negative")


if __name__ == "__main__":
    main()
```

## Key Takeaways
- Only the first true branch of an `if / else if / else` ladder runs, so order conditions from most specific to least specific.
- Always add a final `else` when every input must map to some output.
- Use `==` for comparison; a stray `=` inside a condition compiles in C++ and silently assigns.
- Python uses `elif` and indentation instead of braces; the ternary form is `a if cond else b`.
