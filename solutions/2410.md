# Set/Unset the rightmost unset bit

**Difficulty:** Easy  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Learn Bit Manipulation

## Problem
Given a non-negative integer `n`, return the number obtained by setting its rightmost `0` bit to `1`. If every bit of `n` is already `1` (e.g. `7 = 111`), return `n` unchanged. The companion operation — clearing the rightmost set bit — is `n & (n - 1)` and is discussed below.

Input: `n = 10` (binary `1010`)
Output: `11` (binary `1011`)

## Approach 1: Scan bit positions
Loop `i` from 0 upward and test `(n >> i) & 1`. The first `i` where the bit is 0 is the target; return `n | (1 << i)`. If `i` passes the highest bit of `n`, that means every bit was 1 — some formulations return `n` in that case, others set the next bit; the sheet's version returns `n`.
- **Time:** O(log n)
- **Space:** O(1)

## Approach 2: `n | (n + 1)` (Optimal)
Adding 1 to `n` turns its trailing ones into zeros and sets the first zero bit above them — exactly the rightmost unset bit. Taking `n | (n + 1)` keeps all of `n`'s original bits and adds that one new bit. Example: `10 = 1010`, `11 = 1011`, `1010 | 1011 = 1011`.

Special case: if `n` is all ones (`n & (n + 1) == 0`), then `n + 1` is a fresh power of two and the OR would extend the number. Check for that first and return `n`.

The mirror operation: to clear the rightmost set bit use `n & (n - 1)`; to isolate it use `n & -n`.
- **Time:** O(1)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int setRightmostUnsetBit(int n) {
        if ((n & (n + 1)) == 0) return n;   // all ones: nothing to set
        return n | (n + 1);
    }
    int unsetRightmostSetBit(int n) {
        return n & (n - 1);
    }
};
```

## Key Takeaways
- `n + 1` flips the trailing ones and the first zero above them; OR-ing with `n` restores the ones and keeps the new bit.
- `n & (n + 1) == 0` detects "all ones" numbers (0, 1, 3, 7, 15, ...) — those have no unset bit inside their width.
- The dual identity `n & (n - 1)` clears the rightmost set bit.
- Both operations are O(1); no loops needed.
