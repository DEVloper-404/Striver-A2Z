# Check if a Number is Odd or Not

**Difficulty:** Easy  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Learn Bit Manipulation

## Problem
Given an integer `n`, return `true` if it is odd and `false` if it is even. Negative numbers follow the usual rule: `-3` is odd, `-4` is even.

Input: `n = 7`
Output: `true`

## Approach 1: Modulo
Use the remainder on division by 2. Note that in C++ and Java `-3 % 2` is `-1`, so compare against `0` rather than `1`: `n % 2 != 0`.
- **Time:** O(1)
- **Space:** O(1)

## Approach 2: Test the lowest bit (Optimal)
The value of an integer in binary is `... + b2·4 + b1·2 + b0·1`. Every term except `b0` is a multiple of 2, so the parity of `n` is decided entirely by bit 0. `n & 1` extracts that bit: `1` means odd, `0` means even. This also works for negatives in two's complement, because the low bit of `-3` (`...11111101`) is `1`.

The AND is a single machine instruction and avoids the (slightly more expensive) division that `%` compiles to in the general case.
- **Time:** O(1)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    bool isOdd(int n) {
        return (n & 1) == 1;
    }
};
```

### Java
```java
class Solution {
    public boolean isOdd(int n) {
        return (n & 1) == 1;
    }
}
```

### Python
```python
class Solution:
    def isOdd(self, n: int) -> bool:
        return (n & 1) == 1
```

## Key Takeaways
- Parity lives in bit 0; `n & 1` reads it directly.
- Prefer `n & 1` over `n % 2 == 1` — the latter is wrong for negative numbers in C++/Java because the remainder is `-1`.
- Zero is even (`0 & 1 == 0`).
- The same idea generalises: `n & (2^k - 1)` gives `n mod 2^k` for non-negative `n`.
