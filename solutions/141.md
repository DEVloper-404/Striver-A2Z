# Minimum Bit Flips to Convert Number

**Difficulty:** Medium  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Interview Problems

## Problem
Given two non-negative integers `start` and `goal`, return the minimum number of single-bit flips needed to turn `start` into `goal`. A flip changes one bit from 0 to 1 or from 1 to 0.

Input: `start = 10` (binary `1010`), `goal = 7` (binary `0111`)
Output: `3` (bits 0, 2 and 3 differ)

## Approach 1: Compare bit by bit
Walk over the 32 bit positions and compare `(start >> i) & 1` with `(goal >> i) & 1`; count the positions where they differ. Each differing bit needs exactly one flip, and no flip can fix more than one bit, so the count is the minimum.
- **Time:** O(32) = O(1)
- **Space:** O(1)

## Approach 2: XOR then popcount (Optimal)
`start ^ goal` produces a number whose set bits are exactly the positions where the two inputs differ. So the answer is the popcount of the XOR. Use Kernighan's loop `x &= x - 1` or a built-in popcount.
- **Time:** O(number of differing bits), at most O(1) for fixed-width ints
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int minBitFlips(int start, int goal) {
        int x = start ^ goal, count = 0;
        while (x) {
            x &= (x - 1);
            ++count;
        }
        return count;
        // or: return __builtin_popcount(start ^ goal);
    }
};
```

### Java
```java
class Solution {
    public int minBitFlips(int start, int goal) {
        int x = start ^ goal, count = 0;
        while (x != 0) {
            x &= (x - 1);
            count++;
        }
        return count;
        // or: return Integer.bitCount(start ^ goal);
    }
}
```

### Python
```python
class Solution:
    def minBitFlips(self, start: int, goal: int) -> int:
        x = start ^ goal
        count = 0
        while x:
            x &= x - 1
            count += 1
        return count
        # or: return bin(start ^ goal).count("1")
```

## Key Takeaways
- XOR highlights differing bits; counting them is the Hamming distance between the two numbers.
- Two problems in one: "find differences" (XOR) plus "count set bits" (popcount).
- When `start == goal`, the XOR is 0 and the answer is 0.
- For 64-bit inputs, use the 64-bit popcount (`__builtin_popcountll`, `Long.bitCount`).
