# Count Occurrences in a Sorted Array

**Difficulty:** Easy  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on 1D Arrays

## Problem
Given a sorted array `arr` of size `n` (duplicates allowed) and an integer `x`, return how many times `x` appears in the array. Return `0` if it is absent.

Input: `arr = [1, 2, 2, 2, 3, 5, 5], x = 2`
Output: `3`

Input: `arr = [1, 2, 2, 2, 3, 5, 5], x = 4`
Output: `0`

## Approach 1: Linear Count
Iterate through the array and increment a counter every time `arr[i] == x`. Straightforward, but it touches every element even though only a contiguous block can contain `x`.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: First and Last Occurrence via Binary Search (Optimal)
In a sorted array all copies of `x` sit next to each other. If the first copy is at index `first` and the last at index `last`, the count is `last - first + 1`.

1. Binary search for the first occurrence: on a match, record `mid` and move left.
2. If no occurrence exists, return `0` immediately.
3. Binary search for the last occurrence: on a match, record `mid` and move right.
4. Return `last - first + 1`.

Equivalently, `upperBound(x) - lowerBound(x)` gives the same number in two generic searches.

- **Time:** O(log n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    int firstOcc(vector<int>& arr, int x) {
        int low = 0, high = (int)arr.size() - 1, ans = -1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (arr[mid] == x) { ans = mid; high = mid - 1; }
            else if (arr[mid] < x) low = mid + 1;
            else high = mid - 1;
        }
        return ans;
    }
    int lastOcc(vector<int>& arr, int x) {
        int low = 0, high = (int)arr.size() - 1, ans = -1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (arr[mid] == x) { ans = mid; low = mid + 1; }
            else if (arr[mid] < x) low = mid + 1;
            else high = mid - 1;
        }
        return ans;
    }
public:
    int countOccurrences(vector<int>& arr, int x) {
        int first = firstOcc(arr, x);
        if (first == -1) return 0;
        return lastOcc(arr, x) - first + 1;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def countOccurrences(self, arr: List[int], x: int) -> int:
        def bound(find_first: bool) -> int:
            low, high, ans = 0, len(arr) - 1, -1
            while low <= high:
                mid = (low + high) // 2
                if arr[mid] == x:
                    ans = mid
                    if find_first:
                        high = mid - 1
                    else:
                        low = mid + 1
                elif arr[mid] < x:
                    low = mid + 1
                else:
                    high = mid - 1
            return ans

        first = bound(True)
        if first == -1:
            return 0
        return bound(False) - first + 1
```

## Key Takeaways
- Duplicates in a sorted array form one contiguous block, so counting reduces to locating the two ends of that block.
- Always guard for the absent case before subtracting indices; `-1 - (-1) + 1` would wrongly yield 1.
- `upperBound(x) - lowerBound(x)` is the shortest correct formula if you already have those helpers.
- Two logarithmic searches are still O(log n) overall.
