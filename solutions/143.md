# Single Number - I

**Difficulty:** Medium  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Interview Problems

## Problem
You are given an array `nums` in which every element appears exactly twice except for one element that appears once. Find that element. The solution should run in linear time and use constant extra memory.

Input: `nums = [4, 1, 2, 1, 2]`
Output: `4`

## Approach 1: Hash map frequency count
Count occurrences of every value in a hash map, then return the key whose count is 1. Simple and linear, but it needs O(n) extra memory.
- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Sort and scan
Sort the array; duplicates become adjacent. Walk in steps of two and return the first element that does not match its neighbour. This avoids the hash map but costs a sort.
- **Time:** O(n log n)
- **Space:** O(1) extra (ignoring the sort's own stack)

## Approach 3: XOR everything (Optimal)
XOR is commutative and associative, `x ^ x = 0`, and `x ^ 0 = x`. XOR-ing all elements together cancels each pair, leaving only the unpaired value. One pass, no extra memory.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int acc = 0;
        for (int x : nums) acc ^= x;
        return acc;
    }
};
```

### Java
```java
class Solution {
    public int singleNumber(int[] nums) {
        int acc = 0;
        for (int x : nums) acc ^= x;
        return acc;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        acc = 0
        for x in nums:
            acc ^= x
        return acc
```

## Key Takeaways
- Pairs cancel under XOR, so the running XOR of the whole array is the lone element.
- Works with negative numbers because two's complement bits cancel just the same.
- The trick relies on every other value appearing an even number of times; if duplicates appear three times you need the bit-count-mod-3 variant ("Single Number II").
- Array of length 1 returns that element directly.
