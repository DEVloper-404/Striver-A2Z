# Remove duplicates from sorted DLL

**Difficulty:** Hard  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of DLL

## Problem
Given the head of a doubly linked list sorted in non-decreasing order, delete nodes so that every value appears exactly once, and return the head. Keep the first occurrence of each value and preserve the sorted order. The `prev` and `next` links of the remaining nodes must stay consistent.

```
Input:  1 <-> 1 <-> 2 <-> 3 <-> 3 <-> 3 <-> 4
Output: 1 <-> 2 <-> 3 <-> 4
```

## Approach 1: Hash set of seen values
Walk the list and delete any node whose value is already in a set. This works for unsorted lists too, but for a sorted list it wastes memory since duplicates are always adjacent.

- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Skip runs of equal neighbours (optimal)
Because duplicates are adjacent, stand on `cur` and look ahead: while `cur.next` exists and has the same value, unlink it. After the run is consumed, `cur.next` is the first node with a larger value; link it back with `cur.next.prev = cur` and step `cur` forward. The head never changes because the first occurrence is always kept.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct DNode { int val; DNode* prev; DNode* next; DNode(int v) : val(v), prev(nullptr), next(nullptr) {} };

class Solution {
public:
    DNode* removeDuplicates(DNode* head) {
        DNode* cur = head;
        while (cur && cur->next) {
            DNode* nxt = cur->next;
            while (nxt && nxt->val == cur->val) {
                DNode* dup = nxt;
                nxt = nxt->next;
                delete dup;
            }
            cur->next = nxt;
            if (nxt) nxt->prev = cur;
            cur = nxt;
        }
        return head;
    }
};
```

### Java
```java
// class DNode { int val; DNode prev, next; DNode(int v) { val = v; } }

class Solution {
    public DNode removeDuplicates(DNode head) {
        DNode cur = head;
        while (cur != null && cur.next != null) {
            DNode nxt = cur.next;
            while (nxt != null && nxt.val == cur.val) {
                nxt = nxt.next;
            }
            cur.next = nxt;
            if (nxt != null) nxt.prev = cur;
            cur = nxt;
        }
        return head;
    }
}
```

### Python
```python
# class DNode:
#     def __init__(self, val):
#         self.val = val
#         self.prev = None
#         self.next = None

class Solution:
    def removeDuplicates(self, head):
        cur = head
        while cur and cur.next:
            nxt = cur.next
            while nxt and nxt.val == cur.val:
                nxt = nxt.next
            cur.next = nxt
            if nxt:
                nxt.prev = cur
            cur = nxt
        return head
```

## Key Takeaways
- Sorted input means duplicates form contiguous runs; consume each run with an inner loop.
- Relink both directions after skipping: `cur.next = nxt` and `nxt.prev = cur`.
- The head is always kept, so the function returns the original head.
- Lists of length 0 or 1 pass through unchanged.
