# Implement Min Heap

**Difficulty:** Medium  ·  **Topic:** Heaps [Learning, Medium, Hard Problems] › Learning

## Problem
Design a min heap that supports `push(x)` (insert a value), `pop()` (remove and return the smallest value), `top()` (return the smallest without removing it), and `size()`/`empty()`. All operations must run in logarithmic time or better, and the structure must be backed by an array rather than a pointer-based tree.

Input: operations `push(5), push(2), push(8), top(), pop(), top()`
Output: `2, 2, 5`

## Approach 1: Unsorted Array
Store values in an array. `push` appends in O(1); `top`/`pop` scan for the minimum in O(n). Simple but too slow when many pops are needed.

- **Time:** push O(1), pop/top O(n)
- **Space:** O(n)

## Approach 2: Sorted Array
Keep the array sorted. `top` and `pop` (from the end) are O(1), but `push` needs a shift into position, costing O(n).

- **Time:** push O(n), pop/top O(1)
- **Space:** O(n)

## Approach 3: Array-Backed Binary Heap (Optimal)
Store a complete binary tree in an array with 0-based indexing: parent of `i` is `(i - 1) / 2`, children are `2i + 1` and `2i + 2`. Maintain the invariant that every parent is at most its children.

- **push:** append at the end, then *sift up*: while the element is smaller than its parent, swap them.
- **pop:** save the root, move the last element to index 0, shrink, then *sift down*: repeatedly swap with the smaller child while a child is smaller.
- **top:** return index 0.

Both sift operations walk one root-to-leaf path, so they cost O(height) = O(log n).

- **Time:** push O(log n), pop O(log n), top O(1)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stdexcept>
using namespace std;

class MinHeap {
    vector<int> h;

    void siftUp(int i) {
        while (i > 0) {
            int p = (i - 1) / 2;
            if (h[p] <= h[i]) break;
            swap(h[p], h[i]);
            i = p;
        }
    }

    void siftDown(int i) {
        int n = h.size();
        while (true) {
            int l = 2 * i + 1, r = 2 * i + 2, smallest = i;
            if (l < n && h[l] < h[smallest]) smallest = l;
            if (r < n && h[r] < h[smallest]) smallest = r;
            if (smallest == i) break;
            swap(h[i], h[smallest]);
            i = smallest;
        }
    }

public:
    void push(int x) {
        h.push_back(x);
        siftUp(h.size() - 1);
    }

    int top() const {
        if (h.empty()) throw runtime_error("heap is empty");
        return h[0];
    }

    int pop() {
        int result = top();
        h[0] = h.back();
        h.pop_back();
        if (!h.empty()) siftDown(0);
        return result;
    }

    int size() const { return h.size(); }
    bool empty() const { return h.empty(); }
};
```

### Java
```java
import java.util.ArrayList;
import java.util.List;

class MinHeap {
    private final List<Integer> h = new ArrayList<>();

    private void swap(int i, int j) {
        int t = h.get(i);
        h.set(i, h.get(j));
        h.set(j, t);
    }

    private void siftUp(int i) {
        while (i > 0) {
            int p = (i - 1) / 2;
            if (h.get(p) <= h.get(i)) break;
            swap(p, i);
            i = p;
        }
    }

    private void siftDown(int i) {
        int n = h.size();
        while (true) {
            int l = 2 * i + 1, r = 2 * i + 2, smallest = i;
            if (l < n && h.get(l) < h.get(smallest)) smallest = l;
            if (r < n && h.get(r) < h.get(smallest)) smallest = r;
            if (smallest == i) break;
            swap(i, smallest);
            i = smallest;
        }
    }

    public void push(int x) {
        h.add(x);
        siftUp(h.size() - 1);
    }

    public int top() {
        if (h.isEmpty()) throw new IllegalStateException("heap is empty");
        return h.get(0);
    }

    public int pop() {
        int result = top();
        int last = h.remove(h.size() - 1);
        if (!h.isEmpty()) {
            h.set(0, last);
            siftDown(0);
        }
        return result;
    }

    public int size() { return h.size(); }
    public boolean isEmpty() { return h.isEmpty(); }
}
```

### Python
```python
class MinHeap:
    def __init__(self):
        self.h = []

    def _sift_up(self, i: int) -> None:
        while i > 0:
            p = (i - 1) // 2
            if self.h[p] <= self.h[i]:
                break
            self.h[p], self.h[i] = self.h[i], self.h[p]
            i = p

    def _sift_down(self, i: int) -> None:
        n = len(self.h)
        while True:
            l, r, smallest = 2 * i + 1, 2 * i + 2, i
            if l < n and self.h[l] < self.h[smallest]:
                smallest = l
            if r < n and self.h[r] < self.h[smallest]:
                smallest = r
            if smallest == i:
                break
            self.h[i], self.h[smallest] = self.h[smallest], self.h[i]
            i = smallest

    def push(self, x: int) -> None:
        self.h.append(x)
        self._sift_up(len(self.h) - 1)

    def top(self) -> int:
        if not self.h:
            raise IndexError("heap is empty")
        return self.h[0]

    def pop(self) -> int:
        result = self.top()
        last = self.h.pop()
        if self.h:
            self.h[0] = last
            self._sift_down(0)
        return result

    def size(self) -> int:
        return len(self.h)

    def empty(self) -> bool:
        return not self.h
```

## Key Takeaways
- The array layout of a complete tree removes the need for node objects; index arithmetic replaces pointers.
- Sift up fixes a violation at a leaf after insert; sift down fixes a violation at the root after removal.
- When popping the last remaining element, skip the sift down (there is nothing to compare against); when swapping down, always pick the *smaller* child so the invariant holds for both.
- Swapping `<` for `>` in the two comparisons turns this into a max heap.
