# Check if the i-th bit is Set or Not

**Difficulty:** Easy  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Learn Bit Manipulation

## Problem
Given a non-negative integer `n` and an index `i` (0-based, counted from the least significant bit), determine whether the `i`-th bit in the binary form of `n` is `1` (set) or `0` (unset). Return `true` if set, otherwise `false`.

Input: `n = 13` (binary `1101`), `i = 2`
Output: `true` (bits from the right are 1, 0, 1, 1 — index 2 is `1`)

## Approach 1: Convert to binary and index the string
Build the binary representation as a string or array of digits by repeatedly taking `n % 2` and dividing by 2. Then look at position `i` from the right. If `i` is beyond the length, the bit is 0.
- **Time:** O(log n) to build the digits
- **Space:** O(log n) for the digit array

## Approach 2: Mask with a left shift (Optimal)
`1 << i` is a number whose only set bit is at position `i`. AND-ing it with `n` leaves that single bit (if `n` has it) or produces zero (if not). So `(n & (1 << i)) != 0` answers the question in one instruction.

Equivalent form: shift `n` right by `i` so the target bit lands at position 0, then AND with 1: `(n >> i) & 1`.
- **Time:** O(1)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    bool isBitSet(int n, int i) {
        return (n & (1 << i)) != 0;
        // or: return (n >> i) & 1;
    }
};
```

### Java
```java
class Solution {
    public boolean isBitSet(int n, int i) {
        return (n & (1 << i)) != 0;
        // or: return ((n >> i) & 1) == 1;
    }
}
```

### Python
```python
class Solution:
    def isBitSet(self, n: int, i: int) -> bool:
        return (n & (1 << i)) != 0
        # or: return (n >> i) & 1 == 1
```

## Key Takeaways
- `1 << i` builds a mask with exactly one bit on; AND with it isolates that bit of `n`.
- Compare the AND result with `0`, not with `1` — for `i > 0` the result is `2^i`, not `1`.
- Bit indices are 0-based from the right; `i = 0` is the units bit.
- Keep `i < 31` for a 32-bit signed int, otherwise `1 << i` overflows (use `1L << i` or an unsigned type for wider values).
