# Delete all occurrences of a key in DLL

**Difficulty:** Hard  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of DLL

## Problem
Given the head of a doubly linked list and an integer `key`, remove every node whose value equals `key` and return the head of the resulting list. The key may appear at the head, at the tail, several times in a row, or not at all; the result must have consistent `prev` and `next` links throughout.

```
Input:  head = 10 <-> 4 <-> 10 <-> 10 <-> 6 <-> 10, key = 10
Output: 4 <-> 6

Input:  head = 1 <-> 1, key = 1
Output: (empty list)
```

## Approach 1: Rebuild into a new list
Traverse the original list and, for every node whose value is not the key, append a fresh copy to a new list. Simple but allocates a full copy and ignores the point of the exercise, which is unlinking in place.

- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Single pass, unlink in place (optimal)
Walk with `cur`. When `cur.val == key`:

1. Save `nxt = cur.next` before touching anything.
2. If `cur.prev` exists, bypass forward: `cur.prev.next = cur.next`; otherwise `cur` is the head, so the head moves to `cur.next`.
3. If `cur.next` exists, bypass backward: `cur.next.prev = cur.prev`.
4. Free `cur`, continue from `nxt`.

Because a DLL gives us `prev` directly, no trailing pointer is needed. Consecutive matches work because after each deletion `nxt` is examined on the next iteration.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct DNode { int val; DNode* prev; DNode* next; DNode(int v) : val(v), prev(nullptr), next(nullptr) {} };

class Solution {
public:
    DNode* deleteAllOccurrences(DNode* head, int key) {
        DNode* cur = head;
        while (cur) {
            DNode* nxt = cur->next;
            if (cur->val == key) {
                if (cur->prev) cur->prev->next = cur->next;
                else           head = cur->next;
                if (cur->next) cur->next->prev = cur->prev;
                delete cur;
            }
            cur = nxt;
        }
        return head;
    }
};
```

### Java
```java
// class DNode { int val; DNode prev, next; DNode(int v) { val = v; } }

class Solution {
    public DNode deleteAllOccurrences(DNode head, int key) {
        DNode cur = head;
        while (cur != null) {
            DNode nxt = cur.next;
            if (cur.val == key) {
                if (cur.prev != null) cur.prev.next = cur.next;
                else                  head = cur.next;
                if (cur.next != null) cur.next.prev = cur.prev;
                cur.prev = null;
                cur.next = null;
            }
            cur = nxt;
        }
        return head;
    }
}
```

```python
class Solution:
    def deleteAllOccurrences(self, head, key):
        cur = head
        while cur:
            nxt = cur.next
            if cur.val == key:
                if cur.prev:
                    cur.prev.next = cur.next
                else:
                    head = cur.next
                if cur.next:
                    cur.next.prev = cur.prev
                cur.prev = cur.next = None
            cur = nxt
        return head
```

## Key Takeaways
- In a DLL, deleting `cur` means `cur.prev.next = cur.next` and `cur.next.prev = cur.prev`, each guarded for null.
- The head moves whenever the node being removed has no `prev`; keep `head` updated rather than returning the original.
- Grab `cur.next` before unlinking so the traversal survives the deletion.
- Consecutive and trailing occurrences need no special handling in this loop.
