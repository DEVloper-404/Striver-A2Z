# Find Pairs with Given Sum in Doubly Linked List

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of DLL

## Problem
Given the head of a **sorted** (ascending) doubly linked list of distinct integers and a target `k`, return all pairs `(a, b)` with `a < b` and `a + b == k`. Pairs should be listed in increasing order of the first element. If no pair exists, return an empty list.

```
Input:  head = 1 <-> 2 <-> 4 <-> 5 <-> 6 <-> 8 <-> 9, k = 7
Output: [(1, 6), (2, 5)]
```

## Approach 1: Check every pair
For each node, walk the remainder of the list and test whether the two values sum to `k`. Because the list is sorted you can stop the inner walk once the sum exceeds `k`, but the worst case is still quadratic.

- **Time:** O(n^2)
- **Space:** O(1) besides the output

## Approach 2: Two pointers from both ends (optimal)
The `prev` links let us walk backwards, which is exactly what the sorted-array two-pointer technique needs:

1. Set `left = head` and `right = tail` (walk once to find the tail).
2. While `left` is before `right` (i.e. `left != right` and `right.next != left`):
   - If `left.val + right.val == k`, record the pair and move both inward.
   - If the sum is smaller than `k`, move `left` forward (need a bigger value).
   - If larger, move `right` backward.

The termination check `right.next != left` catches the moment the pointers cross, which cannot be detected by index comparison in a list.

- **Time:** O(n)
- **Space:** O(1) besides the output

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <utility>
using namespace std;
// struct DNode { int val; DNode* prev; DNode* next; DNode(int v) : val(v), prev(nullptr), next(nullptr) {} };

class Solution {
public:
    vector<pair<int,int>> findPairs(DNode* head, int k) {
        vector<pair<int,int>> res;
        if (!head) return res;
        DNode* left = head;
        DNode* right = head;
        while (right->next) right = right->next;
        while (left != right && right->next != left) {
            int sum = left->val + right->val;
            if (sum == k) {
                res.push_back({left->val, right->val});
                left = left->next;
                right = right->prev;
            } else if (sum < k) {
                left = left->next;
            } else {
                right = right->prev;
            }
        }
        return res;
    }
};
```

```java
import java.util.*;
// class DNode { int val; DNode prev, next; DNode(int v) { val = v; } }

class Solution {
    public List<int[]> findPairs(DNode head, int k) {
        List<int[]> res = new ArrayList<>();
        if (head == null) return res;
        DNode left = head, right = head;
        while (right.next != null) right = right.next;
        while (left != right && right.next != left) {
            int sum = left.val + right.val;
            if (sum == k) {
                res.add(new int[]{left.val, right.val});
                left = left.next;
                right = right.prev;
            } else if (sum < k) {
                left = left.next;
            } else {
                right = right.prev;
            }
        }
        return res;
    }
}
```

### Python
```python
# class DNode:
#     def __init__(self, val):
#         self.val = val
#         self.prev = None
#         self.next = None

class Solution:
    def findPairs(self, head, k):
        res = []
        if head is None:
            return res
        left = right = head
        while right.next:
            right = right.next
        while left is not right and right.next is not left:
            s = left.val + right.val
            if s == k:
                res.append((left.val, right.val))
                left = left.next
                right = right.prev
            elif s < k:
                left = left.next
            else:
                right = right.prev
        return res
```

## Key Takeaways
- A sorted DLL supports the classic two-pointer sum search because `prev` gives O(1) backward movement.
- Stop when `left == right` or the pointers have crossed (`right.next == left`); there is no index to compare.
- On a match advance both pointers; values are distinct so no other pair shares either element.
- Empty and single-node lists produce no pairs and exit immediately.
