# Number of provinces

**Difficulty:** Medium  ·  **Topic:** Graphs [Concepts & Problems] › Problems on BFS/DFS

## Problem
You are given an `n × n` matrix `isConnected` where `isConnected[i][j] == 1` means city `i` and city `j` are directly connected. A **province** is a group of cities that are connected directly or indirectly, and which has no connection to any city outside the group. Return the number of provinces.

```
Input:  isConnected = [[1,1,0],
                       [1,1,0],
                       [0,0,1]]
Output: 2          (province {0,1} and province {2})
```

## Approach 1: Recognising the disguise
The wording talks about "provinces", but the structure is exactly a connected-components count on an undirected graph. The matrix is an **adjacency matrix**: row `i` lists which cities city `i` touches. It is symmetric (`isConnected[i][j] == isConnected[j][i]`) because connection is mutual, and the diagonal is all 1s because a city is trivially connected to itself — the diagonal contributes nothing and can be ignored.

Key observation: cities in the same province are exactly the cities reachable from one another. Reachability partitions the cities into disjoint groups, so a single traversal starting anywhere inside a province visits that whole province and nothing else. Therefore:

> number of provinces = number of times we have to *start* a fresh traversal to cover all `n` cities.

The algorithm falls out:
1. `visited[0..n-1] = false`, `count = 0`.
2. For each city `i`: if it is unvisited, it belongs to a province we have not counted yet → `count++` and run DFS/BFS from `i`, marking everything reachable.
3. Return `count`.

Inside the traversal, the neighbours of city `node` are all `j` with `isConnected[node][j] == 1` and `j != node`. Because we read a full row per node, this scan is O(n) per node rather than O(degree).

Dry run on the example:
- `i = 0`: unvisited → `count = 1`. DFS(0) reads row 0 = `[1,1,0]`: `j=0` is itself, `j=1` is connected and unvisited → DFS(1) reads row 1 = `[1,1,0]`, both neighbours already visited, returns. `j=2` is 0, skip. Visited = `{0,1}`.
- `i = 1`: already visited, skip.
- `i = 2`: unvisited → `count = 2`. DFS(2) reads row 2 = `[0,0,1]`, no new neighbours.
- Answer: `2`.
- **Time:** O(n²) — the traversal touches every matrix cell once overall.
- **Space:** O(n) for `visited` and the recursion stack.

## Approach 2: Converting to an adjacency list first
Some prefer to build `adj[i] = { j : isConnected[i][j] == 1, j != i }` and then run the standard component count. This costs an extra O(n²) pass and O(n²) worst-case memory, and gives no asymptotic benefit here because the matrix scan is already O(n²). It is only worth it if you plan to run several graph algorithms on the same input. The direct-on-matrix version below is simpler.
- **Time:** O(n²)
- **Space:** O(n²) for the list — worse than Approach 1

## Approach 3: Disjoint Set Union (alternative optimal)
Instead of traversing, union every pair `(i, j)` with `isConnected[i][j] == 1`. At the end, the number of distinct set representatives (`find(i) == i`) is the number of provinces. With path compression and union by size, the `n²` union calls cost effectively O(n²·α(n)). Same complexity class as DFS here, but the pattern generalises to problems where edges arrive one at a time and you must report the component count after each addition.
- **Time:** O(n² · α(n))
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int findCircleNum(vector<vector<int>>& isConnected) {
        int n = isConnected.size();
        vector<int> visited(n, 0);
        int provinces = 0;
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                provinces++;
                dfs(i, isConnected, visited);
            }
        }
        return provinces;
    }

private:
    void dfs(int node, vector<vector<int>>& g, vector<int>& visited) {
        visited[node] = 1;
        int n = g.size();
        for (int j = 0; j < n; j++) {
            if (g[node][j] == 1 && !visited[j]) dfs(j, g, visited);
        }
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        boolean[] visited = new boolean[n];
        int provinces = 0;
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                provinces++;
                // BFS over the matrix rows
                Queue<Integer> q = new LinkedList<>();
                q.add(i);
                visited[i] = true;
                while (!q.isEmpty()) {
                    int node = q.poll();
                    for (int j = 0; j < n; j++) {
                        if (isConnected[node][j] == 1 && !visited[j]) {
                            visited[j] = true;
                            q.add(j);
                        }
                    }
                }
            }
        }
        return provinces;
    }
}
```

### Python
```python
from collections import deque
from typing import List

class Solution:
    def findCircleNum(self, isConnected: List[List[int]]) -> int:
        n = len(isConnected)
        visited = [False] * n
        provinces = 0
        for i in range(n):
            if visited[i]:
                continue
            provinces += 1
            q = deque([i])
            visited[i] = True
            while q:
                node = q.popleft()
                for j in range(n):
                    if isConnected[node][j] == 1 and not visited[j]:
                        visited[j] = True
                        q.append(j)
        return provinces
```

## Key Takeaways
- "Groups of mutually connected things" is always a connected-components count in disguise.
- The answer equals the number of *outer-loop starts*, not the number of nodes visited.
- With an adjacency matrix each traversal step costs O(n), giving O(n²) total — that is optimal since you must at least read the matrix.
- Ignore the diagonal; it only says a city is connected to itself and never changes the count.
