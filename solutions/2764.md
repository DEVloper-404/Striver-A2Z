# Remove duplicates from Sorted array

**Difficulty:** Easy  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Easy

## Problem
Given an integer array `nums` sorted in non-decreasing order, remove the duplicates in place so that every value appears exactly once, keeping the relative order. Return `k`, the number of unique values; the first `k` slots of `nums` must hold those values. Whatever is beyond index `k-1` does not matter.

Input: `nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]`
Output: `5`, with `nums` starting `[0, 1, 2, 3, 4, ...]`

## Approach 1: Set Then Copy Back
Insert every element into an ordered set (which removes duplicates and keeps them sorted), then copy the set's contents back into the front of `nums`. Correct, but uses extra memory and ignores the fact that the input is already sorted.

- **Time:** O(n log n)
- **Space:** O(n)

## Approach 2: Two Pointers (Optimal)
Because the array is sorted, duplicates are always adjacent. Keep a slow pointer `i` that marks the end of the unique prefix, and a fast pointer `j` that scans the array:

1. Start with `i = 0` (the first element is always unique).
2. For each `j` from `1` to `n-1`: if `nums[j] != nums[i]`, we found a new value, so increment `i` and write `nums[i] = nums[j]`.
3. Otherwise `nums[j]` is a duplicate of `nums[i]` and we skip it.

At the end, `nums[0..i]` holds the unique values in order, so return `i + 1`. Writing only when a new value appears guarantees we never overwrite something we still need, because `i <= j` at all times.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        if (nums.empty()) return 0;
        int i = 0;
        for (int j = 1; j < (int)nums.size(); j++) {
            if (nums[j] != nums[i]) {
                i++;
                nums[i] = nums[j];
            }
        }
        return i + 1;
    }
};
```

### Python
```python
class Solution:
    def removeDuplicates(self, nums: list[int]) -> int:
        if not nums:
            return 0
        i = 0
        for j in range(1, len(nums)):
            if nums[j] != nums[i]:
                i += 1
                nums[i] = nums[j]
        return i + 1
```

## Key Takeaways
- Sorted input means duplicates are adjacent, which is exactly what makes the slow/fast two-pointer pattern work.
- The slow pointer never overtakes the fast one, so in-place overwriting is safe.
- Return `i + 1` (a count), not `i` (an index) — a classic off-by-one.
- Edge cases: empty array returns `0`; an array with all identical values returns `1`.
