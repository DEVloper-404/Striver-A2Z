# Sort a stack using recursion

**Difficulty:** Medium  ·  **Topic:** Recursion [PatternWise] › Get a Strong Hold

## Problem
Given a stack of integers, sort it so that the largest element ends up on top, using only the stack's own operations (`push`, `pop`, `top`, `empty`) and recursion. No auxiliary array, list, or second stack is allowed; the recursion call stack is the only extra storage.

Input: stack (bottom → top) `[3, 1, 4, 2]`
Output: stack (bottom → top) `[1, 2, 3, 4]` (top is `4`)

## Approach 1: Dump into an array and sort
Pop everything into an array, sort it, and push the values back in ascending order. This works but uses an explicit extra container, which is exactly what the problem forbids.
- **Time:** O(n log n)
- **Space:** O(n)

## Approach 2: Recursive insertion sort on the stack
The idea mirrors insertion sort, expressed with two recursive functions:

1. `sortStack(st)`: if the stack is empty, return. Pop the top element `x`, recursively sort the remaining stack, then call `insertSorted(st, x)`.
2. `insertSorted(st, x)`: if the stack is empty or `top <= x`, push `x` (it belongs on top). Otherwise pop the top `t`, recursively insert `x` deeper, then push `t` back.

After the recursive `sortStack` returns, the rest of the stack is sorted with the largest on top, and `insertSorted` slides `x` down to its correct depth. The recursion frames hold the popped elements, so no other storage is needed.
- **Time:** O(n²) — each of the n elements may be inserted past up to n others.
- **Space:** O(n) recursion depth

## Code (Optimal)

### C++
```cpp
#include <stack>
using namespace std;

class Solution {
    void insertSorted(stack<int>& st, int x) {
        if (st.empty() || st.top() <= x) {
            st.push(x);
            return;
        }
        int t = st.top(); st.pop();
        insertSorted(st, x);
        st.push(t);
    }
public:
    void sortStack(stack<int>& st) {
        if (st.empty()) return;
        int x = st.top(); st.pop();
        sortStack(st);
        insertSorted(st, x);
    }
};
```

### Java
```java
import java.util.Stack;

class Solution {
    private void insertSorted(Stack<Integer> st, int x) {
        if (st.isEmpty() || st.peek() <= x) {
            st.push(x);
            return;
        }
        int t = st.pop();
        insertSorted(st, x);
        st.push(t);
    }

    public void sortStack(Stack<Integer> st) {
        if (st.isEmpty()) return;
        int x = st.pop();
        sortStack(st);
        insertSorted(st, x);
    }
}
```

### Python
```python
class Solution:
    def sortStack(self, st: list) -> None:
        """st is a list used as a stack; st[-1] is the top."""
        def insert_sorted(x: int) -> None:
            if not st or st[-1] <= x:
                st.append(x)
                return
            t = st.pop()
            insert_sorted(x)
            st.append(t)

        if not st:
            return
        x = st.pop()
        self.sortStack(st)
        insert_sorted(x)
```

## Key Takeaways
- Two recursions: one peels elements off until the stack is empty, the other re-inserts each element at its sorted depth.
- The call stack replaces the auxiliary container, which is the whole point of the exercise.
- Flip the comparison (`top >= x`) if the smallest element should be on top instead.
- Duplicates are fine; the `<=` check keeps equal elements together without infinite recursion.
