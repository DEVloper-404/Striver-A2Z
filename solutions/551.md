# Shortest Job First

**Difficulty:** Medium  ·  **Topic:** Greedy Algorithms [Easy, Medium/Hard] › Medium/Hard

## Problem
You are given the burst times `bt[i]` of `n` processes that all arrive at time 0. The CPU runs them one after another using the Shortest Job First (SJF) policy: always execute the process with the smallest remaining burst time next. Return the **average waiting time** (floored to an integer), where a process's waiting time is the total time it spends waiting before it starts.

Input: `bt = [4, 3, 7, 1, 2]`
Output: `4` (order 1,2,3,4,7 → waits 0,1,3,6,10 → sum 20, 20/5 = 4)

## Approach 1: Simulation with repeated minimum search
Repeatedly find the unfinished process with the smallest burst time, run it, and add the elapsed time to every remaining process's waiting time. Each pick is a linear scan.
- **Time:** O(n²)
- **Space:** O(n)

## Approach 2: Sort and prefix sum (Optimal)
Because all processes arrive at the same time, SJF simply runs them in ascending order of burst time. The waiting time of the `k`-th process in that order is the sum of the burst times of everything before it.

1. Sort `bt` ascending.
2. Keep a running `elapsed` time; for each process, add `elapsed` to `totalWait`, then `elapsed += bt[i]`.
3. Return `totalWait / n` (integer division).

- **Time:** O(n log n)
- **Space:** O(1) extra (in-place sort)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    long long solve(vector<int>& bt) {
        sort(bt.begin(), bt.end());
        long long elapsed = 0, totalWait = 0;
        for (int t : bt) {
            totalWait += elapsed;
            elapsed += t;
        }
        return totalWait / (long long)bt.size();
    }
};
```

### Java
```java
import java.util.Arrays;

class Solution {
    public long solve(int[] bt) {
        Arrays.sort(bt);
        long elapsed = 0, totalWait = 0;
        for (int t : bt) {
            totalWait += elapsed;
            elapsed += t;
        }
        return totalWait / bt.length;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def solve(self, bt: List[int]) -> int:
        bt = sorted(bt)
        elapsed = total_wait = 0
        for t in bt:
            total_wait += elapsed
            elapsed += t
        return total_wait // len(bt)
```

## Key Takeaways
- With equal arrival times, SJF is just "sort by burst time"; the greedy is optimal because putting a shorter job first reduces the wait of every job after it.
- Use 64-bit sums: waiting times add up quickly for large inputs.
- If arrival times differ (the preemptive SRTF variant), you need a min-heap keyed on remaining time and a proper time simulation instead.
