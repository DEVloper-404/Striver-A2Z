# Implement queue using Linkedlist

**Difficulty:** Easy  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Learning

## Problem
Implement a queue backed by a singly linked list with no fixed capacity. Support `push(x)` (enqueue at the back), `pop()` (dequeue from the front), `front()`, `isEmpty()` and `size()`. Return -1 for `pop`/`front` on an empty queue.

Input: `push(4), push(8), push(15), pop(), front(), size()`
Output: `4, 8, 2`

## Approach: Head for dequeue, tail for enqueue
Keep two pointers: `head` (front of the queue) and `tail` (back). Appending at the tail and removing at the head are both O(1) when you maintain both pointers.

- `push(x)`: create a node; if the list is empty set both `head` and `tail` to it, otherwise link `tail->next` to it and move `tail` forward. `count++`.
- `pop()`: if `head` is null underflow; else save its value, move `head` to `head->next`, and if `head` became null also reset `tail` to null. `count--`.
- `front()`: `head`'s value.

The one subtle point is keeping `tail` valid when the queue becomes empty; forgetting that leaves a dangling pointer that the next push would write through.
- **Time:** O(1) per operation
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
class Queue {
    struct Node {
        int val;
        Node* next;
        explicit Node(int v) : val(v), next(nullptr) {}
    };
    Node* head = nullptr;
    Node* tail = nullptr;
    int count = 0;
public:
    ~Queue() { while (head) pop(); }

    void push(int x) {
        Node* node = new Node(x);
        if (!tail) head = tail = node;
        else { tail->next = node; tail = node; }
        count++;
    }
    int pop() {
        if (!head) return -1;
        Node* old = head;
        int val = old->val;
        head = head->next;
        if (!head) tail = nullptr;
        delete old;
        count--;
        return val;
    }
    int front() const { return head ? head->val : -1; }
    bool isEmpty() const { return head == nullptr; }
    int size() const { return count; }
};
```

### Java
```java
class Queue {
    private static class Node {
        int val; Node next;
        Node(int v) { val = v; }
    }
    private Node head = null, tail = null;
    private int count = 0;

    void push(int x) {
        Node node = new Node(x);
        if (tail == null) { head = tail = node; }
        else { tail.next = node; tail = node; }
        count++;
    }
    int pop() {
        if (head == null) return -1;
        int val = head.val;
        head = head.next;
        if (head == null) tail = null;
        count--;
        return val;
    }
    int front() { return head == null ? -1 : head.val; }
    boolean isEmpty() { return head == null; }
    int size() { return count; }
}
```

### Python
```python
class Node:
    __slots__ = ("val", "next")
    def __init__(self, val):
        self.val = val
        self.next = None

class Queue:
    def __init__(self):
        self.head = None
        self.tail = None
        self.count = 0

    def push(self, x: int) -> None:
        node = Node(x)
        if self.tail is None:
            self.head = self.tail = node
        else:
            self.tail.next = node
            self.tail = node
        self.count += 1

    def pop(self) -> int:
        if self.head is None:
            return -1
        val = self.head.val
        self.head = self.head.next
        if self.head is None:
            self.tail = None
        self.count -= 1
        return val

    def front(self) -> int:
        return -1 if self.head is None else self.head.val

    def is_empty(self) -> bool:
        return self.head is None

    def size(self) -> int:
        return self.count
```

## Key Takeaways
- Two pointers, `head` and `tail`, make both ends O(1); with only `head`, enqueue would be O(n).
- When the last node is removed, reset `tail` to null as well.
- The first push into an empty queue must set both pointers.
- No capacity limit and no wrap-around logic, unlike the circular array version.
