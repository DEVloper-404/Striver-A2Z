# Implement Min Stack

**Difficulty:** Hard  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Learning

## Problem
Design a stack that supports `push(x)`, `pop()`, `top()` and `getMin()`, where `getMin()` returns the smallest element currently in the stack, and every operation runs in constant time.

Input: `push(-2), push(0), push(-3), getMin(), pop(), top(), getMin()`
Output: `-3, 0, -2`

## Approach 1: Brute Force
Use a normal stack and, for `getMin()`, scan every element. Trivial but linear per query.
- **Time:** O(1) push/pop/top, O(n) getMin
- **Space:** O(n)

## Approach 2: Better (stack of pairs, O(2n) space)
Store with every element the minimum of the stack *at the time it was pushed*: push the pair `(x, min(x, currentMin))`. The top pair's second field is always the current minimum, and popping automatically restores the previous minimum.
- **Time:** O(1) for every operation
- **Space:** O(2n) — two values per element

## Approach 3: Optimal (encoded values, O(n) space)
Keep a single stack of numbers plus one variable `mn`. When pushing a value `x` that is smaller than `mn`, do not store `x` itself; instead store the encoded value `2x - mn` (which is guaranteed to be less than `x`, hence less than the new minimum) and set `mn = x`.

Decoding:
- `top()`: if the stored value `v` is `< mn`, it is encoded and the real top is `mn`; otherwise `v` is the real top.
- `pop()`: if the stored value `v` is `< mn`, the element being removed was a minimum; restore the previous minimum as `mn = 2*mn - v`.

Use 64-bit integers because `2x - mn` can exceed the 32-bit range.
- **Time:** O(1) for every operation
- **Space:** O(n) — one value per element plus one variable

## Code (Optimal)

### C++
```cpp
#include <stack>
using namespace std;

class MinStack {
    stack<long long> st;
    long long mn;
public:
    MinStack() : mn(0) {}

    void push(int val) {
        long long v = val;
        if (st.empty()) { st.push(v); mn = v; return; }
        if (v < mn) { st.push(2 * v - mn); mn = v; }
        else st.push(v);
    }
    void pop() {
        long long v = st.top(); st.pop();
        if (v < mn) mn = 2 * mn - v;      // encoded: restore previous min
    }
    int top() {
        long long v = st.top();
        return (int)(v < mn ? mn : v);
    }
    int getMin() { return (int)mn; }
};
```

### Java
```java
import java.util.*;

class MinStack {
    private final Deque<Long> st = new ArrayDeque<>();
    private long mn = 0;

    public void push(int val) {
        long v = val;
        if (st.isEmpty()) { st.push(v); mn = v; return; }
        if (v < mn) { st.push(2 * v - mn); mn = v; }
        else st.push(v);
    }
    public void pop() {
        long v = st.pop();
        if (v < mn) mn = 2 * mn - v;      // encoded: restore previous min
    }
    public int top() {
        long v = st.peek();
        return (int) (v < mn ? mn : v);
    }
    public int getMin() { return (int) mn; }
}
```

### Python
```python
class MinStack:
    def __init__(self):
        self.st = []
        self.mn = 0

    def push(self, val: int) -> None:
        if not self.st:
            self.st.append(val)
            self.mn = val
            return
        if val < self.mn:
            self.st.append(2 * val - self.mn)
            self.mn = val
        else:
            self.st.append(val)

    def pop(self) -> None:
        v = self.st.pop()
        if v < self.mn:
            self.mn = 2 * self.mn - v     # encoded: restore previous min

    def top(self) -> int:
        v = self.st[-1]
        return self.mn if v < self.mn else v

    def getMin(self) -> int:
        return self.mn
```

## Key Takeaways
- The pair-stack is the safe, readable solution; the encoding trick halves memory at the cost of clarity.
- Encoding invariant: a stored value below the current minimum marks a point where the minimum changed, and `2*mn - v` recovers the old minimum.
- Use 64-bit arithmetic; `2x - mn` overflows 32-bit ints for extreme inputs.
- Popping must update the minimum before anything else reads it.
