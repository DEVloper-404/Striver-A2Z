# Divide two numbers without multiplication and division

**Difficulty:** Medium  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Learn Bit Manipulation

## Problem
Given two 32-bit signed integers `dividend` and `divisor` (`divisor != 0`), compute the integer quotient truncated toward zero, using neither `*`, `/` nor `%`. If the true quotient overflows a 32-bit int (only possible for `INT_MIN / -1`), return `INT_MAX`.

Input: `dividend = 22`, `divisor = 3`
Output: `7` (`22 = 3·7 + 1`)

## Approach 1: Repeated subtraction
Work with absolute values. Subtract `divisor` from `dividend` until the remainder is smaller than the divisor, counting subtractions. Apply the sign at the end. Correct, but for `dividend = 2^31 - 1` and `divisor = 1` this loops two billion times.
- **Time:** O(dividend / divisor)
- **Space:** O(1)

## Approach 2: Subtract shifted multiples of the divisor (Optimal)
Long division in base 2. Keep a running `remaining = |dividend|`. For `k` from 31 down to 0, if `divisor << k` fits inside `remaining`, subtract it and add `1 << k` to the quotient. Each power of two is tried once, so the loop is 32 iterations regardless of the values.

Details that matter:
- Do the arithmetic in 64-bit so `|INT_MIN|` and `divisor << 31` do not overflow.
- The sign of the answer is negative exactly when the inputs have opposite signs: `(dividend < 0) ^ (divisor < 0)`.
- Handle `INT_MIN / -1` up front and return `INT_MAX`.
- **Time:** O(32) = O(1) — effectively `O(log |dividend|)`
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <climits>
#include <cstdlib>
using namespace std;

class Solution {
public:
    int divide(int dividend, int divisor) {
        if (dividend == INT_MIN && divisor == -1) return INT_MAX;
        bool negative = (dividend < 0) ^ (divisor < 0);
        long long a = llabs((long long)dividend);
        long long b = llabs((long long)divisor);
        long long q = 0;
        for (int k = 31; k >= 0; --k) {
            if ((b << k) <= a) {
                a -= (b << k);
                q += (1LL << k);
            }
        }
        return (int)(negative ? -q : q);
    }
};
```

### Python
```python
class Solution:
    def divide(self, dividend: int, divisor: int) -> int:
        INT_MAX, INT_MIN = 2**31 - 1, -2**31
        if dividend == INT_MIN and divisor == -1:
            return INT_MAX
        negative = (dividend < 0) != (divisor < 0)
        a, b = abs(dividend), abs(divisor)
        q = 0
        for k in range(31, -1, -1):
            if (b << k) <= a:
                a -= b << k
                q += 1 << k
        q = -q if negative else q
        return max(INT_MIN, min(INT_MAX, q))
```

## Key Takeaways
- Binary long division: greedily subtract the largest `divisor · 2^k` that fits, from high `k` to low.
- Promote to 64-bit before taking absolute values — `abs(INT_MIN)` does not fit in 32 bits.
- The only overflowing case is `INT_MIN / -1`; special-case it.
- Sign of the result is the XOR of the input signs; truncation toward zero comes for free from working with magnitudes.
