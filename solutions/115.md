# Bottom view of BT

**Difficulty:** Medium  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Medium Problems

## Problem
Looking at a binary tree from below, for each column (root at 0, left child `col - 1`, right child `col + 1`) the visible node is the deepest one in that column. If several nodes in a column share the maximum depth, the one that appears later in level order (the rightmost) is shown. Return the visible values from the leftmost column to the rightmost.

Input: root = [20,8,22,5,3,null,25,null,null,10,14]
Output: [5,10,3,14,25]
(column -1 has 8 at depth 1 and 10 at depth 3, so 10 wins; column 0 has 20 and 3 → 3; column 1 has 22 and 14 → 14)

Input: root = [1,2,3]
Output: [2,1,3]

## Approach 1: Vertical Traversal, Keep the Last of Each Column
Build the full vertical order (column → row → values) and take the last value of each column. Works, but stores far more than needed.

- **Time:** O(n log n)
- **Space:** O(n)

## Approach 2: BFS with Overwriting Column Map (Optimal)
Level order visits nodes in non-decreasing depth, and within a level from left to right. So if every node overwrites its column's entry, the value left at the end is the deepest node in that column, and ties are resolved toward the later (rightmost) node — exactly the required rule.

1. BFS with `(node, col)`.
2. `lastInCol[col] = node.val` unconditionally.
3. Emit values in ascending column order.
- **Time:** O(n log n) with an ordered map, O(n) with a hash map and a column range
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; ... } — standard definition
class Solution {
public:
    vector<int> bottomView(TreeNode* root) {
        vector<int> res;
        if (!root) return res;
        map<int, int> lastInCol;
        queue<pair<TreeNode*, int>> q;
        q.push({root, 0});
        while (!q.empty()) {
            auto [node, c] = q.front(); q.pop();
            lastInCol[c] = node->val;
            if (node->left)  q.push({node->left,  c - 1});
            if (node->right) q.push({node->right, c + 1});
        }
        for (auto& [c, v] : lastInCol) res.push_back(v);
        return res;
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
import java.util.*;

class Solution {
    public List<Integer> bottomView(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        TreeMap<Integer, Integer> lastInCol = new TreeMap<>();
        Queue<Object[]> q = new ArrayDeque<>();
        q.offer(new Object[]{root, 0});
        while (!q.isEmpty()) {
            Object[] cur = q.poll();
            TreeNode node = (TreeNode) cur[0];
            int c = (Integer) cur[1];
            lastInCol.put(c, node.val);
            if (node.left != null)  q.offer(new Object[]{node.left,  c - 1});
            if (node.right != null) q.offer(new Object[]{node.right, c + 1});
        }
        res.addAll(lastInCol.values());
        return res;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
from collections import deque

class Solution:
    def bottomView(self, root):
        if root is None:
            return []
        last_in_col = {}
        q = deque([(root, 0)])
        while q:
            node, c = q.popleft()
            last_in_col[c] = node.val
            if node.left:
                q.append((node.left, c - 1))
            if node.right:
                q.append((node.right, c + 1))
        return [last_in_col[c] for c in sorted(last_in_col)]
```

## Key Takeaways
- Top view = keep the first node seen per column in BFS; bottom view = keep the last. One line differs.
- BFS is essential: it makes "last written" equal "deepest, and rightmost among equals" without tracking depth explicitly.
- Some judges define the tie-break differently (leftmost instead of rightmost); confirm the expected convention before submitting.
