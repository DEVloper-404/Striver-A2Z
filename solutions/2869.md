# What are arrays, strings?

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Things to Know in C++/Java/Python or any language

## Problem
Arrays and strings are the two most basic containers in DSA. An **array** is a fixed-size block of elements of the same type stored contiguously in memory and accessed by a 0-based index. A **string** is a sequence of characters, usually backed by an array of `char`. This topic explains how to declare, fill, traverse and mutate them, and what operations cost.

Example task: given an array of integers, print the maximum element, and given a string, print it reversed.

```
Input:  arr = [3, 8, 1, 9, 4], s = "hello"
Output: 9
        olleh
```

## Approach: Arrays

1. **Declaration.** C++: `int a[5];` (static) or `vector<int> a(5);` (dynamic, resizable). Java: `int[] a = new int[5];` or `ArrayList<Integer>`. Python: a `list`, e.g. `a = [0] * 5`.
2. **Indexing.** Valid indices are `0 .. n-1`. Reading `a[n]` is undefined behaviour in C++, throws `ArrayIndexOutOfBoundsException` in Java, and `IndexError` in Python. Negative indices are only valid in Python (`a[-1]` is the last element).
3. **Traversal.** A for-loop over `i = 0 .. n-1`, or a range-based loop (`for (int x : a)`, `for x in a`).
4. **Costs.** Access by index is O(1) because the address is `base + i * sizeof(element)`. Inserting or deleting in the middle is O(n) since later elements must shift. Appending to a dynamic array is amortized O(1).
5. **2D arrays.** `vector<vector<int>> g(rows, vector<int>(cols, 0))`, `int[][] g = new int[rows][cols]`, `g = [[0]*cols for _ in range(rows)]` (never `[[0]*cols]*rows`, which aliases the same row).

## Approach: Strings

1. **Mutability.** C++ `std::string` is mutable (`s[0] = 'H'` works). Java `String` and Python `str` are immutable: every "modification" creates a new object, so building a string with repeated `+=` in a loop costs O(n^2). Use `StringBuilder` (Java) or collect pieces in a list and `"".join(...)` (Python).
2. **Common operations.** Length: `s.size()` / `s.length()` / `len(s)`. Substring: `s.substr(i, len)` / `s.substring(i, j)` / `s[i:j]`. Concatenate with `+`. Compare with `==` in C++ and Python but `equals()` in Java (`==` compares references).
3. **Characters are numbers.** `s[i] - 'a'` gives a 0..25 index, which is the basis of frequency-count arrays of size 26.
4. **Traversal is the same as arrays** — a string behaves like a read-only (or in C++ read-write) char array.

- **Time:** O(1) index access, O(n) traversal, O(n) for insert/delete in the middle
- **Space:** O(n) for n elements

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

int maxElement(const vector<int>& a) {
    int best = a[0];
    for (int i = 1; i < (int)a.size(); i++) {
        if (a[i] > best) best = a[i];
    }
    return best;
}

string reverseString(string s) {
    int l = 0, r = (int)s.size() - 1;
    while (l < r) {
        swap(s[l], s[r]);
        l++; r--;
    }
    return s;
}

int main() {
    vector<int> arr = {3, 8, 1, 9, 4};
    string s = "hello";
    cout << maxElement(arr) << '\n';
    cout << reverseString(s) << '\n';
    return 0;
}
```

### Java
```java
public class Main {
    static int maxElement(int[] a) {
        int best = a[0];
        for (int i = 1; i < a.length; i++) {
            if (a[i] > best) best = a[i];
        }
        return best;
    }

    static String reverseString(String s) {
        char[] c = s.toCharArray();       // strings are immutable, work on a copy
        int l = 0, r = c.length - 1;
        while (l < r) {
            char t = c[l]; c[l] = c[r]; c[r] = t;
            l++; r--;
        }
        return new String(c);
    }

    public static void main(String[] args) {
        int[] arr = {3, 8, 1, 9, 4};
        String s = "hello";
        System.out.println(maxElement(arr));
        System.out.println(reverseString(s));
    }
}
```

### Python
```python
from typing import List


def max_element(a: List[int]) -> int:
    best = a[0]
    for i in range(1, len(a)):
        if a[i] > best:
            best = a[i]
    return best


def reverse_string(s: str) -> str:
    chars = list(s)                 # str is immutable, so use a list
    l, r = 0, len(chars) - 1
    while l < r:
        chars[l], chars[r] = chars[r], chars[l]
        l += 1
        r -= 1
    return "".join(chars)


def main():
    arr = [3, 8, 1, 9, 4]
    s = "hello"
    print(max_element(arr))
    print(reverse_string(s))


if __name__ == "__main__":
    main()
```

## Key Takeaways
- Arrays give O(1) random access but O(n) insert/delete in the middle; indices run from 0 to n-1.
- Java and Python strings are immutable; use `StringBuilder` or `"".join()` to avoid O(n^2) concatenation.
- Compare Java strings with `equals()`, not `==`.
- For 2D grids in Python build each row separately, otherwise all rows share one list.
