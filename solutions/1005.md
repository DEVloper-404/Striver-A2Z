# Swap Two Numbers

**Difficulty:** Easy  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Learn Bit Manipulation

## Problem
Given two integers `a` and `b`, exchange their values without using a third (temporary) variable. Return or print them in swapped order.

Input: `a = 5`, `b = 9`
Output: `a = 9`, `b = 5`

## Approach 1: Arithmetic swap
Use addition and subtraction: `a = a + b; b = a - b; a = a - b;`. After the first step `a` holds the sum; subtracting the original `b` yields the original `a`, which we store in `b`; subtracting that from the sum yields the original `b`. Works, but `a + b` can overflow a fixed-width integer.
- **Time:** O(1)
- **Space:** O(1)

## Approach 2: XOR swap (Optimal)
XOR has the property `x ^ x = 0` and `x ^ 0 = x`. So:
1. `a = a ^ b` — `a` now holds the combined XOR.
2. `b = a ^ b` — `(a ^ b) ^ b = a`, so `b` becomes the original `a`.
3. `a = a ^ b` — `(a ^ b) ^ a = b`, so `a` becomes the original `b`.

No overflow is possible because XOR never produces a value wider than its inputs. One caveat: if `a` and `b` refer to the same memory location, the first step zeroes them both — only relevant when swapping through pointers/references.
- **Time:** O(1)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <utility>
using namespace std;

class Solution {
public:
    // returns {b, a} without a temporary variable
    pair<int,int> swapNumbers(int a, int b) {
        if (a != b) {          // guard for the aliasing case
            a ^= b;
            b ^= a;
            a ^= b;
        }
        return {a, b};
    }
};
```

### Java
```java

    public int[] swapNumbers(int a, int b) {

            a ^= b;

            a ^= b;
        }
        return new int[]{a, b};
    }
}
```

### Python
```python
from typing import Tuple

class Solution:
    def swapNumbers(self, a: int, b: int) -> Tuple[int, int]:
        if a != b:
            a ^= b
            b ^= a
            a ^= b
        return a, b
        # idiomatic Python: a, b = b, a
```

## Key Takeaways
- XOR swap relies on `x ^ x = 0`; three XORs in a row exchange two values in place.
- Unlike `a + b`, XOR cannot overflow.
- Skip the swap (or guard it) when both operands alias the same variable, or you zero it out.
- In real code use `std::swap`, a temp variable, or Python tuple unpacking — the XOR form is an interview trick, not a best practice.
