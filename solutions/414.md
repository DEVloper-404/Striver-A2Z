# Pattern 21

**Difficulty:** Medium  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a hollow `n × n` square of stars: the first and last rows and the first and last columns are stars, everything inside is a space.

Input: `n = 5`
Output:
```
*****
*   *
*   *
*   *
*****
```

## Approach
Treat the square as a grid and decide per cell whether it lies on the border.

1. Outer loop `i` from `0` to `n-1`, inner loop `j` from `0` to `n-1`.
2. A cell is on the border when `i == 0`, `i == n-1`, `j == 0`, or `j == n-1`. Print `*` for border cells and a space otherwise.
3. Newline after each row.

This cell-by-cell test is the general technique for any hollow or outlined figure; for the special case `n = 1` it correctly prints a single star.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern21(int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            bool border = (i == 0 || i == n - 1 || j == 0 || j == n - 1);
            cout << (border ? '*' : ' ');
        }
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern21 {
    public static void pattern21(int n) {
        for (int i = 0; i < n; i++) {
            StringBuilder row = new StringBuilder();
            for (int j = 0; j < n; j++) {
                boolean border = (i == 0 || i == n - 1 || j == 0 || j == n - 1);
                row.append(border ? '*' : ' ');
            }
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern21(n: int) -> None:
    for i in range(n):
        row = "".join(
            "*" if (i == 0 or i == n - 1 or j == 0 or j == n - 1) else " "
            for j in range(n)
        )
        print(row)
```

## Key Takeaways
- For outlined shapes, ask "is this cell on the edge?" rather than trying to build each row from runs.
- The four-way border test handles `n = 1` and `n = 2` without special cases.
- Trailing spaces never appear because the last column is always a star.
