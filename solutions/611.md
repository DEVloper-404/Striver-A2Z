# Clone a LL with random and next pointer

**Difficulty:** Hard  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Hard Problems of LL

## Problem
Each node of a linked list carries a value, a `next` pointer, and a `random` pointer that may point to any node in the list (or be null). Build a deep copy of the list: brand-new nodes with the same values, where every `next` and `random` in the copy points to the corresponding copied node, never to an original node.

Input: `[[7,null],[13,0],[11,4],[10,2],[1,0]]` (value, index of random target)
Output: a new list with the same shape: `[[7,null],[13,0],[11,4],[10,2],[1,0]]`

## Approach 1: Hash map from original to copy
Do one pass creating a fresh node for every original node and storing `map[original] = copy`. Do a second pass and for each original set `copy->next = map[original->next]` and `copy->random = map[original->random]`. The map is what lets us resolve a random pointer to the right copy in O(1).
- **Time:** O(n)
- **Space:** O(n) for the map

## Approach 2: Interleave copies, no extra map
The trick is to make the list itself act as the map: insert each copy right after its original, so `copy = original->next` for every node. Three passes:

1. **Interleave:** for every original `A`, create `A'` and link `A → A' → A.next`.
2. **Assign randoms:** for every original `A`, if `A->random` is not null, then `A'->random = A->random->next` (the copy of whatever `A` points to).
3. **Unzip:** separate the two interleaved lists, restoring the original `next` pointers and building the copy's `next` chain.

Only a few pointers are used; the extra space is just the output list itself.
- **Time:** O(n)
- **Space:** O(1) beyond the copied nodes

## Code (Optimal)

### C++
```cpp
// class Node { public: int val; Node* next; Node* random;
//              Node(int v) : val(v), next(nullptr), random(nullptr) {} }; // standard definition
class Solution {
public:
    Node* copyRandomList(Node* head) {
        if (!head) return nullptr;
        // 1. interleave
        for (Node* cur = head; cur; cur = cur->next->next) {
            Node* copy = new Node(cur->val);
            copy->next = cur->next;
            cur->next = copy;
        }
        // 2. randoms
        for (Node* cur = head; cur; cur = cur->next->next) {
            if (cur->random) cur->next->random = cur->random->next;
        }
        // 3. unzip
        Node dummy(0);
        Node* tail = &dummy;
        for (Node* cur = head; cur; cur = cur->next) {
            Node* copy = cur->next;
            cur->next = copy->next;
            tail->next = copy;
            tail = copy;
        }
        return dummy.next;
    }
};
```

### Java
```java
// class Node { int val; Node next, random; Node(int v) { val = v; } } // standard definition
class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) return null;
        for (Node cur = head; cur != null; cur = cur.next.next) {
            Node copy = new Node(cur.val);
            copy.next = cur.next;
            cur.next = copy;
        }
        for (Node cur = head; cur != null; cur = cur.next.next) {
            if (cur.random != null) cur.next.random = cur.random.next;
        }
        Node dummy = new Node(0), tail = dummy;
        for (Node cur = head; cur != null; cur = cur.next) {
            Node copy = cur.next;
            cur.next = copy.next;
            tail.next = copy;
            tail = copy;
        }
        return dummy.next;
    }
}
```

### Python
```python
# class Node:
#     def __init__(self, x, next=None, random=None):
#         self.val = x
#         self.next = next
#         self.random = random
# (standard definition)
class Solution:
    def copyRandomList(self, head):
        if head is None:
            return None
        cur = head
        while cur:
            copy = Node(cur.val, cur.next)
            cur.next = copy
            cur = copy.next
        cur = head
        while cur:
            if cur.random:
                cur.next.random = cur.random.next
            cur = cur.next.next
        dummy = Node(0)
        tail, cur = dummy, head
        while cur:
            copy = cur.next
            cur.next = copy.next
            tail.next = copy
            tail = copy
            cur = cur.next
        return dummy.next
```

## Key Takeaways
- The core difficulty is resolving `random`; both solutions build an original → copy lookup, either as a hash map or as the interleaved position.
- In the unzip step, restore the original list too; many judges check that the input was not damaged.
- `random` may be null, so guard before dereferencing `cur->random->next`.
- Never let a copy's pointer land on an original node; if you are unsure, verify with identity checks after building.
