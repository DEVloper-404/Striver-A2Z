# Matrix Chain Multiplication | Bottom-Up|(DP-49)

**Difficulty:** Hard  ·  **Topic:** Dynamic Programming [Patterns and Problems] › MCM DP | Partition DP

## Problem
Same task as the memoized version, solved iteratively. Given `arr` of length `n` describing `n - 1` matrices where matrix `i` is `arr[i-1] x arr[i]`, find the minimum number of scalar multiplications required to multiply the entire chain, given that multiplying `a x b` by `b x c` costs `a * b * c`. The goal here is to convert the top-down recursion into a bottom-up table, removing the recursion stack.

```
Input:  arr = [10, 20, 30, 40, 50]
Output: 38000
```

## Approach 1: Recall the recurrence
From DP-48 we have, for `1 <= i <= j <= n-1`:

```
f(i, i) = 0
f(i, j) = min over k in [i, j-1] of  f(i, k) + f(k+1, j) + arr[i-1]*arr[k]*arr[j]
```

- **Time:** O(n^3) with memoization
- **Space:** O(n^2) table + O(n) recursion stack

## Approach 2: Tabulation (Optimal)

**How to derive the loop order.** Tabulation must fill a cell only after every cell it reads is already filled. Look at the recurrence: `f(i, j)` reads `f(i, k)` with `k < j` (same row, smaller column) and `f(k+1, j)` with `k+1 > i` (same column, larger row). So:

- `j` must move **upward** (increasing), because we need smaller columns first.
- `i` must move **downward** (decreasing), because we need larger rows first.

That gives the standard MCM loop shape: `for i = n-1 down to 1`, `for j = i+1 up to n-1`. Equivalently you can loop over increasing interval **length**, which makes the dependency obvious: every cut produces two strictly shorter intervals.

**The algorithm step by step.**
1. Create `dp[n][n]` and set `dp[i][i] = 0` for all `i` (a lone matrix costs nothing).
2. For `i` from `n-1` down to `1`:
   - For `j` from `i+1` up to `n-1`:
     - Set `best = INF`.
     - For every cut `k` in `[i, j-1]`, compute `dp[i][k] + dp[k+1][j] + arr[i-1]*arr[k]*arr[j]` and keep the minimum.
     - Store `dp[i][j] = best`.
3. Answer is `dp[1][n-1]`.

Note the table is upper-triangular: cells with `i > j` are never used, and `i == j` is the base row of zeros.

**Dry run on `arr = [10, 20, 30, 40, 50]`, `n = 5`.** Diagonal `dp[i][i] = 0`.

Length-2 intervals:
- `dp[3][4] = 30*40*50 = 60000`
- `dp[2][3] = 20*30*40 = 24000`
- `dp[1][2] = 10*20*30 = 6000`

Length-3 intervals:
- `dp[2][4]`: `k=2` → `0 + 60000 + 20*30*50 = 90000`; `k=3` → `24000 + 0 + 20*40*50 = 64000` → **64000**
- `dp[1][3]`: `k=1` → `0 + 24000 + 10*20*40 = 32000`; `k=2` → `6000 + 0 + 10*30*40 = 18000` → **18000**

Length-4 interval:
- `dp[1][4]`: `k=1` → `0 + 64000 + 10*20*50 = 74000`; `k=2` → `6000 + 60000 + 10*30*50 = 81000`; `k=3` → `18000 + 0 + 10*40*50 = 38000` → **38000**

Answer `dp[1][4] = 38000`, matching the memoized run. Every cell was read only after being written, confirming the loop order.

- **Time:** O(n^3)
- **Space:** O(n^2), no recursion stack

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int matrixMultiplication(vector<int>& arr) {
        int n = arr.size();                       // n - 1 matrices
        if (n <= 2) return 0;

        vector<vector<int>> dp(n, vector<int>(n, 0));   // dp[i][i] = 0 already

        for (int i = n - 1; i >= 1; i--) {
            for (int j = i + 1; j <= n - 1; j++) {
                int best = INT_MAX;
                for (int k = i; k < j; k++) {
                    int cost = dp[i][k] + dp[k + 1][j]
                             + arr[i - 1] * arr[k] * arr[j];
                    best = min(best, cost);
                }
                dp[i][j] = best;
            }
        }
        return dp[1][n - 1];
    }
};
```

```java
class Solution {
    public int matrixMultiplication(int[] arr) {
        int n = arr.length;
        if (n <= 2) return 0;

        int[][] dp = new int[n][n];               // dp[i][i] = 0 by default

            for (int j = i + 1; j <= n - 1; j++) {
                int best = Integer.MAX_VALUE;
                for (int k = i; k < j; k++) {

                             + arr[i - 1] * arr[k] * arr[j];

            }
        }
        return dp[1][n - 1];
    }
}
```

### Python
```python
from typing import List

class Solution:
    def matrixMultiplication(self, arr: List[int]) -> int:
        n = len(arr)
        if n <= 2:
            return 0

        dp = [[0] * n for _ in range(n)]          # dp[i][i] = 0

        for i in range(n - 1, 0, -1):
            for j in range(i + 1, n):
                best = float('inf')
                for k in range(i, j):
                    cost = dp[i][k] + dp[k + 1][j] + arr[i - 1] * arr[k] * arr[j]
                    if cost < best:
                        best = cost
                dp[i][j] = best

        return dp[1][n - 1]
```

## Key Takeaways
- To tabulate a partition DP, read the recurrence's index directions: needing `f(i,k)` with `k<j` forces `j` ascending, needing `f(k+1,j)` with `k+1>i` forces `i` descending.
- Only the upper triangle `i <= j` is meaningful; the `i == j` diagonal is the base case of zeros.
- An equivalent, often clearer formulation loops over interval length from 2 to `n-1`.
- Tabulation removes the O(n) recursion stack but keeps the same O(n^3) time and O(n^2) space.
