# Insertion at the head of Linked List

**Difficulty:** Easy  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Learn 1D LinkedList

## Problem
Given the head of a singly linked list and a value `x`, insert a new node containing `x` at the front of the list and return the new head. The list may be empty.

Input: `head = 2 -> 5 -> 8, x = 1`
Output: `1 -> 2 -> 5 -> 8`

Input: `head = null, x = 7`
Output: `7`

## Approach 1: Rebuild the list
Copy all values into an array, prepend `x`, and build a fresh list. This works but throws away the O(1) advantage that linked lists offer for front insertion.
- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Relink two pointers (Optimal)
1. Create a new node holding `x`.
2. Point its `next` at the current head.
3. Return the new node as the head.

The existing nodes are untouched. If the list was empty, `next` becomes `null`, which is exactly a one-node list, so no special case is needed.
- **Time:** O(1)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int v) : val(v), next(nullptr) {} };
// (standard definition)

class Solution {
public:
    ListNode* insertAtHead(ListNode* head, int x) {
        ListNode* node = new ListNode(x);
        node->next = head;
        return node;
    }
};
```

### Java

### Python
```python
from typing import Optional

# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
# (standard definition)

class Solution:
    def insertAtHead(self, head: Optional["ListNode"], x: int) -> "ListNode":
        node = ListNode(x)
        node.next = head
        return node
```

## Key Takeaways
- Front insertion is the cheapest linked-list operation: allocate, link, return.
- The caller must use the returned pointer; the old head variable is now the second node.
- The empty-list case works with no extra branch because `node.next = null`.
- Contrast with arrays, where inserting at index 0 shifts every element.
