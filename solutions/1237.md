# Introduction to Singly LinkedList

**Difficulty:** Easy  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Learn 1D LinkedList

## Problem
This item introduces the singly linked list: what a node is, how nodes are chained through pointers, how the list is represented by its head, and how to build a list from an array and traverse it. As a concrete exercise, convert an array to a linked list and print its values.

Input: `arr = [2, 5, 8, 7]`
Output: `2 -> 5 -> 8 -> 7 -> null`

## Approach: What a singly linked list is

**Node.** A node holds a value and a pointer (reference) to the next node. The last node points to `null`.

```
head
 |
[2 | *] -> [5 | *] -> [8 | *] -> [7 | null]
```

**Why use it instead of an array?**
- Arrays are contiguous; inserting or deleting in the middle shifts elements (O(n)) and resizing may reallocate.
- Linked list nodes live anywhere in memory; inserting after a known node is O(1) because you only rewire two pointers.
- The cost: no random access. Reaching the k-th node requires walking k links (O(k)).

**Representation.** The whole list is identified by its `head` pointer. An empty list is `head == null`.

**Building from an array.** Create the first node as head, keep a `tail` pointer, and for each subsequent value create a node, link `tail.next` to it, and move `tail` forward.

**Traversal.** Start a temporary pointer at head and follow `next` until it becomes `null`. Never move `head` itself, or you lose the list.

**Memory note.** In C++ nodes are allocated with `new` and should be released with `delete` when no longer needed. Java and Python garbage-collect unreachable nodes automatically.
- **Time:** O(n) to build, O(n) to traverse
- **Space:** O(n) for the n nodes

## Code (Optimal)

### C++
```cpp
#include <iostream>
#include <vector>
using namespace std;

// Standard singly linked list node.
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v) : val(v), next(nullptr) {}
};

class Solution {
public:
    ListNode* arrayToList(const vector<int>& arr) {
        if (arr.empty()) return nullptr;
        ListNode* head = new ListNode(arr[0]);
        ListNode* tail = head;
        for (size_t i = 1; i < arr.size(); ++i) {
            tail->next = new ListNode(arr[i]);
            tail = tail->next;
        }
        return head;
    }

    void printList(ListNode* head) {
        for (ListNode* cur = head; cur != nullptr; cur = cur->next) {
            cout << cur->val << " -> ";
        }
        cout << "null\n";
    }
};
```

### Java
```java
// Standard singly linked list node.
class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}

class Solution {
    public ListNode arrayToList(int[] arr) {
        if (arr.length == 0) return null;
        ListNode head = new ListNode(arr[0]);
        ListNode tail = head;
        for (int i = 1; i < arr.length; i++) {
            tail.next = new ListNode(arr[i]);
            tail = tail.next;
        }
        return head;
    }

    public void printList(ListNode head) {
        StringBuilder sb = new StringBuilder();
        for (ListNode cur = head; cur != null; cur = cur.next) {
            sb.append(cur.val).append(" -> ");
        }
        System.out.println(sb.append("null"));
    }
}
```

### Python
```python
from typing import List, Optional

# Standard singly linked list node.
class ListNode:
    def __init__(self, val: int = 0, next: "Optional[ListNode]" = None):
        self.val = val
        self.next = next


class Solution:
    def arrayToList(self, arr: List[int]) -> Optional[ListNode]:
        if not arr:
            return None
        head = ListNode(arr[0])
        tail = head
        for v in arr[1:]:
            tail.next = ListNode(v)
            tail = tail.next
        return head

    def printList(self, head: Optional[ListNode]) -> None:
        parts = []
        cur = head
        while cur:
            parts.append(str(cur.val))
            cur = cur.next
        print(" -> ".join(parts + ["null"]))
```

## Key Takeaways
- A linked list is a chain of nodes; the `head` pointer is the only handle to the whole structure.
- Use a separate traversal pointer; never advance `head` during a walk.
- Keep a `tail` pointer while building so each append is O(1).
- Always handle the empty list (`head == null`) as a first-class case.
