# Word ladder II

**Difficulty:** Hard  ·  **Topic:** Graphs [Concepts & Problems] › Problems on BFS/DFS

## Problem
Given `beginWord`, `endWord` and a dictionary `wordList`, return **all** shortest transformation sequences from `beginWord` to `endWord`. Each step changes exactly one letter and every intermediate word must appear in `wordList`. If no sequence exists, return an empty list.

```
Input:  beginWord = "hit", endWord = "cog",
        wordList = ["hot","dot","dog","lot","log","cog"]
Output: [["hit","hot","dot","dog","cog"],
         ["hit","hot","lot","log","cog"]]
```

## Approach 1: Plain DFS over all paths (brute force)
Enumerate every simple path from `beginWord` to `endWord`, keep the shortest length seen, and filter. Correct but catastrophic: the number of paths is exponential, and most of them are far longer than the shortest.
- **Time:** exponential
- **Space:** O(N) recursion depth

## Approach 2: BFS storing whole paths in the queue
A popular first fix: make the queue hold *paths* rather than words. When a path's last word is `endWord`, record it; stop expanding once you pass the first level at which `endWord` appeared. It works, but every queue entry copies an entire vector of strings, so memory and time blow up on large inputs — this is the version that usually TLEs.

There is also a subtle correctness trap. You cannot mark a word visited as soon as one path uses it, because a *different* path of the **same** length may legitimately pass through it too (`hot` is on both answers above). The usual patch is to delete a level's words only after the whole level has been processed. Workable, but fiddly.
- **Time:** O(N · L² · 26 · P) with P paths, plus O(path length) copying per queue entry
- **Space:** O(P · path length)

## Approach 3: BFS for distances, then backward DFS (Optimal)
Split the problem in two, which is the standard way to enumerate all shortest paths in any unweighted graph:

**Phase 1 — forward BFS to label distances.** Run a normal BFS from `beginWord`, recording `steps[word]` = the length of the shortest sequence from `beginWord` to `word`. Assign `steps[w]` only the first time `w` is generated; that map doubles as the visited set, so every word is enqueued once and the phase is linear. No paths are stored yet.

**Phase 2 — backward DFS along decreasing distance.** Start at `endWord` and walk *backwards*. From a word `w` at distance `d`, a predecessor on some shortest path is any neighbour `p` with `steps[p] == d - 1`. Recurse into every such `p`; when you arrive at `beginWord`, reverse the accumulated list and record it.

Why this is exactly right:
- **Every produced sequence is a shortest one.** Each backward step decreases the distance by exactly 1, so a walk from `endWord` (distance `D`) down to `beginWord` (distance 1) has exactly `D` words — the BFS-optimal length.
- **Every shortest sequence is produced.** Take any shortest sequence; each of its words has `steps` value equal to its index, so consecutive words satisfy the `steps[p] == steps[w] - 1` condition at every step, and the DFS explores every such predecessor.
- **No wasted work.** The DFS only ever steps onto vertices that lie on some shortest path, so unlike Approach 1 it never explores a dead branch. Its cost is proportional to the size of the output.

Dry run on the example. Phase 1 BFS gives:
`hit → 1`, `hot → 2`, `dot → 3`, `lot → 3`, `dog → 4`, `log → 4`, `cog → 5`.

Phase 2 starts at `cog` (distance 5). Its one-letter neighbours in the dictionary are `dog` and `log`, both at distance 4 = 5 − 1, so both are valid predecessors:
- From `dog` (4): neighbours at distance 3 → `dot`. From `dot` (3): neighbours at distance 2 → `hot`. From `hot` (2): neighbours at distance 1 → `hit` = `beginWord` → emit `hit, hot, dot, dog, cog` (reversed from the accumulation).
- From `log` (4): → `lot` (3) → `hot` (2) → `hit` → emit `hit, hot, lot, log, cog`.

Both answers, no duplicates, nothing extra.

Practical notes: return an empty list immediately if `endWord ∉ wordList` or if the BFS never labels `endWord`. Keep `beginWord` in `steps` with value 1 even though it may not be in the dictionary. And do not erase words from the dictionary during phase 1 — the backward DFS needs to test membership again.

Let `N = |wordList|`, `L = word length`, `P` = number of shortest sequences.
- **Time:** O(N · L² · 26) for the BFS plus O(P · D · L · 26) to emit the answers
- **Space:** O(N · L) for the distance map plus O(D) recursion

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <string>
#include <queue>
#include <unordered_map>
#include <unordered_set>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<string>> findLadders(string beginWord, string endWord, vector<string>& wordList) {
        unordered_set<string> dict(wordList.begin(), wordList.end());
        vector<vector<string>> ans;
        if (!dict.count(endWord)) return ans;

        // Phase 1: BFS to label every reachable word with its shortest distance.
        unordered_map<string,int> steps;
        steps[beginWord] = 1;
        queue<string> q;
        q.push(beginWord);
        int L = beginWord.size();

        while (!q.empty()) {
            string word = q.front(); q.pop();
            int d = steps[word];
            if (word == endWord) break;                 // no deeper level can help
            for (int i = 0; i < L; i++) {
                char original = word[i];
                for (char ch = 'a'; ch <= 'z'; ch++) {
                    if (ch == original) continue;
                    word[i] = ch;
                    if (dict.count(word) && !steps.count(word)) {
                        steps[word] = d + 1;            // first label = shortest
                        q.push(word);
                    }
                }
                word[i] = original;
            }
        }
        if (!steps.count(endWord)) return ans;

        // Phase 2: walk backwards from endWord along strictly decreasing distance.
        vector<string> path{endWord};
        backtrack(endWord, beginWord, dict, steps, path, ans);
        return ans;
    }

private:
    void backtrack(string word, const string& beginWord,
                   unordered_set<string>& dict, unordered_map<string,int>& steps,
                   vector<string>& path, vector<vector<string>>& ans) {
        if (word == beginWord) {
            vector<string> seq(path.rbegin(), path.rend());
            ans.push_back(seq);
            return;
        }
        int d = steps[word];
        for (int i = 0; i < (int)word.size(); i++) {
            char original = word[i];
            for (char ch = 'a'; ch <= 'z'; ch++) {
                if (ch == original) continue;
                word[i] = ch;
                auto it = steps.find(word);
                if (it != steps.end() && it->second + 1 == d) {
                    path.push_back(word);
                    backtrack(word, beginWord, dict, steps, path, ans);
                    path.pop_back();
                }
            }
            word[i] = original;
        }
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public List<List<String>> findLadders(String beginWord, String endWord, List<String> wordList) {
        Set<String> dict = new HashSet<>(wordList);
        List<List<String>> ans = new ArrayList<>();
        if (!dict.contains(endWord)) return ans;

        Map<String,Integer> steps = new HashMap<>();
        steps.put(beginWord, 1);
        Queue<String> q = new LinkedList<>();
        q.add(beginWord);

        while (!q.isEmpty()) {
            String word = q.poll();
            int d = steps.get(word);
            if (word.equals(endWord)) break;
            char[] arr = word.toCharArray();
            for (int i = 0; i < arr.length; i++) {
                char original = arr[i];
                for (char ch = 'a'; ch <= 'z'; ch++) {
                    if (ch == original) continue;
                    arr[i] = ch;
                    String cand = new String(arr);
                    if (dict.contains(cand) && !steps.containsKey(cand)) {
                        steps.put(cand, d + 1);
                        q.add(cand);
                    }
                }
                arr[i] = original;
            }
        }
        if (!steps.containsKey(endWord)) return ans;

        LinkedList<String> path = new LinkedList<>();
        path.add(endWord);
        backtrack(endWord, beginWord, steps, path, ans);
        return ans;
    }

    private void backtrack(String word, String beginWord, Map<String,Integer> steps,
                           LinkedList<String> path, List<List<String>> ans) {
        if (word.equals(beginWord)) {
            List<String> seq = new ArrayList<>(path);
            Collections.reverse(seq);
            ans.add(seq);
            return;
        }
        int d = steps.get(word);
        char[] arr = word.toCharArray();
        for (int i = 0; i < arr.length; i++) {
            char original = arr[i];
            for (char ch = 'a'; ch <= 'z'; ch++) {
                if (ch == original) continue;
                arr[i] = ch;
                String cand = new String(arr);
                Integer pd = steps.get(cand);
                if (pd != null && pd + 1 == d) {
                    path.add(cand);
                    backtrack(cand, beginWord, steps, path, ans);
                    path.removeLast();
                }
            }
            arr[i] = original;
        }
    }
}
```

### Python
```python
from collections import deque
from typing import List
import string

class Solution:
    def findLadders(self, beginWord: str, endWord: str, wordList: List[str]) -> List[List[str]]:
        dict_set = set(wordList)
        if endWord not in dict_set:
            return []

        # Phase 1: BFS distances from beginWord
        steps = {beginWord: 1}
        q = deque([beginWord])
        while q:
            word = q.popleft()
            if word == endWord:
                break
            d = steps[word]
            for i in range(len(word)):
                for ch in string.ascii_lowercase:
                    if ch == word[i]:
                        continue
                    cand = word[:i] + ch + word[i + 1:]
                    if cand in dict_set and cand not in steps:
                        steps[cand] = d + 1
                        q.append(cand)

        if endWord not in steps:
            return []

        # Phase 2: backward DFS along decreasing distance
        ans = []
        path = [endWord]

        def backtrack(word: str) -> None:
            if word == beginWord:
                ans.append(path[::-1])
                return
            d = steps[word]
            for i in range(len(word)):
                for ch in string.ascii_lowercase:
                    if ch == word[i]:
                        continue
                    cand = word[:i] + ch + word[i + 1:]
                    if steps.get(cand, -1) + 1 == d:
                        path.append(cand)
                        backtrack(cand)
                        path.pop()

        backtrack(endWord)
        return ans
```

## Key Takeaways
- Enumerating *all* shortest paths splits cleanly into BFS-for-distances then DFS-along-decreasing-distance; never store whole paths in the queue.
- The `steps` map is both the distance labelling and the visited set — assign it only on first discovery.
- A word may lie on several shortest sequences, so you must not permanently mark it used during the path enumeration.
- The backward DFS never wanders off a shortest path, so its cost is proportional to the size of the output.
