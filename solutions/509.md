# Word ladder I

**Difficulty:** Hard  ·  **Topic:** Graphs [Concepts & Problems] › Problems on BFS/DFS

## Problem
Given `beginWord`, `endWord` and a dictionary `wordList` (all words the same length), a transformation sequence changes one letter at a time, and **every intermediate word must be in `wordList`**. Return the number of words in the shortest such sequence from `beginWord` to `endWord`, counting both ends, or `0` if no sequence exists.

```
Input:  beginWord = "hit", endWord = "cog",
        wordList = ["hot","dot","dog","lot","log","cog"]
Output: 5      ("hit" → "hot" → "dot" → "dog" → "cog")
```

## Approach 1: See the hidden graph
Nothing here looks like a graph until you name the pieces:
- **Vertices** = words (`beginWord` plus every word in the dictionary).
- **Edges** = an undirected edge between two words that differ in exactly one position.
- **Weights** = all 1, since each transformation is a single step.

The question "shortest transformation sequence" is then literally "shortest path in an unweighted graph", which is BFS. Two consequences follow immediately: DFS is the wrong tool (it finds *a* path, not the shortest), and no priority queue is needed (all edges cost 1, so the first time BFS reaches a word is already optimal).

A naive implementation builds the graph explicitly by comparing every pair of words: with `N` words of length `L` that is O(N²·L) just to construct the adjacency list, which is far too slow for `N = 5000`.
- **Time:** O(N²·L) to build + O(N + E) to search
- **Space:** O(N²) worst case for the adjacency list

## Approach 2: BFS over neighbours generated on the fly (Optimal)
Skip building the graph. Given a word, its neighbours can be *generated*: for each of the `L` positions, try all 26 letters, and keep the results that are in the dictionary. Put the dictionary in a hash set so membership is O(L) (the cost of hashing the string). That gives 26·L candidate neighbours per word, and no O(N²) comparison pass.

Algorithm:
1. Put `wordList` into a hash set `dict`. If `endWord ∉ dict`, return `0` — no valid sequence can finish.
2. Queue holds `(word, steps)`. Push `(beginWord, 1)` (the problem counts `beginWord` as step 1) and erase `beginWord` from `dict`.
3. Pop `(word, steps)`. If `word == endWord`, return `steps`.
4. For each position `i` in `word` and each letter `ch` in `a..z`, form `candidate` by replacing `word[i]` with `ch`. If `candidate` is in `dict`, **erase it from `dict`** and push `(candidate, steps + 1)`.
5. If the queue drains without hitting `endWord`, return `0`.

The erase in step 4 is the visited marker, and it is what keeps the algorithm linear. Because BFS reaches every word at its minimum possible step count, deleting a word the first time it is generated can never discard a shorter route — any later arrival at that word would be through an equal or longer path. Skipping the erase makes the queue blow up exponentially.

Dry run on the example. `dict = {hot,dot,dog,lot,log,cog}`, queue `[("hit",1)]`, erase `hit` (not present anyway).
- Pop `("hit",1)`. Mutating position 0 gives `ait..zit` — none in dict. Position 1 gives `hat..hzt`; `hot` is in dict → erase it, push `("hot",2)`. Position 2 gives `hia..hiz` — none.
- Pop `("hot",2)`. Position 0: `dot` ✓ → push `("dot",3)`; `lot` ✓ → push `("lot",3)`. Position 1: nothing (`hit` was already removed). Position 2: nothing.
- Pop `("dot",3)`. Position 2 gives `dog` ✓ → push `("dog",4)`. (`lot` already erased.)
- Pop `("lot",3)`. Position 2 gives `log` ✓ → push `("log",4)`.
- Pop `("dog",4)`. Position 0 gives `cog` ✓ → push `("cog",5)`. (`log` already erased.)
- Pop `("log",4)` — `cog` is gone from dict, nothing new.
- Pop `("cog",5)` → equals `endWord` → return **5**. Correct.

Note the answer counts *words*, not transformations — a common off-by-one. Also, `beginWord` need not be in `wordList`, but `endWord` must be.

Let `N = |wordList|` and `L = word length`. Each word is dequeued at most once and generates 26·L candidates, each costing O(L) to build and hash.
- **Time:** O(N · L² · 26)
- **Space:** O(N · L) for the set and the queue

## Approach 3: Bidirectional BFS
Run two BFS frontiers, one from `beginWord` and one from `endWord`, always expanding the smaller one, and stop when they meet. If the branching factor is `b` and the answer is depth `d`, this explores roughly `2·b^(d/2)` instead of `b^d` words — a large practical win, though the worst-case complexity class is unchanged. It needs a `visited` map on each side and careful handling of the meeting level.
- **Time:** O(N · L² · 26) worst case, far better in practice
- **Space:** O(N · L)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <string>
#include <queue>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
        unordered_set<string> dict(wordList.begin(), wordList.end());
        if (dict.find(endWord) == dict.end()) return 0;

        queue<pair<string,int>> q;
        q.push({beginWord, 1});
        dict.erase(beginWord);

        while (!q.empty()) {
            auto [word, steps] = q.front(); q.pop();
            if (word == endWord) return steps;
            for (int i = 0; i < (int)word.size(); i++) {
                char original = word[i];
                for (char ch = 'a'; ch <= 'z'; ch++) {
                    if (ch == original) continue;
                    word[i] = ch;
                    if (dict.count(word)) {
                        dict.erase(word);          // visited marker
                        q.push({word, steps + 1});
                    }
                }
                word[i] = original;                // restore before next position
            }
        }
        return 0;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        Set<String> dict = new HashSet<>(wordList);
        if (!dict.contains(endWord)) return 0;

        Queue<String> q = new LinkedList<>();
        q.add(beginWord);
        dict.remove(beginWord);
        int steps = 1;

        while (!q.isEmpty()) {
            int levelSize = q.size();              // process one BFS level at a time
            for (int s = 0; s < levelSize; s++) {
                String word = q.poll();
                if (word.equals(endWord)) return steps;
                char[] arr = word.toCharArray();
                for (int i = 0; i < arr.length; i++) {
                    char original = arr[i];
                    for (char ch = 'a'; ch <= 'z'; ch++) {
                        if (ch == original) continue;
                        arr[i] = ch;
                        String cand = new String(arr);
                        if (dict.remove(cand)) q.add(cand);
                    }
                    arr[i] = original;
                }
            }
            steps++;
        }
        return 0;
    }
}
```

### Python
```python
from collections import deque
from typing import List
import string

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int:
        dict_set = set(wordList)
        if endWord not in dict_set:
            return 0

        q = deque([(beginWord, 1)])
        dict_set.discard(beginWord)

        while q:
            word, steps = q.popleft()
            if word == endWord:
                return steps
            for i in range(len(word)):
                for ch in string.ascii_lowercase:
                    if ch == word[i]:
                        continue
                    cand = word[:i] + ch + word[i + 1:]
                    if cand in dict_set:
                        dict_set.discard(cand)     # visited marker
                        q.append((cand, steps + 1))
        return 0
```

## Key Takeaways
- Words are vertices, one-letter differences are unit-weight edges — "shortest transformation" is plain BFS.
- Generate neighbours by mutating each position over 26 letters instead of comparing all pairs; that turns O(N²L) into O(N·L²·26).
- Deleting a word from the dictionary the first time you reach it is the visited marker and is safe because BFS reaches it at its minimum depth.
- Return `0` early if `endWord` is not in the list, and remember the answer counts words, not transformations.
