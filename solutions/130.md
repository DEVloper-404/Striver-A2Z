# Diameter of Binary Tree

**Difficulty:** Easy  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Medium Problems

## Problem
The diameter of a binary tree is the length (number of edges) of the longest path between any two nodes. The path does not have to pass through the root. Given the root, return the diameter.

Input: root = [1,2,3,4,5]
Output: 3  (path 4 → 2 → 1 → 3 or 5 → 2 → 1 → 3)

Input: root = [1,2]
Output: 1

## Approach 1: Height at Every Node (Brute Force)
The longest path that "turns" at a node `x` has length `height(x.left) + height(x.right)`. So visit every node, compute both subtree heights with a separate recursive height function, and keep the maximum sum.

Heights are recomputed for every ancestor, so the cost compounds.
- **Time:** O(n²) worst case (skewed), O(n log n) if balanced
- **Space:** O(h)

## Approach 2: Height with Side Effect (Optimal)
Compute the height in one post-order pass and, while returning from each node, update a shared answer with `lh + rh`. The height function still returns `1 + max(lh, rh)` for its parent, but the diameter candidate `lh + rh` is recorded before returning.

1. Null node: return 0.
2. `lh = height(left)`, `rh = height(right)`.
3. `best = max(best, lh + rh)`.
4. Return `1 + max(lh, rh)`.

Every node is the "turning point" candidate exactly once.
- **Time:** O(n)
- **Space:** O(h)

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; ... } — standard definition
class Solution {
    int best = 0;
    int height(TreeNode* node) {
        if (!node) return 0;
        int lh = height(node->left);
        int rh = height(node->right);
        best = max(best, lh + rh);
        return 1 + max(lh, rh);
    }
public:
    int diameterOfBinaryTree(TreeNode* root) {
        best = 0;
        height(root);
        return best;
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
class Solution {
    private int best;

    private int height(TreeNode node) {
        if (node == null) return 0;
        int lh = height(node.left);
        int rh = height(node.right);
        best = Math.max(best, lh + rh);
        return 1 + Math.max(lh, rh);
    }

    public int diameterOfBinaryTree(TreeNode root) {
        best = 0;
        height(root);
        return best;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
class Solution:
    def diameterOfBinaryTree(self, root) -> int:
        self.best = 0

        def height(node):
            if node is None:
                return 0
            lh = height(node.left)
            rh = height(node.right)
            self.best = max(self.best, lh + rh)
            return 1 + max(lh, rh)

        height(root)
        return self.best
```

## Key Takeaways
- Diameter is measured in edges, so the candidate at a node is `lh + rh` (heights in nodes), not `lh + rh + 1`.
- The pattern "return one thing to the parent, record another thing globally" recurs in max path sum and many tree DP problems.
- The longest path need not go through the root; that is exactly why every node must be considered as the turning point.
