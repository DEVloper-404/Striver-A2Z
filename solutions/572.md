# Convert Min Heap to Max Heap

**Difficulty:** Medium  ·  **Topic:** Heaps [Learning, Medium, Hard Problems] › Learning

## Problem
You are given an array `arr` that is a valid min heap (array representation). Rearrange it in place so that it becomes a valid max heap: every parent must be greater than or equal to its children. Any valid max heap arrangement of the same values is accepted.

Input: `arr = [3, 5, 9, 6, 8, 20, 10, 12, 18, 9]`
Output: `[20, 18, 10, 12, 9, 9, 3, 5, 6, 8]` (one valid answer)

## Approach 1: Sort Descending
A descending sorted array is trivially a max heap (every parent index is smaller than its children's indices, so its value is at least as large). Sort in decreasing order and return.

- **Time:** O(n log n)
- **Space:** O(1) extra (or O(log n) for the sort's recursion)

## Approach 2: Rebuild by Repeated Insertion
Treat the array as empty and insert each element into a growing max heap using sift up. Correct, but each insertion can cost O(log n).

- **Time:** O(n log n)
- **Space:** O(1)

## Approach 3: Bottom-Up Heapify (Optimal)
The fact that the input is a min heap is irrelevant; any array can be turned into a max heap with the standard build-heap procedure. Starting from the last internal node `n/2 - 1` and moving down to index `0`, run *sift down* (max-heap version): swap the node with its larger child while a child exceeds it.

When we process index `i`, both of its subtrees are already max heaps (they were fixed earlier because their roots have larger indices), so sifting down restores the property for the whole subtree rooted at `i`. Summing the cost over all levels gives O(n), because there are many shallow subtrees and only one deep one.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    void siftDown(vector<int>& a, int i, int n) {
        while (true) {
            int l = 2 * i + 1, r = 2 * i + 2, largest = i;
            if (l < n && a[l] > a[largest]) largest = l;
            if (r < n && a[r] > a[largest]) largest = r;
            if (largest == i) return;
            swap(a[i], a[largest]);
            i = largest;
        }
    }
public:
    void convertMinToMaxHeap(vector<int>& arr) {
        int n = arr.size();
        for (int i = n / 2 - 1; i >= 0; --i) siftDown(arr, i, n);
    }
};
```

### Java
```java
class Solution {
    private void siftDown(int[] a, int i, int n) {
        while (true) {
            int l = 2 * i + 1, r = 2 * i + 2, largest = i;
            if (l < n && a[l] > a[largest]) largest = l;
            if (r < n && a[r] > a[largest]) largest = r;
            if (largest == i) return;
            int t = a[i]; a[i] = a[largest]; a[largest] = t;
            i = largest;
        }
    }

    public void convertMinToMaxHeap(int[] arr) {
        int n = arr.length;
        for (int i = n / 2 - 1; i >= 0; i--) siftDown(arr, i, n);
    }
}
```

### Python
```python
from typing import List

class Solution:
    def convertMinToMaxHeap(self, arr: List[int]) -> None:
        n = len(arr)

        def sift_down(i: int) -> None:
            while True:
                l, r, largest = 2 * i + 1, 2 * i + 2, i
                if l < n and arr[l] > arr[largest]:
                    largest = l
                if r < n and arr[r] > arr[largest]:
                    largest = r
                if largest == i:
                    return
                arr[i], arr[largest] = arr[largest], arr[i]
                i = largest

        for i in range(n // 2 - 1, -1, -1):
            sift_down(i)
```

## Key Takeaways
- Building a heap bottom-up is O(n); the input being a min heap gives no shortcut worth exploiting.
- Process internal nodes from the last one backwards so that every subtree is already a heap when its root is fixed.
- The same routine with `<` instead of `>` converts any array into a min heap.
- Multiple valid outputs exist; graders normally verify the heap property rather than an exact array.
