# Kosaraju's algorithm

**Difficulty:** Hard  ·  **Topic:** Graphs [Concepts & Problems] › Other Algorithms

## Problem
Given a **directed** graph with `V` vertices, count (or list) its **strongly connected components** (SCCs). An SCC is a maximal set of vertices such that every vertex in the set can reach every other vertex in the set. Kosaraju's algorithm finds all SCCs with two depth-first searches.

```
Input:  V = 6, edges = [[0,1],[1,2],[2,0],[2,3],[3,4],[4,5],[5,3]]
Output: 2
        SCCs: {0,1,2} and {3,4,5}
```
Vertices `0,1,2` form a cycle, `3,4,5` form another. The edge `2 → 3` is one-way, so the two groups are not mutually reachable and stay separate.

## Approach 1: Brute force — reachability from every pair
Compute, for each vertex `u`, the set of vertices reachable from `u` (one DFS per vertex). Then `u` and `v` belong to the same SCC exactly when `v` is reachable from `u` **and** `u` is reachable from `v`. Group vertices by this relation.

Correct but expensive: `V` traversals to build the reachability table, then `O(V²)` pair checks.
- **Time:** O(V · (V + E))
- **Space:** O(V²) for the reachability table

## Approach 2: Kosaraju — two DFS passes (Optimal)

**The core difficulty.** A plain DFS spills out of an SCC: starting inside `{0,1,2}` you also walk into `{3,4,5}` through `2 → 3`, so one DFS tree mixes several SCCs. We need a way to start each DFS so that it *cannot* escape its own component.

**Observation 1 — the condensation is a DAG.** Contract each SCC into a single node. The resulting graph has no cycle: a cycle between two contracted nodes would mean the two SCCs are mutually reachable, so they would really be one SCC. So SCCs have a well-defined topological order.

**Observation 2 — reversing the edges keeps SCCs identical but flips the DAG.** If `u` and `v` reach each other in `G`, they still do in `G^R` (just reverse each path). But the *inter*-component edges all flip direction. So a component that could "leak" into others in `G` becomes a component that is a sink in `G^R` — a DFS started there gets trapped inside it.

**Observation 3 — finish times give the topological order.** Run a DFS on `G` and push each vertex onto a stack when it *finishes* (all its descendants are done). Popping the stack visits SCCs in topological order of the condensation: the SCC that comes first in the order is on top.

Combine the three: pop the stack, and for each unvisited vertex run a DFS **on the reversed graph**. Because that vertex belongs to the topologically-earliest remaining SCC, in `G^R` every edge that leaves its SCC now points *into* already-visited territory. The DFS therefore collects exactly one SCC. Repeat until the stack empties; each restart is one more SCC.

**Algorithm.**
1. DFS over all vertices of `G`; push a vertex to a stack when its recursion returns (post-order / finish time).
2. Build `G^R` by reversing every edge.
3. Clear the visited array. While the stack is non-empty: pop `u`; if unvisited, run a DFS on `G^R` from `u`, collecting every vertex it reaches — that group is one SCC. Increment the count.

**Dry run on the example.** Pass 1 from `0`: `0 → 1 → 2 → 3 → 4 → 5`; `5 → 3` hits a visited vertex, so `5` finishes first, then `4`, `3`, `2`, `1`, `0`. Stack from bottom to top: `[5,4,3,2,1,0]`.

Pass 2 on the reversed graph (edges `1→0, 2→1, 0→2, 3→2, 4→3, 5→4, 3→5`): pop `0` — DFS reaches `0 → 2 → 1` and stops (`2`'s reverse-neighbour `3` does not exist; only `3→2` existed, which reversed is `2→3`… careful: reversed edge of `2→3` is `3→2`, so from `2` we cannot get to `3`). SCC #1 = `{0,2,1}`. Pop `1`, `2` — already visited. Pop `3` — DFS reaches `3 → 2`? no, reversed edges out of `3` are `3→2` and `3→5`; `2` is visited, `5` is new, `5 → 4 → 3(visited)`. SCC #2 = `{3,5,4}`. Pop `4`, `5` — visited. **Count = 2.** ✔
- **Time:** O(V + E) — two DFS traversals plus one pass to reverse the edges.
- **Space:** O(V + E) for the reversed adjacency list and the stack.

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    void order(int u, vector<vector<int>>& adj, vector<char>& vis, stack<int>& st) {
        vis[u] = 1;
        for (int v : adj[u])
            if (!vis[v]) order(v, adj, vis, st);
        st.push(u);                       // push on finish
    }

    void collect(int u, vector<vector<int>>& radj, vector<char>& vis, vector<int>& comp) {
        vis[u] = 1;
        comp.push_back(u);
        for (int v : radj[u])
            if (!vis[v]) collect(v, radj, vis, comp);
    }

public:
    // returns the list of SCCs; size() is the SCC count
    vector<vector<int>> kosaraju(int V, vector<vector<int>>& adj) {
        vector<char> vis(V, 0);
        stack<int> st;
        for (int i = 0; i < V; i++)
            if (!vis[i]) order(i, adj, vis, st);

        vector<vector<int>> radj(V);      // reverse every edge
        for (int u = 0; u < V; u++)
            for (int v : adj[u]) radj[v].push_back(u);

        fill(vis.begin(), vis.end(), 0);
        vector<vector<int>> sccs;
        while (!st.empty()) {
            int u = st.top(); st.pop();
            if (vis[u]) continue;
            vector<int> comp;
            collect(u, radj, vis, comp);
            sccs.push_back(comp);
        }
        return sccs;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private void order(int u, List<List<Integer>> adj, boolean[] vis, Deque<Integer> st) {
        vis[u] = true;
        for (int v : adj.get(u))
            if (!vis[v]) order(v, adj, vis, st);
        st.push(u);
    }

    private void collect(int u, List<List<Integer>> radj, boolean[] vis, List<Integer> comp) {
        vis[u] = true;
        comp.add(u);
        for (int v : radj.get(u))
            if (!vis[v]) collect(v, radj, vis, comp);
    }

    public List<List<Integer>> kosaraju(int V, List<List<Integer>> adj) {
        boolean[] vis = new boolean[V];
        Deque<Integer> st = new ArrayDeque<>();
        for (int i = 0; i < V; i++)
            if (!vis[i]) order(i, adj, vis, st);

        List<List<Integer>> radj = new ArrayList<>();
        for (int i = 0; i < V; i++) radj.add(new ArrayList<>());
        for (int u = 0; u < V; u++)
            for (int v : adj.get(u)) radj.get(v).add(u);

        Arrays.fill(vis, false);
        List<List<Integer>> sccs = new ArrayList<>();
        while (!st.isEmpty()) {
            int u = st.pop();
            if (vis[u]) continue;
            List<Integer> comp = new ArrayList<>();
            collect(u, radj, vis, comp);
            sccs.add(comp);
        }
        return sccs;
    }
}
```

### Python
```python
import sys
from typing import List


class Solution:
    def kosaraju(self, V: int, adj: List[List[int]]) -> List[List[int]]:
        sys.setrecursionlimit(10 ** 6)

        vis = [False] * V
        stack = []

        def order(u: int) -> None:
            vis[u] = True
            for v in adj[u]:
                if not vis[v]:
                    order(v)
            stack.append(u)              # push on finish

        for i in range(V):
            if not vis[i]:
                order(i)

        radj = [[] for _ in range(V)]    # reverse every edge
        for u in range(V):
            for v in adj[u]:
                radj[v].append(u)

        vis = [False] * V
        sccs = []

        def collect(u: int, comp: List[int]) -> None:
            vis[u] = True
            comp.append(u)
            for v in radj[u]:
                if not vis[v]:
                    collect(v, comp)

        while stack:
            u = stack.pop()
            if vis[u]:
                continue
            comp = []
            collect(u, comp)
            sccs.append(comp)

        return sccs
```

## Key Takeaways
- SCCs of a directed graph condense into a DAG; that is what makes a topological ordering of components meaningful.
- Pass 1 records finish times (a topological order of the condensation); pass 2 runs on the **reversed** graph so each DFS is trapped inside one component.
- Reversal preserves SCCs but flips all inter-component edges — that is the entire trick.
- Push a vertex on the stack **after** its recursion returns, not when it is first seen; pushing early breaks the ordering.
- Tarjan's algorithm solves the same problem in a single DFS, but Kosaraju is far easier to remember and derive.
