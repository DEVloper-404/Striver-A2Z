# Stock span problem

**Difficulty:** Hard  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Implementation Problems

## Problem
Daily stock prices arrive one at a time. The *span* of today's price is the number of consecutive days ending today (including today) on which the price was less than or equal to today's price. Design a `StockSpanner` class with a method `next(price)` that returns the span for each new price in order. The offline version — given the whole price array, output all spans — uses the same idea.

```
Input:  prices fed in order: 100, 80, 60, 70, 60, 75, 85
Output: 1, 1, 1, 2, 1, 4, 6
```
75 covers itself plus 60, 70, 60 → span 4; 85 covers everything back to (but not including) 100 → span 6.

## Approach 1: Brute Force
For each new price, walk backwards through the stored history counting days until a strictly larger price is found.
- **Time:** O(n) per call, O(n²) total
- **Space:** O(n)

## Approach 2: Monotonic Stack of (price, span) (Optimal)
The span of today's price is `today - (index of previous strictly greater price)`. Keep a stack of `(price, span)` pairs with strictly decreasing prices. When a new price arrives:
1. Start with `span = 1`.
2. While the top price is ≤ the new price, add the top's span to `span` and pop (those days are all absorbed).
3. Push `(price, span)` and return `span`.

Storing spans rather than indices removes the need to count calls. Each pair is pushed once and popped at most once, so the amortised cost per call is constant.
- **Time:** O(1) amortised per `next`, O(n) total
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <stack>
#include <utility>
using namespace std;

class StockSpanner {
    stack<pair<int,int>> st;   // (price, span), prices strictly decreasing
public:
    StockSpanner() {}

    int next(int price) {
        int span = 1;
        while (!st.empty() && st.top().first <= price) {
            span += st.top().second;
            st.pop();
        }
        st.push({price, span});
        return span;
    }
};
```

### Java
```java
import java.util.*;

class StockSpanner {
    private final Deque<int[]> st = new ArrayDeque<>();   // {price, span}

    public StockSpanner() {}

    public int next(int price) {
        int span = 1;
        while (!st.isEmpty() && st.peek()[0] <= price) {
            span += st.pop()[1];
        }
        st.push(new int[]{price, span});
        return span;
    }
}
```

### Python
```python
class StockSpanner:
    def __init__(self):
        self.st = []   # (price, span)

    def next(self, price: int) -> int:
        span = 1
        while self.st and self.st[-1][0] <= price:
            span += self.st.pop()[1]
        self.st.append((price, span))
        return span
```

## Key Takeaways
- Stock span is "distance to the previous greater element" in disguise; the online form just requires storing spans on the stack.
- Pop on `<=` because equal prices count towards the span.
- Amortised analysis: total pops never exceed total pushes, so a sequence of n calls costs O(n) even though one call can pop many items.
