# Reverse a Stack

**Difficulty:** Medium  ·  **Topic:** Recursion [PatternWise] › Get a Strong Hold

## Problem
Given a stack, reverse the order of its elements in place so that the old bottom becomes the new top. You may only use the stack's own operations (`push`, `pop`, `top`, `empty`) plus recursion; no auxiliary stack, queue, or array.

Input: stack (bottom → top) `[1, 2, 3, 4]`
Output: stack (bottom → top) `[4, 3, 2, 1]` (top is `1`)

## Approach 1: Use a second stack
Pop every element into an array (the array now holds top-to-bottom order), then push the array elements back starting from index 0. The old top is pushed first and ends up at the bottom, which is the reversal we want. This is trivial but uses O(n) extra explicit storage, which the problem disallows.
- **Time:** O(n)
- **Space:** O(n) auxiliary container

## Approach 2: Recursion with "insert at bottom"
Two recursive helpers do the job:

1. `insertAtBottom(st, x)`: if the stack is empty, push `x`. Otherwise pop the top `t`, recursively insert `x` at the bottom, then push `t` back. This buries `x` under all existing elements.
2. `reverse(st)`: if the stack is empty, return. Pop the top `x`, recursively reverse the rest, then `insertAtBottom(st, x)`.

Why it works: after the recursive `reverse` the remaining elements are already reversed, and the element that used to be on top should now be at the very bottom, which is exactly what `insertAtBottom` does. Every popped element is held in a recursion frame, so no other memory is needed.
- **Time:** O(n²) — each insert-at-bottom walks the whole stack.
- **Space:** O(n) recursion depth

## Code (Optimal)

### C++
```cpp
#include <stack>
using namespace std;

class Solution {
    void insertAtBottom(stack<int>& st, int x) {
        if (st.empty()) {
            st.push(x);
            return;
        }
        int t = st.top(); st.pop();
        insertAtBottom(st, x);
        st.push(t);
    }
public:
    void reverseStack(stack<int>& st) {
        if (st.empty()) return;
        int x = st.top(); st.pop();
        reverseStack(st);
        insertAtBottom(st, x);
    }
};
```

### Java
```java
import java.util.Stack;

class Solution {
    private void insertAtBottom(Stack<Integer> st, int x) {
        if (st.isEmpty()) {
            st.push(x);
            return;
        }
        int t = st.pop();
        insertAtBottom(st, x);
        st.push(t);
    }

    public void reverseStack(Stack<Integer> st) {
        if (st.isEmpty()) return;
        int x = st.pop();
        reverseStack(st);
        insertAtBottom(st, x);
    }
}
```

### Python
```python
class Solution:
    def reverseStack(self, st: list) -> None:
        """st is a list used as a stack; st[-1] is the top."""
        def insert_at_bottom(x: int) -> None:
            if not st:
                st.append(x)
                return
            t = st.pop()
            insert_at_bottom(x)
            st.append(t)

        if not st:
            return
        x = st.pop()
        self.reverseStack(st)
        insert_at_bottom(x)
```

## Key Takeaways
- "Insert at bottom" is the reusable building block; reversing is just "pop, reverse the rest, insert at bottom".
- The recursion depth equals the stack size, so for very large stacks an iterative approach with explicit storage would be needed.
- Compare with "Sort a stack": same skeleton, only the insertion condition differs.
- Empty and single-element stacks are handled by the base case with no special code.
