# Zig Zag or Spiral Traversal

**Difficulty:** Medium  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Medium Problems

## Problem
Given the root of a binary tree, return its nodes level by level, but alternate the direction on each level: the first level left-to-right, the second right-to-left, the third left-to-right, and so on. Output is a list of lists, one per level.

Input: root = [3,9,20,null,null,15,7]
Output: [[3],[20,9],[15,7]]

Input: root = []
Output: []

## Approach 1: Level Order, Then Reverse Alternate Levels
Do a normal BFS that produces a list per level. Afterwards, reverse every level with an odd index. Simple, but each odd level is touched twice.

- **Time:** O(n)
- **Space:** O(n) for the output plus O(w) for the queue

## Approach 2: BFS with Index Placement (Optimal)
Keep the same BFS, but pre-size each level's array and write each popped node into the correct slot directly:

1. Track a boolean `leftToRight`, starting true.
2. For a level of size `k`, create an array of length `k`. Pop the `i`-th node of the level; if `leftToRight`, put it at index `i`, otherwise at index `k - 1 - i`.
3. Flip the flag after each level.

Children are always pushed left child first, so the queue order stays a plain level order; only the placement changes. A deque-based alternative (alternating which end you pop from) works too but is easier to get wrong.
- **Time:** O(n)
- **Space:** O(n) for the output, O(w) for the queue

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; ... } — standard definition
class Solution {
public:
    vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
        vector<vector<int>> res;
        if (!root) return res;
        queue<TreeNode*> q;
        q.push(root);
        bool leftToRight = true;
        while (!q.empty()) {
            int k = q.size();
            vector<int> level(k);
            for (int i = 0; i < k; ++i) {
                TreeNode* node = q.front(); q.pop();
                int idx = leftToRight ? i : k - 1 - i;
                level[idx] = node->val;
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
            res.push_back(level);
            leftToRight = !leftToRight;
        }
        return res;
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
import java.util.*;

class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;
        Queue<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        boolean leftToRight = true;
        while (!q.isEmpty()) {
            int k = q.size();
            Integer[] level = new Integer[k];
            for (int i = 0; i < k; i++) {
                TreeNode node = q.poll();
                int idx = leftToRight ? i : k - 1 - i;
                level[idx] = node.val;
                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }
            res.add(Arrays.asList(level));
            leftToRight = !leftToRight;
        }
        return res;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
from collections import deque

class Solution:
    def zigzagLevelOrder(self, root):
        res = []
        if root is None:
            return res
        q = deque([root])
        left_to_right = True
        while q:
            k = len(q)
            level = [0] * k
            for i in range(k):
                node = q.popleft()
                idx = i if left_to_right else k - 1 - i
                level[idx] = node.val
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            res.append(level)
            left_to_right = not left_to_right
        return res
    ```

## Key Takeaways
- Keep the queue in ordinary level order and only change where each value is written; that avoids subtle bugs with child push order.
- The level size captured before the inner loop is what separates levels — a standard BFS idiom.
- Empty root must return an empty list, not a list containing an empty list.
