# Pattern 2

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a right-angled triangle of stars with `n` rows. Row `i` (1-indexed) contains exactly `i` stars separated by spaces.

Input: `n = 5`
Output:
```
*
* *
* * *
* * * *
* * * * *
```

## Approach
The only difference from the solid square is that the inner loop bound now depends on the row index.

1. Outer loop `i` from `1` to `n`.
2. Inner loop `j` from `1` to `i` prints `"* "`, so row `i` gets `i` stars.
3. Newline after each row.

Key observation: making the inner bound equal to the row number produces a triangle that grows by one star per row.

- **Time:** O(n²) — total stars = 1 + 2 + … + n = n(n+1)/2.
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern2(int n) {
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            cout << "* ";
        }
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern2 {
    public static void pattern2(int n) {
        for (int i = 1; i <= n; i++) {
            StringBuilder row = new StringBuilder();
            for (int j = 1; j <= i; j++) {
                row.append("* ");
            }
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern2(n: int) -> None:
    for i in range(1, n + 1):
        print("* " * i)
```

## Key Takeaways
- Inner loop bound tied to the row index gives a growing triangle.
- Using 1-based row numbering keeps the "row i has i items" relationship obvious.
- The same skeleton works for numbers or letters by changing what is printed inside the inner loop.
