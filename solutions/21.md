# Find the repeating and missing number

**Difficulty:** Hard  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Hard

## Problem
An array `a` of length n is supposed to contain each integer from 1 to n exactly once, but one value `A` appears twice and another value `B` is absent. Find `A` (the repeating number) and `B` (the missing number) and return them as `[A, B]`.

Input: `a = [4, 3, 6, 2, 1, 1]`
Output: `[1, 5]`

## Approach 1: Brute Force
For each value `v` in 1..n, count its occurrences by scanning the array; a count of 2 marks the repeat, a count of 0 marks the missing value.
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Frequency array
Allocate `cnt[1..n]`, tally each element, then scan `cnt` for the index with 2 and the index with 0.
- **Time:** O(n)
- **Space:** O(n)

## Approach 3: Two equations (sum and sum of squares)
Let `S = 1 + 2 + ... + n` and `S2 = 1² + ... + n²`. With actual sums `Sa` and `S2a` from the array:
- `Sa - S = A - B`
- `S2a - S2 = A² - B² = (A - B)(A + B)`

Divide to get `A + B`, then solve the two linear equations. Needs 64-bit arithmetic because `S2` reaches ~n³/3.
- **Time:** O(n)
- **Space:** O(1)

## Approach 4: XOR bucket split (Optimal, no overflow risk)
1. XOR all array elements with all numbers 1..n. Every correctly present value cancels out, leaving `x = A ^ B`.
2. `x` is non-zero, so pick any set bit (e.g. the lowest). `A` and `B` differ at that bit.
3. Partition both the array elements and the numbers 1..n by that bit, XOR-ing each partition separately. One partition yields `A`, the other `B`.
4. To tell which is which, count how many times the first partition's result appears in the array: if it appears twice, it is the repeat.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> findMissingRepeating(vector<int>& a) {
        int n = a.size();
        int x = 0;
        for (int i = 0; i < n; ++i) { x ^= a[i]; x ^= (i + 1); }
        int bit = x & -x;               // lowest set bit where A and B differ

        int g0 = 0, g1 = 0;
        for (int i = 0; i < n; ++i) {
            if (a[i] & bit) g1 ^= a[i]; else g0 ^= a[i];
            if ((i + 1) & bit) g1 ^= (i + 1); else g0 ^= (i + 1);
        }

        int cnt = 0;
        for (int v : a) if (v == g1) ++cnt;
        if (cnt == 2) return {g1, g0};  // g1 repeats, g0 missing
        return {g0, g1};
    }
};
```

### Java

```java
class Solution {
    public int[] findMissingRepeating(int[] a) {
        int n = a.length;
        int x = 0;
        for (int i = 0; i < n; i++) { x ^= a[i]; x ^= (i + 1); }
        int bit = x & -x;

        int g0 = 0, g1 = 0;
        for (int i = 0; i < n; i++) {
            if ((a[i] & bit) != 0) g1 ^= a[i]; else g0 ^= a[i];
            if (((i + 1) & bit) != 0) g1 ^= (i + 1); else g0 ^= (i + 1);
        }

        int cnt = 0;
        for (int v : a) if (v == g1) cnt++;
        return cnt == 2 ? new int[]{g1, g0} : new int[]{g0, g1};
    }
}
```

### Python
```python
from typing import List

class Solution:
    def findMissingRepeating(self, a: List[int]) -> List[int]:
        n = len(a)
        x = 0
        for i in range(n):
            x ^= a[i]
            x ^= i + 1
        bit = x & -x

        g0 = g1 = 0
        for i in range(n):
            if a[i] & bit:
                g1 ^= a[i]
            else:
                g0 ^= a[i]
            if (i + 1) & bit:
                g1 ^= i + 1
            else:
                g0 ^= i + 1

        cnt = sum(1 for v in a if v == g1)
        return [g1, g0] if cnt == 2 else [g0, g1]
```

## Key Takeaways
- Two unknowns need two independent facts: (sum, sum of squares) or (XOR, bucket XOR).
- The math approach is simpler to write but the squares sum overflows 32-bit quickly; use `long long`.
- The XOR approach produces `{A, B}` unordered; a final count pass is what assigns roles.
