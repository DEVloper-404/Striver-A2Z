# Insert node before head in Doubly Linked List

**Difficulty:** Easy  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Learn Doubly LinkedList

## Problem
You are given the head of a doubly linked list and an integer `x`. Create a new node holding `x` and place it in front of the current head, so it becomes the new head. Return the new head. The same wiring idea covers the sibling operation of appending at the tail, which is shown as a second approach.

```
Input:  head = 2 <-> 3 <-> 4, x = 1
Output: 1 <-> 2 <-> 3 <-> 4
```

## Approach 1: Insert before head (three link updates)
1. Create `node` with value `x`.
2. Point `node.next` at the old head.
3. If the old head exists, set `head.prev = node` so the backward link is consistent.
4. Return `node` as the new head. Its `prev` stays null.

If the list was empty, the new node is simply the whole list.

- **Time:** O(1)
- **Space:** O(1)

## Approach 2: Insert at the tail (for completeness)
Walk to the last node (the one whose `next` is null), then attach: `tail.next = node`, `node.prev = tail`. Unlike the head insert, this costs a traversal unless you also maintain a tail pointer.

- **Time:** O(n) without a tail pointer, O(1) with one
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct DNode { int val; DNode* prev; DNode* next; DNode(int v) : val(v), prev(nullptr), next(nullptr) {} };

class Solution {
public:
    DNode* insertBeforeHead(DNode* head, int x) {
        DNode* node = new DNode(x);
        node->next = head;
        if (head) head->prev = node;
        return node;
    }

    DNode* insertAtTail(DNode* head, int x) {
        DNode* node = new DNode(x);
        if (!head) return node;
        DNode* tail = head;
        while (tail->next) tail = tail->next;
        tail->next = node;
        node->prev = tail;
        return head;
    }
};
```

### Java
```java
// class DNode { int val; DNode prev, next; DNode(int v) { val = v; } }

class Solution {
    public DNode insertBeforeHead(DNode head, int x) {
        DNode node = new DNode(x);
        node.next = head;
        if (head != null) head.prev = node;
        return node;
    }

    public DNode insertAtTail(DNode head, int x) {
        DNode node = new DNode(x);
        if (head == null) return node;
        DNode tail = head;
        while (tail.next != null) tail = tail.next;
        tail.next = node;
        node.prev = tail;
        return head;
    }
}
```

```python
class Solution:
    def insertBeforeHead(self, head, x):
        node = DNode(x)
        node.next = head
        if head:
            head.prev = node
        return node

    def insertAtTail(self, head, x):
        node = DNode(x)
        if not head:
            return node
        tail = head
        while tail.next:
            tail = tail.next
        tail.next = node
        node.prev = tail
        return head
```

## Key Takeaways
- Every DLL insertion touches two directions: the new node's own links and the neighbour's link back to it.
- Inserting before the head is O(1) and always changes what "head" means, so return the new node.
- Guard the empty-list case before dereferencing `head.prev`.
- Tail insertion is the mirror image; keeping a tail pointer turns it into O(1).
