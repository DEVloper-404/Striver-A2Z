# Learn All Patterns of Subsequences (Theory)

**Difficulty:** Easy  ·  **Topic:** Recursion [PatternWise] › Subsequences Pattern

## Problem
This is a theory item. It covers the recursive template behind every "subsequence" problem and the four question types built on it: print all subsequences that satisfy a condition, print only one, count how many, and check whether at least one exists. Knowing these variants lets you solve a whole family of problems by changing a couple of lines.

Running example: `arr = [1, 2, 1]`, target sum `k = 2`. Valid subsequences are `[1, 1]` and `[2]`.

## Approach
### The base recursion: take or not take
At index `i` you either include `arr[i]` in the current subsequence or skip it, then move to `i + 1`. When `i == n` the buffer holds one complete subsequence. This produces `2^n` leaves.

```cpp
void gen(int i, vector<int>& cur, const vector<int>& arr) {
    if (i == arr.size()) { /* process cur */ return; }
    cur.push_back(arr[i]);    // take
    gen(i + 1, cur, arr);
    cur.pop_back();           // backtrack
    gen(i + 1, cur, arr);     // not take
}
```

### Variant 1: print all subsequences with sum k
Carry the running sum as a parameter. At the leaf, print only if `sum == k`.

```cpp
void printAll(int i, int sum, vector<int>& cur, const vector<int>& arr, int k) {
    if (i == arr.size()) { if (sum == k) print(cur); return; }
    cur.push_back(arr[i]);
    printAll(i + 1, sum + arr[i], cur, arr, k);
    cur.pop_back();
    printAll(i + 1, sum, cur, arr, k);
}
```
Time O(2^n · n), space O(n) recursion depth.

### Variant 2: print only one subsequence
Make the function return a boolean. If the "take" branch found an answer, return `true` immediately so the "not take" branch never runs. This is the standard trick for "find any one" problems.

```cpp
bool printOne(int i, int sum, vector<int>& cur, const vector<int>& arr, int k) {
    if (i == arr.size()) { if (sum == k) { print(cur); return true; } return false; }
    cur.push_back(arr[i]);
    if (printOne(i + 1, sum + arr[i], cur, arr, k)) return true;
    cur.pop_back();
    return printOne(i + 1, sum, cur, arr, k);
}
```

### Variant 3: count the subsequences
Return an integer. The leaf returns `1` if the condition holds, else `0`. The result of a call is the sum of the two branches. No buffer is needed because nothing is printed.

```cpp
int count(int i, int sum, const vector<int>& arr, int k) {
    if (i == arr.size()) return sum == k ? 1 : 0;
    return count(i + 1, sum + arr[i], arr, k) + count(i + 1, sum, arr, k);
}
```

### Variant 4: check existence
Same as counting, but combine the branches with logical OR so the search stops at the first success.

```cpp
bool exists(int i, int sum, const vector<int>& arr, int k) {
    if (i == arr.size()) return sum == k;
    return exists(i + 1, sum + arr[i], arr, k) || exists(i + 1, sum, arr, k);
}
```

### The pick-any-index form (used by Combination Sum, Subsets II)
Instead of take/not-take at each index, loop over candidate indices `j` from `i` to `n-1`, pick `arr[j]`, recurse with `j + 1` (or `j` if repeats allowed). Every level of recursion adds one element. Sorting the input and skipping `arr[j] == arr[j-1]` inside the loop removes duplicate subsequences. Both forms enumerate the same subsets; this one makes "skip duplicates" trivial.

- **Time:** All variants are O(2^n) in the worst case; early return in variants 2 and 4 helps in practice.
- **Space:** O(n) recursion depth.

## Code (Optimal)
Below is the take/not-take template with all four variants wired to the same helper, so the differences are visible side by side.

### C++
```cpp
#include <vector>
using namespace std;

class SubsequencePatterns {
public:
    // Variant 1: collect all with sum k
    void all(int i, int sum, vector<int>& cur, const vector<int>& a, int k, vector<vector<int>>& out) {
        if (i == (int)a.size()) { if (sum == k) out.push_back(cur); return; }
        cur.push_back(a[i]); all(i + 1, sum + a[i], cur, a, k, out); cur.pop_back();
        all(i + 1, sum, cur, a, k, out);
    }
    // Variant 2: first one found
    bool one(int i, int sum, vector<int>& cur, const vector<int>& a, int k, vector<int>& ans) {
        if (i == (int)a.size()) { if (sum == k) { ans = cur; return true; } return false; }
        cur.push_back(a[i]);
        if (one(i + 1, sum + a[i], cur, a, k, ans)) return true;
        cur.pop_back();
        return one(i + 1, sum, cur, a, k, ans);
    }
    // Variant 3: count
    int count(int i, int sum, const vector<int>& a, int k) {
        if (i == (int)a.size()) return sum == k ? 1 : 0;
        return count(i + 1, sum + a[i], a, k) + count(i + 1, sum, a, k);
    }
    // Variant 4: exists
    bool exists(int i, int sum, const vector<int>& a, int k) {
        if (i == (int)a.size()) return sum == k;
        return exists(i + 1, sum + a[i], a, k) || exists(i + 1, sum, a, k);
    }
};
```

### Java
```java
import java.util.ArrayList;
import java.util.List;

class SubsequencePatterns {
    void all(int i, int sum, List<Integer> cur, int[] a, int k, List<List<Integer>> out) {
        if (i == a.length) { if (sum == k) out.add(new ArrayList<>(cur)); return; }
        cur.add(a[i]); all(i + 1, sum + a[i], cur, a, k, out); cur.remove(cur.size() - 1);
        all(i + 1, sum, cur, a, k, out);
    }

    boolean one(int i, int sum, List<Integer> cur, int[] a, int k, List<Integer> ans) {
        if (i == a.length) { if (sum == k) { ans.addAll(cur); return true; } return false; }
        cur.add(a[i]);
        if (one(i + 1, sum + a[i], cur, a, k, ans)) return true;
        cur.remove(cur.size() - 1);
        return one(i + 1, sum, cur, a, k, ans);
    }

    int count(int i, int sum, int[] a, int k) {
        if (i == a.length) return sum == k ? 1 : 0;
        return count(i + 1, sum + a[i], a, k) + count(i + 1, sum, a, k);
    }

    boolean exists(int i, int sum, int[] a, int k) {
        if (i == a.length) return sum == k;
        return exists(i + 1, sum + a[i], a, k) || exists(i + 1, sum, a, k);
    }
}
```

### Python
```python
from typing import List

class SubsequencePatterns:
    def all(self, i, s, cur, a, k, out):
        if i == len(a):
            if s == k:
                out.append(cur[:])
            return
        cur.append(a[i]); self.all(i + 1, s + a[i], cur, a, k, out); cur.pop()
        self.all(i + 1, s, cur, a, k, out)

    def one(self, i, s, cur, a, k, ans):
        if i == len(a):
            if s == k:
                ans.extend(cur)
                return True
            return False
        cur.append(a[i])
        if self.one(i + 1, s + a[i], cur, a, k, ans):
            return True
        cur.pop()
        return self.one(i + 1, s, cur, a, k, ans)

    def count(self, i, s, a, k):
        if i == len(a):
            return 1 if s == k else 0
        return self.count(i + 1, s + a[i], a, k) + self.count(i + 1, s, a, k)

    def exists(self, i, s, a, k):
        if i == len(a):
            return s == k
        return self.exists(i + 1, s + a[i], a, k) or self.exists(i + 1, s, a, k)
```

## Key Takeaways
- One recursion, four return types: void (print all), bool with early return (print one / exists), int (count).
- Carry state (running sum, current buffer) as parameters; undo the buffer change after the "take" branch.
- "Print one" and "exists" must stop exploring after the first hit; returning the boolean up the chain does that.
- The pick-any-index loop form is interchangeable with take/not-take and is the natural fit when duplicates must be skipped.
