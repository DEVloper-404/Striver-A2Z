# XOR of numbers in a given range

**Difficulty:** Medium  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Interview Problems

## Problem
Given two integers `L` and `R` with `0 <= L <= R`, compute `L ^ (L+1) ^ ... ^ R`, the XOR of every integer in the inclusive range.

Input: `L = 3`, `R = 6`
Output: `3 ^ 4 ^ 5 ^ 6 = 4`

## Approach 1: XOR every number in the range
Loop from `L` to `R` and accumulate the XOR. Fine for small ranges but linear in `R - L`, which can be up to 10^9 or more.
- **Time:** O(R - L)
- **Space:** O(1)

## Approach 2: Prefix XOR formula (Optimal)
Let `f(n) = 0 ^ 1 ^ ... ^ n`. Because XOR is its own inverse, the range XOR is `f(R) ^ f(L - 1)` — everything below `L` cancels out.

`f(n)` has a closed form with period 4. Consider consecutive pairs `(2k, 2k+1)`: they differ only in bit 0, so `2k ^ (2k+1) = 1`. Hence:
- `n % 4 == 0`: the numbers `1..n` form pairs `(1,2)...` that don't line up; direct computation shows `f(n) = n`.
- `n % 4 == 1`: `f(n) = f(n-1) ^ n = (n-1) ^ n = 1`.
- `n % 4 == 2`: `f(n) = 1 ^ n = n + 1` (since `n` is even, XOR with 1 adds one).
- `n % 4 == 3`: `f(n) = (n + 1 - 1 ... )` — pairs `(n-1, n)` XOR to 1 and the earlier `1` cancels it: `f(n) = 0`.

Verify: `f(0)=0, f(1)=1, f(2)=3, f(3)=0, f(4)=4, f(5)=1, f(6)=7, f(7)=0`. The pattern `n, 1, n+1, 0` repeats.
- **Time:** O(1)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
    int prefixXor(int n) {            // XOR of 0..n
        if (n < 0) return 0;
        switch (n % 4) {
            case 0: return n;
            case 1: return 1;
            case 2: return n + 1;
            default: return 0;
        }
    }
public:
    int xorRange(int L, int R) {
        return prefixXor(R) ^ prefixXor(L - 1);
    }
};
```

### Python
```python
class Solution:
    def _prefix_xor(self, n: int) -> int:
        if n < 0:
            return 0
        r = n % 4
        if r == 0:
            return n
        if r == 1:
            return 1
        if r == 2:
            return n + 1
        return 0

    def xorRange(self, L: int, R: int) -> int:
        return self._prefix_xor(R) ^ self._prefix_xor(L - 1)
```

## Key Takeaways
- Range XOR = prefix XOR up to `R` XOR prefix XOR up to `L-1`, exactly like prefix sums but with XOR as the inverse of itself.
- `f(n) = 0^1^...^n` cycles with period 4: `n, 1, n+1, 0`.
- Handle `L = 0` by returning `0` for `prefixXor(-1)`.
- Memorise the four cases; they show up in many "XOR of a range" and "XOR of an arithmetic pattern" questions.
