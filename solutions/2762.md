# Sort an array of 0's 1's and 2's

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Medium

## Problem
You are given an array that contains only the values 0, 1 and 2. Rearrange it in place so that all 0s come first, then all 1s, then all 2s. Doing it with a library sort is not the point; the goal is a single linear pass without extra memory.

```
Input:  nums = [2, 0, 2, 1, 1, 0]
Output: [0, 0, 1, 1, 2, 2]
```

## Approach 1: Brute Force (Library Sort)
Call the built-in sort. It works, but it is a comparison sort that ignores the fact that there are only three distinct values.
- **Time:** O(n log n)
- **Space:** O(1) to O(log n) depending on the sort implementation

## Approach 2: Counting
Count how many 0s, 1s and 2s there are in one pass. Then overwrite the array: first `c0` zeros, then `c1` ones, then `c2` twos. Two passes, no extra array.
- **Time:** O(n)
- **Space:** O(1)

## Approach 3: Dutch National Flag (Optimal)
Keep three regions using pointers `low`, `mid`, `high`:
- `[0, low)` holds 0s, `[low, mid)` holds 1s, `(high, n-1]` holds 2s, and `[mid, high]` is still unknown.

Look at `nums[mid]`:
1. If it is 0, swap with `nums[low]`, then advance both `low` and `mid`.
2. If it is 1, it is already in the right region; advance `mid`.
3. If it is 2, swap with `nums[high]` and decrement `high` only (the swapped-in value is unknown, so `mid` stays).

Stop when `mid > high`. Every element is inspected at most a constant number of times, so it is one pass.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    void sortColors(vector<int>& nums) {
        int low = 0, mid = 0, high = (int)nums.size() - 1;
        while (mid <= high) {
            if (nums[mid] == 0) {
                swap(nums[low], nums[mid]);
                ++low; ++mid;
            } else if (nums[mid] == 1) {
                ++mid;
            } else { // nums[mid] == 2
                swap(nums[mid], nums[high]);
                --high;
            }
        }
    }
};
```

### Java
```java
class Solution {
    public void sortColors(int[] nums) {
        int low = 0, mid = 0, high = nums.length - 1;
        while (mid <= high) {
            if (nums[mid] == 0) {
                int t = nums[low]; nums[low] = nums[mid]; nums[mid] = t;
                low++; mid++;
            } else if (nums[mid] == 1) {
                mid++;
            } else {
                int t = nums[mid]; nums[mid] = nums[high]; nums[high] = t;
                high--;
            }
        }
    }
}
```

### Python
```python
from typing import List

class Solution:
    def sortColors(self, nums: List[int]) -> None:
        low, mid, high = 0, 0, len(nums) - 1
        while mid <= high:
            if nums[mid] == 0:
                nums[low], nums[mid] = nums[mid], nums[low]
                low += 1
                mid += 1
            elif nums[mid] == 1:
                mid += 1
            else:
                nums[mid], nums[high] = nums[high], nums[mid]
                high -= 1
```

## Key Takeaways
- Three-way partitioning with `low / mid / high` is the standard trick whenever there are exactly three categories.
- After swapping a 2 to the back, do not move `mid`: the element that came from `high` has not been classified yet.
- The loop condition is `mid <= high` (inclusive), otherwise the last unknown element is skipped.
- The counting approach is a fine fallback and is easier to get right under pressure, but it needs two passes.
