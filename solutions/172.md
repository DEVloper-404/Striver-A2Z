# Check if a Number is Power of 2 or Not

**Difficulty:** Easy  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Learn Bit Manipulation

## Problem
Given an integer `n`, return `true` if there exists an integer `k >= 0` such that `n == 2^k`, otherwise `false`. Zero and negative numbers are never powers of two.

Input: `n = 16`
Output: `true` (`2^4`)

## Approach 1: Repeated division
If `n <= 0` return `false`. While `n` is even, divide by 2. At the end `n` is a power of two exactly when it has been reduced to `1`.
- **Time:** O(log n)
- **Space:** O(1)

## Approach 2: Count the set bits
A power of two has exactly one `1` in its binary form (`1`, `10`, `100`, ...). Count the set bits (loop or built-in popcount) and check that the count is 1 and `n > 0`.
- **Time:** O(log n) with a loop, O(1) with a hardware popcount
- **Space:** O(1)

## Approach 3: `n & (n - 1)` (Optimal)
Subtracting 1 from `n` flips its lowest set bit to 0 and every bit below it to 1. If `n` has exactly one set bit, `n - 1` is all ones below that bit, and `n & (n - 1)` is `0`. If `n` has two or more set bits, the higher ones survive the AND, so the result is non-zero. Guard against `n <= 0` because `0 & -1 == 0` would give a false positive.
- **Time:** O(1)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    bool isPowerOfTwo(int n) {
        return n > 0 && (n & (n - 1)) == 0;
    }
};
```

### Java
```java
class Solution {
    public boolean isPowerOfTwo(int n) {
        return n > 0 && (n & (n - 1)) == 0;
    }
}
```

### Python
```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        return n > 0 and (n & (n - 1)) == 0
```

## Key Takeaways
- Powers of two are exactly the positive numbers with a single set bit.
- `n & (n - 1)` clears the lowest set bit; the result is zero only when that was the only bit.
- The `n > 0` guard is essential: `0` and `INT_MIN` both satisfy the AND test but are not powers of two.
- Same trick answers "is `n` a power of 4?": additionally require the single bit to sit at an even position (`n & 0x55555555`).
