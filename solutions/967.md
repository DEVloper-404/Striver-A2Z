# Asteroid Collision

**Difficulty:** Medium  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Monotonic Stack/Queue Problems [VVV. Imp]

## Problem
Each integer in `asteroids` is an asteroid: its absolute value is the size and its sign is the direction (positive → moving right, negative → moving left). All asteroids move at the same speed. When two meet, the smaller one is destroyed; if equal, both are destroyed. Two asteroids moving in the same direction never meet. Return the asteroids that survive, in their original order.

```
Input:  asteroids = [5, 10, -5]
Output: [5, 10]
```
10 and -5 collide, -5 is destroyed; 5 and 10 never meet.

## Approach 1: Repeated Simulation
Scan the array, find any adjacent pair `(+a, -b)`, resolve it, and restart. Every pass removes at least one asteroid.
- **Time:** O(n²) worst case
- **Space:** O(n)

## Approach 2: Stack Simulation (Optimal)
Only a right-moving asteroid already on the stack can collide with a new left-moving one. So walk the array and push right-movers unconditionally. For a left-mover `a` (negative):
1. While the stack top is positive and smaller than `|a|`, pop it (the top is destroyed).
2. If the top is positive and equal to `|a|`, pop it and discard `a` too.
3. If the top is positive and bigger, discard `a`.
4. Otherwise (stack empty or top negative) push `a` — it flies off to the left unhindered.

Each asteroid is pushed and popped at most once.
- **Time:** O(n)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> asteroidCollision(vector<int>& asteroids) {
        vector<int> st;   // used as a stack; final contents are the answer
        for (int a : asteroids) {
            bool alive = true;
            while (alive && a < 0 && !st.empty() && st.back() > 0) {
                if (st.back() < -a) st.pop_back();          // top destroyed, keep checking
                else if (st.back() == -a) { st.pop_back(); alive = false; }
                else alive = false;                          // a destroyed
            }
            if (alive) st.push_back(a);
        }
        return st;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int[] asteroidCollision(int[] asteroids) {
        Deque<Integer> st = new ArrayDeque<>();
        for (int a : asteroids) {
            boolean alive = true;
            while (alive && a < 0 && !st.isEmpty() && st.peekLast() > 0) {
                int top = st.peekLast();
                if (top < -a) st.pollLast();
                else if (top == -a) { st.pollLast(); alive = false; }
                else alive = false;
            }
            if (alive) st.addLast(a);
        }
        int[] ans = new int[st.size()];
        int i = 0;
        for (int x : st) ans[i++] = x;
        return ans;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def asteroidCollision(self, asteroids: List[int]) -> List[int]:
        st = []
        for a in asteroids:
            alive = True
            while alive and a < 0 and st and st[-1] > 0:
                if st[-1] < -a:
                    st.pop()
                elif st[-1] == -a:
                    st.pop()
                    alive = False
                else:
                    alive = False
            if alive:
                st.append(a)
        return st
```

## Key Takeaways
- Collisions only happen for the pattern "positive on the stack, negative arriving"; every other combination is safe to push.
- Use a flag (`alive`) rather than `break` so the equal-size case can pop the top and also drop the new asteroid.
- Using a vector/list as the stack means the surviving order is already the required output order.
