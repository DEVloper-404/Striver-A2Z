# Making a large island

**Difficulty:** Hard  ·  **Topic:** Graphs [Concepts & Problems] › MinimumSpanningTree/Disjoint Set and Problems

## Problem
Given an `n × n` binary grid, you may change **at most one** `0` into a `1`. Return the size of the largest island (a 4-directionally connected group of `1`s) that can be obtained afterwards.

```
Input:  grid = [[1,0],[0,1]]
Output: 3
```
Flipping either `0` connects the two single-cell islands through the new cell, giving an island of size `3`.

```
Input:  grid = [[1,1],[1,1]]
Output: 4     (already one island; no 0 to flip)
```

## Approach 1: Flip each zero and re-run a flood fill
For every `0` cell, flip it and run a full BFS/DFS over the grid to measure the largest island, then flip back. Correct but wasteful: the same islands are re-measured for every candidate cell.
- **Time:** O(n⁴) — up to `n²` zeros, each costing an `O(n²)` scan
- **Space:** O(n²)

## Approach 2: Pre-compute island sizes with DSU, then test each zero (optimal)

**The key observation.** The islands themselves never change; only the *connections between them* change when we flip a `0`. So measure every island **once**, then for each zero cell just add up the sizes of the distinct islands touching it. That turns a repeated `O(n²)` measurement into an `O(1)` lookup per candidate.

**Step 1 — build the components.** Flatten `(r, c)` to `r * n + c`. Sweep the grid, and for every land cell union it with its land neighbours (checking right and down is enough, but all four directions is fine too). Use union **by size**, so `size[find(cell)]` directly gives the size of the island containing that cell. After this sweep every island has a leader whose `size` entry is the island's cell count.

**Step 2 — try every zero.** For each cell holding a `0`:
- Look at its four neighbours. Collect the **leaders** (`find(neighbour)`) of the land neighbours into a small set.
- The resulting island size is `1 + sum of size[leader] over the distinct leaders`.
- Track the maximum over all zeros.

**Why the "distinct leaders" set is essential.** A zero can have two neighbours that already belong to the *same* island — imagine a U-shaped island wrapping around the empty cell. Adding `size[leader]` once per neighbour would count that island two, three or four times and produce an inflated answer. Deduplicating by leader (a 4-element set, or a tiny array with manual checks) fixes it. This is the number-one bug in this problem.

**Step 3 — the all-ones case.** If the grid contains no `0` at all, the loop over zeros never runs. Handle it by initialising the answer to the largest existing island size (or by checking `size[find(cell)]` for every land cell), so `[[1,1],[1,1]]` returns `4` rather than `0`.

**Short dry run** on `grid = [[1,0],[0,1]]` with `n = 2`.
- Step 1: cell `(0,0)` = node `0` has no land neighbour → island `{0}`, size 1. Cell `(1,1)` = node `3` → island `{3}`, size 1. No unions happen.
- Step 2, zero at `(0,1)` = node `1`: land neighbours are `(0,0)` (leader `0`, size 1) and `(1,1)` (leader `3`, size 1). Distinct leaders `{0, 3}` → total `1 + 1 + 1 = 3`.
- Zero at `(1,0)`: symmetric, also `3`.
- Answer `3`. ✓

Now picture the U-shape `[[1,1,1],[1,0,1],[1,1,1]]`: the centre zero has four land neighbours, but all four `find` to the *same* leader of the size-8 ring. The set collapses to one entry, giving `1 + 8 = 9` — correct. Without dedup you would compute `1 + 8·4 = 33`.
- **Time:** O(n²) — one DSU pass to build islands, one pass over the zeros, each cell doing O(1) amortised work
- **Space:** O(n²) for the DSU parent and size arrays

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
#include <set>
#include <numeric>
using namespace std;

class Solution {
    vector<int> parent, sz;
    int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }
    void unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return;
        if (sz[a] < sz[b]) swap(a, b);
        parent[b] = a;
        sz[a] += sz[b];
    }
public:
    int largestIsland(vector<vector<int>>& grid) {
        int n = grid.size();
        parent.resize(n * n);
        sz.assign(n * n, 1);
        iota(parent.begin(), parent.end(), 0);

        const int dr[4] = {-1, 1, 0, 0};
        const int dc[4] = {0, 0, -1, 1};

        // Step 1: union all adjacent land cells
        for (int r = 0; r < n; r++)
            for (int c = 0; c < n; c++) {
                if (!grid[r][c]) continue;
                for (int d = 0; d < 4; d++) {
                    int nr = r + dr[d], nc = c + dc[d];
                    if (nr < 0 || nr >= n || nc < 0 || nc >= n) continue;
                    if (grid[nr][nc]) unite(r * n + c, nr * n + nc);
                }
            }

        // best without flipping anything (covers the all-ones grid)
        int best = 0;
        for (int i = 0; i < n * n; i++)
            if (grid[i / n][i % n]) best = max(best, sz[find(i)]);

        // Step 2: try flipping each zero
        for (int r = 0; r < n; r++)
            for (int c = 0; c < n; c++) {
                if (grid[r][c]) continue;
                set<int> leaders;
                for (int d = 0; d < 4; d++) {
                    int nr = r + dr[d], nc = c + dc[d];
                    if (nr < 0 || nr >= n || nc < 0 || nc >= n) continue;
                    if (grid[nr][nc]) leaders.insert(find(nr * n + nc));
                }
                int total = 1;
                for (int lead : leaders) total += sz[lead];
                best = max(best, total);
            }
        return best;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private int[] parent, size;

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return;
        if (size[a] < size[b]) { int t = a; a = b; b = t; }
        parent[b] = a;
        size[a] += size[b];
    }

    public int largestIsland(int[][] grid) {
        int n = grid.length;
        parent = new int[n * n];
        size = new int[n * n];
        for (int i = 0; i < n * n; i++) { parent[i] = i; size[i] = 1; }

        int[] dr = {-1, 1, 0, 0};
        int[] dc = {0, 0, -1, 1};

        for (int r = 0; r < n; r++)
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 0) continue;
                for (int d = 0; d < 4; d++) {
                    int nr = r + dr[d], nc = c + dc[d];
                    if (nr < 0 || nr >= n || nc < 0 || nc >= n) continue;
                    if (grid[nr][nc] == 1) unite(r * n + c, nr * n + nc);
                }
            }

        int best = 0;
        for (int i = 0; i < n * n; i++)
            if (grid[i / n][i % n] == 1) best = Math.max(best, size[find(i)]);

        for (int r = 0; r < n; r++)
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 1) continue;
                Set<Integer> leaders = new HashSet<>();
                for (int d = 0; d < 4; d++) {
                    int nr = r + dr[d], nc = c + dc[d];
                    if (nr < 0 || nr >= n || nc < 0 || nc >= n) continue;
                    if (grid[nr][nc] == 1) leaders.add(find(nr * n + nc));
                }
                int total = 1;
                for (int lead : leaders) total += size[lead];
                best = Math.max(best, total);
            }
        return best;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def largestIsland(self, grid: List[List[int]]) -> int:
        n = len(grid)
        parent = list(range(n * n))
        size = [1] * (n * n)

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def unite(a: int, b: int) -> None:
            a, b = find(a), find(b)
            if a == b:
                return
            if size[a] < size[b]:
                a, b = b, a
            parent[b] = a
            size[a] += size[b]

        # Step 1: merge adjacent land cells into islands
        for r in range(n):
            for c in range(n):
                if grid[r][c] == 0:
                    continue
                for nr, nc in ((r - 1, c), (r + 1, c), (r, c - 1), (r, c + 1)):
                    if 0 <= nr < n and 0 <= nc < n and grid[nr][nc] == 1:
                        unite(r * n + c, nr * n + nc)

        # baseline: largest island with no flip (handles an all-ones grid)
        best = 0
        for r in range(n):
            for c in range(n):
                if grid[r][c] == 1:
                    best = max(best, size[find(r * n + c)])

        # Step 2: try turning each 0 into land
        for r in range(n):
            for c in range(n):
                if grid[r][c] == 1:
                    continue
                leaders = set()
                for nr, nc in ((r - 1, c), (r + 1, c), (r, c - 1), (r, c + 1)):
                    if 0 <= nr < n and 0 <= nc < n and grid[nr][nc] == 1:
                        leaders.add(find(nr * n + nc))
                best = max(best, 1 + sum(size[lead] for lead in leaders))
        return best
```

## Key Takeaways
- Measure the islands once with a size-tracking DSU, then each candidate flip is an `O(1)` sum instead of another flood fill.
- Deduplicate neighbours **by DSU leader** — a zero can touch the same island from several sides, and counting it twice is the classic wrong answer.
- Seed the answer with the largest existing island so a grid with no `0` still returns the right value.
- Union by size makes `size[find(x)]` the island size directly, which is exactly the query this problem needs.
