# Trapping Rainwater

**Difficulty:** Hard  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Monotonic Stack/Queue Problems [VVV. Imp]

## Problem
An array `height` describes an elevation map: bar `i` has width 1 and height `height[i]`. After it rains, water settles in the dips between taller bars. Compute the total units of water that are trapped.

```
Input:  height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]
Output: 6
```

## Approach 1: Brute Force
Water above bar `i` equals `min(maxLeft, maxRight) - height[i]`, where `maxLeft` is the tallest bar at or before `i` and `maxRight` the tallest at or after `i`. Compute both maxima with a scan for every index.
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Prefix / Suffix Maximum Arrays
Precompute `leftMax[i]` and `rightMax[i]` in two linear passes, then sum `min(leftMax[i], rightMax[i]) - height[i]` over all `i`.
- **Time:** O(n)
- **Space:** O(n)

## Approach 3: Two Pointers (Optimal)
Keep pointers `l` and `r` at the two ends plus running `leftMax` and `rightMax`. Whichever side currently has the smaller max is the side whose water level is fully determined (the other side is guaranteed to have a wall at least that tall), so process that side:
- if `height[l] < leftMax`, add `leftMax - height[l]`, else update `leftMax`; move `l` right.
- symmetrically on the right side.

This eliminates the extra arrays while keeping a single pass.
- **Time:** O(n)
- **Space:** O(1)

(A monotonic stack solution also exists: pop bars shorter than the current one and add water in horizontal layers. It is O(n)/O(n) and belongs to the same family, but the two-pointer version is the tightest.)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int trap(vector<int>& height) {
        int l = 0, r = (int)height.size() - 1;
        int leftMax = 0, rightMax = 0, water = 0;
        while (l < r) {
            if (height[l] <= height[r]) {
                leftMax = max(leftMax, height[l]);
                water += leftMax - height[l];
                ++l;
            } else {
                rightMax = max(rightMax, height[r]);
                water += rightMax - height[r];
                --r;
            }
        }
        return water;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def trap(self, height: List[int]) -> int:
        l, r = 0, len(height) - 1
        left_max = right_max = water = 0
        while l < r:
            if height[l] <= height[r]:
                left_max = max(left_max, height[l])
                water += left_max - height[l]
                l += 1
            else:
                right_max = max(right_max, height[r])
                water += right_max - height[r]
                r -= 1
        return water
```

## Key Takeaways
- Water over a bar is bounded by the *shorter* of its tallest neighbours on each side.
- The two-pointer trick works because the side with the smaller boundary can be settled without knowing the rest of the other side.
- Edge cases: fewer than 3 bars trap nothing; monotonic arrays trap nothing.
