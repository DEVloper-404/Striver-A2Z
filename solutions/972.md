# Sum of Subarray Ranges

**Difficulty:** Medium  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Monotonic Stack/Queue Problems [VVV. Imp]

## Problem
The range of a subarray is `max - min`. Given an integer array `nums`, return the sum of the ranges of all contiguous subarrays. The answer can exceed 32-bit, so use a 64-bit type.

```
Input:  nums = [1, 2, 3]
Output: 4
```
Ranges: [1]=0, [2]=0, [3]=0, [1,2]=1, [2,3]=1, [1,2,3]=2 → total 4.

## Approach 1: Brute Force
For every start index, extend the end index while tracking the running min and max and add `max - min`.
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Sum of Maximums minus Sum of Minimums (Optimal)
Because summation is linear, `Σ(max - min) = Σmax - Σmin`. Both sums are computed with the contribution technique from "Sum of Subarray Minimums":

- For the minimum sum, `nums[i]` is the min of `(i - pse[i]) * (nse[i] - i)` subarrays, where `pse` is the previous strictly-smaller index and `nse` the next smaller-or-equal index.
- For the maximum sum, mirror it: previous strictly-greater and next greater-or-equal.

Four monotonic-stack passes and a final loop give the answer.
- **Time:** O(n)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stack>
using namespace std;

class Solution {
    // Sum over i of nums[i] * (#subarrays where nums[i] is the min) if isMin,
    // or the max otherwise.
    long long sumExtremes(const vector<int>& nums, bool isMin) {
        int n = nums.size();
        vector<int> prev(n), next(n);
        stack<int> st;
        auto worse = [&](int a, int b) { return isMin ? a > b : a < b; };   // a is "worse" than b
        for (int i = 0; i < n; ++i) {
            while (!st.empty() && (worse(nums[st.top()], nums[i]) || nums[st.top()] == nums[i])) st.pop();
            prev[i] = st.empty() ? -1 : st.top();
            st.push(i);
        }
        while (!st.empty()) st.pop();
        for (int i = n - 1; i >= 0; --i) {
            while (!st.empty() && worse(nums[st.top()], nums[i])) st.pop();
            next[i] = st.empty() ? n : st.top();
            st.push(i);
        }
        long long total = 0;
        for (int i = 0; i < n; ++i)
            total += (long long)(i - prev[i]) * (next[i] - i) * nums[i];
        return total;
    }
public:
    long long subArrayRanges(vector<int>& nums) {
        return sumExtremes(nums, false) - sumExtremes(nums, true);
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private long sumExtremes(int[] nums, boolean isMin) {
        int n = nums.length;
        int[] prev = new int[n], next = new int[n];
        Deque<Integer> st = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            while (!st.isEmpty() && (worse(nums[st.peek()], nums[i], isMin) || nums[st.peek()] == nums[i])) st.pop();
            prev[i] = st.isEmpty() ? -1 : st.peek();
            st.push(i);
        }
        st.clear();
        for (int i = n - 1; i >= 0; i--) {
            while (!st.isEmpty() && worse(nums[st.peek()], nums[i], isMin)) st.pop();
            next[i] = st.isEmpty() ? n : st.peek();
            st.push(i);
        }
        long total = 0;
        for (int i = 0; i < n; i++)
            total += (long) (i - prev[i]) * (next[i] - i) * nums[i];
        return total;
    }

    private boolean worse(int a, int b, boolean isMin) {
        return isMin ? a > b : a < b;
    }

    public long subArrayRanges(int[] nums) {
        return sumExtremes(nums, false) - sumExtremes(nums, true);
    }
}
```

### Python
```python
from typing import List

class Solution:
    def subArrayRanges(self, nums: List[int]) -> int:
        def sum_extremes(is_min: bool) -> int:
            n = len(nums)
            worse = (lambda a, b: a > b) if is_min else (lambda a, b: a < b)
            prev, nxt = [-1] * n, [n] * n
            st = []
            for i in range(n):
                while st and (worse(nums[st[-1]], nums[i]) or nums[st[-1]] == nums[i]):
                    st.pop()
                prev[i] = st[-1] if st else -1
                st.append(i)
            st = []
            for i in range(n - 1, -1, -1):
                while st and worse(nums[st[-1]], nums[i]):
                    st.pop()
                nxt[i] = st[-1] if st else n
                st.append(i)
            return sum((i - prev[i]) * (nxt[i] - i) * nums[i] for i in range(n))

        return sum_extremes(False) - sum_extremes(True)
```

## Key Takeaways
- Linearity lets you split `Σ(max − min)` into two independent contribution sums.
- The same helper handles both extremes if you parameterise the comparison; only the direction of "worse" flips.
- Keep one side strict and the other non-strict so duplicate values are counted exactly once per subarray.
