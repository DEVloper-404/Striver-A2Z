# Reverse a LinkedList [Iterative]

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
Given the head of a singly linked list, reverse the direction of every `next` pointer so the last node becomes the first, and return the new head. Do it in place without allocating new nodes.

```
Input:  head = 1 -> 2 -> 3 -> 4
Output: 4 -> 3 -> 2 -> 1
```

## Approach 1: Stack of values
Push all values onto a stack in one pass, then in a second pass pop them back into the nodes in order. The chain of pointers is untouched; only the stored values move. It is easy but needs O(n) extra memory and does not reverse the *nodes*, which matters if callers hold references to specific nodes.

- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Three-pointer iteration (optimal)
Keep `prev` (already reversed part, initially null) and `cur` (node being processed, initially head). For each node:

1. Save `nxt = cur.next` so we can continue after rewiring.
2. Flip the link: `cur.next = prev`.
3. Slide the window: `prev = cur; cur = nxt`.

When `cur` becomes null every link has been flipped and `prev` is the old tail, i.e. the new head.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* cur = head;
        while (cur) {
            ListNode* nxt = cur->next;
            cur->next = prev;
            prev = cur;
            cur = nxt;
        }
        return prev;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } }

class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null, cur = head;
        while (cur != null) {
            ListNode nxt = cur.next;
            cur.next = prev;
            prev = cur;
            cur = nxt;
        }
        return prev;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def reverseList(self, head):
        prev, cur = None, head
        while cur:
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt
        return prev
```

## Key Takeaways
- The three-pointer loop (prev, cur, nxt) is the canonical in-place reversal; memorise its order: save, flip, slide.
- Return `prev`, not `head`; the original head is now the tail with `next = null`.
- Works unchanged for empty and single-node lists.
- This loop is a building block for harder problems (reverse in k-groups, palindrome check, reorder list).
