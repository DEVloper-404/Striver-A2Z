# Quick Sorting

**Difficulty:** Easy  ·  **Topic:** Learn Important Sorting Techniques › Sorting-II

## Problem
Given an array of `n` integers, sort it in non-decreasing order using quick sort: choose a pivot, partition the array so that smaller elements are to its left and larger ones to its right, then sort both sides recursively.

Input: `arr = [4, 6, 2, 5, 7, 9, 1, 3]`
Output: `[1, 2, 3, 4, 5, 6, 7, 9]`

## Approach 1: Quick Sort with Two-Pointer Partition
Unlike merge sort, quick sort does the heavy lifting *before* recursing. The key step is **partition**:

1. Pick a pivot, here `arr[low]`.
2. Move pointer `i` right until it finds an element greater than the pivot, and pointer `j` left until it finds an element less than or equal to the pivot.
3. If `i < j`, swap `arr[i]` and `arr[j]` and continue; otherwise stop.
4. Swap the pivot with `arr[j]`. Now `j` is the pivot's final index: everything to its left is `<= pivot` and everything to its right is `> pivot`.

Recurse on `[low, j-1]` and `[j+1, high]`. There is no merge step because each partition places one element permanently and the two sides never need to be combined.

If the pivot lands near the middle each time, the recursion depth is about `log n` and the total partition work is O(n log n). If the pivot is always the minimum or maximum (for example, the first element of an already-sorted array), each level only removes one element and the runtime degrades to O(n²). Picking a random pivot or the median of three makes that worst case extremely unlikely.

- **Time:** O(n log n) average, O(n²) worst case.
- **Space:** O(log n) average recursion stack (O(n) in the worst case); no extra array.

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <utility>
using namespace std;

class Solution {
    int partition(vector<int>& arr, int low, int high) {
        int pivot = arr[low];
        int i = low, j = high;
        while (i < j) {
            while (i <= high - 1 && arr[i] <= pivot) i++;
            while (j >= low + 1 && arr[j] > pivot) j--;
            if (i < j) swap(arr[i], arr[j]);
        }
        swap(arr[low], arr[j]);
        return j;
    }

    void quickSortRec(vector<int>& arr, int low, int high) {
        if (low >= high) return;
        int p = partition(arr, low, high);
        quickSortRec(arr, low, p - 1);
        quickSortRec(arr, p + 1, high);
    }

public:
    vector<int> quickSort(vector<int>& arr) {
        if (!arr.empty()) quickSortRec(arr, 0, arr.size() - 1);
        return arr;
    }
};
```

### Java
```java
class Solution {
    private int partition(int[] arr, int low, int high) {
        int pivot = arr[low];
        int i = low, j = high;
        while (i < j) {
            while (i <= high - 1 && arr[i] <= pivot) i++;
            while (j >= low + 1 && arr[j] > pivot) j--;
            if (i < j) {
                int tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp;
            }
        }
        int tmp = arr[low]; arr[low] = arr[j]; arr[j] = tmp;
        return j;
    }

    private void quickSortRec(int[] arr, int low, int high) {
        if (low >= high) return;
        int p = partition(arr, low, high);
        quickSortRec(arr, low, p - 1);
        quickSortRec(arr, p + 1, high);
    }

    public int[] quickSort(int[] arr) {
        if (arr.length > 0) quickSortRec(arr, 0, arr.length - 1);
        return arr;
    }
}
```

### Python
```python
class Solution:
    def quickSort(self, arr: list[int]) -> list[int]:
        def partition(low: int, high: int) -> int:
            pivot = arr[low]
            i, j = low, high
            while i < j:
                while i <= high - 1 and arr[i] <= pivot:
                    i += 1
                while j >= low + 1 and arr[j] > pivot:
                    j -= 1
                if i < j:
                    arr[i], arr[j] = arr[j], arr[i]
            arr[low], arr[j] = arr[j], arr[low]
            return j

        def rec(low: int, high: int) -> None:
            if low >= high:
                return
            p = partition(low, high)
            rec(low, p - 1)
            rec(p + 1, high)

        if arr:
            rec(0, len(arr) - 1)
        return arr
```

## Key Takeaways
- Partition first, recurse second: after partition the pivot is in its final place and the two sides are independent.
- Average O(n log n) with O(1) extra memory beyond the stack, which is why it is the default in-place sort in practice.
- Worst case O(n²) with a bad pivot (sorted input + first-element pivot); randomise the pivot to avoid it.
- Not stable; equal elements may be reordered during swaps.
