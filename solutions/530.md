# Distance of nearest cell having one

**Difficulty:** Medium  ·  **Topic:** Graphs [Concepts & Problems] › Problems on BFS/DFS

## Problem
Given an `m × n` binary matrix, for every cell compute the distance to the nearest cell containing a `1`, where distance is the number of 4-directional steps. Cells containing `1` have distance `0`. Return the matrix of distances. (The LeetCode form, *01 Matrix*, asks for the distance to the nearest `0` — the same algorithm with the roles swapped.)

```
Input:  grid = [[0,0,0],
                [0,1,0],
                [1,1,1]]
Output: [[2,1,2],
         [1,0,1],
         [0,0,0]]
```

## Approach 1: One BFS per cell (brute force)
For each of the `m·n` cells, run a BFS outward until you hit the first `1`, and record the level. This is clearly correct — BFS finds the closest one by construction — but you pay a full O(m·n) traversal per cell.
- **Time:** O((m·n)²) — 10^6 cells would mean 10^12 steps.
- **Space:** O(m·n) per BFS.

## Approach 2: Multi-source BFS from all the ones (Optimal)
The brute force asks the question backwards. Instead of "from this cell, where is the nearest `1`?", ask "from all the `1`s at once, how far does the wave travel before it reaches this cell?" Those two questions have the same answer, and the second can be answered in one sweep.

**Key observation:** BFS pops nodes in non-decreasing distance from its source set. Seed the queue with *every* `1` at distance 0 and this property still holds — the value at which a cell is first popped is `min over all sources of dist(source, cell)`, which is exactly what we want. Once a cell is assigned, no later route can improve it (any later arrival is at an equal or larger level), so a simple visited flag is enough — no relaxation, no priority queue. That is only valid because every edge has weight 1.

Algorithm:
1. Allocate `dist` of the same shape and a `visited` matrix.
2. Scan the grid. For each cell containing `1`, set `dist = 0`, mark visited, and push it.
3. BFS: pop `(r, c)`; for each of the four neighbours that is in bounds and unvisited, set `dist[nr][nc] = dist[r][c] + 1`, mark visited, and push.
4. Return `dist`.

Note that we do **not** filter neighbours by their grid value — the wave must pass through `0` cells, that is the point. The only filter is "not already assigned".

Dry run on the example. Sources are `(1,1)`, `(2,0)`, `(2,1)`, `(2,2)`, all at distance 0.
- Level 1: `(1,1)` gives `(0,1)`, `(1,0)`, `(1,2)`; `(2,0)` gives `(1,0)` (already claimed at level 1 — fine, same value); `(2,2)` gives `(1,2)`. So `dist[0][1] = dist[1][0] = dist[1][2] = 1`.
- Level 2: from `(0,1)` we reach `(0,0)` and `(0,2)`; from `(1,0)` we would reach `(0,0)` too. Both get `2`.
- Everything is now assigned. Result matches the expected output. Notice `(0,0)`: its nearest `1` is `(1,1)`? No — that is at Manhattan distance 2 through `(0,1)` or `(1,0)`; both give 2, and `(2,0)` is also 2 steps away. Consistent.

Edge cases: if the matrix contains no `1` at all, the queue starts empty and every cell stays unreachable — decide with the problem statement whether to return `-1` or leave it undefined. If every cell is `1`, all distances are `0` and the BFS does nothing beyond the seeding scan.
- **Time:** O(m·n) — each cell is pushed and popped exactly once, and each pop inspects four neighbours.
- **Space:** O(m·n) for `dist`, `visited` and the queue.

## Approach 3: Two-pass dynamic programming
For 4-directional distance you can also do two sweeps without any queue. Initialise `1` cells to 0 and everything else to a large value. Sweep top-left → bottom-right taking `dist[r][c] = min(dist[r][c], dist[r-1][c] + 1, dist[r][c-1] + 1)`, then sweep bottom-right → top-left taking `dist[r][c] = min(dist[r][c], dist[r+1][c] + 1, dist[r][c+1] + 1)`. The first pass accounts for every shortest path whose last moves come from above/left, the second for the rest; together they cover all four directions. Same O(m·n) time but O(1) extra space beyond the output.
- **Time:** O(m·n)
- **Space:** O(1) extra

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    vector<vector<int>> nearest(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<vector<int>> dist(m, vector<int>(n, 0));
        vector<vector<int>> visited(m, vector<int>(n, 0));
        queue<pair<int,int>> q;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    visited[i][j] = 1;    // distance already 0
                    q.push({i, j});
                }
            }
        }

        int dr[4] = {-1, 1, 0, 0};
        int dc[4] = {0, 0, -1, 1};
        while (!q.empty()) {
            auto [r, c] = q.front(); q.pop();
            for (int k = 0; k < 4; k++) {
                int nr = r + dr[k], nc = c + dc[k];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && !visited[nr][nc]) {
                    visited[nr][nc] = 1;
                    dist[nr][nc] = dist[r][c] + 1;
                    q.push({nr, nc});
                }
            }
        }
        return dist;
    }
};
```

### Java

```java
import java.util.*;

class Solution {
    public int[][] nearest(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dist = new int[m][n];
        boolean[][] visited = new boolean[m][n];
        Queue<int[]> q = new LinkedList<>();

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    visited[i][j] = true;
                    q.add(new int[]{i, j});
                }
            }
        }

        int[] dr = {-1, 1, 0, 0};
        int[] dc = {0, 0, -1, 1};
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int r = cur[0], c = cur[1];
            for (int k = 0; k < 4; k++) {
                int nr = r + dr[k], nc = c + dc[k];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && !visited[nr][nc]) {
                    visited[nr][nc] = true;
                    dist[nr][nc] = dist[r][c] + 1;
                    q.add(new int[]{nr, nc});
                }
            }
        }
        return dist;
    }
}
```

### Python
```python
from collections import deque
from typing import List

class Solution:
    def nearest(self, grid: List[List[int]]) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        dist = [[0] * n for _ in range(m)]
        visited = [[False] * n for _ in range(m)]
        q = deque()

        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    visited[i][j] = True
                    q.append((i, j))

        dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        while q:
            r, c = q.popleft()
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and not visited[nr][nc]:
                    visited[nr][nc] = True
                    dist[nr][nc] = dist[r][c] + 1
                    q.append((nr, nc))
        return dist
```

## Key Takeaways
- "Nearest X for every cell" ⇒ invert the question and run **one** multi-source BFS from all the X cells.
- Because every edge costs 1, the first time BFS reaches a cell is already optimal — no relaxation or priority queue needed.
- Do not restrict the wave to cells of a particular value; the wave must travel through the whole grid.
- The two-pass DP alternative gives the same answer in O(1) extra space for 4-directional grids.
