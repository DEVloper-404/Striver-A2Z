# Word Break

**Difficulty:** Medium  ·  **Topic:** Recursion [PatternWise] › Trying out all Combos / Hard

## Problem
Given a string `s` and a list of dictionary words `wordDict`, decide whether `s` can be written as a sequence of one or more dictionary words joined together. A dictionary word may be reused any number of times. Return `true` or `false`.

Input: `s = "applepenapple"`, `wordDict = ["apple","pen"]`
Output: `true` (apple + pen + apple)

## Approach 1: Plain recursion over every prefix
Define `solve(start)` = can `s[start..]` be segmented? Try every end index `i >= start`; if `s[start..i]` is in the dictionary, recurse on `solve(i + 1)`. If any branch reaches `start == n`, answer yes. The same suffix gets re-solved from many different paths, so the recursion tree blows up.
- **Time:** O(2^n · n) — exponential branching with an O(n) substring check
- **Space:** O(n) recursion depth

## Approach 2: Recursion with memoisation (Optimal)
The answer for `solve(start)` depends only on `start`, so there are just `n + 1` distinct subproblems. Cache the result of each in an array (`-1` unknown, `0` false, `1` true). Store the dictionary in a hash set so membership is O(1) after the O(len) hash. An extra pruning trick: never try a substring longer than the longest dictionary word.

The same idea written bottom-up is the classic `dp[i]` = "prefix of length `i` is breakable", with `dp[0] = true`.
- **Time:** O(n² · L) where `L` is the maximum word length (substring hashing); O(n · L²) with the length cap
- **Space:** O(n) memo + O(n) recursion + dictionary set

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <string>
#include <unordered_set>
using namespace std;

class Solution {
    vector<int> memo;
    unordered_set<string> dict;
    int maxLen = 0;

    bool solve(int start, const string& s) {
        if (start == (int)s.size()) return true;
        if (memo[start] != -1) return memo[start];
        for (int len = 1; len <= maxLen && start + len <= (int)s.size(); ++len) {
            if (dict.count(s.substr(start, len)) && solve(start + len, s))
                return memo[start] = 1;
        }
        return memo[start] = 0;
    }
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        for (auto& w : wordDict) { dict.insert(w); maxLen = max(maxLen, (int)w.size()); }
        memo.assign(s.size() + 1, -1);
        return solve(0, s);
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private int[] memo;
    private Set<String> dict = new HashSet<>();
    private int maxLen = 0;

    public boolean wordBreak(String s, List<String> wordDict) {
        for (String w : wordDict) { dict.add(w); maxLen = Math.max(maxLen, w.length()); }
        memo = new int[s.length() + 1];
        Arrays.fill(memo, -1);
        return solve(0, s);
    }

    private boolean solve(int start, String s) {
        if (start == s.length()) return true;
        if (memo[start] != -1) return memo[start] == 1;
        for (int len = 1; len <= maxLen && start + len <= s.length(); len++) {
            if (dict.contains(s.substring(start, start + len)) && solve(start + len, s)) {
                memo[start] = 1;
                return true;
            }
        }
        memo[start] = 0;
        return false;
    }
}
```

### Python
```python
from functools import lru_cache
from typing import List

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        words = set(wordDict)
        max_len = max((len(w) for w in words), default=0)
        n = len(s)

        @lru_cache(maxsize=None)
        def solve(start: int) -> bool:
            if start == n:
                return True
            for length in range(1, max_len + 1):
                if start + length > n:
                    break
                if s[start:start + length] in words and solve(start + length):
                    return True
            return False

        return solve(0)
```

## Key Takeaways
- Recursion over "where does the next word end" is the pattern; memoising on the start index turns exponential into polynomial.
- Capping the tried length at the longest dictionary word is a cheap, significant speedup.
- Words may be reused, so the dictionary is never modified during the search.
- Edge cases: empty dictionary, `s` equal to a single dictionary word, dictionary words that are prefixes of each other ("cat" / "cats").
