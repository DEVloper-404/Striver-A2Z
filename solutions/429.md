# Switch Case

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Things to Know in C++/Java/Python or any language

## Problem
A `switch` statement compares one expression against a list of constant values and jumps directly to the matching `case`. It is a cleaner alternative to a long `if / else if` chain when every branch tests the same variable for equality. The standard exercise: read a day number from 1 to 7 and print the weekday name, or `Invalid` for anything else.

```
Input:  3
Output: Wednesday
```

## Approach: How switch works and when to use it

1. The controlling expression must be an integer-like type (`int`, `char`, `enum`) in C++; Java also accepts `String`. Each `case` label must be a compile-time constant and all labels must be distinct.
2. Execution jumps to the matching label and then **falls through** into the following cases until it hits `break`. Forgetting `break` is the number-one bug: `case 1: ... case 2: ...` without a break prints both.
3. Fall-through is sometimes intentional: stacking `case 'a': case 'e': case 'i':` lets several values share one body.
4. `default` handles everything not listed. Put it last for readability (position does not change behavior).
5. Ranges (`x >= 10`) and non-constant comparisons cannot be case labels; use `if / else if` for those.

Python has no classic `switch`. The idiomatic replacements are a dictionary lookup (`names.get(day, "Invalid")`) or, from Python 3.10, the `match` statement with `case _:` as the default.

Why prefer switch over an if-ladder: intent is clearer (one variable, many constants) and compilers can turn dense integer cases into a jump table, giving O(1) dispatch instead of k sequential comparisons.

- **Time:** O(1) typical (jump table), O(k) worst case for k labels
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

string dayName(int day) {
    switch (day) {
        case 1: return "Monday";
        case 2: return "Tuesday";
        case 3: return "Wednesday";
        case 4: return "Thursday";
        case 5: return "Friday";
        case 6:
        case 7: return "Weekend";     // intentional fall-through
        default: return "Invalid";
    }
}

int main() {
    int day;
    cin >> day;
    cout << dayName(day) << '\n';

    char op = '+';
    int a = 6, b = 3, result = 0;
    switch (op) {
        case '+': result = a + b; break;
        case '-': result = a - b; break;
        case '*': result = a * b; break;
        case '/': result = b != 0 ? a / b : 0; break;
        default: result = 0;
    }
    cout << result << '\n';
    return 0;
}
```

### Java
```java
import java.util.Scanner;

public class Main {
    static String dayName(int day) {
        switch (day) {
            case 1: return "Monday";
            case 2: return "Tuesday";
            case 3: return "Wednesday";
            case 4: return "Thursday";
            case 5: return "Friday";
            case 6:
            case 7: return "Weekend";
            default: return "Invalid";
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int day = sc.nextInt();
        System.out.println(dayName(day));

        // Java 14+ arrow form: no fall-through, no break needed
        char op = '+';
        int a = 6, b = 3;
        int result = switch (op) {
            case '+' -> a + b;
            case '-' -> a - b;
            case '*' -> a * b;
            case '/' -> b != 0 ? a / b : 0;
            default -> 0;
        };
        System.out.println(result);
        sc.close();
    }
}
```

### Python
```python
def day_name(day: int) -> str:
    match day:
        case 1:
            return "Monday"
        case 2:
            return "Tuesday"
        case 3:
            return "Wednesday"
        case 4:
            return "Thursday"
        case 5:
            return "Friday"
        case 6 | 7:
            return "Weekend"
        case _:
            return "Invalid"


def calc(op: str, a: int, b: int) -> int:
    # dictionary dispatch: the pre-3.10 way to emulate switch
    table = {
        "+": a + b,
        "-": a - b,
        "*": a * b,
        "/": a // b if b != 0 else 0,
    }
    return table.get(op, 0)


def main():
    day = int(input())
    print(day_name(day))
    print(calc("+", 6, 3))


if __name__ == "__main__":
    main()
```

## Key Takeaways
- `switch` is for equality checks of one expression against constants; use `if / else if` for ranges or compound conditions.
- Every case needs `break` (or `return`) unless fall-through is deliberate; stacked labels are the idiomatic way to share a body.
- Always include `default` so unexpected values are handled explicitly.
- Python has no traditional switch: use a dict lookup or the `match` statement (3.10+), where `case 6 | 7` matches either value.
