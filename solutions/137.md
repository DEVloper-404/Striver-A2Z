# Preorder Traversal

**Difficulty:** Easy  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Traversals

## Problem
Given the root of a binary tree, return the values of its nodes in preorder: visit the current node first, then everything in its left subtree, then everything in its right subtree. Return the result as a list.

Input: `root = [1, null, 2, 3]`
```
  1
   \
    2
   /
  3
```
Output: `[1, 2, 3]`

## Approach 1: Recursion
Preorder is defined recursively, so the code writes itself: if the node is null stop; otherwise record the node's value, recurse into the left child, then recurse into the right child. The order of the three statements is the whole algorithm ("Root, Left, Right").
- **Time:** O(n) — every node is visited once
- **Space:** O(h) recursion stack, where h is the tree height (O(n) for a skewed tree)

## Approach 2: Iterative with an explicit stack
Recursion can overflow on very deep trees, so replace the call stack with your own. Push the root. While the stack is non-empty: pop a node, record it, then push its **right** child first and its **left** child second. Because a stack is last-in-first-out, the left child comes out before the right child, which preserves the Root, Left, Right order.
- **Time:** O(n)
- **Space:** O(h) for the stack in the worst case

## Approach 3: Morris traversal (O(1) extra space)
For each node with a left child, find the rightmost node of its left subtree (the inorder predecessor). If that predecessor's right pointer is null, record the current node, point the predecessor's right at the current node as a temporary thread, and move left. If the thread already exists, remove it and move right. Nodes without a left child are recorded and we move right. Every edge is walked at most a constant number of times, and the tree is restored at the end. This is the optimal space solution but is rarely required in interviews; the stack version below is the standard answer.
- **Time:** O(n)
- **Space:** O(1) extra (no stack, no recursion)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stack>
using namespace std;

// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition

class Solution {
public:
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> res;
        if (!root) return res;
        stack<TreeNode*> st;
        st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            st.pop();
            res.push_back(node->val);
            if (node->right) st.push(node->right);   // right first so left pops first
            if (node->left) st.push(node->left);
        }
        return res;
    }
};
```

### Java
```java
import java.util.*;

// class TreeNode { int val; TreeNode left, right; ... } — standard definition

class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        Deque<TreeNode> st = new ArrayDeque<>();
        st.push(root);
        while (!st.isEmpty()) {
            TreeNode node = st.pop();
            res.add(node.val);
            if (node.right != null) st.push(node.right);   // right first so left pops first
            if (node.left != null) st.push(node.left);
        }
        return res;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def preorderTraversal(self, root):
        res = []
        if root is None:
            return res
        stack = [root]
        while stack:
            node = stack.pop()
            res.append(node.val)
            if node.right:          # right first so left pops first
                stack.append(node.right)
            if node.left:
                stack.append(node.left)
        return res
```

## Key Takeaways
- Preorder = Root, Left, Right. The recursive version is three lines; the iterative version swaps the recursion stack for an explicit one.
- In the iterative version push the right child before the left child so the left child is processed first.
- Recursion costs O(h) stack; on a skewed tree of 10^5 nodes that can overflow, which is why the iterative form is worth knowing.
- Morris traversal drops the space to O(1) by temporarily threading predecessor pointers, and must restore them so the tree is unchanged afterwards.
