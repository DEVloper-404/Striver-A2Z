# Find the number that appears once, and other numbers twice.

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Easy

## Problem
Given a non-empty integer array `nums` in which every element appears exactly twice except for one element that appears exactly once, return that single element. The solution should run in linear time and ideally use constant extra space.

Input: `nums = [4, 1, 2, 1, 2]`
Output: `4`

## Approach 1: Count Each Element by Scanning
For each element, scan the whole array and count its occurrences. Return the one whose count is `1`.

- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Hash Map of Counts
Count occurrences in a hash map in one pass, then look for the key whose count is `1`. Sorting and checking adjacent pairs is another O(n log n) option.

- **Time:** O(n)
- **Space:** O(n)

## Approach 3: XOR Everything (Optimal)
XOR is commutative and associative, `a ^ a = 0`, and `a ^ 0 = a`. If you XOR every element of the array together, each pair of duplicates cancels to zero and the result is the lone element, no matter where the duplicates are positioned. One pass, no extra memory, and it works for negative numbers because XOR operates on raw bits.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int x = 0;
        for (int v : nums) x ^= v;
        return x;
    }
};
```

### Java
```java
class Solution {
    public int singleNumber(int[] nums) {
        int x = 0;
        for (int v : nums) x ^= v;
        return x;
    }
}
```

### Python
```python
class Solution:
    def singleNumber(self, nums: list[int]) -> int:
        x = 0
        for v in nums:
            x ^= v
        return x
```

## Key Takeaways
- "Everything appears twice except one" is the signature of the XOR trick: pairs cancel, the odd one survives.
- Order does not matter because XOR is commutative and associative.
- The trick only works when the repeat count is even; for "appears three times" you need bit counting mod 3.
- Edge case: a single-element array returns that element.
