# Minimum insertions or deletions to convert string A to B

**Difficulty:** Hard  ·  **Topic:** Dynamic Programming [Patterns and Problems] › DP on Strings

## Problem
Given two strings `s1` and `s2`, you may delete a character from `s1` or insert a character into `s1` (no replacements). Return the minimum total number of operations to turn `s1` into `s2`.

```
Input:  s1 = "abcd", s2 = "anc"
Output: 3
Explanation: delete 'b' and 'd' from "abcd" to get "ac", then insert 'n' -> "anc".
             2 deletions + 1 insertion = 3.

Input:  s1 = "sea", s2 = "eat"
Output: 2
Explanation: delete 's' and insert 't'.
```

## Approach 1: Brute Force
Search over sequences of operations: at each step try every possible deletion and every possible insertion, recursing on the result until the strings match, and take the shortest sequence. The state space is unbounded in principle (insertions can lengthen the string arbitrarily) so this needs careful pruning and is impractical.

- **Time:** exponential
- **Space:** O(n + m)

## Approach 2: Optimal (find the common core, then count what changes)

**The key observation.** There are no replacements, so no character is ever *transformed*. Every character of `s1` is either deleted or kept, and every character of `s2` is either one of those kept characters or newly inserted. Crucially, insertions and deletions never reorder anything, so the set of kept characters appears in the same relative order in both strings — it is a **common subsequence** of `s1` and `s2`.

Let `L` be the length of the kept block. Then:
- deletions = `n - L` (everything in `s1` that is not kept)
- insertions = `m - L` (everything in `s2` that was not already there)
- total = `n + m - 2L`

To minimise the total we maximise `L`, so we want the **longest** common subsequence:

```
answer = n + m - 2 · LCS(s1, s2)
```

The bound is achievable: fix a longest common subsequence, delete every other character of `s1` (leaving exactly that subsequence), then insert the missing characters of `s2` in their correct gaps. So the formula is exact, not just a lower bound.

**Computing LCS.** With `dp[i][j]` = LCS of the first `i` characters of `s1` and the first `j` of `s2`:

```
dp[i][j] = 1 + dp[i-1][j-1]                     if s1[i-1] == s2[j-1]
dp[i][j] = max(dp[i-1][j], dp[i][j-1])          otherwise
```

Row 0 and column 0 are zeros (an empty string shares nothing). Only the previous row is read, so two rolling arrays give O(m) space.

**Dry run on s1 = "abcd", s2 = "anc".** The LCS is `"ac"`, so `L = 2`. Then deletions = `4 - 2 = 2` (`b` and `d`), insertions = `3 - 2 = 1` (`n`), total `4 + 3 - 4 = 3`. Matches the expected output.

**Dry run on s1 = "sea", s2 = "eat".** LCS is `"ea"`, `L = 2`. Total = `3 + 3 - 4 = 2`: delete `s`, insert `t`.

- **Time:** O(n · m)
- **Space:** O(m)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int minDistance(string s1, string s2) {
        int n = s1.size(), m = s2.size();
        vector<int> prev(m + 1, 0), cur(m + 1, 0);

        for (int i = 1; i <= n; i++) {
            cur[0] = 0;
            for (int j = 1; j <= m; j++) {
                if (s1[i - 1] == s2[j - 1])
                    cur[j] = 1 + prev[j - 1];
                else
                    cur[j] = max(prev[j], cur[j - 1]);
            }
            prev = cur;
        }
        int lcs = prev[m];
        return (n - lcs) + (m - lcs);      // deletions + insertions
    }
};
```

### Java
```java
class Solution {
    public int minDistance(String s1, String s2) {
        int n = s1.length(), m = s2.length();
        int[] prev = new int[m + 1];
        int[] cur = new int[m + 1];

        for (int i = 1; i <= n; i++) {
            cur[0] = 0;
            for (int j = 1; j <= m; j++) {
                if (s1.charAt(i - 1) == s2.charAt(j - 1))
                    cur[j] = 1 + prev[j - 1];
                else
                    cur[j] = Math.max(prev[j], cur[j - 1]);
            }
            int[] tmp = prev; prev = cur; cur = tmp;
        }
        int lcs = prev[m];
        return (n - lcs) + (m - lcs);
    }
}
```

### Python
```python
class Solution:
    def minDistance(self, s1, s2):
        n, m = len(s1), len(s2)
        prev = [0] * (m + 1)

        for i in range(1, n + 1):
            cur = [0] * (m + 1)
            for j in range(1, m + 1):
                if s1[i - 1] == s2[j - 1]:
                    cur[j] = 1 + prev[j - 1]
                else:
                    cur[j] = max(prev[j], cur[j - 1])
            prev = cur

        lcs = prev[m]
        return (n - lcs) + (m - lcs)
```

## Key Takeaways
- Without replacements, the characters that survive form a common subsequence — maximising it minimises the work, giving `n + m - 2·LCS`.
- The formula is exact because a concrete operation sequence achieves it: delete down to the LCS, then insert the rest.
- Do not confuse this with edit distance, which also allows replacement and needs its own three-way recurrence (a replacement there costs 1 instead of 2 here).
- Empty-string edge cases fall out for free: `LCS = 0`, so the answer is `n + m`.
