# Find Median from Data Stream

**Difficulty:** Hard  ·  **Topic:** Heaps [Learning, Medium, Hard Problems] › Hard Problems

## Problem
Design a `MedianFinder` class with two operations: `addNum(num)` inserts an integer into the collection, and `findMedian()` returns the median of everything inserted so far. For an odd count the median is the middle value in sorted order; for an even count it is the average of the two middle values (returned as a double).

```
Input:  addNum(1); addNum(2); findMedian(); addNum(3); findMedian()
Output: 1.5; 2.0
```

## Approach 1: Sort on every query
Append to a list and, on each `findMedian`, sort the list and pick the middle element(s). Fine for tiny inputs, hopeless for a long stream with frequent queries.
- **Time:** O(1) add, O(n log n) per query
- **Space:** O(n)

## Approach 2: Keep the list sorted with binary-search insertion
Find the insertion point with binary search and shift elements to insert. Queries become O(1) index lookups, but each insertion is linear because of the shift.
- **Time:** O(n) add, O(1) query
- **Space:** O(n)

## Approach 3: Two heaps (optimal)
Split the numbers into two halves:

- `low` is a **max**-heap holding the smaller half, so its top is the largest of the small numbers.
- `high` is a **min**-heap holding the larger half, so its top is the smallest of the big numbers.

Keep two invariants: every element in `low` is `<=` every element in `high`, and `low` has either the same size as `high` or exactly one more element.

To add a number, push it into `low`, then move `low`'s top to `high` (this guarantees the ordering invariant). If `high` becomes larger than `low`, move `high`'s top back to `low` (this restores the size invariant). The median is then `low.top()` when the total count is odd, or the average of both tops when even.
- **Time:** O(log n) add, O(1) query
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

class MedianFinder {
    priority_queue<int> low;                                    // max-heap, smaller half
    priority_queue<int, vector<int>, greater<int>> high;        // min-heap, larger half

public:
    MedianFinder() {}

    void addNum(int num) {
        low.push(num);
        high.push(low.top());
        low.pop();
        if (high.size() > low.size()) {
            low.push(high.top());
            high.pop();
        }
    }

    double findMedian() {
        if (low.size() > high.size()) return low.top();
        return (low.top() + (double)high.top()) / 2.0;
    }
};
```

### Java
```java
import java.util.*;

class MedianFinder {
    private final PriorityQueue<Integer> low = new PriorityQueue<>(Collections.reverseOrder()); // smaller half
    private final PriorityQueue<Integer> high = new PriorityQueue<>();                          // larger half

    public MedianFinder() {}

    public void addNum(int num) {
        low.offer(num);
        high.offer(low.poll());
        if (high.size() > low.size()) {
            low.offer(high.poll());
        }
    }

    public double findMedian() {
        if (low.size() > high.size()) return low.peek();
        return (low.peek() + (double) high.peek()) / 2.0;
    }
}
```

### Python
```python
import heapq


class MedianFinder:
    def __init__(self):
        self.low = []   # max-heap via negation: smaller half
        self.high = []  # min-heap: larger half

    def addNum(self, num: int) -> None:
        heapq.heappush(self.low, -num)
        heapq.heappush(self.high, -heapq.heappop(self.low))
        if len(self.high) > len(self.low):
            heapq.heappush(self.low, -heapq.heappop(self.high))

    def findMedian(self) -> float:
        if len(self.low) > len(self.high):
            return float(-self.low[0])
        return (-self.low[0] + self.high[0]) / 2.0
```

## Key Takeaways
- Two heaps that meet in the middle expose the median in O(1) while keeping inserts logarithmic.
- Always route a new number through `low` and then rebalance; this single pattern maintains both invariants without case analysis.
- Cast to `double` before dividing so the even-count median is not truncated.
- A follow-up with a bounded value range (for example 0 to 100) can use a counting array for O(1) inserts and O(range) queries.
