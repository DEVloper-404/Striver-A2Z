# Left Rotate Array by One

**Difficulty:** Easy  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Easy

## Problem
Given an array of `n` integers, rotate it to the left by one position: every element moves one index down, and the first element wraps around to the end. Do it in place and return the array.

Input: `arr = [1, 2, 3, 4, 5]`
Output: `[2, 3, 4, 5, 1]`

## Approach 1: Build a New Array
Create a second array `res` where `res[i] = arr[i+1]` for `i < n-1` and `res[n-1] = arr[0]`. Copy it back if in-place output is required.

- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Save the First, Shift, Restore (Optimal)
Only one element changes its "neighbourhood": the first element moves to the back. So:

1. Save `first = arr[0]`.
2. For `i` from `1` to `n-1`, set `arr[i-1] = arr[i]`, shifting everything one step left.
3. Write `arr[n-1] = first`.

The shift is done left to right so that each element is copied before it is overwritten. This is the one-step version of the general rotate-by-K problem.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> rotateByOne(vector<int>& arr) {
        int n = arr.size();
        if (n <= 1) return arr;
        int first = arr[0];
        for (int i = 1; i < n; i++) arr[i - 1] = arr[i];
        arr[n - 1] = first;
        return arr;
    }
};
```

### Python
```python
class Solution:
    def rotateByOne(self, arr: list[int]) -> list[int]:
        n = len(arr)
        if n <= 1:
            return arr
        first = arr[0]
        for i in range(1, n):
            arr[i - 1] = arr[i]
        arr[n - 1] = first
        return arr
```

## Key Takeaways
- Store the element that wraps around before shifting, then put it back at the end.
- Shift in the direction that never overwrites data you still need (left to right for a left rotation).
- Arrays of size 0 or 1 are unchanged by rotation.
