# Remove Nth node from the back of the LL

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
Given the head of a singly linked list and an integer `n`, delete the n-th node counting from the end (n = 1 is the last node) and return the head. `n` is guaranteed to be valid, so the node always exists.

```
Input:  head = 1 -> 2 -> 3 -> 4 -> 5, n = 2
Output: 1 -> 2 -> 3 -> 5

Input:  head = 1, n = 1
Output: (empty list)
```

## Approach 1: Count the length
Traverse once to get the length `len`. The target is the `(len - n + 1)`-th node from the front. If that is the head (`len == n`), return `head.next`. Otherwise walk to the node just before it and bypass the target. Two passes, but simple.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Two pointers with a gap of n (optimal, one pass)
Use a dummy node before the head so the head can be deleted like any other node. Start `fast` and `slow` at the dummy. Advance `fast` by `n + 1` steps so the gap between them is `n + 1`. Then move both together until `fast` is null. At that moment `slow` sits directly before the node to remove; set `slow.next = slow.next.next`.

Why `n + 1`: we want `slow` to stop one node *before* the target, which is `n` from the end, so the gap must be one more than `n`.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode dummy(0);
        dummy.next = head;
        ListNode* fast = &dummy;
        ListNode* slow = &dummy;
        for (int i = 0; i <= n; i++) fast = fast->next;
        while (fast) {
            fast = fast->next;
            slow = slow->next;
        }
        ListNode* target = slow->next;
        slow->next = target->next;
        delete target;
        return dummy.next;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } }

class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode fast = dummy, slow = dummy;
        for (int i = 0; i <= n; i++) fast = fast.next;
        while (fast != null) {
            fast = fast.next;
            slow = slow.next;
        }
        slow.next = slow.next.next;
        return dummy.next;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def removeNthFromEnd(self, head, n: int):
        dummy = ListNode(0, head)
        fast = slow = dummy
        for _ in range(n + 1):
            fast = fast.next
        while fast:
            fast = fast.next
            slow = slow.next
        slow.next = slow.next.next
        return dummy.next
```

## Key Takeaways
- A dummy head removes the special case of deleting the first node.
- Keep the two pointers exactly `n + 1` apart so `slow` lands on the predecessor of the target.
- One pass, O(1) space; the counting approach is a fine fallback if the gap logic feels risky.
- Return `dummy.next`, since the real head may have been the deleted node.
