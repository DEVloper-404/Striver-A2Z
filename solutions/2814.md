# Cycle Detection in Directed Graph (DFS)

**Difficulty:** Hard  ·  **Topic:** Graphs [Concepts & Problems] › Problems on BFS/DFS

## Problem
Given a directed graph with `V` vertices (numbered `0..V-1`) and an adjacency list `adj`, decide whether the graph contains at least one directed cycle. A cycle is a path that starts at some vertex, follows edges in their direction, and returns to that same vertex. Return `true` if any cycle exists, otherwise `false`.

```
Input:  V = 4, edges = [[0,1], [1,2], [2,3], [3,1]]
Output: true          // 1 -> 2 -> 3 -> 1 is a cycle

Input:  V = 4, edges = [[0,1], [1,2], [2,3]]
Output: false         // a straight chain, no way back
```

## Approach 1: Naive "visit twice" check (why it fails)
The undirected version of this problem is solved by "if I reach an already-visited node that is not my parent, there is a cycle". Copying that idea to a directed graph is wrong. Consider `0 -> 1`, `0 -> 2`, `1 -> 2`. Starting DFS at `0` we visit `1`, from `1` we reach `2` and mark it, then we come back to `0` and see edge `0 -> 2` pointing at an already-visited node — yet the graph has no cycle at all.

The lesson: in a directed graph, meeting a visited node is only suspicious if that node is still *on the current DFS stack*, i.e. we have not finished exploring it yet. If it is visited but already finished, the edge is a cross/forward edge into a region we fully explored and returned from — harmless.

## Approach 2: DFS with two arrays — `visited` and `pathVisited` (Optimal)

**Key observation.** A directed cycle exists exactly when DFS finds a *back edge*: an edge `u -> v` where `v` is an ancestor of `u` in the current recursion path. So we need to distinguish three states of a node:

- **unvisited** — never touched.
- **in the current path** — DFS entered it and has not returned from it yet.
- **done** — DFS entered it and already returned; everything reachable from it was explored and no cycle was found there.

We track this with two boolean arrays: `visited[v]` (ever entered) and `pathVisited[v]` (currently on the recursion stack).

**Algorithm.**
1. For every node `i` that is unvisited, start `dfs(i)`. (The graph may be disconnected, so one DFS is not enough.)
2. On entering node `u`, set `visited[u] = true` and `pathVisited[u] = true`.
3. For each neighbour `v` of `u`:
   - if `v` is unvisited, recurse; if the recursion reports a cycle, propagate `true` upward immediately;
   - else if `pathVisited[v]` is `true`, we just found an edge back into the node chain we are standing on → return `true`;
   - else (`visited[v]` but not on the path) ignore it, that subtree is already cleared.
4. Before returning `false` from `u`, set `pathVisited[u] = false` — we are backtracking, so `u` leaves the current path. **Forgetting this single line is the classic bug**; it turns the algorithm into "any revisit is a cycle", which reports false positives.

**Why it is correct.** If the algorithm returns `true`, it found `u -> v` with `v` on the stack; the stack from `v` down to `u` plus this edge is a genuine directed cycle. Conversely, if a cycle `c1 -> c2 -> ... -> ck -> c1` exists, look at whichever of its nodes DFS enters first, say `c1`. Since every `ci` is reachable from `c1`, DFS cannot return from `c1` before entering all of them, so at the moment `ck` is processed `c1` is still on the path — the edge `ck -> c1` is detected.

**Dry run** on `0->1, 1->2, 2->3, 3->1`:
- enter 0 → path = {0}; enter 1 → path = {0,1}; enter 2 → path = {0,1,2}; enter 3 → path = {0,1,2,3}.
- from 3 the only edge is `3 -> 1`, and `pathVisited[1]` is `true` → return `true` all the way up.

On the chain `0->1->2->3`: 3 has no neighbours, backtrack and clear `pathVisited[3]`, then 2, 1, 0. No node is ever seen on the live path twice → `false`.

- **Time:** O(V + E) — each vertex is entered once and each edge scanned once
- **Space:** O(V) for the two arrays plus O(V) recursion depth

*(A common compact variant merges the two arrays into a single `color[]` with values 0 = white/unvisited, 1 = grey/on path, 2 = black/done — identical logic, one array.)*

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    bool dfs(int u, vector<vector<int>>& adj, vector<int>& visited, vector<int>& pathVis) {
        visited[u] = 1;
        pathVis[u] = 1;
        for (int v : adj[u]) {
            if (!visited[v]) {
                if (dfs(v, adj, visited, pathVis)) return true;
            } else if (pathVis[v]) {
                return true;                 // back edge into the live recursion path
            }
        }
        pathVis[u] = 0;                      // backtrack: u leaves the current path
        return false;
    }

public:
    bool isCyclic(int V, vector<vector<int>>& adj) {
        vector<int> visited(V, 0), pathVis(V, 0);
        for (int i = 0; i < V; i++) {
            if (!visited[i] && dfs(i, adj, visited, pathVis)) return true;
        }
        return false;
    }
};
```

### Java

```java
import java.util.*;

class Solution {
    private boolean dfs(int u, List<List<Integer>> adj, boolean[] visited, boolean[] pathVis) {
        visited[u] = true;
        pathVis[u] = true;
        for (int v : adj.get(u)) {
            if (!visited[v]) {
                if (dfs(v, adj, visited, pathVis)) return true;
            } else if (pathVis[v]) {
                return true;
            }
        }
        pathVis[u] = false;
        return false;
    }

    public boolean isCyclic(int V, List<List<Integer>> adj) {
        boolean[] visited = new boolean[V];
        boolean[] pathVis = new boolean[V];
        for (int i = 0; i < V; i++) {
            if (!visited[i] && dfs(i, adj, visited, pathVis)) return true;
        }
        return false;
    }
}
```

### Python
```python
import sys
from typing import List

class Solution:
    def isCyclic(self, V: int, adj: List[List[int]]) -> bool:
        sys.setrecursionlimit(10 ** 6)
        visited = [False] * V
        path_vis = [False] * V

        def dfs(u: int) -> bool:
            visited[u] = True
            path_vis[u] = True
            for v in adj[u]:
                if not visited[v]:
                    if dfs(v):
                        return True
                elif path_vis[v]:
                    return True
            path_vis[u] = False
            return False

        return any(not visited[i] and dfs(i) for i in range(V))
```

## Key Takeaways
- In a directed graph a cycle means a **back edge** — an edge into a node still on the recursion stack, not merely into a visited node.
- Two flags per node (`visited`, `pathVisited`) or one three-colour array captures this; clearing `pathVisited` while backtracking is mandatory.
- Loop over all vertices as DFS roots: the graph can be disconnected or have unreachable cycles.
- Self-loops (`u -> u`) are caught for free, since `u` is on its own path when its edges are scanned.
