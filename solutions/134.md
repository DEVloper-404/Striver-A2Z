# Level Order Traversal

**Difficulty:** Easy  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Traversals

## Problem
Given the root of a binary tree, return its nodes grouped by depth, top to bottom, and within each level from left to right. The result is a list of lists, one inner list per level.

Input: `root = [3, 9, 20, null, null, 15, 7]`
```
    3
   / \
  9  20
     / \
    15  7
```
Output: `[[3], [9, 20], [15, 7]]`

## Approach 1: Recursion with a depth parameter
Do a DFS that carries the current depth. When you reach a node at depth `d`, append its value to `result[d]`, creating that inner list if it does not exist yet. Because DFS visits the left subtree before the right one, values within a level are still added left to right. This works but it is a DFS pretending to be a level order, and the recursion stack is O(h).
- **Time:** O(n)
- **Space:** O(h) recursion stack plus O(n) output

## Approach 2: Breadth-first search with a queue (optimal)
A queue naturally processes nodes in the order they were discovered, which for a tree is level by level. Push the root. While the queue is non-empty:

1. Record the current queue size `k`; those `k` nodes are exactly one level.
2. Pop `k` nodes, appending each value to a fresh list and enqueueing its non-null left then right children.
3. Append the list to the result.

Taking the size snapshot before the inner loop is what separates levels; the children pushed during the loop belong to the next level and are not touched until the next outer iteration.
- **Time:** O(n) — every node is enqueued and dequeued once
- **Space:** O(w) for the queue, where w is the maximum width of the tree (up to n/2 for the bottom level of a complete tree)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <queue>
using namespace std;

// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition

class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> res;
        if (!root) return res;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int k = q.size();            // nodes on this level
            vector<int> level;
            for (int i = 0; i < k; i++) {
                TreeNode* node = q.front();
                q.pop();
                level.push_back(node->val);
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
            res.push_back(level);
        }
        return res;
    }
};
```

### Java
```java
import java.util.*;

// class TreeNode { int val; TreeNode left, right; ... } — standard definition

class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;
        Queue<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        while (!q.isEmpty()) {
            int k = q.size();            // nodes on this level
            List<Integer> level = new ArrayList<>();
            for (int i = 0; i < k; i++) {
                TreeNode node = q.poll();
                level.add(node.val);
                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }
            res.add(level);
        }
        return res;
    }
}
```

### Python
```python
from collections import deque

# class TreeNode: val, left, right — standard definition

class Solution:
    def levelOrder(self, root):
        res = []
        if root is None:
            return res
        q = deque([root])
        while q:
            k = len(q)                   # nodes on this level
            level = []
            for _ in range(k):
                node = q.popleft()
                level.append(node.val)
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            res.append(level)
        return res
```

## Key Takeaways
- Level order is BFS; the queue does the ordering for you, and snapshotting `q.size()` before each inner loop is what splits the output into levels.
- Enqueue left before right so each level reads left to right.
- Space is bounded by the widest level, not the height, which is the opposite of the DFS traversals.
- This template is the starting point for zigzag order, right/left view, bottom-up order, and "average of each level" problems: they all change only what you do with `level`.
