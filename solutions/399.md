# Sort Characters by Frequency

**Difficulty:** Easy  ·  **Topic:** Strings [Basic and Medium] › Medium String Problems

## Problem
Given a string, rearrange its characters so that characters with higher frequency come first. All copies of the same character must be adjacent. When two characters tie in frequency, any order between them is acceptable.

Input: `s = "tree"`
Output: `"eert"`  (`"eetr"` is also valid)

Input: `s = "Aabb"`
Output: `"bbAa"`  (`"bbaA"` is also valid)

## Approach 1: Count, then sort characters by count
1. Count the frequency of each character with a hash map or a 256-slot array.
2. Collect the distinct characters and sort them by frequency descending.
3. Emit each character `freq` times.

Since there are at most 256 distinct characters (or 62 alphanumerics), the sort is on a tiny list even for very long strings.
- **Time:** O(n + k log k) where k is the number of distinct characters (k ≤ 256, so effectively O(n))
- **Space:** O(k) for counts plus O(n) for the output

## Approach 2: Bucket by frequency (Optimal, strictly linear)
Frequencies range from `1` to `n`. Create `n + 1` buckets where bucket `f` holds all characters whose frequency is `f`. Then walk the buckets from `n` down to `1` and emit each character `f` times. This avoids the sort entirely.

Both approaches are effectively linear; bucket sort is the textbook "sort by frequency in O(n)" trick. The code below uses the count-then-sort version because it is shorter and equally fast in practice.
- **Time:** O(n)
- **Space:** O(n) for the buckets and the output

## Code (Optimal)

### C++
```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    string frequencySort(string s) {
        int cnt[256] = {0};
        for (unsigned char c : s) cnt[c]++;

        vector<int> chars;
        for (int c = 0; c < 256; ++c) if (cnt[c] > 0) chars.push_back(c);
        sort(chars.begin(), chars.end(), [&](int a, int b) {
            return cnt[a] > cnt[b];
        });

        string out;
        out.reserve(s.size());
        for (int c : chars) out.append(cnt[c], (char)c);
        return out;
    }
};
```

### Java
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public String frequencySort(String s) {
        int[] cnt = new int[256];
        for (char c : s.toCharArray()) cnt[c]++;

        List<Character> chars = new ArrayList<>();
        for (int c = 0; c < 256; c++) if (cnt[c] > 0) chars.add((char) c);
        chars.sort((a, b) -> cnt[b] - cnt[a]);

        StringBuilder out = new StringBuilder(s.length());
        for (char c : chars) {
            for (int i = 0; i < cnt[c]; i++) out.append(c);
        }
        return out.toString();
    }
}
```

### Python
```python
from collections import Counter

class Solution:
    def frequencySort(self, s: str) -> str:
        cnt = Counter(s)
        ordered = sorted(cnt.items(), key=lambda kv: -kv[1])
        return "".join(ch * f for ch, f in ordered)
```

## Key Takeaways
- Frequency-based ordering = count first, then order the distinct keys, then expand.
- The alphabet is small, so sorting distinct characters is effectively O(n); bucket sort makes it strictly linear.
- Characters are case-sensitive here: `'A'` and `'a'` are different keys.
- Build output with a builder/list to avoid O(n^2) string concatenation.
