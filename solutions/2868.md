# While loops

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Things to Know in C++/Java/Python or any language

## Problem
A `while` loop repeats its body as long as a condition stays true. Unlike a `for` loop, there is no built-in counter, so it is the natural choice when the number of iterations is not known up front: reading until end of input, shrinking a number until it hits zero, or moving two pointers until they meet. This topic covers `while`, `do-while`, infinite loops with `break`, and the classic digit-processing pattern.

Example task: given a positive integer, print the count of its digits and its digit sum.

```
Input:  12345
Output: 5 15
```

## Approach: While and do-while

**1. `while (cond) { body }`.** The condition is checked first; if it is false initially the body never runs. Something inside the body must eventually make the condition false, or the loop runs forever.

**2. Digit extraction — the canonical while loop.** `n % 10` gives the last digit and `n / 10` drops it. Repeat while `n > 0`. Because the number of digits is not known in advance, `while` fits better than `for`.

```
n = 12345 -> digit 5, n = 1234
n = 1234  -> digit 4, n = 123
...
n = 0     -> stop
```

**3. `do { body } while (cond);`** runs the body at least once and checks the condition afterwards. Use it for "ask, then validate" menus. Python has no `do-while`; emulate it with `while True:` and a `break` at the end.

**4. Infinite loop with a sentinel.** `while (true)` plus `break` when a stopping condition appears mid-body (e.g. reading until a `0` is entered).

**5. While as two-pointer engine.** `while (l < r)` is the shape of palindrome checks, binary search (`while (lo <= hi)`), and merging two sorted lists.

Pitfalls: forgetting to update the variable in the condition (infinite loop), and off-by-one differences between `while (n > 0)` and `while (n >= 0)` — the latter never terminates for digit extraction because `0 / 10` is still `0`.

- **Time:** O(number of iterations); for digit extraction O(log10 n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

pair<int, int> digitStats(long long n) {
    int count = 0, sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
        count++;
    }
    return {count, sum};
}

int main() {
    long long n;
    cin >> n;
    auto [cnt, sum] = digitStats(n);
    cout << cnt << ' ' << sum << '\n';

    // do-while: body runs at least once
    int k = 0;
    do {
        cout << k << ' ';
        k++;
    } while (k < 3);
    cout << '\n';

    // sentinel loop: read numbers until 0
    long long total = 0, x;
    while (true) {
        if (!(cin >> x) || x == 0) break;
        total += x;
    }
    cout << total << '\n';
    return 0;
}
```

### Java
```java
import java.util.Scanner;

public class Main {
    static int[] digitStats(long n) {
        int count = 0, sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
            count++;
        }
        return new int[]{count, sum};
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        long n = sc.nextLong();
        int[] res = digitStats(n);
        System.out.println(res[0] + " " + res[1]);

        int k = 0;
        do {
            System.out.print(k + " ");
            k++;
        } while (k < 3);
        System.out.println();

        long total = 0;
        while (true) {
            if (!sc.hasNextLong()) break;
            long x = sc.nextLong();
            if (x == 0) break;
            total += x;
        }
        System.out.println(total);
        sc.close();
    }
}
```

### Python
```python
def digit_stats(n: int):
    count, total = 0, 0
    while n > 0:
        total += n % 10
        n //= 10
        count += 1
    return count, total


def main():
    n = int(input())
    cnt, s = digit_stats(n)
    print(cnt, s)

    # emulate do-while: run once, then check
    k = 0
    while True:
        print(k, end=" ")
        k += 1
        if not k < 3:
            break
    print()

    # sentinel loop: read numbers until 0 or EOF
    total = 0
    while True:
        try:
            x = int(input())
        except (EOFError, ValueError):
            break
        if x == 0:
            break
        total += x
    print(total)


if __name__ == "__main__":
    main()
```

## Key Takeaways
- Use `while` when the iteration count depends on the data; use `for` when it is known.
- The body must move the loop toward termination — the missing update is the classic infinite-loop bug.
- `n % 10` / `n / 10` is the standard digit loop and runs O(log10 n) times; stop at `n > 0`, not `n >= 0`.
- `do-while` guarantees one execution; Python emulates it with `while True` + `break`.
