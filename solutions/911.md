# Set Matrix Zeroes

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Medium

## Problem
Given an `m x n` integer matrix, if any cell is 0, set its entire row and entire column to 0. The change must be made in place, and the challenge is to do it in constant extra space. The tricky part is that zeros you write must not be mistaken for zeros that were in the original input.

```
Input:  [[1, 1, 1],
         [1, 0, 1],
         [1, 1, 1]]
Output: [[1, 0, 1],
         [0, 0, 0],
         [1, 0, 1]]
```

## Approach 1: Brute Force with a Marker
Scan the matrix; whenever you find a 0, walk its row and column and change every non-zero cell to a sentinel value (e.g. -1) that cannot appear in the input. After the scan, turn every sentinel into 0. Marking instead of zeroing directly avoids chain reactions. This fails if the sentinel can be a legitimate value.
- **Time:** O(m·n·(m+n))
- **Space:** O(1)

## Approach 2: Row and Column Flags
Keep two boolean arrays `rowZero[m]` and `colZero[n]`. First pass: for each 0 at `(i, j)` set `rowZero[i]` and `colZero[j]`. Second pass: set `matrix[i][j] = 0` whenever `rowZero[i]` or `colZero[j]` is true.
- **Time:** O(m·n)
- **Space:** O(m + n)

## Approach 3: Use the First Row and Column as Flags (Optimal)
Reuse the matrix's own first row and first column as the flag arrays from Approach 2:
1. Record separately whether the first row and the first column themselves contain a 0 (`firstRowZero`, `firstColZero`), because their cells will be overwritten as flags.
2. For every cell `(i, j)` with `i >= 1` and `j >= 1` that is 0, set `matrix[i][0] = 0` and `matrix[0][j] = 0`.
3. For every cell with `i >= 1, j >= 1`, zero it if `matrix[i][0] == 0` or `matrix[0][j] == 0`.
4. Finally, if `firstRowZero`, zero the first row; if `firstColZero`, zero the first column.

Doing the interior before the first row/column matters: otherwise you would erase the flags before reading them.
- **Time:** O(m·n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = (int)matrix.size(), n = (int)matrix[0].size();
        bool firstRowZero = false, firstColZero = false;
        for (int j = 0; j < n; ++j) if (matrix[0][j] == 0) firstRowZero = true;
        for (int i = 0; i < m; ++i) if (matrix[i][0] == 0) firstColZero = true;

        for (int i = 1; i < m; ++i)
            for (int j = 1; j < n; ++j)
                if (matrix[i][j] == 0) { matrix[i][0] = 0; matrix[0][j] = 0; }

        for (int i = 1; i < m; ++i)
            for (int j = 1; j < n; ++j)
                if (matrix[i][0] == 0 || matrix[0][j] == 0) matrix[i][j] = 0;

        if (firstRowZero) for (int j = 0; j < n; ++j) matrix[0][j] = 0;
        if (firstColZero) for (int i = 0; i < m; ++i) matrix[i][0] = 0;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        m, n = len(matrix), len(matrix[0])
        first_row_zero = any(matrix[0][j] == 0 for j in range(n))
        first_col_zero = any(matrix[i][0] == 0 for i in range(m))

        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0

        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0

        if first_row_zero:
            for j in range(n):
                matrix[0][j] = 0
        if first_col_zero:
            for i in range(m):
                matrix[i][0] = 0
```

## Key Takeaways
- Never zero cells while still scanning for original zeros; record first, then apply.
- The O(1) trick is to store the row/column flags inside the matrix's own first row and column.
- The cell `(0,0)` is shared by both flag lines, which is why the two booleans are needed for the first row and column.
- Process the interior first and the first row/column last, or the flags get destroyed too early.
