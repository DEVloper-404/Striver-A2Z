# Rat in a Maze

**Difficulty:** Hard  ·  **Topic:** Recursion [PatternWise] › Trying out all Combos / Hard

## Problem
A rat starts at the top-left cell `(0, 0)` of an `n x n` grid and must reach the bottom-right cell `(n-1, n-1)`. A cell with value `1` is open and `0` is blocked. The rat can move Down, Left, Right or Up (letters `D`, `L`, `R`, `U`) and may not visit a cell twice on one path. Return every path as a string of moves, sorted lexicographically. If the start or end is blocked, return an empty list.

Input:
```
grid = [[1,0,0,0],
        [1,1,0,1],
        [1,1,0,0],
        [0,1,1,1]]
```
Output: `["DDRDRR", "DRDDRR"]`

## Approach 1: Enumerate all move strings
Every path of length up to `n² - 1` is a string over `{D,L,R,U}`. Generate all such strings, simulate each one, and keep those that stay on open cells, never revisit a cell, and finish at the goal. The vast majority of strings walk into walls or off the grid, so this is hopeless beyond tiny grids.
- **Time:** O(4^(n²))
- **Space:** O(n²) for the simulated path

## Approach 2: DFS with a visited grid (Optimal)
Do a depth-first search from `(0, 0)`. At each cell, try the four directions in the fixed order D, L, R, U so that the collected answers come out already sorted. A move is allowed only if the target is inside the grid, is open, and has not been visited on the current path. Mark the cell when we enter it, append the direction letter to the path, recurse, then unmark and pop the letter. When we stand on `(n-1, n-1)`, record the path string.

Trying directions in alphabetical order (D < L < R < U) is what makes the output sorted without a separate sort step.
- **Time:** O(4^(n²)) in the theoretical worst case, but realistically bounded by the number of simple paths; each cell branches at most 3 ways after the first step
- **Space:** O(n²) for the visited array and recursion depth

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
    int n;
    const int dr[4] = {1, 0, 0, -1};
    const int dc[4] = {0, -1, 1, 0};
    const char dir[4] = {'D', 'L', 'R', 'U'};

    void dfs(int r, int c, vector<vector<int>>& g, vector<vector<bool>>& vis,
             string& path, vector<string>& out) {
        if (r == n - 1 && c == n - 1) { out.push_back(path); return; }
        for (int k = 0; k < 4; ++k) {
            int nr = r + dr[k], nc = c + dc[k];
            if (nr < 0 || nc < 0 || nr >= n || nc >= n) continue;
            if (g[nr][nc] == 0 || vis[nr][nc]) continue;
            vis[nr][nc] = true;
            path.push_back(dir[k]);
            dfs(nr, nc, g, vis, path, out);
            path.pop_back();
            vis[nr][nc] = false;
        }
    }
public:
    vector<string> findPath(vector<vector<int>>& grid) {
        n = grid.size();
        vector<string> out;
        if (n == 0 || grid[0][0] == 0 || grid[n - 1][n - 1] == 0) return out;
        vector<vector<bool>> vis(n, vector<bool>(n, false));
        string path;
        vis[0][0] = true;
        dfs(0, 0, grid, vis, path, out);
        return out;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private int n;
    private final int[] dr = {1, 0, 0, -1};
    private final int[] dc = {0, -1, 1, 0};
    private final char[] dir = {'D', 'L', 'R', 'U'};

    public List<String> findPath(int[][] grid) {
        n = grid.length;
        List<String> out = new ArrayList<>();
        if (n == 0 || grid[0][0] == 0 || grid[n - 1][n - 1] == 0) return out;
        boolean[][] vis = new boolean[n][n];
        vis[0][0] = true;
        dfs(0, 0, grid, vis, new StringBuilder(), out);
        return out;
    }

    private void dfs(int r, int c, int[][] g, boolean[][] vis, StringBuilder path, List<String> out) {
        if (r == n - 1 && c == n - 1) { out.add(path.toString()); return; }
        for (int k = 0; k < 4; k++) {
            int nr = r + dr[k], nc = c + dc[k];
            if (nr < 0 || nc < 0 || nr >= n || nc >= n) continue;
            if (g[nr][nc] == 0 || vis[nr][nc]) continue;
            vis[nr][nc] = true;
            path.append(dir[k]);
            dfs(nr, nc, g, vis, path, out);
            path.deleteCharAt(path.length() - 1);
            vis[nr][nc] = false;
        }
    }
}
```

### Python
```python
from typing import List

class Solution:
    def findPath(self, grid: List[List[int]]) -> List[str]:
        n = len(grid)
        out: List[str] = []
        if n == 0 or grid[0][0] == 0 or grid[n - 1][n - 1] == 0:
            return out
        moves = [(1, 0, "D"), (0, -1, "L"), (0, 1, "R"), (-1, 0, "U")]
        vis = [[False] * n for _ in range(n)]
        path: List[str] = []

        def dfs(r: int, c: int) -> None:
            if r == n - 1 and c == n - 1:
                out.append("".join(path))
                return
            for dr, dc, ch in moves:
                nr, nc = r + dr, c + dc
                if 0 <= nr < n and 0 <= nc < n and grid[nr][nc] == 1 and not vis[nr][nc]:
                    vis[nr][nc] = True
                    path.append(ch)
                    dfs(nr, nc)
                    path.pop()
                    vis[nr][nc] = False

        vis[0][0] = True
        dfs(0, 0)
        return out
```

## Key Takeaways
- Standard grid backtracking: mark, recurse, unmark. The visited array prevents cycles within one path.
- Explore directions in the order D, L, R, U to get lexicographically sorted output for free.
- Check the start and destination cells up front; a blocked start means zero paths even if the rest is open.
- Do not forget to mark `(0, 0)` as visited before the first call, otherwise a path can loop back to the start.
