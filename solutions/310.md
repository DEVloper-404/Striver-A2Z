# Longest palindromic subsequence

**Difficulty:** Hard  ·  **Topic:** Dynamic Programming [Patterns and Problems] › DP on Strings

## Problem
Given a string `s`, return the length of its longest subsequence that reads the same forwards and backwards. Characters may be dropped but not reordered.

```
Input:  s = "bbbab"
Output: 4
Explanation: "bbbb" is a palindromic subsequence of length 4.

Input:  s = "cbbd"
Output: 2
Explanation: "bb".
```

## Approach 1: Brute Force
Generate all 2^n subsequences, test each for being a palindrome, and keep the longest. Correct but exponential — useful only as a mental model of what we are optimising.

- **Time:** O(2^n · n)
- **Space:** O(n)

## Approach 2: Optimal (reduce to LCS with the reversed string)

**The key observation.** A palindrome is a string equal to its own reverse. So a palindromic subsequence of `s` is a sequence of characters that appears, in order, in `s` **and also**, in order, in `reverse(s)`.

Concretely, suppose `t = s[i1] s[i2] … s[ik]` with `i1 < i2 < … < ik` is a palindrome. Read those same characters from the reversed string: their positions in `reverse(s)` are `n-1-ik < … < n-1-i1`, and the characters they spell out are `s[ik] … s[i1]` = `reverse(t)` = `t`. So `t` is a common subsequence of `s` and `reverse(s)`.

The converse also holds: any common subsequence of `s` and `reverse(s)` can be realised as a palindromic subsequence of `s` of the same length. So

```
LPS(s) = LCS(s, reverse(s))
```

and we can reuse the standard LCS machinery unchanged.

**The LCS recurrence.** With `dp[i][j]` = LCS of the first `i` characters of `s` and the first `j` of `r = reverse(s)`:

```
dp[i][j] = 1 + dp[i-1][j-1]                     if s[i-1] == r[j-1]
dp[i][j] = max(dp[i-1][j], dp[i][j-1])          otherwise
```

Row 0 and column 0 are zeros. The answer is `dp[n][n]`. Two rolling rows give O(n) space.

**Dry run on s = "bbbab", r = "babbb".** Building the table (rows = prefixes of `s`, columns = prefixes of `r`):

|     | "" | b | a | b | b | b |
|-----|----|---|---|---|---|---|
| ""  | 0 | 0 | 0 | 0 | 0 | 0 |
| b   | 0 | 1 | 1 | 1 | 1 | 1 |
| b   | 0 | 1 | 1 | 2 | 2 | 2 |
| b   | 0 | 1 | 1 | 2 | 3 | 3 |
| a   | 0 | 1 | 2 | 2 | 3 | 3 |
| b   | 0 | 1 | 2 | 3 | 3 | 4 |

`dp[5][5] = 4`, which corresponds to the palindrome `"bbbb"`.

**A note on the alternative.** There is also a direct interval DP: `g(i, j)` = LPS of `s[i..j]`, with `g(i,j) = 2 + g(i+1, j-1)` when `s[i] == s[j]` and `max(g(i+1,j), g(i,j-1))` otherwise. It has the same O(n²) complexity; the LCS reduction is preferred here because it reuses code you already have.

- **Time:** O(n²)
- **Space:** O(n) with two rolling rows

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int longestPalindromeSubseq(string s) {
        string r(s.rbegin(), s.rend());
        int n = s.size();
        vector<int> prev(n + 1, 0), cur(n + 1, 0);

        for (int i = 1; i <= n; i++) {
            cur[0] = 0;
            for (int j = 1; j <= n; j++) {
                if (s[i - 1] == r[j - 1])
                    cur[j] = 1 + prev[j - 1];
                else
                    cur[j] = max(prev[j], cur[j - 1]);
            }
            prev = cur;
        }
        return prev[n];
    }
};
```

### Java
```java
class Solution {
    public int longestPalindromeSubseq(String s) {
        String r = new StringBuilder(s).reverse().toString();
        int n = s.length();
        int[] prev = new int[n + 1];
        int[] cur = new int[n + 1];

        for (int i = 1; i <= n; i++) {
            cur[0] = 0;
            for (int j = 1; j <= n; j++) {
                if (s.charAt(i - 1) == r.charAt(j - 1))
                    cur[j] = 1 + prev[j - 1];
                else
                    cur[j] = Math.max(prev[j], cur[j - 1]);
            }
            int[] tmp = prev; prev = cur; cur = tmp;
        }
        return prev[n];
    }
}
```

### Python
```python
class Solution:
    def longestPalindromeSubseq(self, s):
        r = s[::-1]
        n = len(s)
        prev = [0] * (n + 1)

        for i in range(1, n + 1):
            cur = [0] * (n + 1)
            for j in range(1, n + 1):
                if s[i - 1] == r[j - 1]:
                    cur[j] = 1 + prev[j - 1]
                else:
                    cur[j] = max(prev[j], cur[j - 1])
            prev = cur

        return prev[n]
```

## Key Takeaways
- `LPS(s) = LCS(s, reverse(s))` — a one-line reduction that turns a new problem into one you already solved.
- The reduction works because a palindrome is exactly a string that reads identically in both directions, so it must sit inside both `s` and its reverse.
- This does **not** extend to substrings: the longest common substring of `s` and `reverse(s)` can pick up a non-palindromic block that also occurs reversed elsewhere.
- The answer feeds directly into "minimum insertions to make a palindrome", which is just `n - LPS(s)`.
