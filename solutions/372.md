# GCD of Two Numbers

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Know Basic Maths

## Problem
Given two non-negative integers `a` and `b`, return their greatest common divisor — the largest integer that divides both without remainder. By convention `gcd(a, 0) = a`.

Input: `a = 20, b = 28`
Output: `4`

Input: `a = 17, b = 5`
Output: `1`

## Approach 1: Brute force
Try every candidate `d` from `min(a, b)` down to 1 and return the first one that divides both. Correct but slow when the numbers are large.

- **Time:** O(min(a, b))
- **Space:** O(1)

## Approach 2: Euclid by subtraction
Key fact: any common divisor of `a` and `b` also divides `a - b`. So `gcd(a, b) = gcd(a - b, b)` for `a > b`. Repeatedly subtract the smaller from the larger until one becomes 0; the other is the answer. Correct, but degenerate inputs like `gcd(10^9, 1)` take a billion steps.

- **Time:** O(max(a, b)) worst case
- **Space:** O(1)

## Approach 3: Euclidean algorithm with modulo (optimal)
Subtracting `b` from `a` repeatedly until `a < b` is the same as taking `a % b`. So `gcd(a, b) = gcd(b, a % b)`, stopping when `b == 0`. Each pair of iterations at least halves the larger argument, which gives logarithmic time.

Trace for (20, 28): (20, 28) → (28, 20) → (20, 8) → (8, 4) → (4, 0) → answer 4.

- **Time:** O(log(min(a, b)))
- **Space:** O(1) iterative, O(log) stack if written recursively

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int gcd(int a, int b) {
        while (b != 0) {
            int r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
};
```

### Java
```java
class Solution {
    public int gcd(int a, int b) {
        while (b != 0) {
            int r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
}
```

### Python
```python
class Solution:
    def gcd(self, a: int, b: int) -> int:
        while b != 0:
            a, b = b, a % b
        return a
```

## Key Takeaways
- `gcd(a, b) = gcd(b, a % b)` with base case `gcd(a, 0) = a` is the Euclidean algorithm; it runs in O(log min(a, b)).
- The loop handles `a < b` automatically — the first iteration simply swaps them.
- `lcm(a, b) = a / gcd(a, b) * b` (divide first to avoid overflow).
- Standard library versions exist (`std::gcd` in C++17, `math.gcd` in Python), but know the loop for interviews.
