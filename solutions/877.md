# Pow(x,n)

**Difficulty:** Medium  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Advanced Maths

## Problem
Implement `pow(x, n)` that computes `x` raised to the integer power `n`. `x` is a double and `n` may be negative, zero, or positive, including `INT_MIN`.

Input: `x = 2.0, n = 10`
Output: `1024.0`

Input: `x = 2.0, n = -2`
Output: `0.25`

## Approach 1: Brute Force
Multiply `x` by itself `|n|` times; if `n` was negative, return `1 / result`. Correct, but linear in `n`, which is far too slow for `n` around 10^9.
- **Time:** O(|n|)
- **Space:** O(1)

## Approach 2: Optimal (Binary Exponentiation)
Key observation: `x^n = (x^2)^(n/2)` when `n` is even, and `x · x^(n-1)` when `n` is odd. Walk through the bits of `n` from least significant upward:

1. Keep `result = 1` and `base = x`.
2. While `n > 0`: if the lowest bit of `n` is 1, multiply `result` by `base`; then square `base` and shift `n` right by 1.
3. If the original exponent was negative, return `1 / result`.

Each step halves `n`, so only about `log2(n)` multiplications happen. Store `n` in a 64-bit integer before negating it, because `-INT_MIN` overflows a 32-bit int.
- **Time:** O(log |n|)
- **Space:** O(1) (iterative; the recursive form uses O(log n) stack)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    double myPow(double x, int n) {
        long long e = n;
        bool negative = e < 0;
        if (negative) e = -e;
        double result = 1.0, base = x;
        while (e > 0) {
            if (e & 1) result *= base;
            base *= base;
            e >>= 1;
        }
        return negative ? 1.0 / result : result;
    }
};
```

### Java
```java
class Solution {
    public double myPow(double x, int n) {
        long e = n;
        boolean negative = e < 0;
        if (negative) e = -e;
        double result = 1.0, base = x;
        while (e > 0) {
            if ((e & 1) == 1) result *= base;
            base *= base;
            e >>= 1;
        }
        return negative ? 1.0 / result : result;
    }
}
```

### Python
```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        e = abs(n)
        result, base = 1.0, x
        while e > 0:
            if e & 1:
                result *= base
            base *= base
            e >>= 1
        return 1.0 / result if n < 0 else result
```

## Key Takeaways
- Binary exponentiation: square the base, halve the exponent, multiply in when the bit is set.
- Convert `n` to a 64-bit type before taking its absolute value; `-INT_MIN` overflows otherwise.
- `n = 0` returns 1 for any `x` (including `x = 0`), and negative exponents are handled by inverting once at the end.
- The same skeleton works for modular exponentiation and fast matrix powers.
