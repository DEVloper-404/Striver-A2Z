# Find missing number

**Difficulty:** Easy  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Easy

## Problem
You are given an array of `n-1` distinct integers, each between `1` and `n` inclusive. Exactly one number from `1..n` is missing. Return it.

Input: `arr = [1, 2, 4, 5], n = 5`
Output: `3`

## Approach 1: Check Every Candidate
For each value `v` from `1` to `n`, scan the array to see whether `v` is present. The first value not found is the answer.

- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Presence Array or Hash Set
Mark every array element in a boolean array of size `n+1`, then find the index in `1..n` that stays unmarked.

- **Time:** O(n)
- **Space:** O(n)

## Approach 3: Sum Formula
The sum of `1..n` is `n(n+1)/2`. Subtract the sum of the array elements; the difference is the missing number. Watch for overflow: the expected sum can exceed 32-bit range for large `n`, so use a 64-bit type.

- **Time:** O(n)
- **Space:** O(1)

## Approach 4: XOR (Optimal)
XOR has two useful properties: `x ^ x = 0` and `x ^ 0 = x`, and it is commutative. XOR all the numbers `1..n` together, then XOR all array elements into the same accumulator. Every present number appears twice (once from the range, once from the array) and cancels out, leaving only the missing number. Unlike the sum formula, XOR never overflows.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int missingNumber(vector<int>& arr, int n) {
        int x = 0;
        for (int v = 1; v <= n; v++) x ^= v;
        for (int v : arr) x ^= v;
        return x;
    }
};
```

### Python
```python
class Solution:
    def missingNumber(self, arr: list[int], n: int) -> int:
        x = 0
        for v in range(1, n + 1):
            x ^= v
        for v in arr:
            x ^= v
        return x
```

## Key Takeaways
- Pairs cancel under XOR, so XOR-ing the full range with the array leaves exactly the unmatched value.
- The sum formula is equally fast but needs 64-bit arithmetic for large `n`; XOR sidesteps overflow entirely.
- If the range is `0..n` instead of `1..n` (LeetCode's variant), start the range loop at `0` or XOR in `n` and the indices.
- Edge cases: missing number is `1` or `n`; `n = 1` with an empty array returns `1`.
