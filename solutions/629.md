# Sort a Linked List of 0's 1's and 2's

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
You are given the head of a singly linked list in which every node's value is 0, 1, or 2. Rearrange the list so all 0s come first, then all 1s, then all 2s, and return the head. The preferred solution changes links rather than overwriting values.

```
Input:  1 -> 2 -> 0 -> 1 -> 2 -> 0
Output: 0 -> 0 -> 1 -> 1 -> 2 -> 2
```

## Approach 1: Count and overwrite
Traverse once counting how many 0s, 1s and 2s there are. Traverse again writing `c0` zeros, then `c1` ones, then `c2` twos into the nodes. Two passes and O(1) space, but it mutates values instead of relinking nodes, which some problem statements forbid.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Three buckets by relinking (optimal)
Create three dummy heads (`zero`, `one`, `two`) with matching tail pointers. Walk the list once and append each node to the bucket for its value by moving the tail's `next`. After the walk, stitch the buckets together: zero-tail to the first 1 (or the first 2 if there are no 1s), one-tail to the first 2, and terminate the two-tail with null. The head of the result is the first non-empty bucket, which `zero.next -> one.next -> two.next` chaining handles automatically.

- **Time:** O(n)
- **Space:** O(1) (three dummy nodes)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
public:
    ListNode* sortList012(ListNode* head) {
        ListNode zero(0), one(0), two(0);
        ListNode* z = &zero; ListNode* o = &one; ListNode* t = &two;
        for (ListNode* cur = head; cur; cur = cur->next) {
            if (cur->val == 0)      { z->next = cur; z = cur; }
            else if (cur->val == 1) { o->next = cur; o = cur; }
            else                    { t->next = cur; t = cur; }
        }
        z->next = one.next ? one.next : two.next;
        o->next = two.next;
        t->next = nullptr;
        return zero.next;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } }

class Solution {
    public ListNode sortList012(ListNode head) {
        ListNode zero = new ListNode(0), one = new ListNode(0), two = new ListNode(0);
        ListNode z = zero, o = one, t = two;
        for (ListNode cur = head; cur != null; cur = cur.next) {
            if (cur.val == 0)      { z.next = cur; z = cur; }
            else if (cur.val == 1) { o.next = cur; o = cur; }
            else                   { t.next = cur; t = cur; }
        }
        z.next = (one.next != null) ? one.next : two.next;
        o.next = two.next;
        t.next = null;
        return zero.next;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def sortList012(self, head):
        zero, one, two = ListNode(0), ListNode(0), ListNode(0)
        z, o, t = zero, one, two
        cur = head
        while cur:
            if cur.val == 0:
                z.next = cur; z = cur
            elif cur.val == 1:
                o.next = cur; o = cur
            else:
                t.next = cur; t = cur
            cur = cur.next
        z.next = one.next if one.next else two.next
        o.next = two.next
        t.next = None
        return zero.next
```

## Key Takeaways
- Partitioning into buckets with dummy heads is a single-pass, link-only sort for a fixed small alphabet.
- Terminate the last bucket's tail with null, otherwise the old list tail can point into the middle of the result.
- When joining buckets, skip an empty middle bucket (`one.next` may be null).
- Counting values is a valid fallback when mutating values is allowed.
