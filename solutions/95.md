# Minimum days to make M bouquets

**Difficulty:** Medium  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on Answers

## Problem
You have `n` flowers in a row; `bloomDay[i]` is the day the i-th flower blooms. A bouquet needs `k` adjacent bloomed flowers, and you must make `m` bouquets. Return the minimum day on which this is possible, or `-1` if it never is.

Input: bloomDay = [1, 10, 3, 10, 2], m = 3, k = 1
Output: 3  (by day 3 flowers at indices 0, 2, 4 have bloomed → 3 bouquets of size 1)

Input: bloomDay = [7, 7, 7, 7, 12, 7, 7], m = 2, k = 3
Output: 12

## Approach 1: Check Every Day
If `m * k > n` there are not enough flowers, return `-1`. Otherwise, for each day `d` from `min(bloomDay)` to `max(bloomDay)`, scan the array counting runs of consecutive flowers with `bloomDay[i] <= d`; every time a run reaches length `k`, count one bouquet and reset. The first `d` that yields at least `m` bouquets is the answer.
- **Time:** O((max - min) * n)
- **Space:** O(1)

## Approach 2: Binary Search on the Day
If we can make `m` bouquets by day `d`, we can also make them on any later day (more flowers bloom, runs only grow). So feasibility is monotone in `d`. Binary search `d` over `[min(bloomDay), max(bloomDay)]`, using the same linear "count bouquets" check. When feasible, record `d` and search left; otherwise search right.
- **Time:** O(n * log(max - min))
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    bool canMake(const vector<int>& bloomDay, int m, int k, int day) {
        int bouquets = 0, run = 0;
        for (int b : bloomDay) {
            if (b <= day) {
                if (++run == k) { bouquets++; run = 0; }
            } else {
                run = 0;
            }
        }
        return bouquets >= m;
    }

    int minDays(vector<int>& bloomDay, int m, int k) {
        long long need = 1LL * m * k;
        if (need > (long long)bloomDay.size()) return -1;
        int lo = *min_element(bloomDay.begin(), bloomDay.end());
        int hi = *max_element(bloomDay.begin(), bloomDay.end());
        int ans = -1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (canMake(bloomDay, m, k, mid)) {
                ans = mid;
                hi = mid - 1;
            } else {
                lo = mid + 1;
            }
        }
        return ans;
    }
};
```

    private boolean canMake(int[] bloomDay, int m, int k, int day) {
        int bouquets = 0, run = 0;
        for (int b : bloomDay) {
            if (b <= day) {
                if (++run == k) { bouquets++; run = 0; }

        return bouquets >= m;
    }

    public int minDays(int[] bloomDay, int m, int k) {
        if ((long) m * k > bloomDay.length) return -1;
        int lo = Integer.MAX_VALUE, hi = Integer.MIN_VALUE;
        for (int b : bloomDay) {
            lo = Math.min(lo, b);
            hi = Math.max(hi, b);
        }
        int ans = -1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (canMake(bloomDay, m, k, mid)) {
                ans = mid;
                hi = mid - 1;
            } else {
                lo = mid + 1;
            }
        }
        return ans;
    }
}

### Python
```python
from typing import List

class Solution:
    def minDays(self, bloomDay: List[int], m: int, k: int) -> int:
        if m * k > len(bloomDay):
            return -1

        def can_make(day: int) -> bool:
            bouquets = run = 0
            for b in bloomDay:
                if b <= day:
                    run += 1
                    if run == k:
                        bouquets += 1
                        run = 0
                else:
                    run = 0
            return bouquets >= m

        lo, hi = min(bloomDay), max(bloomDay)
        ans = -1
        while lo <= hi:
            mid = (lo + hi) // 2
            if can_make(mid):
                ans = mid
                hi = mid - 1
            else:
                lo = mid + 1
        return ans
```

## Key Takeaways
- Check the impossibility condition `m * k > n` up front (use 64-bit for the product).
- The feasibility check counts *adjacent* bloomed runs; a non-bloomed flower resets the run.
- Search space is `[min, max]` of the array, not `[1, max]`, which slightly tightens the search.
