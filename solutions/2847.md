# Find the starting point in LL

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
Given the head of a singly linked list that may contain a cycle, return the node where the cycle begins (the first node that is visited twice when walking from the head). If there is no cycle, return null. Do not modify the list.

```
Input:  3 -> 2 -> 0 -> -4 -> (back to 2)
Output: node 2

Input:  1 -> 2 -> null
Output: null
```

## Approach 1: Hash set
Walk the list, inserting each node into a set. The first node already in the set when we reach it is the cycle's entry. Reaching null means no cycle.

- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Floyd's algorithm with a reset (optimal)
Phase 1: run slow/fast pointers. If they never meet, return null.

Phase 2: let the distance from head to the cycle entry be `a`, and the cycle length be `L`. When slow and fast meet, slow has walked `a + b` steps (b = offset inside the cycle) and fast has walked `2(a + b)`. The difference `a + b` must be a multiple of `L`, so `a` is congruent to `-b` modulo `L`. That means walking `a` more steps from the meeting point lands exactly on the entry. So: put one pointer back at the head, leave the other at the meeting point, and advance both one step at a time. They meet at the cycle start.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
public:
    ListNode* detectCycle(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) {
                ListNode* p = head;
                while (p != slow) {
                    p = p->next;
                    slow = slow->next;
                }
                return p;
            }
        }
        return nullptr;
    }
};
```

    public ListNode detectCycle(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;

                ListNode p = head;

        }

### Python
```python
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head):
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                p = head
                while p is not slow:
                    p = p.next
                    slow = slow.next
                return p
        return None
```

## Key Takeaways
- Two phases: detect the meeting point, then reset one pointer to head and move both at speed 1.
- The reset works because head-to-entry distance equals meeting-point-to-entry distance modulo the cycle length.
- If the cycle starts at the head, the second phase returns immediately (p == slow at once).
- Uses O(1) space and never mutates the list.
