# Longest Consecutive Sequence in an Array

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Medium

## Problem
Given an unsorted array of integers, return the length of the longest run of consecutive integers that all appear in the array (the numbers do not need to be adjacent in the input). Duplicates count once. The target is an O(n) algorithm.

```
Input:  nums = [100, 4, 200, 1, 3, 2]
Output: 4        (the run 1, 2, 3, 4)
```

## Approach 1: Brute Force
For each element `x`, repeatedly search the array for `x+1`, `x+2`, ... until a value is missing, counting how far the chain goes. Each search is a linear scan.
- **Time:** O(n²) (O(n³) in the worst case if runs are long and every search is linear)
- **Space:** O(1)

## Approach 2: Sort
Sort the array, then walk it once. Keep a counter that grows when `nums[i] == nums[i-1] + 1`, stays the same when `nums[i] == nums[i-1]` (duplicate), and resets to 1 otherwise. Track the best counter value.
- **Time:** O(n log n)
- **Space:** O(1) extra if sorting in place

## Approach 3: Hash Set (Optimal)
Put every value in a hash set. Now the question "is `y` present?" is O(1). The key insight is to only start counting from the *beginning* of a run: for a value `x`, if `x - 1` is in the set, then `x` is not a start and we skip it. If `x - 1` is absent, walk `x+1, x+2, ...` while present and record the length. Each element is visited as part of at most one walk, so the whole thing is linear despite the nested loop.
- **Time:** O(n) average
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <unordered_set>
#include <algorithm>
using namespace std;

class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> s(nums.begin(), nums.end());
        int best = 0;
        for (int x : s) {
            if (s.count(x - 1)) continue;     // not the start of a run
            int len = 1;
            while (s.count(x + len)) ++len;
            best = max(best, len);
        }
        return best;
    }
};
```

### Java
```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> s = new HashSet<>();
        for (int x : nums) s.add(x);
        int best = 0;
        for (int x : s) {
            if (s.contains(x - 1)) continue;
            int len = 1;
            while (s.contains(x + len)) len++;
            best = Math.max(best, len);
        }
        return best;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        s = set(nums)
        best = 0
        for x in s:
            if x - 1 in s:
                continue
            length = 1
            while x + length in s:
                length += 1
            best = max(best, length)
        return best
```

## Key Takeaways
- Only start counting from run *starts* (`x - 1` absent); that is what turns O(n²) into O(n).
- Iterate over the set, not the array, so duplicates do not repeat work.
- The sort approach is a solid fallback and easier to reason about, but remember to skip equal neighbours.
- Empty input returns 0; a single element returns 1.
