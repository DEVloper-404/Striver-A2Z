# Pascal's Triangle I

**Difficulty:** Easy  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Hard

## Problem
Given an integer `numRows`, produce the first `numRows` rows of Pascal's triangle. Every row starts and ends with 1, and each interior value is the sum of the two values directly above it. Return the rows as a list of lists.

Input: `numRows = 5`
Output: `[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]`

Three common variants of this problem show up: (a) print the whole triangle, (b) return a specific row, (c) return a single cell `(r, c)`. The optimal section below handles (a) and shows how (b) and (c) follow from the same formula.

## Approach 1: Build row by row from the previous row
Start with `[1]`. For each new row, put 1 at both ends and fill position `j` with `prev[j-1] + prev[j]`. This is a direct simulation of the definition.
- **Time:** O(n²) — total number of cells is n(n+1)/2
- **Space:** O(n²) for the output (O(1) extra beyond it)

## Approach 2: Generate each row with the running-ratio formula
Cell `(r, c)` (1-indexed) equals `C(r-1, c-1)`. Instead of computing factorials, walk along the row: start with `val = 1`, and for `i` from 1 to `r-1`, do `val = val * (r - i) / i`. Each step turns `C(r-1, i-1)` into `C(r-1, i)` with one multiply and one exact division, so a row costs O(r) and a single cell costs O(c).
- **Time:** O(n²) for the whole triangle, O(r) for one row, O(c) for one cell
- **Space:** O(n²) for the output; O(1) extra

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    // Row number r (1-indexed) built with the running ratio trick.
    vector<int> buildRow(int r) {
        vector<int> row;
        row.reserve(r);
        long long val = 1;
        row.push_back(1);
        for (int i = 1; i < r; ++i) {
            val = val * (r - i) / i;
            row.push_back((int)val);
        }
        return row;
    }

    vector<vector<int>> generate(int numRows) {
        vector<vector<int>> tri;
        for (int r = 1; r <= numRows; ++r) tri.push_back(buildRow(r));
        return tri;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private List<Integer> buildRow(int r) {
        List<Integer> row = new ArrayList<>(r);
        long val = 1;
        row.add(1);
        for (int i = 1; i < r; i++) {
            val = val * (r - i) / i;
            row.add((int) val);
        }
        return row;
    }

    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> tri = new ArrayList<>();
        for (int r = 1; r <= numRows; r++) tri.add(buildRow(r));
        return tri;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def _build_row(self, r: int) -> List[int]:
        row = [1]
        val = 1
        for i in range(1, r):
            val = val * (r - i) // i
            row.append(val)
        return row

    def generate(self, numRows: int) -> List[List[int]]:
        return [self._build_row(r) for r in range(1, numRows + 1)]
```

## Key Takeaways
- Cell `(r, c)` is `C(r-1, c-1)`; the running ratio `val = val * (r-i) / i` computes it with no factorials and no overflow for LeetCode limits.
- The same helper answers all three variants: full triangle, one row, one cell.
- Use a 64-bit accumulator in C++/Java; intermediate products can exceed 32 bits before the division.
