# Union of two sorted arrays

**Difficulty:** Easy  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Easy

## Problem
Given two arrays `a` (size `n`) and `b` (size `m`), both sorted in non-decreasing order and possibly containing duplicates, return their union: every distinct value that appears in either array, in sorted order.

Input: `a = [1, 1, 2, 3, 4, 5], b = [2, 3, 4, 4, 5, 6]`
Output: `[1, 2, 3, 4, 5, 6]`

## Approach 1: Ordered Set
Insert every element of both arrays into an ordered set (a hash set plus a final sort works too). The set removes duplicates and iterating it yields sorted order.

- **Time:** O((n + m) log(n + m))
- **Space:** O(n + m)

## Approach 2: Two-Pointer Merge (Optimal)
Both inputs are already sorted, so we can merge them the way merge sort does, while skipping duplicates. Keep `i` on `a` and `j` on `b`:

1. Compare `a[i]` and `b[j]`. Take the smaller one (either one if equal) as the candidate.
2. Append the candidate to the result **only if** it differs from the last element already in the result. This single check handles duplicates within an array and across the two arrays, because the result is built in sorted order and equal values arrive consecutively.
3. Advance the pointer(s) whose value was consumed.
4. When one array is exhausted, drain the other with the same "append if different from last" rule.

- **Time:** O(n + m)
- **Space:** O(n + m) for the output only.

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> findUnion(vector<int>& a, vector<int>& b) {
        int n = a.size(), m = b.size();
        vector<int> res;
        int i = 0, j = 0;
        auto push = [&](int v) {
            if (res.empty() || res.back() != v) res.push_back(v);
        };
        while (i < n && j < m) {
            if (a[i] <= b[j]) push(a[i++]);
            else push(b[j++]);
        }
        while (i < n) push(a[i++]);
        while (j < m) push(b[j++]);
        return res;
    }
};
```

### Java
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    private void push(List<Integer> res, int v) {
        if (res.isEmpty() || res.get(res.size() - 1) != v) res.add(v);
    }

    public List<Integer> findUnion(int[] a, int[] b) {
        int n = a.length, m = b.length;
        List<Integer> res = new ArrayList<>();
        int i = 0, j = 0;
        while (i < n && j < m) {
            if (a[i] <= b[j]) push(res, a[i++]);
            else push(res, b[j++]);
        }
        while (i < n) push(res, a[i++]);
        while (j < m) push(res, b[j++]);
        return res;
    }
}
```

### Python
```python
class Solution:
    def findUnion(self, a: list[int], b: list[int]) -> list[int]:
        res: list[int] = []

        def push(v: int) -> None:
            if not res or res[-1] != v:
                res.append(v)

        i = j = 0
        n, m = len(a), len(b)
        while i < n and j < m:
            if a[i] <= b[j]:
                push(a[i]); i += 1
            else:
                push(b[j]); j += 1
        while i < n:
            push(a[i]); i += 1
        while j < m:
            push(b[j]); j += 1
        return res
```

## Key Takeaways
- Sorted inputs mean a merge-style two-pointer walk produces sorted output without any extra sorting.
- "Only append if it differs from the last appended value" is enough to deduplicate, because equal values are always adjacent in a sorted merge.
- Do not forget to drain the leftover tail of the longer array.
- Edge cases: one array empty; all elements identical across both arrays (result has one element).
