# 3 Sum

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Hard

## Problem
Given an integer array `nums`, return every unique triplet `[a, b, c]` of values taken from three different indices such that `a + b + c == 0`. The output must not contain duplicate triplets, but the order of triplets and of values inside a triplet does not matter.

Input: `nums = [-1, 0, 1, 2, -1, -4]`
Output: `[[-1, -1, 2], [-1, 0, 1]]`

## Approach 1: Brute Force
Try all index triples `i < j < k`, keep those whose sum is zero, sort each triplet and insert it into a set to strip duplicates.
- **Time:** O(n³ · log m) where m is the number of stored triplets
- **Space:** O(m) for the set

## Approach 2: Hashing the third value
Fix `i`, then for each `j > i` look up whether `-(nums[i] + nums[j])` was seen among indices strictly between `i` and `j` (a set that is rebuilt for each `i`). Triplets still need sorting + a set to remove duplicates.
- **Time:** O(n² · log m)
- **Space:** O(n) for the per-`i` set plus O(m) for results

## Approach 3: Sort + two pointers (Optimal)
1. Sort the array. Now duplicates are adjacent, and for a fixed first element the remaining two can be found by walking two pointers inward.
2. For each `i`, skip it if `nums[i] == nums[i-1]` (already handled). Set `lo = i+1`, `hi = n-1`.
3. While `lo < hi`: compute `s = nums[i] + nums[lo] + nums[hi]`. If `s < 0` move `lo` right, if `s > 0` move `hi` left, otherwise record the triplet and advance both pointers past any repeated values.
4. Because the array is sorted, each triplet is discovered exactly once, so no auxiliary set is needed.

- **Time:** O(n²) after O(n log n) sort
- **Space:** O(1) extra (ignoring output and sort's internal stack)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> res;
        sort(nums.begin(), nums.end());
        int n = nums.size();
        for (int i = 0; i < n - 2; ++i) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            if (nums[i] > 0) break;            // no way to reach zero
            int lo = i + 1, hi = n - 1;
            while (lo < hi) {
                long long s = (long long)nums[i] + nums[lo] + nums[hi];
                if (s < 0) ++lo;
                else if (s > 0) --hi;
                else {
                    res.push_back({nums[i], nums[lo], nums[hi]});
                    ++lo; --hi;
                    while (lo < hi && nums[lo] == nums[lo - 1]) ++lo;
                    while (lo < hi && nums[hi] == nums[hi + 1]) --hi;
                }
            }
        }
        return res;
    }
};
```

import java.util.*;

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        Arrays.sort(nums);
        int n = nums.length;
        for (int i = 0; i < n - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            if (nums[i] > 0) break;
            int lo = i + 1, hi = n - 1;
            while (lo < hi) {
                long s = (long) nums[i] + nums[lo] + nums[hi];
                if (s < 0) lo++;
                else if (s > 0) hi--;
                else {
                    res.add(Arrays.asList(nums[i], nums[lo], nums[hi]));
                    lo++; hi--;
                    while (lo < hi && nums[lo] == nums[lo - 1]) lo++;
                    while (lo < hi && nums[hi] == nums[hi + 1]) hi--;
                }
            }
        }
        return res;
    }
}

### Python
```python
from typing import List

class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        n = len(nums)
        res = []
        for i in range(n - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            if nums[i] > 0:
                break
            lo, hi = i + 1, n - 1
            while lo < hi:
                s = nums[i] + nums[lo] + nums[hi]
                if s < 0:
                    lo += 1
                elif s > 0:
                    hi -= 1
                else:
                    res.append([nums[i], nums[lo], nums[hi]])
                    lo += 1
                    hi -= 1
                    while lo < hi and nums[lo] == nums[lo - 1]:
                        lo += 1
                    while lo < hi and nums[hi] == nums[hi + 1]:
                        hi -= 1
        return res
```

## Key Takeaways
- "Sort, fix one, two-pointer the rest" is the standard shape for k-sum problems; each extra `k` adds one nested loop.
- Duplicate handling has two places: skip repeated `nums[i]`, and after a hit skip repeated `nums[lo]` / `nums[hi]`.
- Early exit when `nums[i] > 0` is a small but free pruning since the array is sorted.
