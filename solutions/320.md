# Partition a set into two subsets with minimum absolute sum difference

**Difficulty:** Hard  ·  **Topic:** Dynamic Programming [Patterns and Problems] › DP on Subsequences

## Problem
You are given an array of non-negative integers. Split every element into one of two groups (each element must go somewhere, groups may be empty) so that the absolute difference between the two group sums is as small as possible. Return that minimum difference.

```
Input:  arr = [3, 1, 4, 2, 2, 1]
Output: 1
Explanation: {3, 1, 2} sums to 6 and {4, 2, 1} sums to 7, difference 1.
```

## Approach 1: Brute Force (try every subset)
Every element has two choices — group A or group B — so there are 2^n assignments. Generate each one recursively, add up group A as `s1`, and note that group B is forced to be `total - s1`. The answer is the minimum of `|total - 2*s1|` over all subsets.

This is correct but hopeless beyond n ≈ 25.

- **Time:** O(2^n)
- **Space:** O(n) recursion stack

## Approach 2: Optimal (subset-sum reachability table)

**The key observation.** Let `total` be the sum of the whole array. If one group has sum `s1`, the other group is fully determined: `total - s1`. The difference is `|total - 2*s1|`. So the problem is *not* really about partitioning at all — it collapses to a single question:

> Which sums `s1` are achievable by *some* subset of the array?

Once we know the set of achievable sums, we just scan it and keep the one that minimises `|total - 2*s1|`.

**Why we only need to scan half.** Since `s1` and `total - s1` describe the same partition from the two sides, it is enough to look at `s1` in `[0, total/2]`. The best `s1` is the achievable value closest to `total/2` from below, and the answer is `total - 2*s1`.

**Building the reachable set.** This is exactly the classic subset-sum DP. Define

`dp[i][t] = true` if some subset of the first `i+1` elements sums to exactly `t`.

Transition for element `arr[i]`: we either skip it (`dp[i-1][t]`) or take it (`dp[i-1][t - arr[i]]`, valid only when `t >= arr[i]`). Base row: with only `arr[0]` available, sum `0` is reachable (take nothing) and sum `arr[0]` is reachable. Careful with zeros in the array — writing the base row as "`dp[0][0] = true` and `dp[0][arr[0]] = true`" handles `arr[0] == 0` correctly because both assignments hit the same cell.

The last row `dp[n-1][*]` is precisely the set of achievable subset sums.

**Space reduction.** Row `i` only reads row `i-1`, so keep two boolean rows of size `total+1` and roll them. (A single row iterated from high `t` down to low also works.)

**Dry run on [3, 1, 4, 2, 2, 1], total = 13.**
- After 3: reachable = {0, 3}
- After 1: {0, 1, 3, 4}
- After 4: {0, 1, 3, 4, 5, 7, 8}
- After 2: {0, 1, 2, 3, 4, 5, 6, 7, 9, 10}
- After 2: adds 8, 11, 12 → {0..12}
- After 1: {0..13}

Scanning `s1` from 0 to 6, the largest reachable value is 6, giving `13 - 12 = 1`. Matches the expected answer.

- **Time:** O(n · total)
- **Space:** O(total)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int minSubsetSumDifference(vector<int>& arr, int n) {
        int total = 0;
        for (int x : arr) total += x;

        // prev[t] = can some subset of processed elements sum to t?
        vector<char> prev(total + 1, 0), cur(total + 1, 0);
        prev[0] = 1;
        if (arr[0] <= total) prev[arr[0]] = 1;

        for (int i = 1; i < n; i++) {
            fill(cur.begin(), cur.end(), 0);
            cur[0] = 1;
            for (int t = 1; t <= total; t++) {
                bool notTake = prev[t];
                bool take = (t >= arr[i]) ? prev[t - arr[i]] : false;
                cur[t] = notTake || take;
            }
            prev = cur;
        }

        int best = INT_MAX;
        for (int s1 = 0; s1 <= total / 2; s1++)
            if (prev[s1]) best = min(best, total - 2 * s1);
        return best;
    }
};
```

### Java
```java
class Solution {
    public int minSubsetSumDifference(int[] arr, int n) {
        int total = 0;
        for (int x : arr) total += x;

        boolean[] prev = new boolean[total + 1];
        boolean[] cur = new boolean[total + 1];
        prev[0] = true;
        if (arr[0] <= total) prev[arr[0]] = true;

        for (int i = 1; i < n; i++) {
            java.util.Arrays.fill(cur, false);
            cur[0] = true;
            for (int t = 1; t <= total; t++) {
                boolean notTake = prev[t];
                boolean take = (t >= arr[i]) && prev[t - arr[i]];
                cur[t] = notTake || take;
            }
            boolean[] tmp = prev; prev = cur; cur = tmp;
        }

        int best = Integer.MAX_VALUE;
        for (int s1 = 0; s1 <= total / 2; s1++)
            if (prev[s1]) best = Math.min(best, total - 2 * s1);
        return best;
    }
}
```

### Python
```python
class Solution:
    def minSubsetSumDifference(self, arr, n):
        total = sum(arr)

        prev = [False] * (total + 1)
        prev[0] = True
        if arr[0] <= total:
            prev[arr[0]] = True

        for i in range(1, n):
            cur = [False] * (total + 1)
            cur[0] = True
            for t in range(1, total + 1):
                not_take = prev[t]
                take = prev[t - arr[i]] if t >= arr[i] else False
                cur[t] = not_take or take
            prev = cur

        best = float('inf')
        for s1 in range(total // 2 + 1):
            if prev[s1]:
                best = min(best, total - 2 * s1)
        return best
```

## Key Takeaways
- The partition question reduces to plain subset-sum: knowing one side's sum determines the other, so `|total - 2*s1|` is the whole objective.
- Keep the *entire* last DP row, not just a single boolean — you need every reachable sum to pick the best one.
- Scanning only `s1 ≤ total/2` avoids double work and makes `total - 2*s1` non-negative, so no `abs` is needed.
- Watch zeros and empty-ish inputs: setting `dp[0][0] = true` before `dp[0][arr[0]] = true` keeps the base row correct when `arr[0]` is 0.
