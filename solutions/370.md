# Divisors of a Number

**Difficulty:** Easy  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Advanced Maths

## Problem
Given a positive integer `n`, print all of its divisors in ascending order. A divisor is any integer `d` with `1 <= d <= n` such that `n % d == 0`.

Input: `n = 36`
Output: `1 2 3 4 6 9 12 18 36`

## Approach 1: Brute Force
Try every candidate from 1 to `n` and print the ones that divide `n` evenly. The output is naturally sorted because the loop goes upward.
- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Optimal (pair up divisors)
If `i` divides `n`, then `n / i` also divides `n`. One of the two is always `<= sqrt(n)`, so scanning `i` from 1 to `sqrt(n)` discovers every divisor either directly or as its partner `n / i`. Be careful when `i == n / i` (perfect squares) so the square root is not listed twice.

The pairs come out unsorted (`1, 36, 2, 18, ...`), so either sort at the end, or collect the small halves in one list and the large halves in another and concatenate the second in reverse.
- **Time:** O(sqrt(n)) to find them, plus O(d log d) if you sort `d` divisors (or O(d) with the two-list trick)
- **Space:** O(d) for the output

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

vector<int> divisors(int n) {
    vector<int> small, large;
    for (int i = 1; (long long)i * i <= n; i++) {
        if (n % i == 0) {
            small.push_back(i);
            if (i != n / i) large.push_back(n / i);
        }
    }
    for (int k = (int)large.size() - 1; k >= 0; k--) small.push_back(large[k]);
    return small;
}
```

### Java
```java
import java.util.*;

class Solution {
    public List<Integer> divisors(int n) {
        List<Integer> small = new ArrayList<>(), large = new ArrayList<>();
        for (int i = 1; (long) i * i <= n; i++) {
            if (n % i == 0) {
                small.add(i);
                if (i != n / i) large.add(n / i);
            }
        }
        for (int k = large.size() - 1; k >= 0; k--) small.add(large.get(k));
        return small;
    }
}
```

### Python
```python
def divisors(n: int) -> list[int]:
    small, large = [], []
    i = 1
    while i * i <= n:
        if n % i == 0:
            small.append(i)
            if i != n // i:
                large.append(n // i)
        i += 1
    return small + large[::-1]
```

## Key Takeaways
- Divisors come in pairs `(i, n/i)`; scanning to `sqrt(n)` is enough.
- Skip the duplicate when `i * i == n`.
- Use `i * i <= n` instead of `i <= sqrt(n)` to avoid floating point rounding issues.
- The same pairing trick underlies checking primality and counting divisors.
