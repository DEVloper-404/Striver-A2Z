# Maximum Sum Combination

**Difficulty:** Hard  ·  **Topic:** Heaps [Learning, Medium, Hard Problems] › Hard Problems

## Problem
You are given two integer arrays `A` and `B` of equal length `n` and an integer `k`. Consider every sum `A[i] + B[j]` over all index pairs `(i, j)`. Return the `k` largest such sums in descending order. Pairs are distinct by index, so equal sums from different pairs are each counted.

```
Input:  A = [3, 2], B = [1, 4], k = 2
Output: [7, 6]
```
All sums are 4, 7, 3, 6; the two largest are 7 and 6.

## Approach 1: Enumerate all pairs
Compute all `n^2` sums, sort them descending, and take the first `k`. Works, but quadratic in memory and `n^2 log n^2` in time, which is too slow for `n` around 10^5.
- **Time:** O(n^2 log n)
- **Space:** O(n^2)

## Approach 2: Bounded min-heap over all pairs
Still enumerate every pair, but push each sum into a min-heap that never exceeds `k` elements (pop the minimum when it overflows). Memory drops to O(k), but time is still quadratic.
- **Time:** O(n^2 log k)
- **Space:** O(k)

## Approach 3: Sorted arrays plus a max-heap frontier (optimal)
Sort both arrays in descending order. Now the largest sum is `A[0] + B[0]`. Whenever `(i, j)` is taken, the next candidates that could be the next largest are `(i + 1, j)` and `(i, j + 1)`; any other unvisited pair is dominated by one of the pairs already in the frontier.

1. Push `(A[0] + B[0], 0, 0)` into a max-heap and mark `(0, 0)` visited.
2. Pop the top, append its sum to the answer.
3. Push `(i + 1, j)` and `(i, j + 1)` if they are in range and not yet visited.
4. Stop after `k` pops.

Each pop adds at most two entries, so the heap holds O(k) items.
- **Time:** O(n log n + k log k)
- **Space:** O(k)

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<int> maxCombinations(vector<int>& A, vector<int>& B, int k) {
        int n = A.size();
        sort(A.rbegin(), A.rend());
        sort(B.rbegin(), B.rend());

        priority_queue<tuple<int, int, int>> maxHeap; // (sum, i, j)
        set<pair<int, int>> seen;
        maxHeap.push({A[0] + B[0], 0, 0});
        seen.insert({0, 0});

        vector<int> result;
        while ((int)result.size() < k && !maxHeap.empty()) {
            auto [sum, i, j] = maxHeap.top();
            maxHeap.pop();
            result.push_back(sum);

            if (i + 1 < n && !seen.count({i + 1, j})) {
                seen.insert({i + 1, j});
                maxHeap.push({A[i + 1] + B[j], i + 1, j});
            }
            if (j + 1 < n && !seen.count({i, j + 1})) {
                seen.insert({i, j + 1});
                maxHeap.push({A[i] + B[j + 1], i, j + 1});
            }
        }
        return result;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public List<Integer> maxCombinations(int[] A, int[] B, int k) {
        int n = A.length;
        Arrays.sort(A);
        Arrays.sort(B);
        // reverse both to get descending order
        for (int l = 0, r = n - 1; l < r; l++, r--) {
            int t = A[l]; A[l] = A[r]; A[r] = t;
            t = B[l]; B[l] = B[r]; B[r] = t;
        }

        PriorityQueue<int[]> maxHeap = new PriorityQueue<>((x, y) -> y[0] - x[0]); // {sum, i, j}
        Set<Long> seen = new HashSet<>();
        maxHeap.offer(new int[]{A[0] + B[0], 0, 0});
        seen.add(0L);

        List<Integer> result = new ArrayList<>();
        while (result.size() < k && !maxHeap.isEmpty()) {
            int[] top = maxHeap.poll();
            int i = top[1], j = top[2];
            result.add(top[0]);

            if (i + 1 < n && seen.add((long) (i + 1) * n + j)) {
                maxHeap.offer(new int[]{A[i + 1] + B[j], i + 1, j});
            }
            if (j + 1 < n && seen.add((long) i * n + (j + 1))) {
                maxHeap.offer(new int[]{A[i] + B[j + 1], i, j + 1});
            }
        }
        return result;
    }
}
```

### Python
```python
import heapq
from typing import List


class Solution:
    def maxCombinations(self, A: List[int], B: List[int], k: int) -> List[int]:
        n = len(A)
        A = sorted(A, reverse=True)
        B = sorted(B, reverse=True)

        heap = [(-(A[0] + B[0]), 0, 0)]  # negate for max-heap behaviour
        seen = {(0, 0)}
        result = []

        while len(result) < k and heap:
            neg_sum, i, j = heapq.heappop(heap)
            result.append(-neg_sum)
            if i + 1 < n and (i + 1, j) not in seen:
                seen.add((i + 1, j))
                heapq.heappush(heap, (-(A[i + 1] + B[j]), i + 1, j))
            if j + 1 < n and (i, j + 1) not in seen:
                seen.add((i, j + 1))
                heapq.heappush(heap, (-(A[i] + B[j + 1]), i, j + 1))
        return result
```

## Key Takeaways
- Sorting both arrays descending turns the `n x n` sum grid into a matrix that decreases along both rows and columns, so a frontier search from the corner enumerates sums in order.
- The visited set is mandatory: `(i + 1, j + 1)` is reachable from two different parents and would otherwise be emitted twice.
- The heap never grows beyond about `2k` entries, so the method scales even when `n^2` is astronomically large.
- Assume `k <= n * n`; if `k` could be larger, the loop exits early when the heap runs dry.
