# Pattern 15

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print an inverted letter triangle of `n` rows. The first row contains the first `n` letters `A … `, and each following row drops the last letter, ending with a single `A`.

Input: `n = 5`
Output:
```
A B C D E
A B C D
A B C
A B
A
```

## Approach
Combine the shrinking bound of Pattern 6 with the letter printing of Pattern 14.

1. Outer loop `i` from `0` to `n-1`.
2. Inner loop `j` from `0` to `n-i-1`: print `'A' + j`.
3. Newline.

Each row starts at `A` and stops one letter earlier than the previous row.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern15(int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n - i; j++) {
            cout << (char)('A' + j) << " ";
        }
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern15 {
    public static void pattern15(int n) {
        for (int i = 0; i < n; i++) {
            StringBuilder row = new StringBuilder();
            for (int j = 0; j < n - i; j++) {
                row.append((char) ('A' + j)).append(' ');
            }
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern15(n: int) -> None:
    for length in range(n, 0, -1):
        print(" ".join(chr(ord("A") + j) for j in range(length)))
```

## Key Takeaways
- Inverting a triangle only changes the inner loop bound from `i + 1` to `n - i`.
- The printed value still depends on the column index `j`, so each row restarts at `A`.
- Check that the last row prints exactly one letter.
