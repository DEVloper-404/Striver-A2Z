# Network Delay Time

**Difficulty:** Medium  ·  **Topic:** Graphs [Concepts & Problems] › Shortest Path Algorithms and Problems

## Problem
You are given a network of `n` nodes labelled `1..n` and a list `times` where `[u, v, w]` means a signal travels from node `u` to node `v` in `w` units of time (one-way). A signal is sent from node `k`. Return the time it takes for **all** nodes to receive it, or `-1` if some node never does.

```
Input:  times = [[2,1,1], [2,3,1], [3,4,1]], n = 4, k = 2
Output: 2
```
Node 1 hears the signal at time 1, node 3 at time 1, and node 4 at time 2. The last arrival is at time 2.

## Approach 1: Bellman-Ford
Relax all `E` edges `n - 1` times; the distances converge to the shortest times, and the answer is their maximum. Simple to write and robust, but slower than necessary since every weight here is positive.

- **Time:** O(n · E)
- **Space:** O(n)

## Approach 2: Dijkstra from the source, then take the maximum (Optimal)

**Key observation — restating the question.** The signal spreads along every outgoing edge simultaneously, so each node first hears it at exactly the *shortest-path time* from `k` to that node. The moment the whole network is covered is therefore

```
answer = max over all nodes v of dist(k, v)
```

and `-1` when any `dist(k, v)` is infinite. Once phrased that way, this is a plain single-source shortest-path problem with non-negative weights — textbook Dijkstra.

**Algorithm.**
1. Build a weighted adjacency list. (Labels are 1-based; either size the arrays `n + 1` or subtract 1 everywhere — mixing the two is the classic bug in this problem.)
2. `dist[k] = 0`, everything else `∞`. Push `(0, k)` into a min-heap keyed by time.
3. Pop the smallest `(d, u)`. If `d > dist[u]` it is a stale leftover from a later improvement — skip. Otherwise, for each edge `u -> v` of weight `w`, if `d + w < dist[v]`, update `dist[v]` and push `(dist[v], v)`.
4. After the heap drains, scan `dist[1..n]`. If any entry is still `∞`, return `-1`; otherwise return the maximum.

**Why the maximum, not the sum.** Signals propagate in parallel, so the network is fully informed as soon as the *slowest* node has heard it. Summing the distances would answer a different question entirely.

**Dry run** on the example, `k = 2`:
- `dist = [_, ∞, 0, ∞, ∞]` (index 0 unused). Heap `{(0,2)}`.
- Pop `(0,2)`: relax `2→1` giving `dist[1] = 1` and `2→3` giving `dist[3] = 1`. Heap `{(1,1), (1,3)}`.
- Pop `(1,1)`: node 1 has no outgoing edges.
- Pop `(1,3)`: relax `3→4` giving `dist[4] = 2`. Heap `{(2,4)}`.
- Pop `(2,4)`: no outgoing edges. Heap empty.
- All of `dist[1..4] = 1, 0, 1, 2` are finite → answer `max = 2` ✓

If we changed `n` to 5 with no edge into node 5, `dist[5]` would stay infinite and we would return `-1` — that unreachable check is easy to forget.

- **Time:** O(E log n) — each edge pushes at most one heap entry
- **Space:** O(n + E) for the adjacency list and heap

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <queue>
#include <climits>
using namespace std;

class Solution {
public:
    int networkDelayTime(vector<vector<int>>& times, int n, int k) {
        vector<vector<pair<int,int>>> adj(n + 1);          // 1-based labels
        for (auto& t : times) adj[t[0]].push_back({t[1], t[2]});

        vector<int> dist(n + 1, INT_MAX);
        priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;  // {time, node}
        dist[k] = 0;
        pq.push({0, k});

        while (!pq.empty()) {
            auto [d, u] = pq.top(); pq.pop();
            if (d > dist[u]) continue;                     // stale entry
            for (auto& [v, w] : adj[u]) {
                if (d + w < dist[v]) {
                    dist[v] = d + w;
                    pq.push({dist[v], v});
                }
            }
        }

        int answer = 0;
        for (int i = 1; i <= n; i++) {
            if (dist[i] == INT_MAX) return -1;             // node never reached
            answer = max(answer, dist[i]);
        }
        return answer;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int networkDelayTime(int[][] times, int n, int k) {
        List<List<int[]>> adj = new ArrayList<>();
        for (int i = 0; i <= n; i++) adj.add(new ArrayList<>());
        for (int[] t : times) adj.get(t[0]).add(new int[]{t[1], t[2]});

        int[] dist = new int[n + 1];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[k] = 0;

        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        pq.add(new int[]{0, k});

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int d = cur[0], u = cur[1];
            if (d > dist[u]) continue;
            for (int[] e : adj.get(u)) {
                if (d + e[1] < dist[e[0]]) {
                    dist[e[0]] = d + e[1];
                    pq.add(new int[]{dist[e[0]], e[0]});
                }
            }
        }

        int answer = 0;
        for (int i = 1; i <= n; i++) {
            if (dist[i] == Integer.MAX_VALUE) return -1;
            answer = Math.max(answer, dist[i]);
        }
        return answer;
    }
}
```

### Python
```python
import heapq
from typing import List

class Solution:
    def networkDelayTime(self, times: List[List[int]], n: int, k: int) -> int:
        adj = [[] for _ in range(n + 1)]
        for u, v, w in times:
            adj[u].append((v, w))

        INF = float("inf")
        dist = [INF] * (n + 1)
        dist[k] = 0
        pq = [(0, k)]                       # (time, node)

        while pq:
            d, u = heapq.heappop(pq)
            if d > dist[u]:
                continue
            for v, w in adj[u]:
                if d + w < dist[v]:
                    dist[v] = d + w
                    heapq.heappush(pq, (dist[v], v))

        answer = max(dist[1:])
        return -1 if answer == INF else answer
```

## Key Takeaways
- "Time for everyone to receive a broadcast" = **maximum** of the single-source shortest distances, because propagation is parallel.
- Non-negative weights make Dijkstra the right tool; Bellman-Ford also works at O(n·E) if you prefer an edge-list formulation.
- Nodes are labelled `1..n` — size arrays `n + 1` and never scan index 0 into the maximum.
- Any node left at infinity means the network is not fully reachable from `k`, so return `-1`.
