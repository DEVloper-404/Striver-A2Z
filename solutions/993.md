# Sum of Beauty of All Substrings

**Difficulty:** Medium  ·  **Topic:** Strings [Basic and Medium] › Medium String Problems

## Problem
The beauty of a string is the difference between the highest and lowest frequency among the characters that appear in it. Given a lowercase string `s`, return the sum of the beauty of every substring.

Input: `s = "aabcb"`
Output: `5`  (the substrings with non-zero beauty are `"aab"`, `"aabc"`, `"aabcb"`, `"abcb"`, `"bcb"`, each with beauty 1)

Input: `s = "aabcbaa"`
Output: `17`

## Approach 1: Recount for every substring
Generate each substring, build its frequency table from scratch, compute `max - min` over non-zero counts, and add it. Cubic because each substring is re-scanned.
- **Time:** O(n^3)
- **Space:** O(1)

## Approach 2: Incremental frequency per start index (Optimal)
Fix the start index `i` and extend the end index `j` one step at a time. Maintain a 26-slot frequency array that is reset only when `i` changes. After adding `s[j]`, scan the 26 counts to find the max and the min among non-zero entries and add their difference.

Each substring costs O(26) instead of O(n), giving quadratic overall time. With `n ≤ 500` this is fast.
- **Time:** O(26 · n^2)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <string>
#include <climits>
using namespace std;

class Solution {
public:
    int beautySum(string s) {
        int n = s.size();
        int total = 0;
        for (int i = 0; i < n; ++i) {
            int cnt[26] = {0};
            for (int j = i; j < n; ++j) {
                cnt[s[j] - 'a']++;
                int mx = 0, mn = INT_MAX;
                for (int c = 0; c < 26; ++c) {
                    if (cnt[c] == 0) continue;
                    if (cnt[c] > mx) mx = cnt[c];
                    if (cnt[c] < mn) mn = cnt[c];
                }
                total += mx - mn;
            }
        }
        return total;
    }
};
```

### Java
```java
class Solution {
    public int beautySum(String s) {
        int n = s.length();
        int total = 0;
        for (int i = 0; i < n; i++) {
            int[] cnt = new int[26];
            for (int j = i; j < n; j++) {
                cnt[s.charAt(j) - 'a']++;
                int mx = 0, mn = Integer.MAX_VALUE;
                for (int c = 0; c < 26; c++) {
                    if (cnt[c] == 0) continue;
                    mx = Math.max(mx, cnt[c]);
                    mn = Math.min(mn, cnt[c]);
                }
                total += mx - mn;
            }
        }
        return total;
    }
}
```

### Python
```python
class Solution:
    def beautySum(self, s: str) -> int:
        n = len(s)
        total = 0
        for i in range(n):
            cnt = [0] * 26
            for j in range(i, n):
                cnt[ord(s[j]) - ord('a')] += 1
                present = [c for c in cnt if c > 0]
                total += max(present) - min(present)
        return total
```

## Key Takeaways
- Fix the start and grow the end so frequency tables are updated incrementally, not rebuilt.
- The alphabet is fixed (26), so the per-substring min/max scan is constant time.
- Only non-zero counts participate in the minimum.
- Substrings of length 1 or with all characters equal contribute 0.
