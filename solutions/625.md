# Add two numbers in Linked List

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
Two non-negative integers are given as singly linked lists where each node holds one digit and the digits are stored in **reverse** order (least significant digit first). Add the two numbers and return the sum as a linked list in the same reversed format. The lists may have different lengths and the sum may need one more digit than either input.

```
Input:  l1 = 2 -> 4 -> 3   (342)
        l2 = 5 -> 6 -> 4   (465)
Output: 7 -> 0 -> 8         (807)
```

## Approach 1: Convert to integers
Read each list into a number, add them, and build a new list from the digits of the sum. This overflows fixed-width integers for long lists, which is exactly the case the problem is designed for, so it is only acceptable when lengths are tiny.

- **Time:** O(m + n)
- **Space:** O(max(m, n)) for the output

## Approach 2: Digit-by-digit with carry (optimal)
Because the least significant digits are at the front, walk both lists simultaneously exactly as you would add on paper:

1. Keep a `carry`, initially 0, and a dummy head for the result.
2. While either list has nodes or carry is non-zero: `sum = carry + (digit of l1 or 0) + (digit of l2 or 0)`; append `sum % 10`; `carry = sum / 10`; advance whichever lists still have nodes.
3. Return `dummy.next`.

Including `carry != 0` in the loop condition creates the extra leading digit automatically.

- **Time:** O(max(m, n))
- **Space:** O(max(m, n)) for the result list; O(1) auxiliary

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode dummy(0);
        ListNode* tail = &dummy;
        int carry = 0;
        while (l1 || l2 || carry) {
            int sum = carry;
            if (l1) { sum += l1->val; l1 = l1->next; }
            if (l2) { sum += l2->val; l2 = l2->next; }
            tail->next = new ListNode(sum % 10);
            tail = tail->next;
            carry = sum / 10;
        }
        return dummy.next;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } }

class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0), tail = dummy;
        int carry = 0;
        while (l1 != null || l2 != null || carry != 0) {
            int sum = carry;
            if (l1 != null) { sum += l1.val; l1 = l1.next; }
            if (l2 != null) { sum += l2.val; l2 = l2.next; }
            tail.next = new ListNode(sum % 10);
            tail = tail.next;
            carry = sum / 10;
        }
        return dummy.next;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def addTwoNumbers(self, l1, l2):
        dummy = ListNode(0)
        tail = dummy
        carry = 0
        while l1 or l2 or carry:
            total = carry
            if l1:
                total += l1.val
                l1 = l1.next
            if l2:
                total += l2.val
                l2 = l2.next
            tail.next = ListNode(total % 10)
            tail = tail.next
            carry = total // 10
        return dummy.next
```

## Key Takeaways
- Reverse-order storage makes the addition a single forward walk; no reversal needed.
- Loop while any of `l1`, `l2`, or `carry` is non-empty so uneven lengths and a final carry are handled uniformly.
- Use a dummy head so the first node needs no special case.
- Never convert to a machine integer; the lists can be far longer than 64-bit precision.
