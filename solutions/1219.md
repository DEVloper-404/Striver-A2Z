# Theory with examples

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Things to Know in C++/Java/Python or any language

## Problem
This topic is time and space complexity: a way to describe how the running time and memory of an algorithm grow as the input size `n` grows, independent of the machine it runs on. You express the growth rate with Big-O notation, drop constants and lower-order terms, and use the result to predict whether a solution will pass a given constraint (roughly 10^8 simple operations per second).

Example: for the two snippets below, state the time complexity.

```
Input:
  A: for i in 0..n-1: print(i)
  B: for i in 0..n-1: for j in 0..n-1: print(i, j)
Output:
  A: O(n)
  B: O(n^2)
```

## Approach: Big-O in practice

**1. What Big-O measures.** Count the number of basic operations as a function of `n`, then keep only the fastest-growing term without its constant. `3n^2 + 5n + 100` becomes `O(n^2)`. Big-O is an upper bound on the worst case; Omega is a lower bound; Theta is a tight bound. In interviews "complexity" almost always means worst-case Big-O.

**2. Reading loops.**
- A single loop over `n` elements: `O(n)`.
- Two nested loops each over `n`: `O(n^2)`. If the inner loop runs `j = i..n`, the total is `n + (n-1) + ... + 1 = n(n+1)/2`, still `O(n^2)`.
- A loop where the variable doubles or halves each step (`i *= 2`, binary search): `O(log n)`.
- A loop over `n` with an `O(log n)` step inside (sorting, heap push): `O(n log n)`.
- Two sequential loops: `O(n) + O(n) = O(n)` — add sequential blocks, multiply nested ones.

**3. Recursion.** Count calls times work per call. `fib(n)` with two recursive calls and no memo is `O(2^n)`; with memoization each state is computed once, `O(n)`. Merge sort splits in half and merges in `O(n)`: `T(n) = 2T(n/2) + n`, which is `O(n log n)`.

**4. Space complexity.** Extra memory beyond the input: variables (`O(1)`), an auxiliary array of size `n` (`O(n)`), a 2D DP table (`O(n*m)`), and the recursion stack — depth `n` recursion uses `O(n)` stack even with no explicit arrays.

**5. Common growth rates, fastest to slowest.** `O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)`.

**6. Using constraints to pick an algorithm.** With about 10^8 operations per second:

| Max n | Feasible complexity |
|-------|---------------------|
| 10^18 | O(log n), O(1) |
| 10^8 | O(n) |
| 10^6 | O(n log n) |
| 10^4 | O(n^2) |
| 500 | O(n^3) |
| 20 | O(2^n) |

**7. Worked example.** "Check if an array has a duplicate": nested loops compare every pair, `O(n^2)` time and `O(1)` space; sorting then scanning neighbours is `O(n log n)` time; a hash set is `O(n)` time and `O(n)` space. Same problem, three points on the time/space trade-off curve.

- **Time:** analysis itself is O(1); the examples range from O(log n) to O(2^n)
- **Space:** from O(1) to O(n) depending on auxiliary structures and recursion depth

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

// O(n) time, O(1) space
long long sumArray(const vector<int>& a) {
    long long s = 0;
    for (int x : a) s += x;
    return s;
}

// O(n^2) time, O(1) space
bool hasDuplicateBrute(const vector<int>& a) {
    int n = a.size();
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            if (a[i] == a[j]) return true;
    return false;
}

// O(n) time, O(n) space
bool hasDuplicateHash(const vector<int>& a) {
    unordered_set<int> seen;
    for (int x : a) {
        if (seen.count(x)) return true;
        seen.insert(x);
    }
    return false;
}

// O(log n) time, O(1) space
int countBinaryDigits(long long n) {
    int c = 0;
    while (n > 0) { n /= 2; c++; }
    return c;
}

int main() {
    vector<int> a = {3, 1, 4, 1, 5};
    cout << sumArray(a) << '\n';               // 14
    cout << hasDuplicateBrute(a) << '\n';      // 1
    cout << hasDuplicateHash(a) << '\n';       // 1
    cout << countBinaryDigits(1000) << '\n';   // 10
    return 0;
}
```

### Java
```java
import java.util.HashSet;
import java.util.Set;

public class Main {
    // O(n) time, O(1) space
    static long sumArray(int[] a) {
        long s = 0;
        for (int x : a) s += x;
        return s;
    }

    // O(n^2) time, O(1) space
    static boolean hasDuplicateBrute(int[] a) {
        for (int i = 0; i < a.length; i++)
            for (int j = i + 1; j < a.length; j++)
                if (a[i] == a[j]) return true;
        return false;
    }

    // O(n) time, O(n) space
    static boolean hasDuplicateHash(int[] a) {
        Set<Integer> seen = new HashSet<>();
        for (int x : a) {
            if (!seen.add(x)) return true;
        }
        return false;
    }

    // O(log n) time, O(1) space
    static int countBinaryDigits(long n) {
        int c = 0;
        while (n > 0) { n /= 2; c++; }
        return c;
    }

    public static void main(String[] args) {
        int[] a = {3, 1, 4, 1, 5};
        System.out.println(sumArray(a));             // 14
        System.out.println(hasDuplicateBrute(a));    // true
        System.out.println(hasDuplicateHash(a));     // true
        System.out.println(countBinaryDigits(1000)); // 10
    }
}
```

### Python
```python
from typing import List


def sum_array(a: List[int]) -> int:          # O(n) time, O(1) space
    s = 0
    for x in a:
        s += x
    return s


def has_duplicate_brute(a: List[int]) -> bool:   # O(n^2) time, O(1) space
    n = len(a)
    for i in range(n):
        for j in range(i + 1, n):
            if a[i] == a[j]:
                return True
    return False


def has_duplicate_hash(a: List[int]) -> bool:    # O(n) time, O(n) space
    seen = set()
    for x in a:
        if x in seen:
            return True
        seen.add(x)
    return False


def count_binary_digits(n: int) -> int:      # O(log n) time, O(1) space
    c = 0
    while n > 0:
        n //= 2
        c += 1
    return c


if __name__ == "__main__":
    a = [3, 1, 4, 1, 5]
    print(sum_array(a))              # 14
    print(has_duplicate_brute(a))    # True
    print(has_duplicate_hash(a))     # True
    print(count_binary_digits(1000)) # 10
```

## Key Takeaways
- Big-O keeps only the dominant term and drops constants; report the worst case unless told otherwise.
- Nested loops multiply, sequential loops add, halving loops are logarithmic.
- Space complexity counts auxiliary memory including recursion depth, not the input itself.
- Read the constraints first: about 10^8 operations per second tells you which complexity class you must hit.
