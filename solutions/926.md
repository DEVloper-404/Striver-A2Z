# Fruit Into Baskets

**Difficulty:** Medium  ·  **Topic:** Sliding Window & Two Pointer Combined Problems › Medium Problems

## Problem
`fruits[i]` is the type of fruit on tree `i`. You have two baskets, each of which can hold unlimited fruit of a single type. Starting at any tree you pick one fruit from every tree moving right, and must stop when you meet a type that fits in neither basket. Return the maximum number of fruits you can collect. In other words: find the longest contiguous subarray with at most two distinct values.

Input: `fruits = [1,2,3,2,2]`
Output: `4` (trees 1..4 give `[2,3,2,2]`)

## Approach 1: Brute Force
For each start `i`, extend `j` while the set of types seen stays at size 2 or less. Record the longest run.

- **Time:** O(n²)
- **Space:** O(1) (set holds at most 3 entries)

## Approach 2: Sliding Window with Frequency Map (Optimal)
Maintain a window with a map `type -> count`. Expand `r` and add `fruits[r]`. While the map has more than two keys, remove `fruits[l]` from the map (deleting the key when its count hits zero) and advance `l`. After the shrink step the window is valid, so update the answer.

Because only 2 distinct types are allowed, the map never holds more than 3 entries, so all operations are constant time.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    int totalFruit(vector<int>& fruits) {
        unordered_map<int, int> cnt;
        int l = 0, best = 0;
        for (int r = 0; r < (int)fruits.size(); ++r) {
            cnt[fruits[r]]++;
            while (cnt.size() > 2) {
                if (--cnt[fruits[l]] == 0) cnt.erase(fruits[l]);
                l++;
            }
            best = max(best, r - l + 1);
        }
        return best;
    }
};
```

### Java
```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int totalFruit(int[] fruits) {
        Map<Integer, Integer> cnt = new HashMap<>();
        int l = 0, best = 0;
        for (int r = 0; r < fruits.length; r++) {
            cnt.merge(fruits[r], 1, Integer::sum);
            while (cnt.size() > 2) {
                int c = cnt.get(fruits[l]) - 1;
                if (c == 0) cnt.remove(fruits[l]);
                else cnt.put(fruits[l], c);
                l++;
            }
            best = Math.max(best, r - l + 1);
        }
        return best;
    }
}
```

### Python
```python
from typing import List
from collections import defaultdict

class Solution:
    def totalFruit(self, fruits: List[int]) -> int:
        cnt = defaultdict(int)
        l = 0
        best = 0
        for r, f in enumerate(fruits):
            cnt[f] += 1
            while len(cnt) > 2:
                cnt[fruits[l]] -= 1
                if cnt[fruits[l]] == 0:
                    del cnt[fruits[l]]
                l += 1
            best = max(best, r - l + 1)
        return best
```

## Key Takeaways
- This is "longest subarray with at most K distinct" with K fixed to 2.
- Delete map keys when their count drops to zero, otherwise `size()` overcounts distinct types.
- Edge cases: a single tree (answer 1), all same type (answer n).
