# Aggressive Cows

**Difficulty:** Hard  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on Answers

## Problem
You are given `n` stall positions along a line (`stalls[i]`) and `k` cows. Place all `k` cows in distinct stalls so that the minimum distance between any two cows is as large as possible. Return that largest possible minimum distance.

Input: stalls = [0, 3, 4, 7, 10, 9], k = 4
Output: 3  (place cows at 0, 3, 7, 10 → smallest gap is 3)

## Approach 1: Try Every Distance
Sort the stalls. The answer lies in `[1, max(stalls) - min(stalls)]`. For each candidate distance `d` starting from 1, greedily place cows: put the first cow in the first stall, then walk forward placing a cow whenever the current stall is at least `d` away from the last placed cow. If `k` cows fit, `d` is achievable. Since feasibility fails once `d` gets too large, return the last achievable `d`.
- **Time:** O(n log n + (max - min) * n)
- **Space:** O(1)

## Approach 2: Binary Search on Distance
If a minimum distance `d` is achievable, every smaller distance is too; if `d` is not achievable, nothing larger is. This monotone property means we can binary search `d` over `[1, max - min]` with the same greedy placement check:

1. Sort stalls.
2. For `mid`, greedily count how many cows can be placed with gap `>= mid`.
3. If at least `k` fit, record `mid` and search right (`lo = mid + 1`); else search left.
- **Time:** O(n log n + n * log(max - min))
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    bool canPlace(const vector<int>& stalls, int k, int dist) {
        int count = 1, last = stalls[0];
        for (size_t i = 1; i < stalls.size(); i++) {
            if (stalls[i] - last >= dist) {
                count++;
                last = stalls[i];
                if (count >= k) return true;
            }
        }
        return false;
    }

    int aggressiveCows(vector<int>& stalls, int k) {
        sort(stalls.begin(), stalls.end());
        int lo = 1, hi = stalls.back() - stalls.front();
        int ans = 0;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (canPlace(stalls, k, mid)) {
                ans = mid;
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return ans;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def aggressiveCows(self, stalls: List[int], k: int) -> int:
        stalls.sort()

        def can_place(dist: int) -> bool:
            count, last = 1, stalls[0]
            for pos in stalls[1:]:
                if pos - last >= dist:
                    count += 1
                    last = pos
                    if count >= k:
                        return True
            return False

        lo, hi = 1, stalls[-1] - stalls[0]
        ans = 0
        while lo <= hi:
            mid = (lo + hi) // 2
            if can_place(mid):
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1
        return ans
```

## Key Takeaways
- This is a "maximise the minimum" problem: feasible values form a prefix, so move *right* when feasible (opposite of Koko / Book Allocation).
- Sorting is mandatory; the greedy "place as early as possible" check is optimal for a fixed distance.
- Search range is `[1, max - min]`; with `k = 2` the answer is exactly `max - min`.
