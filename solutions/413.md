# Pattern 20

**Difficulty:** Medium  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a butterfly of stars with `2n - 1` rows. Each row has the same number of stars on the left and right with spaces between; the star count grows from 1 to `n` (the solid middle row) and then shrinks back to 1.

Input: `n = 5`
Output:
```
*        *
**      **
***    ***
****  ****
**********
****  ****
***    ***
**      **
*        *
```

## Approach
Pattern 20 is Pattern 19 flipped vertically, and because the widest row is shared by both halves, a single loop with one formula suffices.

1. Loop `i` from `1` to `2n - 1`.
2. Stars per side: `i` while `i <= n`, otherwise `2n - i` (rises then falls, exactly like Pattern 10).
3. Spaces in the middle: `2 * (n - stars)`, so every row is `2n` characters wide.
4. Print `stars` stars, the spaces, then `stars` stars again, followed by a newline.

At `i = n` there are zero middle spaces, which produces the solid row.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern20(int n) {
    for (int i = 1; i <= 2 * n - 1; i++) {
        int stars = (i <= n) ? i : 2 * n - i;
        int spaces = 2 * (n - stars);
        for (int j = 0; j < stars; j++) cout << "*";
        for (int j = 0; j < spaces; j++) cout << " ";
        for (int j = 0; j < stars; j++) cout << "*";
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern20 {
    public static void pattern20(int n) {
        for (int i = 1; i <= 2 * n - 1; i++) {
            int stars = (i <= n) ? i : 2 * n - i;
            int spaces = 2 * (n - stars);
            StringBuilder row = new StringBuilder();
            for (int j = 0; j < stars; j++) row.append('*');
            for (int j = 0; j < spaces; j++) row.append(' ');
            for (int j = 0; j < stars; j++) row.append('*');
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern20(n: int) -> None:
    for i in range(1, 2 * n):
        stars = i if i <= n else 2 * n - i
        spaces = 2 * (n - stars)
        print("*" * stars + " " * spaces + "*" * stars)
```

## Key Takeaways
- Rise-then-fall counts collapse to one formula: `i` up to the peak, `2n - i` after it.
- Derive the space count from the star count (`2(n - stars)`) instead of tracking it separately, so the two can never drift apart.
- `2n - 1` rows because the middle row is shared; compare with Pattern 19's `2n` rows.
