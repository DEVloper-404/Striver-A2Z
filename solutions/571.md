# Check if an array represents a min heap

**Difficulty:** Medium  ·  **Topic:** Heaps [Learning, Medium, Hard Problems] › Learning

## Problem
Given an integer array `arr` of size `n`, determine whether it is a valid min heap when interpreted as a level-order (array) representation of a complete binary tree: for every index `i`, `arr[i]` must be less than or equal to both of its children at `2i + 1` and `2i + 2` (when they exist). Return `true` or `false`.

Input: `arr = [10, 20, 30, 21, 23]`
Output: `true`

Input: `arr = [10, 20, 30, 25, 15]`
Output: `false` (`arr[1] = 20` has child `arr[4] = 15`)

## Approach 1: Check Every Node Against Its Parent
Walk indices `1..n-1`. For each `i`, its parent is `(i - 1) / 2`; if `arr[parent] > arr[i]` the heap property is violated. This checks each edge exactly once.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Check Only Internal Nodes (Optimal)
Only indices `0..n/2 - 1` have children; leaves cannot violate anything. For each such `i`, compare with the left child `2i + 1` and, if it exists, the right child `2i + 2`. This halves the loop range and reads naturally as "every parent is at most its children".

Both approaches are linear; this one just visits fewer indices. A recursive version that validates a subtree and recurses on both children is equivalent but uses O(log n) stack.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    bool isHeap(vector<int>& arr) {
        int n = arr.size();
        for (int i = 0; i < n / 2; ++i) {
            int l = 2 * i + 1, r = 2 * i + 2;
            if (l < n && arr[l] < arr[i]) return false;
            if (r < n && arr[r] < arr[i]) return false;
        }
        return true;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def isHeap(self, arr: List[int]) -> bool:
        n = len(arr)
        for i in range(n // 2):
            l, r = 2 * i + 1, 2 * i + 2
            if l < n and arr[l] < arr[i]:
                return False
            if r < n and arr[r] < arr[i]:
                return False
        return True
```

## Key Takeaways
- An array always represents a *complete* tree, so only the ordering property needs checking, never the shape.
- Indices `>= n/2` are leaves; stopping there avoids pointless bound checks.
- Equal values are allowed (`<=`), so only a strictly smaller child is a violation; flip the comparison to check for a max heap.
- Empty or single-element arrays are trivially heaps.
