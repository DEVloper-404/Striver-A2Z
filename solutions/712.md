# Merge Intervals

**Difficulty:** Medium  ·  **Topic:** Greedy Algorithms [Easy, Medium/Hard] › Medium/Hard

## Problem
Given an array of intervals `intervals[i] = [start, end]`, merge every pair of overlapping intervals and return a list of non-overlapping intervals that together cover exactly the same points. Intervals that touch at an endpoint (e.g. `[1,4]` and `[4,5]`) are considered overlapping.

Input: `intervals = [[1,3],[2,6],[8,10],[15,18]]`
Output: `[[1,6],[8,10],[15,18]]`

## Approach 1: Brute Force
Sort the intervals. For each interval not yet absorbed, scan forward through later intervals and keep extending the current end while the next interval's start is within it; mark absorbed intervals. Because you may rescan intervals, this degrades to quadratic time.
- **Time:** O(n log n + n²)
- **Space:** O(n)

## Approach 2: Sort and single pass (Optimal)
After sorting by start, any interval that overlaps the current merged block must be the very next one (its start is ≥ the block's start, and if it starts after the block ends, so does everything after it).

1. Sort by start.
2. Keep the result list; push the first interval.
3. For every next interval, if `start <= result.back().end`, extend `result.back().end = max(end, result.back().end)`; otherwise push it as a new block.

- **Time:** O(n log n)
- **Space:** O(n) for the output (O(1) extra if you merge in place)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        vector<vector<int>> res;
        if (intervals.empty()) return res;
        sort(intervals.begin(), intervals.end());
        res.push_back(intervals[0]);
        for (int i = 1; i < (int)intervals.size(); i++) {
            if (intervals[i][0] <= res.back()[1]) {
                res.back()[1] = max(res.back()[1], intervals[i][1]);
            } else {
                res.push_back(intervals[i]);
            }
        }
        return res;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int[][] merge(int[][] intervals) {
        if (intervals.length == 0) return new int[0][];
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
        List<int[]> res = new ArrayList<>();
        res.add(intervals[0]);
        for (int i = 1; i < intervals.length; i++) {
            int[] last = res.get(res.size() - 1);
            if (intervals[i][0] <= last[1]) {
                last[1] = Math.max(last[1], intervals[i][1]);
            } else {
                res.add(intervals[i]);
            }
        }
        return res.toArray(new int[res.size()][]);
    }
}
```

### Python
```python
from typing import List

class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        if not intervals:
            return []
        intervals.sort(key=lambda x: x[0])
        res = [intervals[0][:]]
        for s, e in intervals[1:]:
            if s <= res[-1][1]:
                res[-1][1] = max(res[-1][1], e)
            else:
                res.append([s, e])
        return res
```

## Key Takeaways
- Sorting by start turns overlap detection into a comparison with only the last merged interval.
- Use `max` when extending: a later interval can be fully inside the current block (`[1,10]` then `[2,3]`).
- The `<=` comparison merges touching intervals; change it to `<` if the problem treats touching as separate.
