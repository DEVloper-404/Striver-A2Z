# STL

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Learn STL/Java-Collections or similar thing in your language

## Problem
This is a theory item, not a coding problem. It covers the C++ Standard Template Library (STL): the ready-made containers, iterators and algorithms that let you write `vector<int>`, `sort(...)`, `map<string,int>` instead of hand-rolling arrays, sorting routines and hash tables. Knowing which container to reach for, and what each operation costs, is the foundation for every later problem in the sheet.

Input: none. Output: a working mental model of the four STL pillars — containers, iterators, algorithms, and functors — plus the handful of containers you will use in 95% of interview code.

## Approach
STL is organised into four parts. You only need to be fluent in the first three.

**1. Sequence containers (ordered by position)**

| Container | When to use | Typical cost |
|-----------|-------------|--------------|
| `vector<T>` | Default dynamic array | push_back amortised O(1), index O(1), insert in middle O(n) |
| `deque<T>` | Push/pop at both ends | O(1) both ends, O(1) index |
| `list<T>` | Many middle insertions with an iterator in hand | O(1) insert/erase, no random access |
| `array<T,N>` | Fixed size known at compile time | Same as a raw array, but with `.size()` |

```cpp
vector<int> v = {3, 1, 2};
v.push_back(7);            // {3,1,2,7}
v.pop_back();              // {3,1,2}
v.insert(v.begin() + 1, 9);// {3,9,1,2}
v.erase(v.begin());        // {9,1,2}
cout << v.size() << ' ' << v.front() << ' ' << v.back();
```

**2. Container adapters (restricted interfaces on top of a sequence)**

- `stack<T>` — LIFO: `push`, `pop`, `top`.
- `queue<T>` — FIFO: `push`, `pop`, `front`, `back`.
- `priority_queue<T>` — max-heap by default; `priority_queue<int, vector<int>, greater<int>>` gives a min-heap. `push`/`pop` are O(log n), `top` is O(1).

```cpp
priority_queue<int, vector<int>, greater<int>> pq; // min-heap
pq.push(5); pq.push(1); pq.push(3);
cout << pq.top(); // 1
```

**3. Associative containers (ordered by key, implemented as balanced BSTs)**

- `set<T>` / `multiset<T>` — sorted unique / non-unique keys. `insert`, `erase`, `find`, `lower_bound`, `upper_bound` are all O(log n).
- `map<K,V>` / `multimap<K,V>` — sorted key → value. `m[key]` inserts a default value if missing, so use `m.find(key)` or `m.count(key)` when you only want to test membership.

**4. Unordered containers (hash tables)**

- `unordered_set<T>`, `unordered_map<K,V>` — average O(1) insert/find/erase, worst case O(n) if many collisions. No ordering, so no `lower_bound`. Prefer these when you only need membership or counting.

```cpp
unordered_map<string, int> freq;
for (string& w : words) freq[w]++;
for (auto& [word, count] : freq) cout << word << ": " << count << '\n';
```

**5. Iterators and the algorithms header**

Every container exposes `begin()`/`end()`. Algorithms take iterator ranges, which is why they work on any container.

```cpp
sort(v.begin(), v.end());                       // ascending, O(n log n)
sort(v.begin(), v.end(), greater<int>());       // descending
reverse(v.begin(), v.end());
int mx = *max_element(v.begin(), v.end());
long long total = accumulate(v.begin(), v.end(), 0LL);
auto it = lower_bound(v.begin(), v.end(), x);   // first element >= x (sorted input)
int idx = it - v.begin();
bool found = binary_search(v.begin(), v.end(), x);
int c = count(v.begin(), v.end(), x);
v.erase(unique(v.begin(), v.end()), v.end());   // dedupe a sorted vector
```

Also worth memorising: `pair<int,int>` with `first`/`second`, `make_pair`, structured bindings `auto [a, b] = p;`, `__builtin_popcount(x)`, `to_string`, `stoi`, and `nth_element` for a linear-time k-th smallest.

- **Time:** depends on container — see the table above; the important defaults are `vector` O(1) amortised push, `map`/`set` O(log n), `unordered_*` O(1) average, `sort` O(n log n).
- **Space:** O(n) for any container holding n elements.

## Code (Optimal)

A small program that exercises the containers you will use most often.

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> v = {5, 3, 8, 1, 3};
    sort(v.begin(), v.end());                          // 1 3 3 5 8
    v.erase(unique(v.begin(), v.end()), v.end());      // 1 3 5 8

    map<int, int> freq;                                // ordered counting
    for (int x : {5, 3, 8, 1, 3}) freq[x]++;

    unordered_set<int> seen(v.begin(), v.end());       // O(1) membership
    bool has5 = seen.count(5) > 0;

    priority_queue<int, vector<int>, greater<int>> minHeap(v.begin(), v.end());
    int smallest = minHeap.top();

    stack<char> st; st.push('('); st.pop();
    queue<int> q;   q.push(1); q.push(2); q.pop();

    int pos = lower_bound(v.begin(), v.end(), 4) - v.begin(); // index of first >= 4 -> 2

    cout << has5 << ' ' << smallest << ' ' << pos << ' ' << freq[3] << '\n'; // 1 1 2 2
    return 0;
}
```

### Java
```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        // Java equivalents of the same STL pieces
        List<Integer> v = new ArrayList<>(List.of(5, 3, 8, 1, 3));
        Collections.sort(v);                               // 1 3 3 5 8
        v = new ArrayList<>(new LinkedHashSet<>(v));       // 1 3 5 8

        Map<Integer, Integer> freq = new TreeMap<>();      // ordered counting
        for (int x : new int[]{5, 3, 8, 1, 3}) freq.merge(x, 1, Integer::sum);

        Set<Integer> seen = new HashSet<>(v);
        boolean has5 = seen.contains(5);

        PriorityQueue<Integer> minHeap = new PriorityQueue<>(v);
        int smallest = minHeap.peek();

        Deque<Character> st = new ArrayDeque<>(); st.push('('); st.pop();
        Queue<Integer> q = new ArrayDeque<>();   q.add(1); q.add(2); q.poll();

        int pos = Collections.binarySearch(v, 4);          // negative -> insertion point
        if (pos < 0) pos = -pos - 1;                       // 2

        System.out.println(has5 + " " + smallest + " " + pos + " " + freq.get(3)); // true 1 2 2
    }
}
```

### Python
```python
import bisect
import heapq
from collections import Counter, deque

def main():
    v = sorted([5, 3, 8, 1, 3])          # [1, 3, 3, 5, 8]
    v = sorted(set(v))                   # [1, 3, 5, 8]

    freq = Counter([5, 3, 8, 1, 3])      # hash-based counting

    seen = set(v)
    has5 = 5 in seen

    heap = list(v)
    heapq.heapify(heap)                  # min-heap
    smallest = heap[0]

    st = []; st.append('('); st.pop()    # list as a stack
    q = deque([1, 2]); q.popleft()       # deque as a queue

    pos = bisect.bisect_left(v, 4)       # 2

    print(has5, smallest, pos, freq[3])  # True 1 2 2

if __name__ == "__main__":
    main()
```

## Key Takeaways
- Default to `vector`; switch to `deque` for two-ended access, `map`/`set` when you need sorted order or `lower_bound`, `unordered_map`/`unordered_set` when you only need O(1) lookup.
- `map[key]` silently inserts a default entry — use `find`/`count` for pure lookups to avoid bloating the map.
- `priority_queue` is a max-heap by default; pass `greater<T>` for a min-heap.
- Algorithms operate on iterator ranges (`begin()`, `end()`), so `sort`, `reverse`, `lower_bound` and friends work the same on any random-access container.
