# Celebrity Problem

**Difficulty:** Hard  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Implementation Problems

## Problem
At a party of `n` people (labelled `0..n-1`), a *celebrity* is someone whom everyone else knows but who knows nobody. You are given an `n × n` matrix `M` where `M[i][j] == 1` means person `i` knows person `j` (the diagonal is ignored). Return the celebrity's label, or `-1` if there is none. On LeetCode the matrix is hidden behind a `knows(a, b)` function, but the algorithm is identical.

```
Input:  M = [[0, 1, 0],
             [0, 0, 0],
             [0, 1, 0]]
Output: 1
```
Persons 0 and 2 know person 1; person 1 knows nobody.

## Approach 1: Brute Force
For each candidate `c`, check that column `c` is all ones (except the diagonal) and row `c` is all zeros.
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Stack Elimination
Push everyone on a stack. Pop two people `a`, `b`; if `a` knows `b`, `a` cannot be the celebrity, so push `b` back, otherwise push `a` back. When one person remains, verify them with a full row/column check.
- **Time:** O(n)
- **Space:** O(n)

## Approach 3: Two-Pointer Elimination (Optimal)
Every comparison `knows(a, b)` rules out exactly one person: if `a` knows `b`, `a` is out; otherwise `b` is out (nobody-knows-`b` contradicts celebrity-ness). So walk `top = 0`, `bottom = n-1`, discard one per step until they meet. Then validate the survivor with one pass over their row and column, because elimination proves uniqueness but not existence.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int celebrity(vector<vector<int>>& M) {
        int n = M.size();
        if (n == 0) return -1;
        int top = 0, bottom = n - 1;
        while (top < bottom) {
            if (M[top][bottom] == 1) ++top;      // top knows bottom -> top is out
            else --bottom;                       // top doesn't know bottom -> bottom is out
        }
        int c = top;
        for (int i = 0; i < n; ++i) {
            if (i == c) continue;
            if (M[c][i] == 1 || M[i][c] == 0) return -1;
        }
        return c;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def celebrity(self, M: List[List[int]]) -> int:
        n = len(M)
        if n == 0:
            return -1
        top, bottom = 0, n - 1
        while top < bottom:
            if M[top][bottom] == 1:
                top += 1
            else:
                bottom -= 1
        c = top
        for i in range(n):
            if i == c:
                continue
            if M[c][i] == 1 or M[i][c] == 0:
                return -1
        return c
```

## Key Takeaways
- One `knows` query always eliminates one person, so `n - 1` queries leave a single candidate.
- The candidate must still be verified — elimination only guarantees "if a celebrity exists, it is this one".
- With the `knows(a, b)` API, the same code uses `knows(top, bottom)` and `knows(c, i) || !knows(i, c)`.
