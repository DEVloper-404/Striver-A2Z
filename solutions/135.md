# Postorder Traversal

**Difficulty:** Easy  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Traversals

## Problem
Given the root of a binary tree, return the values of its nodes in postorder: for every node, output everything in its left subtree, then everything in its right subtree, and only then the node itself. The root is always the last value.

Input: `root = [1, null, 2, 3]`
```
  1
   \
    2
   /
  3
```
Output: `[3, 2, 1]`

## Approach 1: Recursion
Write the definition as code: if the node is null return; recurse left, recurse right, then record the node. "Left, Right, Root". Because a node is recorded only after both children finish, postorder is the natural order for anything that needs children solved before the parent (heights, deleting a tree, evaluating expression trees).
- **Time:** O(n)
- **Space:** O(h) recursion stack

## Approach 2: Iterative with two stacks
Notice that reversing postorder (Left, Right, Root) gives Root, Right, Left, which is just preorder with the children swapped. So run a modified preorder on stack 1, pushing **left** before **right** so that right pops first, and push every popped node onto stack 2. Popping stack 2 at the end gives postorder. Simple and easy to remember.
- **Time:** O(n)
- **Space:** O(n) for the second stack (it eventually holds every node)

## Approach 3: Iterative with one stack (optimal space)
Use a `curr` pointer and a stack. Push nodes while walking left. When `curr` is null, peek at the top node `t`. If `t` has a right child that has not been processed yet (its right child is not the node we just finished, tracked by a `lastVisited` pointer), move `curr` into that right child. Otherwise record `t`, pop it and remember it as `lastVisited`. Every node is pushed once and popped once, and the stack never exceeds the height of the tree.
- **Time:** O(n)
- **Space:** O(h) for the stack

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stack>
using namespace std;

// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition

class Solution {
public:
    vector<int> postorderTraversal(TreeNode* root) {
        vector<int> res;
        stack<TreeNode*> st;
        TreeNode* curr = root;
        TreeNode* lastVisited = nullptr;
        while (curr || !st.empty()) {
            if (curr) {
                st.push(curr);
                curr = curr->left;
            } else {
                TreeNode* top = st.top();
                if (top->right && top->right != lastVisited) {
                    curr = top->right;           // right subtree still pending
                } else {
                    res.push_back(top->val);     // both subtrees done
                    lastVisited = top;
                    st.pop();
                }
            }
        }
        return res;
    }
};
```

### Java
```java
import java.util.*;

// class TreeNode { int val; TreeNode left, right; ... } — standard definition

class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        Deque<TreeNode> st = new ArrayDeque<>();
        TreeNode curr = root, lastVisited = null;
        while (curr != null || !st.isEmpty()) {
            if (curr != null) {
                st.push(curr);
                curr = curr.left;
            } else {
                TreeNode top = st.peek();
                if (top.right != null && top.right != lastVisited) {
                    curr = top.right;            // right subtree still pending
                } else {
                    res.add(top.val);            // both subtrees done
                    lastVisited = top;
                    st.pop();
                }
            }
        }
        return res;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def postorderTraversal(self, root):
        res = []
        stack = []
        curr, last_visited = root, None
        while curr or stack:
            if curr:
                stack.append(curr)
                curr = curr.left
            else:
                top = stack[-1]
                if top.right and top.right is not last_visited:
                    curr = top.right             # right subtree still pending
                else:
                    res.append(top.val)          # both subtrees done
                    last_visited = stack.pop()
        return res
```

## Key Takeaways
- Postorder = Left, Right, Root; the root comes out last, which is why it suits "compute children first" problems.
- The two-stack trick works because reversed postorder is a preorder with swapped children.
- The one-stack version needs a `lastVisited` marker to tell whether a node's right subtree has already been emitted; without it you loop forever.
- Recursion is fine for shallow trees but the iterative forms are needed when the tree can be deep and skewed.
