# Longest Substring With At Most K Distinct Characters

**Difficulty:** Hard  ·  **Topic:** Sliding Window & Two Pointer Combined Problems › Hard Problems

## Problem
Given a string `s` and an integer `k`, return the length of the longest substring that contains at most `k` distinct characters.

Input: `s = "eceba", k = 2`
Output: `3` (`"ece"`)

Input: `s = "aa", k = 1`
Output: `2`

## Approach 1: Brute Force
For every start index, extend right while adding characters to a set; stop when the set size exceeds `k`. Track the best length.

- **Time:** O(n²)
- **Space:** O(k)

## Approach 2: Sliding Window with Frequency Map (Optimal)
Keep a map of character counts for the window `[l, r]`.

1. Add `s[r]` to the map.
2. While the map has more than `k` keys, decrement `s[l]`, erase it when the count hits 0, and advance `l`.
3. Update the answer with `r - l + 1`.

Each character enters and leaves the window at most once. Since the map holds at most `k + 1` keys, `size()` checks are cheap. For ASCII input a 256-slot array plus a `distinct` counter avoids hashing entirely.

- **Time:** O(n)
- **Space:** O(k)

## Code (Optimal)

### C++
```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    int lengthOfLongestSubstringKDistinct(string s, int k) {
        if (k == 0) return 0;
        int freq[256] = {0};
        int distinct = 0, l = 0, best = 0;
        for (int r = 0; r < (int)s.size(); ++r) {
            if (freq[(unsigned char)s[r]]++ == 0) distinct++;
            while (distinct > k) {
                if (--freq[(unsigned char)s[l]] == 0) distinct--;
                l++;
            }
            best = max(best, r - l + 1);
        }
        return best;
    }
};
```

class Solution {
    public int lengthOfLongestSubstringKDistinct(String s, int k) {

### Python
```python
from collections import defaultdict

class Solution:
    def lengthOfLongestSubstringKDistinct(self, s: str, k: int) -> int:
        if k == 0:
            return 0
        cnt = defaultdict(int)
        l = 0
        best = 0
        for r, ch in enumerate(s):
            cnt[ch] += 1
            while len(cnt) > k:
                cnt[s[l]] -= 1
                if cnt[s[l]] == 0:
                    del cnt[s[l]]
                l += 1
            best = max(best, r - l + 1)
        return best
```

## Key Takeaways
- Generalisation of Fruit Into Baskets (`k = 2`); the window invariant is "distinct count <= k".
- Maintain the distinct count incrementally by watching transitions 0 -> 1 and 1 -> 0.
- Edge cases: `k = 0` (answer 0), `k >= number of distinct letters` (answer n).
