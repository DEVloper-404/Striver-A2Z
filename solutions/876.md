# Generate Parentheses

**Difficulty:** Medium  ·  **Topic:** Recursion [PatternWise] › Subsequences Pattern

## Problem
Given `n` pairs of parentheses, generate every string of length `2n` that is a well-formed (balanced) sequence of `(` and `)`. Any order of the output is accepted.

Input: `n = 3`
Output: `["((()))", "(()())", "(())()", "()(())", "()()()"]`

Input: `n = 1`
Output: `["()"]`

## Approach 1: Generate all strings, keep the balanced ones
Recursively build every string of length `2n` over `{'(', ')'}` and validate each with a counter (increment on `(`, decrement on `)`, never negative, zero at the end). It works, but `2^(2n)` strings are produced while only the Catalan number `C(n)` of them are valid.
- **Time:** O(2^(2n) · n)
- **Space:** O(n) recursion depth

## Approach 2: Backtracking with open/close counters
Track how many `(` and `)` have been placed. A prefix can only be extended to a valid string if it obeys two rules:

1. Place `(` only if `open < n` (we still have opens left).
2. Place `)` only if `close < open` (there is an unmatched `(` to close).

When the string reaches length `2n`, it is guaranteed balanced, so record it. Every branch of the recursion leads to at least one valid answer, so the tree is never wasted.
- **Time:** O(C(n) · n) where C(n) is the n-th Catalan number (~4^n / n^1.5)
- **Space:** O(n) recursion depth (excluding output)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
    void gen(int n, int open, int close, string& cur, vector<string>& out) {
        if ((int)cur.size() == 2 * n) {
            out.push_back(cur);
            return;
        }
        if (open < n) {
            cur.push_back('(');
            gen(n, open + 1, close, cur, out);
            cur.pop_back();
        }
        if (close < open) {
            cur.push_back(')');
            gen(n, open, close + 1, cur, out);
            cur.pop_back();
        }
    }
public:
    vector<string> generateParenthesis(int n) {
        vector<string> out;
        string cur;
        gen(n, 0, 0, cur, out);
        return out;
    }
};
```

### Java
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    private void gen(int n, int open, int close, StringBuilder cur, List<String> out) {
        if (cur.length() == 2 * n) {
            out.add(cur.toString());
            return;
        }
        if (open < n) {
            cur.append('(');
            gen(n, open + 1, close, cur, out);
            cur.deleteCharAt(cur.length() - 1);
        }
        if (close < open) {
            cur.append(')');
            gen(n, open, close + 1, cur, out);
            cur.deleteCharAt(cur.length() - 1);
        }
    }

    public List<String> generateParenthesis(int n) {
        List<String> out = new ArrayList<>();
        gen(n, 0, 0, new StringBuilder(), out);
        return out;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        out: List[str] = []

        def gen(open_cnt: int, close_cnt: int, cur: List[str]) -> None:
            if len(cur) == 2 * n:
                out.append("".join(cur))
                return
            if open_cnt < n:
                cur.append('(')
                gen(open_cnt + 1, close_cnt, cur)
                cur.pop()
            if close_cnt < open_cnt:
                cur.append(')')
                gen(open_cnt, close_cnt + 1, cur)
                cur.pop()

        gen(0, 0, [])
        return out
```

## Key Takeaways
- Two counters and two guards (`open < n`, `close < open`) are all it takes to prune every invalid branch.
- Because no invalid prefix is ever extended, no final validation is needed.
- The output size is the Catalan number, so any solution is at least exponential; the goal is to do no wasted work.
- Push then pop (backtrack) on a shared buffer to avoid copying strings at every level.
