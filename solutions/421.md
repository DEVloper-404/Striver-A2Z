# Pattern 8

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print an inverted centered pyramid with `n` rows. The top row has `2n - 1` stars and every following row loses one star from each side, ending with a single centered star.

Input: `n = 5`
Output:
```
*********
 *******
  *****
   ***
    *
```

## Approach
This is Pattern 7 flipped: the padding grows while the star count shrinks.

1. Outer loop `i` from `0` to `n-1`.
2. Print `i` leading spaces.
3. Print `2(n - i) - 1` stars.
4. Newline.

At `i = 0` there are no spaces and `2n-1` stars; at `i = n-1` there are `n-1` spaces and exactly 1 star.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern8(int n) {
    for (int i = 0; i < n; i++) {
        for (int s = 0; s < i; s++) cout << " ";
        for (int j = 0; j < 2 * (n - i) - 1; j++) cout << "*";
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern8 {
    public static void pattern8(int n) {
        for (int i = 0; i < n; i++) {
            StringBuilder row = new StringBuilder();
            for (int s = 0; s < i; s++) row.append(' ');
            for (int j = 0; j < 2 * (n - i) - 1; j++) row.append('*');
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern8(n: int) -> None:
    for i in range(n):
        print(" " * i + "*" * (2 * (n - i) - 1))
```

## Key Takeaways
- Flipping a centered pattern means swapping which quantity grows and which shrinks.
- `2(n - i) - 1` is just the Pattern 7 formula with the row index reversed.
- Get the first and last rows right and the middle follows automatically.
