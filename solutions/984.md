# Reverse every word in a string

**Difficulty:** Medium  ·  **Topic:** Strings [Basic and Medium] › Medium String Problems

## Problem
Given a sentence that may contain leading, trailing, or multiple consecutive spaces, return the words in reverse order, separated by exactly one space and with no surrounding whitespace. Words themselves are not reversed, only their order.

Input: `s = "the sky is blue"`
Output: `"blue is sky the"`

Input: `s = "  hello   world  "`
Output: `"world hello"`

## Approach 1: Tokenize and reverse
Split the string on whitespace into a list of non-empty tokens, reverse the list, and join with a single space. This is the clearest solution and is what most people write first.
- **Time:** O(n)
- **Space:** O(n) for the token list

## Approach 2: Reverse whole, then reverse each word (In-place style)
Work on a mutable character array:
1. Reverse the entire array. Now the words are in the right order but each word is backwards.
2. Walk the array and reverse each individual word back.
3. Compact the array by copying words forward with single-space separators, then trim to the new length.

This uses O(1) extra space beyond the output buffer and is the version interviewers ask for when they say "in place".
- **Time:** O(n)
- **Space:** O(1) extra

## Approach 3: Right-to-left scan (Optimal, simplest O(1)-extra)
Scan from the end of the string. Skip spaces, find the boundaries of one word, append it to the output (with a separator if needed), and continue. Words are naturally emitted in reverse order with a single pass and no intermediate list.
- **Time:** O(n)
- **Space:** O(n) for the output only

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Solution {
public:
    string reverseWords(string s) {
        string out;
        int i = (int)s.size() - 1;
        while (i >= 0) {
            while (i >= 0 && s[i] == ' ') i--;   // skip spaces
            if (i < 0) break;
            int end = i;
            while (i >= 0 && s[i] != ' ') i--;   // find word start
            if (!out.empty()) out.push_back(' ');
            out.append(s, i + 1, end - i);
        }
        return out;
    }
};
```

### Java
```java
class Solution {
    public String reverseWords(String s) {
        StringBuilder out = new StringBuilder();
        int i = s.length() - 1;
        while (i >= 0) {
            while (i >= 0 && s.charAt(i) == ' ') i--;   // skip spaces
            if (i < 0) break;
            int end = i;
            while (i >= 0 && s.charAt(i) != ' ') i--;   // find word start
            if (out.length() > 0) out.append(' ');
            out.append(s, i + 1, end + 1);
        }
        return out.toString();
    }
}
```

### Python
```python
class Solution:
    def reverseWords(self, s: str) -> str:
        out = []
        i = len(s) - 1
        while i >= 0:
            while i >= 0 and s[i] == ' ':
                i -= 1
            if i < 0:
                break
            end = i
            while i >= 0 and s[i] != ' ':
                i -= 1
            out.append(s[i + 1:end + 1])
        return " ".join(out)
```

## Key Takeaways
- Reverse the order of words by scanning from the right; no need to store all tokens.
- Normalise whitespace by skipping runs of spaces and adding exactly one separator between words.
- The "reverse whole, then reverse each word" trick is the in-place answer when the input is a mutable buffer.
- Edge cases: empty string, only spaces, single word with padding.
