# Shortest path in DAG

**Difficulty:** Hard  ·  **Topic:** Graphs [Concepts & Problems] › Shortest Path Algorithms and Problems

## Problem
Given a weighted **Directed Acyclic Graph** with `N` vertices and `M` edges (each edge given as `[u, v, w]` meaning `u -> v` with weight `w`), find the shortest distance from vertex `0` to every other vertex. If a vertex is unreachable, report `-1`. Edge weights may even be negative — acyclicity means no negative cycle can exist.

```
Input:  N = 6, edges = [[0,1,2], [0,4,1], [4,5,4], [4,2,2], [1,2,3], [2,3,6], [5,3,1]]
Output: [0, 2, 3, 6, 1, 5]
```
Vertex 3 is reached best via `0 -> 4 -> 5 -> 3` for `1 + 4 + 1 = 6`, better than `0 -> 4 -> 2 -> 3` = `1 + 2 + 6 = 9`.

## Approach 1: Dijkstra's algorithm
Works whenever all weights are non-negative, at O((N + M) log N). But it does more work than necessary here, and it breaks if the DAG has negative weights — Dijkstra's greedy "the popped node is final" claim relies on non-negativity.

- **Time:** O((N + M) log N)
- **Space:** O(N)

## Approach 2: Topological order + single relaxation pass (Optimal)

**Key observation.** In a DAG, edges never point backwards in a topological order. So if we process vertices in topological order, then by the time we stand on vertex `u`, **every** edge that could ever improve `dist[u]` has already been relaxed — all of `u`'s predecessors come earlier in the order and were processed already. Therefore `dist[u]` is final at that point, and we can confidently push it forward to `u`'s neighbours.

That means one linear sweep in topological order is enough; no priority queue, no repeated relaxation, and negative weights cause no trouble because there are no cycles to exploit.

**Algorithm.**
1. Build the weighted adjacency list.
2. Compute a topological order of the DAG (DFS pushing on the way out, then reversed — or Kahn's algorithm; either works).
3. Set `dist[0] = 0` and `dist[i] = ∞` for the rest.
4. Walk the topological order. For each vertex `u` with `dist[u] != ∞`, relax every outgoing edge: `dist[v] = min(dist[v], dist[u] + w)`. Skip vertices still at `∞` — they are unreachable from the source, and adding a weight to infinity is meaningless (and would overflow).
5. Convert remaining `∞` entries to `-1`.

**Why relaxing once per edge suffices.** The shortest path to `v` is `src = p0 -> p1 -> ... -> pk = v`. In the topological order `p0` appears before `p1`, which appears before `p2`, and so on. We process them in exactly that sequence, so the relaxation of `p0 -> p1` happens before that of `p1 -> p2`, etc. Each relaxation fires when the previous vertex already holds its final value, so the value propagates correctly down the whole path in one sweep. (This is the same argument as dynamic programming over a DAG — the topological order is the DP evaluation order.)

**Dry run** on the example. One topological order is `0, 1, 4, 5, 2, 3` (0 precedes 1 and 4; 4 precedes 5 and 2; 1 precedes 2; 2 and 5 precede 3).
- `dist = [0, ∞, ∞, ∞, ∞, ∞]`.
- Process 0: `dist[1] = 2`, `dist[4] = 1`.
- Process 1 (dist 2): `dist[2] = min(∞, 2 + 3) = 5`.
- Process 4 (dist 1): `dist[5] = 1 + 4 = 5`, `dist[2] = min(5, 1 + 2) = 3`. Note the improvement — and 2 has not been processed yet, so the better value will be the one propagated.
- Process 5 (dist 5): `dist[3] = min(∞, 5 + 1) = 6`.
- Process 2 (dist 3): `dist[3] = min(6, 3 + 6) = 6`.
- Process 3: no outgoing edges. Final `[0, 2, 3, 6, 1, 5]` ✓

- **Time:** O(N + M) — one topological sort plus one pass over every edge
- **Space:** O(N + M) for the adjacency list, O(N) for the stack and `dist`

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stack>
#include <climits>
using namespace std;

class Solution {
    void topoDfs(int u, vector<vector<pair<int,int>>>& adj, vector<int>& vis, stack<int>& st) {
        vis[u] = 1;
        for (auto& [v, w] : adj[u])
            if (!vis[v]) topoDfs(v, adj, vis, st);
        st.push(u);
    }

public:
    vector<int> shortestPath(int N, int M, vector<vector<int>>& edges) {
        vector<vector<pair<int,int>>> adj(N);
        for (auto& e : edges) adj[e[0]].push_back({e[1], e[2]});

        vector<int> vis(N, 0);
        stack<int> st;
        for (int i = 0; i < N; i++)
            if (!vis[i]) topoDfs(i, adj, vis, st);

        vector<int> dist(N, INT_MAX);
        dist[0] = 0;
        while (!st.empty()) {
            int u = st.top(); st.pop();
            if (dist[u] == INT_MAX) continue;          // unreachable, nothing to push forward
            for (auto& [v, w] : adj[u])
                if (dist[u] + w < dist[v]) dist[v] = dist[u] + w;
        }
        for (int i = 0; i < N; i++)
            if (dist[i] == INT_MAX) dist[i] = -1;
        return dist;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private void topoDfs(int u, List<int[]>[] adj, boolean[] vis, Deque<Integer> st) {
        vis[u] = true;
        for (int[] e : adj[u]) if (!vis[e[0]]) topoDfs(e[0], adj, vis, st);
        st.push(u);
    }

    @SuppressWarnings("unchecked")
    public int[] shortestPath(int N, int M, int[][] edges) {
        List<int[]>[] adj = new List[N];
        for (int i = 0; i < N; i++) adj[i] = new ArrayList<>();
        for (int[] e : edges) adj[e[0]].add(new int[]{e[1], e[2]});

        boolean[] vis = new boolean[N];
        Deque<Integer> st = new ArrayDeque<>();
        for (int i = 0; i < N; i++) if (!vis[i]) topoDfs(i, adj, vis, st);

        int[] dist = new int[N];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[0] = 0;
        while (!st.isEmpty()) {
            int u = st.pop();
            if (dist[u] == Integer.MAX_VALUE) continue;
            for (int[] e : adj[u]) {
                if (dist[u] + e[1] < dist[e[0]]) dist[e[0]] = dist[u] + e[1];
            }
        }
        for (int i = 0; i < N; i++) if (dist[i] == Integer.MAX_VALUE) dist[i] = -1;
        return dist;
    }
}
```

### Python
```python
import sys
from typing import List

class Solution:
    def shortestPath(self, N: int, M: int, edges: List[List[int]]) -> List[int]:
        sys.setrecursionlimit(10 ** 6)
        adj = [[] for _ in range(N)]
        for u, v, w in edges:
            adj[u].append((v, w))

        vis = [False] * N
        order: List[int] = []

        def topo(u: int) -> None:
            vis[u] = True
            for v, _ in adj[u]:
                if not vis[v]:
                    topo(v)
            order.append(u)

        for i in range(N):
            if not vis[i]:
                topo(i)

        INF = float("inf")
        dist = [INF] * N
        dist[0] = 0
        for u in reversed(order):            # topological order
            if dist[u] == INF:
                continue
            for v, w in adj[u]:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w

        return [-1 if d == INF else d for d in dist]
```

## Key Takeaways
- In a DAG, topological order is the correct DP evaluation order: when you reach a vertex, its distance is already final.
- One relaxation pass over each edge is enough — O(N + M), strictly faster than Dijkstra's O((N+M) log N).
- Unlike Dijkstra, this handles **negative edge weights**, since a DAG cannot contain a negative cycle.
- Always skip vertices still at infinity; relaxing from them is meaningless and `INT_MAX + w` overflows.
