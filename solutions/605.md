# Largest Subarray with Sum 0

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Hard

## Problem
Given an integer array `arr` (values may be negative), find the length of the longest contiguous subarray whose elements add up to exactly 0. If no such subarray exists, return 0.

Input: `arr = [9, -3, 3, -1, 6, -5]`
Output: `5` (the subarray `[-3, 3, -1, 6, -5]`)

## Approach 1: Brute Force
For every start index `i`, extend the end `j` rightward while accumulating a running sum. Whenever the running sum becomes 0, update the best length with `j - i + 1`.
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Prefix sums + hash map (Optimal)
Let `P[k]` be the sum of the first `k` elements. A subarray `(i, j]` sums to zero exactly when `P[j] == P[i]`. So the problem becomes: for each prefix value, how far apart are its first and current occurrence?

1. Keep a map from prefix-sum value to the earliest index where it appeared.
2. Walk the array maintaining `sum`. If `sum == 0`, the whole prefix `[0..i]` works, so the candidate length is `i + 1`.
3. Otherwise, if `sum` is already in the map at index `first`, the subarray `(first, i]` sums to zero with length `i - first`.
4. Only insert `sum` into the map the first time it is seen; keeping the earliest index maximises the length.

- **Time:** O(n) average with a hash map (O(n log n) with an ordered map)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int maxLen(vector<int>& arr) {
        unordered_map<long long, int> firstIdx;
        long long sum = 0;
        int best = 0;
        for (int i = 0; i < (int)arr.size(); ++i) {
            sum += arr[i];
            if (sum == 0) {
                best = i + 1;
            } else {
                auto it = firstIdx.find(sum);
                if (it != firstIdx.end()) best = max(best, i - it->second);
                else firstIdx[sum] = i;
            }
        }
        return best;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int maxLen(int[] arr) {
        Map<Long, Integer> firstIdx = new HashMap<>();
        long sum = 0;
        int best = 0;
        for (int i = 0; i < arr.length; i++) {
            sum += arr[i];
            if (sum == 0) {
                best = i + 1;
            } else if (firstIdx.containsKey(sum)) {
                best = Math.max(best, i - firstIdx.get(sum));
            } else {
                firstIdx.put(sum, i);
            }
        }
        return best;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def maxLen(self, arr: List[int]) -> int:
        first_idx = {}
        total = 0
        best = 0
        for i, x in enumerate(arr):
            total += x
            if total == 0:
                best = i + 1
            elif total in first_idx:
                best = max(best, i - first_idx[total])
            else:
                first_idx[total] = i
        return best
```

## Key Takeaways
- Equal prefix sums bracket a zero-sum subarray; this is the same trick used for "subarray with sum K" by looking up `sum - K`.
- Store only the first occurrence of each prefix sum so later matches give the longest possible span.
- Handle `sum == 0` separately (or seed the map with `{0: -1}`) so subarrays starting at index 0 are counted.
