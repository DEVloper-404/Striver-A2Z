# Check if the Array is Sorted II

**Difficulty:** Easy  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Easy

## Problem
Given an integer array `nums`, decide whether it could have been produced by taking a non-decreasing array and rotating it some number of positions (possibly zero). Rotating by `x` means the element originally at index `i` moves to index `(i + x) mod n`. Return `true` or `false`.

Input: `nums = [3, 4, 5, 1, 2]`
Output: `true` (rotate `[1, 2, 3, 4, 5]` by 3)

Input: `nums = [2, 1, 3, 4]`
Output: `false`

## Approach 1: Try Every Rotation
For each shift `k` from `0` to `n-1`, build the rotated array and check whether it is non-decreasing. If any rotation passes, answer `true`.

- **Time:** O(n²)
- **Space:** O(n) for the rotated copy (or O(1) with index arithmetic).

## Approach 2: Count the "Drops" (Optimal)
A sorted array has no index where `nums[i] > nums[i+1]`. Rotating it introduces exactly one such drop — the seam where the largest element is followed by the smallest — unless the rotation is by zero (or all elements are equal), which gives zero drops.

So walk the array in a circle, comparing `nums[i]` with `nums[(i+1) mod n]` for every `i`, and count how many times the left value is strictly greater than the right. Treating the array as circular means the wrap-around pair `nums[n-1]` vs `nums[0]` is included, which is what distinguishes `[2, 1, 3, 4]` (two drops: 2>1 and 4>2) from `[3, 4, 5, 1, 2]` (one drop: 5>1). The answer is `true` if the count is at most one.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    bool check(vector<int>& nums) {
        int n = nums.size(), drops = 0;
        for (int i = 0; i < n; i++) {
            if (nums[i] > nums[(i + 1) % n]) drops++;
        }
        return drops <= 1;
    }
};
```

### Python
```python
class Solution:
    def check(self, nums: list[int]) -> bool:
        n = len(nums)
        drops = 0
        for i in range(n):
            if nums[i] > nums[(i + 1) % n]:
                drops += 1
        return drops <= 1
```

## Key Takeaways
- A rotated sorted array has at most one position where the sequence decreases, counting the circular wrap from last to first.
- The wrap-around comparison is essential; without it `[2, 1, 3, 4]` would look valid.
- Duplicates are fine because only strict decreases count; an all-equal array has zero drops.
- The simpler "Check if Array is Sorted" (no rotation) is the same loop without the modulo and with the answer `drops == 0`.
