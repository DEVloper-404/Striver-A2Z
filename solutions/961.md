# LRU Cache

**Difficulty:** Medium  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Implementation Problems

## Problem
Design a cache with fixed `capacity` that supports two operations in O(1): `get(key)` returns the stored value (or `-1` if absent) and marks the key as most recently used; `put(key, value)` inserts or updates the key and marks it most recently used. When an insertion would exceed the capacity, the *least recently used* key is evicted first. (The same policy drives LRU page replacement in operating systems: pages are the keys, and a page fault is a `put` of a missing page.)

```
Input:  capacity = 2
        put(1,1), put(2,2), get(1), put(3,3), get(2), put(4,4), get(1), get(3), get(4)
Output: get(1)=1, get(2)=-1, get(1)=-1, get(3)=3, get(4)=4
```

## Approach 1: Array / List with Timestamps
Store `(key, value, lastUsed)` in a list. `get` scans for the key; `put` scans for the minimum `lastUsed` to evict.
- **Time:** O(capacity) per operation
- **Space:** O(capacity)

## Approach 2: Hash Map + Doubly Linked List (Optimal)
Keep a doubly linked list ordered from most recent (head) to least recent (tail), plus a hash map from key to its list node.
- `get`: look the node up in the map, unlink it and re-insert right after the head, return its value.
- `put`: if the key exists, update the value and move to front; otherwise create a node at the front, and if the size exceeds the capacity, remove the node before the tail and delete its key from the map.

Two sentinel nodes (dummy head and tail) remove all null checks.
- **Time:** O(1) per operation
- **Space:** O(capacity)

## Code (Optimal)

### C++
```cpp
#include <unordered_map>
using namespace std;

class LRUCache {
    struct Node {
        int key, val;
        Node *prev, *next;
        Node(int k, int v) : key(k), val(v), prev(nullptr), next(nullptr) {}
    };
    int cap;
    unordered_map<int, Node*> mp;
    Node *head, *tail;   // sentinels

    void unlink(Node* n) {
        n->prev->next = n->next;
        n->next->prev = n->prev;
    }
    void pushFront(Node* n) {
        n->next = head->next;
        n->prev = head;
        head->next->prev = n;
        head->next = n;
    }
public:
    LRUCache(int capacity) : cap(capacity) {
        head = new Node(0, 0);
        tail = new Node(0, 0);
        head->next = tail;
        tail->prev = head;
    }

    int get(int key) {
        auto it = mp.find(key);
        if (it == mp.end()) return -1;
        Node* n = it->second;
        unlink(n);
        pushFront(n);
        return n->val;
    }

    void put(int key, int value) {
        auto it = mp.find(key);
        if (it != mp.end()) {
            it->second->val = value;
            unlink(it->second);
            pushFront(it->second);
            return;
        }
        if ((int)mp.size() == cap) {
            Node* lru = tail->prev;
            unlink(lru);
            mp.erase(lru->key);
            delete lru;
        }
        Node* n = new Node(key, value);
        pushFront(n);
        mp[key] = n;
    }
};
```

### Java
```java
import java.util.*;

class LRUCache {
    private static class Node {
        int key, val;
        Node prev, next;
        Node(int k, int v) { key = k; val = v; }
    }

    private final int cap;
    private final Map<Integer, Node> mp = new HashMap<>();
    private final Node head = new Node(0, 0), tail = new Node(0, 0);

    public LRUCache(int capacity) {
        cap = capacity;
        head.next = tail;
        tail.prev = head;
    }

    private void unlink(Node n) {
        n.prev.next = n.next;
        n.next.prev = n.prev;
    }

    private void pushFront(Node n) {
        n.next = head.next;
        n.prev = head;
        head.next.prev = n;
        head.next = n;
    }

    public int get(int key) {
        Node n = mp.get(key);
        if (n == null) return -1;
        unlink(n);
        pushFront(n);
        return n.val;
    }

    public void put(int key, int value) {
        Node n = mp.get(key);
        if (n != null) {
            n.val = value;
            unlink(n);
            pushFront(n);
            return;
        }
        if (mp.size() == cap) {
            Node lru = tail.prev;
            unlink(lru);
            mp.remove(lru.key);
        }
        Node fresh = new Node(key, value);
        pushFront(fresh);
        mp.put(key, fresh);
    }
}
```

### Python
```python
from collections import OrderedDict

class LRUCache:
    # OrderedDict is a hash map whose entries keep insertion order and can be
    # moved to the end in O(1), which is exactly the linked-list + map combo.
    def __init__(self, capacity: int):
        self.cap = capacity
        self.od = OrderedDict()

    def get(self, key: int) -> int:
        if key not in self.od:
            return -1
        self.od.move_to_end(key)          # most recent = last
        return self.od[key]

    def put(self, key: int, value: int) -> None:
        if key in self.od:
            self.od.move_to_end(key)
        self.od[key] = value
        if len(self.od) > self.cap:
            self.od.popitem(last=False)   # evict least recent = first
```

## Key Takeaways
- Hash map gives O(1) lookup; the doubly linked list gives O(1) reordering and eviction — you need both.
- Both `get` and `put` on an existing key count as "use" and must move the node to the front.
- Sentinel head/tail nodes avoid special-casing an empty or single-element list.
