# Top View of BT

**Difficulty:** Medium  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Medium Problems

## Problem
Imagine looking at a binary tree from directly above. Assign columns as in vertical traversal (root at 0, left child `col - 1`, right child `col + 1`). For each column, the node visible from the top is the one closest to the root; if several nodes share that minimum depth in a column, the leftmost one encountered in level order is shown. Return the visible values from the leftmost column to the rightmost.

Input: root = [1,2,3,4,5,6,7]
Output: [4,2,1,3,7]

Input: root = [1,2,null,null,3,null,4]  (1 → left 2 → right 3 → right 4)
Output: [2,1,4]  (columns -1, 0, 1; node 3 sits under the root at column 0 and is hidden)

## Approach 1: Vertical Traversal, Keep the First of Each Column
Run the full vertical order traversal (column → row → values) and take the first value of every column. Correct, but it stores every node when only one per column is needed.

- **Time:** O(n log n)
- **Space:** O(n)

## Approach 2: BFS with First-Seen Column Map (Optimal)
Because BFS visits shallower nodes before deeper ones, the first time a column index appears in a level-order traversal is exactly the topmost node of that column. So:

1. BFS with `(node, col)` pairs.
2. Keep an ordered map `col → val`; insert only if the column is not present yet.
3. Output the map's values in ascending column order.

A DFS would not work without extra depth bookkeeping, because DFS can reach a deep node in a column before a shallow one.
- **Time:** O(n log n) with a tree map, O(n) with a hash map plus a min/max column range and array output
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; ... } — standard definition
class Solution {
public:
    vector<int> topView(TreeNode* root) {
        vector<int> res;
        if (!root) return res;
        map<int, int> firstInCol;
        queue<pair<TreeNode*, int>> q;
        q.push({root, 0});
        while (!q.empty()) {
            auto [node, c] = q.front(); q.pop();
            if (firstInCol.find(c) == firstInCol.end()) firstInCol[c] = node->val;
            if (node->left)  q.push({node->left,  c - 1});
            if (node->right) q.push({node->right, c + 1});
        }
        for (auto& [c, v] : firstInCol) res.push_back(v);
        return res;
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
import java.util.*;

class Solution {
    public List<Integer> topView(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        TreeMap<Integer, Integer> firstInCol = new TreeMap<>();
        Queue<Object[]> q = new ArrayDeque<>();
        q.offer(new Object[]{root, 0});
        while (!q.isEmpty()) {
            Object[] cur = q.poll();
            TreeNode node = (TreeNode) cur[0];
            int c = (Integer) cur[1];
            firstInCol.putIfAbsent(c, node.val);
            if (node.left != null)  q.offer(new Object[]{node.left,  c - 1});
            if (node.right != null) q.offer(new Object[]{node.right, c + 1});
        }
        res.addAll(firstInCol.values());
        return res;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
from collections import deque

class Solution:
    def topView(self, root):
        if root is None:
            return []
        first_in_col = {}
        q = deque([(root, 0)])
        while q:
            node, c = q.popleft()
            if c not in first_in_col:
                first_in_col[c] = node.val
            if node.left:
                q.append((node.left, c - 1))
            if node.right:
                q.append((node.right, c + 1))
        return [first_in_col[c] for c in sorted(first_in_col)]
```

## Key Takeaways
- BFS order guarantees the first node seen per column is the shallowest — that is the whole trick.
- Use an ordered map (or record min and max column) so the answer comes out left to right.
- Bottom view is the same code with "always overwrite" instead of "insert only if absent".
