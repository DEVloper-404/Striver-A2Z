# Inorder Traversal of Binary Tree

**Difficulty:** Easy  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Traversals

## Problem
Given the root of a binary tree, return its inorder traversal: for every node, first output everything in its left subtree, then the node itself, then everything in its right subtree. On a binary search tree this yields the values in sorted order.

Input: `root = [1, null, 2, 3]`
```
  1
   \
    2
   /
  3
```
Output: `[1, 3, 2]`

## Approach 1: Recursion
Follow the definition directly: if the node is null return; recurse left, record the node, recurse right. "Left, Root, Right" is the order of the three statements and nothing else changes.
- **Time:** O(n)
- **Space:** O(h) recursion stack (O(n) on a skewed tree)

## Approach 2: Iterative with a stack
Simulate the recursion. Keep a `curr` pointer starting at the root and an empty stack.

1. Walk as far left as possible from `curr`, pushing every node on the way. This mirrors the recursive descent into the left subtree.
2. When `curr` becomes null, pop the top of the stack: that node's left subtree is done, so record its value.
3. Set `curr` to the popped node's right child and repeat from step 1.

Stop when both `curr` is null and the stack is empty. Each node is pushed and popped exactly once.
- **Time:** O(n)
- **Space:** O(h) for the stack

## Approach 3: Morris traversal
Use the unused right pointers of inorder predecessors as temporary "threads" back to the current node so no stack is needed. For the current node: if it has no left child, record it and go right. Otherwise find the rightmost node in its left subtree. If that node's right is null, set it to the current node and move left; if it already points to the current node, reset it to null, record the current node, and move right. The tree is restored by the time the loop ends.
- **Time:** O(n) — each edge is traversed a constant number of times
- **Space:** O(1) extra

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stack>
using namespace std;

// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition

class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> res;
        stack<TreeNode*> st;
        TreeNode* curr = root;
        while (curr || !st.empty()) {
            while (curr) {               // go as far left as possible
                st.push(curr);
                curr = curr->left;
            }
            curr = st.top();
            st.pop();
            res.push_back(curr->val);    // left subtree done, visit node
            curr = curr->right;          // then handle right subtree
        }
        return res;
    }
};
```

### Java

```java
import java.util.*;

// class TreeNode { int val; TreeNode left, right; ... } — standard definition

class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        Deque<TreeNode> st = new ArrayDeque<>();
        TreeNode curr = root;
        while (curr != null || !st.isEmpty()) {
            while (curr != null) {       // go as far left as possible
                st.push(curr);
                curr = curr.left;
            }
            curr = st.pop();
            res.add(curr.val);           // left subtree done, visit node
            curr = curr.right;           // then handle right subtree
        }
        return res;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def inorderTraversal(self, root):
        res = []
        stack = []
        curr = root
        while curr or stack:
            while curr:                  # go as far left as possible
                stack.append(curr)
                curr = curr.left
            curr = stack.pop()
            res.append(curr.val)         # left subtree done, visit node
            curr = curr.right            # then handle right subtree
        return res
```

## Key Takeaways
- Inorder = Left, Root, Right; on a BST this produces sorted output, which many later problems rely on.
- The iterative pattern is "push all the way left, pop, visit, step right". The loop condition must check both `curr` and the stack.
- Recursion depth equals tree height, so a skewed tree can overflow the call stack; the explicit stack avoids that.
- Morris traversal achieves O(1) extra space by threading predecessor right pointers and undoing them afterwards.
