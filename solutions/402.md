# Pattern 10

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a half-diamond of stars with `2n - 1` rows. The star count rises from 1 up to `n` and then falls back to 1, one star per step, with stars separated by spaces.

Input: `n = 5`
Output:
```
*
* *
* * *
* * * *
* * * * *
* * * *
* * *
* *
*
```

## Approach
Instead of writing two loops (growing then shrinking), compute the star count for a single row index with one formula.

1. Loop `i` from `1` to `2n - 1`.
2. If `i <= n`, the row has `i` stars; otherwise it has `2n - i` stars.
3. Print that many `"* "` and a newline.

Check the endpoints: `i = n` gives `n` stars (the peak), `i = n+1` gives `n-1`, and `i = 2n-1` gives `1`.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern10(int n) {
    for (int i = 1; i <= 2 * n - 1; i++) {
        int stars = (i <= n) ? i : 2 * n - i;
        for (int j = 0; j < stars; j++) cout << "* ";
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern10 {
    public static void pattern10(int n) {
        for (int i = 1; i <= 2 * n - 1; i++) {
            int stars = (i <= n) ? i : 2 * n - i;
            StringBuilder row = new StringBuilder();
            for (int j = 0; j < stars; j++) row.append("* ");
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern10(n: int) -> None:
    for i in range(1, 2 * n):
        stars = i if i <= n else 2 * n - i
        print("* " * stars)
```

## Key Takeaways
- A rise-then-fall count can be expressed with one conditional formula instead of two loops.
- The total row count is `2n - 1` because the peak row is shared, unlike Pattern 9 where it is duplicated.
- Always test the formula at the peak and at the last row to catch off-by-one errors.
