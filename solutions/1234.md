# Introduction to Doubly LL

**Difficulty:** Easy  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Learn Doubly LinkedList

## Problem
This is a concept item. A doubly linked list (DLL) is a chain of nodes where every node stores a value plus **two** pointers: `next` (to the following node) and `prev` (to the preceding node). Because each node knows its neighbour on both sides, you can walk the list forwards or backwards and delete a node in O(1) once you hold a pointer to it, which a singly linked list cannot do. The usual starter task is: given an array, build a DLL from it and print it.

```
Input:  arr = [3, 1, 4]
Output: 3 <-> 1 <-> 4
```

## Approach: Node layout and construction
A DLL node:

```
+------+-------+------+
| prev | value | next |
+------+-------+------+
```

- The head's `prev` is `null`; the tail's `next` is `null`.
- To build from an array, create the first node as head, keep a `tail` pointer, and for every further value create a node, set `node.prev = tail`, `tail.next = node`, then move `tail` forward.
- Forward traversal follows `next`; backward traversal starts at the tail and follows `prev`.

Trade-offs versus a singly linked list:
- Extra memory: one more pointer per node.
- Every insert/delete must update two links instead of one, so it is easier to get wrong, but you gain O(1) deletion of a known node and O(1) insertion before a known node.

- **Time:** O(n) to build or traverse n elements
- **Space:** O(n) for the nodes themselves (no extra auxiliary space)

## Code (Optimal)

### C++
```cpp
#include <iostream>
#include <vector>
using namespace std;

struct DNode {
    int val;
    DNode* prev;
    DNode* next;
    DNode(int v) : val(v), prev(nullptr), next(nullptr) {}
};

class Solution {
public:
    // Build a DLL from the array and return its head.
    DNode* constructDLL(vector<int>& arr) {
        if (arr.empty()) return nullptr;
        DNode* head = new DNode(arr[0]);
        DNode* tail = head;
        for (size_t i = 1; i < arr.size(); i++) {
            DNode* node = new DNode(arr[i]);
            node->prev = tail;
            tail->next = node;
            tail = node;
        }
        return head;
    }

    void printForward(DNode* head) {
        for (DNode* cur = head; cur; cur = cur->next) {
            cout << cur->val;
            if (cur->next) cout << " <-> ";
        }
        cout << "\n";
    }
};
```

### Java

```java
class DNode {

class Solution {
    // Build a DLL from the array and return its head.
    public DNode constructDLL(int[] arr) {
        if (arr.length == 0) return null;
        DNode head = new DNode(arr[0]);
        DNode tail = head;
        for (int i = 1; i < arr.length; i++) {
            DNode node = new DNode(arr[i]);
            node.prev = tail;
            tail.next = node;
            tail = node;
        }
        return head;
    }

    public void printForward(DNode head) {
        StringBuilder sb = new StringBuilder();
        for (DNode cur = head; cur != null; cur = cur.next) {
            sb.append(cur.val);
            if (cur.next != null) sb.append(" <-> ");
        }
        System.out.println(sb);
    }
}
```

### Python
```python
class DNode:
    def __init__(self, val):
        self.val = val
        self.prev = None
        self.next = None


class Solution:
    # Build a DLL from the list and return its head.
    def constructDLL(self, arr):
        if not arr:
            return None
        head = DNode(arr[0])
        tail = head
        for v in arr[1:]:
            node = DNode(v)
            node.prev = tail
            tail.next = node
            tail = node
        return head

    def printForward(self, head):
        parts = []
        cur = head
        while cur:
            parts.append(str(cur.val))
            cur = cur.next
        print(" <-> ".join(parts))
```

## Key Takeaways
- A DLL node carries `prev` and `next`; head.prev and tail.next are both null.
- Building from an array is a single pass while keeping a `tail` pointer; always set both links when you attach a node.
- The `prev` pointer is what buys O(1) delete/insert-before at a known node, at the cost of one extra pointer per node.
- Edge case: an empty array yields a null head; a single element is both head and tail.
