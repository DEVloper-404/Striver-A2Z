# Merge Overlapping Subintervals

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Hard

## Problem
You are given a list of closed intervals `[start, end]`. Merge every pair of intervals that overlap (share at least one point) and return the resulting list of non-overlapping intervals, sorted by start.

Input: `intervals = [[1,3],[2,6],[8,10],[15,18]]`
Output: `[[1,6],[8,10],[15,18]]`

Input: `intervals = [[1,4],[4,5]]`
Output: `[[1,5]]` (touching endpoints count as overlapping)

## Approach 1: Sort + scan forward for each interval
Sort by start. For each interval `i` not already absorbed, walk `j = i+1, i+2, ...` and while `intervals[j].start <= currentEnd`, extend `currentEnd`. Once a gap appears, emit the merged interval. Because you re-examine intervals that a previous `i` already swallowed unless you track that, this is quadratic in the worst case.
- **Time:** O(n log n + n²)
- **Space:** O(n) for the answer

## Approach 2: Sort + single pass with the answer list (Optimal)
After sorting by start, the only interval an incoming one can overlap is the last one in the merged output — anything before that ended earlier and is already separated by a gap.

1. Sort by start.
2. Push the first interval into `res`.
3. For each next interval: if its start is `<=` the end of `res.back()`, set `res.back().end = max(res.back().end, cur.end)`; otherwise append it as a new block.

- **Time:** O(n log n)
- **Space:** O(n) for the output (O(1) extra beyond it)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        vector<vector<int>> res;
        if (intervals.empty()) return res;
        sort(intervals.begin(), intervals.end());
        res.push_back(intervals[0]);
        for (size_t i = 1; i < intervals.size(); ++i) {
            vector<int>& last = res.back();
            if (intervals[i][0] <= last[1]) {
                last[1] = max(last[1], intervals[i][1]);
            } else {
                res.push_back(intervals[i]);
            }
        }
        return res;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int[][] merge(int[][] intervals) {
        if (intervals.length == 0) return new int[0][];
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
        List<int[]> res = new ArrayList<>();
        res.add(new int[]{intervals[0][0], intervals[0][1]});
        for (int i = 1; i < intervals.length; i++) {
            int[] last = res.get(res.size() - 1);
            if (intervals[i][0] <= last[1]) {
                last[1] = Math.max(last[1], intervals[i][1]);
            } else {
                res.add(new int[]{intervals[i][0], intervals[i][1]});
            }
        }
        return res.toArray(new int[res.size()][]);
    }
}
```

### Python
```python
from typing import List

class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        if not intervals:
            return []
        intervals.sort(key=lambda iv: iv[0])
        res = [intervals[0][:]]
        for start, end in intervals[1:]:
            last = res[-1]
            if start <= last[1]:
                last[1] = max(last[1], end)
            else:
                res.append([start, end])
        return res
```

## Key Takeaways
- Sorting by start turns overlap detection into a comparison against only the last merged interval.
- Use `max` when extending the end; a later interval can be fully contained inside the previous one (e.g. `[1,10]` then `[2,3]`).
- Touching intervals (`end == next.start`) merge; use `<=` rather than `<` for closed intervals.
