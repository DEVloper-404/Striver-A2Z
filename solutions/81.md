# Search X in sorted array

**Difficulty:** Easy  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on 1D Arrays

## Problem
You are given an array `nums` sorted in ascending order and a target value `x`. Return the index of `x` in the array, or `-1` if it is not present. The expected solution must run in logarithmic time.

Input: `nums = [-1, 0, 3, 5, 9, 12], x = 9`
Output: `4`

Input: `nums = [-1, 0, 3, 5, 9, 12], x = 2`
Output: `-1`

## Approach 1: Linear Scan
Walk the array from left to right and stop at the first index whose value equals `x`. This ignores the fact that the array is sorted, so it does more work than necessary, but it is the baseline every faster method is measured against.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Binary Search (Optimal)
Because the array is sorted, comparing `x` with the middle element tells us which half can still contain it:

1. Keep two pointers `low = 0` and `high = n - 1` describing the range that may still hold `x`.
2. Compute `mid = low + (high - low) / 2` (written this way to avoid integer overflow).
3. If `nums[mid] == x`, return `mid`.
4. If `nums[mid] < x`, every element at or before `mid` is too small, so set `low = mid + 1`.
5. Otherwise every element at or after `mid` is too large, so set `high = mid - 1`.
6. When `low > high` the range is empty and `x` is absent.

Each step throws away half the remaining range, so at most about `log2(n) + 1` comparisons are made.

- **Time:** O(log n)
- **Space:** O(1) for the iterative version; O(log n) call stack if written recursively

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int search(vector<int>& nums, int target) {
        int low = 0, high = (int)nums.size() - 1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (nums[mid] == target) return mid;
            if (nums[mid] < target) low = mid + 1;
            else high = mid - 1;
        }
        return -1;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def search(self, nums: List[int], target: int) -> int:
        low, high = 0, len(nums) - 1
        while low <= high:
            mid = (low + high) // 2
            if nums[mid] == target:
                return mid
            if nums[mid] < target:
                low = mid + 1
            else:
                high = mid - 1
        return -1
```

## Key Takeaways
- Binary search only works on a sorted (monotonic) range; the sortedness is what lets one comparison discard half the candidates.
- Use `low <= high` as the loop condition and move `low`/`high` strictly past `mid` so the loop always terminates.
- Compute `mid` as `low + (high - low) / 2` in C++/Java to stay safe from overflow on large indices.
- Empty arrays are handled naturally: `high = -1` means the loop body never runs and `-1` is returned.
