# Print N to 1 using Recursion

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Learn Basic Recursion

## Problem
Given an integer `N`, print the integers from `N` down to `1` using recursion (no loops).

Input: `N = 5`
Output: `5 4 3 2 1`

## Approach 1: Print, then recurse on n - 1
The most direct version: `solve(n)` prints `n` and then calls `solve(n - 1)`; stop at `n == 0`. Because printing happens *before* the call, the largest number comes out first.

- **Time:** O(n)
- **Space:** O(n) recursion depth

## Approach 2: Backtracking with a counter
Use `solve(i, n)` that recurses to `i + 1` *first* and prints `i` on the way back. The deepest frame (`i = n`) prints first, giving `n, n-1, ..., 1`. This mirrors the "Print 1 to N" backtracking trick and demonstrates that the order of output is controlled entirely by where the print sits relative to the recursive call.

Trace for `n = 3`: `solve(1)` → `solve(2)` → `solve(3)` → `solve(4)` returns → print 3 → print 2 → print 1.

- **Time:** O(n)
- **Space:** O(n) stack

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void printNToOne(int n) {
    if (n == 0) return;
    cout << n << ' ';         // print first
    printNToOne(n - 1);       // then handle n-1 .. 1
}

int main() {
    printNToOne(5);
    cout << '\n';
    return 0;
}
```

### Java
```java
public class Main {
    static void printNToOne(int n) {
        if (n == 0) return;
        System.out.print(n + " ");   // print first
        printNToOne(n - 1);          // then handle n-1 .. 1
    }

    public static void main(String[] args) {
        printNToOne(5);
        System.out.println();
    }
}
```

### Python
```python
def print_n_to_one(n: int) -> None:
    if n == 0:
        return
    print(n, end=" ")       # print first
    print_n_to_one(n - 1)   # then handle n-1 .. 1

if __name__ == "__main__":
    print_n_to_one(5)
    print()
```

## Key Takeaways
- Printing before the recursive call produces descending output when the argument shrinks; printing after it flips the order.
- Both "1 to N" and "N to 1" are the same recursion with the print statement moved — a useful mental model for later tree traversals (pre-order vs post-order).
- Base case `n == 0` (or `i > n`) is what ends the recursion; forgetting it overflows the stack.
