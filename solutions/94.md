# Koko eating bananas

**Difficulty:** Medium  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on Answers

## Problem
There are `n` piles of bananas, `piles[i]` in the i-th pile, and the guards return in `h` hours. Each hour Koko picks one pile and eats up to `k` bananas from it; if the pile has fewer than `k` she finishes it and waits for the next hour. Find the minimum integer speed `k` that lets her finish every pile within `h` hours.

Input: piles = [3, 6, 7, 11], h = 8
Output: 4  (hours needed at k=4: 1+2+2+3 = 8)

## Approach 1: Try Every Speed
The answer lies between `1` and `max(piles)` (eating faster than the largest pile gives no benefit). For each `k` from 1 upward, compute total hours `sum(ceil(piles[i] / k))` and return the first `k` for which the total is `<= h`.
- **Time:** O(max(piles) * n)
- **Space:** O(1)

## Approach 2: Binary Search on Speed
The hours needed is non-increasing as `k` grows, so the predicate "can finish within `h` hours at speed `k`" flips from false to true exactly once. Binary search `k` in `[1, max(piles)]`:

1. Compute `hours(mid)` using ceiling division.
2. If `hours(mid) <= h`, `mid` works; store it and try smaller (`hi = mid - 1`).
3. Otherwise `lo = mid + 1`.

Use 64-bit accumulation for the hour count, since `n * piles[i]` can be large.
- **Time:** O(n * log(max(piles)))
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    long long hoursNeeded(const vector<int>& piles, int k) {
        long long total = 0;
        for (int p : piles) total += (p + k - 1LL) / k;
        return total;
    }

    int minEatingSpeed(vector<int>& piles, int h) {
        int lo = 1, hi = *max_element(piles.begin(), piles.end());
        int ans = hi;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (hoursNeeded(piles, mid) <= h) {
                ans = mid;
                hi = mid - 1;
            } else {
                lo = mid + 1;
            }
        }
        return ans;
    }
};
```

                ans = mid;
                hi = mid - 1;

        }

    }
}

### Python
```python
from typing import List

class Solution:
    def minEatingSpeed(self, piles: List[int], h: int) -> int:
        def hours_needed(k: int) -> int:
            return sum((p + k - 1) // k for p in piles)

        lo, hi = 1, max(piles)
        ans = hi
        while lo <= hi:
            mid = (lo + hi) // 2
            if hours_needed(mid) <= h:
                ans = mid
                hi = mid - 1
            else:
                lo = mid + 1
        return ans
```

## Key Takeaways
- Template for "minimum value that satisfies a feasibility check": binary search the answer, move left when feasible.
- The upper bound is `max(piles)`; any faster speed still costs one hour per pile.
- Ceiling division `(p + k - 1) / k` avoids floating point; accumulate in 64-bit.
- If `h == n`, the answer is `max(piles)`; the search handles it without a special case.
