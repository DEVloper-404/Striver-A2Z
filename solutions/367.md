# Count all Digits of a Number

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Know Basic Maths

## Problem
Given a non-negative integer `n`, return how many digits it has. The number `0` has one digit.

Input: `n = 12345`
Output: `5`

Input: `n = 7`
Output: `1`

## Approach 1: Repeated division
Strip the last digit with integer division by 10 and count how many times you can do that before the number becomes 0. Each division removes exactly one digit, so the loop runs once per digit. Handle `n = 0` separately (the loop would run zero times but the answer is 1).

- **Time:** O(log₁₀ n) — one iteration per digit
- **Space:** O(1)

## Approach 2: Logarithm
The number of digits of a positive integer is `floor(log10(n)) + 1`. This is a single arithmetic call, but floating-point rounding can misbehave at exact powers of ten on some platforms, so the division loop is the safer choice in interviews.

- **Time:** O(1)
- **Space:** O(1)

## Approach 3: String conversion
Convert to a string and take its length. Simple, but it allocates memory and is really just the division loop hidden inside the conversion routine.

- **Time:** O(log₁₀ n)
- **Space:** O(log₁₀ n) for the string

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int countDigits(long long n) {
        if (n == 0) return 1;
        if (n < 0) n = -n;
        int count = 0;
        while (n > 0) {
            n /= 10;
            count++;
        }
        return count;
    }
};
```

### Python
```python
class Solution:
    def countDigits(self, n: int) -> int:
        if n == 0:
            return 1
        n = abs(n)
        count = 0
        while n > 0:
            n //= 10
            count += 1
        return count
```

## Key Takeaways
- The "peel off the last digit with `% 10` and `/ 10`" loop is the base pattern for every digit problem (reverse, palindrome, Armstrong, digit sum).
- Anything that walks the digits runs in O(log₁₀ n), not O(n) — the input size is the number of digits.
- Do not forget `n = 0` (one digit) and negative inputs if the problem allows them.
