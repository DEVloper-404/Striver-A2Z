# Rotten Oranges

**Difficulty:** Medium  ·  **Topic:** Graphs [Concepts & Problems] › Problems on BFS/DFS

## Problem
You are given an `m × n` grid where each cell is `0` (empty), `1` (a fresh orange) or `2` (a rotten orange). Every minute, any fresh orange that is **4-directionally adjacent** to a rotten orange becomes rotten. Return the minimum number of minutes until no fresh orange remains, or `-1` if that is impossible.

```
Input:  grid = [[2,1,1],
                [1,1,0],
                [0,1,1]]
Output: 4
```

## Approach 1: Why DFS is the wrong tool here
It is tempting to DFS out from each rotten orange and record the depth at which each fresh orange is reached. That over-counts: a fresh orange reachable in 2 steps from one rotten orange might be reached at depth 7 by a DFS that wandered in through a long corridor, and DFS has no way to know it should have arrived earlier without re-visiting cells many times. You would need to allow re-visits whenever you arrive with a smaller time, which degenerates badly.

The real structure of the problem is: **all rotten oranges spread simultaneously**, and the answer for a fresh orange is its shortest distance to *any* rotten orange. Shortest distance in an unweighted graph means BFS, and "any of many sources" means BFS started from all of them at once.
- **Time:** exponential in the worst case with naive re-visiting DFS.
- **Space:** O(m·n)

## Approach 2: Multi-source BFS (Optimal)
The key observation is that BFS processes nodes in non-decreasing distance order, and this stays true if you seed the queue with *several* sources at distance 0. Level `k` of that BFS is exactly the set of cells whose nearest source is `k` steps away — which is precisely the set of oranges that rot in minute `k`. So one BFS wave over the whole grid simulates the passage of time, and the depth of the last level is the answer.

Algorithm:
1. Scan the grid once. Push every cell containing `2` into the queue with time 0, and count the fresh oranges in `fresh`.
2. Run BFS. When popping `(r, c, t)`, look at the four neighbours. If a neighbour is in bounds and holds a `1`, turn it into a `2` (this doubles as the visited mark), decrement `fresh`, push it with time `t + 1`, and update `elapsed = max(elapsed, t + 1)`.
3. After the queue empties, if `fresh > 0` some oranges were never reached — they sit in a region walled off by empty cells — so return `-1`. Otherwise return `elapsed`.

Two details matter for correctness:
- **Seed all sources before the loop.** If you BFS from one rotten orange at a time, an orange near two sources would be timed against the wrong one.
- **Mark on push.** Writing `2` into the grid the moment you enqueue guarantees each cell enters the queue exactly once, keeping the run O(m·n).
- **`elapsed` must be the max over the final level, not the queue size.** Tracking time per cell (or processing level-by-level with a size snapshot) both work.

Edge case: if there are no fresh oranges at the start, the answer is `0`, even if the grid is entirely empty. The `fresh == 0` check handles it because `elapsed` stays 0.

Dry run on the example:
- Initial: only `(0,0)` is rotten. `fresh = 6`.
- Minute 1: `(0,1)` and `(1,0)` rot. `fresh = 4`.
- Minute 2: `(0,2)` and `(1,1)` rot. `fresh = 2`.
- Minute 3: `(2,1)` rots (`(1,2)` is empty). `fresh = 1`.
- Minute 4: `(2,2)` rots. `fresh = 0`.
- Queue drains, `fresh == 0`, answer `elapsed = 4`.

If the grid were `[[2,1,1],[0,1,1],[1,0,1]]`, the cell `(2,0)` is fenced off by `0`s; the BFS never reaches it, `fresh` ends at 1, so we return `-1`.
- **Time:** O(m·n) — each cell enters the queue at most once, each pop scans 4 neighbours.
- **Space:** O(m·n) for the queue in the worst case (an entirely rotten grid).

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <queue>
#include <tuple>
using namespace std;

class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        queue<tuple<int,int,int>> q;   // row, col, minute
        int fresh = 0;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) q.push({i, j, 0});
                else if (grid[i][j] == 1) fresh++;
            }
        }
        if (fresh == 0) return 0;

        int dr[4] = {-1, 1, 0, 0};
        int dc[4] = {0, 0, -1, 1};
        int elapsed = 0;

        while (!q.empty()) {
            auto [r, c, t] = q.front(); q.pop();
            elapsed = max(elapsed, t);
            for (int k = 0; k < 4; k++) {
                int nr = r + dr[k], nc = c + dc[k];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == 1) {
                    grid[nr][nc] = 2;      // mark rotten = mark visited
                    fresh--;
                    q.push({nr, nc, t + 1});
                }
            }
        }
        return fresh == 0 ? elapsed : -1;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        Queue<int[]> q = new LinkedList<>();   // {row, col, minute}
        int fresh = 0;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) q.add(new int[]{i, j, 0});
                else if (grid[i][j] == 1) fresh++;
            }
        }
        if (fresh == 0) return 0;

        int[] dr = {-1, 1, 0, 0};
        int[] dc = {0, 0, -1, 1};
        int elapsed = 0;

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            elapsed = Math.max(elapsed, cur[2]);
            for (int k = 0; k < 4; k++) {
                int nr = cur[0] + dr[k], nc = cur[1] + dc[k];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == 1) {
                    grid[nr][nc] = 2;
                    fresh--;
                    q.add(new int[]{nr, nc, cur[2] + 1});
                }
            }
        }
        return fresh == 0 ? elapsed : -1;
    }
}
```

### Python
```python
from collections import deque
from typing import List

class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        q = deque()
        fresh = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 2:
                    q.append((i, j, 0))
                elif grid[i][j] == 1:
                    fresh += 1
        if fresh == 0:
            return 0

        dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        elapsed = 0
        while q:
            r, c, t = q.popleft()
            elapsed = max(elapsed, t)
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    q.append((nr, nc, t + 1))
        return elapsed if fresh == 0 else -1
```

## Key Takeaways
- "Everything spreads at the same time" ⇒ multi-source BFS: seed *all* sources at distance 0 before the loop starts.
- BFS levels map one-to-one onto minutes, so the deepest level reached is the answer.
- Count fresh oranges up front; a non-zero count after the BFS drains is the only way to detect the `-1` case.
- Zero fresh oranges at the start means the answer is `0`, not `-1` — check it before running the BFS.
