# Alien Dictionary

**Difficulty:** Hard  ·  **Topic:** Graphs [Concepts & Problems] › Topo Sort and Problems

## Problem
A dictionary of an alien language uses the first `K` lowercase English letters, but in an unknown alphabetical order. You are given `N` words from that dictionary, already sorted according to the alien order. Reconstruct a possible ordering of the `K` letters. If the input is contradictory (no ordering can explain it), report that no valid order exists.

```
Input:  N = 5, K = 4, words = ["baa", "abcd", "abca", "cab", "cad"]
Output: "bdac"
```
From `"baa"` before `"abcd"` we learn `b < a`; from `"abcd"` before `"abca"` we learn `d < a`; from `"abca"` before `"cab"` we learn `a < c`; from `"cab"` before `"cad"` we learn `b < d`. One ordering satisfying all four is `b, d, a, c`.

## Approach 1: Try all K! letter orders (brute force)
Enumerate every permutation of the `K` letters, treat it as the alphabet, and check whether the given word list is sorted under it. Return the first permutation that works. Correct, but `K!` is unusable beyond ~10 letters, and it hides the structure of the problem.

- **Time:** O(K! · total input length)
- **Space:** O(K)

## Approach 2: Extract precedence edges, then topological sort (Optimal)

**Key observation — where does information come from?** Two adjacent words in a sorted list tell you exactly *one* fact. Compare `words[i]` and `words[i+1]` character by character; at the **first position where they differ**, say `words[i][p] = x` and `words[i+1][p] = y`, sortedness forces `x < y` in the alien alphabet. Everything after that position is irrelevant — the comparison already ended. And non-adjacent pairs add nothing new, because ordering is transitive: `w1 < w2` and `w2 < w3` already imply `w1 < w3`.

So the whole input compresses to at most `N - 1` "letter `x` comes before letter `y`" constraints. That is a directed graph on `K` nodes, and any ordering consistent with all constraints is precisely a **topological ordering** of that graph.

**Algorithm.**
1. Create `K` nodes, one per letter (`'a' + i`).
2. For each consecutive pair of words, walk both simultaneously up to `min(len1, len2)`. At the first mismatch add edge `words[i][p] -> words[i+1][p]` and stop scanning this pair.
3. Run Kahn's algorithm: compute in-degrees, seed the queue with in-degree 0 letters, pop and append, decrementing successors.
4. Build the answer string from the pop order.

**The invalid-input cases.** Two things can make the list unexplainable:
- **A cycle** in the constraint graph (e.g. `a < b` and `b < a`). Kahn's detects it: the output has fewer than `K` letters.
- **A prefix violation**: a longer word appearing before its own prefix, like `["abcd", "abc"]`. The scan finds no mismatch, yet no alphabet can ever place `"abcd"` before `"abc"` — a prefix always sorts first. Detect it explicitly: if the loop ends with no mismatch and `len(words[i]) > len(words[i+1])`, declare the input invalid.

**Dry run** on `["baa","abcd","abca","cab","cad"]` with K = 4:
- Pairs give edges `b->a`, `d->a`, `a->c`, `b->d`. In-degrees: `a:2 (b,d)`, `b:0`, `c:1 (a)`, `d:1 (b)`.
- Queue `[b]`. Pop `b` → answer `b`; `a` drops to 1, `d` drops to 0 → push `d`.
- Pop `d` → answer `bd`; `a` drops to 0 → push `a`.
- Pop `a` → answer `bda`; `c` drops to 0 → push `c`. Pop `c` → answer `bdac`. Length 4 = K ✓.

- **Time:** O(N · L + K + E) where `L` is the max word length; building edges dominates, then Kahn's is O(K + E) with `E ≤ N - 1`
- **Space:** O(K + E) for the graph and in-degree array

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <string>
#include <queue>
using namespace std;

class Solution {
public:
    // returns the alien alphabet, or "" if the input is inconsistent
    string findOrder(vector<string>& words, int K) {
        vector<vector<int>> adj(K);
        vector<int> indeg(K, 0);

        for (size_t i = 0; i + 1 < words.size(); i++) {
            const string& a = words[i];
            const string& b = words[i + 1];
            size_t len = min(a.size(), b.size());
            size_t p = 0;
            while (p < len && a[p] == b[p]) p++;
            if (p == len) {
                if (a.size() > b.size()) return "";   // prefix appears after longer word
            } else {
                adj[a[p] - 'a'].push_back(b[p] - 'a');
                indeg[b[p] - 'a']++;
            }
        }

        queue<int> q;
        for (int i = 0; i < K; i++)
            if (indeg[i] == 0) q.push(i);

        string order;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            order += char('a' + u);
            for (int v : adj[u]) {
                if (--indeg[v] == 0) q.push(v);
            }
        }
        if ((int)order.size() != K) return "";        // cycle
        return order;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public String findOrder(String[] words, int K) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < K; i++) adj.add(new ArrayList<>());
        int[] indeg = new int[K];

        for (int i = 0; i + 1 < words.length; i++) {
            String a = words[i], b = words[i + 1];
            int len = Math.min(a.length(), b.length());
            int p = 0;
            while (p < len && a.charAt(p) == b.charAt(p)) p++;
            if (p == len) {
                if (a.length() > b.length()) return "";
            } else {
                adj.get(a.charAt(p) - 'a').add(b.charAt(p) - 'a');
                indeg[b.charAt(p) - 'a']++;
            }
        }

        Queue<Integer> q = new ArrayDeque<>();
        for (int i = 0; i < K; i++)
            if (indeg[i] == 0) q.add(i);

        StringBuilder sb = new StringBuilder();
        while (!q.isEmpty()) {
            int u = q.poll();
            sb.append((char) ('a' + u));
            for (int v : adj.get(u)) {
                if (--indeg[v] == 0) q.add(v);
            }
        }
        return sb.length() == K ? sb.toString() : "";
    }
}
```

### Python
```python
from collections import deque
from typing import List

class Solution:
    def findOrder(self, words: List[str], K: int) -> str:
        adj = [[] for _ in range(K)]
        indeg = [0] * K

        for a, b in zip(words, words[1:]):
            p = 0
            limit = min(len(a), len(b))
            while p < limit and a[p] == b[p]:
                p += 1
            if p == limit:
                if len(a) > len(b):
                    return ""            # invalid: prefix listed after longer word
            else:
                adj[ord(a[p]) - 97].append(ord(b[p]) - 97)
                indeg[ord(b[p]) - 97] += 1

        q = deque(i for i in range(K) if indeg[i] == 0)
        order = []
        while q:
            u = q.popleft()
            order.append(chr(97 + u))
            for v in adj[u]:
                indeg[v] -= 1
                if indeg[v] == 0:
                    q.append(v)

        return "".join(order) if len(order) == K else ""
```

## Key Takeaways
- Each adjacent word pair yields **exactly one** ordering constraint — the first differing character; transitivity covers the rest.
- The problem is a disguised topological sort over the `K` letters; Kahn's builds the alphabet and flags cycles.
- Two failure modes: a cycle (output shorter than `K`) and the prefix violation (`"abcd"` before `"abc"`), which no ordering can fix.
- Letters that appear in no constraint have in-degree 0 and can land anywhere — the answer is not unique unless the constraints form a chain.
