# Understand recursion by print something N times

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Learn Basic Recursion

## Problem
This item introduces recursion: a function that calls itself with a smaller input until it reaches a *base case*, at which point it stops. The exercise is to print a fixed message `N` times using recursion instead of a loop.

Input: `N = 3`
Output:
```
Hello
Hello
Hello
```

## Approach 1: Recursion with a counter
Think of a function `print(i, n)` that prints once and then asks the *same* function to handle the rest. Every call must make progress toward the base case, otherwise the recursion never ends (stack overflow).

1. Base case: if `i > n`, there is nothing left to print — return.
2. Print the message.
3. Call `print(i + 1, n)` to print the remaining `n - i` copies.

Call stack for `n = 3`: `print(1)` → prints, calls `print(2)` → prints, calls `print(3)` → prints, calls `print(4)` → returns. The three pending frames then return one after another.

Two ideas to keep in mind:
- **Base case** — the condition that stops the recursion.
- **Recursive step** — do a small piece of work and delegate the rest to the same function on a smaller problem.

- **Time:** O(n) — one call per print
- **Space:** O(n) — the recursion depth, because `n` frames are alive at the deepest point

## Approach 2: Count down instead of up
Pass `n` itself and shrink it: print, then call `print(n - 1)`; stop when `n == 0`. Identical cost, and it removes the extra counter parameter.

- **Time:** O(n)
- **Space:** O(n) stack

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void printNTimes(int n) {
    if (n == 0) return;          // base case
    cout << "Hello" << '\n';
    printNTimes(n - 1);          // smaller problem
}

int main() {
    int n = 3;
    printNTimes(n);
    return 0;
}
```

### Java
```java
public class Main {
    static void printNTimes(int n) {
        if (n == 0) return;          // base case
        System.out.println("Hello");
        printNTimes(n - 1);          // smaller problem
    }

    public static void main(String[] args) {
        printNTimes(3);
    }
}
```

### Python
```python
def print_n_times(n: int) -> None:
    if n == 0:          # base case
        return
    print("Hello")
    print_n_times(n - 1)  # smaller problem

if __name__ == "__main__":
    print_n_times(3)
```

## Key Takeaways
- Every recursive function needs a base case and a step that moves toward it; missing either causes infinite recursion and a stack overflow.
- Each call adds a frame to the call stack, so the space cost of a recursion is its maximum depth — O(n) here, even though no arrays are used.
- Recursion is a substitute for a loop; anything you can loop over you can recurse over, and vice versa.
