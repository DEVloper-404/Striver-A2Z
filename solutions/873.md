# Sudoku Solver

**Difficulty:** Hard  ·  **Topic:** Recursion [PatternWise] › Trying out all Combos / Hard

## Problem
Fill a partially completed `9 x 9` Sudoku board in place. Empty cells are marked `'.'`. Every row, every column and every one of the nine `3 x 3` boxes must contain the digits `1`–`9` exactly once. The input is guaranteed to have exactly one solution.

Input (first row shown): `["5","3",".",".","7",".",".",".","."]`, ...
Output: the same board with every `'.'` replaced so that all Sudoku rules hold.

## Approach 1: Backtracking with an on-the-fly validity scan
Scan the board for the first empty cell. Try digits `1`–`9`; for each digit check the row, the column and the box by looping over 9 cells each. If the digit is valid, write it and recurse; if the recursion succeeds propagate `true`, otherwise erase the digit and try the next one. If no digit works, return `false` so the caller backtracks. When no empty cell remains, the board is solved.
- **Time:** O(9^k) where `k` is the number of empty cells, each step costing O(27) checks
- **Space:** O(k) recursion depth

## Approach 2: Backtracking with bitmask lookups (Optimal)
Same search, but keep three arrays of 9-bit masks — `rowMask[9]`, `colMask[9]`, `boxMask[9]` — where bit `d` set means digit `d` is already used. Placing digit `d` at `(r, c)` becomes three OR operations; checking is one AND; undoing is three XORs. Box index is `(r / 3) * 3 + c / 3`.

Collect the empty cells into a list once, then recurse over the index in that list so we never re-scan the board.
- **Time:** O(9^k) worst case with O(1) per validity check; in practice fast because pruning happens immediately
- **Space:** O(k) for the empty-cell list and recursion

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    int rowM[9] = {}, colM[9] = {}, boxM[9] = {};
    vector<pair<int,int>> empties;

    bool go(int idx, vector<vector<char>>& b) {
        if (idx == (int)empties.size()) return true;
        auto [r, c] = empties[idx];
        int box = (r / 3) * 3 + c / 3;
        for (int d = 1; d <= 9; ++d) {
            int bit = 1 << d;
            if ((rowM[r] | colM[c] | boxM[box]) & bit) continue;
            rowM[r] |= bit; colM[c] |= bit; boxM[box] |= bit;
            b[r][c] = '0' + d;
            if (go(idx + 1, b)) return true;
            b[r][c] = '.';
            rowM[r] ^= bit; colM[c] ^= bit; boxM[box] ^= bit;
        }
        return false;
    }
public:
    void solveSudoku(vector<vector<char>>& board) {
        for (int r = 0; r < 9; ++r)
            for (int c = 0; c < 9; ++c) {
                if (board[r][c] == '.') { empties.push_back({r, c}); continue; }
                int bit = 1 << (board[r][c] - '0');
                rowM[r] |= bit; colM[c] |= bit; boxM[(r / 3) * 3 + c / 3] |= bit;
            }
        go(0, board);
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private int[] rowM = new int[9], colM = new int[9], boxM = new int[9];
    private List<int[]> empties = new ArrayList<>();

    public void solveSudoku(char[][] board) {
        for (int r = 0; r < 9; r++)
            for (int c = 0; c < 9; c++) {
                if (board[r][c] == '.') { empties.add(new int[]{r, c}); continue; }
                int bit = 1 << (board[r][c] - '0');
                rowM[r] |= bit; colM[c] |= bit; boxM[(r / 3) * 3 + c / 3] |= bit;
            }
        go(0, board);
    }

    private boolean go(int idx, char[][] b) {
        if (idx == empties.size()) return true;
        int r = empties.get(idx)[0], c = empties.get(idx)[1];
        int box = (r / 3) * 3 + c / 3;
        for (int d = 1; d <= 9; d++) {
            int bit = 1 << d;
            if (((rowM[r] | colM[c] | boxM[box]) & bit) != 0) continue;
            rowM[r] |= bit; colM[c] |= bit; boxM[box] |= bit;
            b[r][c] = (char) ('0' + d);
            if (go(idx + 1, b)) return true;
            b[r][c] = '.';
            rowM[r] ^= bit; colM[c] ^= bit; boxM[box] ^= bit;
        }
        return false;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def solveSudoku(self, board: List[List[str]]) -> None:
        row_m, col_m, box_m = [0] * 9, [0] * 9, [0] * 9
        empties = []
        for r in range(9):
            for c in range(9):
                if board[r][c] == ".":
                    empties.append((r, c))
                else:
                    bit = 1 << int(board[r][c])
                    row_m[r] |= bit
                    col_m[c] |= bit
                    box_m[(r // 3) * 3 + c // 3] |= bit

        def go(idx: int) -> bool:
            if idx == len(empties):
                return True
            r, c = empties[idx]
            box = (r // 3) * 3 + c // 3
            for d in range(1, 10):
                bit = 1 << d
                if (row_m[r] | col_m[c] | box_m[box]) & bit:
                    continue
                row_m[r] |= bit; col_m[c] |= bit; box_m[box] |= bit
                board[r][c] = str(d)
                if go(idx + 1):
                    return True
                board[r][c] = "."
                row_m[r] ^= bit; col_m[c] ^= bit; box_m[box] ^= bit
            return False

        go(0)
```

## Key Takeaways
- Fill one empty cell per recursion level; return `true` up the stack the moment the last cell is filled so the solved board is not undone.
- Box index formula `(r / 3) * 3 + c / 3` maps any cell to one of the nine boxes.
- Bitmasks make the validity check O(1) and the undo a single XOR.
- Because the puzzle has exactly one solution, stopping at the first success is correct.
