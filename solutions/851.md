# Print Longest Increasing Subsequence

**Difficulty:** Medium  ·  **Topic:** Dynamic Programming [Patterns and Problems] › DP on LIS

## Problem
Given an array `arr`, do not just report the *length* of the longest strictly increasing subsequence — **print the subsequence itself**. If several subsequences tie for the maximum length, returning any one of them is acceptable.

```
Input:  arr = [5, 4, 11, 1, 16, 8]
Output: [5, 11, 16]     (length 3; [4, 11, 16] is an equally valid answer)
```

## Approach 1: Length DP, then reconstruct with parent pointers
Start from the standard O(n²) LIS recurrence, where `dp[i]` = length of the longest increasing subsequence **ending at index `i`**:

```
dp[i] = 1 + max{ dp[j] : j < i and arr[j] < arr[i] }   (1 if no such j)
```

The length alone is not enough to print anything, so record **where each value came from**. Keep a second array `parent[i]` = the index `j` that produced the maximum above, or `-1` if `arr[i]` starts its own chain. This turns the DP table into a forest of back-pointers: following `parent` from any index walks the actual subsequence backwards.

Steps:
1. Fill `dp` and `parent` in one nested loop.
2. Find `best` = the index with the largest `dp` value (that is where the longest chain ends).
3. Walk `best → parent[best] → ...` until `-1`, collecting values.
4. Reverse the collected list, because the walk produced them from last to first.

**Dry run** on `[5, 4, 11, 1, 16, 8]`:

| i | arr[i] | dp[i] | parent[i] |
|---|--------|-------|-----------|
| 0 | 5      | 1     | −1        |
| 1 | 4      | 1     | −1        |
| 2 | 11     | 2     | 0         |
| 3 | 1      | 1     | −1        |
| 4 | 16     | 3     | 2         |
| 5 | 8      | 2     | 0         |

The maximum `dp` is 3 at index 4. Backtracking gives `4 → 2 → 0`, i.e. values `16, 11, 5`; reversed, `[5, 11, 16]`.

- **Time:** O(n²)
- **Space:** O(n) for `dp` + `parent`

## Approach 2: Patience binary search with back-pointers (Optimal)
The O(n log n) LIS keeps a `tails` array whose `k`-th entry is the smallest possible tail value of an increasing subsequence of length `k+1`. That array alone is famously *not* a valid subsequence — its entries can come from unrelated parts of the input — so we cannot just print it.

The fix is to carry two extra arrays:

- `tailsIdx[k]` — the **index** in `arr` of the element currently sitting at `tails[k]`.
- `parent[i]` — for the element at index `i`, the index of its predecessor in the chain that it extends.

When `arr[i]` is placed at position `pos` (found by binary search for the first tail `>= arr[i]`), the chain it extends is the best chain of length `pos`, whose last element is `tailsIdx[pos-1]`. So set `parent[i] = pos > 0 ? tailsIdx[pos-1] : -1`, then `tailsIdx[pos] = i`.

The crucial point is that `parent[i]` is fixed at the moment `i` is inserted and never changes afterwards. Later overwrites of `tails[pos]` do not invalidate it, because the chain that `i` pointed to was already complete and valid at that time. At the end, backtrack from `tailsIdx[size-1]`.

**Dry run** on `[5, 4, 11, 1, 16, 8]`:

| i | x  | pos | action  | tails      | tailsIdx | parent[i] |
|---|----|-----|---------|------------|----------|-----------|
| 0 | 5  | 0   | append  | [5]        | [0]      | −1        |
| 1 | 4  | 0   | replace | [4]        | [1]      | −1        |
| 2 | 11 | 1   | append  | [4, 11]    | [1, 2]   | 1         |
| 3 | 1  | 0   | replace | [1, 11]    | [3, 2]   | −1        |
| 4 | 16 | 2   | append  | [1,11,16]  | [3,2,4]  | 2         |
| 5 | 8  | 1   | replace | [1, 8, 16] | [3,5,4]  | 3         |

Backtracking from `tailsIdx[2] = 4`: `4 → 2 → 1`, values `16, 11, 4` → `[4, 11, 16]`. A different (equally long, equally valid) answer than the O(n²) version produced — which is expected, since ties are broken differently.

- **Time:** O(n log n)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> printLIS(vector<int>& arr) {
        int n = arr.size();
        if (n == 0) return {};

        vector<int> tails;                 // smallest tail value per length
        vector<int> tailsIdx;              // index in arr of each tail
        vector<int> parent(n, -1);         // predecessor index for each element

        for (int i = 0; i < n; i++) {
            int pos = lower_bound(tails.begin(), tails.end(), arr[i]) - tails.begin();
            if (pos > 0) parent[i] = tailsIdx[pos - 1];
            if (pos == (int)tails.size()) {
                tails.push_back(arr[i]);
                tailsIdx.push_back(i);
            } else {
                tails[pos] = arr[i];
                tailsIdx[pos] = i;
            }
        }

        vector<int> lis;
        for (int i = tailsIdx.back(); i != -1; i = parent[i]) lis.push_back(arr[i]);
        reverse(lis.begin(), lis.end());
        return lis;
    }
};
```

### Java
```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {
    public List<Integer> printLIS(int[] arr) {
        int n = arr.length;
        List<Integer> lis = new ArrayList<>();
        if (n == 0) return lis;

        int[] tails = new int[n];
        int[] tailsIdx = new int[n];
        int[] parent = new int[n];
        int size = 0;

        for (int i = 0; i < n; i++) {
            int lo = 0, hi = size;                 // first position with tails[pos] >= arr[i]
            while (lo < hi) {
                int mid = (lo + hi) >>> 1;
                if (tails[mid] < arr[i]) lo = mid + 1;
                else hi = mid;
            }
            int pos = lo;
            parent[i] = pos > 0 ? tailsIdx[pos - 1] : -1;
            tails[pos] = arr[i];
            tailsIdx[pos] = i;
            if (pos == size) size++;
        }

        for (int i = tailsIdx[size - 1]; i != -1; i = parent[i]) lis.add(arr[i]);
        Collections.reverse(lis);
        return lis;
    }
}
```

### Python
```python
from bisect import bisect_left
from typing import List


class Solution:
    def printLIS(self, arr: List[int]) -> List[int]:
        n = len(arr)
        if n == 0:
            return []

        tails = []          # smallest tail value per length
        tails_idx = []      # index in arr of each tail
        parent = [-1] * n

        for i, x in enumerate(arr):
            pos = bisect_left(tails, x)
            if pos > 0:
                parent[i] = tails_idx[pos - 1]
            if pos == len(tails):
                tails.append(x)
                tails_idx.append(i)
            else:
                tails[pos] = x
                tails_idx[pos] = i

        lis = []
        i = tails_idx[-1]
        while i != -1:
            lis.append(arr[i])
            i = parent[i]
        return lis[::-1]
```

## Key Takeaways
- To print any DP answer, store *how* each state was reached — a `parent` array turns the table into a linked path you can walk backwards.
- The `tails` array of the O(n log n) LIS is not a real subsequence; only with `tailsIdx` + `parent` can you recover an actual one.
- `parent[i]` is decided once, when element `i` is inserted, and stays valid even after `tails[pos]` is later overwritten.
- Remember to reverse the backtracked list, and handle the empty-array case before touching `tailsIdx.back()`.
