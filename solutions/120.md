# Minimum time taken to burn the BT from a given Node

**Difficulty:** Hard  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Hard Problems

## Problem
A fire starts at a given node of a binary tree. Every second, the fire spreads from each burning node to its left child, right child, and parent. Return the number of seconds until the entire tree is burnt. Node values are distinct and the start node is identified by its value.

Input: root = [1, 2, 3, 4, 5, 6, 7], start = 5
Output: 3 (5 → 2 at t=1; 1, 4 at t=2; 3 at t=3; 6 and 7 at t=4? No: 3 burns at t=3, 6 and 7 at t=4) — corrected output: 4

Input: root = [1, 2, 3, 4], start = 4
Output: 3 (4 → 2 → 1 → 3)

## Approach 1: Brute Force (max distance via repeated searches)
For every node compute its distance to the start node (e.g., by finding both root paths and going through the LCA) and take the maximum. Each distance query is O(N), so the total is quadratic.
- **Time:** O(N²)
- **Space:** O(H)

## Approach 2: Optimal (parent map + BFS from the start node)
The burn time is simply the farthest distance (in edges) from the start node when the tree is viewed as an undirected graph. So:
1. BFS from the root to record every node's parent, and grab a pointer to the start node while doing it.
2. BFS from the start node, expanding to left, right, and parent, with a visited set.
3. Count the number of layers that produce at least one new node; that count is the answer.

This is identical in structure to "nodes at distance K", except we keep expanding until the queue is empty.
- **Time:** O(N)
- **Space:** O(N)

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition
#include <queue>
#include <unordered_map>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int minTimeToBurn(TreeNode* root, int start) {
        if (!root) return 0;
        unordered_map<TreeNode*, TreeNode*> parent;
        TreeNode* src = nullptr;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            TreeNode* n = q.front(); q.pop();
            if (n->val == start) src = n;
            if (n->left)  { parent[n->left]  = n; q.push(n->left); }
            if (n->right) { parent[n->right] = n; q.push(n->right); }
        }

        unordered_set<TreeNode*> seen{src};
        q.push(src);
        int time = 0;
        while (!q.empty()) {
            int sz = q.size();
            bool spread = false;
            for (int i = 0; i < sz; ++i) {
                TreeNode* n = q.front(); q.pop();
                TreeNode* nb[3] = { n->left, n->right, parent.count(n) ? parent[n] : nullptr };
                for (TreeNode* x : nb)
                    if (x && !seen.count(x)) { seen.insert(x); q.push(x); spread = true; }
            }
            if (spread) ++time;
        }
        return time;
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
import java.util.*;

class Solution {
    public int minTimeToBurn(TreeNode root, int start) {
        if (root == null) return 0;
        Map<TreeNode, TreeNode> parent = new HashMap<>();
        TreeNode src = null;
        Deque<TreeNode> q = new ArrayDeque<>();
        q.add(root);
        while (!q.isEmpty()) {
            TreeNode n = q.poll();
            if (n.val == start) src = n;
            if (n.left  != null) { parent.put(n.left,  n); q.add(n.left); }
            if (n.right != null) { parent.put(n.right, n); q.add(n.right); }
        }

        Set<TreeNode> seen = new HashSet<>();
        seen.add(src);
        q.add(src);
        int time = 0;
        while (!q.isEmpty()) {
            int sz = q.size();
            boolean spread = false;
            for (int i = 0; i < sz; i++) {
                TreeNode n = q.poll();
                TreeNode[] nb = { n.left, n.right, parent.get(n) };
                for (TreeNode x : nb)
                    if (x != null && seen.add(x)) { q.add(x); spread = true; }
            }
            if (spread) time++;
        }
        return time;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
from collections import deque

class Solution:
    def minTimeToBurn(self, root, start):
        if not root:
            return 0
        parent, src = {}, None
        q = deque([root])
        while q:
            n = q.popleft()
            if n.val == start:
                src = n
            if n.left:
                parent[n.left] = n
                q.append(n.left)
            if n.right:
                parent[n.right] = n
                q.append(n.right)

        seen = {src}
        q.append(src)
        time = 0
        while q:
            spread = False
            for _ in range(len(q)):
                n = q.popleft()
                for x in (n.left, n.right, parent.get(n)):
                    if x and x not in seen:
                        seen.add(x)
                        q.append(x)
                        spread = True
            if spread:
                time += 1
        return time
```

## Key Takeaways
- Burn time = eccentricity of the start node in the undirected tree; BFS layers count it directly.
- Only increment the timer when a layer actually adds new nodes, otherwise you over-count by one at the end.
- Same template as "all nodes at distance K": parent map, visited set, layered BFS.
- A single-node tree burns in 0 seconds; the loop handles this since no layer spreads.
