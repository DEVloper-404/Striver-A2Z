# Trie Implementation and Operations

**Difficulty:** Hard  ·  **Topic:** Tries › Theory

## Problem
Implement a trie (prefix tree) supporting three operations over lowercase-letter strings:

- `insert(word)` — add `word` to the trie.
- `search(word)` — return `true` if the exact `word` was inserted before.
- `startsWith(prefix)` — return `true` if any inserted word begins with `prefix`.

```
Input:
insert("apple"); search("apple"); search("app"); startsWith("app"); insert("app"); search("app");
Output:
true, false, true, true
```

## Approach: The trie data structure

**Why a trie at all?** A hash set answers `search` in O(1), but it cannot answer `startsWith` without scanning every stored word. A trie stores words by *sharing their common prefixes*, so a prefix query becomes a simple walk down the tree. Both `search` and `startsWith` then cost O(length of the query) regardless of how many words are stored.

**Node structure.** Each node represents one prefix. It holds:
- `links[26]` — a child pointer per lowercase letter. `links[c]` being non-null means the prefix "current prefix + c" exists in the trie.
- `isEnd` — a boolean marking that some inserted word *ends exactly here*.

The root represents the empty prefix and stores no character itself. A character lives on the *edge* between two nodes, which is why the array is indexed by `ch - 'a'`.

**Why `isEnd` is essential.** Without it, inserting `"apple"` would also make `"app"` look like a stored word, since the path for `"app"` exists as part of `"apple"`. `isEnd` is exactly what separates "this prefix exists" from "this word was inserted".

**insert(word).** Start at the root. For each character `c`:
1. If `links[c - 'a']` is null, create a new empty node there — this is the point where the new word branches off from what is already stored.
2. Move into that child.

After the last character, set `isEnd = true` on the node you land on.

**search(word).** Walk the same way, but never create nodes. If at any character the child is missing, the word is not present → `false`. If the walk completes, return the final node's `isEnd` — completing the walk only proves the prefix exists, not the word.

**startsWith(prefix).** Identical walk, but the answer is simply "did the walk complete?" — no `isEnd` check, because we only care that the path exists.

**Dry run on the example.**

1. `insert("apple")`: from the root, `a`, `p`, `p`, `l`, `e` are all missing, so five nodes are created in a chain. The last node gets `isEnd = true`.
2. `search("apple")`: the walk `a→p→p→l→e` succeeds and the final node has `isEnd = true` → **true**.
3. `search("app")`: the walk `a→p→p` succeeds, but that node has `isEnd = false` (it is only an interior node of `"apple"`) → **false**. This is the case `isEnd` exists to handle.
4. `startsWith("app")`: the same walk succeeds and we do not look at `isEnd` → **true**.
5. `insert("app")`: the walk `a→p→p` finds every child already present, so **no new nodes are created** — the word simply reuses the existing branch — and the node after the second `p` gets `isEnd = true`.
6. `search("app")`: same walk, and now `isEnd` is true → **true**.

Notice step 5: sharing prefixes is what keeps the trie compact. Total nodes after both inserts is still 6 (root plus five), not 9.

- **Time:** O(L) per operation, where `L` is the length of the word or prefix
- **Space:** O(total characters inserted) nodes, each holding 26 pointers

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Trie {
    struct Node {
        Node* links[26] = {nullptr};
        bool isEnd = false;
    };
    Node* root;

public:
    Trie() { root = new Node(); }

    void insert(string word) {
        Node* cur = root;
        for (char ch : word) {
            int idx = ch - 'a';
            if (cur->links[idx] == nullptr) cur->links[idx] = new Node();
            cur = cur->links[idx];
        }
        cur->isEnd = true;
    }

    bool search(string word) {
        Node* cur = root;
        for (char ch : word) {
            int idx = ch - 'a';
            if (cur->links[idx] == nullptr) return false;
            cur = cur->links[idx];
        }
        return cur->isEnd;              // path exists AND a word ends here
    }

    bool startsWith(string prefix) {
        Node* cur = root;
        for (char ch : prefix) {
            int idx = ch - 'a';
            if (cur->links[idx] == nullptr) return false;
            cur = cur->links[idx];
        }
        return true;                    // only the path needs to exist
    }
};
```

### Java
```java
class Trie {
    private static class Node {
        Node[] links = new Node[26];
        boolean isEnd = false;
    }

    private final Node root;

    public Trie() { root = new Node(); }

    public void insert(String word) {
        Node cur = root;
        for (int i = 0; i < word.length(); i++) {
            int idx = word.charAt(i) - 'a';
            if (cur.links[idx] == null) cur.links[idx] = new Node();
            cur = cur.links[idx];
        }
        cur.isEnd = true;
    }

    public boolean search(String word) {
        Node cur = root;
        for (int i = 0; i < word.length(); i++) {
            int idx = word.charAt(i) - 'a';
            if (cur.links[idx] == null) return false;
            cur = cur.links[idx];
        }
        return cur.isEnd;
    }

    public boolean startsWith(String prefix) {
        Node cur = root;
        for (int i = 0; i < prefix.length(); i++) {
            int idx = prefix.charAt(i) - 'a';
            if (cur.links[idx] == null) return false;
            cur = cur.links[idx];
        }
        return true;
    }
}
```

### Python
```python
class TrieNode:
    __slots__ = ("links", "is_end")

    def __init__(self):
        self.links = {}          # char -> TrieNode
        self.is_end = False


class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        cur = self.root
        for ch in word:
            if ch not in cur.links:
                cur.links[ch] = TrieNode()
            cur = cur.links[ch]
        cur.is_end = True

    def _walk(self, s: str):
        cur = self.root
        for ch in s:
            if ch not in cur.links:
                return None
            cur = cur.links[ch]
        return cur

    def search(self, word: str) -> bool:
        node = self._walk(word)
        return node is not None and node.is_end

    def startsWith(self, prefix: str) -> bool:
        return self._walk(prefix) is not None
```

## Key Takeaways
- A trie node represents a *prefix*; characters live on edges, indexed by `ch - 'a'` for a 26-letter alphabet.
- `isEnd` is the only thing distinguishing "a word ends here" from "this is just an interior prefix" — `search` checks it, `startsWith` does not.
- Every operation is O(word length) and independent of how many words the trie holds; that is the trie's advantage over scanning a list.
- Edge cases: inserting the empty string marks the root's `isEnd`; inserting a word twice is harmless; a Python dict of children instead of a fixed array saves memory on sparse alphabets.
