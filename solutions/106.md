# LCA in BST

**Difficulty:** Medium  ·  **Topic:** Binary Search Trees [Concept and Problems] › Practice Problems

## Problem
Given the root of a BST and two nodes `p` and `q` that are both present in the tree, return their Lowest Common Ancestor — the deepest node that has both `p` and `q` in its subtree. A node may be an ancestor of itself.

```
Input:  root = [6, 2, 8, 0, 4, 7, 9, null, null, 3, 5], p = 2, q = 8
Output: 6      (2 and 4 sit on opposite sides of 6)

Input:  root = [6, 2, 8, 0, 4, 7, 9, null, null, 3, 5], p = 2, q = 4
Output: 2      (2 is an ancestor of 4, and of itself)
```

## Approach 1: Generic binary-tree LCA (ignores the BST property)
Recurse over the whole tree: if the current node is null or equals `p` or `q`, return it. Otherwise recurse into both children. If both sides return non-null, the current node is the split point and is the LCA; otherwise return whichever side was non-null.

Perfectly correct, but it may explore the entire tree because it has no way of knowing which direction `p` and `q` lie in.
- **Time:** O(N)
- **Space:** O(H)

## Approach 2: Optimal (compare against both values and walk down once)
The BST ordering tells you *which side* a value is on without searching, and that turns LCA into a single downward walk.

The key observation is about the **split point**. Start at the root and consider the current node's value `v`:
- If **both** `p` and `q` are less than `v`, then both live entirely in the left subtree. The current node has both in its subtree, but so does its left child — which is deeper. So the current node is not the *lowest* common ancestor; move left.
- If **both** are greater than `v`, symmetrically move right.
- Otherwise the values **split**: one is `<= v` and the other is `>= v`. Now the current node is a common ancestor (it has one in each subtree, or is one of them itself), and no deeper node can be: any child of `v` contains at most one of the two, since the other is on the opposite side. So `v` is the answer — return it.

This also handles the "a node is its own ancestor" case for free: if `p == v`, then `p` is not strictly less and not strictly greater, so we fall into the split case and correctly return `v`.

**Dry run** on the tree above with `p = 2, q = 8`:
- At `6`: `2 < 6` but `8 > 6` → they split → answer `6`. One comparison, done. ✔

**Dry run** with `p = 2, q = 4`:
- At `6`: both `2` and `4` are `< 6` → go left.
- At `2`: `p == 2`, so it is not the case that both are `> 2`, and not the case that both are `< 2` → split case → answer `2`. ✔

Because we only descend, the loop runs at most once per level. Written iteratively it uses no extra space at all.
- **Time:** O(H) — O(log N) balanced, O(N) skewed
- **Space:** O(1) iterative

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; TreeNode(int x) ... } — standard definition

class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        TreeNode* cur = root;
        while (cur != nullptr) {
            if (p->val < cur->val && q->val < cur->val) {
                cur = cur->left;            // both strictly left → a deeper ancestor exists
            } else if (p->val > cur->val && q->val > cur->val) {
                cur = cur->right;           // both strictly right
            } else {
                return cur;                 // they split here (or cur is p / q) → this is the LCA
            }
        }
        return nullptr;
    }
};
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def lowestCommonAncestor(self, root, p, q):
        cur = root
        while cur:
            if p.val < cur.val and q.val < cur.val:
                cur = cur.left          # both on the left, keep descending
            elif p.val > cur.val and q.val > cur.val:
                cur = cur.right         # both on the right
            else:
                return cur              # split point (or cur is one of them) → LCA
        return None
```

## Key Takeaways
- In a BST, the LCA is the first node where the search paths for `p` and `q` diverge — the "split point".
- You never need to search for the nodes first; comparing values against the current node is enough to know which way each one lies.
- The self-ancestor case falls out automatically because equality lands in the split branch.
- The iterative form is O(H) time and O(1) space; use the generic recursive binary-tree LCA only when the tree is not ordered.
