# Surrounded Regions

**Difficulty:** Medium  ·  **Topic:** Graphs [Concepts & Problems] › Problems on BFS/DFS

## Problem
Given an `m × n` board of `'X'` and `'O'`, capture every region of `'O'`s that is completely surrounded by `'X'`s by flipping those `'O'`s to `'X'`. A region is a group of `'O'`s connected 4-directionally; it is captured only if **no** cell of the region touches the border of the board. Modify the board in place.

```
Input:  [['X','X','X','X'],        Output: [['X','X','X','X'],
         ['X','O','O','X'],                 ['X','X','X','X'],
         ['X','X','O','X'],                 ['X','X','X','X'],
         ['X','O','X','X']]                 ['X','O','X','X']]
```
The middle region is fully enclosed and gets flipped; the `'O'` at `(3,1)` sits on the bottom border, so it survives.

## Approach 1: Test each region for enclosure (brute force)
Scan for an unvisited `'O'`, flood-fill its region while collecting its cells and a boolean "did I touch the border", then flip the collected cells only if that boolean is false. This is correct and still O(m·n) overall, but it needs a per-region cell list and careful bookkeeping, and it is easy to get wrong (forgetting to reset the flag, or flipping mid-traversal).
- **Time:** O(m·n)
- **Space:** O(m·n) for the visited matrix and the region buffer

## Approach 2: Invert the question — mark the survivors (Optimal)
Flip the logic around. Instead of proving that a region *is* enclosed, prove which regions *are not*:

> A region survives ⇔ it contains at least one border cell ⇔ every cell of it is reachable from some `'O'` on the border.

That is a single reachability question with a known source set, so one traversal answers it for the entire board. Everything the traversal does not reach is, by definition, enclosed.

Algorithm:
1. Run DFS/BFS from every `'O'` sitting in row 0, row `m-1`, column 0 or column `n-1`. Mark each reached `'O'` in a `safe` matrix (or temporarily rewrite it as `'#'`).
2. Sweep the whole board once more:
   - `'O'` and not safe → it was unreachable from the border → flip to `'X'`.
   - `'O'` and safe → restore/leave it as `'O'`.
   - `'X'` → untouched.

Correctness both ways. If a region touches the border, its border cell is a source, so the traversal marks the entire region safe and none of it is flipped — correct, it is not surrounded. If a region touches no border cell, then no source lies inside it and no path from a border `'O'` can enter it (a path would have to cross an `'X'`, which the traversal never steps on), so none of it is marked and all of it is flipped — correct.

This also eliminates the trickiest bug of the brute force: partial flipping. Because nothing is written until the traversal is finished, a region can never be half-captured.

Dry run on the example. Border `'O'`s: scanning row 0 (all `'X'`), row 3 finds `(3,1)`, column 0 and column 3 find none. From `(3,1)` the flood looks at `(2,1)` = `'X'`, `(3,0)` = `'X'`, `(3,2)` = `'X'` — the region is just that single cell, marked safe. Second sweep: `(1,1)`, `(1,2)`, `(2,2)` are `'O'` and unmarked → flipped to `'X'`. `(3,1)` is marked → stays `'O'`. Matches the expected output.

Small but important detail: the border scan must cover *all four* sides, and a `1×n` or `m×1` board means every cell is a border cell, so nothing is ever captured. A board with no `'O'` at all is handled trivially.
- **Time:** O(m·n) — each cell is visited at most once by the flood plus once by the final sweep.
- **Space:** O(m·n) for the `safe` matrix; the temporary-`'#'` variant uses O(1) extra beyond the recursion/queue.

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    void solve(vector<vector<char>>& board) {
        if (board.empty() || board[0].empty()) return;
        int m = board.size(), n = board[0].size();

        // 1) flood from every 'O' on the border, temporarily marking them '#'
        for (int i = 0; i < m; i++) {
            if (board[i][0] == 'O')     dfs(board, i, 0);
            if (board[i][n-1] == 'O')   dfs(board, i, n - 1);
        }
        for (int j = 0; j < n; j++) {
            if (board[0][j] == 'O')     dfs(board, 0, j);
            if (board[m-1][j] == 'O')   dfs(board, m - 1, j);
        }

        // 2) unreached 'O' is enclosed -> 'X';  '#' was border-connected -> 'O'
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O')      board[i][j] = 'X';
                else if (board[i][j] == '#') board[i][j] = 'O';
            }
        }
    }

private:
    void dfs(vector<vector<char>>& b, int r, int c) {
        if (r < 0 || r >= (int)b.size() || c < 0 || c >= (int)b[0].size()) return;
        if (b[r][c] != 'O') return;
        b[r][c] = '#';
        dfs(b, r - 1, c);
        dfs(b, r + 1, c);
        dfs(b, r, c - 1);
        dfs(b, r, c + 1);
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public void solve(char[][] board) {
        if (board.length == 0 || board[0].length == 0) return;
        int m = board.length, n = board[0].length;
        Queue<int[]> q = new LinkedList<>();

        for (int i = 0; i < m; i++) {
            if (board[i][0] == 'O')   { board[i][0] = '#';   q.add(new int[]{i, 0}); }
            if (board[i][n-1] == 'O') { board[i][n-1] = '#'; q.add(new int[]{i, n-1}); }
        }
        for (int j = 0; j < n; j++) {
            if (board[0][j] == 'O')   { board[0][j] = '#';   q.add(new int[]{0, j}); }
            if (board[m-1][j] == 'O') { board[m-1][j] = '#'; q.add(new int[]{m-1, j}); }
        }

        int[] dr = {-1, 1, 0, 0};
        int[] dc = {0, 0, -1, 1};
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            for (int k = 0; k < 4; k++) {
                int nr = cur[0] + dr[k], nc = cur[1] + dc[k];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && board[nr][nc] == 'O') {
                    board[nr][nc] = '#';
                    q.add(new int[]{nr, nc});
                }
            }
        }

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O')      board[i][j] = 'X';
                else if (board[i][j] == '#') board[i][j] = 'O';
            }
        }
    }
}
```

### Python
```python
from collections import deque
from typing import List

class Solution:
    def solve(self, board: List[List[str]]) -> None:
        if not board or not board[0]:
            return
        m, n = len(board), len(board[0])
        q = deque()

        for i in range(m):
            for j in (0, n - 1):
                if board[i][j] == 'O':
                    board[i][j] = '#'
                    q.append((i, j))
        for j in range(n):
            for i in (0, m - 1):
                if board[i][j] == 'O':
                    board[i][j] = '#'
                    q.append((i, j))

        dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        while q:
            r, c = q.popleft()
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and board[nr][nc] == 'O':
                    board[nr][nc] = '#'
                    q.append((nr, nc))

        for i in range(m):
            for j in range(n):
                if board[i][j] == 'O':
                    board[i][j] = 'X'
                elif board[i][j] == '#':
                    board[i][j] = 'O'
```

## Key Takeaways
- Do not test each region for enclosure — mark the regions that *escape* through the border and flip everything else.
- All four borders must seed the traversal; a `'#'` sentinel doubles as the visited marker and as "keep this one".
- Nothing is written until the flood finishes, so a region can never be partially captured.
- The same border-first trick solves Number of Enclaves and Pacific/Atlantic-style problems.
