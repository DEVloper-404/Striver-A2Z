# Roman to Integer

**Difficulty:** Medium  ·  **Topic:** Strings [Basic and Medium] › Medium String Problems

## Problem
Convert a Roman numeral string into its integer value. The symbols are `I=1, V=5, X=10, L=50, C=100, D=500, M=1000`. Normally symbols are written from largest to smallest and added, but six subtractive pairs exist: `IV=4, IX=9, XL=40, XC=90, CD=400, CM=900`. The input is guaranteed to be a valid numeral between 1 and 3999.

Input: `s = "MCMXCIV"`
Output: `1994`  (`M=1000, CM=900, XC=90, IV=4`)

Input: `s = "LVIII"`
Output: `58`

## Approach 1: Handle the six pairs explicitly
Walk left to right. At each index check whether the two-character window is one of the six subtractive pairs; if so add its value and skip two characters, otherwise add the single symbol's value and advance one. Works, but requires a second lookup table for the pairs.
- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Compare with the next symbol (Optimal)
The subtractive rule has a uniform shape: whenever a symbol is **smaller than the symbol right after it**, it should be subtracted instead of added. So:

1. Map each character to its value.
2. For each index `i`, if `value(s[i]) < value(s[i+1])`, subtract `value(s[i])`; otherwise add it.
3. The last character is always added.

No pair table is needed, and the loop is a single pass.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Solution {
    int val(char c) {
        switch (c) {
            case 'I': return 1;
            case 'V': return 5;
            case 'X': return 10;
            case 'L': return 50;
            case 'C': return 100;
            case 'D': return 500;
            case 'M': return 1000;
        }
        return 0;
    }
public:
    int romanToInt(string s) {
        int total = 0;
        int n = s.size();
        for (int i = 0; i < n; ++i) {
            int cur = val(s[i]);
            if (i + 1 < n && cur < val(s[i + 1])) total -= cur;
            else total += cur;
        }
        return total;
    }
};
```

class Solution {
    private int val(char c) {
        switch (c) {
            case 'I': return 1;
            case 'V': return 5;

            case 'L': return 50;
            case 'C': return 100;

    public int romanToInt(String s) {
        int total = 0;
        int n = s.length();
        for (int i = 0; i < n; i++) {
            int cur = val(s.charAt(i));
            if (i + 1 < n && cur < val(s.charAt(i + 1))) total -= cur;
            else total += cur;
        }
        return total;
    }
}

### Python
```python
class Solution:
    def romanToInt(self, s: str) -> int:
        val = {'I': 1, 'V': 5, 'X': 10, 'L': 50, 'C': 100, 'D': 500, 'M': 1000}
        total = 0
        n = len(s)
        for i in range(n):
            cur = val[s[i]]
            if i + 1 < n and cur < val[s[i + 1]]:
                total -= cur
            else:
                total += cur
        return total
```

## Key Takeaways
- Subtractive notation is just "a smaller symbol immediately before a larger one".
- Comparing each symbol with its right neighbour handles all six pairs with one rule.
- Guard the `i + 1` access; the last symbol is always added.
- Input is guaranteed valid, so no validation of illegal sequences like `"IIII"` is required.
