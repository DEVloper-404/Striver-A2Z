# Jump Game - I

**Difficulty:** Easy  ·  **Topic:** Greedy Algorithms [Easy, Medium/Hard] › Medium/Hard

## Problem
You start at index `0` of an integer array `nums`, where `nums[i]` is the maximum number of steps you may jump forward from index `i`. Decide whether you can reach the last index. Return `true` or `false`.

Input: `nums = [2, 3, 1, 1, 4]`
Output: `true` (0 → 1 → 4)

Input: `nums = [3, 2, 1, 0, 4]`
Output: `false` (every path lands on index 3, which has jump length 0)

## Approach 1: Recursion / DP over reachable indices
From each index try every jump length `1..nums[i]` and recurse; memoize whether an index can reach the end. Correct, but you visit every (index, jump) pair.
- **Time:** O(n²)
- **Space:** O(n)

## Approach 2: Greedy furthest-reach (Optimal)
Key observation: what matters is only the **furthest index reachable so far**, call it `maxReach`. Scan left to right:
1. If the current index `i` is beyond `maxReach`, you got stuck; return `false`.
2. Otherwise update `maxReach = max(maxReach, i + nums[i])`.
3. If `maxReach >= n - 1` at any point, return `true`.

Every index up to `maxReach` is reachable (you can always shorten a jump), so this single value captures all the information needed.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    bool canJump(vector<int>& nums) {
        int n = nums.size();
        int maxReach = 0;
        for (int i = 0; i < n; i++) {
            if (i > maxReach) return false;
            maxReach = max(maxReach, i + nums[i]);
            if (maxReach >= n - 1) return true;
        }
        return true;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def canJump(self, nums: List[int]) -> bool:
        n = len(nums)
        max_reach = 0
        for i in range(n):
            if i > max_reach:
                return False
            max_reach = max(max_reach, i + nums[i])
            if max_reach >= n - 1:
                return True
        return True
```

## Key Takeaways
- Track a single "furthest reachable" frontier; if the scan ever passes it, the path is broken.
- A `0` is only a problem when it is the furthest you can reach; a `0` inside the reachable window is harmless.
- A single-element array is trivially `true`.
