# Search in a Binary Search Tree

**Difficulty:** Easy  ·  **Topic:** Binary Search Trees [Concept and Problems] › Concepts

## Problem
Given the root of a BST and an integer `val`, find the node whose value equals `val` and return the subtree rooted at that node. If no such node exists, return null.

Input: root = [4, 2, 7, 1, 3], val = 2
Output: [2, 1, 3]

Input: root = [4, 2, 7, 1, 3], val = 5
Output: []

## Approach 1: Brute Force (generic tree search)
Ignore the BST property and traverse the whole tree (DFS or BFS) until a node with the target value appears. Works on any binary tree but wastes the ordering information.
- **Time:** O(N)
- **Space:** O(H)

## Approach 2: Optimal (walk down using the ordering)
Start at the root. If the current value equals `val`, return it. If `val` is smaller, the target can only be in the left subtree, so move left; otherwise move right. Stop when you reach null. Each step eliminates an entire subtree, so the number of steps is at most the height.
- **Time:** O(H) — O(log N) for a balanced tree, O(N) if degenerate
- **Space:** O(1) iteratively (O(H) if written recursively)

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition
class Solution {
public:
    TreeNode* searchBST(TreeNode* root, int val) {
        while (root && root->val != val)
            root = val < root->val ? root->left : root->right;
        return root;
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
class Solution {
    public TreeNode searchBST(TreeNode root, int val) {
        while (root != null && root.val != val)
            root = val < root.val ? root.left : root.right;
        return root;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def searchBST(self, root, val):
        while root and root.val != val:
            root = root.left if val < root.val else root.right
        return root
```

## Key Takeaways
- BST search is binary search on a tree: one comparison per level, discard the other half.
- The iterative form needs no extra memory; the recursive form is equally short but uses O(H) stack.
- Returning the node (not just a boolean) is what lets the caller reuse the subtree.
- The loop naturally returns null when the value is absent, so no special-case branch is needed.
