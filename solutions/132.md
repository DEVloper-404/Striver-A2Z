# Maximum path sum

**Difficulty:** Medium  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Medium Problems

## Problem
A path in a binary tree is any sequence of nodes where consecutive nodes are connected by an edge, and a node appears at most once. The path does not need to start or end at the root or a leaf. Given the root (node values may be negative), return the maximum sum of values along any path.

Input: root = [1,2,3]
Output: 6  (2 → 1 → 3)

Input: root = [-10,9,20,null,null,15,7]
Output: 42  (15 → 20 → 7)

## Approach 1: Try Every Node as the Peak (Brute Force)
For each node `x`, the best path with `x` as its highest point is `x.val + bestDownward(x.left) + bestDownward(x.right)`, where `bestDownward(y)` is the maximum sum of a path that starts at `y` and goes only downward (or 0 if we choose to skip that side). Compute `bestDownward` fresh for each node.

- **Time:** O(n²) in the worst case because `bestDownward` is recomputed for every ancestor
- **Space:** O(h)

## Approach 2: One Post-Order Pass (Optimal)
This is the diameter pattern with values instead of edge counts. Write a helper `gain(node)` that returns the best downward path sum starting at `node`, and while computing it, update a global answer with the "peak at this node" sum.

1. Null node: return 0.
2. `l = max(0, gain(left))`, `r = max(0, gain(right))` — clamp to 0 because a negative branch is better left out entirely.
3. `best = max(best, node.val + l + r)` — path that bends at this node.
4. Return `node.val + max(l, r)` — the parent may only extend along one side.

Initialize `best` to a very small number (not 0), since all values might be negative and the answer could be a single negative node.
- **Time:** O(n)
- **Space:** O(h)

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; ... } — standard definition
class Solution {
    int best;
    int gain(TreeNode* node) {
        if (!node) return 0;
        int l = max(0, gain(node->left));
        int r = max(0, gain(node->right));
        best = max(best, node->val + l + r);
        return node->val + max(l, r);
    }
public:
    int maxPathSum(TreeNode* root) {
        best = INT_MIN;
        gain(root);
        return best;
    }
};
```

### Java

```java
class Solution {
    private int best;

    private int gain(TreeNode node) {
        if (node == null) return 0;
        int l = Math.max(0, gain(node.left));
        int r = Math.max(0, gain(node.right));
        best = Math.max(best, node.val + l + r);
        return node.val + Math.max(l, r);
    }

    public int maxPathSum(TreeNode root) {
        best = Integer.MIN_VALUE;
        gain(root);
        return best;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
class Solution:
    def maxPathSum(self, root) -> int:
        self.best = float("-inf")

        def gain(node):
            if node is None:
                return 0
            l = max(0, gain(node.left))
            r = max(0, gain(node.right))
            self.best = max(self.best, node.val + l + r)
            return node.val + max(l, r)

        gain(root)
        return self.best
```

## Key Takeaways
- Two different quantities per node: the value handed up to the parent (one branch only) and the value recorded globally (both branches).
- Clamping a subtree's contribution at 0 is what lets you drop negative branches for free.
- Start `best` at negative infinity; an all-negative tree must return the largest single value, not 0.
