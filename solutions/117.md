# Count total nodes in a complete BT

**Difficulty:** Easy  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Hard Problems

## Problem
Given the root of a *complete* binary tree (every level is full except possibly the last, which is filled from left to right), return the total number of nodes. The goal is to beat the trivial O(N) traversal by exploiting the completeness guarantee.

Input: root = [1, 2, 3, 4, 5, 6]
Output: 6

Input: root = []
Output: 0

## Approach 1: Brute Force (plain traversal)
Any DFS or BFS that visits every node and counts works for any binary tree. It ignores the "complete" property entirely.
- **Time:** O(N)
- **Space:** O(H)

## Approach 2: Optimal (compare left-spine and right-spine heights)
For a node, measure the height going only left (`lh`) and only right (`rh`):
- If `lh == rh`, the subtree rooted here is a *perfect* binary tree, so it has exactly `2^lh - 1` nodes and we can return without visiting them.
- Otherwise, recurse on both children and add 1.

Because the tree is complete, at each level of recursion at least one child is perfect and is answered in O(log N) time, so only one branch continues recursing. That gives O(log N) levels, each costing O(log N) for the height checks.
- **Time:** O(log² N)
- **Space:** O(log N) recursion

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition
class Solution {
    int leftHeight(TreeNode* n)  { int h = 0; while (n) { ++h; n = n->left;  } return h; }
    int rightHeight(TreeNode* n) { int h = 0; while (n) { ++h; n = n->right; } return h; }
public:
    int countNodes(TreeNode* root) {
        if (!root) return 0;
        int lh = leftHeight(root), rh = rightHeight(root);
        if (lh == rh) return (1 << lh) - 1;
        return 1 + countNodes(root->left) + countNodes(root->right);
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
class Solution {
    private int leftHeight(TreeNode n)  { int h = 0; while (n != null) { h++; n = n.left;  } return h; }
    private int rightHeight(TreeNode n) { int h = 0; while (n != null) { h++; n = n.right; } return h; }

    public int countNodes(TreeNode root) {
        if (root == null) return 0;
        int lh = leftHeight(root), rh = rightHeight(root);
        if (lh == rh) return (1 << lh) - 1;
        return 1 + countNodes(root.left) + countNodes(root.right);
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def countNodes(self, root):
        def left_height(n):
            h = 0
            while n:
                h += 1
                n = n.left
            return h

        def right_height(n):
            h = 0
            while n:
                h += 1
                n = n.right
            return h

        if not root:
            return 0
        lh, rh = left_height(root), right_height(root)
        if lh == rh:
            return (1 << lh) - 1
        return 1 + self.countNodes(root.left) + self.countNodes(root.right)
```

## Key Takeaways
- In a complete tree, equal left-spine and right-spine heights prove the subtree is perfect, and a perfect tree of height h has 2^h - 1 nodes.
- Only one side ever needs deeper recursion, which is what turns O(N) into O(log² N).
- The formula `(1 << h) - 1` is fine for practical heights (h ≤ 30 for int); use `1L` in Java/C++ if you need more.
- This approach is wrong for non-complete trees; the guarantee is what makes the shortcut valid.
