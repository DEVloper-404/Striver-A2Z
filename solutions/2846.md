# Find the intersection point of Y LL

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
Two singly linked lists may share a suffix, so from some node onward they are physically the same chain (a Y shape). Given the two heads, return the first node common to both lists, or null if they never merge. Nodes are compared by identity, not by value, and the lists must be left unchanged.

```
Input:  A = 4 -> 1 -> 8 -> 4 -> 5
        B = 5 -> 6 -> 1 -> 8 -> 4 -> 5   (node 8 is shared)
Output: node 8
```

## Approach 1: Hash set of one list's nodes
Insert every node of list A into a set. Walk list B and return the first node that is in the set. If none, return null.

- **Time:** O(m + n)
- **Space:** O(m)

## Approach 2: Length difference
Compute the lengths `m` and `n`. Advance the longer list's pointer by `|m - n|` nodes so both pointers have the same number of nodes remaining. Then walk both together; the first node where they are equal is the intersection.

- **Time:** O(m + n)
- **Space:** O(1)

## Approach 3: Two pointers that swap lists (optimal)
Start `a` at headA and `b` at headB. Advance both one step at a time; when a pointer reaches null, redirect it to the *other* list's head. After the switch, both pointers have travelled `m + n` nodes when they reach the end of their second list, so they arrive at the shared tail in sync and meet at the intersection. If there is no intersection, they both become null at the same moment, which is the loop exit.

- **Time:** O(m + n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
public:
    ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
        if (!headA || !headB) return nullptr;
        ListNode* a = headA;
        ListNode* b = headB;
        while (a != b) {
            a = a ? a->next : headB;
            b = b ? b->next : headA;
        }
        return a;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } }

public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        if (headA == null || headB == null) return null;
        ListNode a = headA, b = headB;
        while (a != b) {
            a = (a == null) ? headB : a.next;
            b = (b == null) ? headA : b.next;
        }
        return a;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def getIntersectionNode(self, headA, headB):
        if not headA or not headB:
            return None
        a, b = headA, headB
        while a is not b:
            a = headB if a is None else a.next
            b = headA if b is None else b.next
        return a
```

## Key Takeaways
- Switching heads equalises the distance both pointers travel, so they align at the merge point.
- The loop also terminates on no intersection because both pointers become null together.
- Redirect on null (not on the last node) or the pointers can drift by one.
- Identity comparison is essential; two different nodes with equal values are not an intersection.
