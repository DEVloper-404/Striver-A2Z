# Shortest common supersequence

**Difficulty:** Hard  ·  **Topic:** Dynamic Programming [Patterns and Problems] › DP on Strings

## Problem
Given two strings `s1` and `s2`, return the shortest string that contains **both** of them as subsequences. If several shortest answers exist, any one of them is acceptable.

```
Input:  s1 = "brute", s2 = "groot"
Output: "bgruoote"   (length 8)
Explanation: "brute" reads off as b, r, u, t, e and "groot" as g, r, o, o, t.

Input:  s1 = "abac", s2 = "cab"
Output: "cabac"      (length 5)
```

## Approach 1: Get the length first

**The key observation.** A supersequence must contain every character of `s1` and every character of `s2`. Naively concatenating them gives length `n + m` and is always valid. We do better only by letting one character of the result serve *both* strings at once.

Which characters can be shared? A shared character is used by `s1` and by `s2` at compatible positions, and since a supersequence preserves order in both, the set of shared characters must appear in the same relative order in both strings — that is exactly a common subsequence. Sharing `L` characters saves `L` from the naive concatenation, so:

```
length of shortest common supersequence = n + m - LCS(s1, s2)
```

Maximising the sharing means using the *longest* common subsequence.

- **Time:** O(n · m)
- **Space:** O(n · m) — we keep the table for the next step

## Approach 2: Optimal (build the LCS table, then backtrack to construct the string)

Compute the full LCS table:

```
dp[i][j] = 1 + dp[i-1][j-1]                     if s1[i-1] == s2[j-1]
dp[i][j] = max(dp[i-1][j], dp[i][j-1])          otherwise
```

with row 0 and column 0 zero. Then walk backwards from `(n, m)`, emitting characters as you undo each decision:

1. **Match** (`s1[i-1] == s2[j-1]`): this character is shared. Emit it **once** and move diagonally to `(i-1, j-1)`.
2. **Mismatch, came from above** (`dp[i-1][j] > dp[i][j-1]`): `s1[i-1]` is not shared, so it must appear on its own. Emit it and move to `(i-1, j)`.
3. **Mismatch, otherwise**: emit `s2[j-1]` and move to `(i, j-1)`.
4. **Leftovers**: when `i` hits 0, the remaining prefix `s2[0..j-1]` still has to be emitted — dump it (and symmetrically for `j` hitting 0 with `s1`).
5. Reverse the collected characters at the end, since we built the answer back-to-front.

**Why the result is a valid supersequence.** Every step emits a character and consumes at least one of the two strings' pending characters, never skipping one without emitting it. So reading the finished string left to right, both `s1` and `s2` can be traced out in order. And each match emits one character instead of two, so exactly `LCS` characters are saved — the length hits the `n + m - LCS` optimum.

**Dry run on s1 = "brute", s2 = "groot".** The LCS is `"rt"` (length 2), so the answer has length `5 + 5 - 2 = 8`. Backtracking from `(5,5)`:

| cell | s1[i-1] vs s2[j-1] | decision | emitted |
|---|---|---|---|
| (5,5) | `e` vs `t` | mismatch, `dp[4][5]=2 > dp[5][4]=1` → up | `e` |
| (4,5) | `t` vs `t` | match → diagonal | `t` |
| (3,4) | `u` vs `o` | mismatch, go left | `o` |
| (3,3) | `u` vs `o` | mismatch, go left | `o` |
| (3,2) | `u` vs `r` | mismatch, `dp[2][2]=1 > dp[3][1]=0` → up | `u` |
| (2,2) | `r` vs `r` | match → diagonal | `r` |
| (1,1) | `b` vs `g` | mismatch, tie → left | `g` |

Now `j == 0` with `i == 1`, so the drain loop emits the leftover `b`. Collected `"etoourgb"`, reversed → `"bgruoote"` — 8 characters, containing both inputs as subsequences. The `r` and `t` were each emitted once (shared), everything else once per string.

- **Time:** O(n · m) to build the table, O(n + m) to walk it
- **Space:** O(n · m) for the table (needed for reconstruction)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    string shortestCommonSupersequence(string s1, string s2) {
        int n = s1.size(), m = s2.size();
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));

        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= m; j++)
                dp[i][j] = (s1[i - 1] == s2[j - 1])
                         ? 1 + dp[i - 1][j - 1]
                         : max(dp[i - 1][j], dp[i][j - 1]);

        string res;
        int i = n, j = m;
        while (i > 0 && j > 0) {
            if (s1[i - 1] == s2[j - 1]) {
                res.push_back(s1[i - 1]);          // shared: emit once
                i--; j--;
            } else if (dp[i - 1][j] > dp[i][j - 1]) {
                res.push_back(s1[i - 1]);
                i--;
            } else {
                res.push_back(s2[j - 1]);
                j--;
            }
        }
        while (i > 0) { res.push_back(s1[--i]); }  // leftover prefix of s1
        while (j > 0) { res.push_back(s2[--j]); }  // leftover prefix of s2

        reverse(res.begin(), res.end());
        return res;
    }
};
```

### Java
```java
class Solution {
    public String shortestCommonSupersequence(String s1, String s2) {
        int n = s1.length(), m = s2.length();
        int[][] dp = new int[n + 1][m + 1];

        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= m; j++)
                dp[i][j] = (s1.charAt(i - 1) == s2.charAt(j - 1))
                         ? 1 + dp[i - 1][j - 1]
                         : Math.max(dp[i - 1][j], dp[i][j - 1]);

        StringBuilder sb = new StringBuilder();
        int i = n, j = m;
        while (i > 0 && j > 0) {
            if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                sb.append(s1.charAt(i - 1));
                i--; j--;
            } else if (dp[i - 1][j] > dp[i][j - 1]) {
                sb.append(s1.charAt(i - 1));
                i--;
            } else {
                sb.append(s2.charAt(j - 1));
                j--;
            }
        }
        while (i > 0) sb.append(s1.charAt(--i));
        while (j > 0) sb.append(s2.charAt(--j));

        return sb.reverse().toString();
    }
}
```

### Python
```python
class Solution:
    def shortestCommonSupersequence(self, s1, s2):
        n, m = len(s1), len(s2)
        dp = [[0] * (m + 1) for _ in range(n + 1)]

        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if s1[i - 1] == s2[j - 1]:
                    dp[i][j] = 1 + dp[i - 1][j - 1]
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

        res = []
        i, j = n, m
        while i > 0 and j > 0:
            if s1[i - 1] == s2[j - 1]:
                res.append(s1[i - 1])
                i -= 1
                j -= 1
            elif dp[i - 1][j] > dp[i][j - 1]:
                res.append(s1[i - 1])
                i -= 1
            else:
                res.append(s2[j - 1])
                j -= 1

        while i > 0:
            i -= 1
            res.append(s1[i])
        while j > 0:
            j -= 1
            res.append(s2[j])

        return ''.join(reversed(res))
```

## Key Takeaways
- Length is `n + m - LCS`: shared characters are exactly a common subsequence, so the longest one saves the most.
- The construction is LCS backtracking with one change — on a mismatch you *emit* the skipped character instead of discarding it.
- Do not forget the two drain loops: when one index reaches 0, the other string's remaining prefix still has to be appended.
- The full O(n·m) table is required; the rolling-row optimisation only works when you need the length alone.
