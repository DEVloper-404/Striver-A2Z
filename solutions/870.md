# N Queen

**Difficulty:** Hard  ·  **Topic:** Recursion [PatternWise] › Trying out all Combos / Hard

## Problem
Place `n` queens on an `n x n` chessboard so that no two queens attack each other — no two share a row, a column, or a diagonal. Return every distinct board, where each board is a list of `n` strings and a queen is shown as `'Q'`, an empty cell as `'.'`.

Input: `n = 4`
Output: `[[".Q..","...Q","Q...","..Q."], ["..Q.","Q...","...Q",".Q.."]]`

## Approach 1: Backtrack column by column with an explicit safety scan
Place one queen per column, left to right. For column `c`, try every row `r`; before placing, scan the already-filled part of the board to the left along the row, the upper-left diagonal and the lower-left diagonal. If no queen is found, place the queen and recurse to column `c + 1`, then remove it and try the next row. When `c == n` we have a full board, so record it.

The safety check is O(n) per attempt, which is fine but can be made O(1).
- **Time:** O(n! · n) — roughly `n!` placements, each verified in O(n)
- **Space:** O(n²) for the board plus O(n) recursion

## Approach 2: Backtracking with O(1) attack lookups (Optimal)
Keep three boolean arrays instead of scanning:
- `rowUsed[r]` — is there a queen in row `r`?
- `diag1[r + c]` — anti-diagonal (`r + c` is constant along it), size `2n - 1`.
- `diag2[r - c + n - 1]` — main diagonal (`r - c` is constant), shifted so the index is non-negative.

Placing a queen at `(r, c)` sets all three; removing it clears them. The recursion is otherwise identical, and because we advance one column per level, columns are never in conflict.
- **Time:** O(n!) — the branching shrinks with every level
- **Space:** O(n) for the marker arrays and recursion depth, plus the output

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
    int n;
    vector<bool> rowUsed, d1, d2;
    vector<string> board;
    vector<vector<string>> out;

    void place(int c) {
        if (c == n) { out.push_back(board); return; }
        for (int r = 0; r < n; ++r) {
            int a = r + c, b = r - c + n - 1;
            if (rowUsed[r] || d1[a] || d2[b]) continue;
            rowUsed[r] = d1[a] = d2[b] = true;
            board[r][c] = 'Q';
            place(c + 1);
            board[r][c] = '.';
            rowUsed[r] = d1[a] = d2[b] = false;
        }
    }
public:
    vector<vector<string>> solveNQueens(int N) {
        n = N;
        rowUsed.assign(n, false);
        d1.assign(2 * n - 1, false);
        d2.assign(2 * n - 1, false);
        board.assign(n, string(n, '.'));
        place(0);
        return out;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private int n;
    private boolean[] rowUsed, d1, d2;
    private char[][] board;
    private List<List<String>> out = new ArrayList<>();

    public List<List<String>> solveNQueens(int N) {
        n = N;
        rowUsed = new boolean[n];
        d1 = new boolean[2 * n - 1];
        d2 = new boolean[2 * n - 1];
        board = new char[n][n];
        for (char[] row : board) Arrays.fill(row, '.');
        place(0);
        return out;
    }

    private void place(int c) {
        if (c == n) {
            List<String> snap = new ArrayList<>();
            for (char[] row : board) snap.add(new String(row));
            out.add(snap);
            return;
        }
        for (int r = 0; r < n; r++) {
            int a = r + c, b = r - c + n - 1;
            if (rowUsed[r] || d1[a] || d2[b]) continue;
            rowUsed[r] = d1[a] = d2[b] = true;
            board[r][c] = 'Q';
            place(c + 1);
            board[r][c] = '.';
            rowUsed[r] = d1[a] = d2[b] = false;
        }
    }
}
```

### Python
```python
from typing import List

class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        out = []
        board = [["."] * n for _ in range(n)]
        row_used = [False] * n
        d1 = [False] * (2 * n - 1)   # r + c
        d2 = [False] * (2 * n - 1)   # r - c + n - 1

        def place(c: int) -> None:
            if c == n:
                out.append(["".join(row) for row in board])
                return
            for r in range(n):
                a, b = r + c, r - c + n - 1
                if row_used[r] or d1[a] or d2[b]:
                    continue
                row_used[r] = d1[a] = d2[b] = True
                board[r][c] = "Q"
                place(c + 1)
                board[r][c] = "."
                row_used[r] = d1[a] = d2[b] = False

        place(0)
        return out
```

## Key Takeaways
- One queen per column (or per row) removes one constraint for free; the other three are tracked with boolean arrays.
- `r + c` identifies an anti-diagonal and `r - c` a main diagonal — shift the latter by `n - 1` to index an array.
- Always undo state (board cell and the three flags) when backtracking.
- `n = 2` and `n = 3` have no solutions; `n = 1` has exactly one.
