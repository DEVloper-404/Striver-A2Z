# Top K Frequent Elements

**Difficulty:** Medium  ·  **Topic:** Heaps [Learning, Medium, Hard Problems] › Hard Problems

## Problem
Given an integer array `nums` and an integer `k`, return the `k` values that appear most often. The answer may be in any order and is guaranteed to be unique (no ties at the boundary matter for the judge).

```
Input:  nums = [1, 1, 1, 2, 2, 3], k = 2
Output: [1, 2]
```

## Approach 1: Count and sort
Count occurrences with a hash map, copy the `(value, count)` pairs into a list, sort by count descending, and return the first `k` values. Simple and often fast enough, but sorting every distinct value is more than we need.
- **Time:** O(n log n)
- **Space:** O(n)

## Approach 2: Min-heap of size k
Count with a hash map, then stream the `(count, value)` pairs through a min-heap ordered by count. Whenever the heap exceeds `k` entries, pop the least frequent. After the pass the heap contains exactly the `k` most frequent values. With `d` distinct values:
- **Time:** O(n + d log k)
- **Space:** O(d + k)

## Approach 3: Bucket by frequency (optimal)
A count can never exceed `n`, so build an array of `n + 1` buckets where bucket `c` holds every value that occurs exactly `c` times. Walk the buckets from `n` down to `1`, collecting values until `k` have been gathered. No sorting or heap is needed.
- **Time:** O(n)
- **Space:** O(n)

The heap version is the one that belongs to this section, so it is the code shown below; the bucket method is included as an alternative function.

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    // Heap version: O(n + d log k)
    vector<int> topKFrequent(vector<int>& nums, int k) {
        unordered_map<int, int> freq;
        for (int x : nums) freq[x]++;

        // min-heap on (count, value)
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> minHeap;
        for (auto& [value, count] : freq) {
            minHeap.push({count, value});
            if ((int)minHeap.size() > k) minHeap.pop();
        }

        vector<int> result;
        while (!minHeap.empty()) {
            result.push_back(minHeap.top().second);
            minHeap.pop();
        }
        return result;
    }

    // Bucket version: O(n)
    vector<int> topKFrequentBucket(vector<int>& nums, int k) {
        unordered_map<int, int> freq;
        for (int x : nums) freq[x]++;

        vector<vector<int>> buckets(nums.size() + 1);
        for (auto& [value, count] : freq) buckets[count].push_back(value);

        vector<int> result;
        for (int c = nums.size(); c >= 1 && (int)result.size() < k; c--) {
            for (int v : buckets[c]) {
                result.push_back(v);
                if ((int)result.size() == k) break;
            }
        }
        return result;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) freq.merge(x, 1, Integer::sum);

        // min-heap on count: entries are {count, value}
        PriorityQueue<int[]> minHeap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            minHeap.offer(new int[]{e.getValue(), e.getKey()});
            if (minHeap.size() > k) minHeap.poll();
        }

        int[] result = new int[k];
        for (int i = 0; i < k; i++) result[i] = minHeap.poll()[1];
        return result;
    }

    public int[] topKFrequentBucket(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) freq.merge(x, 1, Integer::sum);

        List<List<Integer>> buckets = new ArrayList<>();
        for (int i = 0; i <= nums.length; i++) buckets.add(new ArrayList<>());
        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            buckets.get(e.getValue()).add(e.getKey());
        }

        int[] result = new int[k];
        int idx = 0;
        for (int c = nums.length; c >= 1 && idx < k; c--) {
            for (int v : buckets.get(c)) {
                result[idx++] = v;
                if (idx == k) break;
            }
        }
        return result;
    }
}
```

### Python
```python
import heapq
from collections import Counter
from typing import List


class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        freq = Counter(nums)
        min_heap = []
        for value, count in freq.items():
            heapq.heappush(min_heap, (count, value))
            if len(min_heap) > k:
                heapq.heappop(min_heap)
        return [value for _, value in min_heap]

    def topKFrequentBucket(self, nums: List[int], k: int) -> List[int]:
        freq = Counter(nums)
        buckets = [[] for _ in range(len(nums) + 1)]
        for value, count in freq.items():
            buckets[count].append(value)

        result = []
        for c in range(len(nums), 0, -1):
            for v in buckets[c]:
                result.append(v)
                if len(result) == k:
                    return result
        return result
```

## Key Takeaways
- "Top k by frequency" is "k-th largest" applied to counts: a min-heap capped at `k` keeps the winners.
- Order the heap by count, not by value; put the count first in the pair/tuple so the default comparison does the right thing.
- Bucket sort exploits that counts are bounded by `n`, achieving linear time without any comparison-based structure.
- When `k` equals the number of distinct values, every value is returned; both versions handle that naturally.
