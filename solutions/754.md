# Minimum Window Subsequence

**Difficulty:** Hard  ·  **Topic:** Sliding Window & Two Pointer Combined Problems › Hard Problems

## Problem
Given strings `s1` and `s2`, find the shortest contiguous substring `w` of `s1` such that `s2` is a *subsequence* of `w` (characters of `s2` appear in `w` in order, not necessarily adjacent). If there is no such window return `""`; if several windows tie in length return the one that starts earliest.

Input: `s1 = "abcdebdde", s2 = "bde"`
Output: `"bcde"` (`"bdde"` also has length 4 but starts later)

## Approach 1: Brute Force
For every start index `i` in `s1`, greedily match `s2` forward: walk `j` from `i` and advance a pointer into `s2` whenever characters agree. If the pointer reaches the end of `s2` at position `j`, the window `[i, j]` is a candidate. Take the shortest, earliest.

- **Time:** O(n · m) worst case per start, so O(n² ) in practice, where n = |s1| and m = |s2|
- **Space:** O(1)

## Approach 2: Forward Match then Backward Shrink (Optimal)
Scan `s1` with pointer `i` and match `s2` forward.

1. When the forward match completes at index `end` (the character matching the last letter of `s2`), walk backwards from `end` matching `s2` from its last letter to its first. The index where the backward match finishes is `start`; the window `[start, end]` is the shortest window ending at `end`, because the backward pass takes the latest possible position for every letter of `s2`.
2. Record the window if it is shorter than the best so far (strictly shorter, to preserve the earliest tie-break).
3. Restart the forward scan at `start + 1`, since any better window must begin after `start`.

Each forward/backward pair scans a window whose left boundary then advances, so the total work is bounded by O(n · m) and in practice much less.

- **Time:** O(n · m)
- **Space:** O(1)

## Approach 3: Dynamic Programming
`dp[j]` = the starting index of the best window such that `s2[0..j)` is a subsequence of `s1` ending at the current index. Process `s1` left to right; when `s1[i] == s2[j]`, `dp[j+1] = dp[j]` (for `j = 0`, `dp[1] = i`). Whenever `dp[m]` is set, `[dp[m], i]` is a candidate window. Iterate `j` from high to low so each `s1[i]` is used once per row.

- **Time:** O(n · m)
- **Space:** O(m)

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Solution {
public:
    string minWindow(string s1, string s2) {
        int n = s1.size(), m = s2.size();
        int bestStart = -1, bestLen = n + 1;
        int i = 0;
        while (i < n) {
            int j = 0;
            // forward: find a window ending at some index that contains s2 as subsequence
            while (i < n) {
                if (s1[i] == s2[j]) {
                    j++;
                    if (j == m) break;
                }
                i++;
            }
            if (i == n) break;                 // ran out without completing s2
            int end = i;
            j = m - 1;
            // backward: shrink to the latest possible start
            while (j >= 0) {
                if (s1[i] == s2[j]) j--;
                i--;
            }
            int start = i + 1;
            if (end - start + 1 < bestLen) {
                bestLen = end - start + 1;
                bestStart = start;
            }
            i = start + 1;
        }
        return bestStart == -1 ? "" : s1.substr(bestStart, bestLen);
    }
};
```

                    j -= 1
                i -= 1
            start = i + 1
            if end - start + 1 < best_len:
                best_len = end - start + 1
                best_start = start
            i = start + 1

## Key Takeaways
- Subsequence matching is order-sensitive, so a frequency-count window (as in Minimum Window Substring) does not apply; use forward-then-backward matching instead.
- The backward pass yields the tightest window for a given end; restarting just after its start guarantees no candidate is skipped.
- Use strict `<` when updating so the earliest window wins ties; handle "no window found" by returning `""`.
