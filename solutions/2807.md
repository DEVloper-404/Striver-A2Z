# Print all Divisors

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Know Basic Maths

## Problem
Given a positive integer `n`, return all of its divisors — every integer `d` with `1 ≤ d ≤ n` such that `n % d == 0` — in ascending order.

Input: `n = 36`
Output: `1 2 3 4 6 9 12 18 36`

Input: `n = 7`
Output: `1 7`

## Approach 1: Test every number up to n
Loop `d` from 1 to `n` and keep every `d` that divides `n`. Output is naturally sorted.

- **Time:** O(n)
- **Space:** O(1) extra (besides the output)

## Approach 2: Loop only up to √n
Divisors come in pairs: if `d` divides `n`, so does `n / d`, and one of the two is at most `√n`. So loop `d` from 1 while `d * d ≤ n`; whenever `d` divides `n` record both `d` and `n / d` (only once when they are equal, i.e. `n` is a perfect square). Collect the results and sort them, or push the small divisors into one list and the large ones into another and concatenate the second in reverse to get sorted output without a sort.

- **Time:** O(√n) to find divisors; O(k log k) to sort k divisors if you sort (k is tiny compared with n)
- **Space:** O(k) for the output

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    vector<int> printDivisors(int n) {
        vector<int> small, large;
        for (int d = 1; (long long)d * d <= n; d++) {
            if (n % d == 0) {
                small.push_back(d);
                if (d != n / d) large.push_back(n / d);
            }
        }
        // large holds the big partners in descending order; append them reversed
        for (int i = (int)large.size() - 1; i >= 0; i--) small.push_back(large[i]);
        return small;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public List<Integer> printDivisors(int n) {
        List<Integer> small = new ArrayList<>();
        List<Integer> large = new ArrayList<>();
        for (int d = 1; (long) d * d <= n; d++) {
            if (n % d == 0) {
                small.add(d);
                if (d != n / d) large.add(n / d);
            }
        }
        for (int i = large.size() - 1; i >= 0; i--) small.add(large.get(i));
        return small;
    }
}
```

### Python
```python
class Solution:
    def printDivisors(self, n: int) -> list[int]:
        small, large = [], []
        d = 1
        while d * d <= n:
            if n % d == 0:
                small.append(d)
                if d != n // d:
                    large.append(n // d)
            d += 1
        return small + large[::-1]
```

## Key Takeaways
- Divisors pair up as `(d, n / d)`, so scanning to `√n` finds all of them.
- Use `d * d <= n` instead of `d <= sqrt(n)` to stay in integer arithmetic; cast to 64-bit if `n` is near the `int` limit.
- Add the paired divisor only when `d != n / d` to avoid duplicating the square root of a perfect square.
- Keeping two lists (small ascending, large descending) yields sorted output with no explicit sort.
