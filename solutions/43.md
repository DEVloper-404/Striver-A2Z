# Second Largest Element

**Difficulty:** Easy  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Easy

## Problem
Given an array of `n` integers, find the second largest **distinct** value. If no such value exists (all elements equal or `n < 2`), return `-1`. The companion problem asks for the second smallest in the same way.

Input: `arr = [1, 2, 4, 7, 7, 5]`
Output: `6` (second largest is `5`, second smallest is `2`; this file focuses on the largest side)

## Approach 1: Sort and Walk Back
Sort ascending. The largest is `arr[n-1]`. Walk leftwards from `n-2` until you find a value strictly smaller than the largest; that is the second largest. If you fall off the array, return `-1`.

- **Time:** O(n log n)
- **Space:** O(1) beyond sorting.

## Approach 2: Two Passes
First pass finds the maximum. Second pass finds the largest value that is strictly less than that maximum. Simple and correct, but touches the array twice.

- **Time:** O(n)
- **Space:** O(1)

## Approach 3: Single Pass with Two Trackers (Optimal)
Maintain `first` (largest so far) and `second` (largest so far that is strictly smaller than `first`). For each element `x`:

- If `x > first`: the old `first` becomes `second`, and `x` becomes `first`.
- Else if `x < first` and `x > second`: `x` becomes the new `second`.
- Else (`x == first` or `x <= second`): ignore it.

Initialise both to the smallest possible value (or track with "unset" markers) so that the very first element becomes `first`. The `x < first` check is what handles duplicates of the maximum. The second smallest is symmetric with the comparisons flipped.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <climits>
using namespace std;

class Solution {
public:
    int secondLargest(vector<int>& arr) {
        long long first = LLONG_MIN, second = LLONG_MIN;
        for (int x : arr) {
            if (x > first) {
                second = first;
                first = x;
            } else if (x < first && x > second) {
                second = x;
            }
        }
        return second == LLONG_MIN ? -1 : (int)second;
    }

    int secondSmallest(vector<int>& arr) {
        long long first = LLONG_MAX, second = LLONG_MAX;
        for (int x : arr) {
            if (x < first) {
                second = first;
                first = x;
            } else if (x > first && x < second) {
                second = x;
            }
        }
        return second == LLONG_MAX ? -1 : (int)second;
    }
};
```

### Python
```python
class Solution:
    def secondLargest(self, arr: list[int]) -> int:
        first = second = None
        for x in arr:
            if first is None or x > first:
                second, first = first, x
            elif x != first and (second is None or x > second):
                second = x
        return -1 if second is None else second

    def secondSmallest(self, arr: list[int]) -> int:
        first = second = None
        for x in arr:
            if first is None or x < first:
                second, first = first, x
            elif x != first and (second is None or x < second):
                second = x
        return -1 if second is None else second
```

## Key Takeaways
- Two running trackers (`first`, `second`) solve it in one pass; the `x < first` guard is what makes duplicates of the max not count.
- Use a wider type or an "unset" marker for the initial values so `INT_MIN` in the input cannot be confused with "nothing found".
- Edge cases: `[7, 7, 7]` and single-element arrays must return `-1`.
