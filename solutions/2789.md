# Preorder, Inorder, and Postorder Traversal in one Traversal

**Difficulty:** Easy  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Traversals

## Problem
Given the root of a binary tree, compute its preorder, inorder and postorder sequences with a single pass over the tree. Return three lists. The tree must be visited only once, so running three independent traversals is not acceptable.

Input: `root = [1, 2, 3, 4, 5, null, 6]`
```
      1
     / \
    2   3
   / \   \
  4   5   6
```
Output:
Preorder `[1, 2, 4, 5, 3, 6]`, Inorder `[4, 2, 5, 1, 3, 6]`, Postorder `[4, 5, 2, 6, 3, 1]`

## Approach 1: Three passes
Run the recursive preorder, inorder and postorder routines one after another. Correct and simple, but touches the tree three times, which the problem forbids.
- **Time:** O(n) (three separate linear passes)
- **Space:** O(h) recursion stack

## Approach 2: Single recursive pass
One recursive function can fill all three lists at once, since a DFS naturally has three "moments" per node: before the left call, between the calls, and after the right call. Append to `pre` at the start, to `in` between the recursive calls, and to `post` at the end. This is a genuine one-traversal solution but still depends on the call stack.
- **Time:** O(n)
- **Space:** O(h) recursion stack

## Approach 3: Iterative with a stack of (node, count) pairs (optimal)
Turn the three "moments" into an explicit counter. Push `(root, 1)`. While the stack is non-empty look at the top pair `(node, c)`:

- `c == 1`: this is the first time the node is seen, so add it to **preorder**. Increment `c` to 2 and push `(node.left, 1)` if the left child exists.
- `c == 2`: the left subtree has been fully handled, so add the node to **inorder**. Increment `c` to 3 and push `(node.right, 1)` if the right child exists.
- `c == 3`: the right subtree is done, so add the node to **postorder** and pop it.

The counter is stored with the node on the stack, so when control returns to that node after a child subtree completes it picks up in the correct phase. Every node is pushed once, goes through three constant-time phases, and is popped once.
- **Time:** O(n)
- **Space:** O(h) for the stack (plus O(n) for the three answers)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stack>
#include <utility>
using namespace std;

// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition

class Solution {
public:
    // returns {preorder, inorder, postorder}
    vector<vector<int>> traversals(TreeNode* root) {
        vector<int> pre, in, post;
        if (!root) return {pre, in, post};

        stack<pair<TreeNode*, int>> st;
        st.push({root, 1});
        while (!st.empty()) {
            pair<TreeNode*, int>& top = st.top();
            TreeNode* node = top.first;
            if (top.second == 1) {
                pre.push_back(node->val);
                top.second = 2;
                if (node->left) st.push({node->left, 1});
            } else if (top.second == 2) {
                in.push_back(node->val);
                top.second = 3;
                if (node->right) st.push({node->right, 1});
            } else {
                post.push_back(node->val);
                st.pop();
            }
        }
        return {pre, in, post};
    }
};
```

### Java
```java
import java.util.*;

// class TreeNode { int val; TreeNode left, right; ... } — standard definition

class Solution {
    private static class Frame {
        TreeNode node;
        int count;
        Frame(TreeNode n) { node = n; count = 1; }
    }

    // returns [preorder, inorder, postorder]
    public List<List<Integer>> traversals(TreeNode root) {
        List<Integer> pre = new ArrayList<>();
        List<Integer> in = new ArrayList<>();
        List<Integer> post = new ArrayList<>();
        if (root == null) return Arrays.asList(pre, in, post);

        Deque<Frame> st = new ArrayDeque<>();
        st.push(new Frame(root));
        while (!st.isEmpty()) {
            Frame top = st.peek();
            TreeNode node = top.node;
            if (top.count == 1) {
                pre.add(node.val);
                top.count = 2;
                if (node.left != null) st.push(new Frame(node.left));
            } else if (top.count == 2) {
                in.add(node.val);
                top.count = 3;
                if (node.right != null) st.push(new Frame(node.right));
            } else {
                post.add(node.val);
                st.pop();
            }
        }
        return Arrays.asList(pre, in, post);
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def traversals(self, root):
        """Returns (preorder, inorder, postorder)."""
        pre, ino, post = [], [], []
        if root is None:
            return pre, ino, post

        stack = [[root, 1]]              # [node, count]
        while stack:
            node, count = stack[-1]
            if count == 1:
                pre.append(node.val)
                stack[-1][1] = 2
                if node.left:
                    stack.append([node.left, 1])
            elif count == 2:
                ino.append(node.val)
                stack[-1][1] = 3
                if node.right:
                    stack.append([node.right, 1])
            else:
                post.append(node.val)
                stack.pop()
        return pre, ino, post
```

## Key Takeaways
- Every node passes through three phases in a DFS: first visit (pre), after left (in), after right (post). Encoding the phase as a counter next to the node on the stack lets one pass emit all three orders.
- Only phase 3 pops the node; phases 1 and 2 leave it on the stack with an updated counter so it resumes after the child subtree finishes.
- Push a child with counter 1 so it starts its own three-phase cycle.
- Handles empty trees (three empty lists) and single-node trees (`[v]` three times) without special cases beyond the initial null check.
