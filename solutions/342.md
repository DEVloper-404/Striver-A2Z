# Reverse an array

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Learn Basic Recursion

## Problem
Given an array `arr` of `n` elements, reverse it in place so the first element becomes the last, the second becomes the second-to-last, and so on.

Input: `arr = [1, 2, 3, 4, 5]`
Output: `[5, 4, 3, 2, 1]`

Input: `arr = [10, 20]`
Output: `[20, 10]`

## Approach 1: Copy into a new array
Create a second array and fill it from the end of the original. Correct, but uses extra memory and is not in place.

- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Two pointers (iterative)
Keep `l = 0` and `r = n - 1`. Swap `arr[l]` and `arr[r]`, move `l` right and `r` left, stop when they meet or cross. Each element is touched at most once.

- **Time:** O(n)
- **Space:** O(1)

## Approach 3: Two-pointer recursion
The same idea written recursively: `reverse(l, r)` swaps the ends and calls `reverse(l + 1, r - 1)`; base case `l >= r`. You can also use a single index `i` and swap `arr[i]` with `arr[n - 1 - i]` while `i < n / 2`.

- **Time:** O(n)
- **Space:** O(n) recursion depth (n / 2 frames)

## Code (Optimal)

The two-pointer swap is optimal; the recursive form is what this section practises, so both are shown.

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    // Recursive two-pointer version
    void reverseArray(vector<int>& arr) {
        helper(arr, 0, (int)arr.size() - 1);
    }

    // Iterative version, O(1) space
    void reverseIterative(vector<int>& arr) {
        int l = 0, r = (int)arr.size() - 1;
        while (l < r) {
            swap(arr[l], arr[r]);
            l++; r--;
        }
    }

private:
    void helper(vector<int>& arr, int l, int r) {
        if (l >= r) return;
        swap(arr[l], arr[r]);
        helper(arr, l + 1, r - 1);
    }
};
```

### Java
```java
class Solution {
    // Recursive two-pointer version
    public void reverseArray(int[] arr) {
        helper(arr, 0, arr.length - 1);
    }

    // Iterative version, O(1) space
    public void reverseIterative(int[] arr) {
        int l = 0, r = arr.length - 1;
        while (l < r) {
            int t = arr[l]; arr[l] = arr[r]; arr[r] = t;
            l++; r--;
        }
    }

    private void helper(int[] arr, int l, int r) {
        if (l >= r) return;
        int t = arr[l]; arr[l] = arr[r]; arr[r] = t;
        helper(arr, l + 1, r - 1);
    }
}
```

### Python
```python
class Solution:
    # Recursive two-pointer version
    def reverseArray(self, arr: list[int]) -> None:
        self._helper(arr, 0, len(arr) - 1)

    # Iterative version, O(1) space
    def reverseIterative(self, arr: list[int]) -> None:
        l, r = 0, len(arr) - 1
        while l < r:
            arr[l], arr[r] = arr[r], arr[l]
            l += 1
            r -= 1

    def _helper(self, arr: list[int], l: int, r: int) -> None:
        if l >= r:
            return
        arr[l], arr[r] = arr[r], arr[l]
        self._helper(arr, l + 1, r - 1)
```

## Key Takeaways
- Two pointers closing in from both ends is the standard in-place reversal; the recursion just replaces the loop.
- Base case is `l >= r` — an odd-length array leaves the middle element untouched.
- Only `n / 2` swaps are needed; swapping all `n` positions would reverse the array twice and restore it.
