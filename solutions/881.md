# Recursive Bubble Sort

**Difficulty:** Easy  ·  **Topic:** Learn Important Sorting Techniques › Sorting-II

## Problem
Sort an array of `n` integers in non-decreasing order using bubble sort, but replace the outer loop with recursion. Each recursive call is responsible for one full sweep of adjacent comparisons.

Input: `arr = [13, 46, 24, 52, 20, 9]`
Output: `[9, 13, 20, 24, 46, 52]`

## Approach 1: Recursive Bubble Sort
In iterative bubble sort, pass number `k` sweeps `arr[0..n-k]` and pushes the largest of that range to index `n-k`. The recursion simply encodes "do one sweep over the first `n` elements, then recurse on the first `n-1` elements".

1. Base case: if `n <= 1`, a range of one element is already sorted, so return.
2. Do one sweep over indices `0..n-2`, swapping any adjacent pair that is out of order. Remember whether any swap happened.
3. If no swap happened, the range is sorted and we can stop early.
4. Otherwise, recurse with `n - 1`.

The work is identical to the iterative version; only the bookkeeping of the outer loop moves onto the call stack. The recursion depth is at most `n`, so this is not suitable for very large arrays, but it is a good exercise in translating a loop into recursion.

- **Time:** O(n) best case (already sorted), O(n²) average and worst case.
- **Space:** O(n) for the recursion stack.

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <utility>
using namespace std;

class Solution {
    void bubble(vector<int>& arr, int n) {
        if (n <= 1) return;
        bool swapped = false;
        for (int j = 0; j < n - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) return;
        bubble(arr, n - 1);
    }

public:
    vector<int> bubbleSort(vector<int>& arr) {
        bubble(arr, arr.size());
        return arr;
    }
};
```

### Java
```java
class Solution {
    private void bubble(int[] arr, int n) {
        if (n <= 1) return;
        boolean swapped = false;
        for (int j = 0; j < n - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int tmp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = tmp;
                swapped = true;
            }
        }
        if (!swapped) return;
        bubble(arr, n - 1);
    }

    public int[] bubbleSort(int[] arr) {
        bubble(arr, arr.length);
        return arr;
    }
}
```

### Python
```python
class Solution:
    def bubbleSort(self, arr: list[int]) -> list[int]:
        def bubble(n: int) -> None:
            if n <= 1:
                return
            swapped = False
            for j in range(n - 1):
                if arr[j] > arr[j + 1]:
                    arr[j], arr[j + 1] = arr[j + 1], arr[j]
                    swapped = True
            if not swapped:
                return
            bubble(n - 1)

        bubble(len(arr))
        return arr
```

## Key Takeaways
- Recursion replaces the outer loop: each call does one sweep and then recurses on a range one shorter.
- The base case `n <= 1` and the "no swap" early exit both stop the recursion.
- Same O(n²) comparisons as the iterative version but costs O(n) stack space — prefer the loop in production.
