# Rearrange array elements by sign

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Medium

## Problem
You are given an array with an equal number of positive and negative integers (no zeros). Rearrange it so that the signs alternate, starting with a positive number, while keeping the relative order of the positives among themselves and the negatives among themselves.

```
Input:  nums = [3, 1, -2, -5, 2, -4]
Output: [3, -2, 1, -5, 2, -4]
```

## Approach 1: Separate Lists Then Merge
Collect all positives into one list and all negatives into another (this preserves relative order). Then overwrite the array: position `2k` gets the k-th positive, position `2k+1` gets the k-th negative. This takes two passes plus a merge pass.
- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Direct Placement (Optimal)
Because counts are equal, the final layout is fixed: positives live at even indices, negatives at odd indices. So keep two write pointers into a fresh result array, `posIdx = 0` and `negIdx = 1`. Scan the input once; drop each positive at `posIdx` (then `posIdx += 2`) and each negative at `negIdx` (then `negIdx += 2`). Relative order is preserved because we scan left to right, and only one pass is needed.

Variant with unequal counts: build the two lists (Approach 1), interleave as far as the shorter list allows, then append the leftovers of the longer list at the end.
- **Time:** O(n)
- **Space:** O(n) for the output array (the problem asks for a new array; in-place with order preservation is not O(n))

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> rearrangeArray(vector<int>& nums) {
        int n = (int)nums.size();
        vector<int> res(n);
        int posIdx = 0, negIdx = 1;
        for (int x : nums) {
            if (x > 0) { res[posIdx] = x; posIdx += 2; }
            else       { res[negIdx] = x; negIdx += 2; }
        }
        return res;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def rearrangeArray(self, nums: List[int]) -> List[int]:
        res = [0] * len(nums)
        pos_idx, neg_idx = 0, 1
        for x in nums:
            if x > 0:
                res[pos_idx] = x
                pos_idx += 2
            else:
                res[neg_idx] = x
                neg_idx += 2
        return res
```

## Key Takeaways
- When the target layout is known in advance, write directly to fixed slots instead of separating and merging.
- Order preservation comes for free from a single left-to-right scan.
- If counts are not equal, interleave the two lists as far as possible and append the remainder.
- The in-place O(1)-space version (swapping elements) breaks relative order, so it only fits problems that do not require it.
