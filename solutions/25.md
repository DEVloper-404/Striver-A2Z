# Merge two sorted arrays without extra space

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Hard

## Problem
Given two sorted integer arrays `a` (length n) and `b` (length m), rearrange the elements in place so that the n smallest values sit in `a` (sorted) and the m largest values sit in `b` (sorted). You may not allocate another array of size n + m.

Input: `a = [1, 4, 8, 10]`, `b = [2, 3, 9]`
Output: `a = [1, 2, 3, 4]`, `b = [8, 9, 10]`

The LeetCode variant (`nums1` has trailing zeros of length m as buffer) is the same idea done with a three-pointer merge from the back; both versions are covered below.

## Approach 1: Merge into a temporary array
Standard two-pointer merge into a buffer of size n + m, then copy the first n back into `a` and the rest into `b`. Correct but violates the no-extra-space requirement.
- **Time:** O(n + m)
- **Space:** O(n + m)

## Approach 2: Swap across the boundary, then sort both
Compare `a`'s largest with `b`'s smallest. While `a[i] > b[j]`, swap them and move `i` left / `j` right. After this, every element of `a` is `<=` every element of `b`, but each array is internally unsorted, so sort both.
- **Time:** O(min(n, m) + n log n + m log m)
- **Space:** O(1)

## Approach 3: Gap method (Shell-sort style) (Optimal)
Treat the two arrays as one virtual array of length n + m. Start with `gap = ceil((n+m)/2)`, compare every pair of positions `gap` apart and swap if out of order, then shrink `gap = ceil(gap/2)` until `gap` becomes 1 and one final pass runs. This is the same insight as Shell sort: comparing far-apart elements first moves values most of the way to their final home cheaply, and the final gap-1 pass finishes it.

Index mapping: virtual index `x < n` refers to `a[x]`, otherwise `b[x - n]`.

- **Time:** O((n + m) · log(n + m))
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <utility>
using namespace std;

class Solution {
    static void swapIfGreater(vector<int>& a, vector<int>& b, int n, int i, int j) {
        int& x = (i < n) ? a[i] : b[i - n];
        int& y = (j < n) ? a[j] : b[j - n];
        if (x > y) std::swap(x, y);
    }
public:
    // In-place merge: after the call a holds the n smallest, b the m largest, both sorted.
    void mergeInPlace(vector<int>& a, vector<int>& b) {
        int n = a.size(), m = b.size();
        int total = n + m;
        int gap = (total + 1) / 2;
        while (gap > 0) {
            for (int i = 0; i + gap < total; ++i) swapIfGreater(a, b, n, i, i + gap);
            if (gap == 1) break;
            gap = (gap + 1) / 2;
        }
    }

    // LeetCode 88: nums1 has m valid entries followed by n slots of buffer.
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int i = m - 1, j = n - 1, k = m + n - 1;
        while (j >= 0) {
            if (i >= 0 && nums1[i] > nums2[j]) nums1[k--] = nums1[i--];
            else nums1[k--] = nums2[j--];
        }
    }
};
```

class Solution {
    private static void swapIfGreater(int[] a, int[] b, int n, int i, int j) {
        int x = (i < n) ? a[i] : b[i - n];
        int y = (j < n) ? a[j] : b[j - n];
        if (x > y) {
            if (i < n) a[i] = y; else b[i - n] = y;
            if (j < n) a[j] = x; else b[j - n] = x;
        }
    }

    public void mergeInPlace(int[] a, int[] b) {
        int n = a.length, m = b.length, total = n + m;
        int gap = (total + 1) / 2;
        while (gap > 0) {
            for (int i = 0; i + gap < total; i++) swapIfGreater(a, b, n, i, i + gap);
            if (gap == 1) break;
            gap = (gap + 1) / 2;
        }
    }

    public void merge(int[] nums1, int m, int[] nums2, int n) {

### Python
```python
from typing import List

class Solution:
    def mergeInPlace(self, a: List[int], b: List[int]) -> None:
        n, m = len(a), len(b)
        total = n + m

        def get(x):
            return a[x] if x < n else b[x - n]

        def put(x, v):
            if x < n:
                a[x] = v
            else:
                b[x - n] = v

        gap = (total + 1) // 2
        while gap > 0:
            for i in range(total - gap):
                j = i + gap
                if get(i) > get(j):
                    vi, vj = get(i), get(j)
                    put(i, vj)
                    put(j, vi)
            if gap == 1:
                break
            gap = (gap + 1) // 2

    # LeetCode 88 signature.
    def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
        i, j, k = m - 1, n - 1, m + n - 1
        while j >= 0:
            if i >= 0 and nums1[i] > nums2[j]:
                nums1[k] = nums1[i]
                i -= 1
            else:
                nums1[k] = nums2[j]
                j -= 1
            k -= 1
```

## Key Takeaways
- When a buffer exists (LeetCode 88), merge from the back so nothing valid is overwritten.
- Without a buffer, the gap method gives O((n+m) log(n+m)) with O(1) space by viewing both arrays as one virtual sequence.
- Use `ceil(gap/2)` when shrinking and make sure a gap-1 pass runs exactly once before stopping.
