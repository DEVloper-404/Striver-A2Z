# Print Prime Factors of a Number

**Difficulty:** Hard  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Advanced Maths

## Problem
Given a positive integer `n`, print every distinct prime that divides `n`, in increasing order. Only the primes themselves are needed here, not how many times each one divides `n`.

Input: `n = 60`
Output: `2 3 5`  (60 = 2 × 2 × 3 × 5)

## Approach 1: Brute Force (check every divisor for primality)
Loop `i` from 2 to `n`. If `i` divides `n`, run a separate primality test on `i` (trial division up to `sqrt(i)`) and print it when it passes. Simple, but you pay a primality test for each divisor and scan all the way up to `n`.
- **Time:** O(n · sqrt(n))
- **Space:** O(1)

## Approach 2: Better (divisors come in pairs)
Divisors pair up as `(i, n / i)`, so it is enough to loop `i` up to `sqrt(n)`, and for every hit test both `i` and `n / i` for primality. The candidate set shrinks from `n` numbers to roughly `2·sqrt(n)`, but every candidate still needs its own `sqrt` primality test. Also the output needs sorting since the pairs are discovered out of order.
- **Time:** O(sqrt(n) · sqrt(n)) = O(n) in the worst case, typically much less
- **Space:** O(number of divisors)

## Approach 3: Optimal (divide out each factor)
Key observation: if you loop `i` from 2 upward and, whenever `i` divides `n`, keep dividing `n` by `i` until it no longer does, then every `i` that ever divides `n` must be prime. Why? Any composite `i = a·b` has a smaller prime factor `a` that was already fully divided out before the loop reached `i`. So no explicit primality test is needed.

Loop only while `i * i <= n`; whatever remains in `n` after the loop (if greater than 1) is itself a prime and is the last factor.
- **Time:** O(sqrt(n))
- **Space:** O(1) extra (plus the output list)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

vector<int> primeFactors(int n) {
    vector<int> res;
    for (int i = 2; (long long)i * i <= n; i++) {
        if (n % i == 0) {
            res.push_back(i);
            while (n % i == 0) n /= i;
        }
    }
    if (n > 1) res.push_back(n);
    return res;
}
```

### Java
```java
import java.util.*;

class Solution {
    public List<Integer> primeFactors(int n) {
        List<Integer> res = new ArrayList<>();
        for (int i = 2; (long) i * i <= n; i++) {
            if (n % i == 0) {
                res.add(i);
                while (n % i == 0) n /= i;
            }
        }
        if (n > 1) res.add(n);
        return res;
    }
}
```

### Python
```python
def prime_factors(n: int) -> list[int]:
    res = []
    i = 2
    while i * i <= n:
        if n % i == 0:
            res.append(i)
            while n % i == 0:
                n //= i
        i += 1
    if n > 1:
        res.append(n)
    return res
```

## Key Takeaways
- Dividing a factor out completely guarantees that later divisors found are prime; no separate primality check is needed.
- Always handle the leftover: after the `sqrt` loop, a remaining `n > 1` is a prime factor (e.g. `n = 14` leaves 7).
- `i * i <= n` should use a wide type to avoid overflow near `INT_MAX`.
- For `n = 1` the result is empty; for a prime `n` the result is just `[n]`.
