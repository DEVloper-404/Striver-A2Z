# Count partitions with given difference

**Difficulty:** Hard  ·  **Topic:** Dynamic Programming [Patterns and Problems] › DP on Subsequences

## Problem
Given an array of non-negative integers and an integer `D`, count the number of ways to split the array into two subsets `S1` and `S2` (every element goes to exactly one side) such that `sum(S1) - sum(S2) == D` and `sum(S1) >= sum(S2)`. Return the count modulo 1e9+7.

```
Input:  arr = [1, 1, 2, 3], D = 1
Output: 3
Explanation: total = 7, so the two sides must be 4 and 3. The three splits are
             {1a, 3} | {1b, 2}, {1b, 3} | {1a, 2}, and {1a, 1b, 2} | {3}.
```

## Approach 1: Reduce two unknowns to one

**The key algebra.** A brute force over 2^n assignments works but is exponential. The real insight is that the two subset sums are not independent. Let `total = sum(arr)`, `s1 = sum(S1)`, `s2 = sum(S2)`. Then:

```
s1 + s2 = total
s1 - s2 = D
```

Add the two equations: `2·s1 = total + D`, and subtract them: `2·s2 = total - D`. Either form works; the smaller target is easier, so solve for `s2`:

```
s2 = (total - D) / 2
```

So counting partitions with difference `D` is *exactly* counting subsets whose sum equals `(total - D) / 2`. Every subset with that sum defines a valid partition (its complement automatically has sum `s2 + D`), and every valid partition gives exactly one such subset. The mapping is a bijection, so the counts are equal.

**Two feasibility checks before any DP:**
1. If `total - D < 0`, the required `s2` is negative — impossible, answer 0.
2. If `(total - D)` is odd, `s2` is not an integer — impossible, answer 0.

- **Time:** the reduction itself is O(n)
- **Space:** O(1)

## Approach 2: Optimal (count subsets with sum = target)

Now run the standard "count subsets with sum K" DP on `target = (total - D) / 2`.

`dp[i][t] = number of subsets of arr[0..i] with sum exactly t`

- **Transition:** `dp[i][t] = dp[i-1][t] + dp[i-1][t - arr[i]]` (second term only when `t >= arr[i]`), everything mod 1e9+7. Skipping the element leaves the target untouched; taking it consumes `arr[i]` from the target.
- **Base row, and why zeros matter here.** Set `dp[0][0] = 1` then `dp[0][arr[0]] += 1` when `arr[0] <= target`. If `arr[0] == 0` both writes land on cell 0 and it becomes 2 — which is right, because a zero can be placed on either side of the partition and still leaves the difference unchanged. Every zero in the array doubles the answer, and this base row plus the normal transition captures that automatically.
- **Answer:** `dp[n-1][target]`.

Only the previous row is ever read, so two arrays of size `target+1` suffice.

**Dry run on arr = [1, 1, 2, 3], D = 1.** `total = 7`, so `target = (7 - 1)/2 = 3`. Count subsets summing to 3:

| after element | t=0 | t=1 | t=2 | t=3 |
|---|---|---|---|---|
| 1 | 1 | 1 | 0 | 0 |
| 1 | 1 | 2 | 1 | 0 |
| 2 | 1 | 2 | 2 | 2 |
| 3 | 1 | 2 | 2 | 3 |

Answer 3: the subsets `{1(first), 2}`, `{1(second), 2}`, and `{3}`. Their complements have sums 4, 4, 4 — difference 1 in each case, as required.

- **Time:** O(n · target)
- **Space:** O(target)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int countPartitions(int n, int D, vector<int>& arr) {
        const int MOD = 1000000007;
        int total = 0;
        for (int x : arr) total += x;

        if (total - D < 0 || (total - D) % 2 != 0) return 0;
        int target = (total - D) / 2;

        vector<int> prev(target + 1, 0), cur(target + 1, 0);
        prev[0] = 1;
        if (arr[0] <= target) prev[arr[0]] = (prev[arr[0]] + 1) % MOD;

        for (int i = 1; i < n; i++) {
            for (int t = 0; t <= target; t++) {
                int notTake = prev[t];
                int take = (t >= arr[i]) ? prev[t - arr[i]] : 0;
                cur[t] = (notTake + take) % MOD;
            }
            prev = cur;
        }
        return prev[target];
    }
};
```

```java
class Solution {
    public int countPartitions(int n, int D, int[] arr) {
        final int MOD = 1000000007;
        int total = 0;
        for (int x : arr) total += x;

        if (total - D < 0 || (total - D) % 2 != 0) return 0;
        int target = (total - D) / 2;

        int[] prev = new int[target + 1];
        int[] cur = new int[target + 1];
        prev[0] = 1;
        if (arr[0] <= target) prev[arr[0]] = (prev[arr[0]] + 1) % MOD;

        for (int i = 1; i < n; i++) {
            for (int t = 0; t <= target; t++) {
                int notTake = prev[t];
                int take = (t >= arr[i]) ? prev[t - arr[i]] : 0;
                cur[t] = (notTake + take) % MOD;
            }
            int[] tmp = prev; prev = cur; cur = tmp;
        }
        return prev[target];
    }
}
```

### Python
```python
class Solution:
    def countPartitions(self, n, D, arr):
        MOD = 1000000007
        total = sum(arr)

        if total - D < 0 or (total - D) % 2 != 0:
            return 0
        target = (total - D) // 2

        prev = [0] * (target + 1)
        prev[0] = 1
        if arr[0] <= target:
            prev[arr[0]] = (prev[arr[0]] + 1) % MOD

        for i in range(1, n):
            cur = [0] * (target + 1)
            for t in range(target + 1):
                not_take = prev[t]
                take = prev[t - arr[i]] if t >= arr[i] else 0
                cur[t] = (not_take + take) % MOD
            prev = cur

        return prev[target]
```

## Key Takeaways
- The whole problem is one line of algebra: `s2 = (total - D) / 2` turns a two-subset condition into a single subset-sum count.
- Guard both `total - D < 0` and the parity of `total - D` before allocating the DP table.
- Zeros double the answer each time; the `+=` base row (rather than a plain assignment) is what makes that fall out naturally.
- Same skeleton as "Count subsets with sum K" and "Target sum" — recognising the reduction is the real work.
