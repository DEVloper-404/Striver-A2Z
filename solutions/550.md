# Non-overlapping Intervals

**Difficulty:** Medium  ·  **Topic:** Greedy Algorithms [Easy, Medium/Hard] › Medium/Hard

## Problem
Given an array of intervals `intervals[i] = [start, end]`, return the minimum number of intervals you must remove so that the remaining intervals do not overlap. Intervals that only touch at an endpoint (`[1,2]` and `[2,3]`) do **not** overlap.

Input: `intervals = [[1,2],[2,3],[3,4],[1,3]]`
Output: `1` (remove `[1,3]`)

Input: `intervals = [[1,2],[1,2],[1,2]]`
Output: `2`

## Approach 1: DP on sorted intervals (longest non-overlapping chain)
Sort by start. Let `dp[i]` be the maximum number of non-overlapping intervals in a chain that ends with interval `i`; `dp[i] = 1 + max(dp[j])` over all `j < i` with `end[j] <= start[i]`. The answer is `n - max(dp)`.
- **Time:** O(n²)
- **Space:** O(n)

## Approach 2: Greedy by earliest end (Optimal)
Removing the fewest intervals is the same as **keeping the most**, and that is the classic activity-selection problem: sort by end time and greedily keep every interval that starts at or after the end of the last kept one. Everything not kept is removed.

1. Sort by end ascending.
2. `lastEnd = -∞`, `kept = 0`.
3. For each interval: if `start >= lastEnd`, keep it (`kept++`, `lastEnd = end`); otherwise it overlaps and is counted as removed.
4. Return `n - kept`.

- **Time:** O(n log n)
- **Space:** O(1) extra beyond sorting

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int eraseOverlapIntervals(vector<vector<int>>& intervals) {
        if (intervals.empty()) return 0;
        sort(intervals.begin(), intervals.end(),
             [](const vector<int>& a, const vector<int>& b) { return a[1] < b[1]; });
        int kept = 0;
        long long lastEnd = LLONG_MIN;
        for (auto& iv : intervals) {
            if (iv[0] >= lastEnd) {
                kept++;
                lastEnd = iv[1];
            }
        }
        return (int)intervals.size() - kept;
    }
};
```

import java.util.*;

class Solution {
    public int eraseOverlapIntervals(int[][] intervals) {
        if (intervals.length == 0) return 0;
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1]));
        int kept = 0;
        long lastEnd = Long.MIN_VALUE;
        for (int[] iv : intervals) {
            if (iv[0] >= lastEnd) {
                kept++;
                lastEnd = iv[1];
            }
        }
        return intervals.length - kept;
    }
}

### Python
```python
from typing import List

class Solution:
    def eraseOverlapIntervals(self, intervals: List[List[int]]) -> int:
        if not intervals:
            return 0
        intervals.sort(key=lambda x: x[1])
        kept = 0
        last_end = float('-inf')
        for s, e in intervals:
            if s >= last_end:
                kept += 1
                last_end = e
        return len(intervals) - kept
```

## Key Takeaways
- "Minimum removals" = `n` minus "maximum non-overlapping set"; solve the second with the earliest-finish greedy.
- Sorting by end (not start) is what makes the greedy choice safe: the interval that ends first leaves the most space for the rest.
- Here touching intervals are fine, so the check is `start >= lastEnd`; in problems where touching counts as overlap, use `>`.
