# Count primes in range L to R

**Difficulty:** Hard  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Advanced Maths

## Problem
You are given several queries, each a pair `[L, R]`. For each query, report how many prime numbers lie in the inclusive range `L..R`. (The LeetCode variant "Count Primes" is the single query `[2, n-1]`, i.e. count primes strictly less than `n`.)

Input: `queries = [[3, 10], [8, 20]]`
Output: `[3, 4]`  (3, 5, 7 and 11, 13, 17, 19)

## Approach 1: Brute Force
For each query, walk from `L` to `R` and test each number for primality by trial division up to its square root. Fine for one small query, hopeless for many queries over a large range.
- **Time:** O(Q · (R - L) · sqrt(R))
- **Space:** O(1)

## Approach 2: Better (Sieve of Eratosthenes, then scan)
Precompute a boolean array `isPrime[0..maxR]` once with the sieve: mark 0 and 1 as not prime, then for every `i` from 2 to `sqrt(maxR)` that is still marked prime, cross out all multiples `i*i, i*i + i, ...`. Starting at `i*i` is safe because smaller multiples were already crossed out by smaller primes. Each query then just counts `true` entries in `L..R`.
- **Time:** O(N log log N) for the sieve + O(R - L) per query
- **Space:** O(N)

## Approach 3: Optimal (Sieve + prefix counts)
Turn the sieve result into a prefix array: `cnt[i]` = number of primes in `[0, i]`. Then any query is answered in constant time as `cnt[R] - cnt[L - 1]`.
- **Time:** O(N log log N) preprocessing, O(1) per query
- **Space:** O(N)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    // Answers each [L, R] query; N is the largest R seen.
    vector<int> countPrimes(vector<vector<int>>& queries) {
        int N = 1;
        for (auto& q : queries) N = max(N, q[1]);

        vector<bool> isPrime(N + 1, true);
        isPrime[0] = false;
        if (N >= 1) isPrime[1] = false;
        for (long long i = 2; i * i <= N; i++)
            if (isPrime[i])
                for (long long j = i * i; j <= N; j += i) isPrime[j] = false;

        vector<int> cnt(N + 1, 0);
        for (int i = 1; i <= N; i++) cnt[i] = cnt[i - 1] + (isPrime[i] ? 1 : 0);

        vector<int> ans;
        for (auto& q : queries) {
            int L = q[0], R = q[1];
            ans.push_back(cnt[R] - (L > 0 ? cnt[L - 1] : 0));
        }
        return ans;
    }

    // LeetCode 204: number of primes strictly less than n.
    int countPrimes(int n) {
        if (n < 3) return 0;
        vector<vector<int>> q = {{2, n - 1}};
        return countPrimes(q)[0];
    }
};
```

import java.util.*;

class Solution {
    public int[] countPrimes(int[][] queries) {
        int N = 1;
        for (int[] q : queries) N = Math.max(N, q[1]);

        boolean[] isPrime = new boolean[N + 1];
        Arrays.fill(isPrime, true);
        isPrime[0] = false;
        if (N >= 1) isPrime[1] = false;
        for (long i = 2; i * i <= N; i++)
            if (isPrime[(int) i])
                for (long j = i * i; j <= N; j += i) isPrime[(int) j] = false;

        int[] cnt = new int[N + 1];
        for (int i = 1; i <= N; i++) cnt[i] = cnt[i - 1] + (isPrime[i] ? 1 : 0);

        int[] ans = new int[queries.length];
        for (int k = 0; k < queries.length; k++) {
            int L = queries[k][0], R = queries[k][1];
            ans[k] = cnt[R] - (L > 0 ? cnt[L - 1] : 0);
        }
        return ans;
    }

    // LeetCode 204: primes strictly less than n.
    public int countPrimes(int n) {
        if (n < 3) return 0;
        return countPrimes(new int[][]{{2, n - 1}})[0];
    }
}

### Python
```python
from typing import List

class Solution:
    def countPrimesInRanges(self, queries: List[List[int]]) -> List[int]:
        N = max(1, max(q[1] for q in queries))
        is_prime = [True] * (N + 1)
        is_prime[0] = False
        if N >= 1:
            is_prime[1] = False
        i = 2
        while i * i <= N:
            if is_prime[i]:
                for j in range(i * i, N + 1, i):
                    is_prime[j] = False
            i += 1

        cnt = [0] * (N + 1)
        for k in range(1, N + 1):
            cnt[k] = cnt[k - 1] + (1 if is_prime[k] else 0)

        return [cnt[R] - (cnt[L - 1] if L > 0 else 0) for L, R in queries]

    # LeetCode 204: primes strictly less than n.
    def countPrimes(self, n: int) -> int:
        if n < 3:
            return 0
        return self.countPrimesInRanges([[2, n - 1]])[0]
```

## Key Takeaways
- Sieve of Eratosthenes: start crossing out at `i*i` and only loop `i` up to `sqrt(N)`.
- Prefix sums turn "count in a range" into an O(1) subtraction; the sieve is paid for once.
- Watch the boundaries: 0 and 1 are not prime, `L` may be 0 or 1, and LeetCode's version is exclusive of `n`.
- Use `long`/`long long` for `i * i` and `j` to avoid overflow when `N` is near the int limit.
