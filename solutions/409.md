# Pattern 17

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a centered pyramid of letters with `n` rows. Row `i` (0-indexed) climbs from `A` up to the `i`-th letter and then descends back to `A`, giving `2i + 1` letters, padded on the left so the pyramid is symmetric.

Input: `n = 5`
Output:
```
    A
   ABA
  ABCBA
 ABCDCBA
ABCDEDCBA
```

## Approach
This is the Pattern 7 pyramid with letters that rise and fall inside each row.

1. Outer loop `i` from `0` to `n-1`.
2. Print `n - i - 1` leading spaces.
3. Inner loop `j` from `0` to `2i`: the middle position is `j = i`. For `j <= i` print `'A' + j` (rising); for `j > i` print `'A' + (2i - j)` (falling, mirrored around the middle).
4. Newline.

The mirror formula `2i - j` maps positions after the peak back onto their symmetric partner before it.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern17(int n) {
    for (int i = 0; i < n; i++) {
        for (int s = 0; s < n - i - 1; s++) cout << " ";
        for (int j = 0; j <= 2 * i; j++) {
            int offset = (j <= i) ? j : 2 * i - j;
            cout << (char)('A' + offset);
        }
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern17 {
    public static void pattern17(int n) {
        for (int i = 0; i < n; i++) {
            StringBuilder row = new StringBuilder();
            for (int s = 0; s < n - i - 1; s++) row.append(' ');
            for (int j = 0; j <= 2 * i; j++) {
                int offset = (j <= i) ? j : 2 * i - j;
                row.append((char) ('A' + offset));
            }
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern17(n: int) -> None:
    for i in range(n):
        letters = "".join(
            chr(ord("A") + (j if j <= i else 2 * i - j)) for j in range(2 * i + 1)
        )
        print(" " * (n - i - 1) + letters)
```

## Key Takeaways
- Symmetric rows: use a single loop over `2i + 1` positions and mirror the index with `2i - j` after the midpoint.
- Leading spaces (`n - i - 1`) are the same as in the star pyramid.
- Letters are printed without separators so the pyramid stays aligned.
