# Highest Occurring Element in an Array

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Learn Basic Hashing

## Problem
Given an array `arr` of `n` integers, return the element that occurs the most times. If several elements share the maximum frequency, return the smallest of them. (The same technique yields the least frequent element.)

Input: `arr = [1, 2, 2, 3, 3, 3]`
Output: `3`

Input: `arr = [4, 4, 5, 5, 6]`
Output: `4` (4 and 5 both appear twice; the smaller wins)

## Approach 1: Brute force
For every element, scan the whole array to count its occurrences and keep the best (highest count, ties broken by smaller value).

- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Sort and count runs
Sort the array so equal values are adjacent, then walk it once tracking the current run length. When a run ends, compare its length against the best so far. Because the array is sorted, the first run that reaches the maximum length is automatically the smallest such value.

- **Time:** O(n log n)
- **Space:** O(1) extra

## Approach 3: Hash map (optimal)
Build a frequency map in one pass, then scan the map for the entry with the largest count, using the smaller key to break ties. Two linear passes, no sorting.

- **Time:** O(n) average
- **Space:** O(k), k = number of distinct values

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int mostFrequentElement(const vector<int>& arr) {
        unordered_map<int, int> freq;
        for (int x : arr) freq[x]++;

        int best = INT_MAX, bestCount = 0;
        for (auto& [value, count] : freq) {
            if (count > bestCount || (count == bestCount && value < best)) {
                bestCount = count;
                best = value;
            }
        }
        return best;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int mostFrequentElement(int[] arr) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : arr) freq.merge(x, 1, Integer::sum);

        int best = Integer.MAX_VALUE, bestCount = 0;
        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            int value = e.getKey(), count = e.getValue();
            if (count > bestCount || (count == bestCount && value < best)) {
                bestCount = count;
                best = value;
            }
        }
        return best;
    }
}
```

### Python
```python
from collections import Counter

class Solution:
    def mostFrequentElement(self, arr: list[int]) -> int:
        freq = Counter(arr)
        best, best_count = None, 0
        for value, count in freq.items():
            if count > best_count or (count == best_count and value < best):
                best, best_count = value, count
        return best
```

## Key Takeaways
- Frequency map plus a single scan for the maximum is the standard O(n) answer; only the tie-break rule (smallest value) needs care.
- Track both the best count and the best value; update on strictly greater count *or* equal count with a smaller value.
- The least-frequent element is the same code with the comparison flipped.
- Note: the linked LeetCode problem ("Frequency of the Most Frequent Element") is a harder sliding-window variant where you may increment elements up to k times; the hashing exercise here is the plain "mode of the array" version.
