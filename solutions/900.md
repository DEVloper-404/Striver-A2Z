# Reverse a Doubly Linked List

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Learn Doubly LinkedList

## Problem
Given the head of a doubly linked list, reverse the order of its nodes in place and return the new head (which is the old tail). After reversal, following `next` from the new head must visit the elements in the reverse of the original order, and every `prev` link must still be correct.

```
Input:  head = 1 <-> 2 <-> 3 <-> 4
Output: 4 <-> 3 <-> 2 <-> 1
```

## Approach 1: Copy values through a stack
Walk the list pushing every value onto a stack, then walk it again popping values and overwriting each node's `val`. The links never change, only the data does. It works, but it uses extra memory and does not really exercise the pointer manipulation the problem is about.

- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Swap prev and next at every node (optimal)
Key observation: in a DLL, reversing the list is the same as swapping the roles of `prev` and `next` in every node. Walk the list with `cur`; at each node:

1. Remember `nxt = cur.next` (we need it because we are about to overwrite it).
2. Swap: `cur.next = cur.prev; cur.prev = nxt`.
3. Move on: `cur = nxt`.

The last node processed (the old tail) becomes the new head. A convenient way to grab it is to keep a `last` pointer to the node just processed, or notice that after swapping, `cur.prev` points to where `next` used to go.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct DNode { int val; DNode* prev; DNode* next; DNode(int v) : val(v), prev(nullptr), next(nullptr) {} };

class Solution {
public:
    DNode* reverseDLL(DNode* head) {
        if (!head || !head->next) return head;
        DNode* cur = head;
        DNode* last = nullptr;
        while (cur) {
            DNode* nxt = cur->next;
            cur->next = cur->prev;
            cur->prev = nxt;
            last = cur;
            cur = nxt;
        }
        return last;
    }
};
```

### Java
```java
// class DNode { int val; DNode prev, next; DNode(int v) { val = v; } }

class Solution {
    public DNode reverseDLL(DNode head) {
        if (head == null || head.next == null) return head;
        DNode cur = head, last = null;
        while (cur != null) {
            DNode nxt = cur.next;
            cur.next = cur.prev;
            cur.prev = nxt;
            last = cur;
            cur = nxt;
        }
        return last;
    }
}
```

### Python
```python
# class DNode:
#     def __init__(self, val):
#         self.val = val
#         self.prev = None
#         self.next = None

class Solution:
    def reverseDLL(self, head):
        if head is None or head.next is None:
            return head
        cur, last = head, None
        while cur:
            nxt = cur.next
            cur.next, cur.prev = cur.prev, nxt
            last = cur
            cur = nxt
        return last
```

## Key Takeaways
- Reversing a DLL is a per-node swap of `prev` and `next`; no extra pointers beyond a saved `next`.
- Save `cur.next` before swapping or you lose the rest of the list.
- The node processed last is the new head; return it, not the original head.
- Empty and single-node lists are already reversed.
