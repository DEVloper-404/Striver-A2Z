# Shortest Palindrome

**Difficulty:** Hard  ·  **Topic:** Strings › Hard Problems

## Problem
You are given a string `s`. You may only add characters **in front of** it. Return the shortest palindrome you can obtain this way.

```
Input:  s = "aacecaaa"
Output: "aaacecaaa"
```

```
Input:  s = "abcd"
Output: "dcbabcd"
```

## Approach 1: Brute Force — find the longest palindromic prefix
Because characters may only be prepended, the original `s` must survive intact as a **suffix** of the answer. Write the answer as `X + s`. For `X + s` to be a palindrome, whatever `X` we prepend must mirror a tail of `s`; the part of `s` left untouched in the middle has to already be a palindrome — and it must be a *prefix* of `s`, since it is what sits after `X`.

That gives the whole strategy in one line:

> Find the **longest palindromic prefix** of `s`, say `s[0..k-1]`. The answer is `reverse(s[k..n-1]) + s`.

Minimality follows: a longer prepended `X` corresponds to a *shorter* palindromic prefix, so taking the longest palindromic prefix gives the shortest `X`.

The brute-force implementation tries `k = n, n-1, …, 1` and checks whether `s[0..k-1]` is a palindrome, stopping at the first success. Each check is O(n), so the total is O(n²) — too slow when `n` is 10⁵, and pathological on `"aaaa…a"`.

- **Time:** O(n²)
- **Space:** O(n) for the reversed tail

## Approach 2: Better — hashing
"Is `s[0..k-1]` a palindrome?" can be answered in O(1) by keeping two polynomial hashes of `s`: a forward prefix hash and a backward one. The prefix of length `k` is a palindrome exactly when its forward hash equals its backward hash. Scan `k` downward from `n` and take the first hit.

This reaches O(n) but is probabilistic — a hash collision would report a false palindrome — so you should verify the winning `k` with a direct comparison. It also needs two hash tables and careful modular arithmetic. The KMP formulation below is deterministic and shorter.

- **Time:** O(n)
- **Space:** O(n)

## Approach 3: Optimal — KMP on `s + '#' + reverse(s)`

### The reduction
"The longest prefix of `s` that is a palindrome" can be restated without the word *palindrome*. Let `r = reverse(s)`. A prefix `s[0..k-1]` is a palindrome exactly when it equals its own reverse — and its own reverse is precisely the **suffix of `r` of length `k`**. So:

> longest palindromic prefix of `s`  =  longest prefix of `s` that is also a suffix of `r`

That is a prefix-suffix question, which is exactly what the KMP **LPS array** computes.

### Why the separator matters
Build `t = s + '#' + r`, where `#` occurs in neither string. Then `lps[t.length - 1]` is the longest proper prefix of `t` that is also a suffix of `t`. Because `#` appears exactly once and sits in the middle, no matched region can span it: any prefix-suffix overlap is forced to stay entirely within `s` on one side and entirely within `r` on the other. Consequently the value is capped at `n` and equals exactly the longest prefix of `s` that is a suffix of `r` — our `k`.

Without the separator, the overlap could run past the end of `s` into the reversed copy and report a `k` larger than `n`, producing garbage (e.g. `s = "aaaa"` would give an overlap of length 7).

### Putting it together
1. `r = reverse(s)`, `t = s + '#' + r`.
2. Build the LPS array of `t` with the standard two-pointer construction.
3. `k = lps[t.length - 1]` — the length of the longest palindromic prefix of `s`.
4. Return `reverse(s[k..n-1]) + s`.

### Dry run on `s = "aacecaaa"` (n = 8)
- `r = "aaacecaa"`, so `t = "aacecaaa#aaacecaa"` (length 17).
- The LPS build ends with `lps[16] = 7`: the prefix `"aacecaa"` of `t` equals the last 7 characters of `t`, which are the last 7 of `r`.
- So `k = 7`, meaning `s[0..6] = "aacecaa"` is the longest palindromic prefix — and indeed reading it backwards gives `"aacecaa"` again. ✓
- The leftover tail is `s[7..7] = "a"`; reversed it is `"a"`.
- Answer: `"a" + "aacecaaa"` = `"aaacecaaa"`. ✓

For `s = "abcd"`: `r = "dcba"`, `t = "abcd#dcba"`, `lps` ends at `1` (`"a"` is a prefix of `t` and the last character of `t`). So `k = 1`, tail `"bcd"` reversed is `"dcb"`, answer `"dcbabcd"`. ✓

Everything here is a single linear pass over a string of length `2n + 1`.

- **Time:** O(n)
- **Space:** O(n) for `t` and its LPS array

## Code (Optimal)

### C++
```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    string shortestPalindrome(string s) {
        int n = (int)s.size();
        if (n <= 1) return s;

        string r = s;
        reverse(r.begin(), r.end());
        string t = s + '#' + r;          // '#' blocks overlaps across the middle

        int m = (int)t.size();
        vector<int> lps(m, 0);
        int len = 0, i = 1;
        while (i < m) {
            if (t[i] == t[len]) {
                lps[i++] = ++len;
            } else if (len > 0) {
                len = lps[len - 1];      // fall back to a shorter prefix-suffix
            } else {
                lps[i++] = 0;
            }
        }

        int k = lps[m - 1];              // longest palindromic prefix length
        string tail = s.substr(k);       // the part that must be mirrored in front
        reverse(tail.begin(), tail.end());
        return tail + s;
    }
};
```

### Java
```java
class Solution {
    public String shortestPalindrome(String s) {
        int n = s.length();
        if (n <= 1) return s;

        String r = new StringBuilder(s).reverse().toString();
        String t = s + '#' + r;          // '#' blocks overlaps across the middle

        int m = t.length();
        int[] lps = new int[m];
        int len = 0, i = 1;
        while (i < m) {
            if (t.charAt(i) == t.charAt(len)) {
                lps[i++] = ++len;
            } else if (len > 0) {
                len = lps[len - 1];      // fall back to a shorter prefix-suffix
            } else {
                lps[i++] = 0;
            }
        }

        int k = lps[m - 1];              // longest palindromic prefix length
        String tail = new StringBuilder(s.substring(k)).reverse().toString();
        return tail + s;
    }
}
```

### Python
```python
class Solution:
    def shortestPalindrome(self, s: str) -> str:
        n = len(s)
        if n <= 1:
            return s

        t = s + "#" + s[::-1]        # '#' blocks overlaps across the middle

        m = len(t)
        lps = [0] * m
        length, i = 0, 1
        while i < m:
            if t[i] == t[length]:
                length += 1
                lps[i] = length
                i += 1
            elif length > 0:
                length = lps[length - 1]   # fall back to a shorter prefix-suffix
            else:
                lps[i] = 0
                i += 1

        k = lps[m - 1]               # longest palindromic prefix length
        return s[k:][::-1] + s
```

## Key Takeaways
- Since only prepending is allowed, `s` stays as a suffix — so the answer is fully determined by the **longest palindromic prefix**, and longer palindromic prefix means shorter addition.
- "Prefix of `s` that is a palindrome" rewrites as "prefix of `s` that is a suffix of `reverse(s)`", which is exactly what an LPS array measures.
- The separator `#` is mandatory: it caps the overlap at `n` and stops a match from bleeding across the join.
- Handle `n <= 1` up front, and remember the same trick (`s + sep + reverse(s)`) answers other longest-palindromic-prefix/suffix questions.
