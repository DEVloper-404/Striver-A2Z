# Implement Queue using Stack

**Difficulty:** Easy  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Learning

## Problem
Implement a FIFO queue using only stack operations (`push` to top, `pop`/`peek` from top, `size`, `empty`). Support `push(x)`, `pop()`, `peek()` and `empty()`.

Input: `push(1), push(2), peek(), pop(), empty()`
Output: `1, 1, false`

## Approach 1: Costly push
Keep `s1` holding the queue in "front on top" order. To push `x`: move everything from `s1` to `s2`, push `x` onto `s1`, then move everything back. Now `x` is at the bottom, so `pop`/`peek` are simple `s1` top operations.
- **Time:** O(n) push, O(1) pop/peek
- **Space:** O(n)

## Approach 2: Optimal (two stacks, amortised O(1))
Use an input stack `in` and an output stack `out`.

- `push(x)`: push onto `in`.
- `pop()` / `peek()`: if `out` is empty, pour all of `in` into `out` (this reverses the order, so the oldest element lands on top). Then operate on `out`'s top.

Each element is moved from `in` to `out` at most once in its lifetime, so the total work across any sequence of operations is linear, giving amortised O(1) per operation.
- **Time:** O(1) amortised per operation (O(n) worst case for a single pop)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <stack>
using namespace std;

class MyQueue {
    stack<int> in, out;
    void shift() {
        if (out.empty())
            while (!in.empty()) { out.push(in.top()); in.pop(); }
    }
public:
    void push(int x) { in.push(x); }
    int pop() {
        shift();
        int val = out.top();
        out.pop();
        return val;
    }
    int peek() {
        shift();
        return out.top();
    }
    bool empty() { return in.empty() && out.empty(); }
};
```

### Java
```java
import java.util.*;

class MyQueue {
    private final Deque<Integer> in = new ArrayDeque<>();
    private final Deque<Integer> out = new ArrayDeque<>();

    private void shift() {
        if (out.isEmpty())
            while (!in.isEmpty()) out.push(in.pop());
    }
    public void push(int x) { in.push(x); }
    public int pop() { shift(); return out.pop(); }
    public int peek() { shift(); return out.peek(); }
    public boolean empty() { return in.isEmpty() && out.isEmpty(); }
}
```

### Python
```python
class MyQueue:
    def __init__(self):
        self.inp = []
        self.out = []

    def _shift(self) -> None:
        if not self.out:
            while self.inp:
                self.out.append(self.inp.pop())

    def push(self, x: int) -> None:
        self.inp.append(x)

    def pop(self) -> int:
        self._shift()
        return self.out.pop()

    def peek(self) -> int:
        self._shift()
        return self.out[-1]

    def empty(self) -> bool:
        return not self.inp and not self.out
```

## Key Takeaways
- Two stacks: one receives pushes, the other serves pops; pouring one into the other reverses order.
- Only refill `out` when it is empty; pouring while it still has elements would break FIFO order.
- Amortised analysis: each element is moved once, so n operations cost O(n) total.
- `empty()` must check both stacks.
