# Sliding Window Maximum

**Difficulty:** Hard  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Implementation Problems

## Problem
A window of size `k` slides over the array `nums` one position at a time from left to right. For every window position, report the maximum value inside the window. Return the list of maxima (there are `n - k + 1` of them).

```
Input:  nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3
Output: [3, 3, 5, 5, 6, 7]
```

## Approach 1: Brute Force
For each of the `n - k + 1` windows, scan its `k` elements to find the max.
- **Time:** O(n · k)
- **Space:** O(1) extra

## Approach 2: Max-Heap with Lazy Deletion
Push `(value, index)` into a max-heap as the window advances. Before reading the top, discard entries whose index has fallen out of the window.
- **Time:** O(n log n)
- **Space:** O(n)

## Approach 3: Monotonic Deque (Optimal)
Maintain a deque of *indices* whose values are strictly decreasing from front to back. The front is always the current window's maximum.
For each index `i`:
1. Pop from the front if it is outside the window (`front <= i - k`).
2. Pop from the back while `nums[back] <= nums[i]` — those elements can never be the max again because `nums[i]` is newer and at least as large.
3. Push `i` at the back.
4. Once `i >= k - 1`, record `nums[front]`.

Every index is inserted and removed at most once.
- **Time:** O(n)
- **Space:** O(k)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <deque>
using namespace std;

class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        deque<int> dq;   // indices, values decreasing front -> back
        vector<int> ans;
        for (int i = 0; i < (int)nums.size(); ++i) {
            if (!dq.empty() && dq.front() <= i - k) dq.pop_front();
            while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();
            dq.push_back(i);
            if (i >= k - 1) ans.push_back(nums[dq.front()]);
        }
        return ans;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] ans = new int[n - k + 1];
        Deque<Integer> dq = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            if (!dq.isEmpty() && dq.peekFirst() <= i - k) dq.pollFirst();
            while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i]) dq.pollLast();
            dq.addLast(i);
            if (i >= k - 1) ans[i - k + 1] = nums[dq.peekFirst()];
        }
        return ans;
    }
}
```

### Python
```python
from collections import deque
from typing import List

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        dq = deque()
        ans = []
        for i, x in enumerate(nums):
            if dq and dq[0] <= i - k:
                dq.popleft()
            while dq and nums[dq[-1]] <= x:
                dq.pop()
            dq.append(i)
            if i >= k - 1:
                ans.append(nums[dq[0]])
        return ans
```

## Key Takeaways
- Store indices, not values, so you can tell when the front has expired.
- Pop on `<=` from the back so duplicates do not pile up; the deque stays strictly decreasing.
- Deque size never exceeds `k`, and `k == 1` or `k == n` both fall out naturally.
