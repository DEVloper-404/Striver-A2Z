# Find out how many times the array is rotated

**Difficulty:** Easy  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on 1D Arrays

## Problem
A sorted array of distinct integers was rotated to the right `k` times, where `0 <= k < n`. Given the resulting array `arr`, find `k`. For example, rotating `[1, 2, 3, 4, 5]` right three times yields `[3, 4, 5, 1, 2]`.

Input: `arr = [3, 4, 5, 1, 2]`
Output: `3`

Input: `arr = [1, 2, 3, 4, 5]`
Output: `0`

## Approach 1: Linear Scan for the Minimum
The number of right rotations equals the index of the smallest element: after `k` rotations, the original first element (the minimum) sits at position `k`. Scan the array, track the index of the smallest value, and return it.

- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Binary Search for the Minimum's Index (Optimal)
Use the same "one half is sorted" reasoning as in "Find minimum in rotated sorted array", but track the index of the best candidate rather than the value:

1. If `arr[low] <= arr[high]`, the current range is fully sorted; `low` is the minimum's index within it. Compare with the best so far and stop.
2. If `arr[low] <= arr[mid]`, the left half is sorted; its minimum is at `low`. Update the best index if `arr[low]` is smaller, then search the right half.
3. Otherwise the right half is sorted; its minimum is at `mid`. Update the best index if `arr[mid]` is smaller, then search the left half.
4. Return the recorded index.

- **Time:** O(log n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int findKRotation(vector<int>& arr) {
        int low = 0, high = (int)arr.size() - 1;
        int idx = 0;                // index of smallest value found so far
        while (low <= high) {
            int mid = low + (high - low) / 2;

            if (arr[low] <= arr[high]) {            // whole range sorted
                if (arr[low] < arr[idx]) idx = low;
                break;
            }
            if (arr[low] <= arr[mid]) {             // left half sorted
                if (arr[low] < arr[idx]) idx = low;
                low = mid + 1;
            } else {                                // right half sorted
                if (arr[mid] < arr[idx]) idx = mid;
                high = mid - 1;
            }
        }
        return idx;
    }
};
```

### Python

```python
from typing import List

class Solution:
    def findKRotation(self, arr: List[int]) -> int:
        low, high = 0, len(arr) - 1
        idx = 0  # index of the smallest value found so far
        while low <= high:
            mid = (low + high) // 2

            if arr[low] <= arr[high]:        # whole range sorted
                if arr[low] < arr[idx]:
                    idx = low
                break
            if arr[low] <= arr[mid]:         # left half sorted
                if arr[low] < arr[idx]:
                    idx = low
                low = mid + 1
            else:                            # right half sorted
                if arr[mid] < arr[idx]:
                    idx = mid
                high = mid - 1
        return idx
```

## Key Takeaways
- Rotation count = index of the minimum element; this turns a seemingly new problem into "find minimum in rotated sorted array" with one extra variable.
- Starting `idx` at 0 is safe: if the array is unrotated the first comparison keeps it at 0 and exits.
- Distinct values are required for the endpoint comparisons to be unambiguous.
- Interviewers may phrase the rotation as left rotations instead; then the answer is `n - idx` (mod `n`), so confirm the direction before coding.
