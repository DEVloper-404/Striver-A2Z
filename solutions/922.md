# Maximum Points You Can Obtain from Cards

**Difficulty:** Medium  ·  **Topic:** Sliding Window & Two Pointer Combined Problems › Medium Problems

## Problem
Cards are laid out in a row with values `cardPoints`. In each of exactly `k` moves you take one card from either the left end or the right end. Return the maximum total value you can collect.

Input: `cardPoints = [1,2,3,4,5,6,1], k = 3`
Output: `12` (take the right card `1`, then `6`, then `5`)

## Approach 1: Recursion over Choices
At each step choose left or right, recurse on the remaining range with `k - 1` moves, and take the better of the two branches.

- **Time:** O(2^k)
- **Space:** O(k) recursion depth

## Approach 2: Prefix and Suffix Sums
Any final selection consists of `i` cards from the left and `k - i` from the right for some `i` in `[0, k]`. Precompute prefix sums of the first `k` cards and suffix sums of the last `k` cards, then try every split.

- **Time:** O(k)
- **Space:** O(k)

## Approach 3: Sliding Window Over the Ends (Optimal)
Same observation, done in place. Start with the sum of the first `k` cards (all taken from the left). Then repeatedly give back one card from the left end of that block and take one card from the right end of the array. After `k` swaps every split has been evaluated; keep the maximum.

- **Time:** O(k)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxScore(vector<int>& cardPoints, int k) {
        int n = cardPoints.size();
        int leftSum = 0;
        for (int i = 0; i < k; ++i) leftSum += cardPoints[i];
        int best = leftSum, rightSum = 0;
        for (int i = 0; i < k; ++i) {
            leftSum -= cardPoints[k - 1 - i];
            rightSum += cardPoints[n - 1 - i];
            best = max(best, leftSum + rightSum);
        }
        return best;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def maxScore(self, cardPoints: List[int], k: int) -> int:
        n = len(cardPoints)
        left_sum = sum(cardPoints[:k])
        best = left_sum
        right_sum = 0
        for i in range(k):
            left_sum -= cardPoints[k - 1 - i]
            right_sum += cardPoints[n - 1 - i]
            best = max(best, left_sum + right_sum)
        return best
```

## Key Takeaways
- The order of picks does not matter; only how many come from each end. That collapses the search to `k + 1` splits.
- Equivalent view: the untouched cards form a contiguous middle window of size `n - k`; minimising that window's sum maximises the answer.
- Edge case: `k == n` means every card is taken, and the loop handles it naturally.
