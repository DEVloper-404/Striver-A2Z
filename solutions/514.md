# Number of islands II

**Difficulty:** Hard  ·  **Topic:** Graphs [Concepts & Problems] › MinimumSpanningTree/Disjoint Set and Problems

## Problem
You start with an `n × m` grid of water (all `0`s). A list of `operators[i] = [r, c]` gives cells that are turned into land, one at a time. After each operation, report how many **islands** exist, where an island is a maximal group of land cells connected in the four cardinal directions. Return the list of counts, one per operation.

```
Input:  n = 4, m = 5, operators = [[0,0],[0,1],[1,2],[2,1]]
Output: [1, 1, 2, 3]
```
After `[0,0]`: one island. After `[0,1]`: it touches `[0,0]`, still one. After `[1,2]`: isolated, so two. After `[2,1]`: isolated from both, so three.

## Approach 1: Re-scan the grid after every operation
After each land placement, run a full BFS/DFS over the grid to count connected components from scratch. Simple and clearly correct, but it redoes all the work every time.
- **Time:** O(q · n · m) for `q` operations
- **Space:** O(n · m)

## Approach 2: Incremental Disjoint Set (optimal)

**The key observation.** Land is only ever *added*, never removed. Adding one cell can change the island count in exactly one way: `+1` for the new cell itself, then `-1` for each **distinct** neighbouring island it fuses with. So we can maintain a running count instead of recomputing it.

DSU is the right structure because it supports exactly "merge two groups / are these in the same group?" and it is monotone — it never needs to split, which is what makes an incremental (online) solution possible at all.

**Flattening 2D into 1D.** Map cell `(r, c)` to the DSU node `r * m + c`. This gives a plain array DSU of size `n * m`, with no hashing overhead.

**The algorithm.** Keep a boolean grid `isLand` and a counter `count`.
1. For each operator `(r, c)`:
2. If `isLand[r][c]` is already true, this is a **duplicate operation** — the count does not change; append the current `count` and move on. (Missing this check double-counts and is the single most common bug here.)
3. Mark `isLand[r][c] = true` and do `count++`, tentatively treating the new cell as its own island.
4. For each of the four neighbours `(nr, nc)` that is inside the grid **and** is land: if `find(cell) != find(neighbour)`, they are separate islands that this cell now bridges — `union` them and do `count--`. If they already share a leader (e.g. the new cell touches two cells of the *same* island), do nothing.
5. Append `count` to the result.

**Why the `find` check before decrementing matters.** A new cell can touch up to four land neighbours, but several may belong to the same island already. Decrementing per *neighbour* rather than per *distinct merged island* would undercount. Letting the DSU's `find` decide is what makes this exact.

**Short dry run** on the example with `m = 5`.
- `[0,0]` → node `0`. Not land yet: `count = 1`. No land neighbours. Output `1`.
- `[0,1]` → node `1`. `count = 2`. Neighbour `(0,0)` is land and has a different leader → union, `count = 1`. Output `1`.
- `[1,2]` → node `7`. `count = 2`. Neighbours `(0,2)`, `(2,2)`, `(1,1)`, `(1,3)` are all water. Output `2`.
- `[2,1]` → node `11`. `count = 3`. Neighbours `(1,1)`, `(3,1)`, `(2,0)`, `(2,2)` are all water. Output `3`.
Result `[1, 1, 2, 3]`. ✓

**Where this pattern shows up.** Any problem where connectivity is queried while edges/cells are being added online — dynamic connectivity, "count components after each edge", Kruskal's — is the same shape. Note that if cells could be *removed*, DSU would not work directly and you would typically process the operations in reverse time order so removals become additions.
- **Time:** O(q · α(n·m)) ≈ O(q), plus O(n·m) to initialise the DSU
- **Space:** O(n · m) for the DSU and the land grid

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;

class Solution {
    vector<int> parent, sz;
    int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        if (sz[a] < sz[b]) swap(a, b);
        parent[b] = a;
        sz[a] += sz[b];
        return true;
    }
public:
    vector<int> numOfIslands(int n, int m, vector<vector<int>>& operators) {
        parent.resize(n * m);
        sz.assign(n * m, 1);
        iota(parent.begin(), parent.end(), 0);

        vector<vector<char>> isLand(n, vector<char>(m, 0));
        const int dr[4] = {-1, 1, 0, 0};
        const int dc[4] = {0, 0, -1, 1};

        vector<int> res;
        int count = 0;
        for (auto& op : operators) {
            int r = op[0], c = op[1];
            if (isLand[r][c]) { res.push_back(count); continue; }  // duplicate
            isLand[r][c] = 1;
            count++;
            int cell = r * m + c;
            for (int d = 0; d < 4; d++) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr < 0 || nr >= n || nc < 0 || nc >= m) continue;
                if (!isLand[nr][nc]) continue;
                if (unite(cell, nr * m + nc)) count--;   // fused two islands
            }
            res.push_back(count);
        }
        return res;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    private int[] parent, size;

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private boolean unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        if (size[a] < size[b]) { int t = a; a = b; b = t; }
        parent[b] = a;
        size[a] += size[b];
        return true;
    }

    public List<Integer> numOfIslands(int n, int m, int[][] operators) {
        parent = new int[n * m];
        size = new int[n * m];
        for (int i = 0; i < n * m; i++) { parent[i] = i; size[i] = 1; }

        boolean[][] isLand = new boolean[n][m];
        int[] dr = {-1, 1, 0, 0};
        int[] dc = {0, 0, -1, 1};

        List<Integer> res = new ArrayList<>();
        int count = 0;
        for (int[] op : operators) {
            int r = op[0], c = op[1];
            if (isLand[r][c]) { res.add(count); continue; }
            isLand[r][c] = true;
            count++;
            int cell = r * m + c;
            for (int d = 0; d < 4; d++) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr < 0 || nr >= n || nc < 0 || nc >= m) continue;
                if (!isLand[nr][nc]) continue;
                if (unite(cell, nr * m + nc)) count--;
            }
            res.add(count);
        }
        return res;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def numOfIslands(self, n: int, m: int, operators: List[List[int]]) -> List[int]:
        parent = list(range(n * m))
        size = [1] * (n * m)
        is_land = [[False] * m for _ in range(n)]

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def unite(a: int, b: int) -> bool:
            a, b = find(a), find(b)
            if a == b:
                return False
            if size[a] < size[b]:
                a, b = b, a
            parent[b] = a
            size[a] += size[b]
            return True

        res, count = [], 0
        for r, c in operators:
            if is_land[r][c]:               # repeated cell changes nothing
                res.append(count)
                continue
            is_land[r][c] = True
            count += 1
            cell = r * m + c
            for nr, nc in ((r - 1, c), (r + 1, c), (r, c - 1), (r, c + 1)):
                if 0 <= nr < n and 0 <= nc < m and is_land[nr][nc]:
                    if unite(cell, nr * m + nc):
                        count -= 1
            res.append(count)
        return res
```

## Key Takeaways
- Maintain the island count incrementally: `+1` for the new cell, `-1` per distinct neighbouring island it merges with.
- Only decrement when `union` actually merges two different sets — two neighbours from the same island must not be double-counted.
- Flatten `(r, c)` to `r * m + c` so the DSU is a flat array; add bounds checks on all four neighbours.
- Guard against repeated operators on an already-land cell, and remember DSU handles additions online but not deletions.
