# Reverse words in a given string / Palindrome Check

**Difficulty:** Medium  ·  **Topic:** Strings [Basic and Medium] › Basic and Easy String Problems

## Problem
This item covers two classic string tasks.

**Part A – Reverse words.** Given a string that may contain leading, trailing, or repeated spaces, return the words in reverse order joined by a single space.

Input: `s = "  the sky   is blue "`
Output: `"blue is sky the"`

**Part B – Palindrome check.** Given a string, decide whether it reads the same forwards and backwards (case-insensitive, ignoring non-alphanumeric characters if the variant asks for that).

Input: `s = "A man, a plan, a canal: Panama"`
Output: `true`

## Approach 1: Split, reverse, join
Tokenize the string on whitespace (dropping empty tokens), reverse the token list, and join with one space. Simple and readable; it uses an extra array of words.

For the palindrome check, build a filtered lowercase copy and compare it with its reverse.
- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Two pointers, in place (Optimal)
**Reverse words (O(1) extra beyond the output):**
1. Scan from the right with index `i`. Skip spaces.
2. Find the start of the current word by moving left until a space or the beginning.
3. Append that word to the answer (adding a separator if the answer is non-empty).
4. Continue until `i < 0`.

This visits each character once and never stores a word list. In languages with mutable char arrays you can also reverse the whole array, then reverse each word, then squeeze spaces.

**Palindrome (O(1) extra):** put `l` at the start and `r` at the end. Advance `l` past non-alphanumerics, retreat `r` past non-alphanumerics, then compare lowercase characters. Any mismatch means not a palindrome.
- **Time:** O(n)
- **Space:** O(1) extra (O(n) for the output string in Part A)

## Code (Optimal)

### C++
```cpp
#include <string>
#include <cctype>
using namespace std;

class Solution {
public:
    // Part A: reverse the order of words.
    string reverseWords(string s) {
        string out;
        int i = (int)s.size() - 1;
        while (i >= 0) {
            while (i >= 0 && s[i] == ' ') i--;
            if (i < 0) break;
            int end = i;
            while (i >= 0 && s[i] != ' ') i--;
            if (!out.empty()) out.push_back(' ');
            out.append(s, i + 1, end - i);
        }
        return out;
    }

    // Part B: alphanumeric, case-insensitive palindrome check.
    bool isPalindrome(string s) {
        int l = 0, r = (int)s.size() - 1;
        while (l < r) {
            while (l < r && !isalnum((unsigned char)s[l])) l++;
            while (l < r && !isalnum((unsigned char)s[r])) r--;
            if (tolower((unsigned char)s[l]) != tolower((unsigned char)s[r])) return false;
            l++; r--;
        }
        return true;
    }
};
```

### Java
```java
class Solution {
    // Part A: reverse the order of words.
    public String reverseWords(String s) {
        StringBuilder out = new StringBuilder();
        int i = s.length() - 1;
        while (i >= 0) {
            while (i >= 0 && s.charAt(i) == ' ') i--;
            if (i < 0) break;
            int end = i;
            while (i >= 0 && s.charAt(i) != ' ') i--;
            if (out.length() > 0) out.append(' ');
            out.append(s, i + 1, end + 1);
        }
        return out.toString();
    }

    // Part B: alphanumeric, case-insensitive palindrome check.
    public boolean isPalindrome(String s) {
        int l = 0, r = s.length() - 1;
        while (l < r) {
            while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
            while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
            if (Character.toLowerCase(s.charAt(l)) != Character.toLowerCase(s.charAt(r))) return false;
            l++; r--;
        }
        return true;
    }
}
```

### Python
```python
class Solution:
    # Part A: reverse the order of words.
    def reverseWords(self, s: str) -> str:
        out = []
        i = len(s) - 1
        while i >= 0:
            while i >= 0 and s[i] == ' ':
                i -= 1
            if i < 0:
                break
            end = i
            while i >= 0 and s[i] != ' ':
                i -= 1
            out.append(s[i + 1:end + 1])
        return " ".join(out)

    # Part B: alphanumeric, case-insensitive palindrome check.
    def isPalindrome(self, s: str) -> bool:
        l, r = 0, len(s) - 1
        while l < r:
            while l < r and not s[l].isalnum():
                l += 1
            while l < r and not s[r].isalnum():
                r -= 1
            if s[l].lower() != s[r].lower():
                return False
            l += 1
            r -= 1
        return True
```

## Key Takeaways
- Scanning from the right lets you emit words already in reversed order without a temporary list.
- Handle multiple/leading/trailing spaces by skipping runs of spaces rather than splitting on a single space.
- The two-pointer palindrome check is the template for "compare from both ends while skipping unwanted characters".
- Edge cases: empty string, all spaces, a single word, a single character.
