# Majority Element-I

**Difficulty:** Easy  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Medium

## Problem
Given an array of `n` integers, return the element that appears strictly more than `n / 2` times. The problem guarantees that such an element always exists, so you never need to handle the "no majority" case (though the optimal code below can be extended with a verification pass if that guarantee is dropped).

```
Input:  nums = [2, 2, 1, 1, 1, 2, 2]
Output: 2        (appears 4 times out of 7)
```

## Approach 1: Brute Force
For every element, count how many times it occurs by scanning the whole array. If any count exceeds `n / 2`, that element is the answer.
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Hash Map Counting
Count occurrences of each value in a hash map in one pass, then return the key whose count is greater than `n / 2`. Sorting and picking the middle element (`nums[n/2]`) is another O(n log n) variant that works because a majority element must cover the middle position.
- **Time:** O(n)
- **Space:** O(n)

## Approach 3: Boyer-Moore Voting (Optimal)
Keep a `candidate` and a `count`. Walk the array:
1. If `count` is 0, adopt the current element as the new candidate.
2. If the current element equals the candidate, increment `count`; otherwise decrement it.

Intuition: every non-candidate element "cancels" one candidate vote. A true majority has more votes than everything else combined, so it can never be fully cancelled and ends the pass as the candidate. If existence were not guaranteed, a second pass would confirm the candidate's count exceeds `n / 2`.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int majorityElement(vector<int>& nums) {
        int candidate = 0, count = 0;
        for (int x : nums) {
            if (count == 0) candidate = x;
            count += (x == candidate) ? 1 : -1;
        }
        // Optional verification if a majority is not guaranteed:
        // int freq = 0; for (int x : nums) if (x == candidate) ++freq;
        // if (freq <= nums.size() / 2) return -1;
        return candidate;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        candidate, count = None, 0
        for x in nums:
            if count == 0:
                candidate = x
            count += 1 if x == candidate else -1
        return candidate
```

## Key Takeaways
- Boyer-Moore voting finds a `> n/2` element in O(1) space by pairing off unequal elements.
- The single pass only yields a *candidate*; add a verification pass whenever the majority is not guaranteed.
- Sorting and reading `nums[n/2]` is a neat one-liner but costs O(n log n).
- The same idea generalises to `> n/3` (keep two candidates), which is the follow-up problem.
