# Delete head of Doubly Linked List

**Difficulty:** Easy  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Learn Doubly LinkedList

## Problem
Given the head of a doubly linked list, remove its first node and return the new head. If the list is empty or has a single node, the result is an empty list. As a companion operation, deleting the last node (tail) is also shown, since it uses the same two-pointer bookkeeping from the other end.

```
Input:  head = 5 <-> 6 <-> 7
Output: 6 <-> 7
```

## Approach 1: Delete the head
1. If `head` is null, there is nothing to delete.
2. Let `newHead = head.next`.
3. If `newHead` exists, clear its backward link: `newHead.prev = null`.
4. Detach the old head (`head.next = null`) and free it if the language requires.
5. Return `newHead`.

The only subtlety is step 3: forgetting to null out `prev` leaves a dangling pointer to a deleted node.

- **Time:** O(1)
- **Space:** O(1)

## Approach 2: Delete the tail
Walk to the last node. If it is also the head (single node), return null. Otherwise let `p = tail.prev`, set `p.next = null`, detach `tail.prev`, and free it. The head is unchanged.

- **Time:** O(n) to reach the tail (O(1) if a tail pointer is maintained)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct DNode { int val; DNode* prev; DNode* next; DNode(int v) : val(v), prev(nullptr), next(nullptr) {} };

class Solution {
public:
    DNode* deleteHead(DNode* head) {
        if (!head) return nullptr;
        DNode* newHead = head->next;
        if (newHead) newHead->prev = nullptr;
        head->next = nullptr;
        delete head;
        return newHead;
    }

    DNode* deleteTail(DNode* head) {
        if (!head) return nullptr;
        if (!head->next) { delete head; return nullptr; }
        DNode* tail = head;
        while (tail->next) tail = tail->next;
        DNode* p = tail->prev;
        p->next = nullptr;
        tail->prev = nullptr;
        delete tail;
        return head;
    }
};
```

### Java
```java
// class DNode { int val; DNode prev, next; DNode(int v) { val = v; } }

class Solution {
    public DNode deleteHead(DNode head) {
        if (head == null) return null;
        DNode newHead = head.next;
        if (newHead != null) newHead.prev = null;
        head.next = null;
        return newHead;
    }

    public DNode deleteTail(DNode head) {
        if (head == null) return null;
        if (head.next == null) return null;
        DNode tail = head;
        while (tail.next != null) tail = tail.next;
        DNode p = tail.prev;
        p.next = null;
        tail.prev = null;
        return head;
    }
}
```

### Python
```python
# class DNode:
#     def __init__(self, val):
#         self.val = val
#         self.prev = None
#         self.next = None

class Solution:
    def deleteHead(self, head):
        if head is None:
            return None
        new_head = head.next
        if new_head:
            new_head.prev = None
        head.next = None
        return new_head

    def deleteTail(self, head):
        if head is None or head.next is None:
            return None
        tail = head
        while tail.next:
            tail = tail.next
        p = tail.prev
        p.next = None
        tail.prev = None
        return head
```

## Key Takeaways
- Deleting from a DLL means fixing the link on the surviving side: `newHead.prev = null` for the head, `p.next = null` for the tail.
- Handle empty and single-node lists explicitly; both return null.
- Detach the removed node's pointers before freeing so nothing still references live nodes.
- Head deletion is O(1); tail deletion needs a walk unless you track the tail.
