# Check if two strings are anagram of each other

**Difficulty:** Easy  ·  **Topic:** Strings [Basic and Medium] › Basic and Easy String Problems

## Problem
Two strings are anagrams if one can be rearranged into the other, i.e. they contain exactly the same characters with the same multiplicities. Given `s` and `t`, return true if `t` is an anagram of `s`.

Input: `s = "listen", t = "silent"`
Output: `true`

Input: `s = "rat", t = "car"`
Output: `false`

## Approach 1: Sort both and compare
Sort the characters of each string. If the sorted forms are identical, the multisets of characters match. Easy to reason about but costs a sort.
- **Time:** O(n log n)
- **Space:** O(n) for the sorted copies (or O(1) if sorting in place is allowed)

## Approach 2: Frequency counting (Optimal)
If the lengths differ, they cannot be anagrams. Otherwise keep one count array (size 26 for lowercase letters, or 256 for arbitrary bytes). Increment for every character of `s` and decrement for every character of `t`. At the end every count must be zero.

Using a single array with increments and decrements halves the memory and avoids a second comparison loop; a non-zero entry means some character appears more often in one string than the other.
- **Time:** O(n)
- **Space:** O(1) (fixed-size count array)

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.size() != t.size()) return false;
        int cnt[256] = {0};
        for (size_t i = 0; i < s.size(); ++i) {
            cnt[(unsigned char)s[i]]++;
            cnt[(unsigned char)t[i]]--;
        }
        for (int c : cnt) if (c != 0) return false;
        return true;
    }
};
```

### Java
```java
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) return false;
        int[] cnt = new int[256];
        for (int i = 0; i < s.length(); i++) {
            cnt[s.charAt(i)]++;
            cnt[t.charAt(i)]--;
        }
        for (int c : cnt) if (c != 0) return false;
        return true;
    }
}
```

### Python
```python
from collections import Counter

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        return Counter(s) == Counter(t)
```

## Key Takeaways
- Anagram checks are multiset-equality checks; a frequency array is the linear-time tool.
- A single count array with `+1` / `-1` is cleaner than two arrays.
- Check the length first so you can index both strings in one loop.
- If the alphabet is Unicode, use a hash map instead of a fixed array.
