# Selection Sort

**Difficulty:** Easy  ·  **Topic:** Learn Important Sorting Techniques › Sorting-I

## Problem
Given an array of `n` integers, sort it in non-decreasing order using the selection sort technique. The array should be modified in place and returned.

Input: `arr = [13, 46, 24, 52, 20, 9]`
Output: `[9, 13, 20, 24, 46, 52]`

## Approach 1: Selection Sort
The idea is to build the sorted prefix one slot at a time. For every position `i` from `0` to `n-2`:

1. Scan the unsorted part `arr[i..n-1]` and find the index of the smallest element.
2. Swap that smallest element with `arr[i]`.

After the `i`-th pass, the first `i+1` elements are the `i+1` smallest values of the array and are in their final sorted positions. The last element does not need a pass because once `n-1` slots hold the correct values, the remaining slot must also be correct.

Selection sort always does the same amount of work regardless of the input order, so there is no best case improvement. It does at most `n-1` swaps, which makes it useful when writes are expensive. It is not stable: swapping can move an equal element past its twin.

- **Time:** O(n²) — the inner scan runs `n-1 + n-2 + ... + 1` comparisons in every case.
- **Space:** O(1) — sorts in place.

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <utility>
using namespace std;

class Solution {
public:
    vector<int> selectionSort(vector<int>& arr) {
        int n = arr.size();
        for (int i = 0; i < n - 1; i++) {
            int minIdx = i;
            for (int j = i + 1; j < n; j++) {
                if (arr[j] < arr[minIdx]) minIdx = j;
            }
            if (minIdx != i) swap(arr[i], arr[minIdx]);
        }
        return arr;
    }
};
```

### Java
```java
class Solution {
    public int[] selectionSort(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            int minIdx = i;
            for (int j = i + 1; j < n; j++) {
                if (arr[j] < arr[minIdx]) minIdx = j;
            }
            if (minIdx != i) {
                int tmp = arr[i];
                arr[i] = arr[minIdx];
                arr[minIdx] = tmp;
            }
        }
        return arr;
    }
}
```

### Python
```python
class Solution:
    def selectionSort(self, arr: list[int]) -> list[int]:
        n = len(arr)
        for i in range(n - 1):
            min_idx = i
            for j in range(i + 1, n):
                if arr[j] < arr[min_idx]:
                    min_idx = j
            if min_idx != i:
                arr[i], arr[min_idx] = arr[min_idx], arr[i]
        return arr
```

## Key Takeaways
- Pattern: "pick the minimum of what is left and place it at the front"; the sorted prefix grows by one each pass.
- Only `n-1` swaps at most, but always O(n²) comparisons — there is no early exit.
- Not stable; if stability matters, prefer insertion sort or merge sort.
- Edge cases: empty or single-element arrays need zero passes and the loops naturally handle them.
