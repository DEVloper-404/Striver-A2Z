# Correct BST with two nodes swapped

**Difficulty:** Hard  ·  **Topic:** Binary Search Trees [Concept and Problems] › Practice Problems

## Problem
You are given the root of a tree that *was* a valid BST until the values of exactly two nodes were swapped by mistake. Restore the BST by swapping those two values back. The tree structure must not change — only the two values.

```
Input:  root = [1, 3, null, null, 2]      (inorder: 3, 1, 2)
Output: [3, 1, null, null, 2]             (1 and 3 swapped back; inorder: 1, 2, 3)

Input:  root = [3, 1, 4, null, null, 2]   (inorder: 1, 3, 2, 4)
Output: [2, 1, 4, null, null, 3]          (2 and 3 swapped back)
```

## Approach 1: Brute Force (sort the inorder array)
Collect the inorder traversal into an array, make a sorted copy, and compare position by position. The (at most two) positions where they differ hold the swapped values; walk the tree again and put the right values back.

Correct and easy to explain, but it needs O(N) storage and an O(N log N) sort.
- **Time:** O(N log N)
- **Space:** O(N)

## Approach 2: Optimal (one inorder pass, detect the violations)
The whole problem reduces to one observation: **a valid BST has a strictly increasing inorder traversal**. Swapping two values leaves the traversal *almost* sorted, with either one or two "descents" (adjacent pairs where `prev > cur`). Which of the two happens depends on where the swapped nodes are:

**Case A — the two swapped nodes are not adjacent in the inorder order.** Example: sorted `1 2 3 4 5` with `2` and `4` swapped gives `1 4 3 2 5`. There are **two** descents: `4 > 3` and `3 > 2`. The first offending value is the *larger* one at the **first** descent (`4`, the `prev` of that pair). The second offending value is the *smaller* one at the **second** descent (`2`, the `cur` of that pair).

**Case B — the two swapped nodes are adjacent in the inorder order.** Example: `1 2 3 4 5` with `3` and `4` swapped gives `1 2 4 3 5`. There is only **one** descent: `4 > 3`. Both culprits are in that single pair: `prev = 4` and `cur = 3`.

So a single inorder pass with three pointers handles both cases uniformly:
- `first` — set to `prev` at the **first** descent only.
- `middle` — set to `cur` at the first descent (this is the partner for Case B).
- `last` — set to `cur` at **every subsequent** descent (so it ends up holding the second culprit in Case A).

At the end: if `last` is non-null we saw two descents (Case A) → swap `first` and `last`. Otherwise (Case B) → swap `first` and `middle`.

**Dry run** on `[3, 1, 4, null, null, 2]`. Inorder is `1, 3, 2, 4`.
- Visit `1`: `prev = null` → no comparison. `prev = 1`.
- Visit `3`: `1 < 3`, fine. `prev = 3`.
- Visit `2`: `3 > 2` → descent #1 → `first = 3`, `middle = 2`. `prev = 2`.
- Visit `4`: `2 < 4`, fine.
- End: `last` is null → Case B → swap `first (3)` and `middle (2)`.
- New inorder: `1, 2, 3, 4`. ✔ The root, which held `3`, now holds `2`, and the node that held `2` now holds `3`.

**Dry run** on inorder `1 4 3 2 5` (Case A):
- `4 > 3` → descent #1 → `first = 4`, `middle = 3`.
- `3 > 2` → descent #2 → `last = 2`.
- End: `last` non-null → swap `first (4)` and `last (2)` → `1 2 3 4 5`. ✔

Note that we swap the **values**, not the nodes — the pointers stay exactly as they were, which is what the problem requires.

The traversal can be recursive (O(H) stack), iterative with an explicit stack (also O(H)), or Morris inorder, which threads temporary pointers through the tree to achieve genuine O(1) extra space. The recursive version is shown below for clarity; the follow-up interviewers usually want is "and can you do it in O(1) space?" — the answer is Morris traversal with the same three-pointer bookkeeping.
- **Time:** O(N) — one traversal
- **Space:** O(H) recursion stack (O(1) with Morris inorder)

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left, *right; TreeNode(int x) ... } — standard definition
#include <algorithm>
using namespace std;

class Solution {
    TreeNode *first = nullptr, *middle = nullptr, *last = nullptr, *prev = nullptr;

    void inorder(TreeNode* node) {
        if (node == nullptr) return;
        inorder(node->left);

        if (prev != nullptr && node->val < prev->val) {   // a descent
            if (first == nullptr) {                        // first violation
                first  = prev;
                middle = node;
            } else {                                       // second violation
                last = node;
            }
        }
        prev = node;

        inorder(node->right);
    }
public:
    void recoverTree(TreeNode* root) {
        first = middle = last = prev = nullptr;
        inorder(root);
        if (last != nullptr) swap(first->val, last->val);   // non-adjacent swap
        else                 swap(first->val, middle->val); // adjacent swap
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; TreeNode(int x) ... } — standard definition

class Solution {
    private TreeNode first, middle, last, prev;

    private void inorder(TreeNode node) {
        if (node == null) return;
        inorder(node.left);

        if (prev != null && node.val < prev.val) {
            if (first == null) {
                first = prev;
                middle = node;
            } else {
                last = node;
            }
        }
        prev = node;

        inorder(node.right);
    }

    public void recoverTree(TreeNode root) {
        first = middle = last = prev = null;
        inorder(root);
        if (last != null) {
            int t = first.val; first.val = last.val;   last.val = t;
        } else {
            int t = first.val; first.val = middle.val; middle.val = t;
        }
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def recoverTree(self, root):
        self.first = self.middle = self.last = self.prev = None

        def inorder(node):
            if node is None:
                return
            inorder(node.left)

            if self.prev and node.val < self.prev.val:     # inorder descent
                if self.first is None:
                    self.first, self.middle = self.prev, node   # 1st violation
                else:
                    self.last = node                             # 2nd violation
            self.prev = node

            inorder(node.right)

        inorder(root)
        if self.last:                                       # non-adjacent nodes swapped
            self.first.val, self.last.val = self.last.val, self.first.val
        else:                                               # adjacent nodes swapped
            self.first.val, self.middle.val = self.middle.val, self.first.val
```

## Key Takeaways
- A BST is broken exactly where its inorder traversal descends; one swap creates either one or two descents.
- Two descents → the culprits are the `prev` of the first and the `cur` of the second. One descent → both culprits are that single pair.
- Swap the **values**, never the node pointers — the structure is not what is wrong.
- Follow-up: replace the recursive inorder with Morris traversal to get O(1) auxiliary space while keeping the identical three-pointer logic.
