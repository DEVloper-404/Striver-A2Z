# Rotate String

**Difficulty:** Easy  ·  **Topic:** Strings [Basic and Medium] › Basic and Easy String Problems

## Problem
Given two strings `s` and `goal`, decide whether `goal` can be produced by rotating `s` some number of times. One rotation moves the first character of `s` to its end.

Input: `s = "abcde", goal = "cdeab"`
Output: `true`

Input: `s = "abcde", goal = "abced"`
Output: `false`

## Approach 1: Try every rotation
For each shift `k` from `0` to `n-1`, build the rotated string `s[k..] + s[..k]` and compare it with `goal`. Return true on the first match.
- **Time:** O(n^2)
- **Space:** O(n) for the temporary rotated string

## Approach 2: Doubling trick (Optimal)
Every rotation of `s` appears as a contiguous substring of `s + s`. For example, `"abcde" + "abcde" = "abcdeabcde"` contains `"cdeab"` starting at index 2. So:

1. If lengths differ, answer is false.
2. Otherwise, answer is whether `goal` is a substring of `s + s`.

With a linear-time substring search (KMP, or the library search which is fast in practice) this is O(n). The length check is required; without it, `goal = "ab"` and `s = "abc"` would wrongly pass.
- **Time:** O(n) with KMP; library `find`/`contains` is O(n) average
- **Space:** O(n) for the doubled string

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Solution {
public:
    bool rotateString(string s, string goal) {
        if (s.size() != goal.size()) return false;
        string doubled = s + s;
        return doubled.find(goal) != string::npos;
    }
};
```

### Java
```java
class Solution {
    public boolean rotateString(String s, String goal) {
        if (s.length() != goal.length()) return false;
        return (s + s).contains(goal);
    }
}
```

### Python
```python
class Solution:
    def rotateString(self, s: str, goal: str) -> bool:
        return len(s) == len(goal) and goal in (s + s)
```

## Key Takeaways
- Concatenating a string with itself exposes all of its rotations as substrings.
- Always compare lengths first; the substring test alone is not enough.
- If you need a guaranteed linear bound, plug in KMP for the substring search.
- Edge cases: identical strings (zero rotations, true), empty strings (true), single characters.
