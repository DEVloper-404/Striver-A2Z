# Find Nth root of a number

**Difficulty:** Medium  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on Answers

## Problem
Given two positive integers `n` and `m`, find the integer `x` such that `x^n == m`. If no such integer exists, return `-1`.

Input: n = 3, m = 27
Output: 3  (3^3 = 27)

Input: n = 4, m = 69
Output: -1  (no integer raised to 4 gives 69)

## Approach 1: Linear Scan
Check `x = 1, 2, 3, ...` and compute `x^n`. Stop as soon as `x^n >= m`: if it equals `m` return `x`, otherwise return `-1`. Every candidate is tried one by one.
- **Time:** O(m^(1/n) * n)
- **Space:** O(1)

## Approach 2: Binary Search on the Answer
`x^n` grows monotonically with `x`, so we can binary search `x` in `[1, m]`. For a `mid`, compute `mid^n` carefully: multiply step by step and bail out as soon as the product exceeds `m` (this avoids overflow and wasted work). Return a three-way signal: equal, smaller, or larger.

1. If `mid^n == m`, return `mid`.
2. If `mid^n < m`, the answer is larger: `lo = mid + 1`.
3. Otherwise `hi = mid - 1`.

If the loop finishes without an exact hit, return `-1`.
- **Time:** O(n * log m)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    // returns 0 if mid^n == m, 1 if mid^n < m, 2 if mid^n > m
    int compare(long long mid, int n, long long m) {
        long long prod = 1;
        for (int i = 0; i < n; i++) {
            prod *= mid;
            if (prod > m) return 2;
        }
        return prod == m ? 0 : 1;
    }

    int nthRoot(int n, int m) {
        long long lo = 1, hi = m;
        while (lo <= hi) {
            long long mid = lo + (hi - lo) / 2;
            int c = compare(mid, n, m);
            if (c == 0) return (int)mid;
            if (c == 1) lo = mid + 1;
            else hi = mid - 1;
        }
        return -1;
    }
};
```

### Python
```python
class Solution:
    def _compare(self, mid: int, n: int, m: int) -> int:
        # 0 -> equal, 1 -> smaller, 2 -> larger
        prod = 1
        for _ in range(n):
            prod *= mid
            if prod > m:
                return 2
        return 0 if prod == m else 1

    def nthRoot(self, n: int, m: int) -> int:
        lo, hi = 1, m
        while lo <= hi:
            mid = (lo + hi) // 2
            c = self._compare(mid, n, m)
            if c == 0:
                return mid
            if c == 1:
                lo = mid + 1
            else:
                hi = mid - 1
        return -1
```

## Key Takeaways
- Same skeleton as floor square root, but the answer must be exact, so return `-1` when the loop ends without a hit.
- Never compute `pow(mid, n)` blindly; early-exit the multiplication loop the moment the product exceeds `m` to avoid overflow.
- Edge cases: `m = 1` gives `1` for any `n`; `n = 1` returns `m` itself.
