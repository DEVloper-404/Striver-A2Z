# Insert Interval

**Difficulty:** Medium  ·  **Topic:** Greedy Algorithms [Easy, Medium/Hard] › Medium/Hard

## Problem
You are given a list of non-overlapping intervals `intervals`, sorted by start, and a new interval `newInterval = [s, e]`. Insert the new interval into the list so that the result is still sorted and non-overlapping, merging any intervals that overlap with it. Return the resulting list.

Input: `intervals = [[1,3],[6,9]]`, `newInterval = [2,5]`
Output: `[[1,5],[6,9]]`

Input: `intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]]`, `newInterval = [4,8]`
Output: `[[1,2],[3,10],[12,16]]`

## Approach 1: Append and re-merge
Add `newInterval` to the list, sort by start, and run the standard merge-intervals pass. Simple but wastes the fact that the input is already sorted.
- **Time:** O(n log n)
- **Space:** O(n)

## Approach 2: Three-phase linear scan (Optimal)
Because the intervals are sorted and disjoint, the intervals touched by `newInterval` form one contiguous block.
1. **Left part:** copy every interval that ends before `s` (`end < s`); they cannot overlap.
2. **Merge part:** while the current interval starts at or before `e` (`start <= e`), it overlaps; extend `s = min(s, start)` and `e = max(e, end)`. After the loop push `[s, e]`.
3. **Right part:** copy everything remaining.

- **Time:** O(n)
- **Space:** O(n) for the output

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> insert(vector<vector<int>>& intervals, vector<int>& newInterval) {
        vector<vector<int>> res;
        int n = intervals.size(), i = 0;
        int s = newInterval[0], e = newInterval[1];

        while (i < n && intervals[i][1] < s) res.push_back(intervals[i++]);

        while (i < n && intervals[i][0] <= e) {
            s = min(s, intervals[i][0]);
            e = max(e, intervals[i][1]);
            i++;
        }
        res.push_back({s, e});

        while (i < n) res.push_back(intervals[i++]);
        return res;
    }
};
```

### Java

```java
import java.util.*;

class Solution {
    public int[][] insert(int[][] intervals, int[] newInterval) {
        List<int[]> res = new ArrayList<>();
        int n = intervals.length, i = 0;
        int s = newInterval[0], e = newInterval[1];

        while (i < n && intervals[i][1] < s) res.add(intervals[i++]);

        while (i < n && intervals[i][0] <= e) {
            s = Math.min(s, intervals[i][0]);
            e = Math.max(e, intervals[i][1]);
            i++;
        }
        res.add(new int[]{s, e});

        while (i < n) res.add(intervals[i++]);
        return res.toArray(new int[res.size()][]);
    }
}
```

### Python
```python
from typing import List

class Solution:
    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        res = []
        n, i = len(intervals), 0
        s, e = newInterval

        while i < n and intervals[i][1] < s:
            res.append(intervals[i])
            i += 1

        while i < n and intervals[i][0] <= e:
            s = min(s, intervals[i][0])
            e = max(e, intervals[i][1])
            i += 1
        res.append([s, e])

        res.extend(intervals[i:])
        return res
```

## Key Takeaways
- Sorted, disjoint input means the overlapping intervals are contiguous; split the scan into before / overlapping / after.
- Touching intervals (`end == s` or `start == e`) count as overlapping here, hence `<` in the first loop and `<=` in the second.
- Works for an empty `intervals` list and for a new interval that lands entirely before or after everything.
