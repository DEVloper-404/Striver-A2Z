# Jump Game II

**Difficulty:** Medium  ·  **Topic:** Greedy Algorithms [Easy, Medium/Hard] › Medium/Hard

## Problem
You start at index `0` of array `nums`, where `nums[i]` is the maximum forward jump from index `i`. It is guaranteed that the last index is reachable. Return the **minimum number of jumps** needed to reach the last index.

Input: `nums = [2, 3, 1, 1, 4]`
Output: `2` (jump 1 step to index 1, then 3 steps to index 4)

## Approach 1: Recursion with memoization
`f(i)` = minimum jumps from `i` to the end = `1 + min(f(j))` over `j` in `i+1..i+nums[i]`. Memoize on `i`. Each state loops over up to `n` next positions.
- **Time:** O(n²)
- **Space:** O(n)

## Approach 2: Greedy BFS-style levels (Optimal)
Think of the array as levels of a BFS: with `k` jumps you can reach every index in some contiguous window `[l, r]`. From that window, the next window is `[r + 1, farthest]` where `farthest = max(i + nums[i])` for `i` in `[l, r]`. Each time you move to a new window, you spent one more jump. Stop once `r >= n - 1`.

Implementation with two pointers:
1. `l = r = 0`, `jumps = 0`.
2. While `r < n - 1`: compute `farthest` over `[l, r]`, set `l = r + 1`, `r = farthest`, `jumps++`.

- **Time:** O(n) — every index is scanned exactly once across all windows
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int jump(vector<int>& nums) {
        int n = nums.size();
        int jumps = 0, l = 0, r = 0;
        while (r < n - 1) {
            int farthest = 0;
            for (int i = l; i <= r; i++)
                farthest = max(farthest, i + nums[i]);
            l = r + 1;
            r = farthest;
            jumps++;
        }
        return jumps;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def jump(self, nums: List[int]) -> int:
        n = len(nums)
        jumps, l, r = 0, 0, 0
        while r < n - 1:
            farthest = 0
            for i in range(l, r + 1):
                farthest = max(farthest, i + nums[i])
            l, r = r + 1, farthest
            jumps += 1
        return jumps
```

## Key Takeaways
- Treat "minimum jumps" as BFS depth; each greedy window is one BFS level, so no explicit queue is needed.
- The loop condition `r < n - 1` handles `n == 1` (zero jumps) without a special case.
- The guarantee that the end is reachable is what lets the loop terminate; if that guarantee is dropped, add a check for `farthest <= r`.
