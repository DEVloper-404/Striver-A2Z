# Largest rectangle in a histogram

**Difficulty:** Hard  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Monotonic Stack/Queue Problems [VVV. Imp]

## Problem
`heights` lists the heights of adjacent bars, each of width 1. Return the area of the largest axis-aligned rectangle that fits entirely inside the histogram.

```
Input:  heights = [2, 1, 5, 6, 2, 3]
Output: 10
```
The bars of height 5 and 6 together form a 5 × 2 rectangle.

## Approach 1: Brute Force
For every pair `(l, r)`, the tallest rectangle spanning it has height `min(heights[l..r])`; area = `min × (r - l + 1)`. Track the minimum incrementally while extending `r`.
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Previous / Next Smaller Boundaries
The best rectangle whose height equals `heights[i]` stretches from just after the previous smaller bar to just before the next smaller bar. Compute `pse[i]` and `nse[i]` with two monotonic-stack passes, then area = `heights[i] * (nse[i] - pse[i] - 1)`.
- **Time:** O(n)
- **Space:** O(n)

## Approach 3: Single-Pass Monotonic Stack (Optimal)
Merge the two passes: keep a stack of indices with non-decreasing heights. When bar `i` is shorter than the top, the top's right boundary is `i` and its left boundary is the new top after popping, so its area can be finalised immediately. After the loop, flush the stack using `n` as the right boundary.
- **Time:** O(n)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <stack>
#include <algorithm>
using namespace std;

class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size(), best = 0;
        stack<int> st;   // indices, heights non-decreasing
        for (int i = 0; i <= n; ++i) {
            int cur = (i == n) ? 0 : heights[i];   // sentinel flushes the stack
            while (!st.empty() && heights[st.top()] > cur) {
                int h = heights[st.top()];
                st.pop();
                int left = st.empty() ? -1 : st.top();
                best = max(best, h * (i - left - 1));
            }
            st.push(i);
        }
        return best;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length, best = 0;
        Deque<Integer> st = new ArrayDeque<>();
        for (int i = 0; i <= n; i++) {
            int cur = (i == n) ? 0 : heights[i];
            while (!st.isEmpty() && heights[st.peek()] > cur) {
                int h = heights[st.pop()];
                int left = st.isEmpty() ? -1 : st.peek();
                best = Math.max(best, h * (i - left - 1));
            }
            st.push(i);
        }
        return best;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        n = len(heights)
        best = 0
        st = []
        for i in range(n + 1):
            cur = 0 if i == n else heights[i]
            while st and heights[st[-1]] > cur:
                h = heights[st.pop()]
                left = st[-1] if st else -1
                best = max(best, h * (i - left - 1))
            st.append(i)
        return best
```

## Key Takeaways
- Each bar is the limiting height of exactly one maximal rectangle, bounded by the nearest shorter bars on both sides.
- A sentinel of height 0 at index `n` lets one loop handle both the scan and the final flush.
- Pop on strictly greater: equal-height bars are left in the stack and the last one of the run computes the full width correctly.
