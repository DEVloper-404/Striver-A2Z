# Matrix Median

**Difficulty:** Hard  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on 2D Arrays

## Problem
You are given an `n x m` matrix in which every row is sorted in non-decreasing order, and `n * m` is odd. Return the median of all the elements in the matrix, i.e. the value at position `(n*m) / 2` (0-indexed) if all elements were sorted.

Input: matrix = [[1, 3, 5], [2, 6, 9], [3, 6, 9]]
Output: 5  (sorted: [1, 2, 3, 3, 5, 6, 6, 9, 9] → middle element is 5)

## Approach 1: Flatten and Sort
Copy all `n * m` elements into one list, sort it, and return the middle element. Simple but ignores the row ordering and costs extra memory.
- **Time:** O(n*m * log(n*m))
- **Space:** O(n*m)

## Approach 2: Binary Search on the Value
The median is the smallest value `x` such that at least `(n*m)/2 + 1` elements are `<= x`. That count is non-decreasing in `x`, so binary search `x` over `[min of first column, max of last column]`.

1. For a candidate `mid`, count elements `<= mid` by running an upper-bound binary search in each sorted row and summing the results.
2. If the count is `<= (n*m)/2`, `mid` is too small: `lo = mid + 1`.
3. Otherwise `mid` is at least the median: `hi = mid - 1`.

When the loop ends, `lo` is the median. Because we search values rather than positions, the answer is guaranteed to be an actual matrix element (the count only changes at real values).
- **Time:** O(log(range) * n * log m)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    // number of elements in a sorted row that are <= x
    int countLE(const vector<int>& row, int x) {
        int lo = 0, hi = (int)row.size() - 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (row[mid] <= x) lo = mid + 1;
            else hi = mid - 1;
        }
        return lo;
    }

    int findMedian(vector<vector<int>>& matrix) {
        int n = matrix.size(), m = matrix[0].size();
        int lo = INT_MAX, hi = INT_MIN;
        for (int i = 0; i < n; i++) {
            lo = min(lo, matrix[i][0]);
            hi = max(hi, matrix[i][m - 1]);
        }
        int need = (n * m) / 2;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            int count = 0;
            for (int i = 0; i < n; i++) count += countLE(matrix[i], mid);
            if (count <= need) lo = mid + 1;
            else hi = mid - 1;
        }
        return lo;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def findMedian(self, matrix: List[List[int]]) -> int:
        def count_le(row: List[int], x: int) -> int:
            lo, hi = 0, len(row) - 1
            while lo <= hi:
                mid = (lo + hi) // 2
                if row[mid] <= x:
                    lo = mid + 1
                else:
                    hi = mid - 1
            return lo

        n, m = len(matrix), len(matrix[0])
        lo = min(row[0] for row in matrix)
        hi = max(row[-1] for row in matrix)
        need = (n * m) // 2
        while lo <= hi:
            mid = (lo + hi) // 2
            count = sum(count_le(row, mid) for row in matrix)
            if count <= need:
                lo = mid + 1
            else:
                hi = mid - 1
        return lo
```

## Key Takeaways
- Nested binary search: an outer search on the value range, an inner upper-bound per row to count elements `<= mid`.
- The median is the first value whose "count of elements <= value" exceeds `(n*m)/2`; the loop's final `lo` lands exactly there.
- Search bounds come from the first and last columns, not `matrix[0][0]` and `matrix[n-1][m-1]`, since rows are only sorted individually.
- The problem guarantees `n * m` is odd, so no averaging is required.
