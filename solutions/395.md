# Longest Common Prefix

**Difficulty:** Easy  ·  **Topic:** Strings [Basic and Medium] › Basic and Easy String Problems

## Problem
Given an array of strings, return the longest string that is a prefix of every one of them. If they share no common starting characters, return the empty string.

Input: `strs = ["flower", "flow", "flight"]`
Output: `"fl"`

Input: `strs = ["dog", "racecar", "car"]`
Output: `""`

## Approach 1: Vertical scan
Look at column `i` across all strings at once. For each position `i` starting at 0, check that every string has length `> i` and the same character at `i` as the first string. The first column where this fails ends the prefix.

This is optimal in the sense that it never reads characters beyond the answer length in any string except the one that breaks the match.
- **Time:** O(S) where S is the total number of characters (worst case), but typically far less
- **Space:** O(1) extra

## Approach 2: Sort and compare the extremes (Optimal, neat)
If you sort the strings lexicographically, the smallest and largest strings are the "farthest apart". Any prefix shared by those two is automatically shared by everything in between. So sort, then compute the common prefix of `strs[0]` and `strs[n-1]` with a single scan.

Sorting costs O(n log n) string comparisons, but the final comparison is just one pass over the shorter of the two extreme strings.
- **Time:** O(n log n · L) for sorting where L is the average string length, then O(min length) for the compare
- **Space:** O(1) extra (in-place sort)

Both approaches are accepted; the vertical scan is asymptotically better, the sort trick is shorter to write. The code below uses the sort trick.

## Code (Optimal)

### C++
```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        if (strs.empty()) return "";
        sort(strs.begin(), strs.end());
        const string& a = strs.front();
        const string& b = strs.back();
        int i = 0;
        while (i < (int)a.size() && i < (int)b.size() && a[i] == b[i]) i++;
        return a.substr(0, i);
    }
};
```

### Java
```java
import java.util.Arrays;

class Solution {
    public String longestCommonPrefix(String[] strs) {
        if (strs.length == 0) return "";
        Arrays.sort(strs);
        String a = strs[0];
        String b = strs[strs.length - 1];
        int i = 0;
        while (i < a.length() && i < b.length() && a.charAt(i) == b.charAt(i)) i++;
        return a.substring(0, i);
    }
}
```

### Python
```python
from typing import List

class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""
        strs.sort()
        a, b = strs[0], strs[-1]
        i = 0
        while i < len(a) and i < len(b) and a[i] == b[i]:
            i += 1
        return a[:i]
```

## Key Takeaways
- The common prefix of a set is the common prefix of its lexicographic min and max.
- The vertical scan is the go-to when you need the best worst-case bound or must not mutate the input.
- Always bound the loop by the shortest string, otherwise you index out of range.
- Edge cases: single string (answer is the string itself), an empty string in the array (answer is `""`).
