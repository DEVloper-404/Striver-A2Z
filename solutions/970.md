# Remove K Digits

**Difficulty:** Medium  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Monotonic Stack/Queue Problems [VVV. Imp]

## Problem
You get a string `num` representing a non-negative integer and an integer `k`. Delete exactly `k` digits so that the remaining number (digits kept in order) is as small as possible. Return it as a string without leading zeros; if everything is removed, return `"0"`.

```
Input:  num = "1432219", k = 3
Output: "1219"
```

## Approach 1: Brute Force
Try every way of choosing `k` positions to delete, compare the resulting strings numerically, keep the smallest.
- **Time:** O(C(n, k) · n) — exponential
- **Space:** O(n)

## Approach 2: Greedy with a Monotonic Stack (Optimal)
A number is smaller when its leftmost digits are smaller. So whenever a digit is followed by a smaller digit, removing the bigger left digit helps. Process digits left to right with a stack:
1. While `k > 0` and the stack top is greater than the current digit, pop (one deletion used).
2. Push the current digit.

If `k` deletions remain at the end, the stack is non-decreasing, so remove `k` digits from the *end*. Finally strip leading zeros and handle the empty case.
- **Time:** O(n)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Solution {
public:
    string removeKdigits(string num, int k) {
        string st;   // string used as a stack
        for (char c : num) {
            while (k > 0 && !st.empty() && st.back() > c) {
                st.pop_back();
                --k;
            }
            st.push_back(c);
        }
        while (k > 0 && !st.empty()) { st.pop_back(); --k; }
        size_t pos = 0;
        while (pos < st.size() && st[pos] == '0') ++pos;
        string ans = st.substr(pos);
        return ans.empty() ? "0" : ans;
    }
};
```

### Java
```java
class Solution {
    public String removeKdigits(String num, int k) {
        StringBuilder st = new StringBuilder();
        for (char c : num.toCharArray()) {
            while (k > 0 && st.length() > 0 && st.charAt(st.length() - 1) > c) {
                st.setLength(st.length() - 1);
                k--;
            }
            st.append(c);
        }
        while (k > 0 && st.length() > 0) { st.setLength(st.length() - 1); k--; }
        int pos = 0;
        while (pos < st.length() && st.charAt(pos) == '0') pos++;
        String ans = st.substring(pos);
        return ans.isEmpty() ? "0" : ans;
    }
}
```

### Python
```python
class Solution:
    def removeKdigits(self, num: str, k: int) -> str:
        st = []
        for c in num:
            while k > 0 and st and st[-1] > c:
                st.pop()
                k -= 1
            st.append(c)
        if k > 0:
            st = st[:-k]
        ans = "".join(st).lstrip("0")
        return ans if ans else "0"
```

## Key Takeaways
- Greedy rule: delete a digit as soon as a smaller digit follows it — this is the monotonic-stack "keep it non-decreasing" pattern.
- Leftover deletions must come from the tail since the stack is already sorted.
- Do not forget leading zeros (`"10200", k=1 → "200"`) and the fully-deleted case (`"10", k=2 → "0"`).
