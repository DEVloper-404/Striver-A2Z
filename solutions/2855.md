# Pow(x, n)

**Difficulty:** Easy  ·  **Topic:** Recursion [PatternWise] › Get a Strong Hold

## Problem
Implement `pow(x, n)` that computes `x` raised to the integer power `n`. `x` is a real number and `n` can be negative, zero, or positive, and may be as extreme as `-2^31`.

Input: `x = 2.0`, `n = 10`
Output: `1024.0`

Input: `x = 2.0`, `n = -2`
Output: `0.25`

## Approach 1: Multiply n times
Start with `1.0` and multiply by `x` for `|n|` iterations; if `n` is negative, return the reciprocal at the end. Correct, but `n` can be around two billion, so this is far too slow.
- **Time:** O(|n|)
- **Space:** O(1)

## Approach 2: Binary exponentiation (recursive)
Key observation: `x^n = (x^(n/2))^2` when `n` is even and `x · (x^(n/2))^2` when `n` is odd. Each recursive call halves the exponent, so only about `log n` multiplications are needed.

1. Base case: `n == 0` returns `1`.
2. Compute `half = pow(x, n / 2)` once (do not call it twice, that would blow the complexity back up).
3. Return `half * half`, times an extra `x` if `n` is odd.
4. For negative `n`, compute the positive power and take `1 / result`. Convert `n` to a 64-bit value before negating, because `-INT_MIN` overflows a 32-bit int.

An iterative form does the same by walking the bits of `n`: whenever the current bit is set, multiply the answer by the running `x`, and square `x` at every step.
- **Time:** O(log |n|)
- **Space:** O(log |n|) recursion stack (O(1) for the iterative variant)

## Code (Optimal)

### C++
```cpp
class Solution {
    double fastPow(double x, long long n) {
        if (n == 0) return 1.0;
        double half = fastPow(x, n / 2);
        double res = half * half;
        return (n % 2 == 1) ? res * x : res;
    }
public:
    double myPow(double x, int n) {
        long long e = n;
        if (e < 0) return 1.0 / fastPow(x, -e);
        return fastPow(x, e);
    }
};
```

### Python
```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        def fast_pow(base: float, e: int) -> float:
            if e == 0:
                return 1.0
            half = fast_pow(base, e // 2)
            res = half * half
            return res * base if e % 2 == 1 else res

        if n < 0:
            return 1.0 / fast_pow(x, -n)
        return fast_pow(x, n)
```

## Key Takeaways
- Halving the exponent each step turns O(n) into O(log n); compute the half-power once and square it.
- Negative exponents: compute the positive power, then invert. Widen `n` to 64 bits before negating to survive `n = INT_MIN`.
- `x^0 = 1` for any `x`, including `0^0` under this problem's convention.
- The same idea (fast exponentiation) is reused later for modular power and matrix exponentiation.
