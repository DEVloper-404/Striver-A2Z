# Prime factorisation of a Number

**Difficulty:** Hard  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Advanced Maths

## Problem
Given one or more integers, output the full prime factorisation of each: every prime factor repeated as many times as it divides the number, in non-decreasing order. Unlike "print prime factors", multiplicity matters here.

Input: `queries = [12, 30, 49]`
Output:
```
12 -> 2 2 3
30 -> 2 3 5
49 -> 7 7
```

## Approach 1: Brute Force (trial division to sqrt)
For a single number, loop `i` from 2 while `i * i <= n`; whenever `i` divides `n`, push `i` and divide until it no longer does. Any leftover `n > 1` is the last prime. Every divisor found this way is automatically prime because smaller primes have already been divided out.
- **Time:** O(sqrt(n)) per number
- **Space:** O(1) extra

## Approach 2: Optimal for many queries (Smallest Prime Factor sieve)
When there are many queries up to some bound `N`, precompute `spf[x]` = smallest prime factor of `x` for all `x <= N`. Build it like a sieve: initialise `spf[x] = x`, then for each prime `i` mark `spf[j] = i` for multiples `j = i*i, i*i+i, ...` whose `spf` is still unset (equal to `j`).

Factorising then takes only as many steps as there are prime factors (with multiplicity): repeatedly push `spf[n]` and set `n /= spf[n]` until `n == 1`. Since each division at least halves `n`, this is O(log n) per query.
- **Time:** O(N log log N) preprocessing, O(log n) per query
- **Space:** O(N)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class PrimeFactoriser {
    vector<int> spf;
public:
    explicit PrimeFactoriser(int N) : spf(N + 1) {
        for (int i = 0; i <= N; i++) spf[i] = i;
        for (long long i = 2; i * i <= N; i++)
            if (spf[i] == i)
                for (long long j = i * i; j <= N; j += i)
                    if (spf[j] == j) spf[j] = i;
    }

    vector<int> factorise(int n) {
        vector<int> res;
        while (n > 1) {
            res.push_back(spf[n]);
            n /= spf[n];
        }
        return res;
    }
};
```

### Java
```java
import java.util.*;

class PrimeFactoriser {
    private final int[] spf;

    PrimeFactoriser(int N) {
        spf = new int[N + 1];
        for (int i = 0; i <= N; i++) spf[i] = i;
        for (long i = 2; i * i <= N; i++)
            if (spf[(int) i] == i)
                for (long j = i * i; j <= N; j += i)
                    if (spf[(int) j] == j) spf[(int) j] = (int) i;
    }

    List<Integer> factorise(int n) {
        List<Integer> res = new ArrayList<>();
        while (n > 1) {
            res.add(spf[n]);
            n /= spf[n];
        }
        return res;
    }
}
```

### Python
```python
class PrimeFactoriser:
    def __init__(self, N: int):
        self.spf = list(range(N + 1))
        i = 2
        while i * i <= N:
            if self.spf[i] == i:
                for j in range(i * i, N + 1, i):
                    if self.spf[j] == j:
                        self.spf[j] = i
            i += 1

    def factorise(self, n: int) -> list[int]:
        res = []
        while n > 1:
            res.append(self.spf[n])
            n //= self.spf[n]
        return res
```

## Key Takeaways
- Single query: trial division up to `sqrt(n)`, then append the leftover `n > 1`.
- Many queries: the SPF sieve makes each factorisation O(log n) with no primality tests at all.
- Only overwrite `spf[j]` when it is still `j`, otherwise a larger prime would clobber the smallest one.
- `n = 1` has an empty factorisation; a prime `n` yields just `[n]`.
