# Print subarray with maximum subarray sum (extended version of above problem)

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Medium

## Problem
Given an integer array, find the contiguous subarray whose sum is the largest and return the subarray itself (its elements, or equivalently its start and end indices), not just the sum. The subarray must be non-empty. If several subarrays tie, returning any one of them is acceptable; the code below returns the first one found.

```
Input:  nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
Output: [4, -1, 2, 1]        (sum 6, indices 3..6)
```

## Approach 1: Brute Force
Try every `(start, end)` range, accumulate the sum while extending `end`, and remember the range with the largest sum. Finally slice out that range.
- **Time:** O(n²)
- **Space:** O(1) extra (plus the output)

## Approach 2: Kadane with Index Tracking (Optimal)
Run Kadane's scan, but also track *where* the current running subarray began:
1. Keep `cur` (best sum ending at `i`) and `curStart` (where that subarray starts).
2. If `cur` has become negative before adding `nums[i]`, discard it: set `cur = 0` and `curStart = i`.
3. Add `nums[i]` to `cur`. If `cur` beats `best`, record `bestStart = curStart` and `bestEnd = i`.

The reset in step 2 is the only place the start index moves, so the recorded `[bestStart, bestEnd]` is exactly the subarray that produced `best`.
- **Time:** O(n)
- **Space:** O(1) extra (plus the output)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <climits>
using namespace std;

class Solution {
public:
    // Returns the maximum-sum subarray as a vector.
    vector<int> maxSumSubarray(const vector<int>& nums) {
        int n = (int)nums.size();
        long long cur = 0, best = LLONG_MIN;
        int curStart = 0, bestStart = 0, bestEnd = 0;
        for (int i = 0; i < n; ++i) {
            if (cur < 0) {          // running sum is useless, restart here
                cur = 0;
                curStart = i;
            }
            cur += nums[i];
            if (cur > best) {
                best = cur;
                bestStart = curStart;
                bestEnd = i;
            }
        }
        return vector<int>(nums.begin() + bestStart, nums.begin() + bestEnd + 1);
    }
};
```

### Java
```java
import java.util.Arrays;

class Solution {
    public int[] maxSumSubarray(int[] nums) {
        long cur = 0, best = Long.MIN_VALUE;
        int curStart = 0, bestStart = 0, bestEnd = 0;
        for (int i = 0; i < nums.length; i++) {
            if (cur < 0) {
                cur = 0;
                curStart = i;
            }
            cur += nums[i];
            if (cur > best) {
                best = cur;
                bestStart = curStart;
                bestEnd = i;
            }
        }
        return Arrays.copyOfRange(nums, bestStart, bestEnd + 1);
    }
}
```

### Python
```python
from typing import List

class Solution:
    def maxSumSubarray(self, nums: List[int]) -> List[int]:
        cur = 0
        best = float("-inf")
        cur_start = best_start = best_end = 0
        for i, x in enumerate(nums):
            if cur < 0:
                cur = 0
                cur_start = i
            cur += x
            if cur > best:
                best = cur
                best_start, best_end = cur_start, i
        return nums[best_start:best_end + 1]
```

## Key Takeaways
- Same scan as Kadane; the only addition is remembering where the running subarray started and copying it whenever a new maximum appears.
- Reset `cur` and `curStart` *before* adding the current element, so the current element is always part of a candidate subarray.
- Initialise `best` to negative infinity so an all-negative array still returns its largest single element.
- Use strict `>` when updating `best` to keep the first maximal subarray (use `>=` to keep the last).
