# Pattern 16

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Patterns

## Problem
Given an integer `n`, print a right-angled triangle of `n` rows where row `i` (0-indexed) contains the `i`-th uppercase letter repeated `i + 1` times, separated by spaces.

Input: `n = 5`
Output:
```
A
B B
C C C
D D D D
E E E E E
```

## Approach
This is the letter version of Pattern 4: the printed character is decided by the row index, not the column.

1. Outer loop `i` from `0` to `n-1`; compute `ch = 'A' + i` once per row.
2. Inner loop runs `i + 1` times and prints `ch`.
3. Newline.

- **Time:** O(n²).
- **Space:** O(1).

## Code (Optimal)

### C++
```cpp
#include <iostream>
using namespace std;

void pattern16(int n) {
    for (int i = 0; i < n; i++) {
        char ch = 'A' + i;
        for (int j = 0; j <= i; j++) {
            cout << ch << " ";
        }
        cout << "\n";
    }
}
```

### Java
```java
public class Pattern16 {
    public static void pattern16(int n) {
        for (int i = 0; i < n; i++) {
            char ch = (char) ('A' + i);
            StringBuilder row = new StringBuilder();
            for (int j = 0; j <= i; j++) {
                row.append(ch).append(' ');
            }
            System.out.println(row);
        }
    }
}
```

### Python
```python
def pattern16(n: int) -> None:
    for i in range(n):
        ch = chr(ord("A") + i)
        print(" ".join([ch] * (i + 1)))
```

## Key Takeaways
- Row-driven content: compute the character once per row and reuse it in the inner loop.
- Patterns 14 and 16 differ only in whether `'A'` is offset by `j` or by `i`.
- For `n > 26` the letters run past `Z`; the sheet's constraints keep `n` small enough that this does not matter.
