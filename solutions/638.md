# Longest Palindromic Substring

**Difficulty:** Medium  ·  **Topic:** Strings [Basic and Medium] › Medium String Problems

## Problem
Given a string `s`, return the longest contiguous substring that reads the same forwards and backwards. If several have the maximum length, any one of them is accepted.

Input: `s = "babad"`
Output: `"bab"`  (`"aba"` is also correct)

Input: `s = "cbbd"`
Output: `"bb"`

## Approach 1: Check every substring
For each pair `(i, j)`, test whether `s[i..j]` is a palindrome with a two-pointer scan and keep the longest. Cubic time; only suitable for tiny inputs.
- **Time:** O(n^3)
- **Space:** O(1)

## Approach 2: Dynamic programming
Let `dp[i][j]` be true when `s[i..j]` is a palindrome. Then `dp[i][j] = (s[i] == s[j]) && (j - i < 2 || dp[i+1][j-1])`. Fill by increasing length and remember the longest true cell. Correct and systematic, but uses an n×n table.
- **Time:** O(n^2)
- **Space:** O(n^2)

## Approach 3: Expand around centre (Optimal for interviews)
Every palindrome has a centre: either a single character (odd length) or the gap between two equal characters (even length). There are `2n - 1` centres. For each centre, expand outward while the characters on both sides match, and record the longest span found.

This is O(n^2) in the worst case (e.g. `"aaaa..."`) but with O(1) memory and a tiny constant, which is why it is the standard interview answer. (Manacher's algorithm achieves O(n) but is rarely expected.)
- **Time:** O(n^2)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Solution {
    // Expands from [l, r] while chars match; returns length of the palindrome.
    int expand(const string& s, int l, int r) {
        while (l >= 0 && r < (int)s.size() && s[l] == s[r]) { l--; r++; }
        return r - l - 1;
    }
public:
    string longestPalindrome(string s) {
        if (s.empty()) return "";
        int bestStart = 0, bestLen = 1;
        for (int c = 0; c < (int)s.size(); ++c) {
            int odd = expand(s, c, c);
            int even = expand(s, c, c + 1);
            int len = odd > even ? odd : even;
            if (len > bestLen) {
                bestLen = len;
                bestStart = c - (len - 1) / 2;
            }
        }
        return s.substr(bestStart, bestLen);
    }
};
```

### Java
```java
class Solution {
    private int expand(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
        return r - l - 1;
    }

    public String longestPalindrome(String s) {
        if (s.isEmpty()) return "";
        int bestStart = 0, bestLen = 1;
        for (int c = 0; c < s.length(); c++) {
            int odd = expand(s, c, c);
            int even = expand(s, c, c + 1);
            int len = Math.max(odd, even);
            if (len > bestLen) {
                bestLen = len;
                bestStart = c - (len - 1) / 2;
            }
        }
        return s.substring(bestStart, bestStart + bestLen);
    }
}
```

### Python
```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        if not s:
            return ""

        def expand(l: int, r: int) -> int:
            while l >= 0 and r < len(s) and s[l] == s[r]:
                l -= 1
                r += 1
            return r - l - 1

        best_start, best_len = 0, 1
        for c in range(len(s)):
            length = max(expand(c, c), expand(c, c + 1))
            if length > best_len:
                best_len = length
                best_start = c - (length - 1) // 2
        return s[best_start:best_start + best_len]
```

## Key Takeaways
- Palindromes are defined by their centre; try all `2n - 1` centres (odd and even).
- `start = centre - (len - 1) / 2` works for both parities when `len` comes from the expand helper.
- The expand helper returns `r - l - 1` because the loop overshoots by one on each side.
- Edge cases: single character, all identical characters, no palindrome longer than 1.
