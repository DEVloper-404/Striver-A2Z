# Count Number of Substrings

**Difficulty:** Easy  ·  **Topic:** Strings [Basic and Medium] › Medium String Problems

## Problem
Given a string `s` and an integer `k`, count the substrings of `s` that contain **exactly** `k` distinct characters. Substrings are contiguous and are counted by position, so two equal substrings at different positions count twice.

Input: `s = "aba", k = 2`
Output: `3`  (`"ab"`, `"ba"`, `"aba"`)

Input: `s = "abc", k = 2`
Output: `2`  (`"ab"`, `"bc"`)

## Approach 1: Enumerate every substring
For each start index, extend the end index one character at a time while maintaining a frequency array and a distinct-count. Whenever the distinct count equals `k`, increment the answer; once it exceeds `k`, break (extending further only adds more distinct characters).
- **Time:** O(n^2)
- **Space:** O(1) (26-slot array)

## Approach 2: Sliding window with "at most k" (Optimal)
Counting windows with **exactly** `k` distinct characters directly is awkward because the condition is not monotonic. But "at most `k` distinct" is monotonic: if a window qualifies, every sub-window does too. So:

`exactly(k) = atMost(k) - atMost(k - 1)`

`atMost(k)` with a sliding window: expand `right` one step, add `s[right]` to the frequency map; while the number of distinct characters exceeds `k`, shrink from `left`. Then every window ending at `right` with start in `[left, right]` is valid, contributing `right - left + 1`.

Two linear passes give the answer.
- **Time:** O(n)
- **Space:** O(1) (fixed-size frequency array)

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Solution {
    long long atMost(const string& s, int k) {
        if (k < 0) return 0;
        int cnt[26] = {0};
        int distinct = 0, left = 0;
        long long total = 0;
        for (int right = 0; right < (int)s.size(); ++right) {
            if (cnt[s[right] - 'a']++ == 0) distinct++;
            while (distinct > k) {
                if (--cnt[s[left] - 'a'] == 0) distinct--;
                left++;
            }
            total += right - left + 1;
        }
        return total;
    }
public:
    long long countSubstrings(string s, int k) {
        return atMost(s, k) - atMost(s, k - 1);
    }
};
```

```java
class Solution {
    private long atMost(String s, int k) {
        if (k < 0) return 0;
        int[] cnt = new int[26];
        int distinct = 0, left = 0;
        long total = 0;
        for (int right = 0; right < s.length(); right++) {
            if (cnt[s.charAt(right) - 'a']++ == 0) distinct++;
            while (distinct > k) {
                if (--cnt[s.charAt(left) - 'a'] == 0) distinct--;
                left++;
            }
            total += right - left + 1;
        }
        return total;
    }

    public long countSubstrings(String s, int k) {
        return atMost(s, k) - atMost(s, k - 1);
    }
}
```

### Python
```python
class Solution:
    def countSubstrings(self, s: str, k: int) -> int:
        def at_most(k: int) -> int:
            if k < 0:
                return 0
            cnt = {}
            distinct = left = total = 0
            for right, ch in enumerate(s):
                cnt[ch] = cnt.get(ch, 0) + 1
                if cnt[ch] == 1:
                    distinct += 1
                while distinct > k:
                    lc = s[left]
                    cnt[lc] -= 1
                    if cnt[lc] == 0:
                        distinct -= 1
                    left += 1
                total += right - left + 1
            return total

        return at_most(k) - at_most(k - 1)
```

## Key Takeaways
- "Exactly k" is not monotonic; convert it to the difference of two monotonic "at most" counts.
- In an "at most" window, every valid window ending at `right` is counted by `right - left + 1`.
- Use a `long`/64-bit accumulator: the count can reach ~n^2 / 2.
- Edge cases: `k = 0` (answer 0), `k` larger than the number of distinct characters (answer 0).
