# Count subarrays with given xor K

**Difficulty:** Hard  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Hard

## Problem
Given an integer array `arr` and an integer `k`, count how many contiguous subarrays have a bitwise XOR of all their elements equal to `k`.

Input: `arr = [4, 2, 2, 6, 4]`, `k = 6`
Output: `4` (subarrays `[4,2]`, `[2,2,6]`, `[6]`, `[2,6,4]`... specifically: `[4,2]`, `[6]`, `[2,2,6]`, `[6,4]`? No — `6^4 = 2`; the four are `[4,2]`, `[6]`, `[2,2,6]`, `[4,2,2,6,4]`? Let us verify: `4^2=6` ✓, `6` ✓, `2^2^6=6` ✓, `4^2^2^6^4=6` ✓. So the count is 4.)

## Approach 1: Brute Force
For every start `i`, extend the end `j` and keep a running XOR. Increment the answer each time the running XOR equals `k`. XOR is associative so no recomputation is needed inside the inner loop.
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Prefix XOR + hash map (Optimal)
Let `X[j]` be the XOR of `arr[0..j]`. The XOR of subarray `(i, j]` is `X[j] ^ X[i]` (XOR is its own inverse). We want `X[j] ^ X[i] == k`, i.e. `X[i] == X[j] ^ k`.

1. Keep a frequency map of prefix XOR values seen so far, seeded with `{0: 1}` to represent the empty prefix.
2. For each position, update the running XOR `cur`, then add `freq[cur ^ k]` to the answer — that is the number of earlier prefixes that pair with the current one to give `k`.
3. Then record `cur` in the map.

The seed `{0: 1}` handles subarrays that start at index 0.

- **Time:** O(n) average
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int subarraysWithXorK(vector<int>& arr, int k) {
        unordered_map<int, int> freq;
        freq[0] = 1;
        int cur = 0, count = 0;
        for (int x : arr) {
            cur ^= x;
            auto it = freq.find(cur ^ k);
            if (it != freq.end()) count += it->second;
            freq[cur]++;
        }
        return count;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int subarraysWithXorK(int[] arr, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        freq.put(0, 1);
        int cur = 0, count = 0;
        for (int x : arr) {
            cur ^= x;
            count += freq.getOrDefault(cur ^ k, 0);
            freq.merge(cur, 1, Integer::sum);
        }
        return count;
    }
}
```

### Python
```python
from typing import List
from collections import defaultdict

class Solution:
    def subarraysWithXorK(self, arr: List[int], k: int) -> int:
        freq = defaultdict(int)
        freq[0] = 1
        cur = 0
        count = 0
        for x in arr:
            cur ^= x
            count += freq[cur ^ k]
            freq[cur] += 1
        return count
```

## Key Takeaways
- Prefix XOR works exactly like prefix sum, except "subtraction" is XOR again because `a ^ a = 0`.
- Look up `cur ^ k` *before* inserting `cur`, otherwise a `k == 0` case would count the current prefix against itself.
- Seeding the map with `0 -> 1` is what lets subarrays beginning at index 0 be counted.
