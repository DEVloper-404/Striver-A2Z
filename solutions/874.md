# Word Search

**Difficulty:** Hard  ·  **Topic:** Recursion [PatternWise] › Trying out all Combos / Hard

## Problem
You are given an `m x n` grid of characters `board` and a string `word`. Decide whether `word` can be traced through the grid by moving only up, down, left or right between adjacent cells, using each cell at most once in a single trace. Return `true` or `false`.

Input: `board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]`, `word = "ABCCED"`
Output: `true`

## Approach 1: Try every path from every cell
From every cell, enumerate every simple path of length `len(word)` and compare it with the word. This is the same recursion as the optimal solution but without checking the character until the end, so the branching is a full 4-way fan-out at every step.
- **Time:** O(m · n · 4^L) where `L = len(word)`
- **Space:** O(L) recursion depth

## Approach 2: DFS with per-character pruning (Optimal)
Start a DFS from every cell whose character equals `word[0]`. At recursion depth `k` we are standing on a cell that matches `word[k]`; if `k` is the last index we are done. Otherwise mark the current cell as visited (overwrite it with a sentinel such as `'#'`), try the four neighbours whose character equals `word[k+1]`, then restore the cell before returning.

Two cheap optimisations help a lot on adversarial inputs: return immediately when a neighbour's character does not match, and bail out early at the start if any character in `word` appears more times than it appears in the grid.
- **Time:** O(m · n · 3^L) — after the first step each cell has at most three unvisited neighbours
- **Space:** O(L) recursion depth; the grid itself is used as the visited marker

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
    int m, n;
    bool dfs(vector<vector<char>>& b, const string& w, int r, int c, int k) {
        if (r < 0 || c < 0 || r >= m || c >= n || b[r][c] != w[k]) return false;
        if (k + 1 == (int)w.size()) return true;
        char keep = b[r][c];
        b[r][c] = '#';
        bool found = dfs(b, w, r + 1, c, k + 1) || dfs(b, w, r - 1, c, k + 1) ||
                     dfs(b, w, r, c + 1, k + 1) || dfs(b, w, r, c - 1, k + 1);
        b[r][c] = keep;
        return found;
    }
public:
    bool exist(vector<vector<char>>& board, string word) {
        m = board.size(); n = board[0].size();
        for (int r = 0; r < m; ++r)
            for (int c = 0; c < n; ++c)
                if (dfs(board, word, r, c, 0)) return true;
        return false;
    }
};
```

### Java
```java
class Solution {
    private int m, n;

    public boolean exist(char[][] board, String word) {
        m = board.length; n = board[0].length;
        for (int r = 0; r < m; r++)
            for (int c = 0; c < n; c++)
                if (dfs(board, word, r, c, 0)) return true;
        return false;
    }

    private boolean dfs(char[][] b, String w, int r, int c, int k) {
        if (r < 0 || c < 0 || r >= m || c >= n || b[r][c] != w.charAt(k)) return false;
        if (k + 1 == w.length()) return true;
        char keep = b[r][c];
        b[r][c] = '#';
        boolean found = dfs(b, w, r + 1, c, k + 1) || dfs(b, w, r - 1, c, k + 1)
                     || dfs(b, w, r, c + 1, k + 1) || dfs(b, w, r, c - 1, k + 1);
        b[r][c] = keep;
        return found;
    }
}
```

### Python
```python
from typing import List

class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        m, n, L = len(board), len(board[0]), len(word)

        def dfs(r: int, c: int, k: int) -> bool:
            if r < 0 or c < 0 or r >= m or c >= n or board[r][c] != word[k]:
                return False
            if k + 1 == L:
                return True
            keep = board[r][c]
            board[r][c] = "#"
            found = (dfs(r + 1, c, k + 1) or dfs(r - 1, c, k + 1) or
                     dfs(r, c + 1, k + 1) or dfs(r, c - 1, k + 1))
            board[r][c] = keep
            return found

        return any(dfs(r, c, 0) for r in range(m) for c in range(n))
```

## Key Takeaways
- Grid DFS with backtracking: mark the cell before descending, restore it after, so other branches can reuse it.
- Check the character mismatch at the top of the recursion so every wrong branch dies immediately.
- Using the board itself as the visited set avoids an extra `m x n` array.
- Edge cases: a one-character word, a word longer than `m·n`, and words that need to revisit the same cell (not allowed).
