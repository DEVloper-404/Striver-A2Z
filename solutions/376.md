# Reverse a number

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Know Basic Maths

## Problem
Given a signed 32-bit integer `x`, return the integer formed by reversing its digits. The sign is preserved. If the reversed value does not fit in a signed 32-bit integer (`[-2^31, 2^31 - 1]`), return `0`. You may not use 64-bit integers to hold the intermediate result (the LeetCode version enforces this).

Input: `x = 123`
Output: `321`

Input: `x = -120`
Output: `-21`

Input: `x = 1534236469`
Output: `0` (reversed value overflows)

## Approach 1: Build the reverse digit by digit
Peel off the last digit with `x % 10`, then append it to the result with `rev = rev * 10 + digit`. Repeat until `x` becomes 0. Working on the absolute value and re-applying the sign keeps the logic simple, but with a 64-bit accumulator you can also just let `%` produce negative digits in C++/Java, which naturally preserves the sign.

Trailing zeros vanish automatically (`120 → 021 → 21`), which is the intended behaviour.

- **Time:** O(log₁₀ |x|)
- **Space:** O(1)

## Approach 2: Same loop with overflow check before each append
The only subtlety is overflow. Before computing `rev * 10 + digit`, check whether it would exceed the 32-bit range:

- If `rev > INT_MAX / 10`, or `rev == INT_MAX / 10` and `digit > 7`, the result would overflow positively.
- If `rev < INT_MIN / 10`, or `rev == INT_MIN / 10` and `digit < -8`, it would overflow negatively.

In Python integers never overflow, so you compute the reverse and then compare with the bounds.

- **Time:** O(log₁₀ |x|)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int reverse(int x) {
        int rev = 0;
        while (x != 0) {
            int digit = x % 10;   // negative when x is negative
            x /= 10;
            if (rev > INT_MAX / 10 || (rev == INT_MAX / 10 && digit > 7)) return 0;
            if (rev < INT_MIN / 10 || (rev == INT_MIN / 10 && digit < -8)) return 0;
            rev = rev * 10 + digit;
        }
        return rev;
    }
};
```

### Java
```java
class Solution {
    public int reverse(int x) {
        int rev = 0;
        while (x != 0) {
            int digit = x % 10;   // negative when x is negative
            x /= 10;
            if (rev > Integer.MAX_VALUE / 10 || (rev == Integer.MAX_VALUE / 10 && digit > 7)) return 0;
            if (rev < Integer.MIN_VALUE / 10 || (rev == Integer.MIN_VALUE / 10 && digit < -8)) return 0;
            rev = rev * 10 + digit;
        }
        return rev;
    }
}
```

### Python
```python
class Solution:
    def reverse(self, x: int) -> int:
        sign = -1 if x < 0 else 1
        n = abs(x)
        rev = 0
        while n > 0:
            rev = rev * 10 + n % 10
            n //= 10
        rev *= sign
        if rev < -(2 ** 31) or rev > 2 ** 31 - 1:
            return 0
        return rev
```

## Key Takeaways
- `rev = rev * 10 + x % 10; x /= 10` is the standard digit-reversal loop; it also silently drops trailing zeros.
- Check for overflow *before* the multiply-add, comparing against `INT_MAX / 10`, because after the fact the value is already wrong.
- In C++ and Java, `%` on a negative number gives a negative remainder, which lets one loop handle both signs without special cases.
