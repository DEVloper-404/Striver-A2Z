# Find Min/Max in BST

**Difficulty:** Easy  ·  **Topic:** Binary Search Trees [Concept and Problems] › Concepts

## Problem
Given the root of a BST, return its smallest and largest values. If the tree is empty, indicate that (return -1 or null depending on the platform).

Input: root = [8, 3, 10, 1, 6, null, 14]
Output: min = 1, max = 14

Input: root = [5]
Output: min = 5, max = 5

## Approach 1: Brute Force (full traversal)
Traverse every node (any order) and keep running minimum and maximum. This treats the tree as a plain binary tree and ignores the ordering.
- **Time:** O(N)
- **Space:** O(H)

## Approach 2: Optimal (follow the spine)
In a BST every left child is smaller than its parent and every right child is larger. So the minimum is the leftmost node: start at the root and follow `left` until it is null. Symmetrically, the maximum is the rightmost node reached by following `right`. No comparisons with values are needed at all.
- **Time:** O(H)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition
class Solution {
public:
    int minValue(TreeNode* root) {
        if (!root) return -1;
        while (root->left) root = root->left;
        return root->val;
    }
    int maxValue(TreeNode* root) {
        if (!root) return -1;
        while (root->right) root = root->right;
        return root->val;
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
class Solution {
    public int minValue(TreeNode root) {
        if (root == null) return -1;
        while (root.left != null) root = root.left;
        return root.val;
    }
    public int maxValue(TreeNode root) {
        if (root == null) return -1;
        while (root.right != null) root = root.right;
        return root.val;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition

class Solution:
    def minValue(self, root):
        if root is None:
            return -1
        while root.left:
            root = root.left
        return root.val

    def maxValue(self, root):
        if root is None:
            return -1
        while root.right:
            root = root.right
        return root.val
```

## Key Takeaways
- Leftmost node = minimum, rightmost node = maximum; this is a direct consequence of the BST invariant.
- These two helpers are building blocks for BST deletion (inorder successor/predecessor) and for validation problems.
- Handle the empty tree explicitly; the sentinel value depends on the judge (-1 is common when values are positive).
- The walk is O(H), so a degenerate BST still costs O(N).
