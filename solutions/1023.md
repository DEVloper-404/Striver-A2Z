# Longest Word with All Prefixes

**Difficulty:** Medium  ·  **Topic:** Tries › Problems

## Problem
Given an array of strings, find the longest string `w` in the array such that **every** prefix of `w` (of length 1, 2, ..., |w|) is also present in the array. If several such strings share the maximum length, return the lexicographically smallest one. If no string qualifies, return `"None"`.

```
Input:  words = ["n", "ni", "nin", "ninj", "ninja", "ninga"]
Output: "ninja"
```
`"ninja"` works because `n`, `ni`, `nin`, `ninj`, `ninja` are all in the array. `"ninga"` fails because its prefix `"ning"` is missing.

## Approach 1: Hash set of all words (Brute Force / Better)

Put every word in a hash set. For each word, generate all its prefixes and check membership. Simple and often fast enough, but generating prefixes creates a fresh string of length up to `L` for every prefix, so building them costs O(L^2) characters copied per word.

- **Time:** O(N · L^2) including string construction and hashing
- **Space:** O(N · L) for the set

## Approach 2: Trie with `isEnd` checks along one walk (Optimal)

**The key observation.** In a trie, walking a word visits exactly the nodes corresponding to its prefixes, in order, in a single pass. Prefix `w[0..i]` is a stored word if and only if the node reached after consuming `w[i]` has `isEnd = true`. So "are *all* prefixes present?" becomes "does every node along this walk have `isEnd = true`?" — one O(L) walk, no substring construction at all.

**The algorithm.**
1. Insert every word from the array into a trie (standard insert with `isEnd`).
2. For each word `w`, walk it from the root. At each step move to the child for the current character (it must exist, since `w` itself was inserted) and check `isEnd`. If any node on the path has `isEnd = false`, reject `w` immediately.
3. Among the accepted words, keep the best: strictly longer wins; on equal length, the lexicographically smaller string wins.
4. If nothing was accepted, return `"None"`.

**Why the child is always present.** We only ever walk words we inserted ourselves, so the path is guaranteed to exist. A missing child would indicate a bug, not a legitimate "not found" — but keeping a defensive check costs nothing.

**Handling the tie-break.** Initialise the answer to the empty string. When a word passes, update if `w.length() > best.length()`, or if the lengths are equal and `w < best` lexicographically. Alternatively, sorting the words first and taking the first maximum-length success achieves the same thing.

**Dry run on `["n","ni","nin","ninj","ninja","ninga"]`.**

After inserting all six words, the trie has one chain `n → i → n` which then branches into `j → a` and `g → a`. The `isEnd` flags sit on `n`, `ni`, `nin`, `ninj`, `ninja`, `ninga`.

- `"n"`: walk visits node `n`, `isEnd = true` → accepted, best = `"n"` (length 1).
- `"ni"`: visits `n`(true), `ni`(true) → accepted, best = `"ni"` (length 2).
- `"nin"`: `n`, `ni`, `nin` all true → accepted, best = `"nin"`.
- `"ninj"`: `n`, `ni`, `nin`, `ninj` all true → accepted, best = `"ninj"`.
- `"ninja"`: `n`, `ni`, `nin`, `ninj`, `ninja` all true → accepted, best = `"ninja"` (length 5).
- `"ninga"`: `n`(true), `ni`(true), `nin`(true), then node `ning` — this node exists only because `"ninga"` passes through it, and nobody inserted `"ning"`, so `isEnd = false` → **rejected** at the fourth character, without even looking at the last letter.

Answer: `"ninja"`. Note the rejection of `"ninga"` is exactly the case that distinguishes "the path exists" from "every prefix is a word", which is why `isEnd` and not mere path existence is the test.

- **Time:** O(N · L) to build plus O(N · L) to check
- **Space:** O(N · L) trie nodes

## Code (Optimal)

### C++
```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
    struct Node {
        Node* links[26] = {nullptr};
        bool isEnd = false;
    };
    Node* root;

    void insert(const string& word) {
        Node* cur = root;
        for (char ch : word) {
            int idx = ch - 'a';
            if (cur->links[idx] == nullptr) cur->links[idx] = new Node();
            cur = cur->links[idx];
        }
        cur->isEnd = true;
    }

    // true iff every prefix of `word` is itself a stored word
    bool allPrefixesExist(const string& word) {
        Node* cur = root;
        for (char ch : word) {
            int idx = ch - 'a';
            if (cur->links[idx] == nullptr) return false;
            cur = cur->links[idx];
            if (!cur->isEnd) return false;
        }
        return true;
    }

public:
    string completeString(vector<string>& words) {
        root = new Node();
        for (const string& w : words) insert(w);

        string best = "";
        for (const string& w : words) {
            if (!allPrefixesExist(w)) continue;
            if (w.size() > best.size() ||
                (w.size() == best.size() && w < best)) {
                best = w;
            }
        }
        return best.empty() ? "None" : best;
    }
};
```

### Java
```java
class Solution {
    private static class Node {
        Node[] links = new Node[26];
        boolean isEnd = false;
    }

    private Node root;

    private void insert(String word) {
        Node cur = root;
        for (int i = 0; i < word.length(); i++) {
            int idx = word.charAt(i) - 'a';
            if (cur.links[idx] == null) cur.links[idx] = new Node();
            cur = cur.links[idx];
        }
        cur.isEnd = true;
    }

    private boolean allPrefixesExist(String word) {
        Node cur = root;
        for (int i = 0; i < word.length(); i++) {
            int idx = word.charAt(i) - 'a';
            if (cur.links[idx] == null) return false;
            cur = cur.links[idx];
            if (!cur.isEnd) return false;
        }
        return true;
    }

    public String completeString(String[] words) {
        root = new Node();
        for (String w : words) insert(w);

        String best = "";
        for (String w : words) {
            if (!allPrefixesExist(w)) continue;
            if (w.length() > best.length()
                    || (w.length() == best.length() && w.compareTo(best) < 0)) {
                best = w;
            }
        }
        return best.isEmpty() ? "None" : best;
    }
}
```

### Python
```python
from typing import List


class _Node:
    __slots__ = ("links", "is_end")

    def __init__(self):
        self.links = {}
        self.is_end = False


class Solution:
    def completeString(self, words: List[str]) -> str:
        root = _Node()

        for w in words:
            cur = root
            for ch in w:
                if ch not in cur.links:
                    cur.links[ch] = _Node()
                cur = cur.links[ch]
            cur.is_end = True

        def all_prefixes_exist(word: str) -> bool:
            cur = root
            for ch in word:
                if ch not in cur.links:
                    return False
                cur = cur.links[ch]
                if not cur.is_end:
                    return False
            return True

        best = ""
        for w in words:
            if not all_prefixes_exist(w):
                continue
            if len(w) > len(best) or (len(w) == len(best) and w < best):
                best = w

        return best if best else "None"
```

## Key Takeaways
- Walking a word in a trie visits its prefixes for free; checking `isEnd` at every step answers "all prefixes present?" in one O(L) pass with zero substring allocation.
- The trap is treating "the path exists" as "the prefix is a word" — only `isEnd` distinguishes them, as `"ninga"` demonstrates.
- Remember the tie-break: longest first, lexicographically smallest among equals; an empty best means return `"None"`.
- Edge cases: an empty input array, and words whose first character alone is not in the array (rejected on the very first step).
