# Number of Substrings Containing All Three Characters

**Difficulty:** Hard  ·  **Topic:** Sliding Window & Two Pointer Combined Problems › Medium Problems

## Problem
Given a string `s` made only of the letters `a`, `b`, and `c`, count the substrings that contain at least one of each letter.

Input: `s = "abcabc"`
Output: `10` (`"abc"`, `"abca"`, `"abcab"`, `"abcabc"`, `"bca"`, `"bcab"`, `"bcabc"`, `"cab"`, `"cabc"`, `"abc"`)

## Approach 1: Brute Force
For every start index, extend to the right while tracking which of the three letters are present. Once all three are present at position `j`, every longer substring starting at the same index is also valid, so add `n - j` and move to the next start.

- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Last Occurrence Trick (Optimal)
For each right endpoint `r`, the number of valid substrings ending at `r` equals the number of start positions `x` such that `[x, r]` contains all three letters. That holds exactly when `x <= min(lastA, lastB, lastC)`, where `lastX` is the most recent index of each letter. So the contribution of `r` is `min(lastA, lastB, lastC) + 1` (zero if some letter has not appeared yet, which we encode with an initial index of -1).

Single pass, constant extra state.

- **Time:** O(n)
- **Space:** O(1)

## Approach 3: Sliding Window Counting (Alternative Optimal)
Keep counts of the three letters in `[l, r]`. While the window contains all three, add `n - r` (every extension to the right of a valid window is also valid) and shrink from the left. This also runs in linear time and is a good template for "count substrings satisfying a monotone property".

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    int numberOfSubstrings(string s) {
        int last[3] = {-1, -1, -1};
        int total = 0;
        for (int r = 0; r < (int)s.size(); ++r) {
            last[s[r] - 'a'] = r;
            total += min({last[0], last[1], last[2]}) + 1;
        }
        return total;
    }
};
```

### Java
```java
class Solution {
    public int numberOfSubstrings(String s) {
        int[] last = {-1, -1, -1};
        int total = 0;
        for (int r = 0; r < s.length(); r++) {
            last[s.charAt(r) - 'a'] = r;
            total += Math.min(last[0], Math.min(last[1], last[2])) + 1;
        }
        return total;
    }
}
```

### Python
```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        last = [-1, -1, -1]
        total = 0
        for r, ch in enumerate(s):
            last[ord(ch) - ord('a')] = r
            total += min(last) + 1
        return total
```

## Key Takeaways
- Counting substrings "ending at r" and summing over `r` avoids double counting.
- The smallest last-occurrence index bounds the rightmost valid start.
- Initialising last-seen indices to -1 makes the "letter missing" case contribute zero automatically.
