# Minimum number of platforms required for a railway

**Difficulty:** Medium  ·  **Topic:** Greedy Algorithms [Easy, Medium/Hard] › Medium/Hard

## Problem
You are given arrival times `arr[i]` and departure times `dep[i]` for `n` trains at a station (times as integers such as `0900`, `1130`). A train occupies a platform from its arrival until its departure, inclusive, so two trains whose intervals touch (one departs at the same minute another arrives) still need separate platforms. Return the minimum number of platforms so that no train has to wait.

Input: `arr = [900, 940, 950, 1100, 1500, 1800]`, `dep = [910, 1200, 1120, 1130, 1900, 2000]`
Output: `3` (at 11:00 trains 2, 3 and 4 are all present)

## Approach 1: Brute Force
For each train `i`, count how many other trains `j` overlap with it (`arr[j] <= dep[i] && arr[i] <= dep[j]`). The answer is the maximum overlap count, including the train itself.
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Sort and sweep with two pointers (Optimal)
Sort arrivals and departures independently. Sweep through time: every arrival puts one more train on a platform, every departure frees one. The peak number of trains present at once is the answer.

1. Sort `arr` and `dep`.
2. Pointers `i` (arrivals) and `j` (departures), `count = 0`, `best = 0`.
3. While `i < n`: if `arr[i] <= dep[j]`, a train arrives before (or exactly when) the next one leaves: `count++`, `i++`. Otherwise a train left: `count--`, `j++`.
4. Track `best = max(best, count)`.

The `<=` matters: arrival at the same minute as a departure counts as overlapping.
- **Time:** O(n log n)
- **Space:** O(1) beyond the sort

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findPlatform(vector<int>& arr, vector<int>& dep) {
        int n = arr.size();
        sort(arr.begin(), arr.end());
        sort(dep.begin(), dep.end());

        int i = 0, j = 0, count = 0, best = 0;
        while (i < n) {
            if (arr[i] <= dep[j]) {
                count++;
                i++;
            } else {
                count--;
                j++;
            }
            best = max(best, count);
        }
        return best;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def findPlatform(self, arr: List[int], dep: List[int]) -> int:
        arr = sorted(arr)
        dep = sorted(dep)
        n = len(arr)
        i = j = count = best = 0
        while i < n:
            if arr[i] <= dep[j]:
                count += 1
                i += 1
            else:
                count -= 1
                j += 1
            best = max(best, count)
        return best
```

## Key Takeaways
- Classic "maximum overlap of intervals": sort starts and ends separately and sweep; pairing is not needed.
- The tie rule (`<=`) decides the answer for touching intervals; read the problem statement carefully.
- The sweep never needs `j` bounds-checking because a departure can only be processed after its arrival, so `j < i <= n` always holds.
