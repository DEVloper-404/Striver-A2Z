# Majority Element-II

**Difficulty:** Hard  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Hard

## Problem
Given an integer array `nums` of length `n`, return every element that appears strictly more than `⌊n/3⌋` times. There can be at most two such elements. Order of the output does not matter.

Input: `nums = [3, 2, 3]`
Output: `[3]`

Input: `nums = [1, 1, 1, 3, 3, 2, 2, 2]`
Output: `[1, 2]`

## Approach 1: Brute Force
For every index, count how many times that value occurs by scanning the whole array. If the count exceeds `n/3` and the value is not already in the answer, add it. Stop as soon as two answers are found.
- **Time:** O(n²)
- **Space:** O(1) extra (answer holds at most 2 values)

## Approach 2: Hash Map of counts
Count each value in a map. Then walk the map and pick every key whose count is `> n/3`. Simple and correct, but it needs a map that can grow to `n` entries.
- **Time:** O(n)
- **Space:** O(n)

## Approach 3: Extended Boyer–Moore voting (Optimal)
Key observation: at most two elements can exceed `n/3`, because three such elements would need more than `n` total occurrences. So keep two candidate slots, each with a counter.

1. Scan the array. If the value equals candidate 1, bump `cnt1`; else if equals candidate 2, bump `cnt2`; else if `cnt1 == 0`, adopt it as candidate 1; else if `cnt2 == 0`, adopt as candidate 2; otherwise decrement both counters.
2. Decrementing both counters is like discarding a triple of three distinct values. Any element with more than `n/3` occurrences cannot be fully discarded that way, so it must survive as a candidate.
3. Candidates are only "survivors", not guaranteed answers. Do a second pass to count each candidate and keep it only if its count is `> n/3`.

- **Time:** O(n) — two passes
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> majorityElement(vector<int>& nums) {
        int n = nums.size();
        int cand1 = 0, cand2 = 0, cnt1 = 0, cnt2 = 0;
        bool has1 = false, has2 = false;

        for (int x : nums) {
            if (has1 && x == cand1) cnt1++;
            else if (has2 && x == cand2) cnt2++;
            else if (cnt1 == 0) { cand1 = x; cnt1 = 1; has1 = true; }
            else if (cnt2 == 0) { cand2 = x; cnt2 = 1; has2 = true; }
            else { cnt1--; cnt2--; }
        }

        cnt1 = 0; cnt2 = 0;
        for (int x : nums) {
            if (has1 && x == cand1) cnt1++;
            else if (has2 && x == cand2) cnt2++;
        }

        vector<int> ans;
        if (has1 && cnt1 > n / 3) ans.push_back(cand1);
        if (has2 && cnt2 > n / 3) ans.push_back(cand2);
        return ans;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def majorityElement(self, nums: List[int]) -> List[int]:
        n = len(nums)
        cand1 = cand2 = None
        cnt1 = cnt2 = 0

        for x in nums:
            if cand1 is not None and x == cand1:
                cnt1 += 1
            elif cand2 is not None and x == cand2:
                cnt2 += 1
            elif cnt1 == 0:
                cand1, cnt1 = x, 1
            elif cnt2 == 0:
                cand2, cnt2 = x, 1
            else:
                cnt1 -= 1
                cnt2 -= 1

        ans = []
        for c in (cand1, cand2):
            if c is not None and nums.count(c) > n // 3:
                ans.append(c)
        return ans
```

## Key Takeaways
- At most `k-1` elements can exceed `n/k`; generalise the voting scheme with `k-1` candidate slots.
- Always verify candidates with a second counting pass; the voting pass only guarantees that true majorities survive, not that survivors are majorities.
- Check `x == cand1` before `x == cand2` before the `cnt == 0` branches, otherwise the same value can occupy both slots.
