# Count the Number of Set Bits

**Difficulty:** Easy  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Learn Bit Manipulation

## Problem
Given a non-negative integer `n`, return how many bits are `1` in its binary representation (its Hamming weight or popcount).

Input: `n = 13` (binary `1101`)
Output: `3`

## Approach 1: Shift and test every bit
Loop while `n > 0`: add `n & 1` to the count, then shift `n` right by one. This examines every bit up to the highest set one.
- **Time:** O(log n) — one iteration per bit position
- **Space:** O(1)

## Approach 2: Kernighan's trick `n & (n - 1)` (Optimal)
`n & (n - 1)` removes the lowest set bit of `n`. Repeat until `n` becomes zero and count how many times you did it. The loop runs once per set bit rather than once per bit position, so `n = 2^30` finishes in a single iteration.

Modern CPUs also offer a hardware popcount: `__builtin_popcount` in GCC/Clang, `Integer.bitCount` in Java, and `int.bit_count()` in Python 3.10+.
- **Time:** O(number of set bits), at most O(log n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int countSetBits(int n) {
        int count = 0;
        while (n) {
            n &= (n - 1);   // drop the lowest set bit
            ++count;
        }
        return count;
        // or simply: return __builtin_popcount(n);
    }
};
```

### Java
```java
class Solution {
    public int countSetBits(int n) {
        int count = 0;
        while (n != 0) {
            n &= (n - 1);
            count++;
        }
        return count;
        // or simply: return Integer.bitCount(n);
    }
}
```

### Python
```python
class Solution:
    def countSetBits(self, n: int) -> int:
        count = 0
        while n:
            n &= n - 1
            count += 1
        return count
        # or simply: return bin(n).count("1")
```

## Key Takeaways
- `n & (n - 1)` clears exactly one set bit per step, so the loop count equals the popcount.
- The shift-and-test loop is fine too, but it always walks all bit positions.
- For negative `int` values in C++/Java, use an unsigned/`>>>` shift or Kernighan's method (which terminates correctly since the loop condition is `n != 0`, not `n > 0`).
- Popcount is a building block for problems like "sum of set bits from 1 to N" and "count bits to flip".
