# Wildcard matching

**Difficulty:** Hard  ·  **Topic:** Dynamic Programming [Patterns and Problems] › DP on Strings

## Problem
Given an input string `s` and a pattern `p`, decide whether `p` matches the **entire** string `s`. The pattern may contain two wildcards:
- `?` matches exactly one arbitrary character.
- `*` matches any sequence of characters, including the empty sequence.

Every other character in `p` must match itself.

```
Input:  s = "abcde", p = "a*e"
Output: true      ('*' absorbs "bcd")

Input:  s = "abc",   p = "a?d"
Output: false     ('?' eats 'b', but 'd' != 'c')
```

## Approach 1: Recursion on suffixes (Brute Force)
Compare the two strings from the back. Let `f(i, j)` = "does `p[0..j)` match `s[0..i)`?".

The interesting case is `*`. A `*` can stand for zero characters, one character, two characters, and so on — but instead of branching over every possible length we can use a neat two-way split that covers all of them:

1. **The `*` matches the empty string here** → drop it and ask `f(i, j-1)`.
2. **The `*` consumes `s[i-1]`** → keep the `*` available for more characters and ask `f(i-1, j)`.

Repeatedly applying option 2 generates "star eats k characters" for every `k`, so the two branches together are complete. This is the crucial observation that turns an unbounded branch into a binary one.

For non-star positions:
- If `p[j-1] == '?'` or `p[j-1] == s[i-1]`, the characters are consumed together: `f(i-1, j-1)`.
- Otherwise, the match fails: `false`.

Base cases need care:
- `i == 0 && j == 0` → `true` (empty matches empty).
- `j == 0 && i > 0` → `false` (a non-empty string cannot match an empty pattern).
- `i == 0 && j > 0` → `true` **only if** every character of `p[0..j)` is a `*`, since only stars can vanish.

- **Time:** exponential
- **Space:** O(n + m) recursion depth

## Approach 2: Tabulation (Optimal)
Only `(n+1) × (m+1)` states exist, so build the table bottom-up.

Initialise:
- `dp[0][0] = true`.
- `dp[0][j] = dp[0][j-1] && p[j-1] == '*'` — the leading run of stars matches the empty string, and the moment a non-star appears the rest of the row is false.
- `dp[i][0] = false` for `i > 0`.

Then for each cell:
```
if p[j-1] == '*'                      dp[i][j] = dp[i-1][j] || dp[i][j-1]
else if p[j-1] == '?' or equal chars  dp[i][j] = dp[i-1][j-1]
else                                  dp[i][j] = false
```

**Dry run** for `s = "abcde"`, `p = "a*e"`:

```
          ""     a      *      e
   ""     T      F      F      F
   a      F      T      T      F
   b      F      F      T      F
   c      F      F      T      F
   d      F      F      T      F
   e      F      F      T      T
```
Column `*` becomes true at row `a` (via `dp[a][a] = T` on its left, i.e. the star matching empty) and then stays true all the way down, because each row inherits `dp[i-1][j]` — that is the star swallowing `b`, `c`, `d` one at a time. The final cell is true because `e == e` and the diagonal cell (`abcd`, `a*`) is true.

Since each row reads only the row above and the current row's left neighbour, two rolling arrays of length `m+1` reduce the space to O(m).

- **Time:** O(n · m)
- **Space:** O(m) with the rolling array (O(n·m) for the full table)

## Approach 3: Greedy two pointers (constant space)
An alternative worth knowing: scan `s` and `p` together, and whenever a `*` is seen, remember its position and the current position in `s`. On a later mismatch, "backtrack" — rewind to the last star, let it swallow one more character of `s`, and continue. Trailing stars in `p` are skipped at the end. This runs in O(n · m) worst case but is O(n + m) on typical inputs and uses O(1) memory.

- **Time:** O(n · m) worst case, near O(n + m) typical
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    bool isMatch(string s, string p) {
        int n = s.size(), m = p.size();
        vector<char> prev(m + 1, false), cur(m + 1, false);

        prev[0] = true;                                   // "" matches ""
        for (int j = 1; j <= m; j++)                      // "" vs a run of '*'
            prev[j] = prev[j - 1] && p[j - 1] == '*';

        for (int i = 1; i <= n; i++) {
            cur[0] = false;                               // non-empty s, empty p
            for (int j = 1; j <= m; j++) {
                if (p[j - 1] == '*') {
                    // star matches empty  ||  star swallows s[i-1]
                    cur[j] = cur[j - 1] || prev[j];
                } else if (p[j - 1] == '?' || p[j - 1] == s[i - 1]) {
                    cur[j] = prev[j - 1];
                } else {
                    cur[j] = false;
                }
            }
            prev = cur;
        }
        return prev[m];
    }
};
```

### Java
```java
class Solution {
    public boolean isMatch(String s, String p) {
        int n = s.length(), m = p.length();
        boolean[] prev = new boolean[m + 1];
        boolean[] cur = new boolean[m + 1];

        prev[0] = true;
        for (int j = 1; j <= m; j++) {
            prev[j] = prev[j - 1] && p.charAt(j - 1) == '*';
        }

        for (int i = 1; i <= n; i++) {
            cur[0] = false;
            for (int j = 1; j <= m; j++) {
                char pc = p.charAt(j - 1);
                if (pc == '*') {
                    cur[j] = cur[j - 1] || prev[j];
                } else if (pc == '?' || pc == s.charAt(i - 1)) {
                    cur[j] = prev[j - 1];
                } else {
                    cur[j] = false;
                }
            }
            boolean[] tmp = prev;
            prev = cur;
            cur = tmp;
        }
        return prev[m];
    }
}
```

### Python
```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        n, m = len(s), len(p)
        prev = [False] * (m + 1)
        prev[0] = True
        for j in range(1, m + 1):
            prev[j] = prev[j - 1] and p[j - 1] == '*'

        for i in range(1, n + 1):
            cur = [False] * (m + 1)
            for j in range(1, m + 1):
                if p[j - 1] == '*':
                    cur[j] = cur[j - 1] or prev[j]
                elif p[j - 1] == '?' or p[j - 1] == s[i - 1]:
                    cur[j] = prev[j - 1]
                else:
                    cur[j] = False
            prev = cur
        return prev[m]
```

## Key Takeaways
- The whole problem reduces to one idea: `*` either matches nothing (`dp[i][j-1]`) or eats one more character (`dp[i-1][j]`). Repeating the second option covers all lengths.
- The first row is not all false — a prefix of `p` made entirely of `*` matches the empty string, and that seed is what makes patterns like `"***a"` work.
- Do not confuse this with regex matching (LeetCode 10), where `*` applies to the *preceding* character; here `*` stands alone.
- Watch the degenerate inputs: `s = ""` with `p = "*"` is true, `s = "a"` with `p = ""` is false.
