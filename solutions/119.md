# Maximum Width of BT

**Difficulty:** Medium  ·  **Topic:** Binary Trees [Traversals, Medium and Hard Problems] › Hard Problems

## Problem
The width of a level is the distance between its leftmost and rightmost non-null nodes, counting the null slots that would exist between them in a complete binary tree. Return the largest width over all levels.

Input: root = [1, 3, 2, 5, 3, null, 9]
Output: 4 (level 3 is 5, 3, null, 9 → 4 slots)

Input: root = [1, 3, 2, 5, null, null, 9, 6, null, 7]
Output: 7 (level 4 spans from 6 to 7 across five empty slots)

## Approach 1: Brute Force (materialize a complete tree)
Assign every node its heap-style index (`root = 0`, left child `2i+1`, right child `2i+2`) with a DFS, group indices by depth in a map, and for each depth take `max - min + 1`. Correct, but the indices grow exponentially with depth and can overflow 64 bits for a skewed tree of ~64 levels.
- **Time:** O(N)
- **Space:** O(N) for the map plus recursion

## Approach 2: Optimal (BFS with per-level index normalization)
Do a level-order traversal where each queue entry carries a node and its position index. Within each level, subtract the first node's index from every index so the level starts at 0; this keeps numbers small and prevents overflow. Width of the level is `lastIndex - firstIndex + 1`. Children get `2*pos + 1` and `2*pos + 2` from the normalized position.

Key observation: only the relative positions inside a level matter, so re-basing at every level is safe.
- **Time:** O(N)
- **Space:** O(W) where W is the maximum number of nodes in a level

## Code (Optimal)

### C++
```cpp
// struct TreeNode { int val; TreeNode *left; TreeNode *right; ... } — standard definition
#include <queue>
#include <algorithm>
using namespace std;

class Solution {
public:
    int widthOfBinaryTree(TreeNode* root) {
        if (!root) return 0;
        long long best = 0;
        queue<pair<TreeNode*, long long>> q;
        q.push({root, 0});
        while (!q.empty()) {
            int sz = q.size();
            long long base = q.front().second, first = 0, last = 0;
            for (int i = 0; i < sz; ++i) {
                auto [node, idx] = q.front(); q.pop();
                long long cur = idx - base;
                if (i == 0) first = cur;
                if (i == sz - 1) last = cur;
                if (node->left)  q.push({node->left,  2 * cur + 1});
                if (node->right) q.push({node->right, 2 * cur + 2});
            }
            best = max(best, last - first + 1);
        }
        return (int)best;
    }
};
```

### Java
```java
// class TreeNode { int val; TreeNode left, right; ... } — standard definition
import java.util.*;

class Solution {
    public int widthOfBinaryTree(TreeNode root) {
        if (root == null) return 0;
        long best = 0;
        Deque<TreeNode> nodes = new ArrayDeque<>();
        Deque<Long> idx = new ArrayDeque<>();
        nodes.add(root); idx.add(0L);
        while (!nodes.isEmpty()) {
            int sz = nodes.size();
            long base = idx.peek(), first = 0, last = 0;
            for (int i = 0; i < sz; i++) {
                TreeNode node = nodes.poll();
                long cur = idx.poll() - base;
                if (i == 0) first = cur;
                if (i == sz - 1) last = cur;
                if (node.left  != null) { nodes.add(node.left);  idx.add(2 * cur + 1); }
                if (node.right != null) { nodes.add(node.right); idx.add(2 * cur + 2); }
            }
            best = Math.max(best, last - first + 1);
        }
        return (int) best;
    }
}
```

### Python
```python
# class TreeNode: val, left, right — standard definition
from collections import deque

class Solution:
    def widthOfBinaryTree(self, root):
        if not root:
            return 0
        best = 0
        q = deque([(root, 0)])
        while q:
            size = len(q)
            base = q[0][1]
            first = last = 0
            for i in range(size):
                node, idx = q.popleft()
                cur = idx - base
                if i == 0:
                    first = cur
                if i == size - 1:
                    last = cur
                if node.left:
                    q.append((node.left, 2 * cur + 1))
                if node.right:
                    q.append((node.right, 2 * cur + 2))
            best = max(best, last - first + 1)
        return best
```

## Key Takeaways
- Width counts gaps, so a plain "nodes per level" BFS is wrong; you need positional indices.
- Re-basing the index at each level is what keeps the arithmetic in range; without it, deep trees overflow.
- Use 64-bit integers in C++/Java even with re-basing, since a single level can still be wide.
- Python integers do not overflow, but the re-basing still keeps the code uniform and fast.
