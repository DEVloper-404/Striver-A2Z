# Count subarrays with given sum

**Difficulty:** Medium  ·  **Topic:** Solve Problems on Arrays [Easy -> Medium -> Hard] › Medium

## Problem
Given an integer array `nums` (values may be negative or zero) and an integer `k`, count how many contiguous subarrays have a sum exactly equal to `k`. Because negatives are allowed, a sliding window does not work; the answer needs prefix sums.

```
Input:  nums = [1, 2, 3, -3, 1, 1, 1, 4, 2, -3], k = 3
Output: 8
```

## Approach 1: Brute Force
Fix a start index, extend the end index one step at a time while maintaining a running sum, and increment the counter whenever the running sum equals `k`. Recomputing each sum from scratch would be O(n³); the running sum makes it O(n²).
- **Time:** O(n²)
- **Space:** O(1)

## Approach 2: Prefix Sum + Hash Map (Optimal)
Let `prefix[i]` be the sum of the first `i` elements. A subarray `(j, i]` sums to `k` exactly when `prefix[i] - prefix[j] == k`, i.e. `prefix[j] == prefix[i] - k`. So while scanning, keep a hash map from *prefix-sum value* to *how many times it has occurred so far*. At each index, add `count[prefix - k]` to the answer, then record the current prefix in the map. Seed the map with `{0: 1}` so subarrays starting at index 0 are counted.
- **Time:** O(n) average
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<long long, int> freq; // prefix sum -> occurrences
        freq[0] = 1;
        long long prefix = 0;
        int count = 0;
        for (int x : nums) {
            prefix += x;
            auto it = freq.find(prefix - k);
            if (it != freq.end()) count += it->second;
            ++freq[prefix];
        }
        return count;
    }
};
```

### Java
```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Long, Integer> freq = new HashMap<>();
        freq.put(0L, 1);
        long prefix = 0;
        int count = 0;
        for (int x : nums) {
            prefix += x;
            count += freq.getOrDefault(prefix - k, 0);
            freq.merge(prefix, 1, Integer::sum);
        }
        return count;
    }
}
```

### Python
```python
from typing import List
from collections import defaultdict

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        freq = defaultdict(int)
        freq[0] = 1
        prefix = 0
        count = 0
        for x in nums:
            prefix += x
            count += freq[prefix - k]
            freq[prefix] += 1
        return count
```

## Key Takeaways
- "Number of subarrays with sum k" = number of pairs of prefix sums that differ by `k`; a frequency map counts those pairs in one pass.
- Seed the map with prefix 0 seen once, otherwise subarrays beginning at index 0 are missed.
- Query the map *before* inserting the current prefix so a zero-length subarray is never counted when `k == 0`.
- Sliding window only works for non-negative arrays; this map technique handles negatives and zeros.
