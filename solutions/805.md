# Painter's Partition

**Difficulty:** Medium  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on Answers

## Problem
There are `n` boards of lengths `boards[i]` laid in a row and `k` painters. Each painter paints a contiguous block of boards at one unit of time per unit length, and all painters work in parallel. Assign boards so that the total time (the longest block any single painter gets) is minimised; return that minimum time.

Input: boards = [10, 20, 30, 40], k = 2
Output: 60  (painter 1 takes [10, 20, 30] = 60, painter 2 takes [40])

## Approach 1: Try Every Time Limit
The answer is at least `max(boards)` and at most `sum(boards)`. For each time limit `T` in that range, walk the boards greedily, starting a new painter whenever the current block would exceed `T`. If the number of painters used is `<= k`, `T` is achievable; return the first such `T`.
- **Time:** O((sum - max) * n)
- **Space:** O(1)

## Approach 2: Binary Search on the Time Limit
Painters needed is non-increasing as the limit grows, so binary search `T` over `[max(boards), sum(boards)]`. For each `mid`, count painters greedily; if `painters(mid) <= k`, record `mid` and search left, otherwise search right. This is the Book Allocation / Split Array pattern applied to painters.
- **Time:** O(n * log(sum - max))
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    int paintersNeeded(const vector<int>& boards, long long limit) {
        int painters = 1;
        long long cur = 0;
        for (int b : boards) {
            if (cur + b > limit) { painters++; cur = 0; }
            cur += b;
        }
        return painters;
    }

    long long minTimeToPaint(vector<int>& boards, int k) {
        long long lo = *max_element(boards.begin(), boards.end());
        long long hi = accumulate(boards.begin(), boards.end(), 0LL);
        long long ans = hi;
        while (lo <= hi) {
            long long mid = lo + (hi - lo) / 2;
            if (paintersNeeded(boards, mid) <= k) {
                ans = mid;
                hi = mid - 1;
            } else {
                lo = mid + 1;
            }
        }
        return ans;
    }
};
```

class Solution {
    private int paintersNeeded(int[] boards, long limit) {
        int painters = 1;
        long cur = 0;
        for (int b : boards) {
            if (cur + b > limit) { painters++; cur = 0; }
            cur += b;
        }
        return painters;
    }

    public long minTimeToPaint(int[] boards, int k) {
        long lo = 0, hi = 0;
        for (int b : boards) { lo = Math.max(lo, b); hi += b; }
        long ans = hi;
        while (lo <= hi) {
            long mid = lo + (hi - lo) / 2;
            if (paintersNeeded(boards, mid) <= k) {
                ans = mid;
                hi = mid - 1;
            } else {
                lo = mid + 1;
            }
        }
        return ans;
    }
}

### Python
```python
from typing import List

class Solution:
    def minTimeToPaint(self, boards: List[int], k: int) -> int:
        def painters_needed(limit: int) -> int:
            painters, cur = 1, 0
            for b in boards:
                if cur + b > limit:
                    painters += 1
                    cur = 0
                cur += b
            return painters

        lo, hi = max(boards), sum(boards)
        ans = hi
        while lo <= hi:
            mid = (lo + hi) // 2
            if painters_needed(mid) <= k:
                ans = mid
                hi = mid - 1
            else:
                lo = mid + 1
        return ans
```

## Key Takeaways
- Third appearance of the "minimise the maximum contiguous block" template; learn it once and reuse it.
- Totals can be large, so keep sums in 64-bit.
- If `k >= n`, the answer is simply `max(boards)`; the search reaches it without special handling.
