# Delete the middle node in LL

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
Given the head of a singly linked list with `n` nodes, delete the node at index `floor(n / 2)` (0-based) and return the head. For even `n` this is the second of the two middle nodes. A single-node list becomes empty.

```
Input:  1 -> 3 -> 4 -> 7 -> 1 -> 2 -> 6
Output: 1 -> 3 -> 4 -> 1 -> 2 -> 6      (node 7 at index 3 removed)

Input:  1 -> 2 -> 3 -> 4
Output: 1 -> 2 -> 4                      (index 2 removed)
```

## Approach 1: Count, then walk
Compute the length `n` in one pass. Walk again to the node at index `n / 2 - 1` (the predecessor of the middle) and unlink its successor. Handle `n == 1` by returning null.

- **Time:** O(n) (two passes)
- **Space:** O(1)

## Approach 2: Slow/fast pointers stopping one before the middle (optimal)
The usual tortoise-hare finds the middle itself, but we need the node *before* it in a singly linked list. Trick: give `fast` a head start of two nodes (`fast = head.next.next`) while `slow` starts at head. Now when `fast` runs out, `slow` is exactly one node before `floor(n/2)`. Then `slow.next = slow.next.next`.

Check with n = 4: slow = 1, fast = 3; step: slow = 2, fast = null. Delete slow.next = 3, index 2. Correct.

- **Time:** O(n) (single pass)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
public:
    ListNode* deleteMiddle(ListNode* head) {
        if (!head || !head->next) return nullptr;
        ListNode* slow = head;
        ListNode* fast = head->next->next;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        ListNode* mid = slow->next;
        slow->next = mid->next;
        delete mid;
        return head;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } }

class Solution {
    public ListNode deleteMiddle(ListNode head) {
        if (head == null || head.next == null) return null;
        ListNode slow = head, fast = head.next.next;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        slow.next = slow.next.next;
        return head;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def deleteMiddle(self, head):
        if head is None or head.next is None:
            return None
        slow, fast = head, head.next.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        slow.next = slow.next.next
        return head
```

## Key Takeaways
- To delete a node in a singly linked list you must stand on its predecessor; offset `fast` by two to make `slow` stop there.
- The single-node case must return null, since deleting the middle empties the list.
- Same skeleton as "middle of the list", only the starting position of `fast` changes.
- Verify the offset with both an odd and an even length before trusting it.
