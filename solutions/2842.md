# Reverse LL in group of given size K

**Difficulty:** Hard  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Hard Problems of LL

## Problem
Given the head of a singly linked list and an integer `k`, reverse the nodes in consecutive blocks of size `k` and return the new head. If the number of nodes left at the tail is smaller than `k`, that tail block must stay in its original order. Only pointers may be rewired; node values must not be swapped.

Input: `head = 1 → 2 → 3 → 4 → 5`, `k = 2`
Output: `2 → 1 → 4 → 3 → 5`

Input: `head = 1 → 2 → 3 → 4 → 5`, `k = 3`
Output: `3 → 2 → 1 → 4 → 5`

## Approach 1: Copy into an array
Walk the list and push every value into an array. Reverse the array in slices `[0,k)`, `[k,2k)`, ... skipping the final slice if it is shorter than `k`. Then walk the list a second time and write the values back in order. It is simple but it violates the "do not change values" constraint that interviewers usually add, and it needs extra memory.
- **Time:** O(n)
- **Space:** O(n) for the array

## Approach 2: In-place reversal, block by block
Key observation: reversing one block of `k` nodes is the same as the classic "reverse a linked list" routine, provided we first cut the block off from the rest of the list. So the algorithm repeats three steps until the list is exhausted:

1. From the current block start `temp`, walk `k-1` steps to find the block's last node `kth`. If we run out of nodes before that, the remaining block is shorter than `k`: leave it alone, attach it to the previous block and stop.
2. Remember `nextStart = kth->next`, set `kth->next = null`, and reverse the block starting at `temp`. After the reversal `kth` is the new first node and `temp` is the new last node.
3. Attach the reversed block: if this is the first block, `kth` becomes the head of the answer; otherwise the previous block's tail (`prevLast`) points to `kth`. Set `temp->next = nextStart`, remember `prevLast = temp`, and continue from `nextStart`.

Each node is visited a constant number of times (once during the walk to find `kth`, once during the reversal), so the whole thing is linear and uses only a few pointers.
- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode *next; ListNode(int x) : val(x), next(nullptr) {} }; // standard definition
class Solution {
    ListNode* reverseBlock(ListNode* head) {
        ListNode* prev = nullptr;
        while (head) {
            ListNode* nxt = head->next;
            head->next = prev;
            prev = head;
            head = nxt;
        }
        return prev;
    }
    ListNode* walk(ListNode* node, int steps) {
        while (node && steps > 0) { node = node->next; steps--; }
        return node;
    }
public:
    ListNode* reverseKGroup(ListNode* head, int k) {
        ListNode* temp = head;
        ListNode* prevLast = nullptr;
        ListNode* newHead = head;
        while (temp) {
            ListNode* kth = walk(temp, k - 1);
            if (!kth) {                    // fewer than k nodes remain
                if (prevLast) prevLast->next = temp;
                break;
            }
            ListNode* nextStart = kth->next;
            kth->next = nullptr;
            reverseBlock(temp);            // kth is now the block head, temp the block tail
            if (temp == head) newHead = kth;
            else prevLast->next = kth;
            temp->next = nextStart;
            prevLast = temp;
            temp = nextStart;
        }
        return newHead;
    }
};
```

// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } } // standard definition
class Solution {
    private ListNode reverseBlock(ListNode head) {
        ListNode prev = null;
        while (head != null) {
            ListNode nxt = head.next;
            head.next = prev;
            prev = head;
            head = nxt;
        }
        return prev;
    }

    private ListNode walk(ListNode node, int steps) {
        while (node != null && steps > 0) { node = node.next; steps--; }
        return node;
    }

    public ListNode reverseKGroup(ListNode head, int k) {
        ListNode temp = head, prevLast = null, newHead = head;
        while (temp != null) {
            ListNode kth = walk(temp, k - 1);
            if (kth == null) {
                if (prevLast != null) prevLast.next = temp;
                break;
            }
            ListNode nextStart = kth.next;
            kth.next = null;
            reverseBlock(temp);
            if (temp == head) newHead = kth;
            else prevLast.next = kth;
            temp.next = nextStart;
            prevLast = temp;
            temp = nextStart;
        }
        return newHead;
    }
}

### Python
```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
# (standard definition)
class Solution:
    def reverseKGroup(self, head, k):
        def reverse_block(node):
            prev = None
            while node:
                nxt = node.next
                node.next = prev
                prev = node
                node = nxt
            return prev

        def walk(node, steps):
            while node and steps > 0:
                node = node.next
                steps -= 1
            return node

        temp, prev_last, new_head = head, None, head
        while temp:
            kth = walk(temp, k - 1)
            if kth is None:
                if prev_last:
                    prev_last.next = temp
                break
            next_start = kth.next
            kth.next = None
            reverse_block(temp)
            if temp is head:
                new_head = kth
            else:
                prev_last.next = kth
            temp.next = next_start
            prev_last = temp
            temp = next_start
        return new_head
```

## Key Takeaways
- Detach the block (`kth->next = null`) before reversing so the plain reverse routine can be reused unchanged.
- After reversing, the old block start becomes the block tail; keep it as `prevLast` to stitch the next block on.
- The leftover block shorter than `k` must be re-attached untouched; forgetting that drops the tail of the list.
- `k = 1` or a list shorter than `k` should return the list unchanged.
