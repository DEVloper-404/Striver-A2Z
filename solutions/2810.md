# Middle of a LinkedList [TortoiseHare Method]

**Difficulty:** Easy  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
Given the head of a singly linked list, return the middle node. When the list has an even number of nodes there are two middles; return the second one. The answer is a node reference, not a value.

```
Input:  head = 1 -> 2 -> 3 -> 4 -> 5
Output: node 3

Input:  head = 1 -> 2 -> 3 -> 4 -> 5 -> 6
Output: node 4
```

## Approach 1: Count then walk
Traverse once to count the nodes, `n`. Then traverse again and stop after `n / 2` steps (integer division); that node is the required middle. For n = 6 this stops at index 3 (0-based), which is the second middle, as required.

- **Time:** O(n) (two passes)
- **Space:** O(1)

## Approach 2: Tortoise and hare (optimal)
Use two pointers starting at the head. `slow` advances one node per step, `fast` advances two. When `fast` runs off the end (or reaches the last node), `slow` has covered half the distance and sits on the middle. The loop condition `while fast and fast.next` naturally lands `slow` on the second middle for even lengths.

Walking through n = 6: after steps 1, 2, 3 `slow` is at 2, 3, 4 and `fast` is at 3, 5, null. Loop stops; answer is 4.

- **Time:** O(n) (single pass)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
public:
    ListNode* middleNode(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        return slow;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } }

class Solution {
    public ListNode middleNode(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def middleNode(self, head):
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        return slow
```

## Key Takeaways
- Slow/fast pointers find the middle in one pass without knowing the length.
- The loop guard `fast and fast.next` decides which middle you get for even lengths; this version yields the second one.
- To get the first middle instead, start `fast` at `head.next` or stop when `fast.next.next` is null.
- The same two-pointer trick underpins cycle detection and palindrome checks on lists.
