# Isomorphic String

**Difficulty:** Easy  ·  **Topic:** Strings [Basic and Medium] › Basic and Easy String Problems

## Problem
Two strings `s` and `t` of equal length are isomorphic if you can replace every character of `s` with some character to get `t`, where the replacement is consistent (the same source char always maps to the same target char) and injective (two different source chars never map to the same target char).

Input: `s = "egg", t = "add"`
Output: `true`  (`e→a`, `g→d`)

Input: `s = "foo", t = "bar"`
Output: `false`  (`o` would have to map to both `a` and `r`)

Input: `s = "badc", t = "baba"`
Output: `false`  (`b` and `d` both want to map to `a`)

## Approach 1: Two hash maps
Keep a map `s→t` and a map `t→s`. For each index `i`:
- If `s[i]` is already mapped, it must map to `t[i]`; otherwise return false.
- If `t[i]` is already mapped back, it must map to `s[i]`; otherwise return false.
- Otherwise record both directions.

The second map is what enforces the injective (one-to-one) rule; a single map alone would accept `"ab"` vs `"aa"`.
- **Time:** O(n)
- **Space:** O(k) where k is the alphabet size (at most 256 entries)

## Approach 2: Last-seen index arrays (Optimal)
Instead of storing the mapping, store the **last index at which each character appeared** in its own string. Two strings are isomorphic exactly when, at every position, `lastSeenS[s[i]] == lastSeenT[t[i]]`. If `s[i]` last appeared at position 3, then `t[i]` must also have last appeared at position 3, and vice versa.

Use two fixed arrays of size 256 initialised to `-1`. Store `i + 1` (or `i`) after checking. This is the same logic with O(1) memory and no hashing.
- **Time:** O(n)
- **Space:** O(1) (two 256-int arrays)

## Code (Optimal)

### C++
```cpp
#include <string>
using namespace std;

class Solution {
public:
    bool isIsomorphic(string s, string t) {
        if (s.size() != t.size()) return false;
        int lastS[256], lastT[256];
        for (int i = 0; i < 256; ++i) lastS[i] = lastT[i] = -1;
        for (int i = 0; i < (int)s.size(); ++i) {
            unsigned char a = s[i], b = t[i];
            if (lastS[a] != lastT[b]) return false;
            lastS[a] = lastT[b] = i;
        }
        return true;
    }
};
```

### Java
```java
import java.util.Arrays;

class Solution {
    public boolean isIsomorphic(String s, String t) {
        if (s.length() != t.length()) return false;
        int[] lastS = new int[256];
        int[] lastT = new int[256];
        Arrays.fill(lastS, -1);
        Arrays.fill(lastT, -1);
        for (int i = 0; i < s.length(); i++) {
            char a = s.charAt(i), b = t.charAt(i);
            if (lastS[a] != lastT[b]) return false;
            lastS[a] = i;
            lastT[b] = i;
        }
        return true;
    }
}
```

### Python
```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        last_s = {}
        last_t = {}
        for i, (a, b) in enumerate(zip(s, t)):
            if last_s.get(a, -1) != last_t.get(b, -1):
                return False
            last_s[a] = i
            last_t[b] = i
        return True
```

## Key Takeaways
- Isomorphism is a bijection between characters: you must check both directions.
- Comparing "last seen index" of the two characters is a compact way to check both directions with one comparison.
- Forgetting the reverse mapping is the classic bug (`"ab"` vs `"aa"` should be false).
- Edge cases: strings of different length, identical strings, all characters the same.
