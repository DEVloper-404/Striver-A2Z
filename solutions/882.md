# Recursive Insertion Sort

**Difficulty:** Easy  ·  **Topic:** Learn Important Sorting Techniques › Sorting-II

## Problem
Sort an array of `n` integers in non-decreasing order using insertion sort, with the outer loop written as recursion. Each recursive call inserts one more element into the sorted prefix.

Input: `arr = [12, 11, 13, 5, 6]`
Output: `[5, 6, 11, 12, 13]`

## Approach 1: Recursive Insertion Sort
In the iterative algorithm, step `i` takes `arr[i]` and slides it left into the sorted prefix `arr[0..i-1]`. The recursive version makes "process index `i`, then process index `i+1`" explicit:

1. Base case: if `i == n`, every element has been inserted, so stop.
2. Take `key = arr[i]`, shift every larger element in `arr[0..i-1]` one step right, and place `key` in the gap.
3. Recurse with `i + 1`.

The invariant is the same as the iterative version: when the call with index `i` finishes its insertion, `arr[0..i]` is sorted. The sort stays stable because only strictly greater elements are shifted.

- **Time:** O(n) best case (already sorted), O(n²) worst and average case.
- **Space:** O(n) recursion stack.

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    void insert(vector<int>& arr, int i, int n) {
        if (i == n) return;
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
        insert(arr, i + 1, n);
    }

public:
    vector<int> insertionSort(vector<int>& arr) {
        int n = arr.size();
        if (n > 1) insert(arr, 1, n);
        return arr;
    }
};
```

### Python
```python
class Solution:
    def insertionSort(self, arr: list[int]) -> list[int]:
        n = len(arr)

        def insert(i: int) -> None:
            if i == n:
                return
            key = arr[i]
            j = i - 1
            while j >= 0 and arr[j] > key:
                arr[j + 1] = arr[j]
                j -= 1
            arr[j + 1] = key
            insert(i + 1)

        if n > 1:
            insert(1)
        return arr
```

## Key Takeaways
- Recursion carries the index `i` that a loop would; the insertion logic itself is unchanged.
- Base case `i == n` means every element has been placed; start from `i = 1` because a single element is trivially sorted.
- Adds O(n) stack depth for no algorithmic gain — useful only as a recursion exercise.
