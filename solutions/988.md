# Subarrays with K Different Integers

**Difficulty:** Medium  ·  **Topic:** Sliding Window & Two Pointer Combined Problems › Hard Problems

## Problem
Given an integer array `nums` and an integer `k`, count the contiguous subarrays that contain exactly `k` distinct integers.

Input: `nums = [1,2,1,2,3], k = 2`
Output: `7` (`[1,2]`, `[2,1]`, `[1,2]`, `[2,3]`, `[1,2,1]`, `[2,1,2]`, `[1,2,1,2]`)

## Approach 1: Brute Force
For every start index, extend right while tracking a set of seen values. Increment the answer whenever the set size equals `k`, and stop once it exceeds `k`.

- **Time:** O(n²)
- **Space:** O(k)

## Approach 2: "At Most K" minus "At Most K-1" (Optimal)
A window for "exactly k distinct" is not monotone: shifting the left pointer can keep the distinct count unchanged, so counting valid starts per `r` is awkward. But "at most k distinct" is monotone and easy: for each `r`, shrink `l` until the window has at most `k` distinct values, then every start in `[l, r]` is valid, contributing `r - l + 1`.

`exactly(k) = atMost(k) - atMost(k - 1)`.

- **Time:** O(n)
- **Space:** O(n) for the frequency map (or O(1) with a fixed-size array since values are bounded by n)

## Approach 3: Two Left Pointers (Alternative Optimal)
Maintain two left boundaries for the same right pointer: `l1` = smallest start where the window has at most `k` distinct, `l2` = smallest start where it has at most `k - 1` distinct. The number of subarrays ending at `r` with exactly `k` distinct is `l2 - l1`. This is the same subtraction done in a single pass.

- **Time:** O(n)
- **Space:** O(n)

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
    int atMost(const vector<int>& nums, int k) {
        if (k <= 0) return 0;
        vector<int> freq(nums.size() + 1, 0);
        int distinct = 0, l = 0, count = 0;
        for (int r = 0; r < (int)nums.size(); ++r) {
            if (freq[nums[r]]++ == 0) distinct++;
            while (distinct > k) {
                if (--freq[nums[l]] == 0) distinct--;
                l++;
            }
            count += r - l + 1;
        }
        return count;
    }
public:
    int subarraysWithKDistinct(vector<int>& nums, int k) {
        return atMost(nums, k) - atMost(nums, k - 1);
    }
};
```

```java
class Solution {
    private int atMost(int[] nums, int k) {
        if (k <= 0) return 0;
        int[] freq = new int[nums.length + 1];
        int distinct = 0, l = 0, count = 0;
        for (int r = 0; r < nums.length; r++) {
            if (freq[nums[r]]++ == 0) distinct++;
            while (distinct > k) {
                if (--freq[nums[l]] == 0) distinct--;
                l++;
            }
            count += r - l + 1;
        }
        return count;
    }

    public int subarraysWithKDistinct(int[] nums, int k) {
        return atMost(nums, k) - atMost(nums, k - 1);
    }
}
```

### Python
```python
from typing import List
from collections import defaultdict

class Solution:
    def subarraysWithKDistinct(self, nums: List[int], k: int) -> int:
        def at_most(m: int) -> int:
            if m <= 0:
                return 0
            cnt = defaultdict(int)
            l = 0
            count = 0
            for r, v in enumerate(nums):
                cnt[v] += 1
                while len(cnt) > m:
                    cnt[nums[l]] -= 1
                    if cnt[nums[l]] == 0:
                        del cnt[nums[l]]
                    l += 1
                count += r - l + 1
            return count

        return at_most(k) - at_most(k - 1)
```

## Key Takeaways
- Whenever "exactly k" is hard but "at most k" is a clean window, subtract two at-most counts.
- Counting `r - l + 1` per right endpoint counts every valid subarray exactly once.
- The frequency array works because `1 <= nums[i] <= n`; use a hash map for unbounded values.
