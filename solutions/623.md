# Length of loop in LL

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
Given the head of a singly linked list, return the number of nodes in the cycle if one exists, otherwise return 0. The loop may start at any node, including the head, and may consist of a single node pointing to itself.

```
Input:  1 -> 2 -> 3 -> 4 -> 5 -> (back to 3)
Output: 3     (the cycle is 3 -> 4 -> 5 -> 3)

Input:  1 -> 2 -> null
Output: 0
```

## Approach 1: Hash map of node to step index
Walk the list, storing each node with the step number at which it was first seen. When a node reappears at step `t` and was first seen at step `s`, the loop length is `t - s`. Reaching null means no loop.

- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Floyd's meeting point plus one lap (optimal)
Use slow/fast pointers to find a node inside the cycle (their meeting point). Any node inside the cycle can be used to measure the cycle: start a counter at 1, advance a pointer from the meeting point one step at a time, and stop when it returns to the meeting point. The count is the loop length. If slow and fast never meet, return 0.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
public:
    int lengthOfLoop(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) {
                int len = 1;
                ListNode* p = slow->next;
                while (p != slow) {
                    p = p->next;
                    len++;
                }
                return len;
            }
        }
        return 0;
    }
};
```

### Java
```java

class Solution {
    public int lengthOfLoop(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) {
                int len = 1;
                ListNode p = slow.next;
                while (p != slow) {
                    p = p.next;
                    len++;
                }
                return len;
            }
        }
        return 0;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def lengthOfLoop(self, head) -> int:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                length = 1
                p = slow.next
                while p is not slow:
                    p = p.next
                    length += 1
                return length
        return 0
```

## Key Takeaways
- Once Floyd's pointers meet, you are guaranteed to be inside the loop; one full lap counts its length.
- Start the counter at 1 and step once before comparing so a self-loop (length 1) is measured correctly.
- No meeting means no loop; return 0.
- Constant extra space, single logical pass plus one lap.
