# Check if LL is palindrome or not

**Difficulty:** Medium  ·  **Topic:** Learn LinkedList [Single LL, Double LL, Medium, Hard Problems] › Medium Problems of LL

## Problem
Given the head of a singly linked list, return true if the sequence of values reads the same forwards and backwards, otherwise false. An ideal solution uses O(1) extra space and leaves the list in its original shape when done.

```
Input:  1 -> 2 -> 2 -> 1
Output: true

Input:  1 -> 2
Output: false
```

## Approach 1: Copy into an array or stack
Traverse the list, appending values to an array. Then compare the array with its reverse using two indices from both ends. Equivalently, push all values onto a stack and pop while traversing again. Straightforward but O(n) memory.

- **Time:** O(n)
- **Space:** O(n)

## Approach 2: Reverse the second half in place (optimal)
1. Find the end of the first half with slow/fast pointers (stop fast at `fast.next` and `fast.next.next` being non-null so `slow` lands on the last node of the first half for both odd and even lengths).
2. Reverse the sublist starting at `slow.next`; call its head `second`.
3. Walk `first` from head and `second` in parallel, comparing values. Any mismatch means not a palindrome.
4. Reverse the second half again to restore the list, then return the verdict.

For odd lengths the middle node is left in the first half and never compared against anything, which is correct.

- **Time:** O(n)
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
// struct ListNode { int val; ListNode* next; ListNode(int x) : val(x), next(nullptr) {} };

class Solution {
    ListNode* reverse(ListNode* head) {
        ListNode* prev = nullptr;
        while (head) {
            ListNode* nxt = head->next;
            head->next = prev;
            prev = head;
            head = nxt;
        }
        return prev;
    }
public:
    bool isPalindrome(ListNode* head) {
        if (!head || !head->next) return true;
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast->next && fast->next->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        ListNode* second = reverse(slow->next);
        ListNode* first = head;
        ListNode* p = second;
        bool ok = true;
        while (p) {
            if (first->val != p->val) { ok = false; break; }
            first = first->next;
            p = p->next;
        }
        slow->next = reverse(second); // restore
        return ok;
    }
};
```

### Java
```java
// class ListNode { int val; ListNode next; ListNode(int x) { val = x; } }

class Solution {
    private ListNode reverse(ListNode head) {
        ListNode prev = null;
        while (head != null) {
            ListNode nxt = head.next;
            head.next = prev;
            prev = head;
            head = nxt;
        }
        return prev;
    }

    public boolean isPalindrome(ListNode head) {
        if (head == null || head.next == null) return true;
        ListNode slow = head, fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        ListNode second = reverse(slow.next);
        ListNode first = head, p = second;
        boolean ok = true;
        while (p != null) {
            if (first.val != p.val) { ok = false; break; }
            first = first.next;
            p = p.next;
        }
        slow.next = reverse(second); // restore
        return ok;
    }
}
```

### Python
```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def _reverse(self, head):
        prev = None
        while head:
            nxt = head.next
            head.next = prev
            prev = head
            head = nxt
        return prev

    def isPalindrome(self, head) -> bool:
        if head is None or head.next is None:
            return True
        slow = fast = head
        while fast.next and fast.next.next:
            slow = slow.next
            fast = fast.next.next
        second = self._reverse(slow.next)
        first, p, ok = head, second, True
        while p:
            if first.val != p.val:
                ok = False
                break
            first = first.next
            p = p.next
        slow.next = self._reverse(second)  # restore
        return ok
```

## Key Takeaways
- Middle-finding plus in-place reversal gives an O(1)-space palindrome check.
- Use the `fast.next and fast.next.next` guard so `slow` stops at the end of the first half in both parity cases.
- Compare only while the (shorter or equal) second half has nodes; the odd middle is skipped automatically.
- Restore the list afterward; interviewers often ask for this.
