# Find eventual safe states

**Difficulty:** Hard  ·  **Topic:** Graphs [Concepts & Problems] › Topo Sort and Problems

## Problem
You are given a directed graph as an array `graph`, where `graph[i]` lists the nodes reachable from `i` in one step. A node is **terminal** if it has no outgoing edges. A node is **safe** if *every* path starting from it eventually ends at a terminal node — in other words, no walk from it can get stuck in a cycle. Return all safe nodes in ascending order.

```
Input:  graph = [[1,2], [2,3], [5], [0], [5], [], []]
Output: [2, 4, 5, 6]
```
Here `5` and `6` are terminal, hence safe. `2 -> 5` and `4 -> 5` only reach terminals, so they are safe. Nodes `0`, `1`, `3` sit on the cycle `0 -> 1 -> 3 -> 0` (via `0->1`, `1->3`, `3->0`), so they are unsafe.

## Approach 1: DFS with cycle detection (colour marking)
Run the standard "back edge" DFS with `visited` and `pathVisited`. A node is unsafe exactly when the DFS from it discovers a back edge, i.e. it can reach a cycle. In the DFS, if any neighbour turns out unsafe, the current node is unsafe too; if all neighbours are safe, the node is safe. Mark `check[u] = true` when the node is proved safe, reset `pathVisited[u]` on backtrack, and finally collect all `u` with `check[u]`.

This is correct and O(V + E), but recursive and needs the same careful flag handling as directed cycle detection.

- **Time:** O(V + E) (plus O(V log V) if you sort, though the natural loop order is already ascending)
- **Space:** O(V) arrays plus O(V) recursion depth

## Approach 2: Reverse the graph + Kahn's algorithm (Optimal)

**Key observation — flip the definition.** "Safe" is defined by looking *forward*: all outgoing paths must terminate. Terminal nodes are the base case (out-degree 0 = trivially safe), and a node is safe when **all** its successors are safe. That is a peeling process starting at nodes of out-degree 0 — which is exactly Kahn's algorithm run on **out-degrees** instead of in-degrees.

The cleanest way to reuse standard Kahn's is to **reverse every edge**. In the reversed graph `rev`, the in-degree of a node equals its out-degree in the original graph. So:
- original terminal (out-degree 0) → reversed source (in-degree 0);
- "all successors are safe" → in the reversed graph, a node's counter reaches 0 only after all of its original successors have been popped as safe.

Reversing also gives us the right traversal direction: after proving `v` safe, the nodes that might newly become safe are exactly the original predecessors of `v`, which are `rev[v]`.

**Algorithm.**
1. Build `rev`: for every original edge `u -> v`, add `v -> u` in `rev`. Simultaneously compute `indeg[u] = graph[u].size()` (the original out-degree).
2. Enqueue every node with `indeg == 0` (the terminals).
3. Pop `u`, record it as safe, and for every `w` in `rev[u]` decrement `indeg[w]`; if it becomes 0, all of `w`'s original outgoing edges lead to safe nodes, so push `w`.
4. Sort the collected safe nodes (or simply iterate `0..n-1` and output those flagged safe).

**Why it is correct.** By induction on the pop order. Terminals are safe by definition. When `w` is popped, each of its original successors was popped earlier and is safe by the inductive hypothesis, so every path out of `w` moves to a safe node and therefore terminates. Conversely, any node that can reach a cycle never has all successors safe — the cycle nodes block each other forever, exactly as in cycle detection — so it is never popped.

**Dry run** on `graph = [[1,2],[2,3],[5],[0],[5],[],[]]`:
- Out-degrees: `0:2, 1:2, 2:1, 3:1, 4:1, 5:0, 6:0`. Reversed lists include `rev[5] = [2,4]`, `rev[2] = [0,1]`, `rev[0] = [3]`, etc.
- Queue starts `[5, 6]`. Pop 5 → safe; decrement 2 → 0 (push 2) and 4 → 0 (push 4). Pop 6 → safe, no predecessors.
- Pop 2 → safe; `rev[2] = [0,1]`, so `indeg[0]` 2→1, `indeg[1]` 2→1. Neither hits 0.
- Pop 4 → safe. Queue empty.
- Safe set `{2,4,5,6}` → sorted `[2,4,5,6]`. Nodes 0, 1, 3 stay blocked because each still waits on a cycle partner. ✓

- **Time:** O(V + E) to reverse and run Kahn's, O(V log V) if you sort the result
- **Space:** O(V + E) for the reversed adjacency list

## Code (Optimal)

### C++
```cpp
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> eventualSafeNodes(vector<vector<int>>& graph) {
        int n = graph.size();
        vector<vector<int>> rev(n);
        vector<int> outdeg(n, 0);
        for (int u = 0; u < n; u++) {
            outdeg[u] = graph[u].size();
            for (int v : graph[u]) rev[v].push_back(u);
        }

        queue<int> q;
        for (int i = 0; i < n; i++)
            if (outdeg[i] == 0) q.push(i);

        vector<int> safe;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            safe.push_back(u);
            for (int w : rev[u]) {
                if (--outdeg[w] == 0) q.push(w);
            }
        }
        sort(safe.begin(), safe.end());
        return safe;
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public List<Integer> eventualSafeNodes(int[][] graph) {
        int n = graph.length;
        List<List<Integer>> rev = new ArrayList<>();
        for (int i = 0; i < n; i++) rev.add(new ArrayList<>());
        int[] outdeg = new int[n];
        for (int u = 0; u < n; u++) {
            outdeg[u] = graph[u].length;
            for (int v : graph[u]) rev.get(v).add(u);
        }

        Queue<Integer> q = new ArrayDeque<>();
        for (int i = 0; i < n; i++)
            if (outdeg[i] == 0) q.add(i);

        boolean[] isSafe = new boolean[n];
        while (!q.isEmpty()) {
            int u = q.poll();
            isSafe[u] = true;
            for (int w : rev.get(u)) {
                if (--outdeg[w] == 0) q.add(w);
            }
        }

        List<Integer> ans = new ArrayList<>();
        for (int i = 0; i < n; i++) if (isSafe[i]) ans.add(i);
        return ans;
    }
}
```

### Python
```python
from collections import deque
from typing import List

class Solution:
    def eventualSafeNodes(self, graph: List[List[int]]) -> List[int]:
        n = len(graph)
        rev = [[] for _ in range(n)]
        outdeg = [0] * n
        for u in range(n):
            outdeg[u] = len(graph[u])
            for v in graph[u]:
                rev[v].append(u)

        q = deque(i for i in range(n) if outdeg[i] == 0)
        safe = [False] * n
        while q:
            u = q.popleft()
            safe[u] = True
            for w in rev[u]:
                outdeg[w] -= 1
                if outdeg[w] == 0:
                    q.append(w)

        return [i for i in range(n) if safe[i]]
```

## Key Takeaways
- A node is safe ⟺ it cannot reach any cycle; terminals are the base case and safety propagates backwards.
- Reversing the graph converts "all successors safe" into standard in-degree peeling, so plain Kahn's applies unchanged.
- The condition is **all** successors safe (not *any*), which is why a counter reaching zero — not a single decrement — triggers the push.
- Iterating `0..n-1` over a boolean `safe[]` array gives ascending order for free, avoiding the sort.
