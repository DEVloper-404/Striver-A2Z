# Implement Stack using Arrays

**Difficulty:** Easy  ·  **Topic:** Stack and Queues [Learning, Pre-In-Post-fix, Monotonic Stack, Implementation] › Learning

## Problem
Build a stack (last in, first out) on top of a fixed-size array. Support `push(x)`, `pop()`, `top()`, `isEmpty()` and `size()`. `pop`/`top` on an empty stack should signal an error (here: return -1).

Input: `push(3), push(7), top(), pop(), top(), size()`
Output: `7, 7, 3, 1`

## Approach: Array with a top index
Keep an array `arr` of capacity `cap` and an integer `topIdx` that starts at -1 (empty). The stack's contents are `arr[0..topIdx]`.

- `push(x)`: if `topIdx == cap - 1` the stack is full (overflow); otherwise increment `topIdx` and write `arr[topIdx] = x`.
- `pop()`: if `topIdx == -1` underflow; otherwise return `arr[topIdx]` and decrement `topIdx`.
- `top()`: return `arr[topIdx]` without moving the index.
- `size()`: `topIdx + 1`.

Because every operation touches only the end of the array, all of them run in constant time. A dynamic array (vector / ArrayList / list) removes the fixed-capacity limitation at the cost of occasional amortised resizing.
- **Time:** O(1) per operation
- **Space:** O(cap) for the backing array

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Stack {
    vector<int> arr;
    int topIdx;
    int cap;
public:
    explicit Stack(int capacity = 1000) : arr(capacity), topIdx(-1), cap(capacity) {}

    void push(int x) {
        if (topIdx == cap - 1) return;        // overflow: ignore
        arr[++topIdx] = x;
    }
    int pop() {
        if (topIdx == -1) return -1;          // underflow
        return arr[topIdx--];
    }
    int top() const {
        return topIdx == -1 ? -1 : arr[topIdx];
    }
    bool isEmpty() const { return topIdx == -1; }
    int size() const { return topIdx + 1; }
};
```

class Stack {
    private final int[] arr;
    private int topIdx = -1;

    Stack(int capacity) { arr = new int[capacity]; }

    }

### Python
```python
class Stack:
    def __init__(self, capacity: int = 1000):
        self.arr = [0] * capacity
        self.top_idx = -1
        self.cap = capacity

    def push(self, x: int) -> None:
        if self.top_idx == self.cap - 1:
            return                      # overflow: ignore
        self.top_idx += 1
        self.arr[self.top_idx] = x

    def pop(self) -> int:
        if self.top_idx == -1:
            return -1                   # underflow
        val = self.arr[self.top_idx]
        self.top_idx -= 1
        return val

    def top(self) -> int:
        return -1 if self.top_idx == -1 else self.arr[self.top_idx]

    def is_empty(self) -> bool:
        return self.top_idx == -1

    def size(self) -> int:
        return self.top_idx + 1
```

## Key Takeaways
- A single index (`topIdx`) is the whole state; `-1` means empty.
- Check for overflow before pushing and underflow before popping.
- All operations are O(1) because a stack only ever touches one end.
- Fixed arrays need a capacity; a resizable array gives amortised O(1) pushes without that limit.
