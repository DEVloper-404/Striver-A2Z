# Search in a 2D matrix

**Difficulty:** Hard  ·  **Topic:** Binary Search [1D, 2D Arrays, Search Space] › BS on 2D Arrays

## Problem
You are given an `n x m` matrix where every row is sorted and the first element of each row is greater than the last element of the previous row (so reading it row by row gives one sorted list). Return `true` if a given `target` exists in the matrix, `false` otherwise.

Input: matrix = [[1, 3, 5, 7], [10, 11, 16, 20], [23, 30, 34, 60]], target = 3
Output: true

Input: same matrix, target = 13
Output: false

## Approach 1: Scan Everything
Check every cell against `target`. Ignores the sorted structure entirely.
- **Time:** O(n * m)
- **Space:** O(1)

## Approach 2: Pick the Row, Then Binary Search It
Because rows are sorted and non-overlapping, `target` can only be in a row whose first element is `<= target` and last element is `>= target`. Scan the rows to find that one (or binary search on first elements), then binary search inside it.
- **Time:** O(n + log m), or O(log n + log m) with binary search on rows
- **Space:** O(1)

## Approach 3: Treat the Matrix as One Sorted Array
Flatten mentally: index `idx` in `[0, n*m - 1]` maps to cell `(idx / m, idx % m)`. Run a normal binary search on `idx`, converting to a cell whenever you need to read a value. No extra memory, one binary search.
- **Time:** O(log(n * m))
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int n = matrix.size();
        if (n == 0) return false;
        int m = matrix[0].size();
        int lo = 0, hi = n * m - 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            int val = matrix[mid / m][mid % m];
            if (val == target) return true;
            if (val < target) lo = mid + 1;
            else hi = mid - 1;
        }
        return false;
    }
};
```

### Python
```python
from typing import List

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False
        n, m = len(matrix), len(matrix[0])
        lo, hi = 0, n * m - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            val = matrix[mid // m][mid % m]
            if val == target:
                return True
            if val < target:
                lo = mid + 1
            else:
                hi = mid - 1
        return False
```

## Key Takeaways
- Index mapping `(idx / m, idx % m)` turns a fully sorted matrix into a virtual 1D array.
- This only works when rows are sorted *and* consecutive rows do not overlap; otherwise use the staircase method (Search in 2D Matrix II).
- Guard against an empty matrix before reading `matrix[0]`.
