# Introduction to Bits and Tricks

**Difficulty:** Easy  ·  **Topic:** Bit Manipulation [Concepts & Problems] › Learn Bit Manipulation

## Problem
This is a theory item. It covers how integers are stored in binary, how negative numbers are represented (two's complement), the six bitwise operators (`&`, `|`, `^`, `~`, `<<`, `>>`), and the handful of one-line tricks that almost every bit-manipulation problem is built from.

Input: the decimal number `13`
Output: its 8-bit binary form `00001101` (8 + 4 + 1)

## Approach: Binary representation and the operators

### 1. Decimal to binary and back
An integer is a sum of powers of two. Bit `i` (counting from the right, starting at 0) has weight `2^i`. To convert decimal to binary, repeatedly divide by 2 and collect the remainders in reverse; to convert back, sum `bit_i * 2^i`.

```cpp
string toBinary(int n) {            // n >= 0
    if (n == 0) return "0";
    string s;
    while (n > 0) { s += char('0' + (n & 1)); n >>= 1; }
    reverse(s.begin(), s.end());
    return s;
}
int toDecimal(const string& b) {
    int v = 0;
    for (char ch : b) v = v * 2 + (ch - '0');
    return v;
}
```

### 2. Two's complement (negative numbers)
A 32-bit `int` stores `-x` as `~x + 1` (flip every bit, add one). The top bit is the sign bit, so the range is `-2^31 .. 2^31 - 1`. Consequences you will use: `-1` is all ones, `n & -n` isolates the lowest set bit, and right-shifting a negative number keeps the sign in C++/Java (`>>`), while Java's `>>>` shifts in zeros.

### 3. The operators
| Operator | Meaning | Example (a = 6 `110`, b = 3 `011`) |
|---|---|---|
| `a & b` | AND: 1 only where both are 1 | `010` = 2 |
| `a \| b` | OR: 1 where either is 1 | `111` = 7 |
| `a ^ b` | XOR: 1 where they differ | `101` = 5 |
| `~a` | NOT: flip every bit | `-7` in two's complement |
| `a << k` | shift left, multiply by `2^k` | `6 << 1` = 12 |
| `a >> k` | shift right, divide by `2^k` (floor) | `6 >> 1` = 3 |

XOR facts worth memorising: `x ^ 0 = x`, `x ^ x = 0`, XOR is commutative and associative, so XOR-ing a list cancels every value that appears an even number of times.

### 4. The core tricks
```python
# all functions assume 0-indexed bit positions from the right
def is_set(n, i):     return (n >> i) & 1 == 1      # or n & (1 << i)
def set_bit(n, i):    return n | (1 << i)
def clear_bit(n, i):  return n & ~(1 << i)
def toggle_bit(n, i): return n ^ (1 << i)
def lowest_set(n):    return n & -n                  # isolate rightmost 1
def drop_lowest(n):   return n & (n - 1)             # remove rightmost 1
def is_pow2(n):       return n > 0 and n & (n - 1) == 0
def popcount(n):                                     # count set bits
    c = 0
    while n:
        n &= n - 1
        c += 1
    return c
```

Why `n & (n - 1)` clears the lowest set bit: subtracting 1 flips the lowest 1 to 0 and every 0 below it to 1; AND-ing with the original zeroes exactly that region and leaves the higher bits untouched.

```java
// Java: the same helpers, plus built-ins you can use in interviews
boolean isSet(int n, int i)  { return ((n >> i) & 1) == 1; }
int setBit(int n, int i)     { return n | (1 << i); }
int clearBit(int n, int i)   { return n & ~(1 << i); }
int popcount(int n)          { return Integer.bitCount(n); }
int lowestSet(int n)         { return n & -n; }
```

### 5. Complexity
Every trick above is O(1). Loop-based bit counting is O(number of set bits) with `n & (n - 1)` or O(log n) by shifting one bit at a time.
- **Time:** O(1) per operation, O(log n) to walk all bits
- **Space:** O(1)

### Python
```python
class BitTricks:
    @staticmethod
    def to_binary(n: int) -> str:
        if n == 0:
            return "0"
        bits = []
        while n > 0:
            bits.append(str(n & 1))
            n >>= 1
        return "".join(reversed(bits))

    @staticmethod
    def to_decimal(b: str) -> int:
        v = 0
        for ch in b:
            v = v * 2 + (ord(ch) - ord("0"))
        return v

    @staticmethod
    def is_set(n: int, i: int) -> bool:
        return (n >> i) & 1 == 1

    @staticmethod
    def set_bit(n: int, i: int) -> int:
        return n | (1 << i)

    @staticmethod
    def clear_bit(n: int, i: int) -> int:
        return n & ~(1 << i)

    @staticmethod
    def toggle_bit(n: int, i: int) -> int:
        return n ^ (1 << i)

    @staticmethod
    def popcount(n: int) -> int:
        c = 0
        while n:
            n &= n - 1
            c += 1
        return c
```

## Key Takeaways
- Think of an int as 32 switches; `1 << i` is the mask for switch `i`, and AND / OR / XOR test, set and flip it.
- `n & (n - 1)` drops the lowest set bit; `n & -n` keeps only it. These two identities solve a surprising number of problems.
- XOR cancels pairs: `x ^ x = 0`. That is the engine behind "find the odd one out" problems.
- Watch the sign bit: `~x` and `>>` behave differently on negatives, and `1 << 31` overflows a signed 32-bit int.
