# Recursive Implementation of atoi()

**Difficulty:** Medium  ·  **Topic:** Recursion [PatternWise] › Get a Strong Hold

## Problem
Convert a string to a 32-bit signed integer the way C's `atoi` does. Skip leading spaces, read an optional `+` or `-`, then read digits until a non-digit appears (anything after that is ignored). If no digits are read, the answer is `0`. If the value falls outside `[-2^31, 2^31 - 1]`, clamp it to the nearest bound. The exercise is to build the digit-accumulation part recursively.

Input: `s = "   -42abc"`
Output: `-42`

Input: `s = "91283472332"`
Output: `2147483647` (clamped)

## Approach 1: Iterative scan
Move an index past spaces, record the sign, then loop while the current character is a digit: `result = result * 10 + digit`. Before each multiplication check whether the new value would overflow and clamp if so. This is the standard solution and is already optimal; the recursive version is a different way of writing the same loop.
- **Time:** O(n)
- **Space:** O(1)

## Approach 2: Recursive digit accumulation
Treat the digit-reading loop as a recursive function `build(i, acc)`: if `s[i]` is not a digit, return `acc`; otherwise fold the digit into `acc` and recurse on `i + 1`. Overflow is checked before the fold: if `acc > INT_MAX / 10`, or `acc == INT_MAX / 10` and the digit is larger than `7`, the final value (with sign applied) is guaranteed to overflow, so return the bound immediately. Working with the magnitude and applying the sign at the end keeps the check simple; the negative bound is handled because `2147483648` with a minus sign clamps to `INT_MIN` anyway.

1. Skip spaces and read the sign iteratively (this is preprocessing, not part of the recursion).
2. Call `build(i, 0)`.
3. Multiply by the sign and clamp.
- **Time:** O(n)
- **Space:** O(d) recursion depth where d is the number of digits (at most about 10 before clamping)

## Code (Optimal)

### C++
```cpp
#include <string>
#include <climits>
using namespace std;

class Solution {
    long long build(const string& s, int i, long long acc, int sign) {
        if (i >= (int)s.size() || !isdigit(s[i])) return acc;
        int d = s[i] - '0';
        // would overflow after applying sign -> clamp now
        if (acc > INT_MAX / 10 || (acc == INT_MAX / 10 && d > 7)) {
            return sign == 1 ? (long long)INT_MAX : -(long long)INT_MIN; // magnitude 2147483648
        }
        return build(s, i + 1, acc * 10 + d, sign);
    }
public:
    int myAtoi(string s) {
        int i = 0, n = s.size();
        while (i < n && s[i] == ' ') i++;
        int sign = 1;
        if (i < n && (s[i] == '+' || s[i] == '-')) {
            if (s[i] == '-') sign = -1;
            i++;
        }
        long long val = sign * build(s, i, 0, sign);
        if (val > INT_MAX) return INT_MAX;
        if (val < INT_MIN) return INT_MIN;
        return (int)val;
    }
};
```

### Java

class Solution {
    private long build(String s, int i, long acc, int sign) {
        if (i >= s.length() || !Character.isDigit(s.charAt(i))) return acc;
        int d = s.charAt(i) - '0';
        if (acc > Integer.MAX_VALUE / 10 || (acc == Integer.MAX_VALUE / 10 && d > 7)) {
            return sign == 1 ? (long) Integer.MAX_VALUE : 2147483648L;
        }
        return build(s, i + 1, acc * 10 + d, sign);
    }

    public int myAtoi(String s) {
        int i = 0, n = s.length();
        while (i < n && s.charAt(i) == ' ') i++;
        int sign = 1;
        if (i < n && (s.charAt(i) == '+' || s.charAt(i) == '-')) {
            if (s.charAt(i) == '-') sign = -1;

    }
}

### Python
```python
class Solution:
    def myAtoi(self, s: str) -> int:
        INT_MAX, INT_MIN = 2**31 - 1, -2**31

        def build(i: int, acc: int) -> int:
            if i >= len(s) or not s[i].isdigit():
                return acc
            # Python ints don't overflow; stop early once past the bound
            if acc > INT_MAX:
                return acc
            return build(i + 1, acc * 10 + int(s[i]))

        i, n = 0, len(s)
        while i < n and s[i] == ' ':
            i += 1
        sign = 1
        if i < n and s[i] in '+-':
            sign = -1 if s[i] == '-' else 1
            i += 1
        val = sign * build(i, 0)
        return max(INT_MIN, min(INT_MAX, val))
```

## Key Takeaways
- Preprocess spaces and the sign first; the recursion only needs to handle "digit or stop".
- Check overflow *before* multiplying by 10 (compare against `INT_MAX / 10`), or use a wider type and clamp at the end.
- Strings like `"+-12"`, `"  "`, `"words 42"`, and `"00012"` should give `0`, `0`, `0`, `12` respectively.
- Recursion depth is bounded by the number of digits, so stack overflow is not a concern here.
