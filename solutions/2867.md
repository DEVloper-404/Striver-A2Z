# For loops

**Difficulty:** Easy  ·  **Topic:** Learn the basics › Things to Know in C++/Java/Python or any language

## Problem
A `for` loop repeats a block of code a known number of times. It bundles three pieces into one line: an initializer (run once), a condition (checked before every iteration), and an update (run after every iteration). This topic explains the anatomy of the loop, common variations (counting down, stepping by k, nested loops, range-based loops) and how to reason about how many times the body runs.

Example task: print the first `n` natural numbers and their sum.

```
Input:  5
Output: 1 2 3 4 5
        15
```

## Approach: Anatomy and variations

**1. Standard form.** `for (init; condition; update) { body }`. For `n = 5`, `for (int i = 1; i <= n; i++)` runs the body 5 times with `i = 1..5`. The condition is tested *before* each run, so a loop whose condition is initially false executes zero times.

**2. Counting down and stepping.** `for (int i = n; i >= 1; i--)` visits `n..1`. `for (int i = 0; i < n; i += 2)` visits even indices. Python expresses the same with `range(start, stop, step)` where `stop` is exclusive: `range(n, 0, -1)` and `range(0, n, 2)`.

**3. Range-based loops.** When you only need the elements and not their positions, use `for (int x : v)` (C++), `for (int x : arr)` (Java), `for x in arr` (Python). Use `enumerate(arr)` in Python when you need both.

**4. Nested loops.** A loop inside a loop; the inner loop restarts for every outer iteration. Two loops of length n execute the body n^2 times. This is the backbone of pattern printing and brute-force pair enumeration.

**5. Controlling flow.** `break` exits the loop immediately; `continue` skips to the next update/condition check. In nested loops, `break` only exits the innermost loop.

**6. Counting iterations.** For `for (i = a; i <= b; i += s)` the body runs `floor((b - a) / s) + 1` times (if b >= a). This is the first step toward time-complexity analysis.

Pitfalls: off-by-one errors (`<` vs `<=`), modifying the loop variable inside the body, and using `int i` for a loop that should count up to 10^10.

- **Time:** O(n) for a single loop of n iterations, O(n * m) for nested loops of n and m
- **Space:** O(1)

## Code (Optimal)

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;

    long long sum = 0;
    for (int i = 1; i <= n; i++) {
        cout << i << (i == n ? '\n' : ' ');
        sum += i;
    }
    cout << sum << '\n';

    // count down, step by 2
    for (int i = n; i >= 1; i -= 2) cout << i << ' ';
    cout << '\n';

    // range-based over a vector, with break
    vector<int> v = {4, 7, 10, 13};
    for (int x : v) {
        if (x > 10) break;
        cout << x << ' ';
    }
    cout << '\n';

    // nested loops: n x n grid of stars
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) cout << '*';
        cout << '\n';
    }
    return 0;
}
```

### Java
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();

        long sum = 0;
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= n; i++) {
            sb.append(i).append(i == n ? "\n" : " ");
            sum += i;
        }
        System.out.print(sb);
        System.out.println(sum);

        for (int i = n; i >= 1; i -= 2) System.out.print(i + " ");
        System.out.println();

        int[] v = {4, 7, 10, 13};
        for (int x : v) {
            if (x > 10) break;
            System.out.print(x + " ");
        }
        System.out.println();

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) System.out.print("*");
            System.out.println();
        }
        sc.close();
    }
}
```

### Python
```python
def main():
    n = int(input())

    total = 0
    for i in range(1, n + 1):
        print(i, end="\n" if i == n else " ")
        total += i
    print(total)

    # count down, step by 2
    print(*range(n, 0, -2))

    # iterate over elements with break
    v = [4, 7, 10, 13]
    for x in v:
        if x > 10:
            break
        print(x, end=" ")
    print()

    # nested loops: n x n grid of stars
    for _ in range(n):
        for _ in range(n):
            print("*", end="")
        print()


if __name__ == "__main__":
    main()
```

## Key Takeaways
- A `for` loop is init → check → body → update, with the check happening before every iteration.
- `range(a, b)` in Python excludes `b`; `i <= n` in C++/Java includes `n` — the most common off-by-one source.
- Nested loops multiply: two loops of n iterations cost n^2 body executions.
- `break` exits only the innermost loop; `continue` jumps straight to the next update step.
