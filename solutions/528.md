# Connected Components

**Difficulty:** Medium  ·  **Topic:** Graphs [Concepts & Problems] › Learning

## Problem
A graph is not always one single "piece". If you drop your finger on a node and walk along edges as far as you can, you reach a set of nodes — that set is a **connected component**. The whole graph is partitioned into such components: every node belongs to exactly one, and no edge crosses between two of them. The task here is to understand this idea and to count the components of an undirected graph given `n` nodes (`0..n-1`) and an edge list.

```
Input:  n = 7, edges = [[0,1],[1,2],[3,4],[5,6]]
Output: 3          (components: {0,1,2}, {3,4}, {5,6})
```

## Approach 1: Why one traversal is not enough
The single biggest beginner mistake is writing `dfs(0)` and assuming the whole graph was visited. A traversal started at node 0 can only ever reach nodes that are *reachable* from node 0. In the example above, `dfs(0)` visits `{0,1,2}` and stops — nodes 3..6 are never touched, because no edge connects them to that block.

Key observation: **reachability in an undirected graph is an equivalence relation.** If `u` can reach `v`, then `v` can reach `u` (edges are bidirectional), and reachability is transitive. An equivalence relation partitions the set of nodes into disjoint classes — exactly the components. So a component is fully determined by *any one* of its members: start anywhere inside it, and one traversal marks all of it.

That gives the counting algorithm immediately: loop over every node; if it has not been visited yet, it must belong to a component we have not seen before, so increment the counter and traverse from it to swallow the entire component.
- **Time:** O(V + E) — the outer loop is O(V), and across all traversals each node and each edge is processed once.
- **Space:** O(V) for the visited array plus O(V) recursion/queue depth.

## Approach 2: The algorithm, step by step
1. Build an adjacency list from the edge list. For an undirected edge `(u, v)` push `v` into `adj[u]` **and** `u` into `adj[v]`.
2. Create `visited[0..n-1]`, all false, and `count = 0`.
3. For `i` from `0` to `n-1`:
   - If `visited[i]` is true, skip — some earlier traversal already claimed it.
   - Otherwise `count++`, then run DFS (or BFS) from `i`, marking every node it reaches as visited.
4. Return `count`.

Dry run on `n = 7, edges = [[0,1],[1,2],[3,4],[5,6]]`:
- `i = 0`: unvisited → `count = 1`, traversal marks `0, 1, 2`.
- `i = 1, 2`: already visited, skipped.
- `i = 3`: unvisited → `count = 2`, traversal marks `3, 4`.
- `i = 4`: skipped.
- `i = 5`: unvisited → `count = 3`, traversal marks `5, 6`.
- `i = 6`: skipped. Answer `3`.

Note that isolated nodes (degree 0) are components of size 1 and this loop handles them for free — the traversal just visits the node itself and returns. Also note DFS vs BFS makes no difference to the answer; only the order of visiting changes. Use BFS if `n` is large and recursion depth is a worry.
- **Time:** O(V + E)
- **Space:** O(V + E) including the adjacency list

## Code (Optimal)

### C++
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int countComponents(int n, vector<vector<int>>& edges) {
        vector<vector<int>> adj(n);
        for (auto &e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }
        vector<int> visited(n, 0);
        int count = 0;
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                count++;
                dfs(i, adj, visited);
            }
        }
        return count;
    }

private:
    void dfs(int node, vector<vector<int>>& adj, vector<int>& visited) {
        visited[node] = 1;
        for (int nb : adj[node]) {
            if (!visited[nb]) dfs(nb, adj, visited);
        }
    }
};
```

### Java
```java
import java.util.*;

class Solution {
    public int countComponents(int n, int[][] edges) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }
        boolean[] visited = new boolean[n];
        int count = 0;
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                count++;
                // iterative DFS to avoid deep recursion
                Deque<Integer> stack = new ArrayDeque<>();
                stack.push(i);
                visited[i] = true;
                while (!stack.isEmpty()) {
                    int node = stack.pop();
                    for (int nb : adj.get(node)) {
                        if (!visited[nb]) {
                            visited[nb] = true;
                            stack.push(nb);
                        }
                    }
                }
            }
        }
        return count;
    }
}
```

### Python
```python
from collections import deque
from typing import List

class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        adj = [[] for _ in range(n)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        visited = [False] * n
        count = 0
        for i in range(n):
            if visited[i]:
                continue
            count += 1
            q = deque([i])
            visited[i] = True
            while q:
                node = q.popleft()
                for nb in adj[node]:
                    if not visited[nb]:
                        visited[nb] = True
                        q.append(nb)
        return count
```

## Key Takeaways
- One traversal covers one component only; always wrap it in a loop over all nodes.
- Mark a node visited **when you push it**, not when you pop it, otherwise it can enter the queue several times.
- Isolated vertices count as components of size 1 — the outer loop handles them automatically.
- Disjoint Set Union (union-find) solves the same problem in near-O(E α(V)) and is the better choice when edges arrive online.
